# E1-5: 群れの出荷の順序と出荷の式の検証（2026-10-28）

親計画§7.71の検証記録。§7.70の判定に基づき2つの変更を試し、Worldを144か月進めた（入力・手順は§7.69と同じ、`scripts/auditHerdScale.mts`）。

## 試行A: 収容力の超過分だけを売る（不採用）

出荷量を（頭数−収容力）/（次の1月までの月数）に変えた。1312年の羊は収容力の1.42倍（超過42%）、牛0.83倍（超過11.5%）、飼料不足7.0%（変更前2.6%）に悪化した。

1305年の月ごとの追跡（同じ入力、66か月）では、羊の頭数/収容力は1月に0.93へ跳ね、12月の0.68まで出荷で下がる。この計測は1月の年次更新の直後に取っており、その年の子が加わった最大の頭数を見ている。変更前の式は、翌年の出生を先に売ることで出生後の頭数を収容力に合わせるもので、出生を二重に数えてはいなかった（§7.70の判定は誤り）。試行Aは、出生分を冬の間も抱えるため飼料が不足する。出荷の式は元に戻した。

## 試行B: 出荷は老いた家畜、更新に要らない若い家畜、繁殖用の順に取る（採用）

出荷の式は元のまま、管理された群れの出荷順を老→若（繁殖1頭あたり0.5頭を残す）→繁殖→残りの若に変えた（`applyHerdSale`）。

| 1312年 | 変更前（§7.69） | 試行B |
| --- | ---: | ---: |
| 牛の頭数/収容力 | 0.73 | 0.75 |
| 牛の超過/収容力 | 2.5% | 4.3% |
| 馬の頭数/収容力 | 0.65 | 0.67 |
| 羊の頭数/収容力 | 1.04 | 1.08 |
| 羊の超過/収容力 | 4.5% | 8.3% |
| 飼料不足（直近12か月） | 2.6% | 2.4% |
| 農村の主食 | — | 98.9% |

牛・馬はわずかに増えたが、収容力の±10%には入らない。1311→1312年の牛の増加は年2.7%で、出荷の順序は主因ではない。羊は判定（超過10%未満）を保つ。

## 判定

牛・馬の不足は、出荷の式や繁殖牛の売却ではなく、収容力を大きく下回ったまま出荷のないセルの成長の遅さにあると考えられる（1304年の追跡で、牛の頭数/収容力0.46のまま出荷は月約600頭と少ない）。セルごとの分布は未確認。
