## 確認

- 初回：`npx vitest run src/buildings/medieval/cartAndBakeryDetails.test.ts src/city3d/adoption.test.ts`：16件成功。
- 新しい6種のHighについて、実寸上限、接地、有限の頂点・法線、上面・側面投影、生成物間で独立した資源、一度だけの解放を検証した。
- 荷車・手押し車は、スポークの隙間をレイが通り、木製の輪では遮られること、荷受け部分が縁より低く開放されていることを検証した。
- パン屋3種は、窯口を通り抜け、隣のアーチ壁と奥の焼成室には衝突することを検証した。
- 外観確認で煙突の下端とドームに隙間が見つかったため、煙突を基台まで延ばした。支持が途切れないことを検出するテスト3件を追加し、パン屋関連9件だけ再実行して成功。今回確認した異なる項目は計19件。
- `npx tsc --noEmit`：成功。変更ソースのBiomeチェック、`git diff --check`：成功。
- 実BVで6種すべてのLow→High、Codex作者表示、三角形数、外観を確認。巡回中のJavaScriptエラーは0件。煙突の調整後、パン屋3種の画像と数値を更新した。
