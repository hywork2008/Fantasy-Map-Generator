# 乾燥地・草原・地中海の森林と植栽の適用確認

実施日：2026-10-29。対象：[樹木LOD作製計画](../plan/ce-forest-biome-tree-lod-tasks.md) F2-3（B02〜B06・B15・B20・B24・B25）。

## 結果

9バイオーム×疎密2設定×3視点の54条件をMetal GPUで確認した。樹種と混合条件、疎林表示、候補の安定、斜面接地、開口部の保護、採用版と資源解放が成功した。さらに森林の適用モードと保存済み公園・墓地の植栽選択を確認した。製品コード・モデル・作者・採用版の変更は不要だった。

確認画像はOSの一時ディレクトリで目視確認し、確認後に削除した。リポジトリには本記録・計測JSON・再現スクリプトを残す。

## 森林化の範囲と植栽の区別

バイオームは樹種を選ぶ入力であり、それだけでは森林領域を生成しない。適用範囲は `forestLandCover` の明示設定で決まる。

| 入力 | 現在の扱い |
| --- | --- |
| 森林設定なし／legacy、森林上書きなし | 新しい森林領域を選ばない |
| farmland | 対象の農地セルを森林化 |
| surroundings | 対象の農地と郊外の空地を森林化 |
| 手動のforest指定 | 許容対象の指定セルだけを森林化。legacyでも利用可能 |
| locked／水域／open指定／公園／市街の空地 | 今回の試験では森林化から保護 |
| 公園・墓地の保存済み立木 | 森林設定の有無と独立に、用途のpreferredとバイオームで樹種を解決 |

全9バイオームに同じ固定セル入力を与え、設定なし0、legacy 0、farmland 26、surroundings 51セルを選択することを確認した。6種類の保護セルは選ばず、手動指定は要求した1セルだけになった。設定変更用APIと植栽の収集処理は元の文書・保存済み植栽を変更しなかった。

草原・砂漠全体を自然林とみなす処理は追加していない。利用者が森林化した範囲や保存済み植栽を表現するための対応である。オアシス・河畔帯・土壌水分を検出して自動的に植える範囲を絞る機能はなく、自然分布が正しく再現されたとは判断しない。旧来の2D景観記号の散布は、この森林領域選択とは別の処理として残る。

## 現在の樹種と用途別選択

固定64地点の森林preferred（garden_parkland）と公園の選択は一致した。墓地は保存されたイトスギpreferredを共通セレクタへ渡し、既存の気候適応を維持した。

| ID | バイオーム | 森林／公園 | イトスギpreferredの墓地 |
| --- | --- | --- | --- |
| B02 | hotDesert | ナツメヤシ | ナツメヤシ |
| B03 | coldDesert | サクサウール | サクサウール |
| B04 | savanna | アンブレラソーン＋ナツメヤシ | アンブレラソーン |
| B05 | grassland | シナノキ | イトスギを維持 |
| B06 | tropicalSeasonalForest | アンブレラソーン＋ナツメヤシ | アンブレラソーン |
| B15 | mediterraneanWoodlandScrub | オリーブ | イトスギを維持 |
| B20 | xericShrubland | ギョリュウ＋ナツメヤシ | ギョリュウ |
| B24 | coldSteppe | サクサウール | サクサウール |
| B25 | tropicalDryForest | アンブレラソーン＋ナツメヤシ | アンブレラソーン |

草原の共通セレクタは用途側のpreferredを保持するため、森林からgarden_parklandを渡す結果を、全用途がシナノキになる規則とは解釈しない。地中海でもイトスギの用途を維持する。その他の文化・用途の全件確認はF4-2／F4-3の記録と合わせて判断する。

混合対象の4バイオーム（savanna・tropicalSeasonalForest・xericShrubland・tropicalDryForest）では、庭園／森林preferredの地点hashが0.3未満ならナツメヤシ、それ以外は各主樹種となる。今回の64地点はナツメヤシ18／主樹種46。固定入力での実測比であり、常に正確な30%を配置する保証ではない。季節林と乾燥林には現行2種を共有し、地域固有の追加樹種・季節表現は今回のモデル20種の対応確認から分ける。

## 固定描画と計測

[計測JSON](ce-tree-dry-biomes-20261029.json) に全54フレーム、64地点の樹種内訳、モード別対象数、用途別選択、接地誤差・境界余白・採用ID・候補配置のSHA-256、関連ソースのSHA-256を記録した。

- seed `ce-dry-biomes-v1`、96 m四方、中央24×16 mの開口部、面積8,832 m²。
- 森林品質standard、密度sparse／standard。これらは明示した試験設定であり、バイオームが自動設定した密度ではない。
- 傾斜は `heightAt(x,y)=5+0.05*x+0.02*y`。Apple M4／ANGLE Metal、400×400、DPR 1、CE既定照明・影なし。
- 俯瞰・林縁・低視点のカメラ位置はF1-4と同じ。可視instanceに付いた採用variant IDを現在の採用表と照合した。

| 密度 | 俯瞰の本数 | 林縁の本数 | 低視点の本数 |
| --- | ---: | ---: | ---: |
| sparse | 54 | 52 | 25〜28 |
| standard | 86 | 84 | 41〜48 |

同じ密度では、全バイオーム・視点で候補の位置と半径のSHA-256が一致した。樹高と樹冠幅の比は登録profileを使うため、樹種が違えばY方向の寸法や低視点の可視数は異なる。これを木の再配置とは扱わない。

接地誤差は最大 `2.622604364788117e-7 m`、候補の樹冠半径から外周・開口部までの余白は最小 `0.1276269542519004 m`。重複0、18回の森林解放後はいずれもgeometry 0、WebGL／page／consoleエラーは0だった。

疎密それぞれの9バイオームを一時画像で目視した。ヤシの縦長の樹形、アンブレラソーンの平たい樹冠、サクサウールとギョリュウの疎らな枝葉、オリーブの低い樹冠、混合配置と開口部が確認できた。全試験で共通の地表色を使っており、砂漠地表やオアシスの完成景観を示す画像ではない。
