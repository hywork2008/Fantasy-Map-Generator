## 3. 分かったこと

1. 市場間の交易と、お金の循環の目詰まりは、解消した。
2. 門の台帳は、町と農村のあいだの主な荷（主食の穀物・肉・干し草・農村の買い物）を記録していない。§4.2の観測（穀物91%）とは、もう同じものを測っていない。
3. このまま設計書のC0（台帳を`approachProfile`として渡す）を実装すると、CEは獣脂と鶏を主な荷として区割りを決める。設計書の§6.3（穀物市・家畜市・資材置き場）の判断は、今の台帳からはできない。
4. C0の前に、出荷を作らない流れも、通る門と一緒に台帳へ記録する必要がある。対象は、農村から町への主食、農村の穀物・干し草・肉の売り、農村が町で使うお金に当たる買い物である。経済の値は変えず、記録だけを足す（設計書§8の互換性と同じ）。

## 7. 飼い葉: 農家が払えない分まで買っていた(2026-11-01、実装)

`fodder.mts`(golden、1か月ずつ24か月)。

- 原因: 草刈りの時、市場は農家の冬の備えの不足分(`shortLots`)まで干し草を買う。農家が飼い葉に使えるお金は、毎月、農村の財布の5%である。値段はその払える量(`getFodderSeasonDemandLots`)で決まるのに、買う量は払えるかどうかを見ていなかった。払えない分は在庫に残り、値段は最低の0.25に張り付き、掛けの代金(`ruralHayPayable`)は返されないまま残った。
- 直し(試し): 買う量を、不足分と、次の草刈りまでに払える量の小さい方にした(`livestockFeed.ts harvestLivestockForage`)。

### 7.1 掛けを、農家の干し草の委託販売にした(利用者の決定: a)

- 掛け(`hayPayment: "onCredit"`)では、草刈りの時に値段を決めない。市場は受け取った干し草を、農家の分(`ruralHayConsignedLots`)として在庫に入れる。農家が飼い葉を買うと(`buyFeed`)、農家の分から先に売れたものとし、その売り上げを農村へ払う。農家の分を売り切った後は、市場がもともと持っていた在庫を売る。古い保存の掛けの残り(`ruralHayPayable`)は、その残りの売り上げから返す。
- 現金(`"cash"`)は今までどおり、その場で買い取る。草刈りの時の値段は現金の時だけ使う。
- 割合で分ける案(農家の分と市場の分を在庫の割合で売る)は試して、採らなかった。保存にあった市場の在庫(world-102 で 237,229)の分の売り上げが、いつまでも金庫に残った。

## 9. golden の町の人が主食を半分しか買えない理由(2026-11-01)

`townpurse.mts`で、町ごとに12か月の家計のお金の出入りを経路別に足した(平和モード、1か月ずつ)。

町の人口1あたり(1年):

| 経路 | golden | world-102 |
| --- | ---: | ---: |
| 主食の支払い | −154 | −343 |
| 農家が町で使うお金 | +49 | +249 |
| 町での消費(`spendInBurg`) | +83 | +124 |
| 国からの支払い | +9 | +63 |
| 製造 | +34 | +40 |
| 塩の卸の代金 | +92 | +15 |
| 余りの支出(町の金庫へ) | −59 | −48 |
| 塩の卸を除いた収入 | 192 | 566 |

1. **農家が町で使うお金が少ない。** world-102 の5分の1である。農家は毎月、農村の財布の5%を町で使う(`RURAL_HOUSEHOLD_TOWN_SPEND_SHARE`)ので、golden の農村の財布が小さいことによる。golden の町は、主食の必要の全部(人口1あたり約300)を、塩の卸を除いた収入(192)で払えない。
2. **塩の卸の代金が、塩田のある町に集まる。** golden では塩田のある町は3つで、代金の77%が上位2町(49・94)に入る。その2町は代金が余り、余りの支出(`spendUrbanHouseholdSurplus`)で町の金庫へ移す。同じ市場の他の町は足りない。最大の町 96(人口18.4)は、1年の収入が約150、主食の支払いが245だった。
3. 余りの支出は、町の中の職人・店への支払いとして町の金庫に入る(`burg.treasury`)。同じ町の家計の収入に戻らない。農家が町で使うお金は、以前に同じ理由で、25%だけを町の金庫、残りを町の家計にした(`RURAL_TOWN_SPEND_DUES_SHARE`)。余りの支出はまだ全部が金庫に入る。
