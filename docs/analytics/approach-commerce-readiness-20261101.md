[approach-commerce-quarters.md](../plan/approach-commerce-quarters.md)（門ごとの物流に応じた商業区）の実装の前に、設計書の§4.2（門の観測）と§4.5（市場間の交易の段階）を、今のコードで測り直した。コードは変えていない。

- コード: develop `5be97db8d`（[hay-trade-modes-20261101.md](hay-trade-modes-20261101.md)§15までと、developの季節の降水量を含む）。
- 入力:
  - `tests/fixtures/sim-golden.fmg`（5市場。§4.5と同じ入力。遠距離交易の設定`fmg-long-distance-trade`は`off`のまま）。
  - `docs/analytics/inputs/wet-pastoral-birth-20261029/world-102.fmg`（較正に使った世界。遠距離交易は`on`）。
- 平和モード、3年。`acq.mts`は1年ごとに、交易の段階（`trade()`）と門の観測（`gates()`）を記録した。`acqgoods.mts`は、門を通った品物を品物ごとに足した（golden、12か月）。

- 門の台帳（`approachTraffic`）が記録するのは、市場の中の小売の出荷（`retailInventory.ts`の`MarketShipment`）だけである。
- 町の主食は、市場の食料の台帳（`foodLedgerConsumption.ts`）から、出荷なしで町に渡る。農村の穀物の買い上げ、肉、干し草の買い上げも、出荷を作らない。そのため、門の台帳に入らない。
- §4.2では、穀物が積載枠の91%だった。その後の食料の台帳の変更（2026-10-18〜10-29の一連の変更）で、穀物は小売の出荷を通らなくなった。どのコミットで変わったかは、確かめていない。
- 今の台帳では、獣脂・鶏・飼い葉が門の荷の大部分に見える。中世の町の門を通った荷の大部分は、穀物などの食料だったはずである（設計書§3.1の穀物市・干し草の市）。

## 3. 分かったこと

1. 市場間の交易と、お金の循環の目詰まりは、解消した。
2. 門の台帳は、町と農村のあいだの主な荷（主食の穀物・肉・干し草・農村の買い物）を記録していない。§4.2の観測（穀物91%）とは、もう同じものを測っていない。
3. このまま設計書のC0（台帳を`approachProfile`として渡す）を実装すると、CEは獣脂と鶏を主な荷として区割りを決める。設計書の§6.3（穀物市・家畜市・資材置き場）の判断は、今の台帳からはできない。
4. C0の前に、出荷を作らない流れも、通る門と一緒に台帳へ記録する必要がある。対象は、農村から町への主食、農村の穀物・干し草・肉の売り、農村が町で使うお金に当たる買い物である。経済の値は変えず、記録だけを足す（設計書§8の互換性と同じ）。

## 5. O5 の後の測り直し

出荷を作らない流れの記録([approach-traffic-observatory.md](../plan/approach-traffic-observatory.md)§12)を足して、golden で測り直した。

| 品物 | 積載枠(1か月ずつ12回) | 積載枠(12か月を1回) |
| --- | ---: | ---: |
| 獣脂 | 2,296,730 | 0 |
| 飼い葉 | 2,079,340 | 3,157,016 |
| 木材 | 925,495 | 2,871,844 |
| 鶏 | 548,195 | 0 |
| 穀物(Grain) | 106,793 | 27,893 |
| 大麦 | 20,802 | 224,848 |

- 獣脂: 3年目ではなく1年目から、各市場の獣脂の在庫は140万〜270万樽で、価格は最低の0.5である。burg 59→96 と burg 2→97 の小売の出荷が大部分を占める。獣脂の作りすぎか、使い道がないことによる在庫の積み上がりで、門の台帳の問題ではない。
  - 原因と修正: と畜の獣脂を recipe の係数で数え、牛1頭が360 kgになっていた。重さで数えるようにした([goods-physical-units.md](../plan/goods-physical-units.md)§40)。修正の後、門を通った獣脂は25,078積載枠になった(修正の前は2,296,730)。
- 進め方による違い: 同じ入力でも、1か月ずつ12回進めた場合と、12か月を1回で進めた場合とで、門の荷が大きく違った(獣脂と鶏は0になる)。§2の値は、1か月ずつ進めた`acqgoods.mts`のものである。
  - 原因: 生産・交易の決算(`production.settle`)が microtask へ遅らされ、複数日を同期で進めると期間の最後にまとめて動いていた([ce-roadside-growth-observation.md](../plan/ce-roadside-growth-observation.md)§2.2 の P0)。
  - 修正: その日の終わりに決算するようにした。修正の後は、12か月を1回で進めても、1か月ずつ進めた上の表の左の列と完全に同じ値になる。
- 主食の穀物は、1年に約2.8万〜10.7万積載枠である(人口点241の5市場)。町の数と比べて少なすぎないかは、まだ確かめていない。
