# Salt S3 代金と賃金（2026-10-23）

S3を実装した。家計・家畜の購入、国営製塩所の賃金と燃料購入、卸・国際購入・輸送の支払を既存の現金口座へ接続した。塩の必要量は価格で縮小せず、購入できない分は不足として残す。次はS4の持ち主の分離。

## 決済と出力の方針

詳細は[仕様のS3節](../simulation/salt-logistics.md#s3-代金賃金2026-10-23)。新規の独立した資金プールは作らず、現行の保有国庫を製塩事業の財布とする。

- 保有国が実製造分の賃金を作業班の都市家計へ、Wood代を発地市場の営業現金へ払う。作業者月と既存の地域穀価連動賃金から算出する。
- 着地市場が出発前に卸と運賃を全額前払いする。国際購入は着地市場→輸入国→輸出国を同一決済内で通し、追加の国庫補助を作らない。新規製塩の売上は国庫、既存在庫の売上は在庫所有市場へ渡す。
- 売主側国庫が既存の物量・距離に応じた運賃を発地中心都市の家計へ払う。卸代金と一緒に前受けした運賃を渡すので、別途無制限な輸送予算を作らない。
- 家計は既存の都市・農村財布から購入する。都市は所属国家と市場を一致させ、別の都市財布を肩代わりに使わない。農村財布は従来どおり市場単位のプールである。家畜補給も農村財布から購入する。
- 国庫の賃金・燃料資金、着地市場の卸資金、家計資金が不足した分は生産・購入しない。営業現金から農産物未払・交易未払・輸送中の後払い約定を除く。資金不足を借金や無料配給で埋めない。
- 出荷時の`wholesalePaid/freightPaid`を保存し、到着時は再請求しない。旧保存貨物の欠落フィールドにも遡及請求しない。既存の資金・現物・設備能力は注入・リセットしない。
- 請求をセント単位にそろえ、国庫・市場の既存残高のセント未満の端数は保持する。賃金の財布間配分残は最後の受取先へ渡す。

価格は物理的な月必要量・市場在庫・供給費用参照から平滑化し、一般商品のutilitiesベースの更新で床へ押し戻される経路から外した。価格の平滑化・需給の上下限・卸の費用回収余力5%等はモデル上の仮定で、史実価格の校正値ではない。

出力に小売価格への弾力式は追加しないと判断した。必需量を維持し、需要・能力・物理入力・運転資金・買い手資金で決める。新規の卸は実賃金燃料費を下回らない見積りを用い、採算不足を理由に必要量をゼロへ書き換えない。家計の支払増はその後に使える同じ財布の残高を減らす。これは回帰テストで同じ現物量を異なる価格で購入して確認した。
