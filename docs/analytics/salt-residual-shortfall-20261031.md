## 4. 分かったこと

1. **製塩所は需要以上を作っている（塩の優先順位の1）。** 在庫と人手による不足は無くなった。残る不足（1306年に家畜4.7千袋、人1.9千袋。需要の1.0%と0.7%）は、すべて買い手のお金による。
2. **家畜の不足は、新しい小さい市場24・25・27の農村の財布の小ささと、運び賃による高い値段が重なった所に出ている。** 推測のとおりだった。農村の財布は市場1の約360分の1である。
3. **人の塩の不足は、市場14・16・21の町の家計の財布の小ささによる。** 都市のお金の不足と同じ原因である。
4. どちらも塩の仕組みの不具合ではなく、家計の現金収入の問題である。塩の側で上限や掛けを広げると、2つの問題が起きる。
   - 返せない掛けが増える（優先順位の3に反する）。
   - 原因が見えなくなる。
   - よって、塩の側は変えない。

## 5. 次に決めること

- **農村の現金収入（市場22〜27）。** 町がほとんど無い市場では、農村が穀物や家畜を売る相手がいない。ほかの市場へ売る道を作るかを決める（[urban-money-shortfall-20261031.md](urban-money-shortfall-20261031.md)の未決の事項）。
- **町の家計の財布（市場14・16・21）。** 国の税の見直し（既定の塩税か普通の税か）と一緒に見る。
- **市場24の値段が仕入れ値より低いこと。** 塩を売る市場の金庫が損をしていないかを、ついでに確かめる。量は小さい。
