# 葡萄畑の無い市場の干し葡萄とワイン（2026-11-10）

[raisin-trade.md](../plan/raisin-trade.md) §5の4。干し葡萄とワインの足りない分が、葡萄畑のある市場と無い市場のどちらにあるか、無い市場へ運ばれない理由はどこかを調べた。

## 1. 条件

- 地図は北緯30°の2枚（2102・2103、[barilla-20261108.md](barilla-20261108.md)）、24か月、戦争なし・隊商の略奪なし。コミット22c2967d8を凍結したworktreeで動かした。
- 計測スクリプトは[marketprobe.mts](fruit-reach-20261110/marketprobe.mts)、実行は[run.sh](fruit-reach-20261110/run.sh)。
  - 12か月目と24か月目に、市場ごとの帳簿（累計）・在庫・値段・ワインの土地の度合い・町の人を取り、差を2年目とした。
  - 2年目のその市場のセルで葡萄が実った市場を「葡萄畑のある市場」とした。
  - 2年目に、市場の間の取引の照合の各段階で止まった組（売る市場 → 買う市場）の数を、品ごとに数えた（`setTradeStageObserver`）。

- ワインの足りない分の85〜81%は、葡萄畑のある市場の中にある。葡萄畑のある市場は、自分のワインの土地の需要も満たせていない。
- 葡萄畑の無い市場には、ワインはほとんど届かない（年1樽）。干し葡萄は、需要の8〜5%が届いた。
- 干し葡萄の足りない分の73〜65%は、葡萄畑の無い市場にある。

干し葡萄は値の差から先に組む道（speculative、2102で189・2103で55）を通り、pairの段階を通らない。

- ワインは、組の92〜85%が「運べる荷の決まり」で止まる。これは重さあたりの値段で決まる運べる日数の上限（`getGoodMaxTradeDurationDays`の`densityLimit`）である。
  - ワインの値段は200 Lの樽で1.28（穀物の重さあたりの約3倍）、重さと嵩は3・3なので、上限は陸で約10日、川で約20日、海で約100日になる。
  - 1樽の値段を8から1.28へ下げた時（[goods-physical-units.md](../plan/goods-physical-units.md) §29）に、陸の上限も約6分の1になった。
- 干し葡萄は、買う市場にお金が無いところで多く止まる。運べる日数の上限（陸で約40日）では止まっていない。

## 4. 読み取り

1. ワインの足りない分は、ほとんど葡萄畑のある市場の中にある。セルの加工の労働の上限（セルの人の15%、`CELL_FOOD_PRESERVATION_LABOR_SHARE`）で、搾る量が止まっている（[grape-season-20261110.md](grape-season-20261110.md) §3）。運ぶより先に、この上限を見直す必要がある。
2. 葡萄畑の無い市場へワインが届かないのは、陸で約10日の運べる日数の上限による。中世のワインは、多くが川と海で運ばれ、陸の運びは高くついた。この上限が史料より厳しいかは、陸と川のワインの運びの史料で確かめる必要がある。
3. 干し葡萄は、葡萄畑の無い市場の町にお金が無いところで止まる。葡萄畑の無い市場の干し葡萄の需要は、2年目で年約900荷（約225 t）である。
