# E1: 越冬できる頭数への制限（2026-10-25）

親計画§7.45の検証記録。比較元は§7.44の変更後（[e1-market-supply-20261024](e1-market-supply-20261024.md)）、比較先は本作業ツリー。固定入力・設定は同じ。

## 原因の確認（World102、2年目の12か月）

| 項目 | 千t乾物 |
| --- | ---: |
| 必要量 | 2,305 |
| 放牧 | 1,213 |
| 干草給与 | 517 |
| 未充足 | 576 |
| 干草収穫 | 841 |
| 刈られず残った余剰草 | 3,127 |

- 土地は足りていた。未充足の原因は干草作りの人手。草の余剰は穀物の収穫期と同じ月に出るため、大人が収穫に取られて刈れない。
- 越冬に必要な干草を自分の草地から作れるかを、計画（`calculateLivestockHayPlan`）で解いても制約にならなかった（全セルで1）。
- 一方、収容力は年間の草の量だけで決まり、前年に実際に何頭を養えたかを見ていなかった。そのため、冬に飢える群れが毎年そのまま維持されていた。

## 変更

1. **前年の給与実績による制限:** `getRecentlyFedHerdShare` で直近12か月（年次更新が12月の決済より先に走るため、10か月以上を条件にした）の給与率を求める。給与率が1未満なら、収容力を「現頭数×給与率」に制限する。上限を超えた成畜は既存の年次調整（秋に55%）で売却・屠畜される。越冬できない分を秋に処分する、冬前屠畜の考え方。
2. **越冬分の干草による理論上限:** `calculateWinterFeedShare` を追加した。夏の余剰を干草にして端境期を越せる頭数の割合を求める。今回の入力では制約にならなかったが、草地が足りない寒冷地の安全弁として残す。

## 判定

- Worldでは、飢える群れを維持し続ける状態が解消に向かい、未充足は36か月で13%まで下がった。まだ低下途中で、収束していない。
- 代わりに牛は1人あたり約0.07頭まで減った。史料の約0.35頭を大きく下回る。干草作りの人手が穀物の収穫と重なることが、そのまま群れの規模を決めている。
- 次の論点は、干草作りの時期（史実では穀物の収穫の1〜2か月前に刈る）と人手の重なり方。刈り取りを草の成長の山の前半へ寄せる計画と、季節の雇用・互助を確認する。
