## 1. 基準の確定範囲

「人が食べた塩」「食品加工で投入した塩」「家畜への購入給塩」「産出」を分ける。塩蔵後の脱塩・廃液・ホエーへの流出があるため、加工投入量をそのまま人の摂取量へ加えない。史料の配給・税の強制購入量も生理的な必要量とは区別する。

| 用途・プロファイル | 確認できた量・単位 | 証拠の性質とS0での扱い |
| --- | --- | --- |
| 前近代欧州・料理への添加 | 3.5〜4 kg/人/年 | フランス文化省の考古学解説[A]。地域・階層別の原帳簿の幅ではなく、桁の照合に使う研究機関の概括値。既存の3.6 kgはこの範囲内だが、全人口への納品を保証しない |
| 前3千年紀・北中部アナトリア | 3.6 kg/人/年 | Dardeniz[B]が既往研究の10 g/日を人口推計へ当てたモデル。実測値でも中世欧州の原典でもない。10×365/1000は3.65 kgであり、3.6は概数。現行コードは年3.6 kgを12等分する |
| 前2世紀・イタリアの農場労働者 | 1 modius/人/年 | Cato『農業論』58[C]の配給。質量への換算・対象人口・保存用途の境界が不確かなため、そのままkgの目標値にしない |
| 中世欧州・肉の塩蔵 | 肉重量の少なくとも10% | [A]。肉の加工量×投入率として照合する。年kg/人は地域の保存加工量がないため**基準なし** |
| 中世欧州・乳加工 | バター重量の10%、チーズへの添加5〜10% | [A]。投入率であり製品の残留塩分ではない。年kg/人は乳製品の加工量がないため**基準なし**。現行Cheeseの1.5%との比較では投入と残留を分ける |
| 中世・13世紀以降の保存加工全体 | 塩産出の50〜60%という概括 | [A]。人の摂取比率ではない。固定枠2.4 kg/人の実消費を裏づける値として使わない |
| 古代地中海・魚の長期塩蔵 | 魚重量の30%以上の方式 | Alessandriほか[D]が古代の加工法を検討。全ての魚・軽塩・燻製に適用しない。漁獲量ではなく実際にこの方法で塩蔵した魚の重量が分母。年kg/人は**基準なし** |
| 古代中央イタリア・家畜 | 牛20〜30 kg/頭/年、羊・山羊1.4〜5 kg/頭/年という既往推計 | Sotgiaほか[E]の比較。実測でなく推計間の差が大きい。前近代欧州の購入給塩量としては**基準なし**。飼料・飲水・自然の塩場に含まれる分を引かず、全必要量を市場購入に置かない |
| 中世後期ドイツ・総量15〜16 kg/人/年の旧候補 | **採用基準なし** | 旧リンクの解説[F]に記述はあるが、原典・人口・用途の内訳を確認できていない。料理用3.6 kgと直接比較して不足倍率を出さない |

料理用3.5〜4 kgと加工の投入率は初回照合に使える。家畜の既往推計は購入給塩の採用係数にしない。**総量6 kg/人/年を史実の確定値とする根拠は得られていない**。S1では家計、実際の食品加工、購入給塩を別に求め、同じ需要を重複計上しない。史料がない用途をゼロ需要と確定したわけではない。

### 保存則の監査上の留保

`期末（市場＋塩専用輸送中）−期首（同）−Σsource＋Σsink`は、provinceで**+1,145.202 kg**、worldで**+262.247 kg**残る。worldでは一般交易のimportArrival/exportDeparture各71,700 kgと、navyExport 235,714.682 kgも別記される。一般輸送中・海軍への移動を最終消費と扱わず、この残差は上記境界と記録イベントの照合残とする。

塩業所のsourceフローと丸め済み国家台帳の産出にもprovinceで+3.856 kg、worldで−2.919 kgの差がある。残差全体をこの丸め差で説明したことにはしない。無償補正・自動的な損耗認定は行わない。S1〜S2で市場在庫の更新箇所、輸送と丸めの境界を追う対象として残す。

## 5. S0残作業の追補（2026-10-23）

### 5.1 追加調査と基準の採否

追加調査は、古代の給塩原典、1300年前後のイングランドの荘園研究、中世スウェーデンの塩の研究を対象とした。全時代・全地域の史料を調べ尽くしたという意味ではない。§4.0の「確認できない項目は基準なし」とする規定に従い、今回確認できる範囲を以下で確定する。

| 項目 | 確認結果 | 採否とS1への契約 |
| --- | --- | --- |
| 古代ギリシアの羊への給塩 | Aristotle『動物誌』VIII.10、596aの英訳原典[G]には、夏に羊100頭へ5日ごとに1 medimnusを与える記述がある | 季節・群れ・容積の記述として採用。夏の日数、塩のかさ密度、こぼれ・食べ残し、自然摂取、市場購入の割合が未確定。kg/頭/年へ外挿せず、中世の購入係数には使わない |
| 中世イングランド・Peterborough修道院領 | Biddick[H]の原研究、1125年調査のTable 9（p.48）に塩27 modiiの貢納、14世紀初めの酪農費用（pp.96–97）に塩・圧搾器・攪乳器等を含む費用がある | 貢納と酪農費用は人の摂取量・生きた家畜への給塩量とは別物。対象人数・kg換算・用途別物量がそろわないため、地域総量kg/人/年と給塩kg/頭/年は**基準なし** |
| 中世スウェーデン・Stora Kopparberget | Söderberg[I] pp.140–141は1347年の労働規定に、労働者へ年約14 kg、職長へ34 kgの塩の現物給与があると報告。実際に履行された程度は不明とする | 地域・階層別の現物給与の事例として記録。原規定からの換算過程・家族への配分・保存投入・転売を確定できず、一般住民の摂取量・総消費の範囲には採用しない |
| 中世後期ドイツ15〜16 kg/人/年 | 初回[F]の二次記述から、人口・用途の分母が確定した原典へは到達できなかった | **採用基準なし**を確定。6 kgの代替目標にはしない |

- [G: Aristotle, History of Animals, Book VIII](https://penelope.uchicago.edu/aristotle/histanimals8.html), D'Arcy Wentworth Thompson英訳、§10。シカゴ大学公開の原典本文。
- [H: Kathleen Biddick, The Other Economy: Pastoral Husbandry on a Medieval Estate](https://publishing.cdlib.org/ucpressebooks/public/book/the-other-economy-pastoral-husbandry-on-a-medieval-estate.html), UC Press, 1989, Table 9 / The Cattle Herds, pp.48, 96–97。荘園資料を分析する原研究。貢納の出典はChronicon Petroburgense、費用の出典はFitzwilliam Account Rollsであり、未閲覧の帳簿原本まで確認済みとは扱わない。

これにより、料理・肉/乳加工・魚塩蔵・家畜それぞれについて「照合範囲」「直接採用しない数字」「基準なし」の境界を固定する。基準なしは需要ゼロでも係数自由でもない。S1で給塩需要を実装する場合は、自然由来の摂取と購入を分け、採用する暫定値・適用種・季節・不確実性を別途明記する。生理的要求量、古代の給塩量、中世の市場購入量を同一視しない。
