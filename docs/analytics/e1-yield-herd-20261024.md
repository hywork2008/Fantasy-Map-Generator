# E1: 作物気候の修正と家畜係数の史料化、36か月比較（2026-10-24）

親計画§7.43の検証記録。固定入力 `docs/analytics/inputs/salt-s0-aligned-20261023/`、Standard・遠距離交易on・隊商襲撃off、盛期中世。変更前＝HEAD `63086e766`（§7.41の実装済み）、変更後＝本作業ツリー。生成: `scripts/auditHerdScale.mts`（schemaVersion 2で耕地/人・平均単収を追加）。

## 変更

1. 開墾した温帯林の土壌を`humus`→`loam`（寒冷林`cold`は`humus`のまま）。経済側`getCellSoilType`とホスト推定`getEstimatedFoodSoil`を同じ規則に揃えた。
2. 多雨側の作物適性: 理想上限→ECOCROP上限で1→0.6（旧1→0）、上限超過は0.6×√(上限/降水)（旧0.25×上限/降水）。
3. オフライン校正表`foodClimateCalibration.json`と`docs/calibration/food-climate.csv`を再生成し、指紋・検証テストを回復した。校正の固定入力でhumusの行は`forest+cold`。
4. 家畜係数: 役畜0.29/耕地ha（上限は農村1人0.36頭）、馬40%、役牛1頭あたり非役用の牛2頭、羊1.3/人（Allen 2005 Table 2・3、Broadberry et al. 2010 Table 1・4）。
5. 豚0.2/人（同上）、鶏1/人（出典なしの仮置き）を実人口から計算。出荷は群れ由来に統一。旧群れの一度だけの引き上げはbaseline v2で豚・鶏にも適用。

## 判定

- 耕地/人はイングランド1300（0.99ha）の桁に入った。単収は基準450kgの約55〜65%で、冷涼な気温（年平均0〜7℃）の地域が多いことによる。
- Worldの主食は3年目で農村97%・都市92%に改善した。Provinceは2年目94%から3年目77%へ下がる。初期備蓄の取り崩し後に収穫が需要を下回る傾向が残っており、収穫と労働の年次推移を次に確認する。
- 牛の収容力は需要目標の約4割のままで、牧夫と飼料の人手が律速。耕地が半減しても解消していない。畑の労働日数と牧畜の労働の配分が次の対象。
