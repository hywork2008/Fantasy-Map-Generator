# Medieval 42 — Ottoman Balkan caravanserai High (2026-11-02)

`balkan-caravanserai`にCodex GPT-6.1 Solの明示的なLow／Highを登録した。既存Lowの形状署名とdefault IDは維持する。地域的な架空外観のモデルであり、特定の実在遺構の再現ではない。

## 構成と共通化

Highは中庭、宿泊棟、前面サービス棟、門、回廊、外階段、家畜設備、水槽の8部品。それぞれ独立factoryから必要な部品だけを生成し、BVで全体／単体を切り替える。既存の材質結合と部品台帳を使用する。

- 宿泊棟3棟は連続した床と上階床、部屋の間仕切り、内側の共用通路、中庭に開く上下階入口、外側窓を持つ。正教会修道院で共用化した開口付き石造壁へ丸アーチを指定し、壁の生成を重複実装しない。北棟の端では隣接棟に塞がれる入口を作らず、共用通路から客室へ通じる。
- 前面2棟は平屋のサービス棟。門の母体へ少し重ねて隙間を防ぐ。宿泊棟の上階とは分け、階段の無い上階客室を増やさない。
- 門は幅3.2 mの通過開口を持つ連続したヴォールト、内外の迫石、側柱、笠石。中央で床から天井まで約4.3 m確保する。
- 上階回廊の床上面は3 m。東・西・北をつなぎ、角と階段接続部分では手すりを開ける。柱・床梁・屋根桁・方杖・垂木で支える。連続した上屋を宿泊棟へ重ね、特定の付属物用の屋根穴は開けない。
- 階段は既存`createExteriorStair`を高さ2.84 m・踏面合計4.5 m・幅1.2 mで再生成し、中庭床0.16 mから回廊床3 mへ接続する。完成階段を変形して合わせない。上端の開いた側が回廊へ接し、共通の入口保護を維持する。
- 給餌槽4基と水槽は既存Highを再利用し、依存元IDも記録する。既存High給餌槽には315本の干し草があり、4基分で50,400三角形だった。共通factoryへ`filled: false`を追加し、隊商宿では空の詳細木部を使う。既存の干し草入り単体Highの形状署名は不変。
- 屋根は共通`ModelKit.roof`による連続面と支持材を使い、コースの重なりと丸瓦の筋を追加。多数の独立した瓦を配置せず、全体の描画量を抑える。

任意の部品交換や寸法調整のUIは今回追加しない。BV用モデルは品質登録へ追加したが、CEが生成する既存の隊商宿施設をこのモデルへ置き換える変更は行っていない。
