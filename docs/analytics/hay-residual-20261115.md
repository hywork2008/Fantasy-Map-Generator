## 3. 70の土地の大人の働き先（2102、1か月目の割り当ての暦）

- [slack-2102.json](hay-catchup-20261115.md)（§1の出力、SHA 5d9c3755…）から、§1の15か月目の70の土地を抜き出した。大人105,333人、子ども97,073人。荒れ地・湿地・針葉樹林・落葉樹林が8割。

（千日。2月は1月、4〜6月・8月・11月は3月・9月・10月と同じ傾向。干し草・世話は計画の日数）

1. 3〜11月は、畑仕事の暦だけで大人の働ける日数を超える。超えた分は手伝い（家族・近隣・市場圏・町）に回る。干し草と世話は畑の後に残る日数から取るので、取れない。
2. 食料以外の仕事はほぼ0である。家の織物は0（割り当ての最後で、残りが無い）、狩猟・漁労・ぶどうも1千日。運搬・建設・護衛などは町の側の仕組みで、この上限から農村の大人を取っていない。
3. 手が余るのは12〜2月だけ（月約110万日）で、干し草の季節と合わない。
4. 上限の月11.7日（年140日）は、[farm-labour-calibration.md](../plan/farm-labour-calibration.md) §1.1で「男女の成人をならした、自分の畑の作業に回せる日数」として決めた値である。同じ節の史料では、成人男子の実働は250〜300日で、畑の外の日数は「家畜の世話、運搬、雇われ仕事、手工業など」に充てられた。女性は普段、家事・家内工業・家畜の世話をし、収穫の時に畑へ出た。今の割り当ては、家畜・干し草・家の織物も畑の140日の中から取っており、年の残り（男子で約110〜160日）はどの仕事にも割り当てていない。
5. 規模：70の土地で、1年に刈らずに残った草386百万kgを刈るのに要るのは約1.16百万日（3日/t）。大人1人あたり年11日である。
