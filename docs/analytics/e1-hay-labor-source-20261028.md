# E1: 干草作りの作業日数3日/t乾物の史料照合（2026-10-28）

親計画§7.68の記録。§7.44以降、`HAY_WORK_DAYS_PER_TONNE_DM = 3`（干草1t乾物あたりの延べ作業日数）と`PASTURE_ANNUAL_DM_KG_PER_HECTARE = 1500`の史料照合が残っていた。計測はない。

## 照合した資料

- Victoria County History, Wiltshire vol.4「Medieval agriculture」: 慣習保有農の草刈りは「おおむね1日に1エーカーか½エーカー」。Heddington（1280年まで）は「1日に½エーカーを刈って持ち上げる」、Fiddington（1309年）は「2刈り幅で1日の仕事」。Amesbury（1295年）は草地36エーカーの草刈りと干草の反転・運搬に13s.6d.を払い、干草を積み上げる（cock）のは別の小屋住み農の仕事だった。Oaksey（14世紀）は干草の反転と運搬に1人1日の賦役。
- 草刈りの速さ½〜1エーカー/日は、1haあたり2.5〜5人日に当たる。反転・積み上げ・運搬は草刈りとは別の人手で、同程度以上の人日を要したと見られる（定量的な値は未確認）。

## 照合

- モデルの草地の生産1.5t乾物/haを全量刈るとすると、3日/tは1haあたり4.5人日で、草刈りだけの2.5〜5人日の範囲に収まり、反転・運搬を含めると下限に近い。
- 草地の単収（1エーカーあたりの干草の荷・t）の中世の値は見つからず、1.5t乾物/haは未確認のまま残る。単収が低ければ1tあたりの日数は増える。

## 判定

3日/tは史料の範囲の下限として維持し、コメントに出典を記した（`src/extensions/economy/generators/livestockFeedPolicy.ts`）。引き上げると、§7.63〜§7.66で人手が律速と分かった干草の不足が増えるため、引き上げは草地の単収の照合と合わせて判断する。
