# 石鹸の炭酸カリウムの計測（2026-11-09）

設計は[town-soap.md](../plan/town-soap.md) §3.5。炭酸カリウムを校正の表に入れ、市場の最低量を柔らかい石鹸の最低量の材料の分とした。

## 1. 条件

- 地図と条件は[town-soap-20261108.md](town-soap-20261108.md) §1と同じ（北緯30°の2枚、シード2102・2103、24か月、`FMG_CONFLICT_AUTONOMY=peace`、`FMG_CARAVAN_RAIDS=off`）。
- 実行は[run.sh](soap-potash-20261109/run.sh)、集計は[summary.py](soap-potash-20261109/summary.py)、出力は[summary.txt](soap-potash-20261109/summary.txt)。

| 名前 | コード |
| --- | --- |
| base | 石鹸2つの校正の行まで。出力は[town-soap-floor-20261109.md](town-soap-floor-20261109.md)のfloorを使った |
| potash | base＋炭酸カリウムの校正の行（`floorFromSoapPotash`） |

## 2. 結果

単位は樽。13〜24か月目。

- 石鹸の買い物は約2.5〜2.8倍になり、需要の5割を超えた。作った石鹸は全部買われ、在庫は0のまま。
- 月の買い物は16か月目に一番多く（2102で1,977樽、2103で1,449樽、需要は月2,783・1,887樽）、そのあと2102で月1,200〜1,500樽、2103で月700〜1,000樽に下がった。下がった訳は調べていない。
- 炭酸カリウムは在庫が少し残り、値段が約4割上がった。灰は在庫が増えた。獣脂は在庫が多く残る。
- 柔らかい石鹸が市場の間を運ばれるようになった（年460〜810樽）。
- 白い石鹸は変わらず少ない。

## 3. 結論

- 炭酸カリウムの校正の行は残す。石鹸は需要の約2割から約6割になった。
- 16か月目の後の買い物の下がりを調べる。
