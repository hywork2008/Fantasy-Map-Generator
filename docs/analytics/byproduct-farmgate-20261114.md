## 5. 読み取り

1. 農家は副産物の代金として1か月約1.8万（2103）を受け取り、農村の家計は約9%増えた。前の[money-flow-20261114.md](money-flow-20261114.md)で、国の予算と親方の取り分で減った農村の家計（2〜4%）を上回る。
2. 1年目は、品不足で革が価値の約1.5倍だったため、払いが大きく、市場のお金が約17%減った。2年目から革が価値の約半分になり、市場の減りは約5%に縮んだ。
3. 市場は、払った分のおよそ4割を、農村への払いが減ることで取り戻している。残りは農村から町へ回り、町の家計と町の金庫が増えた。
4. 7つの持ち手の合計は、2102で+0.7%、2103で+0.3%。代金の払いはお金を動かすだけなので、差は他の段のお金の生まれ方・消え方が変わったためと見られる（段は未確認）。
