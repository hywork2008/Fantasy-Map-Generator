# メッシュなしCE 施設は建物の外形で区画を取る（U3 手順3）

2026-11-13。[受入前の改善](../plan/ce-meshless-pre-acceptance-improvements.md)のU3。ユーザーが施設ありの町のSVGで空き地を赤く塗った図（市壁内の約28%）を受けた作業。空き地は「施設の庭」「余った区画」「列の間の中庭」がそれぞれ約9%と見積もり、このうち施設の庭を除く。列の間の中庭はユーザーの判断で残す（不採用）。

## 変更

1. **施設の敷地は建物の外形だけ**（`facilityLots.ts`の`placeFacilitiesOnLots`）。これまでは建物が触れた区画を区画線まで丸ごと敷地にしていたので、敷地の31〜41%が庭になっていた。今は敷地＝外形で、他の施設の敷地とは重ならない。
2. **施設が切った区画は、残りに住宅が建つ**（`perimeter.ts`の`fitLot`）。施設の外形が区画にかかった時、残りが区画の半分以上かつ15 m²以上の一続きの形なら、その形の住宅を建てる。住宅は施設の壁に接する。それより小さい残りは空き地になる。
3. **施設を区画線に合わせて置く**。建物を街路に沿って滑らせる候補に、建物の側面が列の区画線に重なる位置（中心に近い順に12）を加え、残りが住宅にならない土地（無駄）が最も少ない位置を選ぶ。無駄が5 m²未満なら打ち切る。
4. **施設は並んで建つ**。種の区画を、既に置いた施設に接する区画、施設のある街区の区画、その他の順に試す（商業と川沿いの施設は除く）。これまでは抽選の順で町中に1軒ずつ散らばっていた。
5. **市壁の大きさの見積りの施設の土地**（`suburbs.ts`の`FACILITY_PARCEL_FACTOR`）を1.8から1.2へ。1.0では市壁内の人口が74〜100%に下がった。

試して戻したこと: 小さすぎる残りを隣の区画に足す処理。341件の小さい残りの合計は1,642 m²（街区の土地の約2%）と小さく、隣の区画との和が1つの形にならず効かなかった。

## 残ること

- 空き地（残地）は施設ありで19〜28%。全部建てても残る列の間の中庭（12〜17%、残す）と、余った区画。余った区画は、作った区画の容量で市壁の大きさを直す手順で消す。
- 施設が切った区画の残りのうち、半分未満のものは空き地のまま（街区の土地の約2%）。
- gothengsfeldの施設ありの生成は約26秒かかる。ほぼ全部がなめし場の河岸の予約（`reserveTanneryRow`）で、施設の変更の前のコードでも同じ時間だった（敷地の形に依存）。別に調べる。
