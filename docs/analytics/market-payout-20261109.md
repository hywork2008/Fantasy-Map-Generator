# 市場の払い出しの中身（2026-11-09）

[harvest-reserve-20261109.md](harvest-reserve-20261109.md) §3の続き。手順`production:marketPayout`（`payOutMarketSurplus`）は、余りの払い出しの前に、掛けで買った穀物と干し草の農家への返しと、他の市場の商館への払いをする。どれが市場のお金を減らすかを分けて計った。コードは変えていない。

## 1. 条件

- コードはfbabb9c8a（収穫の準備金まで）。シード2103の地図（[town-soap-20261108.md](town-soap-20261108.md) §1と同じ）、24か月（2月から翌々年の1月）。
- [payoutsplit.mts](market-payout-20261109/payoutsplit.mts)は[cashsteps.mts](market-cash-20261109/cashsteps.mts)に、この手順の前後の全市場の穀物の掛け（`ruralGrainPayable`）、干し草の掛け（`ruralHayPayable`）、商館への払い（`tradePayables`）、自分の商館のお金（`tradeWorkingCapital`）の変わりを足した。残りを余りの払い出しとした。実行は[run.sh](market-payout-20261109/run.sh)。

## 3. 結論

- 2年目の夏に市場のお金が尽きるのは、商人への払い出しではなく、収穫の代金を農家に払うためである。市場は現金と掛けで収穫を買い、一年かけて売りながら農家に返す。収穫の準備金が効かないのはこのため（[harvest-reserve-20261109.md](harvest-reserve-20261109.md)）。
- 市場のお金はこの形で正しく働いている。町のお金の夏の減りを直すには、市場ではなく、農家に渡った穀物の代金がどう町へ戻るかを見る必要がある。
- 次は、農家の財布（`foodLedger.ruralHouseholdWealth`）を月ごとに計り、5〜1月に受け取った穀物の代金が、町の品の買い物（`production:ruralSpending`）でいつ町へ戻るかを調べる。
