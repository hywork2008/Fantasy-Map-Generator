- つまり、国の給与の大部分は、塩の見えない税でまかなわれていた。ほかの税（人頭税・売上税・関税）は小さい。

## 4. 分かったこと

1. **値の修正で、塩の優先順位の2と3は満たされた。**
   - 値段は作る費用と運び賃の1.1〜1.3倍。
   - 掛けは返されている。
   - 家畜の塩の不足は6割余り減った。
2. **優先順位の1は満たされていない。** 残る不足（年1.4〜1.9万袋）は、お金ではなく製塩所の能力が上限になったためとみられる。家畜が増えるにつれて足りなくなる。
3. **国の給与の約8割は、塩の見えない税でまかなわれていた。** 値の修正でこれが無くなり、国が家計へ払うお金は年24万から4〜5万に減った。
4. **貧しい市場は、塩の値の修正だけでは良くならない。** 農村の大きい市場で給与が減った分、市場16・21・10の町は悪くなった。根の原因は、農村の現金収入の小ささである。
5. **都市の主食は、後半に少し悪くなる**（1306年に0.6ポイント）。給与が町に払われなくなった分とみられるが、市場ごとの確認はしていない。

## 5. 次に決めること

- **(1) 国の税の見直し。** 税の無い塩を正しい値とすると、国の収入が足りない。次のどちらかで国の財政を立て直す必要がある。
  - (a) 既定の塩税（`saltPolicy.taxRate`）を時代と国の形で与える。
  - (b) 普通の税（人頭税・地租・売上税・関税）を史料に合わせて見直す。
  - 中世の国の主な収入は地租・関税・直轄地で、塩税は一部の国（フランスのgabelle、ヴェネツィアの専売など）にあった。
- **(2) 製塩所の能力。** 家畜の需要を入れて能力を見直す（salt-supply-calibration.mdのQ1の候補(b)）。国ごとの能力と需要の計測から始める。
- **(3) 貧しい市場の農村の売り先。** [urban-money-shortfall-20261031.md](urban-money-shortfall-20261031.md)§5の(b)。
