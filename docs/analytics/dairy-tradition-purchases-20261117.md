# 乳製品の伝統に買った分を入れた計測（2026-11-17）

[dairy-demand.md](../plan/dairy-demand.md) §3.1の残り。`dairyTraditionSource` の `herdsAndPurchases`（新しい既定）は、伝統を、市場の家畜が出す乳と、人が食べた牛乳・チーズ（牛乳に直した量）の多い方へ寄せる。`herdsOnly` は家畜だけ（今までの決まり）。

## 1. 条件

- 地図2103、36か月、戦争なし・略奪なし、他は既定（`cellCheeseSale` allMilk）。[run.sh](dairy-tradition-purchases-20261117/run.sh)。3年目、1人・年。

## 2. 結果

| | 家畜だけ | 家畜と買った分 |
| --- | ---: | ---: |
| 食べたチーズ | 6.94 kg | 7.01 kg |
| 市場の間で運んだチーズ | 0.11 kg | 0.10 kg |
| 満たせなかったチーズの需要 | 0.72 kg | 0.77 kg |
| 伝統（1人・年の牛乳、36か月、最小 / 中央値 / 最大） | 53 / 80 / 110 L | 56 / 82 / 115 L |
| チーズの値段（中央値 / 最小〜最大） | 13.7 / 10.1〜17.5 | 13.7 / 10.8〜17.6 |
| 全ての市場のチーズの在庫（36か月） | 6,849 | 5,857 |

- 家計の収入・GDP の差は1%以内。

## 3. 読み取り

1. 効きは小さい。伝統は3年で約2〜5%上がっただけで、需要と食べた量はほとんど変わらない。
2. この地図には、家畜のいない市場が無い（伝統の最小が53 L）。市場の間で運ぶチーズも1人0.1 kgと少ない。そのため、買った分が伝統を動かす場面がほとんど無い。
3. 半減期10年の指数平均なので、効きは長い年数で表れる。家畜の少ない島や町だけの市場がある地図で、改めて確かめる。
