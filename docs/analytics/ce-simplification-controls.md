# CE：都市部・郊外の簡略化を独立

2026-10-28。森林の性能調整で住宅にも適用した近景LODを、品質優先時に解除できるようにした。

## 操作

Generate → View に次の独立した設定を追加した。

| 設定 | 自動（初期値） | 無効（品質優先） |
| --- | --- | --- |
| 都市部の簡略化（3D） | 近景だけ詳細、64棟・50万三角形などの制限 | 距離・棟数・総三角形数によらず選択した住宅品質を維持。補助ファサードのLODも解除 |
| 郊外の農地・森林の簡略化（3D） | 森林品質の指定に応じたLOD・数量制限、軽量な農地 | 森林品質の指定より優先して可視候補をBV樹木化。農地の地形追従を1 mに細分化し、小麦の保存された畝も表示 |

都市を高品質に見たい場合は、**モデル品質：高品質／都市部の簡略化：無効／郊外の簡略化：自動**を選ぶ。

設定は端末に保存する。文書、生成条件、建物位置、森林面積、共有データ、Undo/Redoは変更しない。都市部を変更しても郊外レイヤーを再構築せず、郊外を変更しても住宅レイヤーを再構築しない。郊外を自動へ戻すと、元の森林品質設定が復帰する。

画面外の描画省略、インスタンス描画、1フレーム2棟までの住宅の段階構築は維持する。大量の住宅は詳細が揃うまで複数フレームを要する。モデル内部の品質段階や、詳細モデルが存在しない建物の形状は、このスイッチで新しい形状にはならない。農地にも作物一本ずつのモデルは追加していない。

無効時は表示量・メモリ・影の負荷が増える。自動モードの数量上限や33 ms目標は適用しない。郊外は自動を維持して都市部だけ解除できる。

## 確認

関連9ファイル61件のVitest、`npx tsc --noEmit --pretty false`、変更TypeScriptのBiomeが成功した。住宅90棟の遠景表示、画面外の省略、補助ファサード、森林の距離・本数上限解除、インスタンスバッファ拡張と資源解放、農地の畝と地形追従、UIの独立保存と不正値の復帰、シーンの独立再構築を検証した。

対象：`regionalHouseLod`、`buildingDetails`、`forestMeshes`、`forestTreeDetails`、`farmMeshes`、`buildingAppearanceControls`、`cityViewRendering`、`CityEditorPage.generationWorkspace`、`editorMessages` の各テスト。

実GPUはChromium／ANGLE Metal／Apple M4、1000×720、DPR 1。住宅90棟と森林4096 m²の比較用シーンを同一カメラで撮影した。影の描画と性能測定は今回のブラウザー確認に含めない。

| 条件 | 詳細住宅 | BV樹木 | 描画三角形数 |
| --- | ---: | ---: | ---: |
| 両方自動 | 0 | 8 | 678,970 |
| 都市部だけ無効 | 90 | 8 | 1,270,762 |
| 郊外だけ無効 | 0 | 45 | 3,792,024 |

このカメラでは住宅が小さく見えるため、自動では全棟が簡略形状になる。都市部だけ無効にすると90棟・594,672三角形の住宅詳細が表示され、森林の統計全項目は自動時と等しい。郊外だけ無効では、住宅の統計全項目が自動時と等しい。各条件でWebGLエラー0、context lossなし、pageerrorなし。
