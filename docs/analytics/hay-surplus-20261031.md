# 干し草は余っているのか（2026-10-31）

[market-treasury-cash-20261031.md](market-treasury-cash-20261031.md)§2で、「どの市場でも、農村は市場が欲しい量の20〜180倍の干し草を出している。干し草は余っている」と書いた。干し草が本当に余っているのか、余っているなら牧草地と草刈りの労働を減らすべきかを確かめた。コードは変えていない。

- 干し草は、全体では余っていない。足りない。
  - 毎年、春（刈り取りの前の3〜4か月）に、必要量の1〜2%の不足が出る。
  - 納屋の在庫は、刈り取りの後でも計画の備えに届かない。3年目の最大は7.24百万で、計画は7.96百万である。
- 草刈りの労働は、計画より少ない。労働で刈れる量は、計画の刈り取り量の88〜91%である。
- 草刈りの計画（`calculateLivestockHayPlan`）は、セルの今の家畜が冬を越すのに要る量だけを刈る。余りの草を全部刈る計画ではない。
- 売りに出した量は、必要量の3%である。自分の納屋が計画の備えに届いたセルが、労働で刈れる残りを出している。その量は、不足（必要量の2%）を埋められる大きさである。
- 市場が買ったのは、売りに出した量の4%（18〜24千）だけである。農村が市場から買った量も20〜47千で、不足の7〜30%である。

## 4. 分かったこと

1. **干し草は余っていない。** 全体では毎年春に不足し、草刈りの労働も計画より1割少ない。前の記録の「干し草は余っている」は誤りである。20〜180倍は、市場が欲しい量が小さいことから来ていた。売りに出された量が大きいのではない。
2. 牧草地と草刈りの労働を減らすと、春の不足が増える。草刈りの計画は、もともと自分の家畜の分だけを刈る。売りに出される量（必要量の3%）は、計画と実際の家畜の差や、セルごとの草の伸びの差から出る、小さな余りである。
3. 問題は、余ったセルの干し草が、同じ市場の足りないセルに届かないことである。
   - 市場は、前の年に売れた量までしか買わない。在庫が少ないと売れず、次の年はもっと少なく買う。この輪で、市場が持つ干し草は年々減る。
   - 農村が飼い葉に使えるお金は、財布の毎月5%までである。
   - 買い上げは、市場の金庫の残高でも止まる（前の記録§2）。
4. 売りに出されて買われなかった干し草は、刈られない（記録上は刈った量に入らない）。ただし、その草刈りの労働は畜産の労働として取ってあり、ほかの仕事には回っていない。売りに出した量は年に約45万トン、労働に直すと約160万日である。市場が買う分を除いた労働が、遊んでいる。

## 5. 直し方の候補

| 候補 | 何を変えるか | 効く所 |
| --- | --- | --- |
| A. 市場の干し草の買い入れを不足から決める | 前の年に売れた量ではなく、市場の農村の冬から春の不足の見込み（計画の備え−納屋の在庫）まで買う | §4の3の縮む輪 |
| B. 同じ市場の中の農家どうしの売り買い | 余ったセルから足りないセルへ直接売る。お金は農村の財布の中で動く | 金庫の残高で止まること、市場の在庫の輪 |
| C. 遊んでいる草刈りの労働を戻す | 刈るあてのない分（売りに出したのに買われなかった量）の労働を、その月の別の仕事に戻す | §4の4 |

AかBで不足が埋まれば、売りに出された干し草の多くは使われる。Cはその後に残る分に効く。どれも、調整の値や方式をSimulation設定で選べるようにする。
