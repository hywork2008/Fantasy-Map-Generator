# メッシュなしCE M8 実装・検証記録

2026-11-07。M8の機能別敷地・景観・地形とFreeform連携を実装した。次はM9の互換性・精度・負荷の受入。

## 操作と実装範囲

メッシュなし画面の「敷地・景観・地形」から、矩形または画面上で描く多角形で敷地を作成できる。接続道路と、港の場合は河川を選ぶ。敷地の生成結果をnativeへ保存し、描画時には再生成しない。既存の住宅生成済み都市ではM6の影響候補・採用フローに渡し、それ以外は一括履歴へ保存する。

| 機能群 | M8の対応 |
| --- | --- |
| 城・稜堡・堀 | 実幅の市壁回路、共有ノードの門と取付道路、主郭・隅部、防御用地、任意の堀。堀の橋も共通規約の角度・直線・乾いた取付・長さ判定を通す。稜堡はageOfExploration以降。二重市壁・壁間道路のM3機能は維持 |
| 港・護岸・船・荷役 | 敷地側の河岸を参照する港、護岸、河川内の船、荷役用地と道路接続を保存。河岸との隙間・船の水域内配置・乾いた敷地を検証。河川移動によって手動港を水没／陸上化させる変更は拒否 |
| 市場 | 区画内の店舗、開市／閉市、通路と生成予約を保存。開閉だけの変更では位置を再抽選しない。仮設市場資産は共通の閉市規約に従って非表示とし、固定された個別店舗の活動状態は保持 |
| 寺院・墓地・公園・農地・森林 | 接道する保護領域と保存済みの構造物・植生・農地区画。密度と高さ・石造／木造を指定可能。BV資産を選ぶ場合は実測寸法・高さと外観を保存し、敷地へ押し込む拡大縮小はしない |
| 地区・土地利用 | 領域の描画、結合・切除・交差。穴と複数成分を保持。用途・密度・高さ上限を住宅／施設配置に反映し、設定変更後もM6で再評価する |
| 固定・レイヤー・手動編集 | 敷地と所属する道・資産の固定、表示切替、削除、設定変更、Undo／Redo。敷地の接続先となった自動道路は手動入力へ昇格し、再生成で消失させない |
| 地形・造成 | FMGの粗い高さ入力を高さ場recipeとして保持。丘・標高と隆起／掘削／平滑化、Freeformの平坦敷地・河床・可変川幅・階段道路を連携。資産の平行移動・回転で敷地も移し、敷地高を個別編集できる |
| 表示・出力・保存共有 | 共通renderDataに地面・等高線・投影高さを渡す。2D、3D、SVG、PNG、GLB、文書共有で同じ敷地・配置・地形recipeを使う |

主な実装は`generators/vector/features.ts`、`terrain.ts`、`editing/regions.ts`、`validation/environment.ts`、`components/vector/VectorEnvironmentPanel.ts`、`services/io/vector/freeform.ts`。高さ場・地形地物・道路勾配・階段・市場外観・BVモデルは既存のセルに依存しない処理を再利用した。高さを標本化する配列は表示／高さ計算用であり、門・川・道・壁の位置を決める編集セルではない。

## 文書と依存更新

nativeは`fmg-vector-city` v7。v1〜v6を移行し、既存文書を読むだけで都市を再生成しない。`environment`に敷地、表示状態、地形を持ち、地区の用途・密度・高さと資産のquality／palette／activityも保存する。段階表示の旧入力は既存のチェックポイントを維持する。手動で追加した敷地は入力として表示し、自動施設と住宅を後から同時生成したように見せない。

敷地は小路・街区・住宅の生成予約となる。後付けした敷地や地区制約に影響する自動配置だけを再評価し、手動・固定配置は保護する。表示切替は生成予約を解除しない。道路・河川のanchor参照、門・橋、敷地の所属IDが壊れた文書は保存／読込時に拒否する。

Freeform読込は明示的な操作である。地面・sculpt・敷地高・道路・河川・用途・BV配置と市場予約を取り込み、独立した`freeformSource`に元ledgerを保持する。新方式で移動・造成しても元ledgerは変えず、「保持したFreeform文書を開く」で既存Freeform画面へ復帰できる。Freeformを含む旧CEの複製もこのadapterを使う。不適合な渡河は元文書を変えずに取込エラーとして示す。

## 検証

- 敷地10件、地形／Freeform8件、生成との結合4件、UI2件。
- 既存の文書22件・codec3件、接続／橋26件、依存更新6件、都市生成6件、骨格／FMG入力14件、renderData2件、旧都市複製2件、共有3件、表示寿命2件、ページ方式分岐8件、i18n10件。
- 特に、城の門と堀の直角橋、港の反対岸選択防止、施設先行の旧段階表示、ゼロ密度への変更後の住宅撤去、接続先の自動小路の保護、固定店舗の保持、Freeform敷地高・元文書の保持を確認。

BVを選ばない構造物・植生・船等は、保存された簡易立体で表示する。BV選択時は実寸モデルを照合し、変形せずに配置する。旧CEの詳細プランの完全な外観一致をこの記録の合格基準にはしていない。元の旧文書を保持する複製と、新しい敷地操作の受入を区別する。

地形編集は10 km以内、計算用高さ場は最大257×257、表示地面は65×65を上限とする。曲線の編集形状はこの標本点へ吸着させない。港は指定河川の河岸に接する乾いた敷地が必要で、適法な橋の乾いた取付が取れない防御用地も明示的に失敗させる。正式切替の判断はM9で、既存CEとの機能比較、曲線・投影の精度、都市規模ごとの負荷を検証して行う。
