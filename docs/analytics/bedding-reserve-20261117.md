# 毛布のお金の取り置きを、買える衣服の分だけにした計測（2026-11-17）

[textile-basket-scale.md](../plan/textile-basket-scale.md) §3.4。`beddingCashReserve` の `buyableWardrobes`（新しい既定）は、毛布に回さず取り置くお金を、その月に市場の棚にある衣服の分だけにする。比べる相手は [textile-gaps-20261117.md](textile-gaps-20261117.md)（今までの決まり `wardrobeNeed`）。

## 1. 条件

- 地図2103、36か月、戦争なし・略奪なし、既定。[run.sh](bedding-reserve-20261117/run.sh)。3年目の月平均、ロット。

## 2. 結果（月平均）

| | 今までの決まり | 買える衣服 |
| --- | ---: | ---: |
| 毛布・町 使った量 / 需要 | 36.1 / 56.7 | 13.8 / 56.6 |

- 家計の収入・GDP の差は1%以内。

## 3. 読み取り

1. 農村が買う毛布は2倍になったが、町の買う分が減り、合計はほぼ同じ。毛布の在庫が無くなり、作る量で止まるようになった。
2. 衣服も毛布も、主な原因は作る量になった（§3.5）。
3. 精算の内訳の「取り置き」（`priorityGap`）は、買える衣服の決まりでも農村で月326ロット残る。`priorityAllocatedBudget` が「月初めの財布 − 毛布に使えるお金」で、衣服に使ったお金まで取り置きに数えるため、内訳が実際より大きく出る。数え方の誤りで、お金の動きには効かない。
4. 農村の家で作る毛布（`ruralTextileProduction`）は、今も今までの取り置きの決まりで0のまま。
