# 衣服・毛布を作る量が足りない原因（2026-11-17）

[textile-basket-scale.md](../plan/textile-basket-scale.md) §3.5。[bedding-reserve-20261117.md](bedding-reserve-20261117.md) の計測（reserve-2103.json、新しい出力は無い）の3年目の品の流れを、羊毛から衣服・毛布まで追った。

- 刈った羊毛は、毎月ほぼ全てが布の材料に使われる。在庫は残らない。
- 羊毛は月約512ロット（1ロット1.5 t）、1人・年約0.9 kg。

## 2. 要る羊毛

- 衣服1揃い（4 kg）は布4.44 t / 1,000揃い、布4 tは羊毛6ロット（9 t）から作る（`textileRecipeContracts.ts`）。衣服1 kg に羊毛約2.5 kg。
- 衣服の需要（1人・年1 kg）を全て毛で作ると、羊毛は1人・年約2.5 kg。毛布（1人・年約0.13 kg）を足すと約2.8 kg。
- 刈れる羊毛（約0.9 kg）は、その約1/3。衣服の需要の57%が満たされているのは、麻・綿・亜麻の布と、家の手仕事による。

## 3. 羊の数

- 羊は100人あたり112頭（[dairy-herd-20261116.md](dairy-herd-20261116.md)）。Allen の1300年の表では456頭（輸出の羊毛の群れを含む）。
- 1頭の年の羊毛は0.7 kg（`woolProductionPolicy.ts`、Stephenson 1988 の0.6〜0.8 kg）。史料の頭数なら、1人・年約3.2 kg（輸出を含む）。
- 羊の数の差は、[settled-questions.md](../plan/settled-questions.md) で「荒蕪地の放牧の残課題」とされている（親計画 [historical-economy-production-consumption-circulation.md](../plan/historical-economy-production-consumption-circulation.md) E1-3）。

## 4. 読み取り

1. 衣服・毛布を作る量が足りない主な原因は、羊毛の量。羊毛は全て使われていて、町の工房・農村の家の手仕事のどちらも、羊毛があれば作る。
2. 羊毛の量は、羊の数（史料の約1/4）で決まっている。1頭の羊毛の量は史料と合う。
3. 衣服の値段が上限まで上がらないのは、値段が「材料の値 + 上乗せ」で、羊毛の値段（5.2、基準の値13の0.4倍）が低いため。羊毛は刈った月に使い切られ、市場の在庫で値段が決まらない。羊毛の値段の決まりは、別に調べる。
