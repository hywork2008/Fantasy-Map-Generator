# Salt S4 所有者と資金の帰属（2026-10-23）

S4を実装した。製塩所の領域上の国家と、製塩権の所有者を分離し、市場画面から国営・都市営・教会営・私営を選べる。旧保存の所有者がない施設は国営として移行する。次はS5の塩専売・塩税。

## 所有者と口座

| 区分 | 保存する参照 | 費用と売上の口座 |
| --- | --- | --- |
| 国営 | `state` + 国家ID | 既存国庫 |
| 都市営 | `burg` + 都市ID | 既存都市金庫 |
| 教会営 | `church` + 国家ID | 既存`departmentBalances.ecclesiastica` |
| 私営 | `private` + 人物ID | 正規のCharacters人物資金口座 |

`Saltworks.stateId`は引き続き領域・国内外配送・国家別集計に使用し、`owner`が費用と売上の帰属を決める。教会営はその国の既存教会部門の集合口座で、司祭個人の財布とは分ける。私営はCharactersの正規シミュレーション人物一覧を参照し、参照モデルの休眠人物も既存の個人資金台帳へ接続する。互換packのコピーだけへの書込みや、所有者を作るための新規人物生成は行わない。

選択できるのは施設の領域国家内の既存主体。口座のない教会部門、死亡人物、削除都市、他国の都市・人物、不正なID等は受け付けない。既に指定された所有者が無効になった場合は権利参照を保持し、製造資金を0として停止する。国庫への自動付替え・無料救済はしない。資金0でも有効な口座は選べるが、生産にはS3の先払資金が必要である。

新規施設は国営で開始し、旧保存は未設定の`owner`だけを国営へ補完する。明示済みの所有者、在庫、貨物、能力、残高は変更せず、移行は再実行しても同じ結果になる。現行の選択は地図編集としての製塩権の割当であり、資産売買・買収代金・相続・国有化政策ではない。旧所有者の現金や市場在庫を新所有者へ移さない。

## 決済と画面

S3の資金上限を所有者口座へ置き換えた。賃金・Woodの実支払、新規製塩の卸売上、前受けした運賃の支払が同じ所有者へ帰属する。国際購入は従来どおり国庫間を通すが、輸出国は非国営者の売上を国庫に留めず、その所有者へ渡す。既存在庫の再配送売上は在庫所有市場へ渡し、製塩所の新所有者の所得にしない。

市場の詳細画面に「製塩所」タブを追加した。所有者の選択、現在の所有者資金、直近決済の所有者、直近の生産量・卸受取・賃金/燃料/運賃を表示する。英語・日本語の表示を追加した。変更時点で失効した参照は変更を拒否し、一覧を更新する。

`settlementOwner`を施設に、`sellerOwner`を新規製塩の前払い貨物に保存する。決済後に所有者を編集しても、その決済と出発済み貨物の帰属は書き換えない。観測ビューもネストした所有者参照を複製し、観測結果の編集で元データが変わらないようにした。既に支払った貨物の到着時に新所有者へ再支払することもない。
