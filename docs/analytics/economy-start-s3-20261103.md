# 地元の段（S3）の観測（2026-11-03）

設計書: [urban-craft-staffing.md](../plan/urban-craft-staffing.md) §6.2・§10.3。前の段階は [economy-start-s2-20261102.md](economy-start-s2-20261102.md)。

- 入力: S2と同じseed 2101〜2104・同じ設定で、各版のコードで地図を生成し直した。都市・川・陸地の数はS2と同じである。
- 平和モード、60か月。probeは`economy-start-20261102/economystart.mts`、S2との比較は`economy-start-s2-20261102/compare.mts`、塩・家畜は`economy-start-s2-20261102/foodprobe.mts`（seed 2101・2102、24か月）。
- 行ごとの人数は`economy-start-s3-20261103/rows.mts`で数えた。町の行の人数は「その月に町が作った行の財 × 1ロットの労働量」で、表の人数（§5.2、港などの補正込み）と比べる。表の人数が工房1つ（2.5人）に満たない町は数えない。注文仕立て（`textileCommissions.ts`）と修理の労働は財を作らないので、ここには入らない。

## 2. 初版と手番の版で分かったこと

- **初版:** 手工業はS2とほぼ同じで、道具の生産は月30〜86 → 0〜29ロットに減った。地元の段で道具に失敗した町（町の財布が足りないなど）は、その月の国の資金の注文（Phase 1b）でも道具を飛ばしていた。
- **手番の数:** seed 2101では400町のうち391町が、その月の手番（人口ポイントの切り上げ）を使い切っていた。S2の後は1回の試みの労働が小さく、手番のほうが先に尽きる。地元の段で靴を試せた町は16町だけだった。
- **手番の版:** 手工業が人口1,000人あたり213〜291人になり、都市人口が2〜3%減った。そのうち約390人は木炭だった。地元の段で道具・武具・ガラスが作られて木炭の値段が上がり、利益の順（Phase 2）で木炭が勝つ。Phase 2の1手番は労働1ポイント（1,000人）を使い、木炭の労働量は1袋21.5人月だった。パン（較正の無いまま、1ロット1,000人月）も1,000人あたり26人を使っていた。石鹸は月584〜3,604ロットに増えた。
