# 蝋燭の在庫が増えて値段が下がる件（分析）

関連：[wax-long-20261114.md](wax-long-20261114.md) §2

## 1. 条件

- 新しい計測はせず、[wax-long-20261114.md](wax-long-20261114.md)の72か月の出力（地図2102・2103、既定の設定）を年ごとに数え直した。スクリプトは [flows.py](candle-stock-20261114/flows.py)。

- 2103も同じ形（在庫79→285→397→467→504→534、値段の比2.02→0.74）。

## 3. 読み取り

1. 在庫の増えは年ごとに小さくなり、6年目でほぼ止まった。6年目の在庫（2102で1,106）は、買われる量の約1.4か月分で、積み上がりではなく、店の手持ちの量である。
2. 値段の下がりは、材料の値段による。蜜蝋が下限（基の値の0.25倍、[wax-pricing-20261114.md](wax-pricing-20261114.md)）になったので、蝋燭の元値は1個あたり約2.4になった。蝋燭の値段は「元値 + 上乗せ × 需要と在庫の比」で、基の値14との差の上乗せ（約4.3）を足すと約6.7、基の値の約0.48倍になる。在庫の重みを付けた値段の比0.50はこれと合う。
3. 安い蜜蝋が安い蝋燭になるのは仕組みどおりで、直す必要は無い。作る量は買われる量にほぼ合っている（差は年に約2〜3%で、在庫の1.4か月分に収まる）。

## 4. 出力

- 新しい出力は無い。元の出力のSHA-256は[wax-long-20261114.md](wax-long-20261114.md) §5。
