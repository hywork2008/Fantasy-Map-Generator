## 3. 畳む判定（M2）は一度も畳まなかった

- 市場18は72か月目に12か月続けて基準を下回った。それでも84か月目まで畳まれなかった。
- `inflight.mts`で、毎月の待つ理由を見た（71〜84か月目）。

  | 理由 | 月数 |
  | --- | ---: |
  | 商隊が運送中（`caravan`） | 3 |
  | 町への荷（`marketShipment`） | 3 |
  | 交易の資本が荷に入っている（`tradeCapitalLocked`） | 4 |
  | 前払いの代金（`tradeEscrow`） | 4 |

- 小さい市場でも、毎月どれかの荷が動いている。荷の無い月を待つ方式では、いつまでも畳めない。
- 83〜84か月目は、商隊が無いのに前払いの代金28.36が残っていた。どの荷の分かは確かめていない。

## 4. 分かったこと

1. **M1だけで、残る家畜の塩の不足は無くなった。** 昇格した村を中心にした、町の無い市場が作られなくなったためである。
2. M1は、世界の誕生の時の昇格にも同じ`fmg:settlement-promoted`の経路で効く。ただし固定入力は世界の誕生の後なので、この計測では確かめていない。
3. **M2の「荷の無い月を待つ」方式は成り立たない。** 畳む時に、運送中の荷を扱う方法を決める必要がある。
