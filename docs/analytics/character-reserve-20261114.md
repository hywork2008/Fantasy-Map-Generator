## 3. 読み取り

1. 人の手持ちは2年目から2102で約7万、2103で約4.5万で横ばいになり、増え続けることが止まった。領主・商人・部隊の長は、目安を超えた分を毎月町で使う段に入った。
2. 人が使った分は、町の家計・市場のお金・農村の家計に戻った（町の家計の年ごとの減りの一部が戻った）。
3. 支配者・中央の役人・ギルドの親方は、前と同じく1年目でほぼ0になる。蓄えの年数ではなく、手当と生活費の釣り合いの問題で、借金を入れる時（設計§5の1）に合わせて見る。
4. 死んだ人のお金は、手持ちが減った分だけ少ないが、まだ増え続ける（2102で年約2千）。
5. 1か月目の値が前と違う（2102で126.8と120.0）のは、最初の月の生活費から新しい目安で払うため。
