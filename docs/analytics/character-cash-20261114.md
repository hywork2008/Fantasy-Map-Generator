# 人の手持ちのお金が増え続ける理由（計測）

関連：[wax-long-20261114.md](wax-long-20261114.md) §4の3、[initial-wealth-calibration.md](../plan/initial-wealth-calibration.md) §8.3

## 1. 条件

- 地図2102・2103（北緯30°）、36か月、戦争なし・隊商の略奪なし、既定の設定。
- スクリプトは [goods.mts](character-cash-20261114/goods.mts)（wax-long-20261114のものに、生きている人の暮らしの段ごとの人数・お金・蓄えの目安と、死んだ人のお金を加えた）、[run.sh](character-cash-20261114/run.sh)、[tiers.py](character-cash-20261114/tiers.py)。
- 蓄えの目安：暮らしの費用 ×（1 + 12 × 蓄えの年数（5年））。これを超えた分の10%を毎月町で使う（`applyCharacterLivingCosts`）。
- 人のお金は全て人物に結び付いた口座（`character.wealth`）にあった。役の口座の溜まり（pools）は0だった。

## 3. 読み取り

1. 人の手持ちの増えは二つからなる。
   - 領主・市場の長・商人・部隊の長が、蓄えの目安（生活費の5年分）に向けて貯め続けている（2102で年約+16千）。目安の約3割にしか届いておらず、どの人も余りを使う段に入っていない。この貯めは仕組みどおりだが、目安に届くまで十数年かかる。
   - 死んだ人のお金が、口座に残ったまま誰にも渡らない（2102で年約+5千）。相続（`settlePersonalEstates`）は、持ち主の席（`ownerSlotId`）と生きている子のある口座だけを分けるので、そこに当たらない人物のお金は死後に動かないと見られる（どの条件で外れるかは未確認）。
2. 逆に、ギルドの親方・中央の役人・支配者・徒弟は1年目でお金がほぼ0になり、そのまま戻らない。入る手当より生活費が高いか、手当が払われていない。人の段で、お金の偏りが大きい。
3. 町の家計・市場のお金が減った分の行き先は、主に領主と商人の貯めと、死んだ人の残したお金である。
