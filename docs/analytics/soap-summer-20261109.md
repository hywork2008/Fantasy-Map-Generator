# 夏から秋の石鹸の減り（2026-11-09）

[soap-potash-20261109.md](soap-potash-20261109.md) §2で、石鹸の買い物は16か月目の後に下がった。その訳を市場ごとに調べた。コードは変えていない。

## 1. 条件

- コードは8a3226417（石鹸と炭酸カリウムの校正の行まで）。シード2103の地図（[town-soap-20261108.md](town-soap-20261108.md) §1と同じ）、24か月。1か月目は2月。
- 市場ごとに、石鹸・炭酸カリウム・灰・獣脂・木の流れ、月末の在庫と値段、炉の灰の帳簿、町の石鹸の需要、町のお金、町の生産の診断（各ガードの理由の数）を毎月記録した。
- 実行は[run.sh](soap-summer-20261109/run.sh)、記録は[soapmarkets.mts](soap-summer-20261109/soapmarkets.mts)。

- 町のお金は、2年とも5月から9月に約35%減り、10月から4月に戻る。石鹸の買い物と同じ形。
- 石鹸と炭酸カリウムは、8〜10月に「材料を買うお金が足りない」で作れない町が2〜3倍に増えた。
- 灰は在庫が1万3,000袋を下回らない。最も減った市場（市場5・10）でも、低い月に1,600袋と380袋が残った。獣脂の在庫も多い。材料の量は止めていない。
- 減りの大きい市場は8〜14℃と14〜18℃の帯。

## 3. 結論

- 16か月目の後の減りは、夏から秋に町のお金が減り、石鹸職人が材料（獣脂、炭酸カリウムの灰）を買えないため。灰や作り手の数ではない。
- 町のお金の季節の動きは石鹸の外の仕組み。次は、何が5〜9月に町のお金を減らすか（町の買い物か、収穫前の穀物か）を調べる。
