# 穀物を主食と一体にした後の観測（2026-11-03）

設計書: [urban-craft-staffing.md](../plan/urban-craft-staffing.md) §10.7。前の段階は [economy-start-ale-20261103.md](economy-start-ale-20261103.md)。

- 入力: 前の段階と同じseed 2101〜2104・同じ設定で、地図を生成し直した。都市・川・陸地の数は同じである。
- 平和モード、60か月。手順は前の段階と同じ。

## 1. 変えたこと

- 市場の主食の作物（大麦・小麦など）の行を、食料の帳簿の作物の「市場から出してよい量」の写しにし、値段を主食の値段 × 作物の価値 ÷ 主食の価値にした。収穫の卸を市場の行にもう一度足すのをやめた。
- 工房が主食の作物を買う時は、帳簿の作物の在庫から引き、値段の押し上げを掛けない。
- 主食の作物を、町どうしの一般の取り引きと、町の小売りの在庫と、値段の2つの補正（町の取り引きの偏り・お金の量）から外した。
- ビール・林檎酒・梨酒・ワイン・チーズ・干しぶどうの値段を、月の家計の需要と在庫で決め、売り買いの値動きを掛けない。

## 4. 分かったこと

- 大麦の値段は主食の値段の0.9倍（0.71〜0.72）になり、ビールの値段は月の家計の需要に応じて3〜4に上がった。ビールに利益が出るようになった。
- 最初の数か月に、ビールが家計の需要の1か月分の備えまで一度に作られ、市場の主食の余り（出してよい分）を使い切る。9か月目以降、出してよい大麦・小麦は0のままで、2101・2102では12か月目からビールが作られない。
- 醸造が主食の余りを使った分、町の主食の充足が下がり（2102の12か月目に0.945）、都市人口の伸びが止まった（60か月目に2101で−2.4%、2102で−1.5%）。
- 市場が農家から主食を買う量（`foodProduction.ts`の購入の上限）は、人の食べる分と備えだけで決まり、醸造の穀物を含まない。
