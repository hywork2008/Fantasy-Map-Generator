# CE M9 旧港の航行・荷役・実寸船の意味変換

2026-11-07。[防御受入](ce-meshless-m9-defense-20261107.md)の後続作業。固定の平坦な旧海港を、セル参照のない港プランへ変換し、一部受入とした。[最終受入JSON](ce-meshless-m9-harbor-verified-20261107.json)と[初回受入JSON](ce-meshless-m9-harbor-20261107.json)を保存した。港の機能群は`limited`、公開区分は試験運用のまま。

## 実装

`environment.harbor`に独立した港プランを追加した。岸壁・荷役場・桟橋・道路への接続、クレーン、荷物、船と荷役割当を保存する。旧face参照は、独立した土地所有者と水深領域のIDへ置き換える。旧meshの接続や頂点・辺IDを持ち込まない。船の位置・回転・船型・船体長・帆／砲門状態と、艀から母船への参照を保持する。

旧港プランを一度だけ解決して採用し、以降の描画・航行・荷役判定は保存した港プランから行う。稼働判定のために旧文書を復元したり、仮のCityDocumentやmeshを作ったりはしない。変換先の所有権・道路・航行・荷役が成立しなければ港プラン全体を拒否し、未対応の理由を報告する。元文書の保管・復元は維持する。

### 航行

旧CEの距離変換・開放水面への接続判定を、polygon入力からも使える共通処理へ切り出した。従来の旧CE入口は同じラスタ入力と境界条件を渡すため、旧側の動作を変えない。native側は陸、水、水深不足、桟橋、他船を独立polygonとして渡す。船幅と喫水に必要な余裕があり、開放水面に接続するかを保存後にも判定する。

標本間隔は旧側と同じ`max(2m, extent / 700)`。既知領域外を水と扱うか、フレーム外を開放境界と扱うかも保存する。今回の固定入力では旧CEの「地域水域がない場合、既知meshの外は水として続く」という仮定を明示的に継承した。実在する沖合航路の調査や、連続幾何での安全証明には一般化しない。nativeの閉鎖境界は、フレームに触れるだけで航行可能にならない。

### 荷役

`activeVectorHarborCargo`は保存されたIDの存在だけで稼働としない。共通の固定半径荷役solverで、船の姿勢・船型・船体長、喫水・甲板、クレーンの軸・旋回角・腕長・滑車／フック高、荷下ろし地点、索具と荷の旋回、岸壁からの直線退避、旋回場所を確認する。保存した姿勢・フック・旋回量と解が一致した場合にだけ割当を返す。

艀の割当は実在する同じ水域の待機母船を参照する。母船に架空の直接クレーン接続を与えない。船が移動・変更された場合、不正な母船やクレーンを参照した場合は稼働としない。固定港の直接改変も依存更新で拒否する。

### 生成と描画

荷役場・桟橋・荷役の進入路、クレーンと荷の旋回範囲、岸壁の作業水面、船と荷物を生成予約へ加える。表示上の装飾だけに留めず、都市の街区や建物の候補地から除外する。港プランを生成と都市配置のfingerprintへ含める。

2Dの船体footprintは保存船体長と船型の幅から作る。3Dは既存の`createTownShips`、クレーンと貨物のBV描画を使い、用地へ合わせて縮めない。船の帆・砲門状態を反映し、各モデルをローカル原点で作ってから採用位置と水位へ移す。子meshからも元の船IDを選択できる。海の部分は基盤と旧water reservationの塗りを除き、保存水位を描く。港専用の検査・編集UIは今回の受入に含めない。

## 固定受入

従来から使っている3領域の旧海港fixtureを維持した。岸壁1、船4、稼働荷役1で、荷役は艀と待機母船を含む。入力seedは`harbor-test-seed`／`cargo-test`、元文書SHA-256は既存の追加受入と同じ`b4251db9bc4841bb39ea6068d7547a3ee273353fe1ed495d392d89ab361077fa`。

| 項目 | 結果 |
| --- | --- |
| 意味変換 | 港・船4隻・稼働荷役1を`converted`として採用。保存プランにface／vertex／mesh参照なし |
| 保存 | native再読込、元文書の不変と復元が成功 |
| 航行 | 船4隻について喫水・幅・障害物を含めて再判定し成功 |
| 道路・荷役 | 道路曲線アンカー、岸壁・クレーン・母船への参照を保持。荷役solverの再計算と保存割当が一致 |
| 生成予約 | 実際の街区生成結果と港予約の重複面積0m² |
| 2D／3D | 実寸船体footprint、BV船・クレーン、帆／砲門状態、位置・水位、論理IDの選択を確認 |
| 不正な保存入力 | 不明な母船・クレーン・道路、船の姿勢変更、水深不足、船体長や表示状態の不正、クレーン角度の変更を拒否 |
| 狭い航路 | 船幅を広げると閉塞。唯一の航路を浅瀬／障害物が遮ると航行不可 |
| 閉鎖水域 | 開放境界に触れない小水域、および閉鎖境界は航行不可 |
| 起伏 | 港プランを部分採用せず、拒否理由を報告。元文書は復元可能 |

## 残る制約と次の作業

今回の自動変換は固定・平坦な海港を対象とする。河川の帯状水域、起伏、フレーム道路や河川接続で表される交差進入路は、それぞれの水面・水深・障害物の権威を引き継ぐまで明示的に拒否する。Freeform地形との併存も未対応。多様な港入力の同等性、港計画と専用UIでの編集、ラスタ外の連続航路保証は未受入である。

次は旧自動景観の再生成・樹木外観・文化設定を受け入れる。防御・港の残り、造成境界の連続鉛直誤差、5,000人の施設不足と10秒目標も正式移行の条件に残す。
