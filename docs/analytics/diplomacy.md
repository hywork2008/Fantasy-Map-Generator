# 国家外交（Diplomacy）

## 現在の外交関係（Diplomacy）の生成の仕組み

Diplomacy Editorで閲覧できる国家間の関係は、コアマップ生成プロセスの一部として `src/generators/states-generator.ts` 内の `generateDiplomacy()` 関数で決定されています。
生成の主な流れは以下の通りです：

1. **基本関係の初期化**: 
   全国家ペアの初期状態を「Unknown」または「x（自分自身）」で初期化します。
2. **宗主国（Suzerain）と属国（Vassal）の確立**:
   国家拡張のシミュレーション結果や規模に基づいて、既に属国である場合はその関係を明記します。属国は宗主国の外交関係（同盟や敵対）をそのまま引き継ぎます。
3. **軍事力・攻撃力の比較（AP vs DP）**:
   各国家の人口や軍事力をベースに、攻撃力（Attack Power = AP）と防衛力（Defense Power = DP）を計算します。
   この時、近隣の国家や距離が考慮され、**APがDPに対して一定の乱数（ガウス分布）を上回った場合、他国を「Enemy（敵）」または「Suspicion（疑念）」とみなします**。
4. **同盟（Ally）の締結**:
   共通の「Enemy」を持つ国家同士は、防衛のために「Ally（同盟）」を結びやすくなります。
5. **ランダム要素**:
   一部の決定には `P(0.2)` のような確率判定や、`gauss` 関数を使った乱数により、毎回異なる外交状況が生まれるようになっています。
