# メッシュなしCE M7 実装・検証記録

2026-11-07。M7（2D／3D・出力・保存共有・既存都市の複製変換）を完了。次はM8の機能別移植とFreeform・地形連携。

## 実装

- `renderers/vector/renderData.ts`を共通表示契約とし、採用済みの道・川・壁・門開口・橋・街区・入口・建物を、同じフレームと段階でSVG・Three.js・出力へ渡す。表示のための再生成はしない。施設段階と住宅追加段階を切り替えても、保存された配置は変わらない。
- 3Dは実寸BVモデルを採用外形・高さと照合する。不一致・切断・仮敷地・複製した旧建物は保存外形のマスモデルとし、理由を表示する。モデルの幅を合わせるための変形はしない。ビュー切替・文書変更・閉じる操作でGPU資源とイベントを解放する。
- SVG、2D／3D PNG、GLBを出力。SVGは編集補助を除去する。GLBは同じ配置IDとメートル単位を保持し、BV独自シェーダーは標準glTF材質へ近似する。変換方針と件数をextrasへ記録する。
- nativeを`fmg-vector-city` v6へ更新。表示外形・高さ・来歴と旧文書の原本／変換報告を保存し、v1〜v5を移行する。読込だけで生成を再実行しない。原本も旧codecで検証し、復元できないアーカイブを拒否する。
- 共有は「完成文書＋表示段階」と「入力＋生成設定」を分ける。前者は手動修正を含む配置を直接復元し、後者だけ専用Workerで生成する。編集済みの生成要素を入力共有から黙って削除しない。圧縮データのサイズ・展開量を制限し、不正入力はエラー表示する。同一ページのリンク遷移にも対応する。
- 既存CEからの複製は専用Workerで候補を作り、変換／形状snapshot／未対応の報告を確認して一括採用する。元文書を保持し、「元文書を復元」で既存CEへ戻せる。変換不能な橋は架けず、原本と診断を残す。遅延結果・取消・別文書への誤適用を防ぐ。

## 検証

関連Vitestは21ファイル・165件成功。文書移行・共有の破損／展開上限・入力再生成、段階ごとのSVG／3D配置ID一致、実際の門開口、複製原本の往復、ページdispatch・共有リンク遷移、表示資源解放・取消、M6の部分更新／編集の回帰を含む。旧SVGのmask構造を前提にしていた門テストは、共通の壁ポリゴンに開口があり、その隣に壁が残る検証へ変更した。全件テストや多数seed探索は実行していない。

Biome、legacy UI／world writers／architecture／simulation境界チェックは成功。型検査は既存の`src/controllers/charts-overview.ts:560`と`src/services/approachPrior.ts:259`の2件で失敗し、M7変更箇所のエラーはない。

## M8以降への境界

旧CEの建物外形は複製時のsnapshotであり、旧方式の屋根・城・墓地・市場・地形等の動的機能をすべて移植したという意味ではない。未対応要素の原本と診断を保つ。Freeformの区画・敷地高・整地等の意味と地形連携はM8で扱う。

M7以前の文書には高さが保存されていない建物があり、対応BVモデルの高さで表示した場合は未検証である旨を示す。新規生成では実測高さを保存する。GLBの材質表現は標準材質への近似となる。大都市の負荷・全機能互換性の正式な受入はM9で行う。
