# Medieval 41 — Orthodox monastery High (2026-11-02)

`orthodox-monastery`にCodex GPT-6.1 Solの明示的なLow／Highを登録し、BVとCEを同じ部品factoryへ接続した。既存Lowと互換defaultの形状署名は不変。架空の地域的外観モデルであり、特定の実在修道院の再現ではない。

## 変更と共通化

従来はHigh建築の指定を例外で拒否し、CEも正教会修道院だけdefaultへ固定していた。この制限を解消し、CEのLow／StandardはLow建築、HighはHigh建築を採用する。互換default factoryはLowのまま残す。

- 居住棟・教会外殻・門・外壁は既存の修道院High生成処理を再利用。既存の尖頭アーチを既定に残し、正教会では同じ開口付き石造壁処理へ丸アーチを指定する。教会のゴシック風扶壁は使わない。
- 居住棟4棟に中庭側への開いた入口を追加。窓・コース材が入口を塞がないよう既存の開口処理を使う。
- 中央ドラムは12面の丸アーチ窓・奥まったガラス・窓枠と上部コーニス。教会屋根は連続させ、ドラムの下部を屋根内へ重ねる。特定ドームのための屋根穴は作らない。
- ドームは滑らかな回転面、12本の継ぎ目、頂部飾りと三段の十字架。ドラムと継ぎ目は教会の向きに追従する。
- 鐘楼は開いた鐘室と入口、コーニス、支持横木・吊金具・中空の鐘・舌、既存の板／瓦葺き屋根処理で生成する。
- BVの14部品は生成前に選択可能。樹木2本と井戸は独立したLowを維持し、建築Highを理由に格上げしない。敷地床もLowと明示する。任意の部品交換UIは今回追加しない。
