# E1 季節飼料の備蓄・採草労働（2026-10-24）

固定Worldの季節飼料不足を、牧草の成長・採草労働・乾草の備蓄/損失・購入資金に分けて調べた。固定25%の採草計画と一律3か月の備蓄目標を、地元の月別成長と実頭数からの計画へ変更した。食料優先の労働配分と実物/現金の制約を維持する。E1全体の完了や史実校正ではない。

[派生比較](economy-e1-seasonal-feed-comparison-20261024.json)、[全量出力のハッシュと再生成](raw-observations-20261024.md)、[保存再読込確認](economy-e1-feed-reload-20261024.json)。E0と同じ1300年の固定World/Provinceを使用。Standard、High Medieval、populationRate1000、urbanization1、遠隔交易on・隊商襲撃off。Worldは乾草の翌年への持越しを確認するため修正前後36か月、Provinceは影響確認12か月とした。多数シードの検証ではない。

## 原因と変更

| 観点 | 確認したこと | 変更/制約 |
| --- | --- | --- |
| 牧草成長 | 気候による成長停止期間は一律3か月ではない。固定Worldでは6〜8月の不足が大きい | 気候の平年値12か月から放牧で足りない量と刈れる余剰を分ける。北半球の冬を全地域へ固定しない |
| 採草計画 | 従来は年間必要量等の25%を計画し、成長のある月へ配分。放牧だけで余剰が消える月にも採草仕事を配分し得た | 放牧分を引いた余剰だけを刈り、季節の不足と保存損失から仕事量を求める。月別作業を余剰のある月へ配分 |
| 備蓄 | 一律3か月上限では長い成長停止期間を越せない | 次の12か月の成長・必要量・乾燥/保存損失から月末必要備蓄を逆算。3か月は既存の最低バッファとして残す。余剰が全くないセルに架空の年内回復を置かない |
| 人手 | 修正前初年度の実採草は約940.6万kg DM、決済時の参照作業上限は約999.8万kg。牧草の総余りを家畜所在地へ無償移送できない | 同じ牧畜割当人数の世話/採草比率で刈り取りを制限。食料から人を取り上げず、既存群れを一括削除しない |
| 購入 | 修正前初年度の実購入は約3,797kg DM、支払64.21。市場のFodder現物と購入予算が必要 | 直近の不足を先に買い、季節備蓄はその後。同じ農村財布の5%上限、実在庫、売買の数量/代金移転を維持 |

1500kg DM/ha/年、乾燥後85%、保存損失1%/月、採草3日/t DM等の仮係数は変更していない。これらの史実校正を済ませたとは扱わない。新規干し草・家計金・労働者の初期追加もない。保存済み派生労働列の修復版を8→9へ更新し、旧保存は一度再計算する。

## 観測の境界

従来の約49.8%は月末端点の`feedTotals`を12回合計した値。今回、実際の`production:livestockFeed`終了時に決済済み期間を重複なく観測した。修正前初年度の実決済不足率は54.3855%であり、49.8→54.4%を経済悪化と解釈しない。診断追加だけの初期/全12区間の経済値は前回の最終Worldと完全一致し、36か月基準の最初の12区間も一致した。

初年度は実決済が11期間で、2・4〜12月と翌1月を記録し、3月分は記録されない。生産の遅延実行時の暦月と期間ガードによるもので、食料決済の明示的な対象月とは別経路。未記録期間を充足0/不足0で補わない。2・3年目は各12期間。今回の比較は同じ対象期間同士であり、36回の月次飼料決済の完全性や群れの収束を証明しない。この暦月境界の修正は次工程へ残す。

## 残る作業

**E1は進行中。次は飼料決済の暦月境界を先に修正し、月ごとの必要量・給与・損失を欠落/重複なく扱う。** そのうえで、季節飼料と牧夫労働で支えられる頭数を複合生産需要と結び、既存動物を即時大量削除しない移行を設計する。今回の36か月は備蓄の持越し観測であり、未実装の群れ目標の収束判定ではない。土地質別の配分、採毛の史料校正も未完了。長期の食料不足は市場別の在庫・輸送・現金・領域変化を再診断する。
