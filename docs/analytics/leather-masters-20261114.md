# 地図2103で皮革の親方が減った理由

設計：[guild-master-workshop.md](../plan/guild-master-workshop.md)。新しい計測はせず、[guild-master-workshop-20261114.md](guild-master-workshop-20261114.md)（新）と[state-budget-income-20261114.md](state-budget-income-20261114.md)（前の決まり）の`cash-2103.json`を読んだ。

## 1. 親方の数

皮革の親方は13〜23か月目69、24〜35か月目15、36か月目5（年の決まりは12・24・36か月目）。

前の決まりの出力でも、在庫と値段はほぼ同じ（36か月目の革333.5・0.53、長靴26.7・0.47）。親方の決まりが原因ではない。

## 3. 革の流れ（前の決まり、13〜36か月目の1か月の平均、単位）

| | 単位 |
| --- | ---: |
| 屠った牛の皮（burgCraft） | 125,651 |
| 長靴の材料 | 75,405 |
| 革の品の材料 | 35,567 |
| 傷み（夏の皮の傷みと、使う量の12か月分を超えた分） | 8,574 |
| 港からの送り出し | 422 |
| その他（馬具・武器・輸入） | 約1,800 |

- 革は品を作る仕事ではなく、屠った牛1頭が革1巻きになる（slaughter.ts）。作る量は使う量の約1.1倍で、余りの大部分は傷みで消える。在庫は3年で2.6倍になったが、36か月目でも使う量の約3か月分である。前に「使う量の約2倍」と書いたのは、秋に屠る36か月目の1か月だけを見た誤りだった。

## 4. 値段と儲け

- 屠った家畜の副産物の値段は、毎月、町の1か月の目当ての量を在庫で割った比で決まる（\`getRawGoodTargetPrice\`、markets-generator.ts）。在庫が使う量の約3か月分あると、値段は価値の約3分の1を目指す（下限は4分の1、近づく速さを抑えるので約半分に留まる）。
- 長靴と革の品は材料の値段に、需要と在庫の比で増減する上乗せを足した値段なので、革が安いと一緒に安くなり、儲けは上乗せの分になる。
- 皮革の儲けは町ごとに小さい（地図2103の2〜3か月目で595の町の合計が1か月5,637、平均9.5、[stipend-funding-20261114.md](stipend-funding-20261114.md) §7）。取り分0.3で親方の生活費7.2に届くには1か月24の儲けが要る。

## 5. 読み取り

1. 1年目は長靴と革の品の在庫が尽き（12か月目に長靴0.1千）、上乗せが大きくなって、12か月目の平らにした儲けが大きかった。そこで69の町に皮革の親方が置かれた。設計の見込み（約70）も、在庫が尽きかけた2〜3か月目の儲けから数えていた。
2. 2年目からは長靴と革の品が需要に追いつき、上乗せが小さくなった。儲けが生活費の半分を下回り、親方が退いた。36か月目の5人は、落ち着いた儲けで親方を養える町の数にあたる。
3. 革の作り過ぎではなく、1年目の品不足が一時的に儲けを大きくしたのが原因。親方の置き方は、儲けをそのまま映している。
4. 季節に屠る副産物は、使う量の数か月分の在庫を持つのが普通なのに、値段が1か月の目当てと比べて決まるため、いつも価値の半分ほどになる。これは副産物の価値を家畜の値段に戻す件（次の作業）で扱う。
