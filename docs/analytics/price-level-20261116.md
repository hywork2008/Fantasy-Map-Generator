# 5年後の物価を1500〜1540年のイングランドと比べる（2026-11-16）

農業生産と越冬の調整が一段落した後の物価・賃金・通貨量を、史実の相対価格と比べ、開始時の配分を見直す前の課題を挙げる。

## 1. 条件

- コード: feature/fmg-economy-start-2 の HEAD 1f2873421（既定の設定）。
- 地図 2102・2103（docs/analytics/raw/barilla-20261108/maps、World）、60か月、戦争なし、隊商の略奪なし。
- 記録は [prices.mts](price-level-20261116/prices.mts)（毎月：持ち手ごとの残高。6か月ごと：全市場の価格の中央値・賃金・人口）、実行は [run.sh](price-level-20261116/run.sh)、比較は [compare.py](price-level-20261116/compare.py)。物理量は `GOOD_MEASURES`（[measures.json](price-level-20261116/measures.json)）。
- 比べ方: 絶対額（SP と d）は較べず、主食 1 kg の何倍かで比べる。シムは `Grain` の小売価格（1 wain = 465 kg）、史実は小麦 0.35 d/kg（6.5 s/quarter）。
- 史実の値は Rogers・Beveridge・Phelps Brown & Hopkins・Allen・Mayhew 等の概数を記憶から取ったもので、出典の確認はしていない。±30〜50% の幅で読むこと。

## 4. 課題（大きい順）

1. **実質賃金が史実の約 1/11。** 1日の賃金で主食 1 kg（史実 11 kg）。賃金の定義（自分の食費 × 1.5）では、家族を養えず、肉・布・道具を買う余裕も無い。価格の比を合わせる前に、賃金（と1人あたりの所得）の尺度を決め直す必要がある。[craft-wage-subsistence-scale.md](../plan/craft-wage-subsistence-scale.md) の 1.2〜2.0 という範囲より 1 桁上の議論になる。
2. **主食と家畜の価格が下限に張り付いて動かない。** 主食は `PRICE_FLOOR` 0.8、牛・羊は `PRICE_FLOOR_FACTOR` 0.25。余りが常に出ているので、価格で需給が調整されていない。ほかの全ての比の分母が下限の値になっている点にも注意。
3. **お金の減り続け。** 国庫は2年目以降も年 0.1〜1.7%、合計は年 0.5〜2% 減る。開始時の配分を見直す前に、どの項目で消えるのかを `--money-flows` で数える。
4. **通貨量と持ち手の割合。** 1人あたりは史実の約 1/3、国庫の割合は史実の 3〜5 倍。以前の目標「年間食費の 3〜6 か月分」（[money-scale-calibration.md](../plan/money-scale-calibration.md) §5）は、史実で GDP の 3〜4 か月分にあたる量を食費と取り違えている。食費で数えると 1.5〜2 年分が史実に近い。
5. **商品ごとのずれ。**
   - 安すぎる: 馬（約 1/12）、羊毛（1/7〜1/9）、毛織物（1/3）、薪（1/3）。
   - 高すぎる: チーズ（6倍）、鉄（約 3倍で上昇中）、羊・ビール（2倍強）。
   - ほぼ合う: 肉・蝋燭・亜麻布・靴・ワイン・塩（0.7〜1.7倍）。
   - 羊毛が安く羊が高いので、羊毛を取るために羊を飼う経済が成り立たない。1500年代イングランドの主産業と逆の構図になっている。

## 5. 次の作業

1. 3 の減りの項目を、地図 2103 の 60か月で `npm run sim --money-flows` を使って数える。
2. 1・4 の尺度（1人あたりの所得・賃金・通貨量を主食の何倍にするか）を設計書にする。開始時の配分の見直しはその後に行う。
3. 2 の下限の張り付きと 5 の商品ごとのずれは、1 の尺度を決めてから測り直す。
