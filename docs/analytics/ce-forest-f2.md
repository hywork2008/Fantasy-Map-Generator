# CE森林 F2：2D描画の確認

対象：[実装計画](../plan/ce-forest-surroundings.md)。固定入力はF0の `small-flat`（seed: `ce-forest-f0-small-v1`、1,200 m、建物940棟）1都市のみ。

## 実装した表示

- [面＋林縁](ce-forest-f2/edge-fill.png)：既定。連続した緑の面、少量の樹冠模様、林縁の木。隣接セルの共有辺に木を並べない。
- [全域に樹木](ce-forest-f2/all-trees.png)：同じ森林領域に内部の樹木を追加する。林縁を優先し、上限内で描く。
- 幹込みの詳細な3Dモデルは使わず、広葉樹と針葉樹の上面記号を共有する。樹種・色は植生から選び、住宅文化で森林を決めない。
- 2方式とも外周と穴を同じ複合pathへ保持する。樹冠と内部模様は同じ領域でclipし、道路・水域・施設の空地へはみ出させない。海岸や風車等の追加の余白も正本から導出した森林領域に反映する。
- 表示上の方式は `ForestSvgOptions.representation` で指定できる。設定UI・表示設定の保存はF4で接続する。

## 計測結果

Apple M4、Node v22.23.1、Headless Chromium、1000×1000、DPR 1。1回のウォームアップ後3回の中央値。SVG構築と同期的なattach/layoutを測り、paint・GPU完了時間は含めない。FPSの計測ではない。

森林部分はルートgroupを除く子孫要素数。樹木のuseだけでなく、defs・pattern・clipも上限に含む。

| 方式 | 品質 | 森林部分の要素数 | 木の数 | 都市全体のSVG構築 | attach/layout |
| --- | --- | ---: | ---: | ---: | ---: |
| 従来の耕作地 | detailed | 0 | 0 | 63.8 ms | 5.0 ms |
| 面＋林縁 | detailed | 1,289 | 1,274 | 19.6 ms | 9.1 ms |
| 面＋林縁 | light | 1,289 | 1,274 | 11.8 ms | 7.1 ms |
| 面のみ | minimal | 1 | 0 | 5.2 ms | 1.3 ms |
| 全域に樹木 | detailed | 8,000 | 7,985 | 78.0 ms | 44.3 ms |
| 全域に樹木 | light | 3,000 | 2,985 | 55.8 ms | 16.1 ms |
| 面のみ | minimal | 1 | 0 | 4.7 ms | 1.2 ms |

森林化後の面積は、全6ケース・全標本で **993,664.5634041692 m²（約99.37 ha）** と一致した。面積の違う植生を描いた比較ではない。一方、従来方式には耕作地の畝等があり、森林化でそれらが除去されるため、従来方式と林縁方式の時間差を森林レンダラー単体の高速化率と解釈しない。

記号の候補はseedと世界座標から導き、品質を変えても同じ候補の部分集合になる。panでは配置を変えず、zoomでは既存のgroup属性とCSSだけで細かい記号を隠す。外周・穴の再計算は行わない。幾何キャッシュは密度・品質・カメラをキーにせず、地形・用途・道路・施設・追加余白の変更で無効化する。

## 静的SVGと再現方法

```sh
node --import tsx scripts/verifyCeForestSvg.mts
```

F0の全量文書があればそれを読み、なければ同じ固定レシピから1都市を再生成する。[results.json](ce-forest-f2/results.json)に各標本、実行時のGit HEAD・環境・入力のSHA-256を保存した。Git HEADは実行の基点であり、未コミットの今回の実装を含むコミットではない。

エクスポートは全景を描き、ビューのzoomによる記号の非表示を適用しない。樹木記号、pattern、clip、色、スタイルをSVG内へ含め、useにhrefとxlink:hrefを付ける。外部アセットへの参照は不要。

再生成可能な全量SVGはGit管理外に保存した。3 MBを超える全域方式の出力を含め、管理対象は比較PNG・計測JSON・この記録のみとする。
