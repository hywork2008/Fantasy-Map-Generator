# メッシュなしCE M9 追試

2026-11-07。公開判断の次作業として、5,000人の施設探索と住宅接道、生成profile、詳細機能の比較、既存の型エラーを扱った。**公開区分は試験運用のまま**。基準は[受入・公開判断](../plan/ce-meshless-release-acceptance.md)。

## 配置探索と接道

施設の共有試行回数は4万回のまま、1要求あたり240回を上限にした。上限に達した要求だけが残予算を分け合い、1件が後続を探索不能にしない。探索していない要求は`unsearched`、上限で打ち切った要求は`budget`、最後まで探して置けない要求は用地・河岸・用途の理由で残す。住宅が探索上限で止まった場合は`housing-search-budget`、接道を探し終えて住戸が残る場合だけ`housing-capacity-shortfall`とする。

小路は本数の上限を変えず、街区の奥まで伸ばして長いものから採用する。住宅は長い接道から置き、連続して入らない区間は先へ進む。実寸の住宅モデルと人口の不足表示は変えていない。出入口が削られた境界上に残る場合は、建物側へ4mm寄せて予約地の内側に置く。

## 詳細機能の比較

対応表の4機能群は、固定入力の既存テストで確認できる項目だけを受け入れ、残りは制約付きのままにした。旧CEの詳細プランを自動で同義変換したことにはしない。

| 機能群 | 受け入れたもの | 残すもの |
| --- | --- | --- |
| 城・堀・稜堡 | 1回路、共有門、直交する堀、大航海時代以降の稜堡、固定所有、元文書の復元 | 旧防御プランの自動的な意味変換 |
| 港・船・市場 | 乾いた岸壁、荷役路、最近接岸の船、施錠された市の露店 | 旧CEの航行、荷役操作、詳細な船プラン |
| 寺院・墓地・公園・農地・森林 | 6種の領域がnative／2D／3Dで同じ形状、BV資産は実寸のまま | 旧自動景観と文化設定の全体 |
| 地形・造成 | 作成済みの平坦地・造成、適法な交差、剛体移動、元帳の復元、地区の穴 | 描画格子の近似、急な造成境界をまたぐ連続的な鉛直誤差 |

## 型検査と公開判断

`npx tsc --noEmit`は成功した。対象は`charts-overview.ts`の積み上げ系列の型と、`approachPrior.ts`で配列風の都市一覧を添字で辿るようにした点である。

正式移行の条件はまだ揃っていない。5,000人の人口と全施設、10秒、詳細機能の残りがある。11機能群は確認済み、5機能群は制約付き、公開区分は試験運用、自動移行はしない。

関連テストは都市生成、依存更新、環境統合、生成パネル、M2曲線、approach prior、charts、受入計測を分割して実行し、いずれも成功した。全件テストとE2E全件は実行していない。計測用のブラウザーは別セッションが使用中で、生成パネルの診断文は画面では確認していない。
