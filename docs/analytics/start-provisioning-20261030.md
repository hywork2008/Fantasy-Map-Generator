- 最初の測定では住居が0のままだった。固定入力は世界の誕生の時点で保存された地図で、読み込みは`ConstructionOperations.generate()`を通らない。`seedStartHousing`を足して直した。
- 衣服は12か月目に在庫が0に戻る（値段1.26）。生産が買い替えに追いついていない。
- 塩は始めの数か月だけ下がり、半年後には前と同じ水準に戻る。能力の余裕×1.15で在庫を積み増せないことは変わらない（[塩の計画](../plan/salt-supply-calibration.md)）。
