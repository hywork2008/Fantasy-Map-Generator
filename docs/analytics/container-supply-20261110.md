# 飲み物の器の足りなさを、町のガラス・陶器の作り手と需要から見る（2026-11-10）

[soap-by-period-20261109.md](soap-by-period-20261109.md)で、灰はほぼ石鹸にしか使われず、石鹸は器（ガラス・陶器）を支えていないと分かった。そこで、器が本当に足りないのか、足りないならどこで止まっているのかを、作り手と需要の側から調べた。コードは変えていない。

## 1. 条件

- 地図は北緯30°の2枚（2102・2103、[barilla-20261108.md](barilla-20261108.md)）、24か月、戦争なし・隊商の略奪なし、コミット1b8da6078。2年目（13〜24か月）を集計した。
- 計測スクリプトは[containerflow.mts](container-supply-20261110/containerflow.mts)。[drink-containers-20261107](drink-containers-20261107/containerflow.mts)のものに、蒸留酒と器の材料（粘土・白い砂・炭酸カリウム・バリラ）、果物・蜂蜜・大麦の流れを足した。実行は[run.sh](container-supply-20261110/run.sh)。

## 2. 飲み物（2年目）

| 飲み物 | 2102 飲んだ | 足りない | 満たした割合 | 2103 飲んだ | 足りない | 満たした割合 |
|---|---:|---:|---:|---:|---:|---:|
| エール（Beer） | 455,383 | 13,520 | 97% | 308,347 | 3,852 | 99% |
| 蜂蜜酒（Mead） | 4,443 | 2,094 | 68% | 3,415 | 980 | 78% |
| シードル（Cider） | 15,098 | 64,443 | 19% | 9,819 | 30,560 | 24% |
| ワイン（Wine） | 650 | 65,633 | 1% | 277 | 33,372 | 1% |
| ペリー（Perry） | 0 | 39,770 | 0% | 11 | 20,179 | 0% |

- 足りないのはワイン・シードル・ペリーで、どれも農村で果物を搾るもの（`ruralHarvest`）である。年末の在庫は0で、作った分は全部飲まれた。
- 農村の搾りは、果物の量と、市場の空の樽・樽の在庫で上限が決まる（`getOrchardMaterialCapacity`）。12か月目の樽の在庫は2102で70,709、2103で39,605、空の樽は40.5万と26.0万あり、樽はこの上限を決めていない。止めているのは、果樹園と葡萄畑の果物の量である。
- 蜂蜜酒は蜂蜜の約6〜9%しか使わず（残りは家計の食べ物）、在庫も残る。器でなく、醸造の量の決まり方で止まっている。

## 3. 器（2年目）

| | 2102 | 2103 |
|---|---:|---:|
| 樽 詰め直した数 | 7,445,039 | 5,028,184 |
| 樽 作った数（burgCraft） | 181,001 | 128,370 |
| 樽 空の樽が足りず新しく買った数 | 48,589 | 42,263 |
| 陶器 作った数（町） | 2,093 | 1,064 |
| 陶器 エールに使った取り替え | 956 | 988 |
| 陶器 在庫へ戻した空の器（`containerReturn`） | 231 | 394 |
| 陶器 12か月目の在庫 / 値段（値4） | 3,679 / 2.07 | 1,722 / 1.94 |
| ガラス 作った数（町 / 森 / 海の輸入） | 100 / 484 / 371 | 82 / 345 / 202 |
| ガラス 町の贅沢品・人物の贅沢 | 670 / 66 | 407 / 82 |
| ガラス 飲み物（蜂蜜酒） | 0 | 33 |

- 樽は失われる1つにつき約20回詰め直され、作る数は取り替えに足りている。
- 陶器は町で作られ、エールの器の取り替えより多い。余った空の器が在庫に戻り、在庫は値の約半分の値段で残っている。陶器の作り手は足りており、陶器を求める需要の方が小さい。
- ガラスは贅沢品と香水に使われ、飲み物にはほとんど使われない（樽と陶器より高いため）。

## 4. 結果

- 北緯30°の地図では、中世の飲み物の足りなさは器では起きていない。エールは97〜99%満たされ、樽と陶器には余りがある。
- 足りないのは果物から作る飲み物（ワイン1%、シードル19〜24%、ペリー0%）で、果樹園と葡萄畑の面積・果物の量で止まっている。ガラス・陶器を増やしても、この足りなさは変わらない。
- 器の足りなさは、寒い土地（粘土・樽の木材が少ない土地）に限られる見込みである。この計測は暖かい地図だけで、寒い地図は[cold-clay-20261107.md](cold-clay-20261107.md)のものを見直す必要がある。
