# チーズが少ないのは、牛の数か、乳の量か（2026-11-16）

[dairy-supply-use-20261116.md](dairy-supply-use-20261116.md) の後、搾れる牛乳（1人・年79 L）がチーズの需要（25 kg = 牛乳250 L）の約3割しかない理由を数えた。

## 1. 条件

- 地図2103、既定の設定、6か月目（7月、乳を出す月）。[herd.mts](dairy-herd-20261116/herd.mts)。
- 乳の量は `getMilkOutput` と同じ式で数えた: 繁殖群 × 乳を出す割合 0.375 × 1頭の年の乳 × 世話・餌・痩せの係数。

- 牛の数と1頭の乳の量は、1300年ごろのイングランドの値と同じ桁にある。
- 1500年ごろは、人口が黒死病の後の約230万人に減り、牛の数はほぼ同じだった（概数）。1人あたりの牛と乳は、1300年の約2倍になる。

## 4. 読み取り

1. **牛の数と乳の量は、史料と釣り合っている。** 足りなく見えるのは、需要の側である。
2. **チーズの需要（1人・年25 kg、`DAIRY_TARGETS`）は、搾れる量の約3倍。** コード中で「史料で確かめていない値」とされている。
   - 搾れる乳を全てチーズにしても、1300年の家畜の数では1人約8 kg。1500年の家畜の数で約15 kg。
3. 籠（Phelps Brown & Hopkins）の乳製品12.5%は、1450〜1500年の町の労働者の家計で、1人あたりの家畜が多かった時代の値。1300年の家畜の数のシムとは、同じ時代として比べられない。
4. 牛の数は、バイオーム（牧草と人手）から決まっている。乳を出す季節（3〜10月の8か月）は、気温・半球によらず固定。
