# 葡萄の季節と、ワインの土地（2026-11-10）

設計は[grape-season-and-wine-country.md](../plan/grape-season-and-wine-country.md)。[orchard-area-20261110.md](orchard-area-20261110.md) §4で満たされなかった、市場の生の葡萄・干し葡萄の需要と、どこにも無かったワインの土地を調べた。

## 1. 条件

- 地図は北緯30°の2枚（2102・2103、[barilla-20261108.md](barilla-20261108.md)）、24か月、戦争なし・隊商の略奪なし。2年目（13〜24か月）を集計した。
- base: コミット811ca2261。new: 葡萄が実った市場を全てワインの土地とした形（全てか無しか）。share: 設計の形（ワインの土地の度合い）。どれも凍結したworktreeで動かした。
- 計測スクリプトは[orchardprobe.mts](grape-season-20261110/orchardprobe.mts)（帳簿にエール・蜂蜜酒・蜂蜜を加えた）、実行は[run.sh](grape-season-20261110/run.sh)。

## 3. 読み取り

- new（全てか無しか）は、葡萄畑の少しある市場まで全ての町をワインの土地にした。ワインの需要は約6倍になったが、作る量は加工の労働の上限で1.7倍にとどまり、エールを飲んだ量は約1/3に減った。
- share は、ワインを飲んだ量を base から44〜45%増やし、エールの減りを6%、蜂蜜酒の減りを2〜9%にとどめた。ワインの満たした割合が base より下がったのは、ワインの土地の需要が加わったためで、飲んだ量は増えている。
- 生の葡萄の足りない分は、どちらの形でも約8割減った。残りは、葡萄が実った月に、セルが食べ・蓄え・搾った後に残らなかった分である。
- 干し葡萄は、base の0から16〜20%になった。
