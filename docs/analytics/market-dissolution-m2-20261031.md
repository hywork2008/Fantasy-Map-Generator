# 市場を畳む時の運送中の荷: 店じまいと引き継ぎ（2026-10-31）

計画: [market-founding-viability.md](../plan/market-founding-viability.md)§4.2。前の記録: [market-founding-m1-20261031.md](market-founding-m1-20261031.md)§3（荷の無い月を待つ方式では畳めなかった）。

- 入力: 固定入力`docs/analytics/inputs/wet-pastoral-birth-20261029/world-102.fmg`、平和モード、84か月。
- コード: HEAD 62e9a55efに、M1・M2と、この記録の2つの方式を加えた作業ツリー。間隔の倍率1.0、中央値の20%、12か月。
- probe: `marketv2.mts`（`marketv1.mts`に次を加えた）。
  - 方式を環境変数`FMG_MARKET_DISSOLVE_CARGO`で選ぶ。
  - 畳む直前と直後に、全市場のお金（金庫・前払い・交易の資本・農村の財布）、市場が負う掛け、市場の貸しの合計を数える。
  - 店じまい中の市場の、毎月の待つ理由。

## 1. 2つの方式

| | 店じまい（`windDown`、既定） | 引き継ぎ（`handOver`） |
| --- | --- | --- |
| 条件に達した月 | 新しい取り引き（市場どうしの交易・戦略物資の調達）を受けない | すぐに畳む |
| 市場どうしの運送中の荷 | 着くまで待つ | 商隊・輸出の待ち荷・運送の予約・海外の遠征の行き先や出どころを、取り込み先に付け替える |
| 自分の町への荷・塩の荷・運送の資産の注文 | 取り込み先に付け替える | 同じ |
| 前払いの代金・荷に入った資本 | 着いた時に精算される | 取り込み先の金庫に移す |
| 商船を持つ市場 | 畳まない | 畳まない |

商船は造船の拡張が市場の番号で持っていて、経済の側では持ち主を付け替えられない。そのため、商船を持つ市場はどちらの方式でも畳まない。

## 2. 結果

- 店じまいの71〜72か月目は、ほかの市場から市場18へ向かう商隊を待った。前払いの代金・荷に入った資本・輸出の待ち荷は、どの月も0だった。
- 最初の計測では、店じまいが84か月目まで終わらなかった。待つ理由は運送の予約（`transportReservation`）だった。予約は使い終わった後も、状態（`released`・`lost`・`cancelled`）付きで記録に残る。判定がそれも数えていたので、`reserved`と`inTransit`だけを数えるように直した（単体テストを1件加えた）。
- 70か月目までは、どちらの方式もM1だけの計測と月ごとに同じ値だった。

## 3. 分かったこと

1. 店じまいと引き継ぎは、どちらも働く。お金・掛け・貸しを作りも消しもしない。
2. 店じまいは、条件に達してから2か月で畳めた。前の「荷の無い月を待つ」方式が畳めなかった理由は、次の2つである。
   - 自分の町への荷を待っていた（今は付け替える）。
   - 使い終わった運送の予約を数えていた（判定の誤り）。
3. 設定画面（Simulation設定の「畳む市場の運送中の荷」）は、ブラウザーでの表示を確かめていない。
