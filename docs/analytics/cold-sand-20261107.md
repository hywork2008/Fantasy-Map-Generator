# 寒い土地のガラスの砂（2026-11-07）

設計は[cold-land-clay.md](../plan/cold-land-clay.md) §5。粘土の計測は[cold-clay-20261107.md](cold-clay-20261107.md)。

## 1. 条件

- 地図: [site-bonus-20261107.md](site-bonus-20261107.md)のH = 25の地図（シード2101〜2104）。
- コード: f5fa0455aに、ガラスの砂の条件と移行の変更（まだコミットしていない）を足したもの。凍結したworktreeで動かした。
- 初めの配置: [clayprobe.mts](cold-clay-20261107/clayprobe.mts)に財の名前`White sand`を渡した。出力は[start-summary-sand.txt](cold-clay-20261107/start-summary-sand.txt)。
- 12か月の計測: [clayflow.mts](cold-clay-20261107/clayflow.mts)。実行は[run-sand.sh](cold-clay-20261107/run-sand.sh)。襲撃なし、平和。シード2102・2103。
  - base: 保存した地図の粘土とガラスの砂のまま。
  - add: 粘土とガラスの砂を、粘土の計測と同じ方法で加えた。
    - 新しい条件だけが許すセルに、その地図で古い条件のセルに置かれた割合で加える（乱数はシードで固定）。
    - ガラスの砂の割合は、2102で2.9%、2103で4.3%。
    - 粘土を先に置き、ガラスの砂は空いたセルにだけ置いた。粘土の分は、粘土の計測と同じになる。
  - ガラスの砂・ガラス・炭酸カリウム・陶器の流れを、市場の気温の帯ごとに足した。出力は[summary-sand.txt](cold-clay-20261107/summary-sand.txt)（`compare.py --goods "White sand,Glass,Potash,Ceramics"`）。

## 2. 結果

### 2.1 初めの配置（4枚）

- ガラスの砂のセルは4枚で41。平均気温4℃未満の47の市場には、1つも無い。
- シード2104の地図は、粘土もガラスの砂も1つも無い（年平均気温8℃以上の海岸と川のセルが2つしか無い）。

- 掘った量は、農村の採取（`ruralHarvest`）と町の作業（`burgCraft`）の合計。
- 寒い市場でガラスの砂を掘るようになったが、ガラスはほとんど増えない。ガラスの砂は在庫にたまる。
- 0〜4℃の市場の炭酸カリウムは年に約10樽で、ガラス20荷分にしかならない。寒い土地のガラスは、炭酸カリウムで止まる。
- ガラスの値段は下がり、家計と人物の贅沢の購入が増えた（2103の0〜4℃の`luxuryPurchase`は14 → 36荷）。増えた分は、主に海軍の輸入（`navyImport`、60 → 98荷）でまかなわれた。
- 陶器は、粘土の計測とほぼ同じ（2102の0〜4℃は0 → 113荷、2103は43 → 282荷）。
