## 1. 世界の塩は本当に足りない（1302年の12か月、袋＝60 kg）

| 項目 | 量 |
| --- | --- |
| 生産 | 161千 |
| 人の需要 | 258千 |
| 人に売れた量 | 123千（需要の48%） |
| 家畜の需要（自然の塩を除いた買う分） | 1,024千 |
| 家畜に売れた量 | 33千（需要の3%） |

生産は人の需要だけでも6割余りしか無く、家畜の需要を入れると全体の需要の13%にとどまる。各月の世界の在庫は、1か月の需要（人・家畜・加工）の0〜26%で、在庫が1か月分以上の月は無い。`priceSalt`の`pressure`が3に張り付くのは、在庫の目標の決め方による見かけでなく、本当の品不足を示している。

月末の在庫は製塩所のある市場（市場1・2で各8千袋余り）に偏り、出す側の市場が自分の在庫目標を残すため、他の市場には回らない。生産は春（3〜5月）にほぼ0になる季節の差が大きい。

## 2. 家畜の需要が人の4倍ある

家畜の塩の需要（年1,024千袋＝6.1万トン）は人の需要（年258千袋、1人年3.6 kg）の約4倍で、牛1頭年20 kg（`SALT_LIVESTOCK_ANNUAL_KG`）など、今の乳牛の推奨の上の端の値から来る。[計画](../plan/livestock-salt-cash-share.md)§2に書いたとおり、中世の小さな牛ではもっと少なかったとみられる。

## 3. 結論

- 値段が基準の約3倍に張り付くのは本当の品不足による。`priceSalt`の式を変える案A・Bは、品不足を隠すので採らない（案C: 変えない）。
- 農村の人の塩の支払いが大きいのは、品不足の値段で、需要の5割前後を買っているため。
- 品不足の大きな部分は、家畜の塩の需要の大きさから来る。家畜の1頭あたりの塩の量（`SALT_LIVESTOCK_ANNUAL_KG`）と、生産の量（製塩所の数と能力）を史料と照合するのが次の課題になる。
