# 町の家計が年ごとに減る理由（2026-11-14）

[peat-long-20261113.md](peat-long-20261113.md) §3の3で、町の家計が6年で545千から286千へ下がり続けた。お金が地図から消えるのか、別の持ち手へ移るのかを調べた。

## 1. 条件

- コード: feature/fmg-economy-start-2のHEADに[fuel-price-share.md](../plan/fuel-price-share.md)と[peat-cut-plan.md](../plan/peat-cut-plan.md)の実装を加えたもの。凍結したworktreeで動かした。
- 地図2102、36か月、`npm run sim`の`--money-flows`で、毎月、11の持ち手（scripts/lib/observeViews.mts `MONEY_HOLDERS`）ごとに、各段がお金をどれだけ動かしたかを記録した。
- `sim.mts`は`FMG_CONFLICT_AUTONOMY`を読まないので、これまでの測定と違い、戦争は止めていない。
- 実行は[run.sh](town-money-drain-20261114/run.sh)、集計は[flows.py](town-money-drain-20261114/flows.py)。

- 人物（personal cash）は年約2.4万増えた。

## 3. 読み取り

1. お金は地図から消えていない。これまでの測り（国庫・町の金庫・町の家計・農家・市場）に入っていないギルドの金庫へ、年約13万が移って戻らない。
2. ギルドは、その分野の作った品の売上（税の後）の35%（guildTreasury.ts `GUILD_PROFIT_SHARE`）を受け取る。ギルドから町へ戻るのは、町の金庫が快適な水準を下回った時の`payoutStrugglingBurg`だけで、ギルドの金庫に上限も他の使い道もない。
3. 町の職人の賃金になるはずの売上の一部がギルドに溜まり続けるので、町の家計が年ごとに減る。中世のギルドの金庫は、会費・罰金で集め、祝宴・礼拝堂の灯り・貧しい親方の救済・葬式・兄弟団の施しに使い、町へ戻った。
