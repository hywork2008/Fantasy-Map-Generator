# 泥炭が3年目に跳ね、年ごとに増える理由（2026-11-13）

[fuel-price-share-20261113.md](fuel-price-share-20261113.md) §3の3・4（泥炭を採る量が25か月目に約3.7倍に跳ね、年ごとに増える）を、その出力と、沼の採れる量の上限（peatSupply.ts `potential`）で調べた。

## 1. 条件

- 毎月の流れは、fuel-price-share-20261113のpriceShare-2102・priceShare-2103とchurch-wax-pay-20261113のwax0.05-2102（cheapest）を使った。新しい長い実行はしていない。
- 上限は、HEADに[fuel-price-share.md](../plan/fuel-price-share.md)の実装を加えたコードで1か月動かし、各市場の`peatSupply.potential`を足した。測りは[potential.mts](peat-growth-20261113/potential.mts)、実行は[run.sh](peat-growth-20261113/run.sh)。

- 沼の採れる量の上限は、2102が1か月約21.8万俵（年約262万俵）、2103が1か月約13.4万俵（年約161万俵）。3年目に採った量（2102: 約20.8万、2103: 約23.3万俵）は、その約8%・14%。
- 上限の全てを燃やすと、木材にして2102が年約8.1万山、2103が年約5.0万山の熱で、3年目の暖房の木材（約25.3万・16.8万山）の約3割にあたる。

## 3. 読み取り

1. 跳ねる理由：1月に木材を採る量が下がり、木材の在庫が減った市場の暖房が泥炭を多く使う。泥炭を採る量は「使った量の平滑 × 6か月（`PEAT_STOCK_COVER_MONTHS`）− 在庫」まで増やす決まりなので、冬に使う量が増えると、その6か月分を採ろうとして、使った量の約2倍を採る。在庫が増えて値段が下がり（0.67→0.49）、泥炭の分がさらに増える。
2. 2年目の1月（24か月目）から跳ねたのは、1年目の終わりまでに泥炭が値段で分を持つようになり、木材の下がった月に泥炭へ移る量が、在庫（約6千俵）を超えたためと考えられる。1年目の1月（12か月目）は、泥炭の分がまだ小さかった。
3. 増え方は、泥炭の在庫が使った量の6か月分になり、熱あたりの値段が木材に近づくまで続くと考えられる。この時の泥炭の分はk=4で約半分になるが、沼の採れる量の上限で、暖房の熱の約3割で止まる。
4. 泥炭の多い所（ノーフォーク、ネーデルラント、アイルランド）では、泥炭が家の主な燃料だったので、3割で止まることは不自然ではない。冬の後に夏に掘って乾かし、在庫にする動きも、泥炭の掘り方と合う。
5. 一方、跳ねる時に使った量の約2倍を採る動きは、冬に使った量を6か月分の目安にするためで、平滑（1/6）が冬の山を年の量と見なす。
