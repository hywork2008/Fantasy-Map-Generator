- 地図は北緯30°の2枚（2102・2103、[barilla-20261108.md](barilla-20261108.md)）、24か月、戦争なし・隊商の略奪なし。
- コード: コミット7690c1f6eに、[cask-stock-20261110.md](cask-stock-20261110.md) §5の樽の直しを加えたもの。凍結したworktreeで動かした。

  - 毎月末に、国のお金の集計（`getStateMoneyStocks`、[stateMoneySupply.ts](../../src/extensions/economy/generators/stateMoneySupply.ts)）が数える持ち手の残高を、一つずつ取った。
  - お金でない借り（市場が農家に払っていない分`ruralGrainPayable`、町の掛けの借り）も取った。
  - 人物のお金は、個人の口座（`personalAccounts`）として合計だけを取った。

## 4. 読み取り

1. お金はほとんど消えない（2年で−1.5%）。問題は量ではなく、偏りである。
2. 農村の家計が、お金の合計の7〜10%から、9か月で約40%を持つようになり、その後は止まる。国庫は1年目に約4割減り、市場のお金は約8割減った。お金は国庫と市場から農村の家計へ移り、農村の家計から出て行く道が細い。
3. 市場が張り付く所である。
   - 3・6・9・12月に、市場の4〜8割でお金が初めの10%を下回る。四半期ごとの払いと見られる（[craft-book-credit.md](../plan/craft-book-credit.md)の四季の支払日など、内訳は未調査）。
   - 1年中、市場の2〜7割で、農家への未払いが市場のお金を上回る。収穫の月（7〜8月）に最も多い。市場は農家に払えず、借りが残る。
4. 町の金庫も、四半期の後に1〜3割の町で初めの4分の1を下回る。町の家計は張り付いていない。
5. 商人の元手は、2年目に約4割減った。
6. 職人の組合は、合計は増えるが、4分の1がゼロにいる。合計が小さく（全体の2%未満）、町の流れへの影響は小さいと見られる。

## 5. 次に調べること

1. 農村の家計のお金の出入り。何を買い、何に払うか（町の品、税、地代）。出口が細いなら、それが市場と町のお金の不足の元である。
2. 市場のお金の、3・6・9・12月の大きな出。どの段階で、誰へ出るか（[market-cash-20261109.md](market-cash-20261109.md)の段階ごとの測りを、四半期の月に広げる）。
3. 国庫の1年目の約4割の減り。どこへ払われたか。
