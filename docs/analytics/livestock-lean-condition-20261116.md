| 26（3月） | 1.29 | 0 | 8 | 3 | 0.993 | 0 |
| 27（4月） | 5.85 | 0 | 24 | 3 | 0.984 | −2.6 |

1. 借りは見込みどおり、4月に生まれ、5〜7月の草で戻り、8月に0になった。
2. 6月の食べ戻しが小さいのは、本刈りの前に草地を閉じる月で、刈らずに残る草がほとんど無いため。
3. 肉の減りは、世界で0.02%以下で、見込み（0.05%以下）の中だった。
4. 足りない市場の肉の減りは最大1.6%で、見込みの「数%」より小さかった。
   - 理由は二つ。
     - 市場の割合は、足りない土地だけでなく市場の全ての土地の餌の量で平均している。
     - 4月の不足は、足りない土地でも1か月の餌の一部にとどまる。
   - 0.991は、市場の借りが市場の1か月の餌の約7%であることを指す（1−0.25×0.072/2）。
5. 不足の月の屠畜は、その月の餌の決算より前に数える。そのため、肉の差は次の月から出る（15か月目は0）。
6. 27か月目の持ち手のお金の差：
   - 農村+0.43%、市場+0.71%、そのほかは0.2%未満。作った品は−0.002%。
   - 差は18か月目から月ごとに符号を変えて広がっていて、肉の減り（月に十数荷）より大きい。肉の減りが市場の動きを少しずらした広がりと読む。

## 3. 締めと餓え死に（cull/、[run-cull.sh](livestock-lean-condition-20261116/run-cull.sh)）

設計§7。2102を30か月、既定（`leanCull` unfed・`leanDeaths` die）と、どちらもoffを並べた。記録は§1と同じleanprobe.mtsに、売る土地・死ぬ土地と、その頭数を餌の量で数えた値を足したもの。

| か月目（暦の月） | 売る土地 | 売る頭数（1か月の餌の量、百万kg） | 死ぬ土地 | 借り（百万kg） 既定 / off | 肉（荷） 既定 / off |
| --- | --- | --- | --- | --- | --- |
| 15（4月） | 0 | 0 | 0 | 6.43 / 6.43 | 同じ |
| 27（4月） | 8 | 2.42 | 0 | 5.82 / 5.82 | 同じ |
| 28（5月） | 0 | 0 | 0 | 2.63 / 3.72 | 91,579 / 90,069（+1.7%） |
| 29（6月） | 0 | 0 | 0 | 2.60 / 3.62 | 87,786 / 87,904 |
| 30（7月） | 0 | 0 | 0 | 0.52 / 0.90 | 85,915 / 86,029 |

1. 死は0で、見込みどおり。
2. 売りは27か月目の8つの土地だけで、見込み（10以下）の中。
   - この8つは、3月と4月の二月続けて足りず、借りが半月分の餌を超えた。
   - 15か月目は不足が1か月だけで、どの土地も売り始めの量に届かなかった。
3. 売った頭数は世界の群れの約0.05%。それでも、売った次の月（28か月目）の肉は+1.7%になった。
   - ふだんの月の売りは年の増えた分を月に分けた数なので、群れの一部をまとめて売ると、その月の肉には大きく出る。
   - 獣脂は+749荷だった。
   - その後の2か月は、群れが小さい分だけ肉が0.1%少ない。
4. 売った家畜が借りを持ち去り、28か月目の借りはoffの約7割になった。
5. 30か月目の持ち手のお金の差は0.75%以内（大きいのは市場の−0.75%）。
6. 5月以降の借りは§1より少し小さい（16か月目で3.62から3.49百万kg）。ふだんの売りで頭数が減った分、借りも減るようにしたため。
