# 生活費 - living expenses / cost of living

CustomAboutContent.tsx

🟡 が世界に一つだけの抽象通貨であること(穀物価格 ≒ 1🟡/wain)を前提に、シミュレーションの一人当たり食料必要量(GROSS_FOOD_NEED = 0.43)を根拠として:
農民一人の最低生存費: 約0.3〜0.4🟡/年
都市住民一人の生活費: 約0.4〜0.8🟡/年(同じ食料需要+都市の小売価格分)
4〜5人家族の生活費: 約2〜4🟡/年
質素な住宅一軒: 約10〜30🟡(労働者数年分の貯蓄相当) — 住宅購入は未実装のため、あくまで世界観の目安として明記
コードベースにゲーム内定数として存在しない「住宅価格」は「シミュレートされた価格ではない」と明示し、既存の食料消費式から導ける数値とは区別しました。
