## 実装した操作

既存CEのGeneration methodから「Meshless (vector editing)／メッシュなし（ベクトル編集）」を選択すると、専用の編集画面へ切り替わる。既存メッシュ都市への復帰と方式ごとの履歴保持はM1の経路を維持する。

| 操作 | 採用する形状・動作 |
| --- | --- |
| プリセット | 円・楕円、四角形、正多角形。中心座標、メートル寸法、方位、辺数、角丸半径を指定 |
| 寸法の指定 | 幅・高さの適用と、内包面積・縦横比の適用を別操作にする。後者は角丸を差し引いた実面積を保持する |
| 自動寸法 | 文書の目標人口から寸法を決定したプリセットを作成し、`origin: automatic`で採用形状を保存。都市全体の自動生成はM4 |
| プリセットのプレビュー | 確定前の中心線を表示。幅・接続・予約用地等の検査を通過した変更のみ履歴へ登録 |
| 曲線へ変換 | 解析的な円弧・楕円弧を三次ベジェへ変換。永続anchorの位置を区切りとして残す。Undoで元のプリセットへ戻る |
| 折れ線 | クリックで点を配置。完了／Enterで確定、Backspaceで末尾点を削除、Escapeで取消 |
| フリーハンド | pointerで描画し、メートル単位の許容誤差で簡略化。pointerを離した時に検証・確定 |
| ベジェ | 点をクリックし、ドラッグでハンドルを指定。既存頂点・制御点もドラッグ可能。独立・接線連続・対称の連動を保存 |
| 数値編集 | 区間の始終点・制御点の座標、移動量、原点まわりの回転を指定 |
| 曲線の構造 | 分割位置の指定、内部頂点の削除と隣接区間の結合、開閉、反転、線とその接続の削除。保持できない参照を伴う操作は拒否 |
| 幅 | 左右の実幅、曲線上の幅基準点の追加・置換・削除。基準点間は中心線の近似弧長に沿った線形補間 |
| 固定 | 固定・解除。固定した線そのもの、または固定された接続先を動かす操作は確定しない |

区間の選択はインスペクターのSegment欄で行う。変換で多数の小区間が生じるため、青い制御ハンドルは選択区間に絞り、他の頂点は小さく表示する。ドラッグ中は中心線の下書きだけを更新し、pointer解放時に1回のUndo対象として確定する。取消・不正な操作では保存済み文書を変更しない。

## 幾何と文書

- `geometry/presets.ts`: 解析的な区間、方位変換、角丸の最大値・実面積、面積と縦横比からの寸法解。
- `geometry/sampling.ts`: 中心線の位置誤差5 mm・接線角誤差0.1°を上限とする適応分割。ベジェは制御点の凸包と導関数の向き、円弧は曲率に基づく上界で検証する。深さ24・16,384標本の予算を超える形状は拒否する。
- `geometry/surfaces.ts`: 左右幅から道路面・河岸・壁帯を生成。外側の折れ点はbevel、内側はoffset直線の交点とする。閉路は穴付き帯で表示し、都市内部を壁として塗らない。自己交差、反転、内側の潰れ等を検査する。派生形状は正本にせず、32件まで内容別にキャッシュし、画面破棄時に解放する。
- `editing/convertPreset.ts`: 変換時の位置・接線誤差を制限し、幅基準点、共有点、道路辺、門、施設アクセスの参照を同時に更新する。永続anchorは変換後の区間端点に置くため、固定した接続先も動かさない。
- `editing/paths.ts`: 変更した線と共有端点に接続する編集可能な曲線を一括更新。固定、移動を要する内部接続、矛盾する共有点、予約領域・施設用地との重なりは拒否する。予約用地との境界接触も保守的に重なりと判定する。
- `renderers/vector/documentSvg.ts`: プリセットは正確なSVG arc、任意曲線はSVG cubicの中心線、実幅は派生polygonを使う。河川は道路より上に描き、交差箇所に架空の橋面を補わない。編集した線がframe外へ出ても全体が収まるよう表示範囲を広げる。

文書は`fmg-vector-city` **v2**へ更新した。角丸、頂点ハンドルの連動、フリーハンドの許容誤差、幅の補間方式を保存する。M1の固定v1 fixtureは変更せず、読込時に旧形式を検証してv2へ移行し、現在の形状検査も行う。不正な形状を黙って修復しない。未対応のv3以降は拒否する。既存のメッシュ文書codecにはこの変更を適用しない。

## 次の段階と境界

M3で、明示的な新規接続・門の開口・交差点の面結合・適法な橋・二重壁の関係と壁間道路を実装する。M2では線の見た目の交差から接続・橋を自動作成しない。既存anchorを維持できない区間削除や、他のプリセット・区間内部の接続を動かす編集は拒否する。高度な接続拘束の解決もM3で扱う。

FMG入力からの自動骨格生成はM4、用途・施設・住宅はM5以降、3D・共有URL等はM7以降のままである。既存CEの全機能をメッシュなしへ移植済みとは扱わない。M0で記録した橋APIの明示値が絶対上限30度を超える問題は、M3の受入前に共通規約の修正として解消する。
