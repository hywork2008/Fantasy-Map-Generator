# 町が目標を買う・なめし・屠殺・パン屋（S4）の観測（2026-11-03）

設計書: [urban-craft-staffing.md](../plan/urban-craft-staffing.md) §10.4。前の段階は [economy-start-s3-20261103.md](economy-start-s3-20261103.md)。

- 入力: S3と同じseed 2101〜2104・同じ設定で、地図を生成し直した。都市・川・陸地の数はS3と同じである。
- 平和モード、60か月。probeと比較の手順はS3と同じである（`economystart.mts`、`compare.mts`、`foodprobe.mts`、`rows.mts`）。
- `rows.mts`に、業種ごとの実務者（`guilds[].people`、財を作らない仕事も入る）と、表の業種の合計（`expectedDomainWorkerPeople`）の比較を加えた。

## 1. 変えたこと

- 町は、靴・蝋燭の1人あたりの目標の量を、日用品の一般の買い物の前に町の財布で買う（`householdPurchase`）。
- 肉屋: 町の家計が買った肉1トンあたり2.5人月を、食品加工の職人として数える。
- なめし: 市場に入った皮1枚あたり0.05人月を、市場の町に人口の割合で分けて、皮革の職人として数える。
- パン屋: 表のパン屋の人数（1,000人あたり12人）× 町で主食が足りた割合を、パンの職人として数える。
