- 既定（allRevenue・workshop）、`pollTax`、親方を前の決まり（legacy・stipend）、両方を前の決まりの4通り。

## 2. 国の予算（pollTax → allRevenue、36か月の合計の差、千）

| 段 | 国 | 人 | 農村 | 町の家計 | 市場 |
| --- | ---: | ---: | ---: | ---: | ---: |
| 予算の配分（allocateTreasury） | −68.5 | +61.5 | | | |
| 国の公共の支出（publicSpending） | +61.8 | | −51.1 | −10.7 | |
| 人の暮らしの費用（characterLivingCosts） | | −59.1 | | +44.8 | +14.4 |
| 農村が町で使う（ruralSpending） | | | +53.5 | −40.1 | |
| 36か月目の残り | −4.7 | +3.9 | −8.2 | −2.3 | −3.8 |

- 国は、蓄えの目安を超えた金庫の一部を公共の支出として家計（主に農村）に払う。予算が全ての収入からになると、国の金庫から部局・王家・役人へ回る分が増え、その分だけ目安を超える分が減って、公共の支出が約5%減った。
- 前は国→家計（農村）に直に回ったお金が、国→人→（暮らしの費用）→町の家計と市場、に回るようになった。農村は収入が減った分、町で使う分を減らすので、町の家計もほぼ元に戻る。
- 部局の予算はお金を新しく生まず、公共の支出との取り合いになっている。お金は消えていない（7つの持ち手の合計の差は−0.0%）。

## 3. 親方の稼ぎ（legacy・stipend → byWorkshop・workshop、千）

| 市場から農村への払い（marketPayout） | | | −2.4 | +22.2 | −22.6 | |
| 36か月目の残り | −3.3 | +12.6 | +8.6 | −17.9 | −5.2 | +5.2 |

- 親方の取り分は町の金庫から払われ、親方はそれを町で使う（町の家計 +56）。
- 市場のお金が減った主な理由は、年ごとのギルドの段で、豊かな町が金庫の余りの一部を市場の預かりに入れる分（\`MARKET_SHARE\`、guildTreasury.ts）が減ったこと（市場 −28）。町の金庫が親方の取り分を払った分だけ、年の余りが小さくなる。市場のお金が減ると、市場が農村に払う分（marketPayout）が減り、農村の家計が減る。
- つまり、町の金庫→市場→農村の通り道に乗っていたお金が、町の金庫→親方→町の家計に回るようになった。
