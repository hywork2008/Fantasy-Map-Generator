# 収穫の準備金の計測（2026-11-09）

設計は[harvest-cash-reserve.md](../plan/harvest-cash-reserve.md)。市場は余りを払い出す前に、次の4か月に前の年の同じ月の収穫の買い取りで払った額を残す（`harvestReserveMonths` 既定4）。

## 1. 条件

- 地図と条件は[market-credit-20261109.md](market-credit-20261109.md) §1と同じ（北緯30°の地図2枚、24か月）。石鹸の流れは`barillaflow.mts`、市場のお金と町のお金は[cashsteps.mts](market-cash-20261109/cashsteps.mts)（2103、24か月）。実行は[run.sh](harvest-reserve-20261109/run.sh)。
- baseは931547a96（市場の掛けまで）。石鹸はmarket-credit-20261109のmarket-*.json、市場のお金は[base.sh](harvest-reserve-20261109/base.sh)で同じ24か月を計った。

- 2年目の2〜4月は、baseでも市場のお金が人の数の蓄えを少し超えるだけで、払い出しは月2〜4千だった。準備金はこれを止め、4月の市場のお金を6千増やしたにとどまる。
- 2年目の`marketPayout`は5〜8月に月3〜5万。この手順は、余りの払い出しの前に、掛けで買った穀物と干し草の農家への返し、商館への払いもする。5〜8月の分は、収穫の買い取りの掛けの返しが多いと見られるが、この計測では分けていない。準備金は月初めの次の4か月を見るので、6月からは小さい（7〜10月の買い取りは約6万）。
- 町のお金は2〜3千多いが、5〜9月に約35%減るのは同じ。

## 3. 結論

- 収穫の準備金は効かない。春に市場のお金を大きく払い出したのは1年目だけで、地図の初めの市場のお金（37万）による。2年目は市場のお金が人の数の蓄えをほとんど超えない。
- 2年目の市場のお金は、収穫の買い取り（5〜7月に約18万）と`marketPayout`（5〜8月に約16万）で尽きる。`marketPayout`のうち、農家への掛けの返しと商人への余りの払い出しの割合は分かっていない。
- 次は、`marketPayout`を、穀物の掛けの返し、干し草の掛けの返し、商館への払い、余りの払い出しに分けて計る。
