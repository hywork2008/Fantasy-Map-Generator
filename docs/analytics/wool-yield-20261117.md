# 毛の布を羊毛4ロットで作る計測（2026-11-17）

[textile-basket-scale.md](../plan/textile-basket-scale.md) §3.6。Cloth・Wool Cloth の羊毛を、布1ロット（4 t）に6ロット（9 t、2.25 kg/kg）から4ロット（6 t、1.5 kg/kg）にした（`WOOL_LOTS_PER_CLOTH`、保存は `migrateWoolClothYield`）。根拠は [wool-sources-20261117.md](wool-sources-20261117.md)（16世紀の標準の布で1.31 kg/kg、中世の脂付きの羊毛は洗いでより多く減る）。比べる相手は [bedding-reserve-20261117.md](bedding-reserve-20261117.md)。

## 1. 条件

- 地図2103、36か月、戦争なし・略奪なし、既定。[run.sh](wool-yield-20261117/run.sh)。3年目の月平均、ロット。

## 2. 結果

| | 6ロット（前） | 4ロット |
| --- | ---: | ---: |
| 衣服 使った量（町 + 農村） / 需要 | 108.2 / 211.8（51%） | 135.1 / 211.8（64%） |
| 毛布 使った量（町 + 農村） / 需要 | 61.8 / 433.0（14%） | 119.2 / 433.0（28%） |
| 農村の衣服の不足のうち 財布 / 在庫 | 50.4 / 37.6 | 36.3 / 26.5 |
| 羊毛の値段 | 5.23 | 3.83 |
| 毛の布の値段 / 衣服の値段 / 毛の衣服の値段 | 70.1 / 164.7 / 123.1 | 81.5 / 184.5 / 129.7 |
| 36か月目の在庫 毛の布 / 亜麻布 / 毛布 | 1.4 / 0.4 / 1.5 | 80.4 / 15.6 / 0.8 |

- 刈った羊毛は、どちらも毎月全て使われる。
- 家計の収入・GDP の差は2%以内。

## 3. 読み取り

1. 衣服は需要の51% → 64%、毛布は14% → 28%に上がった。
2. 毛の布と亜麻布が在庫に残るようになった。羊毛の量ではなく、布から衣服を仕立てる量（人手・工房）が次の上限になった。衣服の在庫は今も0。
3. 羊毛の値段は下がった（布1ロットに要る羊毛が減り、羊毛の値が布の値に占める割合が下がる）。衣服の値段は少し上がった。
4. 毛布の不足の内訳の「取り置き」は、数え方の誤り（[bedding-reserve-20261117.md](bedding-reserve-20261117.md) §3の3）で大きく出ている。
