# 家計の布が満たされない原因（2026-11-17）

[textile-basket-scale.md](../plan/textile-basket-scale.md) §3.1の計測。布の家計の精算（`textileDemand.ts` `settleHouseholdTextiles`）が買い手ごとに残す不足の内訳（`settlementDiagnostics`）を、月ごとに全ての市場で足した。

## 1. 条件

- 地図2103、36か月、戦争なし・略奪なし、既定。[run.sh](textile-gaps-20261117/run.sh)、記録は [basket.mts](household-basket-20261116/basket.mts)（`textileGaps`・`textileStocks` を足した）。
- 3年目（25〜36か月）の月平均。単位はロット（衣服は1,000揃い、毛布は100枚）。
- 不足の内訳は重ならない分け方で、順に「先に取り置いたお金（priority）」「財布（budget）」「在庫（stock）」「割り当て・端数」。

## 3. 読み取り

1. **衣服は、作る量が足りない。** 町は財布が余っている（月10,273）のに、在庫が0で買えない。不足の8割が在庫による。衣服・布の在庫は、どの市場でもほぼ0。
2. **農村の衣服は、財布と在庫の両方。** 不足の57%が財布、43%が在庫。使った量の大部分（96のうち82）は家の手仕事と仕立ての請負で、市場で買う分は少ない。
3. **毛布は、衣服のための取り置きで止まっている。** 農村の毛布の不足のほぼ全て（353のうち353）が「取り置き」。毛布は、衣服の残りの需要の分のお金を取り置いた後でしか買えない（`getBeddingCashBudget`）。衣服は在庫が無くて買えないのに、そのお金は取り置かれたまま毛布に回らない。毛布の在庫は残っている。
4. 財布（手持ちの月5%）が主な原因という見込み（設計§3.1）は、半分だけ当たった。主な原因は、衣服を作る量と、毛布の取り置きの決まりである。
