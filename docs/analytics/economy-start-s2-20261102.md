# 較正の無いレシピ財の労働量（S2）の観測（2026-11-02）

設計書: [urban-craft-staffing.md](../plan/urban-craft-staffing.md) §6.3・§10.2。前の段階の観測は同書§10.1（S1、`economy-start-s1-20261102/analysis.json`）。

- 入力: S1と同じseed 2101〜2104・同じ設定（`economy-start-20261102/storage.json`）で、各版のコードで地図を生成し直した。都市・川・陸地の数はS1と同じである。
- 平和モード、60か月。probeは`economy-start-20261102/economystart.mts`。比較は`economy-start-s2-20261102/compare.mts`（S1との比較、`comparison.json`）。
- 塩・保存食・家畜の市場在庫と値段、町の財布は`economy-start-s2-20261102/foodprobe.mts`で、seed 2101・2102を24か月観測した。S1の値は、S1のコード（`0ba25a5ad`）をS1の地図で走らせた。

## 2. 労働量だけ（seed 2101）

月の生産（世界の合計、ロット）。S1 → 労働量だけ、1・12・60か月目:

| 財 | 1か月 | 12か月 | 60か月 |
| --- | --- | --- | --- |
| 保存食 | 48 → 5,152 | 41 → 7,944 | 41 → 5,338 |
| タール | 1 → 0 | 5 → 2,560 | 8 → 5,495 |
| 蝋燭 | 11 → 5,616 | 3 → 0 | 11 → 0 |
| ビール | 0 → 1,405 | 6 → 354 | 8 → 314 |
| 樽 | 0 → 640 | 1 → 642 | 2 → 684 |

- 上限の無い財（保存食・タール・蝋燭）は、1ロット1,000人月の労働だけで抑えられていた。労働を実際の値にすると、原料と資金の続く限り作られる。
- ビール（家計の上限あり）と樽（較正の行あり）は、今まで労働が足りず作られなかった分が作られるようになった。
- 贅沢品（宝飾品・彫刻・美術品など）は、贅沢品の需要で抑えられ、変わらない。

- 在庫の上限を入れると、在庫は目標の3か月分の前後で止まり、家畜の値段はS1に戻る（2102の牛は+11%）。塩は3つの版とも変わらない。
