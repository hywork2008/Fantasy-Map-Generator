# BV高品質モデル 第15群：石灰窯と漂白場（2026-11-01）

Medieval 30の石灰窯と31の漂白場にCodex GPT-6.1 SolのHighを追加した。[複合モデル設計](../plan/bv-composite-models.md)に従い、各モデルを生成境界で3部品に分け、部品台帳と統合後の頂点範囲を保持した。元のLow生成関数とCE用default参照は保持する。

### 石灰窯の部品

- ：窯壁、上部の投入部、焚口・通路・炉床、内側の受け段・支持と装入石。焚口を暗い面で塞ぐ表現にはせず、実際の空間として残した。
- ：地形に一体化した投入土手、踏段、支持柱付きの頂部足場、側方の手すりと基礎。会館用の扉接続付き外階段とは接続条件が異なるため、土手を含む独立した機能部品とした。最後の投入経路を手すりで塞がない。
- ：原石、横木に載る薪、脚付きの道具台・道具。支持物も同じ部品に含む。

### 漂白場の部品

- ：草地・布・杭・留め紐、柵・開いた門・作業通路。布下面を草地の上面に接触させた。
- ：3基の乾燥枠を同じ関数で生成する。脚・柱・方杖・横木・込栓と布・留め紐を一緒に扱う。布は横木の下に浮かせず、横木をまたいで前後へ垂らす。
- ：共通ModelKitの厚壁開放桶を使用し、箍・継ぎ目・水面・攪拌棒を追加した。布の置き台と脚も同じ部品に含む。

BVのViewで各部品を単体表示できる。単体選択時は選択したfactoryだけを生成する。Lowは従来の一体生成を単一のLow部品として表示する。

## 資料と模式化の範囲

石灰窯はHistoric Englandの[Pre-industrial Lime Kilns](https://historicengland.org.uk/images-books/publications/iha-preindustrial-lime-kilns/heag222-pre-industrial-lime-kilns/)で説明される、炉床と装入石を分ける受け、下部の焚口・通路、間欠式窯の構造を参考にした。上部の投入面・作業面については[充填口と背後のcharging platformの説明](https://historicengland.org.uk/listing/the-list/list-entry/1021012/?section=overview)も参照した。この登録例そのものを中世の実例とは扱わない。

今回の窯は未点火で石を装入した模式モデルで、特定の遺構を復元したものではない。円筒形、寸法、石積み、土手の形、手すり、資材配置は表示用の設計判断であり、中世全域の標準形式として検証したものではない。

漂白場の草地に布を広げる工程は、[National Museums NIの所蔵写真解説](https://collections.nationalmuseumsni.org/object-hoyfm-wag-1046)と[オランダ野外博物館の説明](https://www.openluchtmuseum.nl/en/activities-agenda/laundry)を参考にした。後世の記録・展示は工程の参考であり、今回の柵・乾燥枠・桶の配置や寸法が特定の中世地域の史料で確認されたとは主張しない。草地は作業区画を示す模式的な広さで、実際の施設規模や処理能力の算定には用いない。

- `npx vitest run src/buildings/medieval/kilnAndBleachingDetails.test.ts src/city3d/adoption.test.ts`を関連範囲として実行。土手内の支持接合を調べるレイは、地形表面ではなく接合対象の柱・足場を検査するよう調整した。最終結果は専用9件、採用3件の計12件成功。

- 各3部品の単体生成、High台帳、統合後の部品範囲を確認。
- 窯は焚口の複数の高さから炉内へ通じること、周囲に壁があること、投入部が開いていること、投入足場と柱の接合、手すり支柱と基礎の接合、投入経路が空くことを検証。
- 漂白場は布下面と草地の接触、門から作業通路が通れること、布が乾燥枠の横木をまたいでいること、水面が桶の縁より低いことを確認。

- 実BVで2種のLow／High、各3部品の単体表示、全景・低い視点を確認。巡回中のJavaScriptエラーは0件。
