# 副産物の値段（2026-11-11）

革（Leather）・獣脂（Tallow）などの副産物の値段が、在庫が何年分あっても下がらない理由を調べた。

## 1. 条件

- 地図は北緯30°の2102（[barilla-20261108.md](barilla-20261108.md)）、12か月、戦争なし・隊商の略奪なし。
- コード: aa5cf2a29に[leather-uses.md](../plan/leather-uses.md)と[footwear-capacity.md](../plan/footwear-capacity.md)の実装を加えたもの。凍結したworktreeで動かした。
- 測りは[markets.mts](byproduct-prices-20261111/markets.mts)で、毎月末に市場ごとの在庫と、基の値に対する値段を取った。実行は[run.sh](byproduct-prices-20261111/run.sh)、集計は[sum.py](byproduct-prices-20261111/sum.py)。
- これまでの測り（[goods.mts](household-goods-pay-20261111/goods.mts)）の値段は、市場の単純な平均だった。在庫の無い市場も同じ重みで入るため、ここでは在庫で重みを付けた値段も取った。

- 測りの弱さは、結果を変えなかった。革は、在庫で重みを付けても、ほぼ全ての市場で上限の3倍にある。
- 獣脂は、在庫が4.7倍になっても基の値の約1.2倍のまま動かない。
- 搾り滓のワインと駱駝は、在庫が増えると値段が下がる。作り方を持つか、セルに分布があり、毎月の値付けを通るためである。

## 3. 仕組み

1. 毎月の値付け（`initializeMarketPrices`、[markets-generator.ts](../../src/extensions/economy/generators/markets-generator.ts)）には2つの段がある。1つ目はセルに分布のある品・鉱山・炉の品、2つ目は作り方（recipe）のある品である。革と獣脂はどちらにも当たらないため、値付けを通らない。鉱石と地金にあった抜け（farm-labour-calibration.md §17）と同じである。
2. 家畜をつぶした皮と獣脂は、`credit`（[slaughter.ts](../../src/extensions/economy/generators/slaughter.ts)）で在庫に足されるだけで、値段を動かさない。
3. 買われると、1単位ごとに基の値の1%ずつ値段が上がる（`applyMarketPressure`、[marketPricing.ts](../../src/extensions/economy/generators/marketPricing.ts)）。下げるものが無いので、値段は上がる一方で、上限に張り付く。革は靴に多く買われるので上限に、獣脂は蝋燭に少し買われるだけなので始めの値の近くに止まる。
4. 長靴と革の品は2つ目の段で値付けされる。元値（革2枚 × 上限の値段）に、上乗せ ×（需要+5）÷（在庫+5）を足す。在庫のある市場の8割近くで上限にあるので、この需要は町が実際に買う量（`householdPurchase`の目標）よりずっと大きいと見られる。長靴の需要は、町の人数 × 日用品（utilities）の割合から出している（`calculateGoodDemand`）。数はまだ確かめていない。

## 4. 読み取り

1. 革・獣脂の値段が下がらないのは、値付けの抜けである。在庫と需要で値段を決める段に入れれば、下がる。
2. 長靴・革の品は、値付けの需要と、町が買う量が別のものになっている。値付けは、買う量の目標（較正の行）を需要として見るのが良い。
3. 町の家計と金庫の減り（[footwear-capacity-20261111.md](footwear-capacity-20261111.md) §4）は、上限の値段で目標の量を買うためで、値付けを直せば小さくなる見込みである。
