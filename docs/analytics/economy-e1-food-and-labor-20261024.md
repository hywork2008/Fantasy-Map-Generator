# E1 新市場の初回食料決済と牧畜・開墾労働（2026-10-24）

E0完了済みの`feature/economy-circulation`で、E0から引き継いだ初回食料決済スキップと、配分経路の労働量の不整合を修正した。**E1全体は未完了**。牧草地・群れ目標・冬季飼料・地域別採毛の再校正を完了扱いにしない。新しい羊毛用途、衣服/寝具の需要式、初期金、人口、在庫、商品単位は変更していない。

## 配分原則との照合

| 原則 | 現在の経路 | 差分と今回の扱い |
| --- | --- | --- |
| 主食を先に確保 | 作物の月別作業を先に取り、狩猟、その後に漁業・牧畜・果樹を価値順に配分し、残りを家庭内繊維加工へ回す | 最低限を満たした後の追加食料と他の必需品を、必要度で比較していない。配分順は今回変更していない |
| 土地の質と食料充足で用途を分ける | `husbandry.ts`は耕地・市街地を除いた面積に適性上限と人口×1 haの仮値を適用 | 耕作不適地の優先利用と、食料充足を条件とする耕作可能地の転用は未対応 |
| 休閑・共有地を一度だけ使う | `landUseActivities.ts`は明示指定された休閑放牧・圃場飼料を別牧草地の要求から控除 | 自動計画での利用・実飼料量の接続は未完了。控除できる面積を無条件に飼料へ加算していない |
| 月別の労働を一度だけ使う | calendar経路は作物を差し引き、各職の季節ピークで残余を制限。家内加工はその後 | 閑散月だけ他職へ移る配分ではない。都市収穫援助等の全職種の同時使用はE4に残す |
| 牧夫は実際の群れを世話する | 従来は`max(実頭数, 土地の潜在頭数)`を全種の世話・採草需要に使用 | **修正**: 種別の頭数が記録済みなら実頭数を使用。既存の超過群れも全頭世話する。未初期化の種だけは従来の土地計画を初期化前の代用として使う |
| 開墾は同じ住民の労働から出す | 職種列を`workforce.otherOccupationDays`に換算して維持・開墾予算から引く | **修正**: 実人数の職種列にpopulationRateを再度掛けていた。実人数×年間作業日数へ統一。明示設定した作業日数は引き続き優先 |
| 群れは複合生産・需要・冬飼料で決める | 種別面積は適性重み、年間飼料上限は実購入・売却・損耗を反映。既存超過群れは段階調整 | 肉・乳・皮・羊毛・堆肥・畜力・輸出需要を共通の群れ目標へ結んでいない。今回の労働修正を群れ目標の完成に読み替えない |

## 新市場の初回決済

`settleMonthlyFoodConsumption`が台帳なしの市場をスキップしていた。既存の`emptyFoodLedger`を共用し、消費の直前に空台帳だけを作る。新世界用bootstrapを呼ばず、セルの自家備蓄・都市備蓄・既存口座をそのまま使う。既存市場の公的穀物を新市場へ自動で移す処理も追加していない。農家の財布は従来の`moveRuralPursesWithFarms`と遅延初期化を使い、消費のための追加資金を作らない。

Worldの1301-01-26の実決済で、新市場17には次が記録された。台帳の`month=12`は従来の呼出し引数を維持しており、実際の観測日時と分ける。

| 食料台帳の量 | 修正前 | 食料決済だけ修正後 |
| --- | ---: | ---: |
| 農村必要量 | 欠測 | 2,896.00単位 |
| 農村供給（全て既存の自家備蓄） | 欠測 | 2,096.57単位 |
| 農村の不足 | 欠測 | 799.43単位 |
| 都市必要量 | 欠測 | 113.06単位 |

| 都市の在庫制約による不足 | 欠測 | 113.06単位 |

初回決済時の農村134,964.137人・都市3,155.053人が台帳の対象となり、この時点の対象外人数は両方0になった。これは食料充足ではない。修正前の欠測を不足0として比較しない。消費前の空台帳作成なので、1301-01-01の市場発生直後の観測では台帳がまだない点も維持する。
