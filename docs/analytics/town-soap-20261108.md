- baseで町の買い物は贅沢品の予算と人物の贅沢品。soapでは家計の需要（`householdFood`）。
- 町の買い物は、2102で約70倍、2103で約110倍になった。それでも需要の約1割。
- 作った石鹸は、その月のうちに全部買われ、在庫は残らない。
- 月の買い物は、2102で15か月目から月180〜360樽、2103で月150〜230樽で、それ以上増えない。需要は月2,783樽と1,887樽。
- 国の船は、石鹸を持ち帰らなくなった。

- 石鹸の生産を約1割で止めている訳は調べていない。`Soap`は校正の表に無い品で、町は毎月の生産の手順の中で、利益でほかの品と比べて作る。
- 獣脂の在庫（86万・44万）と値段は、baseと変わらない。

## 3. バリラ

| | 2103 base | soap |
| --- | ---: | ---: |
| 輸出（1〜12か月） | 1.2 | 11.8 |
| 輸出（13〜24か月） | 0.1 | 12.1 |
| 白い石鹸の材料（13〜24か月） | 6.0 | 11.8 |

- 2103では、バリラが14〜18℃の市場から8〜14℃の市場へ年約12樽運ばれた。白い石鹸を作る油の市場が、バリラを輸入した。
- 2102では、バリラの輸出は0のまま。白い石鹸の材料は年5.5樽から29.5樽に増えた（14〜18℃の市場の中）。24か月目の在庫は145樽から112樽に減った。
- 白い石鹸そのものは、どの市場の間でも運ばれなかった。作った市場の町が全部買う。

## 4. ほかの変化

- 2102の油は、13〜24か月目の生産が258.5樽から66.6樽に、蝋燭の材料が168.7樽から0に減った。24か月目の値段は3.05から4.60に上がった。白い石鹸に使った油は62.2樽。減った訳は調べていない。2103の油の生産は82.1樽から46.1樽。

## 5. 結論

- 町の石鹸の需要は残す。石鹸の買い物は、2枚とも史料の量の約1割まで増え、白い石鹸が町に買われ、2103でバリラが市場の間を運ばれた。
- 生産が需要の約1割で止まる。町の生産の手順で石鹸を作る量が足りない。次は、石鹸と炭酸カリウムを校正の表（人1人あたりの床と労働の量）に入れ、その職人の数を史料に合わせる。
- 油の生産の減りを調べる。
