1. 値段は、値の比（12.5分の1）どおりには下がらず、6〜14分の1だった。安くなって需要が増え、需給の分だけ値の倍率が上がった。
2. 農家が月の予算で買う干し草は5〜10倍になった。市場は草刈りの時に多く買い上げ、在庫は夏で約4〜5倍になった。
3. 4月の不足は、2年目で6.43から2.13百万kgに（約3分の1）、3年目で3.39から2.56に下がった。見込み（0.10%より下がる）どおりで、2年目は0.05%になった。足りない土地は2年目で43から22。3年目の売る土地は2から0。
4. 持ち手のお金の差は、どの時点も0.9%以内だった（27か月目：農村+0.43%・市場+0.89%・町−0.67%）。作った品は−0.34%。見込み（数%）より小さい。干し草の売り買いは、農村の財布と市場の金庫の間を回るお金で、どちらの側でも全体のお金に比べて小さい。
5. 残る不足（2年目4月の2.13百万kg）は、干し草の在庫も月の予算も足りない市場のものと読む。市場ごとには数えていない。
