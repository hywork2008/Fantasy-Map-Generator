# 農村の収入と、農村の産物の値段（2026-11-18）

[town-health-20261117.md](town-health-20261117.md) §3で、農村の家計の収入が賃金の倍率によらず同じだった。農村に賃金の入り口を足す前に、史料と、農村の産物の値段を確かめた。

## 1. 史料: 1300年ごろの農村の賃労働

| | 内容 | 出典 |
| --- | --- | --- |
| 労働の分け方 | 家族の仕事が生産の労働の約60%、領主への賦役が約10%、残り約30%が雇われ（日・仕事・出来高の払い、年雇いの奉公人） | Bailey, *Continuity and Change*（近年の推計の引用） |
| 雇われの担い手 | 多くは小さな土地を持つ農民。雇われは不定期で短い | 同上 |
| 領主の直営地の常雇い（famuli） | 1300年に約10.5万〜12.8万人、人口の約2% | Claridge & Langdon 2015; Claridge, *EcHR* 2026 |
| カクスハム（オックスフォードシャー、1300年） | 約30戸。領主は常雇い9人。小屋住み14戸は領主から仕事を得た（農の賃金に年£3） | Dyer, *Standards of Living in the Later Middle Ages*, ch. 8 |

小さな農民の家の収入のうち賃金の割合を直接示した値は、見つけていない。

## 2. 農村の中の賃金は、農村の収入の合計を増やさない

- シムの農村の家計は、市場ごとに1つの財布である。農民が小屋住みを雇っても、財布の中でお金が動くだけで、合計は変わらない。
- 農村の収入の合計が増えるのは、町・市場・国から入るお金が増える時だけで、それは農村が売る物の量と値段で決まる。

## 3. 農村の産物の値段（地図2103を作り直したもの、既定の設定、倍率5、[run.sh](rural-income-20261118/run.sh)）

- 農村の生の産物（穀物・家畜・羊毛・木・炭・蜂蜜）は、ほとんどが下限か、その近くにある。町で作る品は値以上にある。
- 生の産物の値段は、市場の需要 ÷ 在庫（`getRawGoodTargetPrice`）で決まる。在庫が需要より大きいまま、下限に張り付いている。
- 史実の値段（price-level-20261116 §2、主食 kg に直した1500年ごろの値）と比べると、ずれは品によって違う。羊毛は史実の0.11〜0.15倍、薪は0.35倍で安すぎる。家畜は下限でも牛1.6倍・羊2.5倍で、史実より高い。

## 4. 読み取り

1. 農村に賃金の入り口を足しても、農村の財布の中の移し替えになる。史実の雇われの約30%は、主に農民どうし・領主の直営地の中の雇いで、シムでは財布の中に入る。
2. 倍率1.5の時は、町の品も安かったので目立たなかった。倍率5で町の品が値に見合う値段になり、農村の生の産物だけが下限に残った。
3. 直す所は、生の産物の値段が下限に張り付く理由（在庫が需要を上回り続ける理由）である。品ごとに、在庫に何が入っているか（家畜の群れ、売れ残りの積み上がり）と、需要の数え方を確かめる必要がある。羊毛は値そのものも史実より安い。

## 6. 生の産物の値段に加工で使った量を入れた後（2026-11-18 追記）

[raw-good-processing-demand.md](../plan/raw-good-processing-demand.md) の計測。同じ地図、36か月、既定の設定。[run.sh](rural-income-20261118/run.sh) の後半。

- processing: 作り方が使った量を需要の下限に入れた。
- wool: それに加えて、羊毛を生の産物の値段の決めに入れた（今の既定）。

### 6.2 3年目の結果

| | 前 | processing | wool |
| --- | ---: | ---: | ---: |
| 1人あたりの GDP（主食の年数） | 1.95 | 2.02 | 2.02 |
| 衣服を満たした割合（町 / 農村） | 59% / 64% | 57% / 64% | 60% / 64% |
| 毛布を満たした割合（町 / 農村） | 42% / 19% | 38% / 18% | 42% / 17% |
| 農村の家計の入りの合計 | 129.4万 | 127.6万 | 127.2万 |
| 農村の家計（36か月目） | 15.7万 | 15.4万 | 15.2万 |

- 農村の収入は増えず、少し減った。羊毛の値段が上がると、農村の機織りが買う羊毛の費用が上がる。
- **刈った羊毛は、代金を払われずに市場の在庫に入る。** `woolProduction.ts` に農家への払いが無く、農村の家計の段ごとの出入りにも羊毛の売りが無い。農村の家は、自分の羊から刈った羊毛を市場から買い戻している。亜麻・麻・綿も、農村の収穫が払われているかを確かめる必要がある。
