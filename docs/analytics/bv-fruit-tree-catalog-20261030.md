新規8種の版IDは `tree.<speciesのハイフン表記>@<quality>#codex-gpt-6.1-sol`。作者は4品質とも `Codex GPT-6.1 Sol`、各品質1版を暗黙採用し、low／medium／highの派生元は同種ultra。具体的なID、派生元、factory、LOD、各品質のbytes・外接実測値・GPU資源数は [台帳JSON](bv-fruit-tree-catalog-20261030.json) へ保存した。新規8種は全て `pixels`・`bounded`、自然林用の `biomes` は未指定。

全32品質がlow≤500、medium≤3,000、high≤25,000、ultra≤120,000三角形、high source配列≤3 MiB、ultra≤13 MiBという制作目安内。全て3 mesh・3 material以内。source bytesはCPU側の属性とindex配列であり、GPUメモリ量ではない。これらは単木の目安で、8種を同時に置く園地の有限予算を保証しない。

BV宣言寸法は原点中心で実測を覆う枠。地表Y=0、根の下端Y=-0.35 mを共通基準とし、上表の高さに地下の根を加えない。BVのMesh dimensionsには地下部分も含まれる。寸法は描画用の例で、品種・地域・時代共通の栽培規格や実測木ではない。

## 照合方法と検証範囲

`scripts/auditBvFruitTreeCatalog.mts` で、現行BV登録・採用解決・単一版・作者と派生元・LOD・寸法と、10件の保存済み単木計測を照合した。各計測のSHA-256も台帳JSONへ収録する。新規32品質の制作予算、全40品質の接地・宣言寸法・実BV採用表示、各GPU記録の巡回時geometry数の安定と破棄後0、pageerror 0を確認する。

```sh
node --import tsx scripts/auditBvFruitTreeCatalog.mts
```

これは現行の登録情報と保存済み計測の照合で、全樹木を再生成・再描画する処理ではない。幾何を変更した場合は、該当の単木検証スクリプトで計測を更新してから台帳を作り直す。40品質を同時に描く場面や、園地の自動配置、都市全体FPS、歴史的適性、季節・収量は検証しない。

最新F08では関連156件の成立を確認し、修正後の影響9件も成功。各段階の検証件数は同じテストを含むため足し合わせない。型チェックは既存の `fogControls.ts:45` のエラーで失敗し、解決済みとはしていない。F08で変更したソース7ファイルのBiome、差分チェックと台帳照合は成功。画像は各段階で一時出力を目視後に削除し、Gitへ収録していない。

## V01：ブドウの後続要件

V01は後続要件の記録を完了した。ブドウのモデルやCEブドウ園を実装済みという意味ではない。対象種は `Vitis vinifera` とし、次の契約を別のブドウ／園地設計へ引き継ぐ。

| 項目 | 後続設計で決める内容・完了条件 |
| --- | --- |
| モデル単位 | 根元・幹・多年枝・新梢・葉と果房を持つ1株と、支柱・棚・畝／列を分離。立木のTreeSpeciesや自然林の選択へ無理に登録しない |
| 仕立てと根拠 | 初版の地域・時代・史料と仕立てを選び、株仕立て・支柱・棚等のどれを作るかを確定する。近代のワイヤー列を全時代の既定にしない |
| 区画と列 | 園地境界から列・株間・畝間・管理通路と支持物の反復を生成し、区画外・建物・水域・保護区域との重複を避ける |
| 接地と保存 | 株・支持物の斜面接地、向き・seed・仕立て・間隔を保存し、読込・Undo/Redoで再現する |
| 表示と予算 | 葉・果房・支持物を統合／インスタンス化し、近中遠景・影・有限予算と省略時の代替を決める。採用版・作者・派生元を記録する |
| 受入検証 | 株の近景と列の反復を実UIで確認し、果房の接続、地形・排他、品質切替、資源解放と固定区画の性能を検証する |

果房の個数を収量へ換算せず、FMGの商品と実際の土地配分を使う接続設計へ渡す。V01は本計画の新規8樹種32品質枠へ加算しない。天然ゴムはこの果樹計画の対象外を維持する。

## 次の作業

BV単木の追加計画P0〜P6を完了。**次はCE果樹園への接続計画の立案**とし、FMGの実際の多年生作物の土地配分・商品識別からCEへ渡すデータ、区画・列・間隔・地形・排他・保存と有限予算を先に確定する。

既存の自然林へ果樹を追加するだけで栽培地の表示を完了扱いにしない。O01〜O03・D01〜D03、V01で記録したブドウの後続制作は未実装であり、地域・時代と園地の目的に応じて優先順を決める。今回のBV完成により、FMG・REの表示や経済・作物暦・収量が変更されたとはしない。
