## 4. 指標の修正（T0の値の読み方）

- **T0の背面と給水・排水口の指標は誤りだった。** BVモデルを平面に置く時の座標は (x, −z) で、モデルの前（+z）は平面の −y になる（`bvFacilityAsset`）。T0では z をそのまま y として扱ったため、背面の口ではなく前面の位置を測っていた。T0の「岸の最前列」「背面が水」「流れ正」は前面についての値である。工房の数・未配置・群・町の下流は影響を受けない。
- 「背面が水」の基準は、川の中心線の頂点ではなく、水面の縁の最寄り点に変えた（中心線が2点だけの直線の川、中心線が水面から外れた川で誤るため）。
