## 4. 読み取り

1. 蜜蝋の在庫は、2102で5年目から約5,200、2103で6年目に約2,800で頭打ちになった。教会に納める蝋の地代が、市場の使い道の1年分の上限として働くことを確かめた。
2. 2102の6年目には採れた量の約23%を納めている。蝋燭の材料が年約9,400から約8,100に減ったのは、蝋燭の在庫が増えて値段が基の値の0.74倍まで下がり、蝋燭屋が作る量を減らしたため（需要の側）で、地代が材料を取ったためではない（地代は12か月分を超えた在庫だけに掛かる）。
3. 人の手持ちのお金は、6年間ずっと増え続けた（2102で年+25千→+14千、2103で+17千→+9千）。増え方は遅くなるが、止まってはいない。2年目から6年目に、人の手持ちが約+72千のとき、市場のお金−80千、町の家計−34千、国の金庫−29千、ギルド−19千が減った。人が使わずに貯めるお金が、他の持ち手から少しずつ吸われている。
4. 測った7つの持ち手の合計は、5年で約3%（2102）・約1.4%（2103）減った。測っていない持ち手（11の持ち手の残り）への動きか、地図の外への出口かは、この計測では分からない。
