# 首都の行政雇用を実人数で数えた後の手工業（2026-11-02）

前の記録: [economy-start-20261102.md](economy-start-20261102.md) §4・§7のA（首都の成人を行政職がすべて取り、首都の職人がほかの大きな町の3分の1〜2分の1しかいない）。

- 入力: 前の記録と同じseed 2101〜2104・同じ設定（`economy-start-20261102/storage.json`）で、修正後のコードで地図を生成し直した。都市・川・陸地の数は修正前と同じである。
- 平和モード、60か月。probeと集計は前の記録と同じ（`economy-start-20261102/economystart.mts`・`analyze.mts`）。集計の結果は`economy-start-admin-20261102/analysis.json`。

## 1. 変えたこと

- `getAdministrationRequiredWorkers`（`administrationEmployment.ts`）は、旧式の人口ポイント`4 + 国の人口×0.005 + 都市数×1`をやめた。実人数の`getAdministrationEmploymentPeople`（8人＋都市あたり2人＋国の人口の0.5%）をポイントに換算する。
- 首都の行政は、首都の成人の15%（`ADMINISTRATION_MAX_CAPITAL_ADULT_SHARE`）までとした。実人数にしても、国の人口の0.5%の項で、首都の成人を超える首都が地図ごとに3〜13あったためである（例: 272万人の国を、成人1,611人の首都が治める）。国の残りの役人と守備兵は地方で働き、首都の労働力を取らないとみなす。15%は、宮廷と官庁が小さな居城都市で人口の5〜10%、大きな首都で1〜2%だったという目安による。
- Calibration Overviewの行政の表示も、同じ値（上限込み）にした。

- 首都の職人は、首都以外の町と同じ水準になった。首都の行政職は、成人の15%前後（中央値0.149〜0.150、最大0.16）である。
- 首都以外の町は、ほとんど変わらない。
- 60か月目の都市人口・会館の数・取引回廊の数は、修正前と1%以内の差である。

## 3. 残ったこと

- 修正後は、首都の手工業が6〜12か月目に人口1,000人あたり130〜318人まで上がり、2〜3年で80〜135人に落ち着く。前の記録§1の「生成直後は落ち着いた値の約3分の1で、そのあと一度上がりすぎる」動きが、首都でも起きるようになった。生成直後（0か月）の値は修正前と同じである。これは改善候補B（生成直後の経済を落ち着いた状態に近づける）で扱う。
- 15%は目安の値で、校正はしていない。
