## 3. 蜂蜜の使われ方（前）

- 計測スクリプト: [honeyflow.mts](honey-biome-20261107/honeyflow.mts)。読み取りのみ。
  - 物の流れの記録（`setGoodFlowObserver`）から、蜂蜜の出入りを月ごとに、向きと種類で足した。
  - あわせて、毎月末の市場の在庫と、在庫で重み付けした値を出した。
- シード2103・2102を12か月。襲撃なし、平和。
- 集計: [flowsummary.py](honey-biome-20261107/flowsummary.py)。出力は[flow-summary.txt](honey-biome-20261107/flow-summary.txt)。
- 前のコードは、土地を広げた後で、量・値・家計の需要を変える前である（採取は月0.04樽/1,000人、値4）。

| | 2103 | 2102 |

| 農村の採取（樽/月） | 360 | 681 |
| レシピの材料（酢・薬） | 9 | 15 |

- 使われるのは採取の約3%だけで、残りは在庫に積み上がった。

## 4. 量・値・家計の蜂蜜を変えた後

設計書§6の値（採取は月0.6樽/1,000人、値1.5、家計の蜂蜜は1人あたり年1 kg）。条件は§3と同じ。

| | 2103 前 | 2103 後 | 2102 前 | 2102 後 |
| --- | ---: | ---: | ---: | ---: |
| 農村の採取（樽/月） | 360 | 4,813 | 681 | 9,021 |
| 1人あたりの採取（kg/年、町と農村） | 0.08 | 1.12 | 0.09 | 1.15 |
| 家計（`householdFood`） | 0 | 4,260 | 0 | 7,841 |
| 家計の需要を満たした割合 | | 0.99 | | 1.00 |
| レシピの材料 | 9 | 13 | 15 | 24 |
| 他の市場へ送った量 | 3 | 6 | 47 | 23 |
| 12か月目の在庫（樽） | 4,706 | 6,955 | 8,972 | 14,877 |
| 12か月目の値（値打ち） | 1.00（4） | 0.39（1.5） | 1.22（4） | 0.38（1.5） |
| 在庫のある市場 | 25/25 | 23/25 | 42/43 | 36/43 |

- 家計の需要は、ほぼ満たされた（99〜100%）。家計が採取の約88%を使う。
- 残りの約11%（月約550〜1,180樽）は使い道が無く、在庫が月に約600〜1,200樽ずつ増える。そのため値は、値打ちの約1/4まで下がった。
  - この残りは、次に入れる蜂蜜酒の材料に当たる。
- 1人あたりの採取は約1.1 kgで、設計の1.5 kgより少ない。採取は農村の人だけが行い、町の人も数に入るためである（農村の人1人あたりでは約1.3 kg）。
- 蜂蜜の取れない市場（泥炭地・湿地など）のうち、6〜7市場は在庫が無い。他の市場から送られる量は少ない。
