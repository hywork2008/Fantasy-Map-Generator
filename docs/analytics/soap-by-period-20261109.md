## 4. 結果

- 町の石鹸の買い物は約12%になった（10%の割合と白い石鹸）。石鹸の炭酸カリウムは87〜88%、灰は87〜88%減った。
- 獣脂の石鹸への使い道はほぼ消え、獣脂はろうそくと海の輸出へ回った。オリーブは石鹸に使われず、油と香水が増えた。
- ガラスの炭酸カリウムは37→42、34→38樽と少し増えたが、町のガラスは135→100、138→86樽に減り、森のガラスと海の輸入が増えた。灰の使い道の大半は石鹸であり、容器（ガラス・陶器）の灰はもともと小さい。
- 町のお金の4〜9月の減りは24%（25.6万→19.8万）から20%（25.8万→21.0万）になった。市場のお金は2〜4月に1〜1.4万多い。
