# 立地の加点の割り引きと、木の無い土地の町のエール（2026-11-07）

設計は[low-habitability-site-bonus.md](../plan/low-habitability-site-bonus.md)。続きの元は[ale-biome-20261107.md](ale-biome-20261107.md)。

- A: 立地の加点を居住適性で割り引く（`siteBonusFullHabitability`、既定25）。
- B: 森の少ない市場の町のエールを減らす（`fmg-treeless-town-ale-woodland`、既定5%）。

## 1. 条件

- コード: 431609a43に、AとBの変更（まだコミットしていない）を足したもの。
  - 計測は、別の作業ツリーにコードを固めて行った。
- 36か月、襲撃なし、平和。集計は13〜36か月目。
- 計測スクリプト:
  - [beerprobe.mts](beer-shortfall-20261104/beerprobe.mts)
  - [biomeprobe.mts](ale-biome-20261107/biomeprobe.mts)
  - [siteprobe.mts](site-bonus-20261107/siteprobe.mts): 設計書§3.3の見込みの表。
  - [compare.py](site-bonus-20261107/compare.py): 比べた結果。出力は[summary.txt](site-bonus-20261107/summary.txt)。
- 実行:
  - [run.sh](site-bonus-20261107/run.sh): Bの計測と、Aの地図・計測。
  - [run-a.sh](site-bonus-20261107/run-a.sh): Aの地図と計測だけ。
- 計測は2つ。
  1. Bだけ: ale-biome-20261107と同じ地図4枚で計測し、ale-biome-20261107と比べた。
  2. A: シード2101〜2104の世界の地図を作り直した。
     - H = 25のlocalStorageは[storage-h25.json](site-bonus-20261107/storage-h25.json)、H = 1は[storage-h1.json](site-bonus-20261107/storage-h1.json)。
     - どちらもBを入れて計測した。
     - H = 1は、upstreamと同じ点数である。

H = 1の地図の結果は、Bだけの計測とほぼ同じになった（エールの需要: 2102は月24,202と24,189、2103は22,670と22,649、2104は15,719と15,717）。地図の作り直しによる違いは小さい。

### 3.3 エール

- H = 25では、世界の不足が需要の3.9%になった（H = 1は6.2%、Bの前は8.9%）。

## 4. まとめ

- Bで、世界の不足は8.9%から6.9%になった（同じ地図）。
- Aを足すと、新しく作る地図で3.9%になった。
- 泥炭地のKと町の人は、史料（設計書§2）の比に近づいた。
  - Kの密度は約1/65（面積の重みで1/52）。史料の北方の土地は約1/40〜1/45。
  - 町の人の割合は1.4%。フィンランドは約2.8%。
- 既定はH = 25とT = 5%のままにする。

## 5. 残った問題

1. 2102で、Kが減ったのにburgsが増えた原因（町の数を決める計算と`cells.s`の関係）。
   - 調べた結果は[town-count-20261107.md](town-count-20261107.md)。町の数は文化の届いたセルの数で決まり、文化の中心が移って届く範囲が広がったためである。
2. 泥炭地の町の人の割合（1.4%）は、史料（2.8%）の半分である。今の数字は4枚の合計で4.8kと少なく、地図による違いが大きい。
3. 樽職人が居ない市場のエールは、今も0である（設計書§6の2、土の器）。
