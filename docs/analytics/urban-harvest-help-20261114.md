## 3. 見込みとの違い

見込み（[urban-harvest-help.md](../plan/urban-harvest-help.md) §4）は、干し草の足りない日数8.6百万日のうち94%が埋まり、干し草が約2.7百万t乾物（8.05百万日 ÷ 3日/t）増えることだった。増えたのは約0.07百万tで、見込みの約3%だった。

## 4. 外れた理由（コードの読み取り）

干し草を刈る量は、毎月`harvestLivestockForage`で次の小さい方になる。

1. 伸びた草（立ち草＋余りの伸び）。
2. 干し草の人手（`getHusbandryLaborBudget().hayCapacityDays` ÷ 3日/t）。これは「計画の干し草の日数（`plannedHayDays`）」と「割り当てられた日数 − 世話の日数」の小さい方。
3. 蓄えの目標（`getCellHayPlan().reserveAfterMonthKg`）までの分。

[hay-plan-herd.md](../plan/hay-plan-herd.md)で3の目標は冬を越す頭数（今の頭数と養える数の大きい方）にしたが、2の計画の干し草の日数と、職業の割り当てが見る干し草の不足（`haymakingShortfallDays`）は、どちらも`calculateHusbandryDemand`の`hayWorkers`から出ており、その月にいる頭数（`careHeads`）の1年の餌で計画されている。夏の頭数は養える数の約6〜7割なので、刈る量の上限も、町の人が埋める不足も、今の頭数の分のままだった。

- 見込みの計算（[hay-labor-capacity-20261114.md](hay-labor-capacity-20261114.md)）は、要る日数を冬を越す頭数の計画で数えたため、コードが見る不足より大きかった。
- 同じ記録の「空いている大人の手で賄える割合約73%」は、要る日数を冬を越す頭数で数えた割合で、刈る量が止まる理由が人手か、計画の日数の上限かは分けていなかった。

## 5. 次に確かめること（計測の前に）

1. `calculateHusbandryDemand`の干し草の計画（`hayWorkers`）を、`getCellHayPlan`と同じ冬を越す頭数（設定`hayPlanHerd`に従う）にする。
2. その上で、干し草の月ごとに、刈る量を止めているのが（伸びた草・計画の日数・人手・目標）のどれかを土地ごとに数える（1枚・干し草の月まで）。

## 6. 干し草の人手の計画を冬を越す頭数にした後、刈る量を止めているもの

- `calculateHusbandryDemand`の干し草の計画（`hayWorkers`）を、`hayPlanHerd` winteredの時は種類ごとに今の頭数と養える数の大きい方で立てるようにした（`getCellHayPlan`と同じ）。
- [haybind.mts](urban-harvest-help-20261114/haybind.mts)（[run-bind.sh](urban-harvest-help-20261114/run-bind.sh)）で、地図2103を9か月進め、干し草を刈る土地と月ごとに、刈れる草・計画の日数・人手（割り当ての日数 − 世話）・蓄えの目標のどれが刈る量を止めたかを数えた。

| 暦の月 | 計画（千t） | 人手で刈れる分 legacy / cornAndHay | 刈って蓄えた分 legacy / cornAndHay | 目標で止まった土地 |
| --- | ---: | ---: | ---: | ---: |
| 5 | 199 | 187 / 187 | 143 / 143 | 239 |
| 6 | 2,310 | 2,048 / 2,120 | 1,848 / 1,920 | 579 |
| 7 | 3,740 | 3,510 / 3,589 | 2,065 / 2,097 | 2,001 / 2,085 |
| 8 | 2,684 | 2,644 / 2,684 | 1,091 / 1,074 | 2,239 / 2,301 |
| 9 | 1,060 | 1,060 / 1,060 | 245 / 238 | 1,565 |
| 1年 | 10,437 | 9,881 / 10,071 | 7,570 / 7,617 | |

1. 刈れる草はどの月も計画を下回らない。
2. 人手の不足は計画の約5%（legacy 0.56百万t）で、町の手伝いでその約3分の1（0.19百万t）が埋まる。
3. 刈る量を最も多く止めているのは蓄えの目標で、7〜10月にほとんどの土地が目標に届いて刈るのを止めている。刈れる分と蓄えた分の差は1年に約2.3百万tある。
4. したがって、3月に約600の土地で残る餌の不足（[hay-plan-herd-20261114.md](hay-plan-herd-20261114.md)）は、人手ではなく、蓄えの目標（干し草の計画）が冬に実際に食べる量より小さいことか、土地の間の偏りによる。
