# 町のお金の季節の動き（2026-11-09）

[soap-summer-20261109.md](soap-summer-20261109.md)の続き。町のお金（`burg.treasury`の和）は5〜9月に約35%減り、石鹸の職人が材料を買えなくなった。何がお金を動かすかを、シミュレーションの手順ごとに調べた。コードは変えていない。

## 1. 条件

- コードは8a3226417。シード2103の地図（[town-soap-20261108.md](town-soap-20261108.md) §1と同じ）、12か月（2月から1月）。
- [pursesteps.mts](town-purse-20261109/pursesteps.mts)は、計る手順（`measureTickStep`）ごとに、その中の町のお金の変わりを、中の手順の分を除いて足す。手順の外の変わりは毎月0で、町のお金の動きはすべて手順に入った。
- 2回目は、各品のレシピの材料と町の作った品を、その時の市場の値段で値打ちにした。
- 実行は[run.sh](town-purse-20261109/run.sh)。

- 季節で動くのは町の生産（`burgLoop`）。2〜4月は月2〜3万の入り、6〜9月は月1.4〜3万の出。
- 需要の買い物は月2〜2.9万の出で、年を通してほぼ同じ。
- 職人の委託の売りは9月から増え、1月に4.6万。夏に作った品が秋から売れる。
- 農村の支出と家計の支出は、年の後ろほど入りが増える。

- 町が作る獣脂と革の値打ちは、1月に一番大きく（冬の屠畜）、4月から12月まで減り続ける（獣脂で約3万、革で約1.1万）。
- 毛の衣類・毛の布の材料は、6月から月約5,000〜6,000増える（羊毛の取れる時）。
- 石鹸の材料は月約2,500〜3,500。
- この2つで、4月から8月の町の生産の変わり（約6万）の半分ほど。残りは調べていない。

## 4. 結論

- 町のお金の季節の動きは、町の生産の入りが年の後ろへ減ることから来る。1月の屠畜の獣脂と革の売りが月ごとに減り、夏には羊毛の材料の買いが重なる。夏に作った品は、秋から委託で売れて戻る。
- 石鹸は、この夏から秋の町のお金の少ない時に材料を買えず、減った。石鹸だけの問題ではない。
- 町のお金に季節の入りと出の差を均す蓄えや掛けの無いことが、町の生産の季節の止まりになっている。
