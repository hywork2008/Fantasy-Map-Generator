## 4. 持ち手のお金（toRenewalのlegacyとの差）

- 12か月目：農村の家計 −5%（2102 −4.9%、2103 −5.2%）、市場 +4〜5%、町の家計 −3%。1年目は副産物の代金が、在庫が多く値段の安い皮の分だけ減った。
- 36か月目：どの持ち手も±4%以内（2103：農村 +1.6%、市場 +0.4%、ギルド +3.8%、町の家計 −1.2%）。

## 5. 読み取り

1. 1年目から牛・肉・皮が約3割増え、長靴と革の品の在庫は尽きなくなった（2103で11か月目に長靴4.2千・革の品3.3千）。革の値段は1年目も価値の約半分で、1.5倍への値上がりは無くなった。
2. 毎月の牛の量は、1年の中での減り方が小さくなった（2103の1年目で2月125.8千、6月129.8千、11月62.6千）。秋に減る理由（その年に増える分の見積もりが1年の中で変わるためか、餌の季節の掛けのためか）は確かめていない。
3. 3年目は、牛・羊・豚・肉が前の決まりより12〜18%少ない。前の決まりでは売り残した余り（養える数を超えた頭）が持ち越されて子を産み、その分も売られていた。新しい決まりでは頭数を養える数に保つので、増える分も小さい。養える数を超えた頭に餌が足りていたかは確かめていない。
4. 3年目の長靴と革の品を作る量の減りは5〜9%で、肉と皮の減りより小さい。
