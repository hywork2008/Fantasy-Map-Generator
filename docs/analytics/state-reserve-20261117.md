## 2. 読み取り

1. 国庫は約29万で落ち着いた。年の収入を前の計測の約25万とすると約1.1年分で、0.75年より多い。この計測では国の収入を記録しておらず、年数は確かめていない。
2. 国庫から出た約52万は、町と農村の家計、市場へ移った。貨幣の合計はほぼ変わらない。
3. 保存済みの地図では、開始時の余りを最初の6か月で使い下げる（100万 → 38万）。1年目の支出の山は、保存済みの地図では残る。新しい地図では開始時の国庫が使い始める額に近いので、山は出ない見込み（未計測）。
4. GDP はほとんど変わらない（1.89 → 1.92）。お金を国から家計へ移しても、作る量は需要と供給で決まっているため。

## 2.5 新しく作った地図（2026-11-17 追加）

今のコードで地図2103を作り直し（開始時の国庫は人口 × 1.875）、同じ条件で36か月回した。観測に国の収入（借入と残りの戻しを除く税・関税）と公共の支出を足した。地形は前の地図と同じ種だが、市場・人口は同じではない。

- 1年目の公共の支出の山は無くなった（前の決まりでは1年目63万・2年目以降28万）。
- 国庫は収入の約1年分で落ち着く。設定の0.75年より多いのは、使い始める額を越えた分の25%しか毎月使わないため（使う額と入る額が釣り合う所が、線より上にある）。
- 貨幣の合計は約156万で、GDP の約2.8か月分（目安3〜4か月）。1人あたりの GDP は主食の1.88年分。
