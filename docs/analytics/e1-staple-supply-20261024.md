# E1: 主食収穫の物量と農作業不足の誤計上（2026-10-24）

前工程の36か月観測で、Provinceの主食不足が牧草地縮小では解消しないことを確認した。今回は、収穫・農村の自家留保・市場への販売候補を分け、農作業の労働不足を調査した。初期食料・資金、収量係数、作付面積の政策、冬季飼料源は追加していない。

## 原因と修正

`allocateRuralOccupations` は主食の農作業を先に取り、その後の牧畜・漁業・果樹などを余力内で配分する。一方、従来の `seasonalLaborShortage` は採用できなかった他職の希望作業も含む。その全体を `getCropLaborCoverageByCell` へ渡し、農作業の日数を上限として収穫から控除していた。畑を作業する労働を確保していても、未充足の牧畜求人が多ければ収穫が減る不整合だった。

月別の実際の予約作業から、移住後の住民作業能力・既存の家族支援・受入援助を差し引いた農作業不足を `cropLaborShortage` として分離した。収穫の充足率にはこちらを使う。全職種の希望に対する不足は既存の診断に残す。実際に農作業が能力を超える場合の未収穫は残し、旧surplus経路は互換性を維持する。新しい保存項目は追加せず、既存の収穫充足列へ反映する。

回帰試験では、実在する大きな群れの世話の求人が未充足でも、能力内の農作業を未実施扱いにしないこと、能力を超えた繁忙月は引き続き農作業不足になることを確認した。

## Provinceで分離できた物量

固定Province101はStandard・遠距離交易on・隊商襲撃off。台帳単位は主食相当量で、乳・肉を含む全栄養ではない。初期状態の農村主食年需要97,495.974に対し、耕地の見込収穫は労働反映前83,779.113、修正前の労働反映後53,281.558だった。修正後は53,578.872である。この誤計上の修正だけで土地・実労働の不足を解決したとはしない。

実際の生産処理の直前・直後に自家備蓄を読み、自家留保と市場への販売候補（購入搬入＋売れ残り）を分けた。留保は市場搬入と重複しない。初年度の実収穫は34,561.336、2年目55,143.646、3年目56,061.750台帳単位（修正前）。年見込と実処理は異なる時点の作付け・収穫暦を使うため、その差だけから消失量を認定しない。

修正前→修正後の36回の実主食供給は、農村211,437.660→211,926.460、都市9,642.090→9,653.330台帳単位。改善は小幅であり、初期備蓄で隠れていた継続供給不足は残る。セル別の生産・需要差は交易や共有地による補給を含まないので、個々のセルに畑を強制する判定には使わない。
