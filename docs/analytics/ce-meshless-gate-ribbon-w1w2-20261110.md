## 1. 変更

| 箇所 | 内容 |
| --- | --- |
| `suburbs.ts` `clipVectorDomainToWall` | 骨格の道路の経路探索の前に、敷地を「市壁の内側＋門の開口＋予約地（墓地・城・外堡・稜堡）＋配置の敷地」に切る。海側を開けた市壁は、壁の線で切った敷地のうち中心との間に壁の無い部分を残す。市壁の無い町は変えない |
| `suburbs.ts` `vectorRibbonShortfall`・`vectorInteriorFreeM2` | 市壁の内側の空き地（水面・予約地・配置・全ての道の面を除く）×0.016戸/m²（階数2.25で、全区画を建てた時の実測0.014〜0.018）×0.9で内側の住戸数を見積もり、必要住戸数との差を不足とする |
| `suburbs.ts` `raiseVectorRibbonLand` | 外周の残地の大きさによらず常に帯を足す。不足は、川の下流（町を出た後の川の80 m以内）に沿う帯を除いて、交通量＋1の比で配り、0.85戸/mで帯を伸ばす。バービカンの時代（盛期中世以降）は伸ばす帯に90 mを足す。描画範囲の縁で足りない帯は2列目（幅2倍）にし、それでも足りない長さを`ribbon-extent`の診断で示す。帯は道の曲がりに沿う直線の継ぎで作る。斜堤（市壁から空きの距離）を市壁の全周で除く。都市形態のあるFMGの都市も帯を足す |
| `suburbs.ts` `wallBerm` | 市壁の線から一定距離の帯を、線分ごとの四角形で返す。稜堡のある線を太らせた面（`pathSurface`）は折れて失敗し、四角形の和集合は多角形の演算が失敗したため、和集合を取らずに差し引く側へ渡す |
| `shanty.ts` | 外周の残地の大きさによらず貧民街の土地を足す。市壁から8 mの帯を除き、門の開口（町の敷地）とつながらないようにする |
| `perimeter.ts` | 市壁の外では、住宅の建たない街区（と、その地区のすべての街区が空の時は地区の街路も）を記録しない。不足を見込んで足した帯のうち使わなかった部分が、空の街区・小路として描かれない |
| `pipeline.ts` | 稜堡の予約の直後に敷地を切り、宿・同業組合・貧民街の後で不足に応じた帯を足す |

## 4. 残り

- 2列目の並び方（§3.5、1列目は街道に正面を向けて連続、2列目は街道から分かれる小路に面する）は、旧CEの街区の区画の生成器に任せており、目視では帯の中の小路に面した区画になっている。§3.5の距離・間隔の分布での確認はW4で行う。
- 描画範囲（`frame.extentMeters`）の拡張は未実装。帯が縁に届けば2列目にし、足りない長さを`ribbon-extent`で示すまで。
- 海側を開けた市壁の町は、閉じた外の市壁が無いため入口の帯（`vectorApproachBands`）が作られず、不足分を帯へ出せない。
- 住宅の建った帯が、交通量の比ではなく区画の抽選の順で1本に集まることがある（帯の土地は比で配るが、住宅は抽選の順で埋まる）。
- 補正の作り直し（未収容が残った時に帯を1回作り直す）は未実装。今の観測では未収容が出ていない。
- `MESHLESS_TARGET_FILL`を0.9へ上げる作業（W1aの残り）は、上の帯の偏りを見てから行う。
