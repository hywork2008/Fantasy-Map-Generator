# Salt S2 生産の物理制約（2026-10-23）

S2の生産接続を実装した。需要だけからSaltを作る経路を、設備・共通労働・燃料・季節の範囲に制限した。次はS3の代金と賃金。生産・家計受取・輸送の価格表示は、現金の支払済みを意味しない。

## 変更と仮定

- 製塩の実作業を同市場の都市の労働予算から引き、残りを通常製造・輸送資産建造・委託へ渡す。同じ市場の複数施設も一つの予算を共有する。基本産業への既存雇用を先に除く。
- 農村セルに立地しても同市場の都市の作業班を雇う。農村の月別農業・紡織・移住配分を重複利用せず、作業班を確保できなければ生産しない。農村住民の直接雇用はこの版では行わない。
- 煮詰めはWood在庫と作業量の小さい方で制限し、実消費だけを一度引き落とし、WoodのrecipeInputへ記録する。天日・岩塩採掘には煮詰め燃料を課さない。
- 天日は地域の月平均気温と降水から設備年能力を月別配分する。冬季停止を無料の煮詰めで代替しない。年内に天日の適期が一度もない沿岸施設は煮詰め法を使う。
- 内陸は既存の蒸発岩地質だけを候補にし、地下水圧で塩泉と岩塩坑を区別する。標高だけでは産地にしない。硫黄や硝石を食塩として消費しない。
- 旧保存の既存施設能力・貨物・在庫を維持する。施設未保有国に内陸候補があれば年900 bag以下の1施設を追加し、次月以降は重複させない。今回の2入力では施設数は変わらなかった。

係数、気候近似、単位換算の詳細は[仕様](../simulation/salt-logistics.md#s2-生産の物理制約2026-10-23)。煮詰めの82人時/34.5 kgと木60 kg/34.5 kgは、[Dardenizの研究](https://www.cambridge.org/core/journals/european-journal-of-archaeology/article/model-of-salt-production-and-consumption-patterns-in-bronze-age-anatolia/B0A2D8BFF1947DC1566724CC8AF5101A)が紹介するTencariuらの実験を参照した暫定設定で、中世一般の標準ではない。天日0.1人時/kg、採掘0.5人時/kg、160時間/作業者月、気候式の係数は明示的な未校正の仮定である。

## 物量境界と残課題

市場在庫とSaltShipment輸送中在庫を境界とした「期末−期首−source＋sink」の照合残は、Province **−0.145 kg**（S1 −0.102）、World **+307.806 kg**（S1 +341.662）。一般貨物の別境界・丸めを含む未説明分を残し、補正供給でゼロにしない。Worldの期末在庫＋Salt輸送中は約2,308,267 kgであり、世界在庫があることと各地の家計充足は別である。

市場備蓄は3か月分のままで、天日停止期間を越える備蓄計画は追加していない。自国施設保有国は自国へ発注する既存規則を維持し、能力不足時の外国への自動切替契約も追加していない。S3では既存の配送・受取を誰が支払うかを先に接続し、賃金・燃料費・卸代金・家計代金の保存を検証する。生産性・塩水濃度・気候・自然摂取の校正、農村直接雇用の拡張、未説明の物量残差は引き続き明記する。
