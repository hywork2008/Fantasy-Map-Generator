### 2.2 生産の診断（シード2103、3か月）

| --- | --- | ---: |
| 計画 | `nonPositiveRecipeYield` + `noPreparationAction` | 681 |
| 計画 | `ranking` | 67 |

| 計画 | `materials` + `recipeUnavailable` | 7 |

- 0〜4℃の市場では、3か月でガラスを1度も作らなかった。4〜8℃の市場では、47回の作業で計3.7荷を作った。
- ガラスの砂を加えても、ほぼ同じだった。加えない時の`nonPositiveRecipeYield`は618回。
- `nonPositiveRecipeYield`は、材料のどれかが市場に無く、しかも作る量がごく小さい時に出る。
  - 小さすぎて「材料が足りない」の判定（0.001荷）を通るが、作れる量は0になる。
  - 炭酸カリウムを先に作る計画も立たない（`noPreparationAction`）。

### 2.3 作る量が小さい理由

ガラスは、町のガラス職人の仕事として数えている。

- 1荷（465 kg）に27人月（`laborPointsPerLotAtDefaultRate` 0.027）。1人月に約17 kg。
- ガラス職人の数は、町の人口1,000人に陶工2人とガラス職人0.3人（`occupationalCalibration`の`pottery`・`glazing`）。ガラスに使えるのは、その1/4（`inlandShare` 0.25）。
  - 職人の表の出典の欄には、「ガラス職人。ガラスそのものは森のガラス小屋から来た」とある。
- 平均1,420人の町では、ガラスに使える人手は月0.8人月。作れるのは月約0.03荷（14 kg）になる。
- 寒い市場の町は小さい。どの町も、ガラスを1度に作る量がごく小さくなる。

### 2.4 ガラス小屋の史料

史料のまとめは[forest-glasshouses.md](../plan/forest-glasshouses.md) §2。

- ドイツの森のガラス小屋（Waldglas）は、1 kgのガラスに積んだ木材約1 m³を使った。小屋は年2,000〜3,000 m³の木材を使い、森20〜30 haにあたる（[Waldglas](https://de.wikipedia.org/wiki/Waldglas)）。
  - 木材の大部分は、炭酸カリウムの灰にするためのものである。
- 1763年のリーゼンゲビルゲ（[Die Glasgewinnung im Riesengebirge](https://jbc.jelenia-gora.pl/Content/41097/45559_Glas_Worbs_Goerlitz.pdf)）:
  - 小屋の働き手は計38人。ガラス職人10人、火夫3人、少年8人、木こり15人、荷造り2人。
  - 炉を焚いたのは年24週。
- シュヴァルツヴァルトのブールバッハ（19世紀、[Waldglashütten](https://www.waldglas.com/)の引用）: 120人が働き、年に約20,000ツェントナー（約1,000 t）のガラスを作った。
- シュピーゲルベルクの小屋は、年に最大800ツェントナー（約40 t）の炭酸カリウムを使った（同）。
- 中世のイングランドのガラスは、ウィールドなどの家族の小さな森のガラス小屋で作った（[Early modern glass in England](https://en.wikipedia.org/wiki/Early_modern_glass_in_England)）。

## 4. 森のガラス小屋の計測

### 4.1 条件

- 地図はシード2102・2103、12か月。襲撃なし、平和。粘土とガラスの砂を寒い土地に加えた（`add`）。
- 凍結した作業ツリーは2つで、どちらもe8cc16fb5に森のガラス小屋の変更を足したもの。
  - base: `simulation.ts`から小屋の毎月の仕事（`settleForestGlasshouses`）の呼び出しを外した。小屋の上限が0のままなので、町はこれまでどおりガラスを作る。
  - new: 変更のすべて。
- 実行: [run.sh](glass-houses-20261107/run.sh)。計測スクリプトは[clayflow.mts](cold-clay-20261107/clayflow.mts)。
- 比較: [compare.py](cold-clay-20261107/compare.py) `--modes base,new --goods "Glass,White sand,Potash,Wood"`。出力は[summary.txt](glass-houses-20261107/summary.txt)。

- 地元のガラスは、2102で136 → 374荷、2103で47 → 246荷になった。
- 国の船の持ち帰りは、2102で229 → 169荷、2103で384 → 245荷に減った。
- 2102では、贅沢品のガラスの買い物が78 → 197荷に増えた。2103はほぼ変わらず、持ち帰りの代わりに地元のガラスを買った。

- ガラスの砂をレシピに使う量は、2102で131 → 374荷になった。12か月目の在庫は減ったが、尽きていない。
- 町がガラスを作らなくなり、炭酸カリウムをレシピに使う量は2102で129 → 81樽に減った。
- 市場の木材の流れは、ほぼ変わらない。小屋の木材は森の上で切って使うため、市場の流れに入らない。作ったガラスからは、1年に2102で約1.2万、2103で約8千単位である。
