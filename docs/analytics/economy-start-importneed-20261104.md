# 醸造の穀物を輸入の判断と輸出から外した後の観測（2026-11-04）

設計書: [urban-craft-staffing.md](../plan/urban-craft-staffing.md) §10.9（未決事項14）。前の段階は [economy-start-brewgrain-20261104.md](economy-start-brewgrain-20261104.md)。

- 入力: 前の段階と同じseed 2101〜2104・同じ設定で、地図を生成し直した。
- 平和モード、60か月。手順は前の段階と同じ（`raw/economy-start-importneed-20261104/run.sh`）。2101だけ`migrationprobe.mts`も24か月走らせた。

## 1. 変えたこと

- **輸入の判断。** 市場の食料の輸入が要る量（`importNeed`）を、在庫の合計ではなく、醸造がこれから6か月で引く分（`min(出してよい分, 醸造の穀物6か月分)`、`brewingReserve`）を除いた在庫で計る（`foodProduction.ts`）。
- **輸出。** 他の市場へ食料を売れる量を、出してよい分から自分の`brewingReserve`を引いた残りにした（`foodImportNetwork.ts`）。

輸入の判断だけを直した版（途中の版、`raw/economy-start-importneed-20261104/halfway/`、`comparison-halfway.json`）では、ビールが崩れた。

- 地図を作った時の市場の在庫には食べる分しか入っていない。醸造の6か月分を除くと、ほぼすべての市場が食べる在庫の不足になり、輸入を求めた。
- seed 2103の1か月目に、市場1〜9が市場10〜27の出してよい分を合わせて64,074輸入し、全市場の出してよい分が合計82になった。どこにも醸造の穀物が無くなり、1か月目のビールは14,509 → 954トンになった（2104は13,646 → 3,091トン、2101の60か月目は7,829 → 3,439トン）。
- 輸出の側も直すと、同じ1か月目の輸入は0で、出してよい分は11,261残った（`economy-start-brewgrain-20261104/importprobe.mts`）。

## 4. 分かったこと

- 都市人口は2101・2102で+1.3%・+0.3%、2103・2104で−0.3%・−0.4%。差はどれも1.5%以内で、醸造の穀物を市場の買い付けに含める前（§10.7の版）の2101の667,326人を上回った。
- ビールは2101・2102・2104で増え、2103は60か月目でほぼ同じ。序盤（1か月目）は4枚とも増えた（2103は14,509 → 21,616トン）。
- 2103・2104の後半のビールが月3,000〜5,000トンでエールの需要に届かないこと（未決事項15）は変わらない。
