# メッシュなしCE 施設が区画を切った残りの扱い（U3、§2.9の順序の3の前段）

2026-11-13。[受入前の改善](../plan/ce-meshless-pre-acceptance-improvements.md)。§2.9の順序の3（施設を区画に合わせる）のうち、BVのモデルを変えずにできる配置側の変更。

## 計画区画の内訳（合成3,000人・施設あり、狙いの埋まり1.0、変更前）

市壁内の計画区画29,317 m²のうち、建った区画13,994 m²、施設に切られて建たなかった区画15,810 m²（施設の外形10,443 m²を含む）、その他の当てはめ失敗321 m²。施設が切った区画の、長方形の住宅にならない残り約5,400 m²（街区の土地の約9%）が空き地になっていた。施設ありの空き地15〜19%の約半分である。

## 変更（`facilityLots.ts`、`perimeter.ts`）

1. **長方形の住宅にならない残りは施設の敷地に入れる**。施設の外形と、施設が切った区画のうち長方形の住宅（`restRectangle`、§2.9の応急処置と同じ判定）にならない残りを合わせて敷地にする。敷地が1つの形にならない時、他の敷地や守る土地にかかる時、扉が敷地の外になる時は外形だけ。空き地の帯が施設の脇の庭になる。
2. **種の区画を3つまで比べる**。施設が置ける種の区画を最大3つ試し、無駄（長方形の住宅にならない残り）が最も少ないものを採る。無駄が5 m²未満ならすぐ決める。
3. **市壁の大きさの見積りの施設の土地**（`suburbs.ts`の`FACILITY_PARCEL_FACTOR`）を1.2→1.6。施設の庭の分を含めた実測で、市壁内の人口は1.2で80〜99%、1.4で88〜100%、1.6で97〜100%。
4. 回帰の確認（`facilityLots.test.ts`）: 施設の敷地は外形を超える庭が外形の35%未満（区画を丸ごと取っていた時は60〜70%）。

市壁内の人口は全件97〜100%になった。施設ありの空き地は10〜18%で、施設なし（8〜17%）とほぼ同じ。建物の被覆率は市壁が少し大きくなった分だけ下がった町がある。施設の外形と区画の大きさが合わないことによる損失（施設の庭3〜5%）は、BVのモデルを区画の幅に合わせる作業（§2.9の順序の3の本体）で無くす。

生成時間は施設ありで3〜28秒（種の比較で最大2倍）。gothengsfeldの約28秒はなめし場の河岸の予約による（別件）。
