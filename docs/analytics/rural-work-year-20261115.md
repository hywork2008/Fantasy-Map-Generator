設計：[rural-work-year.md](../plan/rural-work-year.md)。前の記録：[hay-residual-20261115.md](hay-residual-20261115.md)、[hay-catchup-20261115.md](hay-catchup-20261115.md) §3。

- 地図2102・2103、36か月、戦争なし・隊商の略奪なし、既定の設定（`ruralWorkYear` offField、365日、家事160日）。HEAD 024c80ac9に今回の変更。
- 記録は[workyear.mts](rural-work-year-20261115/workyear.mts)（urbanhelp.mtsに家の織物・家畜の働き手、農村・町の人口を足したもの）。[run-36.sh](rural-work-year-20261115/run-36.sh)、[run-legacy.sh](rural-work-year-20261115/run-legacy.sh)、[run-residual.sh](rural-work-year-20261115/run-residual.sh)。
- 記録のスクリプトは、設定を地図の準備（prepare）の後に入れる。1か月目の割り当ては、どの計測でも既定の設定で行われる。

（餌の足りない量の割合・1%より多く足りない土地の数。前は[hay-catchup-20261115.md](hay-catchup-20261115.md) §3のaftermath）

2102が見込み（0.1%未満）から外れたので、[residual.mts](hay-residual-20261115/residual.mts)（家の織物の働き手を足した）で27か月を数えた（first/residual-2102.json）。

1. 15か月目に足りない48の土地のうち、前の70の土地と重なるのは8だけだった。家の織物の働き手は0で、織物が畑の外の日数を取ったのではない。
2. 刈り足しの日数は、7月の刈り残しが全て8月に入っていた（0.26百万日）。8月は人手（172百万kg分）が刈れる草（95）を上回り、草が先に尽きた。草の残る9月（刈れる草75、刈った49）と10月（39、0）には回っていなかった。
3. 原因は、刈り足し（`carryHayShortfall`）が草を見ずに、後の月の空いた手を早い月から詰めていたことである。

## 2. 直した版（月ごとの刈れる余りの伸びで止め、残りを次の月へ）

刈り足しの日数を、その月の伸び − 今の頭数の放牧 − 計画の干し草（3日/t）までとした。飼料面積の記録の無い土地では止めない。比べる先は同じコードの`ruralWorkYear` legacy（刈り足しの直しは両方に入る）。

1. 3〜4月の餌の不足は、両方の地図でほぼ0になった。見込み（2102の4月で0.05%以下）どおり。
2. 家の織物の働き手は、legacyでも36か月で大きく増える（2102で18.1万→31.5万、2103で10.1万→15.1万）。offFieldでの増えはその約1%で、作った布（毛織物・亜麻布・衣類）は±0.4%以内。織物が大きく増えないという見込みどおり。
3. 家畜の働き手は+0.6〜1.0%、農村・町の人口は同じ（差は0.01%未満）。
4. 3年の町の工房の作った品は−0.27%（2103）・−0.28%（2102）。持ち手のお金の差（36か月目）は1.6%以内で、大きいのはギルドの−1.51%・−1.45%。理由は数えていない。
