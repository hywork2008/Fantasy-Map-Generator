# 牧畜の月別作業配分と越冬給与（2026-10-24）

## 修正した制約

[前回の残渣給与検証](winter-slaughter-crop-residues-20261024.md)では、麦類の実収穫由来の残渣があっても自然入力の利用は0だった。牧畜管理・採草・食肉準備・残渣作業を一つの年間候補へまとめ、最も余力の少ない月の倍率を全月へ適用していたためである。

農村職業配分の牧畜候補について、各月の要求人日と、その月に住民へ残された人日の小さい方を予約するよう変更した。穀物作業と先に配分された職業を差し引き、他月・他セルの余力を借りない。予約を月別の現在作業量と最低維持作業量へ一度ずつ加え、移住余力・農繁期不足の計算へ渡す。`husbandryWorkers`は予約した年間人日の合計/140という年平均換算値であり、新しく生成した人口ではない。

牧畜以外の候補の年間倍率、穀物の優先、既存の農繁期延長作業日、相互扶助の契約は変更していない。牧畜へ予約した余力は後続の仕事や他セルへの応援へ再使用できない。作業不足のある月は不足のまま残す。

## 実行側の接続

- 通常管理を先に確保し、残る月枠の中で採草・残渣・食肉準備を決済する既存の順序を維持する。
- 採草は当月の計画要求と実予約残量で制限する。年平均人数を再び掛け、利用可能な繁忙月の枠を縮小しない。
- 乳・羊毛・放牧家畜の出荷は、その期間の実管理作業/管理要求を読む。年間平均の人数が正でも、当期の管理予約0なら生産倍率は0。
- 土地・群れの年次計画は従来の年間換算倍率を保持する。単一の不足月を年間の維持土地へ直接掛けない。
- 屠畜の取扱量は当期予約人日を標準作業月へ換算して制限する。保管容量は従来の年間換算人数に基づく上限と世帯人口上限を維持し、繁忙月の作業日だけで設備を増やさない。
- 月別台帳が無い旧年次配分や、労働者の直接編集で台帳を失効した場合は、明示した従来のfallbackを維持する。月別配列の保存形式は変更していない。

## 判断と次の作業

自然入力で残渣利用0となっていた月別配分の問題を修正し、同じ入力で実回収と給与が稼働することを確認した。月別余力の利用によって採草・食肉・交易も変わるが、1入力・12か月の結果を歴史的な給与率や長期収束の証明にはしない。試験係数と既定offは維持する。

**次は、維持耕地内の播種中/刈跡/輪作休閑の排他的な区分と輪作位相を土地台帳へ接続する。** 既存牧草地との二重面積、播種中の作物への放牧、他用途留保の飼料への再使用を防ぐ。休閑草の供給は実区画・季節成長・当期労働を確定してから加える。敷料/燃料との実需要配分、史料校正、長期のE1収束は引き続き残る。
