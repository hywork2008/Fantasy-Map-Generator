## 座板・支持材の突出修正（2026-11-01）

ユーザーの指摘により、小舟2種の座板と支持材が外板を貫通していたことを確認した。座板の幅を船縁の幅から決めており、取り付け高さで狭くなる船内断面と、板の前後方向の厚みを考慮できていなかった。従来の寸法・開口テストでは、この突出を検出できていなかった。

座板下面の高さと前後両端で船体内面を補間し、狭い方に合わせて板を短くした。支持材は座板の下へ配置し、下端もその高さの船体内面に合わせた。実際の船板と座板・支持材には部材識別を付け、統合後の船板形状に対するレイ検証で、全座板・支持材の全頂点が内面より内側にあることを両船で確認する回帰テストを追加した。

- `npx vitest run src/buildings/medieval/boatAndPublicGranaryDetails.test.ts`：9件成功。
- `npx tsc --noEmit`、変更ソースのBiomeチェック、`git diff --check`：成功。
- 実BVで両船の外観を再確認し、通常視点・上方視点の画像4枚を更新した。巡回中のJavaScriptエラーは0件。

## 座板と船体の接合修正（2026-11-01）

前回の突出対策は内側へ短くすることに偏り、座板と支持材が船体に接しない状態になっていた。今回、座板の左右端を船内曲面に沿わせた形状へ変更した。座板下の左右に、同じく曲面に沿う受け材を設け、船板の厚み内へ約8 mm入れて接合した。座板下面は受け材上面へ5 mm重ね、隙間なく載る形とした。受け材には木栓も追加した。

突出の回帰テストは船板の外面を越えないことを検証するよう更新した。さらに独立した接合テストを両船へ追加し、3枚の座板それぞれの左右・前後2点について、座板と受け材の外端が船板の内外面の間に入っていること、座板下に受け材の上面が存在することを実際のメッシュへのレイで検証する。前回のように短くして離すだけでは、この接合テストが失敗する。

- `npx vitest run src/buildings/medieval/boatAndPublicGranaryDetails.test.ts`：11件成功。
- `npx tsc --noEmit`、Biome、`git diff --check`：成功。
- BVで漁船・手漕ぎ舟の座板と船体の接続を上方から再確認し、画像4枚を更新。巡回中のJavaScriptエラーは0件。
