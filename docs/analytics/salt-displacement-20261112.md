# 替えた塩は塩田・塩坑の売りを減らすか（2026-11-12）

[salt-price-20261112.md](salt-price-20261112.md) §4の3を確かめた。皮と獣脂の輸出（[byproduct-export.md](../plan/byproduct-export.md)）を入れた時（staple）と入れない時（off）で、塩田・塩坑の卸と塩の出入りを比べた。

## 1. 条件

- 地図2102（北緯30°）、24か月、戦争なし・隊商の略奪なし。2年目（13〜24か月）を集計した。
- コード: 7826dddf5に[byproduct-export.md](../plan/byproduct-export.md)までの実装（入れる品は`STAPLE_RETURN_GOODS`）を加えたもの。offは始めに`byproductExport`を`off`にしたもの。
- 測りは[salt.mts](salt-displacement-20261112/salt.mts)（[salt-price-20261112](salt-price-20261112/salt.mts)の測りに、塩田・塩坑の卸の代金`monthlyWholesaleReceived`と国庫を加えた）、実行は[run.sh](salt-displacement-20261112/run.sh)。
- 塩の税は家が買う時にかかり（`buyHouseholdSalt`）、塩の出どころによらない。

## 3. 読み取り

1. 替えて入った塩（96万）のうち、約2割（約20万）は足りなかった家畜と家の塩を埋め、約5割（約49万）は塩田・塩坑の卸に取って代わり、残り（約29万）は市場の在庫に積み上がった。
2. 塩田・塩坑の卸の代金は約2割減った。国庫の差は小さい（−0.6%）。
3. 史料でも、湾の塩は北の国々の塩と競った。ただし、皮と獣脂の輸出の見返りに選ぶ品が、地図の中で作る品の売りを2割奪うのは大きすぎる。

## 4. 次の直し（案）

1. 入れる品は、その市場で在庫の月数が最も少ない品（足りない品）から選ぶ。月数は、皮と獣脂と同じく、市場ごとの月の使い道の均した値（`byproductUse`と同じ形）で測る。
2. 地図の中で作れる品（塩・ワイン）は、在庫が使い道の目安（例えば3か月分）に届いたら選ばない。

## 6. 足りない品から選ぶ決まりの後（short）

§4の1を実装した（[byproduct-export.md](../plan/byproduct-export.md) §7.2、`byproductReturnMonths`=3）。港の市場は、5つの持ち帰る品のそれぞれを、自分の使い道の3か月分に足りない分だけ、月数の少ない品から入れ、出す皮と獣脂もその値までとした。同じ条件で回した（[run-short.sh](salt-displacement-20261112/run-short.sh)、塩は24か月、品は[goods.mts](byproduct-export-20261112/goods.mts)で36か月）。

| 2年目 | off | staple | short |
| --- | ---: | ---: | ---: |
| 塩田・塩坑の卸の代金 | 20.7万 | 16.3万 | 14.9万 |
| 塩田・塩坑から入った塩 | 236万 | 187万 | 161万 |
| 替えて入った塩 | 0 | 96万 | 116万 |
| 家畜と家の塩 | 236万 | 256万 | 253万 |
| 国庫の合計 24か月目 | 146.1万 | 145.1万 | 144.9万 |

- 塩田・塩坑の卸は、offより約28%減り、直す前（staple）より悪くなった。
- 塩の在庫は、塩の値付けと塩田の送りの目安（`SALT_MARKET_RESERVE_MONTHS`）で、いつも使い道の約1〜3か月分に保たれる。そのため塩は、どの月も「3か月分に足りない」品になり、入る品のほとんどが塩のままだった（3年目に約120万）。
- 獣脂は3年目に25万樽出したが、在庫は17万で横ばいになった（直す前は減っていた）。出す量が、入れる品の値で抑えられたためである。

在庫の月数は、塩のように在庫を少なく保つ品では、足りないことの目印にならない。

## 7. 地図で作れない品だけを持ち帰る決まりの後（nomap）

持ち帰る品を、その市場に地図の中から届く量（市場の入りの均した値）が使い道の5%未満の品に限った（[byproduct-export.md](../plan/byproduct-export.md) §7.3）。届かない品は使い道が見えないため、使い道は、見えた量とその市場の需要（家の月の需要と町の品ごとの月の需要）の大きい方とした。同じ条件で回した（[run-nomap.sh](salt-displacement-20261112/run-nomap.sh)）。

- 見返りの品が少ないため、出せる獣脂は年約6万樽に減り、獣脂の在庫はまた年約18万樽増える。
- 毛織物・香辛料・絹は、町の需要が量として小さい（香辛料・絹は贅沢の値の需要で、量の需要が無い）ため、ほとんど入らない。
- お金の持ち手ごとの額は、どの決まりでも差が1%以内だった。

## 8. 贅沢の予算を見返りの需要に入れた後（luxury）

持ち帰る品の需要に、市場の町の贅沢の予算のうちその品に回る月の分（`luxuryStockTarget` ÷ `LUXURY_STOCK_CYCLES`、[luxuryDemand.ts](../../src/extensions/economy/generators/luxuryDemand.ts)）を足した（[byproduct-export.md](../plan/byproduct-export.md) §7.4、[run-luxury.sh](salt-displacement-20261112/run-luxury.sh)）。

| 3年目 | nomap | luxury |
| --- | ---: | ---: |
| 外へ出した獣脂（樽） | 6.4万 | 6.7万 |
| 外へ出した革 | 4.8万 | 5.4万 |
| 入った絹 | 823 | 1,127 |
| 入った香辛料・毛織物 | 23 | 16 |
| 獣脂の在庫 36か月目 | 50万 | 49万 |
| 塩田・塩坑の卸の代金（2年目） | 20.6万 | 20.6万 |

- 効きはわずかだった。贅沢の予算は、獣脂の量に比べて小さい（絹1,127の値は、獣脂の下限の値段で約3千樽分）。
- 香辛料と毛織物は、地図の中から届く市場が多く（香辛料の在庫は地図に約900）、見返りにならない。
- 物と物を替える限り、見返りの品の需要が、出せる獣脂の上限になる。地図で作れない品の需要は、積み上がる獣脂（年約18万樽）を替えるには足りない。
