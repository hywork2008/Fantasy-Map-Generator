## 1. 変更

| 箇所 | 内容 |
| --- | --- |
| `tanneryWaterWorks.ts`（新規） | なめし場の配置から、給水・排水の水路と護岸を求める。水路は、モデルの口（`DEDICATED_TANNERY.waterPorts`）から背面に垂直に水面まで伸ばし、0.4 m先まで入れる（幅0.6 m、最大8 m）。護岸は、予約した敷地から建物の足跡を除いた部分 |
| `renderData.ts` | なめし場ごとに護岸（`#a39883`）と水路（`#5f97b0`）の面を加える。2D（SVG）と3D（地表に貼る面）の両方に出る。選ぶとなめし場が選ばれる |
| `facilityLots.ts` 小路 | 120°より鋭く折り返す小路を作らない。格子探索では、セルどうしの間を1 mおきに調べる（細い市壁や流れの見落とし）。予約地から3 m（工房からは1.6 m）離す。調べた点を0.5 m格子でキャッシュする |

T2の後に2Dで見ると、小路が列の上流の端から入り、列に沿って鋭く折り返していた。原因は2つあった。下流の端から市壁を回り込む経路が、格子のセルの間で細い市壁を見落としていたこと。もう1つは、1軒だけの短い小路に、残りの列が先端から逆向きにつながったこと。直した後は、門の外の街道から市壁を回り込み、列の下流の端へ入って前面に沿う1本の小路になった。

## 4. CE画面での確認（3D）

- 手順: 開発サーバー（localhost:5173）のCEで「Meshless」に切り替える。River 1を `through`、Building generationを `medieval-facilities`、市壁あり、Wall shapeを `polygon`、seedを `fixture`、人口5,000にして「Generate city」を押す。生成は約4秒。
- 結果:
  - 市壁の外の川下の北岸に、なめし場14軒が隙間なく1列に並ぶ。
  - 小路は門の外の街道から市壁を回って列の下流の端へ入り、前面に沿う。
  - 近くで見ると、どの工房も作業小屋が陸側、モデル内の給水・排水の溝が川側にある。溝は護岸を渡って水面に届いている。
  - 反転した工房も含めて、溝の並びが列の中でそろっている。
- 気づいた点: 同じモデルが14軒続くため単調に見える。設計書 §9 の未決事項（工房ごとの小物の揺らぎ）のとおり、BVの見た目の種で扱う。
