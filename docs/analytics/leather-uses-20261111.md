## 4. 読み取り

1. 革の在庫の増えは、年約290万から約160万（2102）に減ったが、まだ積み上がる。減った分のほぼ全部が夏の傷み（作った量の約半分）で、使い道の増えは作った量の約3%（2%から5%）にとどまる。
2. 長靴は見込みの需要の約5%しか作られていない。足りないのは靴屋の人数（町の人1,000人に10〜20人、`occupationalCalibration`）と長靴の手間（1人月に約1足）で、需要を増やしても作る量が上限に当たる。§4.4の釣り合いの見込みは、靴屋が足りる前提だった。
3. 作れない需要が残るので、長靴と革の品の値段は上がった（0.7 → 1.5〜1.7）。革も、在庫が増えているのに値段が上がった（1.7〜2.0 → 2.6〜2.9）。値段が需要と在庫で釣り合わない問題（household-goods-pay §5の1）が、そのまま残る。
4. 町の家計の減りは、長靴と革の品を払う分と見られる（未確認）。

## 5. 次に調べること・直す候補

1. 靴屋の上限と長靴の手間。中世の靴屋は町の人の何人に1人か、1人が月に何足作ったかの史料を集め、上限を見直す。農村の履物は、家で作る（木靴・自家製の革）割合も考える。
2. 革の値段が在庫で下がらない理由（元値の付け方）。
3. 夏の傷みの割合（今は作った量の約半分を捨てる）。上の1が直れば、0.1は大きすぎる見込み。
