# 動物性の蛋白の上限を入れた計測（2026-11-17）

[dairy-demand.md](../plan/dairy-demand.md) §3.3。`animalProteinCapGramsPerDay`（既定30 g/日、仮値）と、主食が足りない時にチーズの値段で需要を減らさない決まりを入れた。比べる相手は [dairy-cost-20261117.md](dairy-cost-20261117.md)。

## 1. 条件

- 地図2103、36か月、戦争なし・略奪なし、既定。[run.sh](dairy-cap-20261117/run.sh)。3年目、1人・年。
- 蛋白: 肉150 g/kg（仮値）、チーズ250 g/kg、牛乳33 g/L（`nutritionAudit.ts`）。

## 2. 結果

| | 上限なし（前の計測） | 上限30 g/日 |
| --- | ---: | ---: |
| 食べた肉 | 21.9 kg | 21.9 kg |
| 食べたチーズ | 7.26 kg | 7.26 kg |
| 飲んだ牛乳 | 4.04 L | 4.04 L |
| 動物性の蛋白 | 約14 g/日 | 約14 g/日 |
| チーズの値段（中央値 / 最小〜最大） | 30.5 / 4.1〜38.1 | 30.5 / 4.1〜38.1 |

- 帳簿の値・値段・家計の収入・GDP は一致した。

## 3. 読み取り

1. 上限は効いていない。動物性の蛋白（肉3.3 kg・チーズ1.8 kg・牛乳0.1 kg、年5.2 kg）は上限（年11 kg）の約半分。
2. 上限は、チーズや肉の値段が下がって需要が膨らむ時の歯止めとして働く。今の家畜の数では、ふだんは効かない。
3. この地図の3年間で、主食が足りない四半期は無く、チーズの需要を値段で減らさない決まりも働いていない。
