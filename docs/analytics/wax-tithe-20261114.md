# 余った蜜蝋を教会に納める（計測）

設計：[wax-tithe.md](../plan/wax-tithe.md)

## 1. 条件

- 地図2102・2103（北緯30°）、36か月、戦争なし・隊商の略奪なし、既定の設定（`waxSurplus` tithe、12か月分を持ち、超えた分の10%を毎月納める）。
- 比べる先は [wax-pricing-20261114.md](wax-pricing-20261114.md) の stockAndDemand の出力（蝋の地代の無い同じコード）。
- スクリプトは [goods.mts](wax-tithe-20261114/goods.mts)、[run.sh](wax-tithe-20261114/run.sh)、[compare.py](wax-tithe-20261114/compare.py)。

## 3. 読み取り

1. 納めるのは在庫が使い道の12か月分を超えた市場だけで、36か月では2102の一部の市場が超え始めたところだった。蝋燭の材料・値段は変わらず、蝋燭屋の材料を取らないことを確かめた。
2. 2102の3年目の在庫の増えは約27%減った。納める量は超えた分に比例するので、市場の在庫は使い道の1年分あたりで頭打ちになる（超えた分の10%が月の余り（2102で年約1,300個 ÷ 超えた市場）と釣り合う所）。
3. 2103は在庫が12か月分に届く市場が無く、効きは出ていない。
4. 港の積み出しが少し減ったのは、納めた分だけ港の余りが減ったため。
