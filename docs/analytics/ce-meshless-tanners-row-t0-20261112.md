## 2. 指標

- **要求**: `buildPopulationFacilityRequests` が出すなめし場の数（職人2.5人で1軒）。
- **岸の最前列**: 給水口・排水口が両方とも水際から3.5 m以内にある工房。敷地と水の最短距離は最小で3.05 mで、岸の後退距離より水に近づけない。そのため、ここを最前列の基準にした。
- **背面が水**: 背面（給水・排水口の中点）の向きと、敷地の中心から最寄りの川の点への向きのなす角が45°以内。
- **流れ正**: 排水口が給水口より下流にある。
- **町の下流**: 敷地が、川の上で町の中心より下流にある。
- **群**: 敷地の中心どうしが22 m以内のものをつないだ数。工房が全部ばらばらなら工房数と等しくなる。

## 4. 分かったこと

1. **見た目以前に、なめし場の大半が置けていない。** 未配置の理由はほぼすべて `"river"` で、水から80 m以内に郊外のロットがない。市壁のある合成の町とarchiaguでは0軒だった。
   - 合成の町の市壁ありの場合、街道の帯は川から116〜289 m離れている。市壁の外の街区で水に最も近いものでも89 mある。
   - archiaguでは帯と川の距離が164〜631 m、市壁の外の街区は110 m。
   - `suburbs.ts` の川下の帯（`downstreamOf`、川から80 m以内）に当たる街道がなく、帯が伸びない。
2. **川に沿う街道があっても、工房は河岸に並ばない。** gothengsfeldには川から1 mを通る街道が2本ある。それでも配置は2軒で、どちらも水から35〜46 m離れている。
3. **背面の向きはロットの前面の線しか見ていない。** 合成の町の最前列17軒は、すべて背面が水に向いていない（側面を川に向けている）。myosiasosだけは、川と平行な道に面する列で背面が水に向いた。
4. **町の下流の判定が実質効いていない。** 配置の半数は町の上流にある。
5. **要求数は人口の約4.4/1,000で一定**（5,000人で22軒、20,000人で88軒）。史料の小さな町の5人程度、都市の工房十数軒と比べると多い。§7の「入りきらない分」の量を決めるので、T2の前に確かめる。
6. **どの町でも、なめし場の要求のうち1軒が `"district"` で未配置になる。** 原因は未調査。

## 5. 計画への反映

- **T2**: 配置の起点を、郊外のロット（街道の帯）から、町の下流の岸線そのものへ移す。岸に沿う街道や帯が無ければ、なめし職人の通りを岸と平行に作る。帯の80 m判定に頼らない。
- **T1**: 着手できる。岸線は、FMGの川（gothengsfeld、myosiasos）でも合成の川でもサンプリングでき、どちらも点の順序が流れの向きである。
- **要求数の検証（T1a、新規）**: `medievalTradeDemand` のなめし業の職人数と、2.5人で1軒の換算を史料と照らす。結果によっては1軒あたりの職人数を増やす（パン焼き5人、醸造6人と同じ扱い）。
- **別の不具合**: 生成が失敗する4件と、毎回1軒出る `"district"` は、なめし場とは別に記録しておく。
