# 都市と農村の世帯のお金の流れ（2026-10-29）

[unsold-harvest-household-store.md](../plan/unsold-harvest-household-store.md) §4の調べ。市場9・10などで都市の世帯の財布が尽きる原因を、「輸出の強い市場にお金が集まり、弱い市場の手持ちが尽きる」という仮説（利用者）で確かめた。

固定入力 `docs/analytics/inputs/wet-pastoral-birth-20261029/world-102.fmg` を、f3241c832に計測用の観測フック（`setHouseholdWealthFlowObserver`・`setRuralHouseholdWealthFlowObserver`、通常の実行では何もしない）を加えたコードで84か月進めた。都市（町ごと）と農村（市場ごと）の世帯の財布への入金と出金を、払った処理（モジュール・関数）ごとに市場・年で合計した（`scripts/auditUrbanMoneyFlows.mts`）。

    NODE_OPTIONS=--max-old-space-size=6144 node --import tsx scripts/auditUrbanMoneyFlows.mts docs/analytics/inputs/wet-pastoral-birth-20261029/world-102.fmg <output.json> 84

都市の財布が減る市場（9・10・1・2・11、都市の人14.2万）と、増える市場（6・5・4・21、12.6万）を比べた。値は1305年の12か月、都市の人1,000人あたり。

- **仮説はおおむね当たっている。** 増える市場の農村は、飼い葉・干し草と燃料を売って外からお金を得る。減る市場の農村は、売れる余りが少なく（飼い葉の売りは228→64に減った）、塩と飼い葉を買う支払いが続く。外へ出たお金が戻らないので、農村が町で使えるお金が細り、都市の財布が尽きる。
- 増える市場は、塩の支払いが−426→−37に減った。塩を自分で賄えるようになったか、在庫を持ったためとみられる（未確認）。
- 「輸出の強いところは他から買う必要が無い」も、塩の支払いの減りに表れている。ただし、増える市場の農村も飼い葉を買っている（−166）ので、何も買わないわけではない。
- 隊商による商人の取引（商人の資本）は、世帯の財布の外にあり、今回は見ていない。

## 追記: 減る市場の産物は売れているか（候補1）

市場ごとに、各財の記録された流れ（生産・輸出・町での消費・腐敗など）を、量とその時の市場の価格で集計した（`scripts/auditMarketProductSales.mts`、同じ固定入力・f3241c832、84か月）。値は1305年の12か月の金額、都市の人1,000人あたり。

| 牧畜の産物 | 減る市場 | 増える市場 |
| --- | ---: | ---: |
| 牛の出荷（→加工の材料） | 1,278 | 1,142 |
| 羊の出荷（→加工の材料） | 1,179 | 1,027 |
| チーズ（→町の食料） | 93 | 77 |
| 山羊 | 66 | 37 |
| 羊毛 | 14 | 22 |
| **輸出（全部の財）** | **ほぼ0** | **69** |
| 輸入（全部の財） | 21 | 31 |

- **減る市場の牧畜の産物は、売れている。** 1人あたりでは、増える市場より多い。家畜はその市場の中で加工の材料（肉・皮）として買われ、チーズは町で食べられる。売れ残りや腐敗は目立たない。
- **市場の間の交易は、どちらの側でも小さい。** 輸出は増える市場で69、減る市場でほぼ0。どちらも、地元で売る量（数千）の1〜2%である。
- したがって、候補1（減る市場が外に売れるものがお金に変わっていない）は当たらない。差は輸出ではなく、次の飼い葉の買い上げにある。

### 飼い葉の買い上げ

| 飼い葉（Fodder） | 減る市場 1301 | 減る市場 1305 | 増える市場 1301 | 増える市場 1305 |
| --- | ---: | ---: | ---: | ---: |
| 市場が農村から買った量（千ロット） | 99.5 | 44.4 | 72.5 | 65.5 |
| 同じ金額 | 308 | 80 | 480 | 406 |
| 家畜の餌として使われた量（千ロット） | 62.9 | 75.4 | 54.9 | 48.4 |

- `livestockFeed.ts`の`harvestLivestockForage`は、農家が自分の干し草を取った残りの草を、**市場が金庫のお金で、需要に関係なく全部買い上げる**（価格の0.8倍、金庫の残高まで）。穀物の買い上げ（`foodProduction.ts`）には「売れる分と蔵の上限まで」という制限があるが、飼い葉には無い。
- 増える市場は、毎年使う量（48千ロット）より多く（65千ロット）買い、その代金が農村に入って町で使われる。市場の金庫から農村・都市へお金を移す経路になっている。
- 減る市場（多雨地の牧畜の市場を含む）は、草の多くを自分の群れが食べるので、売る草の余りが少ない（99→44千ロット）。1ロットあたりの値も安い（増える市場の約半分）。使う量（75千ロット）が買い上げより多く、飼い葉の支払いで農村からお金が出ていく。
- 1301年の「農村が町で使うお金」の差の多くは、この需要の無い飼い葉の買い上げで説明できる。
