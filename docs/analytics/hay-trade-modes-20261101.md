## 1. 2つの方式

| | A. 市場が買う（`marketShortfall`、既定） | B. 農家どうしを先に（`farmsFirst`） |
| --- | --- | --- |
| 草刈りの時 | 市場が、農家の冬の備えの不足分（前の年の飼い葉の販売の方が多ければその量）から在庫を引いた量まで買う | 余った農家から、同じ市場の足りない農家へ直接回す。まだ足りない分を、Aと同じく市場が買う |
| お金 | 市場の金庫が値段の8割で払い、農家は飼い葉を値段で買う | 直接回す分は、どちらも同じ農村の財布なのでお金は動かない |

前のやり方（前の年に売れた量までしか買わない）は、在庫が減ると買う量も減る輪がある（前の記録§2）。そのため、選択肢には残していない。

## 3. Bで農村の財布が減る理由: 市場は干し草を高く買って安く売っている

市場に入る干し草は、ほとんど全部が農家に飼い葉として戻る（`fodderflow-A-24.json`）。

| 年 | 農家から買った（ロット） | 農家に売った | 他の市場へ |
| ---: | ---: | ---: | ---: |
| 1 | 235.6千 | 281.6千 | 0.8千 |
| 2 | 188.4千 | 235.9千 | 0 |

それでも、農村の財布の干し草の差し引きは、Aで1年目+93.7千、Bで−23.0千である（`mv3-*-money.json`）。Aでは、市場の金庫から農村にお金が入っている。1ロットあたりの値段にすると、次のとおりである。

| 年 | 市場 | 買った値（値段の8割） | 売った値 |
| ---: | ---: | ---: | ---: |
| 1 | 全体 | 0.94 | 0.45 |
| 1 | 6 | 1.41 | 0.40 |
| 1 | 14 | 2.40 | 0.49 |
| 2 | 全体 | 1.00 | 0.51 |
| 2 | 7 | 1.87 | 0.77 |

- 市場は、草刈りの時に、農家に売る時の2〜5倍の値で干し草を買っている。金庫は干し草で毎年損をしており、その損が農村の収入になっている。
- 前の記録で「豊かな市場の金庫が干し草の買い上げで農村にお金を入れている」としたのは、この損である。現金のある市場ほど高い値で多く買うので、豊かな市場の農村ほど多く受け取る。
- Bでは、干し草の多くが市場を通らない。損が無くなった分、農村の財布が減り、金庫が増えた。2年目からは、金庫の現金で穀物の門口の代金を払えるようになった（`settleFarmgatePayment`がAより+60〜87千）。その分、町の主食の代金で掛けを返す額と、余りの払い出しは減った。
- Aでも、高い値で買うので、同じ現金で買える量が少ない。在庫が冬までに無くなり、不足があまり減らない理由の1つと考えられる。

## 4. 分かったこと

1. 干し草の値段は、季節に逆らって動いている。現実の干し草は刈った時が一番安く、冬の終わりが一番高い。シミュレーションでは、市場は刈った時に高く買い、冬に安く売る。
   - 草刈りの月の買い値は、前の月（春の在庫切れの後）の高い値段の8割である。
   - 買った後は在庫が多くなり、値段が下がる。農家はその値段で買う。

   これは、取り引きの記録からの推定である。値段を決める計算の順番は、まだ確かめていない。
2. この値段の動きのせいで、市場の金庫から農村へ、毎年10万前後のお金が干し草の名目で流れている。市場の金庫と農村の財布の差（[market-treasury-cash-20261031.md](market-treasury-cash-20261031.md)）の一部は、この流れである。
3. Bは家畜の飼料には良いが、農村の財布を18%減らす。ただし、それは不自然なお金の流れが止まったためである。値段を直してからでないと、AとBのどちらを既定にするかは決められない。

## 5. 次にすること

- Fodderの値段の月ごとの動きと、値段を決める計算と草刈りの順番を確かめる。
- 値段の直し方を決める。例えば次のものがある。
  - 買い値を、刈った後の在庫で決める。
  - 市場が、買った値に保管の分を足した値より安く売らない。
- 直した後に、AとBをもう一度比べて、既定を決める。

## 7. 値段の直し（v1〜v3）

§5の続きである。干し草の値段を決める計算を確かめ、3回直して計り直した。

### 7.1 値段が逆に動く理由（確かめた）

- 1か月の順番は、草刈りの買い上げ（`production:forageHarvest`）→ 値段の計算（`production:pricesAndLabor`の`initializeMarketPrices`）→ 農家への飼い葉の販売（`production:livestockFeed`）である。
- 草刈りの買い値は、前の月の値段の8割だった。
- 値段は「価値×（需要＋5）÷（在庫＋5）」で、需要は農家のその月の注文だった。注文は、その月の不足と冬の備えの不足の和を、農村の財布の毎月5%で買える量までに抑えたものである。
- 1年分の在庫を、1か月分の注文と比べていた。そのため、刈った後は値段が下限（価値の0.25倍）に落ちた。在庫が無くなると、上限（3倍）に張り付いた。
- `fodderprice-v0-A-24.json`（直す前のA）では、市場14の在庫は年に8〜10か月0で、値段は上限の3.00だった。草刈りの月にその8割で買い、翌月から0.3〜0.7で売っていた。

### 7.2 3つの直し

| | 何を変えたか | 結果 |
| --- | --- | --- |
| v1 | 草刈りの買い値を、買った後の在庫で値段の式に入れた値の8割にした。市場の値段もその値にする | 刈った後の値段が下限に落ちる（1年分の在庫と1か月分の注文の比のまま）。農家の手取りが少ない |
| v2 | v1に加えて、値段と市場どうしの取り引きの需要を、農家の冬の備えまでの不足の全部（財布で抑えない）にした | 値段が1年中1.6〜2.7倍になった。農家は毎月5%の財布で少ししか買えない。市場6は春に2.3万ロットを持ったまま、家畜が足りない |
| v3 | v1に加えて、需要を「次の草刈りまでの月数×農家が毎月飼い葉に使うお金÷値段」と農家の不足の小さい方にし、軍の分を月数倍にした。月数は、市場が最後に農家から干し草を買った月から1年である（`fodderCutPeriod`） | 値段が1年を通して落ち着き、在庫が次の草刈りまでもつ |

- v1は、値段の式の需要が1か月分である問題が残る。
- v2は、農家が払えない値段になる。
- v3を残した。
- v3の市場6の値段は、0.35〜0.95で動く（`fodderprice-v3-A-24.json`）。在庫は2年目には一度も0にならない。
- v3の市場14は、1年目の春には直す前と同じく在庫が無かった。草刈りの後は0.26〜0.63である。

### 7.4 分かったこと

1. 直す前の、干し草を高く買って安く売るお金の流れが無くなった。その分、農村の財布が減り、市場の金庫に残った。
2. 金庫に残ったお金は、農村に戻っていない。干し草の高い買い上げが、市場の金庫から農村へお金を戻す一番大きい道だった。Bでは市場が干し草をほとんど買わないので、その道がもっと細い。
3. 金庫の余りの払い出し（`payOutMarketSurplus`）が、その代わりになっていない。払い出しは、準備金を超えた分の一部だけを、商人と町と農村に払う。
4. 既定はAのままにする。Bは家畜の飼料には良いが、金庫から農村へお金を戻す道ができるまでは、農村の財布を大きく減らす。

### 7.5 次にすること

- 市場の金庫がためたお金が、なぜ払い出しで農村に戻らないかを確かめる（準備金の大きさ、払い出しの割合と配り先）。
- 戻り道を直した後に、AとBの農村の財布をもう一度比べる。

### 8.3 分かったこと

1. 直す前の農村の財布の高さの一部は、干し草の値段の誤りで金庫から流れたお金だった。直した後の財布の減りは、その分である。
2. 塩の3つの目標（作る量、通常の値段、掛けの返済）は、どれも悪くなっていない。掛けの返済と人の塩の不足は、良くなった。
3. 金庫は、準備金（町の人口×20）までお金をためる。準備金は全市場で約15万あり、農村の財布の4割に当たる。ためる間は、農村の財布が少しずつ減ると考えられる。
4. 余りの払い出しには、農村への道が無い。干し草と穀物の取り引きの差益は農家から得たものなのに、払い出しは町と商人にしか行かない。

## 9. 余りの払い出しを農村にも（§8.4のb）と84か月

- 変更: [householdWealth.ts](../../src/extensions/economy/generators/householdWealth.ts)の`payOutMarketSurplus`。
  - 町の給与として払っていた分（払い出しから商人の利益を引いた分）を、町の人口と、農村の人口×重みで分ける。
  - 重みはSimulation設定の「市場の余りの給与の農村の重み」（`surplusRuralWeight`）で、既定は1（人数どおり）である。0で町だけになる。
  - 国の給与（`payStateHouseholds`）と同じく、町の`population`とセルの`pop`を比べる。
- 計測: v3のAで、重み1と重み0を84か月ずつ。HEADは[market-dissolution-m2-20261031.md](market-dissolution-m2-20261031.md)の`m2-wind.jsonl`（同じ固定入力・平和モード）。

- 36か月では塩は良くなっていた（§8.2）。84か月では、1304年から人の塩の不足とbudgetGapが悪くなる。
  - 不足が増えたのは国10・28に加えて、国5・8である（1305〜1306年）。
- 重み1は、重み0より農村の財布を18%多く残す。その分、町の家計の財布は18%少ない。人の塩の不足とbudgetGapは、ほとんど変わらない。
- 市場の金庫は、どちらもHEADより多く、毎年増えている。準備金（全市場で約15万）に届くまで、家計からお金を吸い続けている。
  - 1306年の農村の、払い出しからの受け取りは、重み1で58.6千、重み0で56.2千である（穀物の掛けの返済を含む）。準備金を超える市場が少ないので、払い出しそのものが小さい。
- 町の家計の財布は、多くの市場で減った（市場10・12・15・9・17・1・8・5）。町の収入の大部分は、農村が町で使うお金（農村の財布の毎月5%）である。農村の財布が減って、それが減った（1306年の`spendRuralHouseholdsInTowns`: HEAD −290.1千、重み1 −228.2千、重み0 −208.2千）。

### 9.1 分かったこと

1. bは働くが、効きは小さい。準備金を超えるお金が少なく、払い出しそのものが小さいからである。
2. 干し草の値段を直した後は、市場の金庫が準備金に向けてお金をため続ける。その分、農村の財布が減り、町の収入（農村が町で使うお金）も減る。その結果、町が主食を買えない（budgetGap）。人の塩の不足も増える。
3. 直す前の干し草の損は、たまたま金庫のお金を家計に戻す役をしていた。それが無くなって、準備金の大きさ（町の人口×20）が家計のお金に比べて大きすぎることが出てきた。

### 9.2 次にすること

- §8.4のc。準備金の倍率（`MARKET_CASH_RESERVE_PER_POPULATION_FACTOR`、今は1）をSimulation設定にして、0.5・0.25などで84か月を計る。金庫が実際に使う運転資金（穀物の門口の代金、草刈りの買い上げ、塩の掛け）と比べて、準備金の大きさを決める。
