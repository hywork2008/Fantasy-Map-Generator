# Rennet: 胃・抽出液量・凝乳能力・価格の史料照合

2026-10-22。[商品の物理単位](../plan/goods-physical-units.md)のT13に対応する追加調査。**中世の購入支出は確認できたが、購入数量がなく、1 L・胃1枚あたりの中世の価格はまだ決められない。** 抽出液のL数も濃度・力価を揃えないと比較できない。初回調査ではゲームの数値を変更していない。実装着手後の状態は§7に記録する。2026-10-22追補: §6で現代の実験研究とFAOの定量資料を追加し、仔牛の基準量は中世の力価史料を待たずに設定できると判断した。

## 2. 抽出液量と凝乳能力

同じ「胃1枚」からでも、濃い少量の液と薄い多量の液を作れる。比較には、抽出液量に加えて、乳の種類・温度・酸度・凝固時間と、その条件で処理できる乳量が必要になる。

| 年代・地域・史料 | 確認できた量 | 確認できないこと・採用範囲 |
| :--- | :--- | :--- |
| 1787、英国Warwick。Twamley, *Dairying Exemplified*, pp.43–45 | 通常の塩水抽出は水1 gallonに胃2枚。浸漬は24時間 | 仕込み水量であり、濾過後の回収液量ではない。gallonの種類と数値化した力価は不明 |
| 同書pp.109–111のDerbyの製法 | 植物を使った液1 gallonに胃3枚。9〜10日後に瓶詰め。15〜16 lbのチーズにtablespoon 1杯を目安とする | 植物併用、匙の容量、乳からチーズへの歩留まりが揃わない。通常の塩水抽出と同じ力価にはしない |
| 1793、James Dinwiddie手稿 | 胃の貨幣大の切片をhalf pintの水に浸し、20 gallonsの乳に使う | 胃全体の大きさ・切片の面積が不明なので、胃1枚の処理乳量には戻せない |

出典: [Twamleyの原文](https://www.gutenberg.org/cache/epub/69922/pg69922-images.html)、[Dinwiddie手稿の大学所蔵情報・翻刻](https://emmr.lib.unb.ca/recipes/rennet-cheese)。いずれも18世紀末の史料で、中世の確定値としては扱わない。

### 2.1 胃の枚数と相対的な力価が同時に分かる1916年の記録

A. Todd / Elfrida C. V. Cornish, “The Preparation of Home-Made Rennet”, *Journal of the Board of Agriculture*, August 1916の転載を確認した。*Queensland Agricultural Journal*, November 1916、pp.323–325、PDFの39〜41ページに当たる。胃10枚に水1 gallonを使い、得られる家庭製抽出液は良くても当時の市販品の半分程度の強さとする。同じ試験で市販品の凝固時間は約33秒、家庭製は通常その倍以上。再抽出も記すが、さらに弱い。[州政府所蔵の原文](https://era.dpi.qld.gov.au/id/eprint/15708/1/Vol_6NS_Part_5.pdf#page=39)

Imperial gallonを4.54609 Lとして換算すると、初回の仕込み水は胃1枚あたり約0.455 L。これは回収歩留まりではない。当時の市販品の半分という相対評価も、現代の145 MCU/mLやIMCU/mLと同じ規格だとは確認できない。したがって「胃1枚から現代製品相当0.227 L採れる」という採用値にも使わない。仔牛の年齢や胃ごとのばらつきも原文にあり、全ての牛の胃を同じ出力として扱う根拠にはならない。

## 3. 数量付きの後代価格は得られた

J. Pedersen, “The Casein Industry”, *New Zealand Journal of Agriculture*, 20 December 1919、Rennet Caseinの節は、カゼイン1 tonにレンネット約2 gallons、費用£3 14sと記す。同時代の製造上の必要量と費用の組を確認できる。[国立図書館の本文](https://paperspast.natlib.govt.nz/periodicals/NZJAG19191220.2.4)

この記載からの計算値は次のとおり。カゼインの生産費のうちレンネットに帰する額であり、中世の価格ではない。

| 計算 | 結果 |
| :--- | ---: |
| £3 14s ÷ 2 gallons | £1 17s / gallon = 37s / gallon |
| Imperial gallon = 4.54609 Lの場合 | 約8.139s / L = 97.67d / L |
| 同じ液の120 L相当 | 約£48.833 |

原文は乳100 gallonsにレンネット4 ozとも記すが、ozが液量か質量かを明記していないので、これだけから厳密な体積力価1:4,000を確定しない。1916年の英国製品とも別の記録であり、両者を接続して胃1枚の価格を逆算しない。1919年の価格を通貨換算だけで中世のSPに移すこともしない。

## 4. 現在のモデルとの照合

以下は史料値ではなく、調査時点のコードから導いた値。

| 項目 | 現在のコード・計算 |
| :--- | :--- |
| Rennetの市場1単位 | 120 L、値40 |
| 牛の入力 | 4.8市場頭 / 120 L → **25 L / 市場頭** |
| 羊の入力 | 12市場頭 / 120 L → 10 L / 市場頭 |
| 山羊の入力 | 10市場頭 / 120 L → 12 L / 市場頭 |
| Cheese 1,000 kgの入力 | 乳10,000 L、Rennet 2.5 L → 実使用時の投入比は乳4,000 L / 抽出液1 L。標準試験の力価とは別 |
| Rennetのカタログ価格でのチーズへの寄与 | 40 × 2.5 / 120 = 0.8333 SP / チーズ1,000 kg。Cheeseの値14の約5.95% |

正本: [`goods-generator.ts`](../../src/extensions/economy/generators/goods-generator.ts)のRennet・Cheese・`RENNET_BARRELS_PER_CHEESE_LOT`。カタログ値での原価比較であって、実際の市場価格・家計支出ではない。

設計書§27の「胃1つから3 L」とコードの25 L / 市場頭を結び付けているのは「仔牛1頭をCattle 0.12頭として原価を計算する」というモデル仮定であり、史料から得た頭数換算ではない。市場のCattle数量から仔牛の個体数・年齢を復元する処理はこのレシピにない。従って、4.8市場頭から胃40枚を得たことにはできず、**実装の出力量と、胃1枚の史料上の出力量を分ける必要がある**。

`slaughter.ts`のと畜後の副産物はTallowとLeatherで、Rennetは含まれない。Rennetは独立した家畜入力レシピのままである。「既にと畜した仔牛の胃を回収して抽出する」という物量契約にもまだなっていない。[実装](../../src/extensions/economy/generators/slaughter.ts)

## 5. 採用判断と残作業

今回の調査で「中世の購入支出そのものが見つからない」という状態は解消した。一方、数量付きの中世単価は得られていないため、**価格40・仔牛の胃3 L・羊と山羊の相対出力・Cattle 0.12頭の仮定は、いずれも史実に校正済みとはしない**。

次の校正では、以下を別々に確定する。

1. 液体の基準力価と試験条件。同じL数の中身が変わらないよう、輸送用の実液量と凝乳能力を区別する。家庭製・市販濃縮品を同じLのまま混ぜない。
2. 年齢を区別したと畜頭数と、回収できる胃の枚数。仔牛の安さを頭数の縮小で代用しない。胃から抽出する費用と、と畜全体の費用配分も分ける。
3. 同じ品の形・力価で、数量と金額が揃う価格史料。中世の1〜3d・18dは購入支出の照合用に残し、1 L価格には使わない。自家製や在庫持越しもあるため、乳業売上に対する比率だけで単価を確定しない。

初回調査では、中世の数量付き単価と胃1枚から基準力価への換算を未確定としていた。**後者は§6の現代資料で仔牛の基準を置けるため、中世の実験記録がないことを停止理由にしない。** T13全体では中世の単価と、羊・山羊の胃1枚あたりの相対出力が残る。


## 6. 現代の実験・技術資料による校正基準(2026-10-22追補)

前の調査は年代の合う史料に偏り、現代の生理・食品工学の測定値を物量校正に使う可能性を十分に調べていなかった。ここを修正する。動物の同種の酵素を使う物理的な基準は現代資料から置き、年齢・飼料・抽出・保存による差を別に扱う。以下の資料は、中世と現代の能力が全条件で等しいことを直接実証するものではないが、校正を進める定量根拠になる。

### 6.1 実験研究は存在する

- **Ferrandiniほか(2008)** は、仔羊の胃の内容物の有無と乾燥・凍結を組み合わせた4種類の実験レンネットペーストを比較した。凝乳活性は、内容物を除き乾燥した胃で391.20 IMCU/g、内容物を除き凍結した胃で172.87 IMCU/g。保存・調製条件で約2.26倍違う。同じ仔羊でも一律の値ではないことと、測定値を使って量を揃えられることの両方を示す。公開要旨に胃1枚の製品回収量はないため、この数値だけで仔牛との1頭あたりの比を出さない。[論文・公開要旨](https://journals.sagepub.com/doi/10.1177/1082013208095335)
- **Anifantakis / Green(1980)** は、乾燥した仔羊・仔山羊の胃から抽出したレンネットを仔牛由来と比較している。pHへの応答や保存安定性にも差がある。動物種別の実験資料として使えるが、公開要旨だけでは胃1枚あたりの総活性を確定できない。サイトのオンライン公開年2009と論文の刊行年1980を区別する。[原著論文](https://doi.org/10.1017/S0022029900021099)

IMCU/g・IMCU/mLの製品濃度と、IMCU/胃の総回収活性は区別する。後者を出すには、同じ実験の製品量または抽出回収量を掛け合わせる。

### 6.2 仔牛の胃と基準力価をつなぐFAO資料

J.-C. Lambert, *La transformation laitière au niveau villageois*, FAO Animal Production and Health Paper 69、1988年、第3部VI.2は、未離乳の仔牛の胃を使い、**胃約2枚から力価1:10,000の液体約1 L**、年間120 Lには胃240枚という目安を明記する。同じ節で、力価は35°C・40分の試験で定義している。[書誌](https://www.fao.org/4/x6934f/x6934f00.htm)、[数量と力価の定義](https://www.fao.org/4/x6934f/X6934F03.htm)

したがって、仔牛の基準を次のように置ける。

| 項目 | 採用する校正用の基準 | 根拠・位置付け |
| :--- | :--- | :--- |
| 原料 | 未離乳の仔牛の第四胃1枚 | 成牛や羊・山羊にそのまま適用しない |
| 標準化した製品量 | 約0.5 L / 胃 | FAOの実務目安。標本数や分散を示した実験平均ではない |
| 製品の力価 | 1:10,000、35°C・40分の標準試験 | 現代製品の任意のIMCU値と無条件には同一視しない |
| 胃1枚に対応する標準試験の乳量 | 約5,000 L | 0.5 × 10,000という計算値。実際のチーズ製造時の処理量とは別 |
| 同じ製品120 Lに対応する胃 | 約240枚 | 120 ÷ 0.5。仔牛の安さを0.12頭として数えない |

この0.5 Lは標準化後の製品量で、仕込み水量ではない。資料の工程には反復抽出と力価の標準化が含まれる。**中世の抽出回収率まで同じと断定する必要はないが、仔牛の基準量を資料のない3 Lのまま保つ必要もない。** 時代による違いを入れる際は、基準の酵素量を変えるのではなく、抽出・保存で残る活性として明示する。この扱いは歴史モデルへの適用方針であり、史料から測定された中世の回収率ではない。

### 6.3 力価と実使用量を分けると、Cheeseの現行投入量も照合できる

FAO *La fromagerie et les variétés de fromages du bassin Méditerranéen*, 第III章・表7は、力価1:10,000の製品について、非加熱圧搾チーズでは乳100 kgに20〜25 mLを挙げる。[表7](https://www.fao.org/4/x6551f/X6551F03.htm)

乳10,000 kgなら2.0〜2.5 L、上の0.5 L/胃なら胃4〜5枚という計算になる。ゲームのMilk 10,000 Lを質量約10,000 kgと近似すると、現行のCheese 1,000 kgにRennet 2.5 Lという投入量は、この実務範囲と整合する。**使用比1:4,000だから製品の標準力価も1:4,000だ、とは言えない。** 先の§4の表現もこの点を修正した。

今後の数値修正では、Rennetをまず「力価1:10,000に標準化した液」と定義し、仔牛の胃1枚あたり0.5 Lを校正基準にする。現在の25 L/Cattle市場頭との差を、仔牛の年齢構成・と畜からの胃回収・費用配分とともに直す。Cheeseの2.5 Lを先に増やす修正は行わない。価格40は、この物量基準が得られても歴史価格に校正されたことにはならない。

### 6.4 残る範囲

- 仔牛は、胃1枚と標準化した液量の校正基準を得た。中世の凝乳能力の実験値を待つ作業は外す。
- 羊・山羊は実験論文を得たが、胃1枚あたりの総回収活性の比較が必要。「仔牛の1/4」を確定値にはしない。
- 中世の数量付き価格は引き続き別の調査課題。物量の校正と価格史料の不足を一括して保留しない。
- 調査段階では価格・レシピ・保存形式を変更していなかった。続く実装変更は§7を参照。

### 6.5 生産・と畜処理への適用点の確認

[`faunaPopulation.ts`](../../src/extensions/economy/generators/faunaPopulation.ts)には`young / breeding / old`の集約層がある。ただしCattleの`youngMaturityYears = 2`は成熟へ移る速度のパラメータで、未離乳仔牛を識別する月齢台帳ではない。`applyCull`は高齢→繁殖→若齢の選択と比例抽出を混ぜて群れを減らし、`drawDomesticatedFaunaOfftake`からは総数量だけを返す。市場のCattle在庫には、未離乳の何頭から来たかが残らない。

従って、現在の全Cattle在庫に0.5 L/頭を一律に掛ける変更や、`young`全体を未離乳とみなす変更はしない。物量修正は次の接続を一緒に扱う。

1. 群れから出した頭数のうち、レンネット原料に適する未離乳個体を区別し、その内訳を市場またはと畜まで引き継ぐ。単なる幼若層の割合や仔牛価格から個体数を作らない。
2. 実際にと畜した適格な個体1頭から胃1枚を回収し、Tallow・Leatherと同じ個体の副産物として記録する。Rennetの独立レシピで同じ個体を再消費しない。
3. 回収した胃1枚あたり0.5 L(力価1:10,000)を基準に製品を計上する。小さい生産量を120 Lの樽単位の丸めで消さない。
4. と畜副産物から作る原価と歴史価格の校正を分ける。240枚/120 Lを、そのままCattle 240市場頭を買うレシピに置き換えない。

ここまでで、研究不足による保留と、実装側に未離乳個体の追跡がないことによる作業を分離できた。現代資料で仔牛の校正基準を決める判断は維持し、実装接続は家畜の頭数・副産物・小量在庫の整合を保って行う。


## 7. 実装着手: 誤った家畜レシピの停止と回収処理

2026-10-22。`rennet.ts`に120 L/樽・0.5 L/未離乳仔牛の第四胃という物量契約を定義した。Cheeseの投入量2.5 L/1,000 kgチーズも同じモジュールにまとめ、量は維持した。

- 新規カタログからCattle 4.8・Sheep 12・Goats 10の独立レシピを削除した。既存セーブも`migrateRennetCalfContract`でこれらの家畜を使うレシピを削除する。旧係数へ再価格設定する処理も削除した。既存のRennet在庫・価格と、家畜を使わないカスタムレシピは維持する。保存済みの液の力価は確認できないため、在庫の数量を推測で補正しない。
- `settleSlaughter`は、呼出側が市場ごとの適格な未離乳仔牛数を明示した場合、その市場で実際にと畜したCattle頭数を上限に、胃1枚/頭としてRennetを副産物に加算する。Tallow・Leatherと同じ個体を使い、追加の家畜を消費しない。1頭で1/240樽となるため、Rennetの在庫・生産累計は小数第2位に丸めない。
- **通常の生産処理から適格頭数を渡す接続はまだない。** 現在の`settleSlaughter()`呼出しでは年齢不明としてRennetを新規生産しない。これは旧レシピを止めたことによる実際の挙動変更で、供給の完成を意味しない。既存在庫が尽きた後はほかのCheeseレシピへの依存が増える。次は未離乳個体を群れから出荷・輸送・と畜まで追跡する処理を実装する。`young`全体や任意の固定割合で適格数を捏造しない。
