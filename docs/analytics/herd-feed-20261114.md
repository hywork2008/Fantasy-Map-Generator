## 4. 読み取り

1. 前の決まりで養える数を超えて持ち越した頭には、冬の終わり（2〜4月）に餌が足りていなかった。3月には要る量の約2割が足りず、土地の4割余りで不足した。新しい決まりでは、その不足が約半分になる。
2. 養える数の見積もりが小さいのではなく、前の決まりの頭数（と3年目の12〜18%多い肉と皮）は、冬の餌の足りないまま保たれていた。新しい決まりを既定のままにする。
3. 新しい決まりでも3月に要る量の1〜1.5割が足りない。今は餌が足りなくても乳と羊毛が減るだけで（`getLivestockFeedCoverage`、dairy.ts・woolProduction.ts）、家畜の頭数・死・子の数には響かない。養える数が冬の終わりの餌を基にしていないか、干し草が土地の間で偏っているかは確かめていない。
