# E1: 複合生産需要と年間更新の物量接続（2026-10-24）

牛・羊・山羊について、[Province101](e1-joint-demand-province-20261024.json)と[World102](e1-joint-demand-world-20261024.json)の固定入力を使用した。各JSONに入力・実行ソースのSHA、Standard設定、交易設定、開始時と12か月後の診断を保存する。[集約・比較結果](e1-joint-demand-summary-20261024.json)に両観測のSHAと既存診断の一致を記録した。

## 実装した契約

- `livestockJointDemand.ts`は、同じ群れが出す複数の産物を一つの頭数で評価する。他の群れの潜在産出と既存在庫を控除し、各産物の必要頭数の最大値をとる。乳用群と採毛用群を足し算しない。
- 得られる頭数は「他の群れを現状に固定した場合の、判明している需要についての条件付き下限」である。3種の条件付き下限を同時に実現する目標とはしない。需要や歩留まりが不明なら完全な下限はnull。群れが存在しない場合にも年齢構成や産出を仮造しない。
- `requiredJointOfftakeHeads`は、肉と皮を同じ解体の共同産出として年間屠畜フローを換算する。肉用と皮用の頭数を加算せず、未知の需要・歩留まりを0にしない。この年間フローを、そのまま飼養在庫の頭数と同一視しない。
- `assessAnnualHerdRenewal`は出生・自然死・年間出荷を分ける。実際の年次コホート更新も同じ出生/自然死計算を使い、診断と本処理の式を重複させない。出荷実績を取得できない読み取りではnullとし、自然増減を出荷後の純増減と取り違えない。
- 乳量係数を`dairyProductionPolicy.ts`へ共通化した。年間500/150/75 L（牛/山羊/羊の泌乳雌）、繁殖群の泌乳割合0.375という既存の仮係数は変更していない。

## 市場・既存需要への接続

`livestockJointDemandMarket.ts`が、既存の`getMonthlyHouseholdDemand`を年換算し、飲用乳とチーズ原料を物量へ接続する。完成チーズの市場在庫を先に差し引き、その分の乳を群れへ重ねて要求しない。生乳在庫の控除は当月の飲用需要までとし、腐敗する生乳を通年の備蓄とは見なさない。これは物理的な潜在供給の診断であり、買手の支払能力や将来の在庫保持を保証するものではない。

乳の潜在産出は同じ市場の実コホートから求める。年齢構成を保持し、若齢/老齢を泌乳成畜と同じにしない。羊毛も同じ羊の年齢別係数で評価するが、衣服の全需要を羊毛へ置き換えない。既存の家内加工/委託の選択済み原毛注文は当月のkgとして併記し、年間需要や都市需要を含む値へ勝手に拡張しない。

既存の`species[].demandStatus`は頭数上限の未接続を示す表示として維持し、今回の部分的な物量計算は`jointProductMarkets`へ保存する。

肉・皮の年間需要と本番歩留まり、繊維の代替と純交易、畜力/堆肥、繁殖・更新方針が未確定のため、総合的な目標頭数はnullのまま。需要に基づく頭数上限への自動反映は未実装であり、家畜の適正判定を完了とはしていない。

## 開始時点の固定入力で判明した桁の不一致

| 現行モデルの年換算 | Province101 | World102 |
| --- | ---: | ---: |
| 飲用乳の需要（L） | 9,067,439.66 | 83,882,441.65 |
| チーズの需要（kg） | 11,334,299.57 | 104,853,052.06 |
| チーズ用原乳の需要（L、完成在庫控除後） | 113,342,995.74 | 1,048,530,520.61 |
| 既存群れの潜在乳量（L、管理/給与損失の前） | 41,666.98 | 6,802,054.04 |

これは実際の年間生産/消費の計測ではなく、現行仮係数での年間計画量である。飲用乳20 L/人/年＋チーズ25 kg/人/年×原乳10 L/kgという需要は原乳270 L/人/年に相当する。この仮目標と産出係数の不一致を、現状の家畜が一律に過剰である証拠にも、群れをこの需要まで増やす根拠にも使わない。史料での需要・歩留まりの校正を先に進める。

初期状態での年間出生/自然死の予測は、例えばWorldの牛で約3,199.47/2,001.15頭、羊で約30,703.87/16,024.19頭。これは現在の頭数・資源上限での一時点の年次予測であり、今後12か月に積算される出生・自然死の実績ではない。

## 出荷フローと検証範囲

監査ツールに、prepare後の実際の`ruralHarvest`の生体市場搬入を実頭数で数える観測を追加した。Horsesは既存の25頭/市場単位を一度だけ換算する。市場別/種別の累計、年齢群の由来が不明な搬入を分ける。生体搬入は屠畜・食肉供給とは呼ばず、年次予測から別期間の実出荷を引いて架空の収支を作らない。

固定2入力の独立した12か月走行では、開始時と12か月後の既存5種の診断全項目（頭数・資源上限・現行目標・超過等）が変更前と一致した。出荷/更新政策や係数を変更していないため、今回は36か月の移行試験を繰り返していない。

Worldの12か月の実生体搬入は牛545頭・羊622頭・山羊106頭、Provinceでは牛1頭・羊1頭だった。両入力で観測した生体搬入の年齢群由来不明は0頭。これは市場に入った生体の数で、自家屠畜・軍/商人等の所有動物の移動や肉kgを含む全出荷/全消費ではない。Worldの12か月後の潜在乳量は約818万L/年となったが、その時点の年換算需要・潜在産出であり、実際の年間乳量ではない。

関連Vitest 6ファイル83テスト、型チェック、変更TSのBiome、シミュレーション境界チェック成功。共同産出の最大値、他群れ/在庫の控除、未知、年次フローの次元、出生/自然死の分離、L/lotの換算と市場境界を検証した。
