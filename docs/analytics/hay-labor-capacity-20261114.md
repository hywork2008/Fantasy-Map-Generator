# 干し草の月に割り当てられる大人の手はあるか

設計：[hay-plan-herd.md](../plan/hay-plan-herd.md)。過去の記録：[e1-feed-shortage-20261026.md](e1-feed-shortage-20261026.md)（§7.58）、[e1-hay-births-20261028.md](e1-hay-births-20261028.md)。

## 1. 方法

- 地図2102・2103、1か月だけ進め、年1回の職業の割り当て（畑の暦）が入った状態で数えた。HEAD 4f27d2bd5に今回の変更。
- [haylabor.mts](hay-labor-capacity-20261114/haylabor.mts)は、家畜のいる陸の土地ごとに、冬を越す頭数（種類ごとに今の頭数と養える数の大きい方）の干し草の計画（`getLivestockHayPlan`）が刈る月について、次を数える。
  - 要る日数：刈る量（t）× 3日（`HAY_WORK_DAYS_PER_TONNE_DM`）。
  - 空いている大人の手：大人 × その月の働ける日数 − 畑仕事（年1回の割り当ての畑の暦）− 狩猟・漁労・ぶどう − 家畜の世話。数え方は`scripts/auditFeedShortage.mts`の§7.58と同じ。
- [run.sh](hay-labor-capacity-20261114/run.sh)。

## 3. 読み取り

1. 冬を越す頭数の干し草を刈るのに要る日数のうち、空いている大人の手で賄えるのは約73%で、両方の地図で同じである。割り当てを直しても、刈れるのは約73%までである。
2. この割合は、刈り取りが計画の約75%で止まること（[hay-plan-herd-20261114.md](hay-plan-herd-20261114.md)の計算）と、3月に約600の土地で残る不足に合う。
3. 半分以上の土地で、干し草の月の少なくとも1か月が、畑仕事などだけで大人の手が埋まっている。10月の記録（森林系とタイガの二次的な制約）より広い。干し草の月が穀物の刈り入れと重なるためと見られる。

## 4. 4つの候補と、食以外に取られている手（過去の記録とコード、1か月の数え直し）

### 4.1 調査済みの候補

1. **干し草1t乾物に3日**：[e1-hay-labor-source-20261028.md](e1-hay-labor-source-20261028.md)で、Victoria County History（Wiltshire）の草刈り½〜1エーカー/日（1haに2.5〜5人日）と照合済み。3日/tは草刈りだけの範囲で、反転・運搬を入れると史料の下限に近い。値は多過ぎない。草地の単収1.5t/haは未確認のまま。
2. **1人あたりの家畜**：[e1-hay-hire-20261025.md](e1-hay-hire-20261025.md)で牛は100人あたり約12頭（史料の約35頭の3分の1）。家畜は多過ぎず、むしろ少ない。
3. **子ども・近隣の手伝い・雇い人**：子どもの干し草作り（[e1-hay-children](e1-hay-children-20261025.md)、`CHILD_HAYMAKING_SHARE`）、同じ国の隣の土地の手伝い（[e1-hay-boon](e1-hay-boon-20261025.md)）、同じ市場圏の農村の手の空いた大人の25%（[e1-hay-hire](e1-hay-hire-20261025.md)）は実装済み。§2の「空いている大人の手」はこれらを入れない数え方なので、実際に刈れる割合（約75%）とほぼ同じになった。
4. **本刈りの月**：草の伸びの山の1か月前を本刈り、山の月までの2か月を干し草の季節とした（[e1-hay-labor](e1-hay-labor-20261025.md)、[e1-hay-season](e1-hay-season-20261025.md)）。調整済み。

### 4.2 干し草の月の大人の手の使い道（[haylabor.mts](hay-labor-capacity-20261114/haylabor.mts)に畑の最小の暦・家の織物・町の大人を加えた、百万日）

| | 2102 | 2103 |
| --- | ---: | ---: |
| 大人の働ける日数 | 552.4 | 257.3 |
| 畑仕事（年1回の割り当ての暦） | 347.5 | 167.7 |
| うち、村の食べる分に要る畑（最小の暦） | 327.2 | 152.5 |
| 家の織物（牧畜の後に割り当て） | 12.0 | 6.4 |
| 家畜の世話 | 22.9 | 11.6 |
| 狩猟・漁労・ぶどう | 4.4 | 2.2 |
| 干し草に要る日数 | 67.0 | 32.0 |
| 足りない日数 | 17.7 | 8.6 |
| 畑を最小の暦にした時の足りない日数 | 15.2 | 7.4 |
| 町の大人が干し草の月に25日ずつ出た時の日数 | 23.0 | 15.6 |
| 町の大人で同じ市場圏の不足を埋められる割合 | 90% | 98% |

- 地図全体では、干し草の月の大人の手は干し草に要る日数の2倍以上空いている（2103で257 − 168 − 12 − 2 = 75百万日に対し32百万日）。足りないのは、畑仕事で大人の手が埋まる土地に集まっている。
- 農村の食以外の仕事（家の織物）は牧畜の後に割り当てられ、干し草の手を取っていない。村の食べる分を超えた畑の手（2103で15百万日）を外しても、不足は約14%しか減らない。
- 町の人は、穀物の刈り入れにだけ、中世で大人の5%（`URBAN_HARVEST_HELP_SHARE_MEDIEVAL`）が出る。干し草の手伝いには町の人は出ず（`applyHaymakingMutualAid`は農村だけ）、出た分の町の仕事も減らしていない。町の大人が干し草の月に出れば、同じ市場圏の不足の9割以上を埋められる。

## 5. 読み取り（§4を含めて）

1. 干し草の手の不足は、農村の大人が食以外に取られているためではない。農村の手は食（畑・家畜）でほぼ使い切られている。
2. 食以外に手を取っているのは町の人で、刈り入れと干し草の月にも町の仕事を続け、穀物の刈り入れに5%が出るだけである。
3. 中世の英国では、1351年の労働者規制法と1388年のケンブリッジ法が、職人と手工業者を刈り入れに出させた（正確な条文は確かめる必要がある）。町の人の刈り入れと干し草への手伝いを、職人の仕事の減りとあわせて設計し直す余地が大きい。
