# バリラの石鹸の計測（2026-11-08）

設計は[barilla-soap.md](../plan/barilla-soap.md)。石鹸の値段の作り方を直し、油とバリラの石鹸のレシピを足した。暖かい市場の町がバリラで石鹸を作るか、バリラが遠くへ運ばれるかを見た。

## 1. 条件

- 地図：[barilla-20261108.md](barilla-20261108.md) §1と同じ北緯30°の2枚（シード2102・2103）、同じバリラの置き方と`add "Clay,White sand"`。地図は`docs/analytics/raw/barilla-20261108/maps/`のものを使い直した。
- 24か月。`FMG_CONFLICT_AUTONOMY=peace`、`FMG_CARAVAN_RAIDS=off`。市場は平均気温で4つに分けた（18℃以上、14〜18℃、8〜14℃、8℃未満）。
- 実行は[run.sh](barilla-soap-20261108/run.sh)と[run-dfix.sh](barilla-soap-20261108/run-dfix.sh)（どちらも[barillaflow.mts](barilla-20261108/barillaflow.mts)）、集計は[summary.py](barilla-soap-20261108/summary.py)、出力は[summary.txt](barilla-soap-20261108/summary.txt)。
- バリラの取引の関門は[tradeprobe.mts](barilla-soap-20261108/tradeprobe.mts)（12か月、newのコード）、材料の需要の割合は[demandprobe.mts](barilla-soap-20261108/demandprobe.mts)で見た。

| 名前 | コード |

## 2. 石鹸

単位は樽。町の買い物は`luxuryPurchase`と`characterLuxury`の和。

- 値段を直すと、石鹸の値段は24か月目に8〜14℃の市場で3.88から2.82（2102）、4.69から3.30（2103）に下がった。baseの値段は、油の無い市場の品不足の油の値段（基準の値の3倍）と、苛性ソーダの「獣脂だけ」のレシピの平均から作っていた。
- 値段が下がって、町の生産は約3分の1になった。baseは作る量が買い物の4〜5倍で、在庫が24か月目に645・380樽まで積み上がっていた。直した後も作る量は買い物の約2倍で、積み上がりは半分以下になった。
- 町の買い物は、2102で約3割、2103で7割減った（soapfix）。減ったのは人物の贅沢品（`characterLuxury`、2102で55.0から1.5、2103で45.6から2.8）で、町の家計の贅沢品（`luxuryPurchase`）は2102で28.4から55.5に増え、2103で23.7から16.7に減った。人物の買い物が減った訳は調べていない。2103のsoapfixは、8〜14℃の市場の町の生産が年9.6樽まで落ちた。
- バリラの石鹸は、2103の8〜14℃・14〜18℃の市場で年17〜18樽作られ、2103の町の生産を22樽から59樽（new）に戻した。2102では年3〜6樽。油の取れる市場（オリーブの市場）と、バリラの取れる市場が重ならない。
- 油は、レシピの材料の記録に出ない。油を作る町が自分の在庫から使うため（`fromInventory`は市場の買い物でないので記録しない）。

## 3. バリラの取引

### 3.1 関門

[tradeprobe.mts](barilla-soap-20261108/tradeprobe.mts)の1〜12か月目。

| | 2102 | 2103 |
| --- | ---: | ---: |
| 輸出と輸入の市場の組（`pair`） | 0 | 0 |
| 投機の取引の候補（`speculative`） | 0 | 12 |
| 取引（`deal`） | 0 | 7（1回0.3樽ほど） |
| 12か月目のバリラの在庫 | 82.2（2市場） | 16.7（6市場） |
| 12か月目のバリラの値段 | 0.11（底） | 0.11〜0.46 |

- 輸入の市場が1つも無い。取引の蓄えは、品の需要の割合（町の人1人あたり、品ごとに世界で1つ）から作る。バリラの消費の需要は0で、材料の需要も0だった（[demandprobe.mts](barilla-soap-20261108/demandprobe.mts)）。
- 材料の需要は、校正のある時、作った品ごとに基準の値で最も安いレシピ1つから取る。まだ世界が知らない材料を0として比べていたので、ガラスはソーダ灰のレシピ（「ガラスの砂だけ」）、石鹸は苛性ソーダのレシピ（「獣脂だけ」）が選ばれ、炭酸カリウムの材料の需要も0だった。
- 投機の取引は、2102で1度も候補にならなかった。2103の取引は、海の道の1組だけ。バリラの値打ち（1樽0.45、重さと嵩で6）から、陸の運びは約3.6日まで、海は約36日まで（`getGoodMaxTradeDurationDays`）。

### 3.2 材料の需要を直した結果（dfix）

| 材料の需要（町の人1人あたり、2103） | new | dfix |
| --- | ---: | ---: |
| 炭酸カリウム | 0 | 3.45×10⁻³ |
| バリラ | 0 | 0 |
| 獣脂 | 1.51×10⁻² | 1.51×10⁻² |

- 炭酸カリウムの輸出と輸入は、2103の13〜24か月目に8〜14℃の市場で3.1・2.2樽から5.2・4.6樽に増えた。14〜18℃の市場の24か月目の炭酸カリウムの値段は0.83から1.13に上がった（2102は0.85から0.96）。ほかの流れは、ばらつきの中。
- バリラの材料の需要は0のまま。知らない材料のレシピを除くと、最も安いレシピはガラスも石鹸も炭酸カリウムのもの（ガラス1荷のアルカリが炭酸カリウム0.45、バリラ0.72）。炭酸カリウムは町の炉の灰でどの市場にもある。
- 2103のdfixの石鹸の生産は、13〜24か月目にnewより18樽少なかった（58.9と41.2）。炭酸カリウムの石鹸（7.1樽と5.4樽で、石鹸約6樽の差）とバリラの石鹸（約2樽の差）では説明しきれず、残りの訳は調べていない。2102では差が無い（115.5と119.1）。

## 4. 結論

- 石鹸の値段の直し、バリラの石鹸、材料の需要の直しの3つとも残す。
- バリラは、取れる市場とその近くの石鹸とガラスに使われる。遠くへの取引は、値段では起きない。史料の取引（アリカンテからイタリア・イングランドへ）は、クリスタッロと白い固い石鹸の質のためだった。質の違う品を作るのは、次の設計とする（[barilla-soap.md](../plan/barilla-soap.md) §5の3・6）。
- 2102のバリラの在庫は、24か月目に155〜158樽で変わらない。
