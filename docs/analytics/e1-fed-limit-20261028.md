# E1: 前年の給与率による制限を不足に比例させる（2026-10-28）

親計画§7.62の検証記録。§7.61で、給与率が1を少しでも下回ると収容力が「計画頭数×草地の割合」から「今の頭数×給与率」へ段差で落ち、1307年の牛の収容力の落ち込み（1,095→693千頭）を起こしていることが分かった。`src/extensions/economy/generators/husbandry.ts`の`getGrazedCarryingCapacity`で、制限を「今の頭数×給与率」と「計画×草地の割合×給与率」の大きい方にした。前の値は§7.60の`e1-herd-order-20261027/world-after-96.json`（同じ固定入力・96か月）。

- 群れは毎年増え続け、1308年に牛25.9頭・羊97.1頭（前は15.7・55.0頭で頭打ち）。

## 判定

変更は維持する。段差による収容力の落ち込みはなくなった。群れが増えたぶん飼料不足が約3%に戻っており、原因（干草の人手か草そのものか）は未確認。牛・羊は1308年でもまだ増えているが、頭数目標に対して牛42%・羊63%・山羊90%で、目標を超えてはいない。
