# バリラの計測（2026-11-08）

設計は[barilla.md](../plan/barilla.md)。暖かい港の町が、バリラ（塩生植物の灰）でガラスを作るかを見た。計測の途中で、ガラスの値段の作り方の誤り（§3〜5）が見つかったので、直して計り直した。

## 1. 条件

- 地図：北緯30°（`"latitude": "30"`）の世界地図2枚（シード2102・2103）。今までの計測の地図は、陸の平均気温が12℃までで、バリラの取れる14℃以上の土地が無かった。
  - 変更前のコードで作った（保存した地図の移行`migrateBarillaGood`を通す）。設定は[storage-warm.json](barilla-20261108/storage-warm.json)。
  - 2102：市場50（平均気温18℃以上2、14〜18℃15、8〜14℃23、8℃未満10）。陸の気温は−2〜20℃。
  - 2103：市場28（14〜18℃7、8〜14℃19、8℃未満2）。
- 保存した地図には資源の配置が無いので、計測の中で、空いている条件に合うセルにバリラを確率3%で置いた（[barillaflow.mts](barilla-20261108/barillaflow.mts)）。2102は345セルのうち3、2103は272セルのうち4。
  - 寒い土地の粘土・ガラスの砂も、[glass-houses-20261107.md](glass-houses-20261107.md)と同じく足した（`add "Clay,White sand"`）。
- 24か月。`FMG_CONFLICT_AUTONOMY=peace`、`FMG_CARAVAN_RAIDS=off`。
- 市場は平均気温で4つに分けた（18℃以上、14〜18℃、8〜14℃、8℃未満）。
- 実行は[run.sh](barilla-20261108/run.sh)・[run-v2.sh](barilla-20261108/run-v2.sh)・[run-v4.sh](barilla-20261108/run-v4.sh)、集計は[summary.py](barilla-20261108/summary.py)。出力は[summary.txt](barilla-20261108/summary.txt)（base・new・new2・new3）、[summary-v4.txt](barilla-20261108/summary-v4.txt)（base・basefix・new・new4）。

## 2. バリラ

13〜24か月目（1年）。単位は樽。

| | 2102 new4 | 2103 new4 |
| --- | ---: | ---: |
| 取れた量（農村） | 39.0 | 29.6 |
| 町の生産（資源のセルの町） | 51.3 | 0 |
| ガラスに使った量 | 15.1 | 24.1 |
| ガラスの荷数（÷1.6） | 9.4 | 15.1 |
| 24か月目の在庫 | 157.9 | 24.7 |

- 14〜18℃の市場の町が、バリラでガラスを作った。その市場のガラスの炭酸カリウムは、basefixの年18.8・17.4樽から、new4で10.9・10.3樽に減った。バリラが炭酸カリウムに代わった。
- 2103では、8〜14℃の市場にもバリラが運ばれた（1〜12か月目に6.1樽）。
- 2102では、取れる量が使う量の約6倍で、在庫が積み上がった。資源のセルにある町が自分でもバリラを作る（年51樽）。ほかの港へはほとんど運ばれなかった。

## 3. v1：レシピの平均のガラスの値段

- ガラスの値段（在庫の値打ち ÷ 在庫）は、v1でどの気温の市場でもbaseより1〜4%高かった。バリラの無い8℃未満の市場でも高かった（2102の12か月目に3.51 → 3.66）。
- 原因は、作った財の値段の元にする材料の費用が、レシピの平均だったことである（[foodProcessingEconomics.ts](../../src/extensions/economy/generators/foodProcessingEconomics.ts)の`getRecipeCostBasis`）。バリラの無い市場では、バリラの値段が品不足で高く、3つ目のレシピの費用がガラスの値段に入った。
- ガラスの買い物（`luxuryPurchase`、13〜24か月目）は、2102で620.7 → 537.6荷、2103で407.6 → 355.3荷になった。

## 4. v2：材料を持つレシピの値段

- エールと同じく、材料の全部を1荷分持つレシピのうち、最も安いものの費用でガラスの値段を作った。
- ガラスの値段は、baseより2〜11%低くなった。
- 原因は、工業のソーダ灰の技術の前は、ソーダ灰が使えない財で、値段の計算がそれを材料から外していたことである。ソーダ灰のレシピが「ガラスの砂1」だけになり、最も安いレシピとして選ばれ、アルカリの費用の無いガラスの値段になった。
  - 作る側（[production-generator.ts](../../src/extensions/economy/generators/production-generator.ts)）は、使えない材料のあるレシピを使わない。
  - baseのレシピの平均にも、この「ガラスの砂だけ」のレシピが半分入っていた。baseのガラスの値段は、アルカリの費用が半分しか入っていなかった。

## 5. v3：作れないレシピを外す

- 使えない材料のあるレシピを、材料を持つレシピに選ばないようにした。
- 結果は、1か月目にv1と同じになった。ほとんどの市場は、ガラスの砂1荷と炭酸カリウム0.5樽を同時に持たず、レシピの平均（バリラの高い値段が入る）に戻った。

## 6. v4：作れるレシピの最も安いもの

- どのレシピの材料も1荷分無い市場は、作れるレシピのうち最も安いものの費用でガラスの値段を作った。エールは今まで通りレシピの平均。
- basefixは、baseにこの値段の作り方だけを入れたもので、値段を直した影響とバリラの影響を分けるために計った。
