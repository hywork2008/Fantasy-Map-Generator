# 統治形態別・財政レジーム史実対照（調査ノート）

**目的**: 為政者の個人 `Character.wealth` が薄く感じる問題と、「国庫・部門・領の金が使えるのが自然」という直観を、史実の財政レジームと照合し、**実装前の共通認識**を固定する。  
**位置づけ**: 調査・論点整理。実装仕様ではない。支出側の既存設計は [state-treasury-department-budget.md](../plan/state-treasury-department-budget.md)、個人俸給の現行梯子は [character-wealth-balance.md](./character-wealth-balance.md) を参照。  
**対象ゲーム形態**: `state.form` の Monarchy / Republic / Theocracy / Union / Anarchy。

## 0. 調査の枠組み

史実の「国家財政」は近代予算国家と同じではない。中世〜近世ヨーロッパ（＋比較のため教皇領・複合君主制）を主参照とし、各形態について次の4軸で整理する。

| 軸 | 問い |
| :--- | :--- |
| **A. 歳入源** | 何が「普通の収入」で、何が「臨時」か |
| **B. 金庫構造** | 金は何個の財布に分かれ、誰の名義か |
| **C. 支出権限** | 誰が何に使えるか。承認・慣習・強制の違いは |
| **D. 為政者の私財** | 個人の所持金と、統治に使える金の関係 |

### 0.1 史実から先に言える一般原則

1. **「税」は必ずしも平時の通常収入ではない**  
   西ヨーロッパ封建期、君主の通常収入は所領・関・裁判料・特権料など**家産・職務収入**に近く、広域の人頭税・動産税は戦時や特別補助金として議会・慣習の承認を要することが多かった。  
2. **財布は複数あるのが普通**  
   王室家政 / 王国会計、都市の公庫 / 評議会特別会計、教皇庁の Camera Apostolica、複合君主制下の**領邦ごとの会計**など。単一 `state.treasury` は強い抽象化である。  
3. **「個人が金貨を持つ」≠「統治できる」**  
   領主・王は地代と権限で動き、現金ストックはしばしば薄い。逆に都市財政や戦時公債の規模は個人所持金をはるかに超える。  
4. **形態差の本質は税率表より「誰の金か・誰が決めるか」**  
   同じ関税でも、王の関と市の関、教会の十一税では政治的意味が違う。

これらの原則は、現行 FMG が「全形態で同じ `collectTaxes` パイプ＋形態別の税率/部門%」であることの**最大のズレ**を指す。

## 1. ゲーム形態 ↔ 史実アナログ

| `state.form` | 主な史実アナログ（理想型） | 注意 |
| :--- | :--- | :--- |
| **Monarchy** | 中世〜近世の王権国家（英・仏など）、封建君主＋王室所領 | formName（Kingdom/Empire 等）で称号は分かれるが、財政型はほぼ同じ枠 |
| **Republic** | イタリア都市共和（ヴェネツィア、ジェノヴァ、フィレンツェ等）、一部ハンザ都市 | 「全国民共和」ではなく**都市／商人寡頭**が近い |
| **Theocracy** | 教皇領、聖職者支配の領邦、騎士修道会国家 | 十分の一・聖職禄が本体。常備軍国家ではない |
| **Union** | 同君連合・複合君主制（カルマル、ハプスブルク、PL 等）、緩い連邦的中央 | 「一つの税務署」ではなく**複数会計の束** |
| **Anarchy** | 内乱・軍閥・権力空白期 | 正規財政というより略奪・保護・従士への分け前 |

既存設計書 §1 のアナログ表と整合する。本ノートはそこを**歳入・金庫・権限・私財**まで拡張する。

## 2. 形態別プロファイル

### 2.1 Monarchy（君主制）

#### A. 歳入源

| 種類 | 史実での位置づけ | 平時/臨時 |
| :--- | :--- | :--- |
| 王領・荘園収入、森林・鉱山特権 | 王が「自分の土地」から取る | 通常 |
| 関・通行料・市場特権 | 王権または請負 | 通常〜半通常 |
| 裁判料・登記・特権認可 | 司法・恩顧の現金化 | 通常 |
| 封建的援助・騎士金 | 特定事由 | 準臨時 |
| 動産税・補助金（fifteenth/tenth 等） | 共同体一括や議会同意と結びつきやすい | **臨時・戦時寄り** |
| 強制公債・「好意」、関税強化 | 近世化に伴い増大 | 臨時〜構造化 |

**示唆**: 人頭税を平時の主エンジンにするのは、封建君主より**近世財政国家**に近い。Monarchy を中世寄りに寄せるなら、**所領・関・特権**を通常、**広域賦課**を臨時にするのが史実的。

#### B. 金庫構造

- **王室家政（household / chambre）** と **王国会計（exchequer 等）** の分離が典型。  
- 前者は宮廷・威信・私的贈与、後者は戦争・外交・一部行政。境界は曖昧で、流用は政治問題になる。  
- 地方では**州・都市・領主**が独自に徴収し、王は一部だけを吸い上げる。

#### C. 支出権限

- 王は家政と（慣習の範囲で）王国会計に強い発言権。  
- ただし広域税や大戦争は**貴族・議会・都市**の同意・交渉が絡む。  
- 官職（尚書・元帥・家宰）は「部門予算口座の所有者」というより、**王の名における執行者**。

#### D. 為政者の私財

- 王が「ポケットに金貨数百枚」を常時持つイメージは史実的に弱い。  
- 豊かさは **所領・権限・信用（借入能力）・家政の規模** で測られる。  
- 現金が薄い王でも、戦時に関税や補助金で巨額を動かす。

**ゲームへの含意**

| 望ましい見え方 | 個人 wealth だけを厚くする案 | より史実的な案 |
| :--- | :--- | :--- |
| 「豊かな王」 | cap を上げる | **家政口座＋国庫**を UI で見せ、Monarchy は家政シェア大 |
| 戦争できる | 個人から支出 | **国庫／戦時特別**から支出 |

---

### 2.2 Republic（共和制・都市共和）

#### A. 歳入源

| 種類 | 位置づけ |
| :--- | :--- |
| 港湾関税・取引税・入市税 | **本体**になりやすい |
| 都市財産・公有地・塩など独占 | 市の資産収入 |
| 強制公債・国債的債務 | 戦時・艦隊整備で巨大化 |
| 人頭・直接税 | あるが、商業都市では間接税比重が高いことが多い |

**示唆**: 現行の「Republic = 低 sales + 中程度 poll」は方向として sales を厚くしてもよい。Republic の「薄税」イメージは、**元首への集中**が薄いことと混同しやすい。

#### B. 金庫構造

- **市／国の公庫**が主役。元首個人の金庫は副次。  
- 評議会・十人会・艦隊委員会など**目的別会計**が並ぶことがある。  
- 商人資本（個人・家）は公庫と別だが、貸付・請負で接続する。

#### C. 支出権限

- 大きな支出は**合議・任期制官職**の承認が前提、という理想型。  
- 傭兵隊への支払いは遅れれば契約破棄・クーデタリスク（既存設計書 §1 と同旨）。  
- 諜報・外交・官僚機構への経常支出が厚い。

#### D. 為政者の私財

- ドージェ／首長は**俸給制の公職者**に近く、個人への富の集中は警戒対象。  
- 「元首の所持金が国庫より少ない」のは**健全**と見なされうる。  
- 真の富裕層はしばしば**商人・名門家**（ゲームでは Market manager / rival 側）。

**ゲームへの含意**

- 現行の household 5%・chancery 厚めは史実方向と整合。  
- 為政者個人 wealth が薄いのは Republic では**問題になりにくい**。  
- 不足感が出るなら、見せるべきは **公庫と商会資本**。

### 2.3 Theocracy（神権）

#### A. 歳入源

| 種類 | 位置づけ |
| :--- | :--- |
| 十一税・初穂・免役的貢納 | 信徒・土地に紐づく**宗教歳入** |
| 教会荘園・聖職禄 | 司教座・修道会の家産 |
| 巡礼・免償・手数料 | 宗教サービス収入 |
| 世俗税・関税 | 教皇領などでは世俗支配として併存 |

**示唆**: 通常の poll/sales と同じパイプに全部流すと、「教会会計」の味が消える。少なくとも **Ecclesiastica 向け歳入ラベル**か別プールがあると史実的。

#### B. 金庫構造

- 教皇庁の **Camera Apostolica（使徒会計院）** のような中央教会会計が史実モデル。  
- 司教区・修道会は**半独立の会計**を持つ。  
- 世俗の「国庫」と宗教会計の境界が、形態のコア。

#### C. 支出権限

- 聖堂・救貧・聖職者・法（教会法）・巡礼インフラ。  
- 軍事は騎士修道会・臨時十字軍・世俗諸侯への依存が多く、**常備 Marshalcy が薄い**のは妥当。  
- 聖戦時は教会会計と軍事が一時的に合流しうる（既存の War Footing 議論と接続）。

#### D. 為政者の私財

- 教皇・高位聖職者は奢侈のイメージもあるが、制度上は**職務財と私財の峻別**が建前。  
- 個人 wealth より **教会庁予算の厚さ**が「豊かさ」の指標。

**ゲームへの含意**

- ecclesiastica 48% の支出表は「符号」として良い。  
- 歳入が Monarchy と同じ式なのが弱い。  
- 為政者個人 cap を上げるより、**教会会計の可視化**が効く。

---

### 2.4 Union（連合・複合体）

#### A. 歳入源

- 中央は関税・郵便・一部独占・分担金・戦時補助金など**限定的**。  
- 各構成国・領邦は**独自の税と議会**を持つ（ハプスブルク複合君主制など）。  
- 資金を領邦間で移すのは交渉事であり、自動プールではない。

#### B. 金庫構造

- **単一国庫が存在しない／薄い**のが本質。  
- 中央金庫 + 構成国金庫 +（王朝家産）の多層。  
- 研究上も「中央 treasury だけ見て複合君主制を測ると誤る」と指摘される。

#### C. 支出権限

- 中央: 外交・王朝・限定的軍事・調整コスト（chancery 厚いは既存設計と一致）。  
- 軍事は構成国分担や貴族召集に依存し、中央為政者の**私兵基盤が弱い**。  
- 属国（Vassal）は宗主が軍事を抑え、防衛を外注する関係と相性が良い（既存 structural multiplier の史実根拠）。

#### D. 為政者の私財

- 同君連合の君主は**複数の「王冠」ごとの収入権**を持つが、それは一つの Character.wealth ではない。  
- 中央元首のポケットが薄いのは自然。豊かさは**どの領の会計に手が届くか**。

**ゲームへの含意**

- 単一 `state.treasury` は Union 表現として最も苦しい。  
- 中期目標: **構成 state 間の上納・分担・送金**（burg-treasury 設計で保留されていた政体上納と接続）。  
- 個人 wealth 増額は優先度低。

---

### 2.5 Anarchy（無政府・軍閥）

#### A. 歳入源

- 正規税より **保護料・略奪・通過税・臨時徴発**。  
- 帳簿上の pollTax=0 は「制度がない」表現として既に近い。

#### B. 金庫構造

- 公金と私財の境界が溶解。  
- 「国庫」は従士への分け前プールに近い。

#### C. 支出権限

- 支出 ≈ 配下の維持。削ると離反（既存設計書の「最も削れない軍事」）。  
- 行政・教会への経常支出はほぼ消える。

#### D. 為政者の私財

- **私財と軍資金が同一**に見えやすい。  
- ここだけは Character.wealth と state.treasury を近づける／同一視するデザインが史実的。

**ゲームへの含意**

- Anarchy では個人 cap と国庫の分離を緩める選択肢がある。  
- 他形態と同じ生活費・同じ部門表は味が薄い。

## 3. 対照マトリクス（要約）

### 3.1 歳入（通常の中心）

| 形態 | 史実的中心 | 現行 FMG | ギャップ |
| :--- | :--- | :--- | :--- |
| Monarchy | 所領・関・特権＋臨時賦課 | poll + sales | 所領/特権が薄い。poll が常時主軸 |
| Republic | 関税・取引・公債 | 同上（sales 低め） | 公債・市有財産なし。sales が主軸になりきっていない |
| Theocracy | 十一税・聖職禄・教会荘園 | 同上（sales 高め） | 教会歳入のラベル/プールなし |
| Union | 構成国税＋中央の限定収入 | 同上を state 単位で独立 | 上納・分担・多会計なし |
| Anarchy | 略奪・保護・臨時 | poll/sales 0 | 略奪・保護収入が制度として弱い |

### 3.2 金庫

| 形態 | 史実 | 現行 | ギャップ |
| :--- | :--- | :--- | :--- |
| Monarchy | 家政 / 王国 | `state.treasury` 1本＋個人 wealth | 家政口座なし |
| Republic | 公庫優位 | 同上 | 公庫と元首の分離は % のみ |
| Theocracy | 教会会計＋世俗 | 同上 | Camera 的分離なし |
| Union | 多層・多領邦 | state ごと 1本 | 連合中央会計なし |
| Anarchy | 公私混線 | 同上 | 分離が強すぎる可能性 |

### 3.3 支出権限・為政者の「使える金」

| 形態 | 為政者が自然に使えるもの（史実理想型） | 現行でプレイヤーが主に見るもの |
| :--- | :--- | :--- |
| Monarchy | 家政＋（制限下の）国庫 | 個人 wealth（薄い）＋隠れた state.treasury |
| Republic | ほぼ公庫のみ（合議） | 個人薄い＋公庫は UI 依存 |
| Theocracy | 教会庁予算 | 個人薄い＋部門は名目 |
| Union | 領ごとの会計の一部 | 自 state の treasury のみ |
| Anarchy | 手持ち＝軍資金 | 個人＋薄い国庫 |

### 3.4 個人 wealth の史実的「厚み」

| 形態 | 個人 cash が厚いべきか | コメント |
| :--- | :--- | :--- |
| Monarchy | **中**（家政は厚いが私室金とは限らない） | 見せ方は家政口座が本命 |
| Republic | **低** | 薄いのは妥当 |
| Theocracy | **低〜中** | 教会会計が本体 |
| Union | **低**（中央） | 領収入は別 |
| Anarchy | **高／国庫と一体** | 例外的に個人＝権力 |

→ 「為政者全員の個人 wealth が金貨数枚で足りない」は、**Republic/Theocracy/Union では必ずしもバグではない**。違和感の中心は **Monarchy（と Anarchy）で公金が見えないこと**。

## 4. 現行実装との対応（ギャップ一覧）

コード上の事実（2026-08 時点の理解）:

| 項目 | 形態差 | 備考 |
| :--- | :--- | :--- |
| `DEFAULT_TAX_BY_FORM` | 税率の種のみ | 歳入の**種類**は共通 |
| `collectTaxes` | 共通パイプ | 議会・請負・関税吏なし |
| `BASELINE_ALLOCATION_BY_FORM` | 部門% | 名目。部門残高なし |
| 個人俸給 clamp | ほぼ共通 | Monarchy 家政だけ cap 内で厚くなりうるが上限 5 SP/cycle |
| 属州領主 | 共通 | Burg から固定個人俸給。領支出権限なし |
| 上納・分担 | ほぼなし | 設計上の将来課題 |

部門表と税率に史実メモは既にあるが、**「入り方・財布の個数・権限」は未分化**——ユーザーの直感と一致する。

## 5. まだ調査が足りない点（オープン）

実装前に深掘りすると効く論点。

1. **非ヨーロッパ形態**  
   カリフ制・中華王朝・日本の幕藩などは formName で触れるが、本ノートは欧州中心。拡張時は別表が必要。  
2. **戦時財政**  
   補助金・強制公債・軍票・略奪の一般化。War Footing と接続。  
3. **請負（tax farming）**  
   徴税権売却は商人・領主を豊かにするが state 現金を前借りする。Market/Guild との接続候補。  
4. **債務**  
   都市共和と近世君主の「豊かさ」はしばしば借入能力。treasury 残高だけでは測れない。  
5. **属州／辺境**  
   領主が地代を取り、中央へ定額を送るモデル vs 中央直轄徴税。  
6. **数量感**  
   本ノートは構造が主で、SP 換算の史実キャリブレーションは [character-wealth-balance.md](./character-wealth-balance.md) / [cost-of-living.md](./cost-of-living.md) と別作業。

## 6. 設計への推奨（調査結論 → 次の B へ）

優先度付き。実装コミットはしない。

### P0 — 認識と UI（コード少）

1. 為政者・Treasury UI で **個人 wealth / state.treasury / 部門名目** を並記し、「王が貧乏」誤読を防ぐ。  
2. ドキュメントとツールチップで **Monarchy の豊かさ = 家政＋国庫** と明記。

### P1 — 会計の意味づけ（中）

3. **Household purse**（または household 名目の実残高）を Monarchy で厚く、Republic で薄く。個人 wealth はその一部または別口。  
4. 部門は「%表示」から、少なくとも **Marshalcy / Ecclesiastica など重要部門の実残高 or 使用可能額**へ。  
5. 領主: 個人俸給に加え **着任 Burg（将来 province）treasury への支出フック**。

### P2 — 歳入の形態差（大）

6. 歳入ミックス:  
   - Monarchy: 所領・関比重、広域 poll は戦時ブースト  
   - Republic: sales/関税・債務  
   - Theocracy: 宗教歳入 → Ecclesiastica  
   - Union: 構成国上納  
   - Anarchy: 略奪・保護、正規税ほぼゼロ（現状維持＋収入イベント）  
7. 徴税イベント: 議会同意失敗、請負腐敗、属国拒否など。

### P3 — 個人 wealth の再調整

8. **形態別**に個人 floor/cap を変える（Monarchy/Anarchy のみ厚く等）。  
9. 全形態一律に cap を上げるのは、Republic の史実イメージを壊しやすいので最後。

## 7. 一文まとめ

史実では、為政者の「手元の金貨」より **どの名義の金庫を、誰の承認で使えるか** が統治力の本体である。  
現行 FMG は形態差を**税率と支出%**に閉じ込め、**歳入の種類・金庫の分割・権限**を共通化している。  
したがって次の本丸は個人 wealth の底上げではなく、**形態別財政レジーム（多財布＋権限）の設計**である。本ノートはその調査土台とする。
