# 灰と炭酸カリウムの使い道（2026-11-09）

石鹸は、酒の器（陶器・ガラス）を作るための灰を安定して供給する目的で入れた。贅沢品としての石鹸がその役を負えるかを確かめるため、灰・炭酸カリウム・ガラスの流れを使い道ごとに足した。コードは変えていない。

## 1. 条件

- 出力は[grain-quarter-day-20261109.md](grain-quarter-day-20261109.md)の`quarter-2102.json`と`quarter-2103.json`（北緯30°の地図2枚、`barillaflow.mts`の財の流れ）。13〜24か月目の和。
- 陶器（`Ceramics`）のレシピは粘土だけ（`{ Clay: 1 }`）で、灰を使わない。

## 2. 結果

- 町の炭酸カリウムの99%は石鹸に使われ、ガラスは1%に満たない。
- ガラスの大部分は森のガラス小屋（自分の木を焼いて炭酸カリウムを作り、市場の灰を使わない）と船の持ち帰りから来る。
- 陶器は灰を使わない。
- 町の炉の灰は、使う量の3か月分まで市場が買う（[wood-ash-potash.md](../plan/wood-ash-potash.md) §3.2）。灰を使う前の市場も炭酸カリウム1樽分は買う。灰の供給は、石鹸が無くても使う量に応じて数か月で立ち上がる。

## 3. 結論

- 今のモデルでは、石鹸は酒の器のための灰を支えていない。炭酸カリウムのほぼすべてを、石鹸そのものが使っている。
- 町の石鹸の量（町の人1人年2 kg、1793年のイギリス）は、炭酸カリウムの需要のほぼすべてを決めている。中世の量に下げると、町の炭酸カリウムはガラスの分（年数十樽）だけになる。
- 器のガラスに炭酸カリウムが要るなら、灰の供給は炉の灰の買いの仕組みで足りる。
