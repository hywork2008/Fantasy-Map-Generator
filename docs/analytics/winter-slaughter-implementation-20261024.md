## 稼働する条件での検証

`winterSlaughter.test.ts`では、飼料不足と実頭数・労働・材料・保管枠を明示した入力で、老齢群と更新余剰youngだけの整数屠畜、保護群の残存と給与不足、最小必要頭数、同じ部位の二重使用防止、給与必要量の減少、期限/処理損失を確認。15テスト成功。年月・地域に校正済みの実績値として採用する試験ではない。

`winterSlaughterSettlement.test.ts`では、実Economy sliceの群れ・Salt stock・農村財布・市場財布を使う。処理後の実群れから当月の給与を計算し、塩の実使用と現金の送受一致を検証。禁止種、無効/簡易モード、既存ジョブを残して無効化した場合と早送りの物理決済要否も検証した。

`winterSlaughter.node.test.ts`では固定Province上の一世帯だけに、明示したテスト用の豚・労働・材料・初期財布を置き、実ホストの決済→加工中アーカイブ保存再読込→同期間の再実行→完成/自家消費→再保存を通した。群れ・材料・現金の再控除、完成肉の二重発生が無いことを確認。これらの人工的な初期条件を自然入力の供給増とは混同しない。

関連する牧畜・農村職業配分・生産・由来保存・オプション入出力・共通解体・早送り・食料観測のテストが成功。型チェック、変更ソースのBiome、差分空白、既存許容一覧を維持したシミュレーション境界チェック、Economy拡張のVite buildも成功。全件テストや多数シードは実行していない。Worldの追加12か月比較は中止し、未完了の結果は採用していない。
