# E1: 群れの更新を職業の割り当ての前に回す（2026-10-27）

親計画§7.59の検証記録。§7.58で、年次処理の職業の割り当て（`updateAnnualAgriculture`）が群れの出生・加齢（`updateAnnualFaunaCohorts`）より先に走り、出生前の群れの分しか牧畜の暦を取らないことが分かった。`src/extensions/economy/simulation.ts`の年次処理で、群れの更新を割り当ての前に移した。前の値は§7.54のafter（同じ固定入力・48か月）。

## 判定

順序の変更は維持する。牛の頭数が前の水準を超えるか、および残る不足1.4%（森林系の畑仕事との重なり）は、より長い期間で確かめる。

## 追加: 96か月（親計画§7.60）

同じ変更のまま World を96か月進めた（頭数: `world-after-96.json`、主ホスト・上限1.5GB。飼料不足: `world-feed-96.json`、計測専用機・上限6GB）。

- 牛は1306年（72か月）に前の水準（約15頭）を超え、1307年に16.0頭。
- 85〜96か月の飼料不足は0.9%（48か月時点1.4%）。全量が干草の人手で、割り当て時/干草の時点の必要人数は1.03倍とそろったまま。干草の月に畑仕事だけで手が埋まる月が残るのは温帯雨林・火山性土壌などの森林系で、確保率は0.84〜0.92。
- 1307年の収容力の落ち込み（1,095→693千頭）は、85〜96か月の不足が小さいため、前年の給与率による恒常的な制限ではない。73〜84か月の一時的な要因と見られ、翌年に822千頭へ戻り始めている。原因はこの計測では区間外で、特定していない。

判定: 順序の変更は維持する。前年の給与率による制限は、不足が1%前後になった今は見直さない。
