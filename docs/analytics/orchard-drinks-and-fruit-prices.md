# T14: 果樹園の収穫・Cider/Perryと林檎・梨の価格

2026-10-22。[残課題T14](../plan/goods-physical-units-remaining-tasks.md)の計測・史料調査。初回調査では価格・レシピ・需要・通常の生産処理を変更していない。追加依頼による修正と再計測は§6。

## 1. 数量付きの価格史料

Alicia Amherst, *A History of Gardening in England* (1895), Chapter IIに、英国王室の果物購入会計の抜粋・翻訳がある。単なる贈答への謝礼と異なり、次の記載は果物の数量と価格を対応させている。ただし王室向けの品種別購入であり、醸造用の産地価格には置き換えない。

| 年代・場所・品 | 記録の数量・価格 | 原単位での比較 |
| :--- | :--- | :--- |
| 1292–1293、Berwick、Costard apples | 300個、100個あたり12d | 林檎0.12d/個 |
| 同じ送荷、Regul pears | 700個、100個あたり3s | 梨0.36d/個。上の林檎の3倍/個 |
| 同会計、Bernwellへの送荷、apples | 900個、100個あたり3d | 林檎0.03d/個 |
| 同じ送荷、Regul pears | 100個あたり10d | 梨0.10d/個。上の林檎の約3.33倍/個 |
| 同会計、Calluewell / pas pucell pears | 100個あたり4s / 2s | 品種による差もある |
| 同会計、York、gold knopes pears | 6,000個、100個あたり2d | 高価な梨だけの一律価格にはできない |

[抜粋・翻訳と典拠](https://bookdome.com/gardening/History-Gardening-England/Thirteenth-Century-Part-3.html)。同書の典拠表示は Exchequer, Treasury of the Receipt Miscellanea, 49/24, 20–21 Edward I。運搬・籠・紐の費用は別の行にも記される。現物の会計原本画像との字形の再照合は行っておらず、ここでは刊本の翻訳による確認とする。

さらに、王名の欠けた治世7年の会計(同書はおそらく1223年と推定)には、4月20日「Pois」向けの林檎600個12s、S. Ruleの梨100個10sがある。数量・支出はあるが、年の同定には留保があり、パリから王室へ届ける高級果実の購入である。[同書の説明](https://bookdome.com/gardening/History-Gardening-England/Thirteenth-Century-Part-2.html)

19世紀の比較資料として、Henry Mayhew, *London Labour and the London Poor*, vol.1の果物売り調査は、ロンドンの街頭小売の林檎平均4s/bushel、梨は通常それより9d/bushel高いと記す。林檎48dに対し梨57d、容量建てでは約1.19倍。ただし梨は同じbushelに入る個数も違うとされ、輸入品の箱と市場bushelの差、林檎の藁詰めにも言及する。kg単価・中世の卸価格には変換しない。[当時の調査本文](https://victorianlondon.org/publications/mayhew1-3.htm)

### モデル値との区別

- 現行Applesは0.7 / 1,000 kg、Pearsは0.8 / 1,000 kg。1 kgあたりでは0.0007と0.0008、梨/林檎は約1.14倍。**どちらもモデル値を維持する。**
- 上の中世史料は個数建てで、1個の重量がない。19世紀史料も果実別のbushelのkg換算がなく、同じ実物量で穀物と比較できない。中世の品種差や王室購入を均一な1 tの醸造原料に適用しない。
- 「中世英国の林檎が麦より安いので0.7」という§29の見込みは、今回も確定できない。Cider/Perryの原価を成立させるために決めた値と史料値を区別する。史料が未換算だからといって、同額の果実を使う製法で価格を上げ下げすることも行わない。

## 2. 計測の方法と対象

再現用スクリプトは[scripts/observeOrchardDrinks.mts](../../scripts/observeOrchardDrinks.mts)。通常のNodeシミュレーションで36か月を1か月刻みに進め、実収穫・市場への供給・購入に相当する消費フロー・価格・在庫・照合・出発を別々に記録する。果実のセル内実収穫は `cumulativeCellFoodFlows.harvested` の開始時からの差であり、市場の `source:ruralHarvest` と同一視しない。

入力は作業用に残っていた `world-102.fmg`。Standard、populationRate=1000、Historical period=`ageOfExploration`、暦1929-01-01〜1932-01-01、長距離交易あり、盗賊なし。基準リビジョン・入力SHA-256・実行ごとの生サンプルSHA-256・月次集計を[計測JSON](orchard-drinks-observation-20261022.json)に記録する。古い§29の入力と同一ではなく、§29前後の価格変更を因果比較する試験でもない。

- **通常入力**: 気候・商品・在庫・労働を変更せず計測。
- **梨の検証用コピー**: 同じ入力に `--pear-fixture` を指定。人口と国家があり、既存の作物選択処理が梨を選ぶgridセルを順に最大12個選び、その降水量を8(800 mm相当のproxy)にする。元の値と変更先のセルIDをJSONに記録。果実在庫・レシピ・価格・労働力を注入しない。気候変更は他の作物等にも影響するため、通常地図の梨の頻度や両実行の差の因果分離には使わない。

```sh
node --import tsx scripts/observeOrchardDrinks.mts world-102.fmg /tmp/orchard-natural.json
node --import tsx scripts/observeOrchardDrinks.mts world-102.fmg /tmp/orchard-pear.json --pear-fixture
```

果樹園の選択面積は人員充足前の値。実収穫があることを別に確認する。市場在庫はセルの私的な食料備蓄を含まない。フローの評価額は記録時の価格での在庫評価であり、現金支出ではない。市場価格も売買成立価格とは区別する。

## 4. 経路の評価

`markets-generator.ts` の生鮮食品処理を追跡した。

1. Apples/Pearsは `freshFood`。通常は生のまま市場共通在庫へ供給せず、産地セルの生食・保存・確認済み商用加工需要に収穫量を配分する。冷蔵輸出は別経路。
2. セルの備蓄用加工先は `isPreservedFoodGood` から選ぶ。Apples/Pearsは `Dried Fruits` に接続する。
3. `getCellFoodCommercialPath` は `grapeWine` に該当する加工先を優先し、それ以外は備蓄用加工先に戻る。Cider/Perryのタグは `food, beverage` であり、この商用加工先には入らない。
4. Cider/Perryの都市レシピ自体は存在し、各1,000 Lに果実1.5 tとBarrels 0.4 lotを必要とする。しかし、都市の通常生産は市場から原料を取得するため、生果実が市場へ来ないと起動しない。

この構造では、果樹園があることと醸造原料が使えることは一致しない。価格0.7/0.8を変更しても、物理的な供給経路の欠落は解消しない。醸造を有効化する次の実装では、産地セルでの商用圧搾・発酵を接続し、生食・非常備蓄との優先順、確認済み飲料需要、樽の修繕・返却台帳、原料の二重使用を確認する必要がある。既存の葡萄例外へ品名だけを追加して、樽材料なしに酒を発生させる変更は行わない。

また `foodProcessingLedger.ts` はMilk/Cheese/Grapes/Raisins/Wine/Beerだけを追跡し、Apples/Pearsの `recordFoodProcessingConsumption` は早期returnする。したがって果実の `processed` の欠測を「加工0」と読まない。今回の実収穫はこの早期returnの前段で記録される `harvested` を使う。セル内生食の購入額や生果実の実取引価格もこの計測からは得られない。

## 5. 判断・検証

## 6. 経済モデルの修正(2026-10-22、追加実装)

§1〜§5は修正前の調査記録。追加依頼を受け、次を修正した。

### 価格とレシピ

- 果実の価格0.7・0.8は引き続きモデルの基準値。空の市場共通在庫を品薄と誤認しないよう、林檎・梨の提示価格はこの産地基準値×貨幣価格水準へ平滑化する。地域の空在庫による上乗せも除外する。これは市場に出ない生鮮原料の参考価格であり、史料から中世のkg単価を確定した変更ではない。
- Cider/Perryの価格は果実と樽修繕材の原価に加えて、その飲料の具体的な月次需要と在庫に応じて動く。生産側も原料評価額と補助材料価格を含めて10%以上の加工余剰を必要とし、赤字の商用加工を始めない。
- 醸造の物量は1,000 Lに果実1,500 kg、樽修繕材0.4 lotを維持し、`foodLots.ts` に集約した。FAOの近代的な林檎圧搾の例690〜770 L/tに対し、現行666.7 L/tは近似のモデル値として扱う。中世の実測歩留まりや梨の実測値とはしない。搾りかすは葡萄専用のPomaceに加算しない。[FAO、13.6.2](https://www.fao.org/4/y2515e/y2515e15.htm)
- 干し果物250 kgに必要な林檎4,000 kg→2,400 kg、梨4,000 kg→2,333.33 kg。CSU Extensionの採取時からの乾燥歩留まり(林檎12 lb→1.25 lb、梨14 lb→1.5 lb)を使用する。皮・芯等の調製損失も含む現代資料で、中世の設備を直接再現する値ではない。他の果物の経路は今回の校正対象にしない。[CSU、Table 1](https://extension.colostate.edu/resource/drying-fruits/)

### 需要と生産

- 生食は年1人あたり林檎6 kg・梨3 kgを継続。生食・非常備蓄の原料を先に確保し、同じ収穫を重ねて醸造に使わない。
- Ciderは成人あたり年6 L、Perryは3 L、成人比率0.65という明示したモデル需要を追加する。史料による全国平均消費量ではない。既存Beer需要は変更せず、今回の嗜好飲料需要を独立させる。家計の残り需要・在庫で実消費を決め、世界市場の輸入需要と提示価格にも同じ月次量を使う。
- 収穫期以外にも飲めるよう、醸造の在庫上限は月次需要12か月分。都市の持つ私的な原料・製品在庫も通常生産の上限判定に含む。人口が0なら追加生産の余地は0。
- 林檎・梨の産地セルの商用加工先をCider/Perryへ接続する。生食・備蓄の後、加工労働、需要上限、共有市場の樽材料、採算で出力を制限する。必要な修繕材は同じレシピから実際に引き落とし、別のセルや都市の加工と二重使用しない。市場内の加工材料の在庫変換として記録し、新しい現金取引や支出は捏造しない。
- 材料を引いた後にのみ飲料を市場へ置き、filled lot・修繕材・実消費による返却を飲料別の容器台帳へ記録する。都市側で醸造する場合も同じ台帳と上限を使う。返却は空樽素材の新規生産ではない。遠隔地での容器所有・返送の完全な追跡はT20の範囲を維持する。
- 2.5 Lのような少量の出力も在庫・生産累計で小数第2位に丸めない。原料の実収穫・加工・セル内生食と、市場への出力・市場での消費を別々に計測する。従来の果実加工カウンタの欠測も解消した。

### 既存セーブ

既存の果実・飲料の単位と数量は今回変更しない。カタログ移行でCider/Perryの商用タグと、干し果物の林檎・梨レシピを接続する。保存済みの商品IDを使い、既存の在庫やセル備蓄を再換算しない。容器台帳の新しい欄は必要になった時に追加する。旧来の量を新規の容器出費として遡及請求しない。
