# 開始時の貨幣と国庫の大きさ（2026-11-17）

[per-capita-income-scale.md](../plan/per-capita-income-scale.md) §5.3 の前に、今の貨幣と国庫の大きさを数えた。新しい計測はせず、[tailoring-20261117.md](tailoring-20261117.md) の出力（地図2103、36か月）を読んだ。

## 1. 結果（3年目）

| | 値 | 目安（§5.3） |
| --- | ---: | --- |
| 1人あたりの GDP | 主食の1.89年分 | 史実（1500年ごろ）5〜6年分 |
| 貨幣の合計 | 約245万 = GDP の約4.3か月分 | 3〜4か月分 |
| 国庫の合計 | 約81万 = 年の収入（約25万）の約3.2年分 | 1年分未満 |
| 公共の支出（1年目 / 2年目以降） | 約63万 / 約28万 | — |

国庫の推移: 1か月目 110万 → 6か月目 86万 → 12か月目 83万 → 36か月目 81万。

## 2. 仕組み（`taxes-generator.ts`）

- 国が余りを使い始める線（`reserveTarget`）は、次の大きい方。ただし国の貨幣の30%まで。
  - 年の収入 × `STATE_RESERVE_YEARS`（2年）
  - 人口 × `stateTreasuryPerPopulation`（8、`economyStartMode.ts` の balanced）
- 線を越えた分の25%を、毎月、国の家計へ払う（`publicSpending`）。
- 地図2103では人口の項（約81万）が収入の項（約50万）より大きく、国庫は人口の項に張り付いている。
- 開始時の国庫も人口 × 8 × 貨幣の倍率で、線より約30万多い。この差を1年目に使い切るのが、1年目の公共の支出の山になる。

## 3. 読み取り

1. 国庫が年の収入の3年分あるのも、1年目の支出の山も、`stateTreasuryPerPopulation` 8 が開始時の額と使い始める線の両方に使われていることによる。
2. 8は [initial-wealth-calibration.md](../plan/initial-wealth-calibration.md) §7.4 で、当時の経済の落ち着く先（国庫 7.5〜11/人）から逆算した値。その後に収入の側が変わり、今は収入の年数で見て大きすぎる。
3. 貨幣の合計（GDP の4.3か月分）は目安に近い。国庫の分（約81万）を家計へ移しても、合計は変わらない。

## 4. 直し方の案（未実施）

- 使い始める線を、収入の年数だけで決める（人口の項をやめる）。`STATE_RESERVE_YEARS` を設定にし、既定を1年未満（例: 0.75年）とする。
- 開始時の国庫を、見込みの年の収入 × 同じ年数にする。開始時に線を越えないので、1年目の山が消える。
- 減らした分は家計の開始時の額へ移し、貨幣の合計を保つ。
- 中世の王の国庫が年の収入より小さかったこと（借入・前借りで賄った）は記憶による理解で、史料は確かめていない。
