# 町の石鹸の作り手の計測（2026-11-09）

## 2. 石鹸

単位は樽。13〜24か月目。

| | 2102 base | floor | 2103 base | floor |
| --- | ---: | ---: | ---: | ---: |
| 町の買い物（柔らかい石鹸） | 3,320 | 7,358 | 2,063 | 4,699 |
| 町の買い物（白い石鹸） | 114.5 | 86.6 | 33.1 | 23.5 |
| 需要を満たした割合 | 10.3% | 22.3% | 9.3% | 20.9% |
| 炭酸カリウムの生産 | 853 | 1,181 | 516 | 744 |
| うち石鹸の材料 | 774 | 1,132 | 449 | 727 |
| 炉の灰の買い入れ（袋） | 26,808 | 58,389 | 17,008 | 35,675 |

- 石鹸の買い物は約2.2倍になった。作った石鹸はその月に全部買われ、在庫は24か月目も0。
- 柔らかい石鹸は、2102で8〜14℃の市場から運び出された（13〜24か月目に43樽）。
- 白い石鹸は約25%減った。油とバリラを持つ市場は限られ、柔らかい石鹸の手が増えた。
- 炭酸カリウムは、作った量の96〜98%が石鹸に使われ、24か月目の在庫は44・17樽（baseは55・29）。灰の在庫は1万7,029袋・9,558袋に増えた。今の石鹸を止めているのは炭酸カリウムの生産で、灰ではない。`Potash`は校正の表に無い品で、町は利益でほかの品と比べて作る。
- 獣脂の在庫と値段は変わらない。

## 3. 結論

- 石鹸2つの校正の行は残す。石鹸の買い物は需要の約1割から約2割になった。
- 次は、炭酸カリウムの作り手を、市場の石鹸の最低量から決める（石鹸の材料の分）。
