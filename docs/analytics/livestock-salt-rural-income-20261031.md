# 家畜の塩の不足と農村の現金収入（2026-10-31）

固定入力: `docs/analytics/inputs/wet-pastoral-birth-20261029/world-102.fmg`、平和モード（`FMG_CONFLICT_AUTONOMY=peace`）、冬の屠殺は`off`。作業ツリーはf9f9fd1d2に未コミットの変更（新市場への穀物の移転、世界の誕生時の畑、塩の値段の扱い）を加えたもの。

## 1. 不足を止めている上限

`saltLogistics.ts`の家畜の塩は、必要量・在庫（人の分を除く）・お金（財布の5%＋掛けの枠）の最も小さい量を買う。計測のため、`livestockLimit`の直前に3つの上限を`globalThis.__saltDiag`へ書き出す1行を一時的に入れた（計測後に削除。再計測にはこの1行が要る）。

- 24か月のすべての不足が「お金」の上限による。在庫の上限は13・14か月目の市場22（127・48袋）だけ。
- 不足は6月から増え、10〜11月に約4千袋/月、1年目の12月と2年目の1月に減って、2年目の10月に5.1千袋/月。
- 2年目は、市場1・13・19・11・22で、財布の5%の枠が全部掛けの返済に使われ、新しく払える額が0になる（掛けは3か月分の上限に張り付く）。

## 2. 農村の現金収入（1年目、世界）

農村の財布へ入るお金は年0.68百万。出どころは、穀物の代金（`foodProduction`、1〜2月と12月に集中）、その掛けの返済（`foodLedgerConsumption`）、干し草の売り上げ（`livestockFeed`、11〜12月）、木材（`heating`）、国の給金（`householdWealth`の`payStateHouseholds`）。

家畜の塩の代金（必要量×値段）は、市場ごとの年の現金収入の21〜53%（市場1: 41%・33%）。

## 3. 塩の量と値段は史料に合う

- 塩の量は1人あたり年約7.4 kg（人3.6 kg＋家畜3.8 kg）。ネッケルの安い塩の地方の8.8 kg（[計画](../plan/salt-supply-calibration.md)§3.10）より少し少ない。
- 値段は1 kgあたり穀物の3.5倍（`goods-generator.ts`、goods-physical-units.md §22）で、今は基準の1.03〜1.09倍で動いている。
- 1人あたりの塩の費用は穀物の年の費用の約13%、そのうち家畜の分は約6.7%。

## 4. 原因: 農村から市場へ出た産物の代金が農村へ入らない

`markets-generator.ts`の`addRuralOutput`は、農村の産物を市場の在庫へ加えるだけで、代金を払わない。代金を払うのは、穀物（`settleFarmgatePayment`、値段の80%）、干し草（`livestockFeed.ts`）、木材（`heating.ts`）だけである。

市場の在庫が売れると、代金は全額が市場の金庫に入る（`marketPurchases.ts`）。金庫の準備金を超えた分は、`payOutMarketSurplus`が「小売と農場渡しの差」として町の給金と商人の利益に配る。家畜などについては農場渡しの支払いが無いので、売り上げの全額が町へ行く。

1年目に農村から市場へ入った産物の値打ち（その月の市場の値段）は年2.68百万で、農村の現金収入（0.68百万）の約4倍。

| 鶏 | 774 |
| 牛 | 536 |

市場1では、年の値打ち335千（鶏122千、羊103千、牛66千）に対して、現金収入は61千、家畜の塩の代金は25千。

家畜を飼う費用（塩・買う飼い葉）は農村が払い、家畜を売った代金は町へ行く。このため、家畜の塩の不足は、財布の5%という割合の問題でも、塩の量や値段の問題でもなく、家畜を売っても収入が無いことによる。[冬の屠殺の計画](../plan/winter-livestock-slaughter-and-preservation.md)の「販売代金は売り手へ」、[羊毛の計画](../plan/wool-products-and-sheep-husbandry.md)の残りの課題「農村製品の販売」と同じ穴である。

## 5. 納めた時に払う試み（取り消した）

`addRuralOutput`で、木材と泥炭（暖房で売れた時に払う）を除く産物に、市場の値段の80%（`FARMGATE_PRICE_SHARE`）を金庫から払い、足りない分を`ruralGrainPayable`の掛けにする変更を試した。24か月の結果:

| | 変更前 | 変更後 |
| --- | ---: | ---: |
| 金庫の現金（世界、10か月目） | 152千 | 0.8千 |
| 農村への掛け（同） | 0 | 749千 |
| 農村の財布（同） | 201千 | 367千 |
| 家畜の塩の不足（2年目10月） | 5.1千袋 | 6.4千袋 |

金庫の現金は1か月目からほぼ0になり、支払いのほとんどが掛けになった。掛けは1年目の12月に852千に達し、1月の穀物の掛けの上限（`FARMGATE_PAYABLE_YEARS`）で543千に切られた。家畜の塩の不足は減らなかった。

理由は、市場へ入った家畜の値打ちのほとんどが、誰からも代金が入らない値打ちだからである（変更前の13か月の流れ）。

- 羊・牛・豚は、入った月のうちに全部`slaughter.ts`で獣脂と革に変わる（`recipeInput`）。肉の財が無いので肉は消え、市場に入るお金は獣脂と革の分だけになる。
- 鶏は毎月30〜48万羽が入り、売れるのは月80羽。市場の在庫は97万羽から13か月目には301万羽に増えた。

市場の値段で払うと、売れない分・肉として売られない分まで払うことになり、返せない掛けが積み上がる。そこで変更を取り消した。
