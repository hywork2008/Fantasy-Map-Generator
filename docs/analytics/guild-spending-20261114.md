# ギルドの金庫を町で使う（2026-11-14）

[guild-spending.md](../plan/guild-spending.md)の実装（`guildSurplusUse` spend）を、今までの決まり（keep）と比べた。

## 1. 条件

- コード: feature/fmg-economy-start-2のHEADに[fuel-price-share.md](../plan/fuel-price-share.md)・[peat-cut-plan.md](../plan/peat-cut-plan.md)と設計書の実装を加えたもの。凍結したworktreeで動かした。
- 地図2102・2103、36か月、戦争なし・隊商の略奪なし。
- keep: 2102は`FMG_GUILD_SURPLUS=keep`で動かした。2103は[peat-cut-plan-20261113.md](peat-cut-plan-20261113.md)のnew-2103（この設計の前の同じコード。ギルドの金庫は測っていない）。
- 測りは[goods.mts](guild-spending-20261114/goods.mts)（お金にギルドの金庫を加えた）、実行は[run.sh](guild-spending-20261114/run.sh)、手元に残す分の確かめは[reserve.mts](guild-spending-20261114/reserve.mts)。

| --- | ---: | ---: |

ギルドの金庫は増え続けた。1か月後のギルドの金庫は6,433あり、合計約4.4万（平均約7）で、手元に残す分（親方の手当の12か月分、201.6）を超えたのは4つだけだった。ほとんど使われないので、手元に残す分を設定（`guildReserveMonths`、既定1か月分）にし、毎月の割合を0.08にした（§3）。

## 4. 読み取り

1. ギルドの金庫は2年目の終わりから増えなくなり、2102で約17.5万、2103で約10.5万で落ち着いた。
2. 町の家計は36か月目に2102で+20%、2103で+23%になった。使ったお金は町の家計から市場（+11%・+9%）と農家（+8%・+8%）にも回った。
3. 同じ暦の月（13か月目と25か月目）で比べると、町の家計は2年目にまだ減る（2102: 485→391）。3年目（25→36か月目）は増えた。2年目の減り方は、ギルドの金庫が落ち着くまでの間と、ギルド以外の動き（[town-money-drain-20261114.md](town-money-drain-20261114.md)の人物の手元のお金の増え方など）と考えられる。
4. 作った品と使った品の差は2%以内だった。
