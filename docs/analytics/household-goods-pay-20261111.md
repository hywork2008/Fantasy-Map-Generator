# 家の品の払いと、積み上がる品（2026-11-11）

家の品の払い（Simulation settingsの`householdGoodsPayment`、既定`free`）を`pay`にした時の違いを測った。あわせて、ブラウザで何年も回した地図で革（Leather）の在庫が積み上がったことを受け、品ごとの在庫・値段・出入りを取った。

## 1. 条件

- 地図は北緯30°の2枚（2102・2103、[barilla-20261108.md](barilla-20261108.md)）、36か月、戦争なし・隊商の略奪なし。3年目（25〜36か月）を集計した。
- コード: コミットaa5cf2a29（[rural-town-spending.md](../plan/rural-town-spending.md)の実装の後）。凍結したworktreeで動かした。
- free: 既定。pay: 始めに`householdGoodsPayment`を`pay`にしたもの。
- スクリプトは[goods.mts](household-goods-pay-20261111/goods.mts)、実行は[run.sh](household-goods-pay-20261111/run.sh)、集計は[sum.py](household-goods-pay-20261111/sum.py)。
  - 毎月末に、品ごとの市場の在庫の合計と、基の値に対する値段の市場の平均を取った。
  - 品の物の出入りは、`setGoodFlowObserver`（[goodsBalanceLedger.ts](../../src/extensions/economy/generators/goodsBalanceLedger.ts)）で、向きと区分ごと（材料は、作る品ごと）に足した。
  - 市場の家の品の需要（`getMonthlyHouseholdDemand`）と、主な持ち手のお金も取った。

## 2. 家の品の払い（3年目）

満たした割合は、市場の在庫から家が取った量（`householdFood`）÷ 需要である。牛乳・林檎・梨・チーズは、ほとんどがセルの中で食べられて市場の在庫を通らないため、この測りでは比べられない（0〜2%と出る）。

| | 2102 free | pay | 2103 free | pay |
| --- | ---: | ---: | ---: | ---: |
| ワイン | 71% | 74% | 71% | 75% |
| シードル | 41% | 40% | 55% | 52% |
| 蜂蜜酒 | 70% | 44% | 75% | 36% |
| 干し葡萄 | 78% | 76% | 75% | 73% |
| 蜂蜜 | 92% | 90% | 89% | 85% |

お金（千、36か月目）。

| | 2102 free | pay | 2103 free | pay |
| --- | ---: | ---: | ---: | ---: |
| 農村の家計 | 292 | 424 | 152 | 225 |
| 市場のお金 | 871 | 955 | 452 | 527 |
| 町の家計 | 590 | 486 | 347 | 280 |

| 国庫 | 1,413 | 1,386 | 792 | 772 |

- payでは、町の家計が約2割減り、そのお金が市場と農村の家計に移った。
- 蜂蜜酒の満たした割合は、70〜75%から36〜44%に落ちた。値段で他の飲み物に移る仕組みが無く、払えない町の分がそのまま足りなくなる（[drink-price-allocation.md](../plan/drink-price-allocation.md) §2）。
- 農村の家計がpayで約45%多いのは、月の額のうち家の品に払えなかった分が残るためと見られる（未確認）。

## 3. 積み上がる品（freeの3年目）

### 3.1 革

| | 2102 | 2103 |
| --- | ---: | ---: |
| 在庫 12か月目 → 36か月目 | 223万 → 802万 | 115万 → 414万 |
| 1年に作った量（家畜をつぶした皮・狩り） | 290万 | 150万 |
| うち使った量（長靴・馬具・武具・市場の投資・輸出） | 5.7万（2.0%） | 1.9万（1.3%） |
| 値段（基の値の何倍、36か月目） | 1.72 | 1.94 |

- 革には作り方（recipe）が無い。皮は家畜をつぶした時（`settleSlaughter`、[slaughter.ts](../../src/extensions/economy/generators/slaughter.ts)）と狩り（[production-utils.ts](../../src/extensions/economy/generators/production-utils.ts)）に、頭数に比例して出る。需要も値段も見ない。
- 使い道は、長靴（2102で2.4万）、馬具（0.6万）、武具（わずか）、市場の投資（2.7万）だけで、作った量の約2%である。98%が在庫に積み上がる。
- 在庫が1年分の約3倍あるのに、値段は基の値の1.7〜2.0倍で、下がらない。

## 4. 読み取り

1. payを既定にするのは、まだ早い。お金は町の家計から市場へ移るが、値段で飲み物を選ぶ仕組みが無いため、蜂蜜酒の満たした割合が半分近くに落ちる。payは、飲み物の値段による配分（[drink-price-allocation.md](../plan/drink-price-allocation.md)）と合わせて入れるのが良い。
2. 革・獣脂・搾り滓のワインは、別の品を作ると一緒に出る品（副産物）である。作る量は主の品（肉・ワイン）で決まり、副産物の需要も値段も見ない。使い道が細く、作った量の95〜99%が積み上がる。
3. 在庫が何年分もあるのに、革の値段は基の値の1.7〜2倍で止まり、下がらない。値段の決まり（元値 + 上乗せ ×（需要+5）÷（在庫+5））で、元値（cost basis）が高く残っていると見られる。値段が下がらないので、安さで使い道が増えることも無い。これは、値段で需要と供給を釣り合わせるという今回の見直しの目的に、真っ向から反する。
4. 市場の在庫が無限に積み上がることは、長く回すと保存の大きさと計算の重さにも響く。

## 5. 次に調べること・直す候補

1. 副産物の値段がなぜ下がらないか。元値の付け方（つぶした家畜の値の割り当て）と、`relaxMarketPrice`の下限（基の値の0.25倍）に届かない理由を調べる。
2. 副産物の在庫の上限と処分。在庫が何か月分を超えたら、傷み・捨てる・安く売る（例：皮を肥料・膠・鞣さずに捨てる）。史料では、皮は鞣し屋（tanner）が買い、鞣しに半年から1年以上かかった。鞣しの量を、在庫の月数や値段で抑える。
3. 革の使い道を増やす。靴・ベルト・袋・鞍・水袋・本の装丁などの家の需要と、職人の需要。今は長靴・馬具・武具・本だけである。
4. payの既定は、飲み物の値段による配分の後に、もう一度測って決める。
