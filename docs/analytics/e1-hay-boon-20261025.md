# E1: 干草作りの近隣互助（2026-10-25）

親計画§7.49の検証記録。比較元は§7.48（[e1-hay-season-20261025](e1-hay-season-20261025.md)）。固定入力・設定は同じで、48か月まで実行した。

## 原因

`allocateRuralOccupations`では、牧畜の大人の日数は、その月の大人の作業可能日数から畑仕事などに予約済みの日数を引いた残りに限られる。干草作りの月は畑仕事が大人の日数をほぼ使い切っており、計画の約7割しか刈れなかった。隣接セルからの手伝い（`applyHarvestMutualAid`・`applyRegionalHarvestHelp`）は穀物の作業にしか働かず、刈れない干草は手伝いの対象になっていなかった。

## 変更

`applyHaymakingMutualAid`を追加した。穀物の手伝いの後に、同じ国の隣接セルでまだ手の空いている大人が、刈りきれない干草作りを手伝う（領主直営地の干草の賦役にあたる。モデル方針）。手伝う日数はそのセルの干草作業の不足分までで、牧畜の他の仕事は含めない。
