# ギルドが使うようになった後の、町の家計の2年目の減り（2026-11-14）

[guild-spending-20261114.md](guild-spending-20261114.md) §4の3で、ギルドが金庫を町で使うようにした後も、同じ暦の月で比べた町の家計が2年目に減った（地図2102: 485千→391千）。どの持ち手へ移ったかを調べた。

## 1. 条件

- コード: feature/fmg-economy-start-2のHEADに[fuel-price-share.md](../plan/fuel-price-share.md)・[peat-cut-plan.md](../plan/peat-cut-plan.md)・[guild-spending.md](../plan/guild-spending.md)の実装を加えたもの（既定の設定）。凍結したworktreeで動かした。
- 地図2102、36か月、`npm run sim`の`--money-flows`。[town-money-drain-20261114.md](town-money-drain-20261114.md)と同じく、戦争は止めていない。
- 実行は[run.sh](town-money-year2-20261114/run.sh)、集計は[flows.py](town-money-year2-20261114/flows.py)。

- 11の持ち手の合計は4,383千→4,336千で、3年で約4.7万しか減らない。
- 2年目に町の家計が減った分（−96千）は、ギルド（+53千）、農家（+58千）、市場（+53千）、人物（+25千）へ移った。
- ギルドは3年目にほぼ増えなくなった（+3千）。町の家計は3年目に増えた（+22千）。
- 人物（personal cash）は毎年約2.2〜2.5万増える。生活費（`taxes:characterLivingCosts`、年約−11.6万）より、領主・市場・国庫からの手当（年約+13.7万）が多い。

## 3. 読み取り

1. 2年目の減りは、地図から消えるお金ではない。1年目に国庫から町の家計と市場へ大きく移った分（国庫−621千）が、2年目に農家と市場へ戻る動きと、ギルドの金庫が落ち着くまでの残り（+53千）でできている。
2. 3年目には、ギルドも町の家計もほぼ釣り合った。町の家計が年ごとに減り続ける動きは、ギルドが使うことで止まった。
3. 残る一方向の溜まりは人物の手元のお金（年約2.4万、合計の約0.6%）で、今は小さい。長い年数で増え続けるなら、人物の使い道を考える。
