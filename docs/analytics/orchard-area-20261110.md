# 葡萄畑と果樹園の面積・収穫と、果物の飲み物（2026-11-10）

設計は[vintage-and-orchard-yield.md](../plan/vintage-and-orchard-yield.md)。[container-supply-20261110.md](container-supply-20261110.md)で足りなかったワイン・シードル・ペリーの元を調べた。

## 1. 条件

- 地図は北緯30°の2枚（2102・2103、[barilla-20261108.md](barilla-20261108.md)）、24か月、戦争なし・隊商の略奪なし。2年目（13〜24か月）を集計した。
- base: コミット1b8da6078。new: 同じコミットに設計の変更を加えたもの。どちらも凍結したworktreeで動かした。
- 計測スクリプトは[orchardprobe.mts](orchard-area-20261110/orchardprobe.mts)。毎月、作物ごとに望む面積・人手のある面積・収穫できる量（`getPerennialHarvestOutputs`、年1回の収穫の暦をかける前の月の量）・その土地の人と、市場ごとの果物と飲み物の帳簿を足した。実行は[run.sh](orchard-area-20261110/run.sh)。

## 4. 結果

- ワインは1%から44〜52%になった。葡萄畑のある市場では、ワインの需要と1年分の在庫の上限まで搾っている。
- シードルは変わらない。林檎の収穫できる量は6倍になったが、搾った量は同じだった。果樹園のある市場では、シードルの需要の上限まで搾っており、base でも林檎の量ではなく需要の上限で止まっていたと分かった。
- 残りの足りない分は、葡萄畑・果樹園の無い市場の需要である。ワイン・シードルは市場の全ての人に需要を置くが、作るのは果物のセルのある市場だけで、ほかの市場へはほとんど送られない。
- 生の葡萄・干し葡萄の市場の需要（2103で年約2万 t・2万荷）は、変わらず満たされない。生の葡萄はセルの中で食べられ、市場に出ないためである。
- ペリーは、梨の果樹園がほとんど無いため0のままである。
