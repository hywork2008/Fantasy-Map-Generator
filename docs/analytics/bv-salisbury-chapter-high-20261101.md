# Salisbury参事会室のHigh作製

2026-11-01

## 制作内容と再利用

[P5初回の部品化](bv-salisbury-parts-p5-20261101.md)で未詳細化のLowと判定した参事会室をHigh化した。`salisbury:chapter-house`の部品ID、全体の12部品構成、Lowの入口を維持し、Highのfactoryだけを実際の詳細形状へ接続した。既存の全体Highの改良であり、全体モデル監査で新規Highを1件増やす変更ではない。

ギルドホールの既存共通化を先に確認した。`GUILD_HALL_PROFILE`、`civicHallPartFactories`、`createHighCivicHallBody`、`createExteriorStair`が寸法・建築本体・階段の契約を既に持っている。今回これらのファイルを変更せず、ギルドホール用の別外殻や階段factoryも追加していない。八角形の参事会室はこの矩形会館と異なる固有建築として扱い、既存の`GothicDetailKit.arch`／`panel`／`point`、`ModelKit`の梁・柱・円柱・管、共通の部品合成と材質結合を使う。彫刻や用途の見た目だけで共通会館の寸法・支持構造を変えない方針を維持する。

追加した形状は次のとおり。

- 八面の厚み付き石壁。尖頭窓と入口は実際に壁を貫通し、ガラスは外面から0.28 m奥に置く。
- 各面の四連窓と組み合わせアーチ、上部の円形トレーサリー。入口面は扉と上部窓の両方に開口を設ける。
- 接地した段付き扶壁、水切り、窓台と胴蛇腹。
- 八面の屋根と稜線・目地。
- 中央の束ね柱・柱頭と8方向の基本リブ。室内家具・展示物は追加しない。
- 既存の回廊東辺まで届く、側壁・床・切妻屋根を持つ入口通路。通路中央を壁で埋めない。

外形の中心(-7, 58)、半径8、軒高12、屋根立上り6 mは従来の概略モデルに合わせる。扶壁と通路を加えた単体の幅×奥行×高さは約21.39×17.80×18.06 m。現地実測や歴史的配置の厳密な復元ではなく、既存の概略配置へ合わせた構成である。通路の接続位置と窓細部は推定で、現実の寸法を取得していない。

## 参照資料

[Gleeson White『The Cathedral Church of Salisbury』1898年版](https://www.gutenberg.org/files/23668/23668-h/23668-h.htm#Page_71)の参事会室の記述・写真にある八角形、大きな窓、中央柱を形状の参照とした。彫刻の物語や細部の精密複製は対象外とし、現モデルの寸法をこの文献の寸法へ一括変更しない。[大聖堂公式収蔵品IM/598](https://collections.salisburycathedral.org.uk/im.598)にも中央柱のある室内を写した資料が記載されている。これらの資料を持つ参事会室は、ギルドホールの職種別の装飾違いとは区別する。

Low全体の形状署名は`57830caca7f54e783d539e880c5e7753acdb75a1f9357ed668e4789d2e167edd`で変更なし。参事会室を除いたHighの11部品は`bb09ca3aae5885385d5009debc3c9c015b82770fdf184fd067b758539755d2c5`で制作前後一致した。ワールド座標と法線を1e-5で丸め、三角形の頂点順と材質設定も含めて、バッチ順を無視して比較している。

全体Highの幅×奥行×高さは約139.45×99.90×123 mで、BV登録の146×110×125 m以内。Lowは変更なし。参事会室Highの部品品質は明示的Highとなり、従来の「High全体にもLowの参事会室がある」という注記を更新した。
