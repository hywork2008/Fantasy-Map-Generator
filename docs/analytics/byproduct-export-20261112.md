# 皮と獣脂を地図の外へ（2026-11-12）

[byproduct-export.md](../plan/byproduct-export.md)の実装（`byproductExport`=`staple`、使い道の6か月分を残し、超えた分の2割を毎月）を、[currying-tallow-20261112.md](currying-tallow-20261112.md)のnew（prev）と比べた。

## 1. 条件

- 地図は北緯30°の2枚（2102・2103）、36か月、戦争なし・隊商の略奪なし。3年目を集計した。
- コード: コミット7826dddf5に、[candle-demand.md](../plan/candle-demand.md)・[household-goods-values.md](../plan/household-goods-values.md)・[currying-tallow.md](../plan/currying-tallow.md)・設計書の実装を加えたもの。凍結したworktreeで動かした。
- 測りは[goods.mts](byproduct-export-20261112/goods.mts)、実行は[run.sh](byproduct-export-20261112/run.sh)、集計は[sum.py](byproduct-export-20261112/sum.py)。
- 設計からの違い: 船の荷の枠で抑えることは入れていない。

- 獣脂の在庫は2年目から減りに転じた。値段は在庫で重み付けて0.25〜0.26倍で、まだ下限に近い。
- 革は、2102で在庫の増えが年約13万から約6万になった。2103はほとんど変わらない（港の無い市場の革と見られる、§6の1）。
- 長靴・革の品の作った量と、お金の持ち手ごとの額は、差が1%以内だった。

## 3. 入った品（3年目、2102）

蝋燭2,402、銀の延べ棒1,232、カスティーリャ石鹸1,176、コーヒー806、ココア706、乳香275、茶183ほか。2103も同じ顔ぶれ。

- 「その市場で基の値に比べて最も高い贅沢の品」を選ぶため、中世の地図でもコーヒー・ココア・茶が入る。蝋燭（贅沢の札が付く）も入る。毛織物・ワインに当たる品は無い。

## 4. 読み取り

1. 獣脂の積み上がりは止まった。革は港の市場では半分になったが、港の無い市場の分が残る。
2. 入れる品の選び方は直す必要がある。時代に無い品（コーヒー・ココア・茶）や、蝋燭のように地図の中で作る家の品が入っている（[byproduct-export.md](../plan/byproduct-export.md) §6の2）。
3. お金は動かない（物と物の替え）。

## 5. 入れる品を直した後（return）

入れる品を、ステープルの船が持ち帰った品（`STAPLE_RETURN_GOODS`：上等の毛織物・ワイン・塩・香辛料・絹）のうち、その市場で基の値に比べて最も高い品に替えて、同じ条件で回した（[run-return.sh](byproduct-export-20261112/run-return.sh)）。

| 3年目に入った品 | 2102 | 2103 |
| --- | ---: | ---: |
| 塩 | 103.6万 | 58.2万 |
| ワイン | 1.7万 | 0.8万 |
| 絹 | 151 | 106 |
| 上等の毛織物 | 122 | 45 |
| 香辛料 | 39 | 40 |

- 時代に無い品と、地図の中で作る家の品は入らなくなった。
- 入った品のほとんどが塩だった。塩の値段は基の値の約1.7倍で高く、基の値が小さいため、同じ値で多くの量が入る。市場の塩の在庫は、2102で26万から51万（36か月目）、2103で8万から21万に増えたが、値段は1.7倍のまま下がらない。
- 獣脂・革の出した量と在庫、お金の持ち手ごとの額は、入れる品を直す前とほぼ同じ（差は2%以内）。
- 湾の塩は、実際にステープルの船の主な持ち帰りの品だった。ただし、塩の値段が在庫で下がらないため、市場に積み上がる。塩の値の決め方（[byproduct-prices.md](../plan/byproduct-prices.md)と同じ形の問題か）は別に調べる。
