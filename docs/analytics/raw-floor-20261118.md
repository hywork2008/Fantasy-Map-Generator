## 2. 読み取り

1. **家畜は在庫が0で、値段が下限にある。** 家畜は市場に並ばず、その月に全て屠畜される。農家は肉の売れた値の取り分（`slaughter.ts` の `sellMeat`、肉は値 × 物価）で払われる。家畜の市場の値段は、農村の収入をほとんど決めていない（馬・海軍の買いなどの少ない買いにだけ効く）。
2. **羊毛は、在庫が1か月分に満たないのに値の0.30。** 値段の需要（`calculateGoodDemand`）は、町の人口 × 品ごとの係数と、農村の布の注文の材料で、町の工房が実際に使う量（加工 479/月）を数えていない。需要が実際の使い方より小さく出て、値段が下がる。亜麻・麻は値段が値の0.57・0.88で、同じ形の可能性がある。
3. **木材は、開墾で出る木が暖房の需要を上回り、約4か月分の在庫がある。** 余りによる安さで、決まりの誤りではない。
4. **主食は、在庫が大きく、主食の下限0.8にある。** 農村の収入の4割（主食の売り約54万/年）はこの値段で決まる。下限の扱いは、price-level-20261116 §4の2の残課題で、別に扱う大きな課題である。
