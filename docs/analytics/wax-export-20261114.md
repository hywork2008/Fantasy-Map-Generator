## 3. 読み取り

1. 港から出た蜜蝋は年に数百で、採れた量（2102で約1.05万）の約4%（2102）・約2%（2103）だった。蜜蝋の在庫はまだ年約2,500（2102）・約1,200（2103）ずつ増える。
2. 蜜蝋の溜まる市場の多くは港が無いか、港のある市場では外の品の値の上限を革と獣脂が先に使っていると考えられる。市場ごとの在庫と港の有無は、この測りでは見ていない。
3. 在庫で重みを付けた値段（約1.7〜2.0倍）が平均の値段（約1.2倍）より高い。蜜蝋の多い市場ほど値段が高く、在庫があっても周りの市場へ流れない。値段の決まり方が、在庫の多い市場で下がらない理由を調べる必要がある。
4. 革と獣脂を出す量、蝋燭、お金の持ち手の差は5%以内だった。
