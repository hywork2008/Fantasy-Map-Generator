# 農村のエールを市場から外した後の観測（2026-11-04）

設計書: [urban-craft-staffing.md](../plan/urban-craft-staffing.md) §10.11（未決事項17）。前の段階は [beer-shortfall-20261104.md](beer-shortfall-20261104.md)。

- 入力: 前の段階の地図（seed 2101・2103・2104）。平和モード、隊商の襲撃なし（`FMG_CARAVAN_RAIDS=off`）、60か月。
- 変更前はHEAD（`d0b50b57b`）をworktreeに置いて同じ条件で走らせた。変更前の結果は、前の段階（襲撃あり）の値と同じだった。
- ビールと樽は`beerprobe.mts`、都市人口と職人は`economystart.mts`（0・12・36・60か月）、2101の収穫は`harvestprobe.mts`（36か月）で見た。手順は`rural-ale-20261104/run.sh`・`run-obs.sh`。

## 1. 変えたこと

市場のエールの需要（`foodProcessingLedger.ts`の`calculateAleDemand`）から、農村の人の分（大人1人あたり年48 L）を外した。農村の家は自分の穀物でエールを醸造し、その穀物は食べる分（`GROSS_FOOD_NEED`）の中に入っているとして、農家の穀物の消費は増やさない。市場のビール・樽・醸造の穀物の買い付けの需要は、町の分（年300 L、ワインの地域の町は48 L）と水の安全の上乗せだけになった。

- **樽はほぼ足りるようになった。** 樽の下限（町の人口 × 年0.078）は町のエールの詰め替えと同じ量なので、樽で不足する分は2103・2104で1〜8%、2101で15〜22%になった。残る樽の不足は、水の安全の上乗せの分である。
- **需要に対する割合は2103・2104で約2倍になった**（15〜24% → 31〜49%）。止めているのは穀物のままである。
- **2101は、年を追ってビールが減る。** 1年目は需要の64%だったが、5年目は31%で、量は月10,093 → 1,310トンになった。

## 3. 2101のビールが減る理由: 市場の買い付けの上限

市場が農家から買う量の上限（`foodProduction.ts`の`storageCap`）は、「町の食べる分 ＋ 農村の買い足し（`ruralMarketDraw`）＋ 醸造の穀物」の12か月分である。変更後は醸造の穀物が約半分になり、上限が下がった。

2101（36か月、`harvest-2101.json`）:

| | 1年目の買い付け | 収穫後の最大在庫 | 12か月目の在庫 | うち醸造に使える穀物 |
| --- | ---: | ---: | ---: | ---: |
| 変更前 | 約65.7万 | 58.3万 | 25.4万 | 11.5万 |
| 変更後 | 約53.1万 | 46.0万 | 11.2万 | 2.0万 |

- 市場が買わなかった収穫は農家の納屋に残る（`unsoldHarvest`は納屋の上限を超えた分で、毎月2.5万以下）。2101では、穀物は農家にあるのに、市場が買わなくなった。
- 5〜12か月目の在庫の減りは、変更前31.9万・変更後33.3万。町の食べる分（帳簿の`urbanNeed`）は約19.0万、ビールは7.3万・6.5万で、**残りの5.5万・7.7万は農村の買い足し・他の市場への輸出・傷み**である。上限はこのうち農村の買い足しだけを数え、輸出と傷みを数えない。3つの内訳は計っていない。
- 変更前は、農村のエールの穀物（年約14万）が上限に入っていて、市場はその分も買っていた。樽が足りずにその分のビールは作られず、穀物は倉に残り、上限が数えない輸出と傷みの分は、結果としてこの残りから出ていた。
- 変更後の2101は、毎年収穫の前に食べる在庫が6か月分を下回り、輸入が要る量（`importNeed`）が6〜8.5万になる（変更前は48・60か月目に2.8〜4万）。都市人口は+1.7%で、町の主食は輸入で賄われている。

## 4. 分かったこと

- 農村のエールを外すと、樽の不足はほぼ無くなり、需要に対するビールの割合は上がる。都市人口と職人の数への影響は2%以内だった。
- 穀物の不足は残る。2103・2104では農家の余りそのものが足りない（前の段階の§3）。2101では、市場の買い付けの上限が、他の市場へ出ていく分と傷む分を数えていない。
- 直し方の候補: 市場の買い付けの上限に、前の12か月に実際に出ていった分（輸出と傷み）を足す。
