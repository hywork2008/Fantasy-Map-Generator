## 1. 条件

- 地図2103、36か月、戦争なし、略奪なし。記録は [basket.mts](household-basket-20261116/basket.mts)、実行は [run.sh](dairy-supply-use-20261116/run.sh)。
- 4本を比べた。
  - old: 今の決まり（`cellCheeseSale` fixedShare、`ruralDairyUse` reserveOnly、牛乳の人手は品の目録の値）
  - new: §3.1・§3.2を入れたもの
  - labour: new に、牛乳の人手を作業日数で数える直し（§7）を足したもの
  - share: labour に、農家が食べる割合の上限（§8）を足したもの。今の既定

## 3. 読み取り

1. **new だけでは、ほとんど増えなかった。** 牛乳の人手（品の目録の `preservationLaborPerUnit` 0.08）が人口点の単位のままで、牛乳1,000 Lに80人・月かかっていた。土地の人の15%の人手では、牛乳の約19%しか扱えなかった。
2. **人手を作業日数（既定10日/1,000 L、設定 `cheeseMakingDaysPerMilkLot`）にすると、牛乳は全て使われた。** ただし、農家の需要（25 kg）が作れる量（約8 kg）を上回るため、農家が全部食べ、町への売りが0になった。
3. **農家が食べる割合を自分の牛乳の半分まで（設定 `ruralCheeseEatShare` 0.5）にすると、町への売りが戻った。** 町はほぼ需要を満たす。
4. **中央値の市場のチーズの値段は、上限近くのまま。** 乳を出す家畜のいない市場が多く、チーズを運ぶ量が足りないとみられる（数えていない）。
5. 塩・家計には目立つ変化は無い。
6. 籠の乳製品の比は、量の面では大きく増えた（チーズ 0.5 → 7.4 kg）。値で数えると、自家消費を農家渡しの値段で数える観測がまだ無い（basket.mts の GDP は市場で動いた分だけ）。籠の比は、この観測を足してから出す。
