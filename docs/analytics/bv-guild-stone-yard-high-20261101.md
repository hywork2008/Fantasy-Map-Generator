# BV高品質モデル 第14群：統一したギルド会館と石工作業場（2026-11-01）

職人ギルド会館4種と石工作業場1種にCodex GPT-6.1 SolのHighを追加した。[複合モデル設計](../plan/bv-composite-models.md)に従い、職種によって同じ建築を別々に作ることを避けた。

## 共通建築の契約

`civicHallProfile.ts`の`GUILD_HALL_PROFILE`を唯一の共通プロファイルとし、織物商人会館と職人ギルド会館4種は同じ建築factoryを呼ぶ。

| 要素 | 共通仕様 |
| --- | --- |
| 建築本体 | 幅15 m、奥行7 m |
| 2階床面 | 高さ3.32 m |
| 上階壁 | 高さ3.25 m |
| 屋根 | 立上り2.2 m、同じ瓦葺きfactory |
| 1階の支持 | 石造アーチ回廊、同じ柱・柱頭・アーチ・床梁 |
| 外階段 | 同じ部品、東側、扉中心Z=-2.3 m、床高3.32 m |
| バルコニー | 同じ床・支持柱・方杖・手すり |

5ギルド会館とも全体の最大高さは約9.061 mで一致する。職種で変えるのは紋章・検査台・商品や素材見本だけとした。建築本体・外階段・用途部品の3部品をBVで単体表示できる。織物商人会館も用途部品を建築本体から分離した。市庁舎の高い上階・鐘楼と市場会館の木柱は、職人ギルドの差ではなく名前付きの市民施設構成として明示した。

既存Low/defaultの生成関数・IDは保持する。Lowの既存前面階段を含む形状を一括して変更する作業は行っていない。
