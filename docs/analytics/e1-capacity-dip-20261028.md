# E1: 1307年の牛の収容力の落ち込み（2026-10-28）

親計画§7.61の検証記録。§7.60の96か月計測で、Worldの牛の収容力が1306年1月の1,095千頭から1307年1月の693千頭へ落ちた。原因を調べるため、`scripts/auditCapacityDip.mts`で`getGrazedCarryingCapacity`と同じ式を4つの要因に分け、60〜84か月（1305年1月〜1307年1月）の毎月を記録した。0か月は読み込んだ地図の日付（1300年1月）。

    NODE_OPTIONS=--max-old-space-size=1900 node --import tsx scripts/auditCapacityDip.mts docs/analytics/inputs/salt-s0-aligned-20261023/world-102.fmg e1-capacity-dip-20261028/world-cattle-60-84.json 60 84

収容力 = 計画頭数 × min(年間の飼料係数, 越冬の飼料の割合) × 前年の給与率による制限。

- 落ち込みは1306年8〜10月（79〜81か月）に起きた。計画頭数は増えており、草地・越冬の飼料はどのセルでも制限になっていない（年間の飼料係数・越冬の割合が効いたセルは0）。
- 全量が前年の給与率による制限で、制限されたセルが約670→1,550に増えた。
- 落ち込みの大きい40セル（すべて寒冷ステップ）の直近12か月の給与率は平均0.94で、不足は6%前後にすぎない。それでも制限は0.06〜0.08まで下がり、例えばセル3271の牛の収容力は2,548→207頭になった。
- 制限は「今の全畜種の頭数×給与率÷計画頭数」で、給与率が1を少しでも下回ると、収容力が計画の水準から今の頭数の水準へ段差で落ちる。群れがまだ計画頭数に届いていない（寒冷ステップのセル3271で実頭数938頭、牛だけで217頭）ため、段差が大きい。気候災害や草の生育による落ち込みではない。
- 1307年1月に収容力が693千頭へ戻り始めたのは、年次の出生で実頭数が増え、「今の頭数×給与率」が上がったためで、制限そのものは続いている。

## 判定

1307年の落ち込みは、わずかな飼料不足で前年の給与率による制限に切り替わる段差による。§7.55で「群れを固定する」と見た仕組みと同じで、§7.59以降は群れが増えて計画頭数との差が開いたぶん段差が大きくなった。実頭数（597千頭）は収容力を下回っており、今回の落ち込みで頭数が大きく減ったわけではないが、セルが制限に入ると群れは増えられなくなる。
