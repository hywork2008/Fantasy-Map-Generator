# 木の灰と炭酸カリウム（2026-11-07）

設計は[wood-ash-potash.md](../plan/wood-ash-potash.md)。続きの元は[cold-sand-20261107.md](cold-sand-20261107.md)。

## 1. 条件

- 地図: [site-bonus-20261107.md](site-bonus-20261107.md)のH = 25の地図のうち、シード2102・2103。12か月。襲撃なし、平和。
- 計測スクリプト: [clayflow.mts](cold-clay-20261107/clayflow.mts)。見る財は、環境変数`CLAYFLOW_GOODS`で渡した。
- どちらの計測でも、粘土とガラスの砂を寒い土地に加えた（`add`、[cold-sand-20261107.md](cold-sand-20261107.md)と同じ）。
- 凍結した作業ツリーは2つで、どちらも26d992138（ガラスの砂まで）に、まだコミットしていない変更を足したもの。
  - base: 灰の変更を、元の値・レシピ・需要に戻した。計測スクリプトの変更（`CLAYFLOW_GOODS`）だけが残る。
  - new: 灰の変更を足したもの。
- §2.1の前の調べは、ガラスの砂の変更（まだコミットしていなかった）の上で、作業ツリーを固めずに動かした。
- 実行: [run.sh](wood-ash-20261107/run.sh)（baseとnew）、[run-new.sh](wood-ash-20261107/run-new.sh)（灰の建設の需要をなくした後のnew）。
- 比較: [compare.py](cold-clay-20261107/compare.py) `--modes base,new --goods "Ash,Potash,Glass,Soap,Cheese"`。出力は[summary.txt](wood-ash-20261107/summary.txt)。

## 2. 結果

### 2.1 前の調べ（変更の前）

シード2103に粘土とガラスの砂を加えて、12か月を計測した（`probe-add-2103.json`）。

- 0〜4℃の市場の炭酸カリウムは、年に約11樽だった。灰（年約9袋）と同じく、使う分だけ作られていた。在庫はどちらもほぼ0。
- 0〜4℃の市場のガラス（年）は、地元で作った量が6荷、国の船の持ち帰り（`navyImport`）が98荷だった。
  - 地元のガラスの量は、職人の贅沢品の需要の割り当てで決まる。
  - ガラスを止めていたのは、炭酸カリウムではなかった。
- 家計の暖房（町と農村）は、0〜4℃の市場で年80,890山の木材を燃やしていた。

### 2.2 最初のnew（灰に建設の需要が残っていた）

- 町の灰の需要（`burgDemand`）が、2102の4〜8℃の市場で年9袋から4,102袋になった。
- 建設の予算の一部を値で割り当てるので、灰の値を1/125にすると、袋の数が増える。
- 灰の建設の需要をなくした（設計書§3.1の5）。この結果は`first/`に残した。

- 灰は、ほとんどが町の炉から来るようになった。
  - 職人の作った灰（`burgCraft`）は、baseでは木材のレシピと燃料の副産物の合計である。
  - newでは灰のレシピが無いので、燃料の副産物（レンガ・蒸留酒・燻製）だけである。
- 灰の在庫は、使う量の数か月分に収まった。2102の0〜4℃は、月に約40袋を使い、在庫は549袋。市場ごとの最低の24袋を含む。
- 炭酸カリウムは、2102で約45%、2103で約20%増えた。2103の0〜4℃は変わらない（11樽）。
  - 炭酸カリウムの値段は1.2〜1.8で、新しい値（0.9）より高い。
- 石鹸は約40%増えた。ガラスは30〜50%増えたが、寒い市場の地元のガラスは少ないまま（2103の0〜4℃は6荷）。
- チーズは変わらない。
- 灰の値段は0.024〜0.031で、新しい値（0.012）の約2倍である。
