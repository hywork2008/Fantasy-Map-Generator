# E1 飼料決済の対象期間を遅延実行から分離（2026-10-24）

飼料の採草・保存損失・給与は、実行時の暦月ではなく、発生時に確定した決済期間を使うよう修正した。[冬前屠畜設計](../plan/winter-livestock-slaughter-and-preservation.md)のW0のうち、詳細生産決算の欠落/重複を防ぐ変更である。屠畜・食肉・保存加工の実装と係数校正は含めない。

## 原因と契約

Economyの生産は既存の30日周期で発生し、microtaskへまとめて後送りされる。従来は実行時の`currentYear/currentMonth`を飼料期間と成長月に使ったため、同じ暦月に2回実行されると後の処理が重複としてスキップされた。前回の固定入力12か月では3月分を欠いた11期間しか記録されなかった。

新しい`livestockFeedNextPeriod`をEconomyの保存対象cadence列に持ち、通常の生産周期ごとに連番の対象期間を確保する。旧セーブは読み込み後、新規世界は生産準備時に、その時点からの次期へ初期化する。既存の周期途中の日数は維持し、未記録の過去月へ飼料や損失を遡及追加しない。初期化を拡張登録時に行うと地図読込前の日付を取ってしまうため、読込/準備時と時間更新のフォールバックで行う。

詳細生産コマンドへ各対象期間を渡し、その同期サイクルの間だけ採草・季節備蓄・Fodder発注・給与・履歴照会を同じ期間にそろえる。終了/例外時に適用期間を復元する。既に処理済みの期間と、それより古い期間では再採草・再給与しない。監査の月表示も実行月と対象月を分ける。

これは生産全体を暦月末へ移す変更ではない。30日周期と365日暦は異なり、1つの暦月区間に対象期間2回、別の区間に0回となり得る。12区間内の連続性を確認するもので、毎年必ず12回という一般保証ではない。ほかの生産物の季節参照や食料決済の暦の契約も今回一括変更していない。

Fast-Forwardの年率による概算経済は、引き続き物理的な採草/給与を実行しない。期間列は進めるが未給与の履歴を作らず、後で遡及給与もしない。したがって概算Fast-Forwardと詳細計算の物理履歴の同一性は今回の達成範囲外である。通常のAdvance Month/Yearで詳細決算をまとめて実行する経路とは区別する。

## 固定入力と比較の注意

[比較JSON](economy-e1-feed-calendar-comparison-20261024.json)、[全量観測ハッシュ](raw-observations-20261024.md)。前回と同じ1300年のWorld102 / Province101、Standard、High Medieval、populationRate1000、urbanization1、遠隔交易on・隊商襲撃offで12か月確認した。Worldの変更前は既存36か月出力の最初の12区間を使う。新たな36か月/多数シードは回していない。

変更前は11期間、変更後は12期間となるため、不足率や年間合計の増減は同じ分母の改善比較ではない。これまで欠けた給与・採草・損失・支払が発生する。物量を実行前のままに維持するために欠測分を捨てる修正ではない。

## 実観測の結果

両入力で、対象期間15601〜15612（1300年2月〜1301年1月）の連続12期間を記録した。実行日は対象月と異なり、3月の暦区間には実決済0回、4月の区間には3月分と4月分の2回となる。期間列には欠落/重複がない。

| World | 11 → 12 | 295,428,693.17 → 322,560,543.24 | 158,064,814.52 → 154,859,896.85 | 53.5035% → 48.0096% |
| Province | 11 → 12 | 1,726,079.40 → 1,884,994.13 | 0.00 → 0.00 | 0.0000% → 0.0000% |

Worldの都市穀物不足0、農村の丸め規模0.03単位を維持。Provinceも都市0・農村0.01単位を維持した。Worldの原毛実市場流入は33,961.38→37,151.52kg、Provinceは1,786.28→1,786.11kg。給与履歴が生産へ影響するため、飼料以外の結果も完全一致とはしない。前回の36か月観測で判明した2年目以降の食料不足が解消したことは、この12か月から主張しない。

各実決済の市場別に、必要量＝放牧給与＋乾草給与＋不足の物量式を照合した。最終両入力の全記録済みsrcと監査本体/ヘルパーの実行時ハッシュも現在のソースと一致した。初期化タイミングを補った最終版は、その直前の12か月観測と初期/全区間の経済値が一致し、重複する暫定出力は削除した。

## 検証

- 飼料、都市生産、採毛、食料台帳の関連4ファイル56テスト成功。期間処理変更後の飼料テストも11件成功、初期化変更後の都市生産35件も成功。
- 回帰ケースは遅延3期間の異なる成長月、同期間/逆順の再実行防止、年越し、保存済み次期の利用、例外時の適用期間復旧。
- `reloadReproducibility.node.test.ts`の同じ入力を別ホストで読む比較とcadence保存復元は成功。
- 同ファイルの47日連続対17日＋保存再読込＋30日比較は、`simulation.extensions.characters`だけが不一致で失敗。変更前HEADを一時ディレクトリへ展開した実行でも同一箇所の失敗を再現した。経済領域のハッシュ不一致はない。この全世界比較を成功とは記載しない。
- 型チェック、変更ソース/テストのBiome、差分空白チェック成功。関連範囲以外の全件テストは実行していない。
