# E1: 農繁期の応援配分と移住余力の整合（2026-10-24）

前工程で全職種の求人不足と農作業不足を分離した後、実際の月別予約・収穫応援・移住余力を照合した。収量や初期食料・資金、応援労働の係数、冬季飼料源は追加していない。

## 修正した処理

近隣の相互援助と市場内の季節応援は、作業の希望総量から不足を求めていた。そのため、未充足求人の大きいセルが応援を受け取り、実際の刈り取りが不足するセルの取り分を減らしていた。応援対象を、実際に予約した作業が住民能力・既存の家族支援を超える部分へ変更した。市場内から出る応援も、近隣援助と同様に、送り出すセルの実作業と希望作業の両方へ記帳する。

さらに、移住可能人数を年平均の作業量だけで求め、その人数を農繁期の収穫能力から差し引いていた。年平均で余っていても繁忙月に必要な住民まで移住可能として扱わないよう、各月の実作業・既存の家族支援・受入援助から安全な移住上限を求める。従来の年平均による安全余裕と、明示された都市向け移住予約は維持する。応援に出る住民の月別作業もこの判定に含める。

近隣・市場内の2経路で、先のセルに大きな未充足求人、後のセルに実際の収穫不足、別のセルに余力を置いた回帰試験を追加した。修正前の両経路で試験が失敗し、修正後は収穫の不足を補い、送り出すセルにも労働を記帳することを確認した。未充足求人そのものは不足診断に残る。
