# 熱帯・水辺・高地・火山の割当と接地確認

実施日：2026-10-29。対象：[樹木LOD作製計画](../plan/ce-forest-biome-tree-lod-tasks.md) F3-3（B08・B13・B18・B19・B21〜B23・B26・B27・B29）。

## 修正した問題

CEの詳細樹木はprototypeを候補の高さ・半径へ正規化する際、モデル全体の最下端をY=0へ移動していた。元モデルのY=0は地表で、根はY<0へ埋める設計になっている。この移動で根の埋没部分が持ち上がり、幹や板根の地表との位置関係も変わっていた。

`forestTreeDetails.ts` ではY方向の平行移動を廃止し、地表Y=0を固定したまま、地上の最高点を10 mへ合わせる。地下の根は負のYとして残す。X／Zの候補半径、候補位置・回転、LODの選択規則、モデル・作者・採用版は変更しない。共通の詳細選択処理を使う森林・公園・墓地へ反映される。

カポックとオオバヒルギについて4品質ずつ検証する回帰テストを追加した。修正前は両種とも最下端が0になり、期待する埋没深さと一致せず失敗した。修正後はモデル本来の地表基準と地下部分を保持し、地上最高点も候補高に一致する。

## 固定検証

[計測JSON](ce-tree-wet-upland-biomes-20261029.json) に樹種・品質・採用ID、接地と地表基準の誤差、樹冠余白、候補配置のSHA-256、森林化・水域除外の結果、関連ソースのSHA-256を記録した。

- 10バイオームを温度未指定で確認し、floodedForestは19.99℃と20℃も追加した12条件。
- 平地 `height=5` と斜面 `heightAt(x,y)=5+0.05*x+0.02*y` の2条件、俯瞰・林縁・低視点の3視点。合計72フレーム。
- seed `ce-wet-upland-biomes-v1`、96 m四方、中央24×16 mの開口部、森林面積8,832 m²、密度standard・森林品質standard。
- Apple M4／ANGLE Metal、400×400、DPR 1、CE既定照明、影なし。都市全体の性能計測ではない。

全フレームで次を確認した。

- 可視instanceと詳細本数が一致し、採用IDが現在の採用表と一致する。
- バイオームと冠水林の温度分岐を変えても、同じ地形条件の候補位置・半径のSHA-256が一致する。
- instance基点とterrain高さの誤差は最大 `3.051757815342171e-7 m`。
- 元モデルの地表Y=0を固定して正規化した場合との外接Y誤差は最大 `1.3370207274654433e-8`。全ての可視prototypeに負のYの根が残り、最高点は10。
- 候補の樹冠半径から外周・開口部までの最小余白は `0.15069705513306664 m`。
- 重複0。24回の森林解放後はいずれもgeometry 0。WebGL／page／consoleエラー0。

接地検証はモデルの地表基準と埋没部分を保つことを対象とする。斜面の細かな起伏へ根を1本ずつ変形・吸着させる処理を追加したわけではない。支柱根や板根の全頂点が任意地形と接触する保証にはしない。

## 水域・開放地の保護

9セルの固定入力で、locked、open指定、湖、海、公園、市街の空地を除外し、設定なし0、legacy 0、farmland 2、surroundings 3セルとなることを全10バイオームで確認した。手動forest指定は要求した1セルのみ。元の文書は変更しなかった。

加えて、選択された陸セルの内部に河川polygonを置き、実際の `buildForestPlan` を通した。森林面積は1,056 m²となり、河川polygonの中心を含まず、別の許容陸地点は保持した。mangrove／floodedForestでもこの水域除外を維持する。森林指定があってもバイオームをlavaFieldへ変えた場合は0セルとなった。

水際の立木を陸域へ置く確認であり、潮汐・季節冠水・水位・湿地土壌のシミュレーションや、水面をまたぐ支柱根の専用描画は今回の達成範囲ではない。

## 目視確認と再現

平地・斜面の各10バイオームをOSの一時画像で比較し、カポックの板根と水平な枝段、オオバヒルギの支柱根、ハンノキ・ナナカマドの樹冠、トウヒ／シラカバの混交、カナリアマツの枝葉を確認した。確認後に一時画像を削除し、リポジトリには保存していない。

```sh
node --import tsx scripts/verifyCeWetUplandBiomes.mts
npx vitest run src/city3d/three/forestTreeDetails.test.ts src/city3d/three/forestMeshes.test.ts src/city3d/three/openSpaceTreeLod.test.ts src/city3d/three/openSpaceMeshes.test.ts
```

通常実行では画像を出力しない。目視確認時だけOS一時ディレクトリを `CE_TREE_PREVIEW_DIR` に渡し、確認後は削除する。

関連4ファイル49件と、変更2ファイルのBiome確認が成功。新しい2件の回帰テストは2樹種×4品質の地表基準を検証する。`npx tsc --noEmit --pretty false` は既存の `src/city-editor/renderers/fogControls.ts(45,36)` のstring／EditorMessageKey不一致で失敗し、今回の変更箇所の型エラーはなかった。今回、都市全体の操作p95は再計測していない。
