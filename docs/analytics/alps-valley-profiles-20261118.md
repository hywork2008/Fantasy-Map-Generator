# アルプスの川の谷の横断面（2026-11-18）

設計: [`../plan/alps-terrain-tiles.md`](../plan/alps-terrain-tiles.md)（A5）、[`../plan/fmg-cell-valleys.md`](../plan/fmg-cell-valleys.md)。比較の基準: [`japan-valley-profiles-20261117.md`](./japan-valley-profiles-20261117.md)

## 入力と方法

- 川：Natural Earth 10m の河川中心線と欧州補遺（`temp/ne_10m_rivers_lake_centerlines.geojson`、`temp/ne_10m_rivers_europe.geojson`、パブリックドメイン、1:1000万）。範囲（東経4.5–17.0°、北緯43.5–48.6°）に掛かる線。
- 標高：AWS Terrain Tiles（Terrarium）z10（北緯46°で約106m）、814枚（`temp/terrarium-alps/10/`）。
- `node scripts/sampleValleyProfiles.mjs --region alps --reachKm 10`（`--everyKm 2 --floorKm 1.5`）。川に沿って2kmごとに、川と直角に ±10km を 125m おきに読む。1:1000万の線は実際の流路から離れやすいので、谷底は線から ±1.5km 以内の最低点。
- ±6km（日本と同じ）では、深さ600m以上の断面の41%で尾根が到達範囲の端に当たったので、±10km にした（端に当たるのは23%に減る）。
- 全断面：`docs/analytics/raw/alps-valley-profiles/sections.json`（1,295,411 bytes、SHA-256 `a1f114d4b9e80b127bd0638d45bd8b8bba0aebd164fc94a6f5652c24edd96dc5`）。

## 日本との違い

- 深い：深さ600m以上が25%（日本1.6%）。谷底が高いほど深く、谷底1000m以上で中央値1,209m（日本256m）。
- 広い：尾根まで約7km（日本3〜4km）、半深幅4.5〜5.4km（日本0.9〜3km）、谷底幅1.4〜1.9km（日本0.4〜1km）。
- 側壁の形はほぼ同じ（ほぼ直線）。谷底脇（0.1）がわずかに緩い（0.06〜0.08、日本0.10〜0.11）だけで、はっきりしたU字の曲線は出ない。この解像度（約106m）と線の位置の誤差（1:1000万）では、U字谷の形は谷底の広さとして現れる。
- 峡谷は少ない（3.5%）。

## 限界

- 1:1000万の川の線は主な川だけで、支流の谷は入らない。線のずれは谷底の探索（±1.5km）で吸収している。
- 約106mの格子なので、谷底幅の小さい値と側壁の急な部分は下限の見積もり。
