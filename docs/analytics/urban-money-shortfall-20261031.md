# 町のお金の不足の原因（2026-10-31）

[livestock-meat-sales-l4-20261031.md](livestock-meat-sales-l4-20261031.md)§3.1の続き。市場14・15・16・21の町が肉の需要の3〜10%しか買えない理由を調べた。コードは変えていない。

- 入力: 固定入力`docs/analytics/inputs/wet-pastoral-birth-20261029/world-102.fmg`、平和モード、L4の修正後のコード（未コミット分を含む）。
- 町と農村の財布の流れ: L4の`money-l4-fix-84.json`（84か月、`scripts/auditUrbanMoneyFlows.mts`）。
- 市場の金庫の流れ: 新しいprobe `treasuryflows.mts`（36か月）。`marketTreasury.balance`の変化を、呼び出したモジュールごとに数える。
- 比べた市場: 貧しい市場14・15・16・21・10と、豊かな市場2・4・6・7。市場1は§4に記す。

## 2. 農村: 現金収入が半分で、塩の支出は同じ

町の一番大きな収入は「農村が町で使うお金」で、これは農村の財布の毎月5%である。農村を1人あたりで比べた（1306年、×1000）:

- 塩の支出は1人あたり54〜82で、市場によって大きく違わない。人の塩はどこでも約23で、残りが家畜の塩である。
- 貧しい市場の現金収入は、豊かな市場の半分ほどしかない。違うのは干し草（4〜7分の1）、肉、町に売る穀物の3つである。国の給与は同じくらい。
- 塩は先に払うものなので、収入が少ないと、町で使うお金がその分だけ減る。貧しい市場では、収入の55〜59%を塩に払った残りから町で使う。
- 町に売る穀物が少ないのは、農村に対して町が小さいためである（市場10・16は町1人に農村9〜12人）。穀物は、その市場の町と、市場の間の食料の輸入（`foodImportNetwork`）にしか売れない。

- 金庫は塩の代金をほぼそのまま製塩所の持ち主へ渡す。持ち主は274か所のすべてが国である（`getSaltOwnerAccount`）。
- 製塩所の持ち主の国は、そこから賃金を、製塩所で働く人の町へ払う。運び賃は、塩を売った市場の中心の町へ払う（`paySaltInputs`、`paySaltWholesale`）。
- 国の金庫に残った分は、国の給与（`payStateHouseholds`）で、国のすべての町と農村へ人口に応じて分ける。首都は3倍に数える。
- 製塩所の無い市場の農村が払った塩の代金のうち、賃金と運び賃の分は、製塩所のある市場の町の収入になる。給与で戻ってくるのは、自分の人口の割合の分だけである。
- 豊かな市場の金庫は、干し草の差し引きで、農村へ町の1人あたり0.18〜0.31を払っている。貧しい市場は0.04〜0.13である。干し草の買い上げは、市場が1年に飼い葉として売った量が上限になる（[fodder-purchase-demand-cap.md](../plan/fodder-purchase-demand-cap.md)）。

## 4. 分かったこと

1. **貧しい町の原因は、町の支出ではなく収入にある。** 町の家計の収入のうち一番大きいのは、農村が町で使うお金である。貧しい市場では、それが農村の小さい現金収入から塩の代金を引いた残りの5%になる。
2. **農村の現金収入が小さい理由は3つ:**
   - 町が小さく、穀物を売れる相手が少ない。
   - 干し草の買い上げが少ない。
   - 町が貧しいので、肉が売れない。
3. **塩は、製塩所の無い市場から製塩所のある市場へ、毎年お金を移す。** 給与で戻るのは人口の割合の分だけである。そのため製塩所の無い市場は、町と農村を合わせて毎年お金を失う。84か月の合計で、町の1人あたり年0.02〜0.10を失い、豊かな市場は0.05〜0.08を得る。
   - 追記（V2）: 国の給与がこの塩の利益を、ほぼ人口に応じて返していた。そのため、塩と給与を合わせると、農村の大きい市場にとってはほぼ差し引きゼロに近かった。塩の値を直しても、これらの市場は良くならなかった（[salt-untaxed-value-v2-20261031.md](salt-untaxed-value-v2-20261031.md)§3.1）。
4. **悪い循環になっている。** 町が貧しいので肉が売れず、そのため農村の収入が減り、それで町に入るお金がまた減る。財布は6年で約5分の1まで減り、主食の代金ぎりぎりで止まる（町の主食の充足はほぼ保たれる）。
5. **市場1は例外。** 製塩所が23か所あり、農村の現金収入も多いのに、町は肉の需要の29%しか買わない。その原因はまだ調べていない。

## 5. 次に確かめること（コードを変える前）

- **(a) 塩の重さ:** 家畜の塩と人の塩が、農村の現金収入の36〜59%を占める。中世の農家の支出に占める塩の割合と比べて妥当かを、資料で確かめる。妥当でなければ、どこに原因があるかを調べる（1頭あたりの塩の量、塩の値段、収入のどれか）。塩の優先順位（作る量・普通の値段・掛けの返済）を守るため、塩の値段を下げて症状だけを抑える修正はしない。→ §6で調べた。値の基準が税込みの値段になっていた。
- **(b) 農村の売り先:** 町が小さい市場の農村が、他の市場へ穀物・家畜を売る道。牛を他の市場へ追う計画は、既に保留にしてある。
- **(c) 市場1:** 町の収入のうち何が少ないか。

## 6. (a)の結果: 塩の値は税込みの値段になっている

### 6.1 量は史料の範囲にある

- 人の塩は1人年3.6 kg、家畜の塩は生理的な必要量の0.4倍（`SALT_LIVESTOCK_PURCHASED_SHARE`）である。合わせると、Neckerのpays rédimés（塩の安い地方）の1人年8.8 kgに合わせてある（[salt-supply-calibration.md](../plan/salt-supply-calibration.md)§3.10）。
- 計測の農村の塩の支出（1人0.054〜0.097、1袋0.45前後）は1人7〜13 kgで、この値と合う。量に原因は無い。

### 6.2 値は、作る費用と税の無い史料の値段の約7倍

| | 1 kgの値（穀物 = 1） | 出典 |
| --- | ---: | --- |
| モデルの`Salt.value` 0.45（60 kg） | 3.5 | [goods-physical-units.md](../plan/goods-physical-units.md)§22。§13.4の「史料の目安2〜5」には出典の記載が無い |
| モデルの製塩所の作る費用（煮詰め） | 約0.5 | 本書の計算。賃金は1袋142.6時間で約0.048、薪は104 kgで約0.016、`unitCost`×1.05で約0.067 |
| 英国1340年の塩（white 3s 3d・bay 2s / quarter）と小麦（5〜6s / quarter） | 約0.35〜0.6 | Bridburyの数字。孫引きなので原典での確認が要る。塩のquarterは約200 kg、小麦は約218 kg |
| 近世フランスの税の無い地方（ブルターニュ、49 kgで31スー） | 約0.15〜0.25 | 小麦の値段（1 kgあたり2.5〜4スー）は概算 |
| 近世フランスの重税の地方（grandes gabelles、アンジューで49 kgが591スー） | 約3〜5 | 塩税で元の値段の10〜20倍になった。家族の塩の代金は年に約1か月分の賃金 |
| Clarkの英国の生計費指数 | 家計の0.5% | 塩の重み0.005 |

- モデルの値3.5は、塩税の重い地方の値段に当たる。税の無い値段（0.15〜0.6）と、モデルの作る費用（約0.5）は合っている。
- 塩税は、別の仕組みとして既にある（`saltPolicy.taxRate`、既定は0の「open」）。税込みの値段を基の値にすると、税を2回数えることになる。
- 卸値は`max(値×0.5, 産地の値段×0.8, 作る費用×1.05)`（`saltLogistics.ts`）で決まり、値×0.5（0.225）が下限になる。作る費用は約0.067なので、卸値の大部分は製塩所の持ち主の利益になる。

### 6.3 その利益は国の金庫に入る

| 年 | 市場の金庫が製塩所に払った額 | 町への製塩の賃金 | 運び賃 | 国の給与（町＋農村） | 家計の収入の計（町＋農村） |
| --- | ---: | ---: | ---: | ---: | ---: |
| 1301 | 254,766 | 24,075 | 9,867 | 341,954 | 1,105,287 |
| 1302 | 262,939 | 25,888 | 11,855 | 231,768 | 1,066,527 |
| 1303 | 271,080 | 26,460 | 11,380 | 241,432 | 1,048,559 |

- 製塩所に払った額のうち、賃金と運び賃は約14%である。残りの約22万（年）は、持ち主の国の金庫に入る。274か所のすべてが国の持ち物である。
- この利益は家計の収入の約20%で、国の給与と同じくらいの大きさになる。これが、人数と家畜の頭数に応じて全員から取る見えない塩税として働いている。
- 国はこれを、給与として町と農村へ人口に応じて分ける（首都は3倍）。そのため、農村が大きく家畜の多い市場から、首都と製塩所のある市場へお金が移る。
- 国の金庫にどれだけ残るかは、この計測では測っていない。

### 6.4 分かったこと

- 町が貧しい原因（§4）のうち、塩の重さは、塩の値が税込みの値段で決めてあることによる。
- 量・作る費用・税の仕組みは正しく、値の基準が史料とも、モデル自身の費用とも合わない。
- これは症状ではなく、基の値の誤りと考える。直すなら、`Salt.value`を税の無い値段（作る費用＋利幅、穀物の約0.5〜0.8倍/kg、値0.07〜0.1）に下げ、重い塩税は`saltPolicy.taxRate`に任せる。
- 直す前に決めることと、直した後に確かめること:
  1. 新しい値（0.07〜0.1のどこか）を決める。
  2. 国の金庫から塩の利益（年約22万）が無くなるので、国の給与・軍・建設がどれだけ減るかを測る。国が新しい塩税の手段（`taxRate`）を使うかどうかも見る。
  3. 塩の優先順位（作る量・普通の値段・掛けの返済）が保たれるかを84か月で確かめる。卸値の下限（値×0.5）が作る費用（約0.067）を下回ることがあるので、下限の式も一緒に見る。
  4. 保存食（塩の費用が主）・塩漬けの値段の影響を見る。
  5. 古い保存の塩の値を移す（`migrateWeightRepricing`と同じ形）。
