# メッシュなしCE 余った区画の分、都市を縮める（U3、狙いの埋まり1.0）

2026-11-13。[受入前の改善](../plan/ce-meshless-pre-acceptance-improvements.md)§2.9の順序の2。

## 変更

1. **狙いの埋まり`MESHLESS_TARGET_FILL`を0.8→1.0**（`urbanSizing.ts`）。市壁内の区画を建て切る大きさで敷地を決める。見積りに届かない分は門の外の帯へ回る。
2. **施設の外形が街区からはみ出す不具合**（`facilityLots.ts`）。外形が街区の中にあるかを0.5 m間隔の点で確かめていたため、角が街区の外に出ることがあった（施設が区画を丸ごと取っていた時は区画が隠していた）。外形と街区の差の面積で確かめる。1.0で縮めた町で表に出た。
3. **多角形演算の再帰の溢れ**（`geometry/regions.ts`の`regionBoolean`）。演算ライブラリの再帰が深すぎた時（`RangeError`）は、座標を微小な格子に丸めて計算し直す仕組みがあったが、エラーの呼び出し履歴に`RingOut`が含まれる時だけに限っていた。呼び出し履歴は既定で10段で切れるので、その名前はほとんど残らず、やり直さずに生成が失敗していた。同じ入力でも実行環境（呼び出し履歴の段数の設定）で成否が変わり、生成パネルのテストと合成5,000人の施設ありが、他の生成の後に実行すると落ちていた原因である。再帰の溢れはすべてやり直す。

施設なしの町は、空き地8〜17%（全部建てても残る分は6〜9%）でほぼ建ち切り、被覆率はメッシュあり（0.33〜0.38）を上回る。erenteだけ見積りが2割小さく、12%が門の外に住む。

施設ありの町は、市壁内に空き地が15〜19%あるのに、人口の4〜18%が門の外に住む。空き地は施設が切った区画の残りで、長方形にならず住宅を建てない土地である（§2.9の応急処置）。施設を区画に合わせる手順（§2.9の順序の3）で無くす。合成20,000人の施設ありは再び`region-budget`（多角形演算の頂点数の上限）で生成できない。
