- **耕地は、農村の人の主食に要る畑（5.1百万ha）の1.85倍ある。** 都市の主食（0.63百万人分、約0.9百万ha）を加えても約6.0百万haで、残る約3.4百万ha（耕地の36%）は主食の必要を超えている。内訳（他の作物、前年の畑を減らさない規則、人手による開墾の余地）は未確認。

## 追記: 畑が広い理由の内訳（1302年1月）

土地利用の計画（\`pack.landUse\`の各セルの\`requiredAreaHa\`・\`policyTargetAreaHa\`・\`allocatedAreaHa\`）を集計した。

| | 百万ha |
| --- | ---: |
| 主食に要る畑（計画、農村3.72・都市0.63・市場0.03百万人の4.38百万人分） | 8.07 |
| 同、予備1.1倍 | 8.87 |
| 人手で耕せる面積が予備を超えるセルの上乗せ（1,040セル） | 0.87 |
| 計画の目標 | 9.74 |
| 割り当てられた畑 | 9.41 |

- 上の表の「農村の人の主食に要る畑5.09百万ha」は、\`EDIBLE_SHARE_AFTER_SEED_LOSS_STOCK\`（0.65）を掛け忘れた概算で、誤りだった。計画の必要量は、どのセルでも概算のちょうど1/0.65＝1.54倍である。主食の必要を超える畑は36%ではなく、人手による上乗せの約9%だけである。
- 0.65は名前に「種子」を含むが、基準単収450kgは種子を引いた純単収（Broadberry Table 2）なので、種子の二重控除に見える。ただし、200kg・0.65・450kg・0.67で約1.02ha/人となり、1300年のイングランドの耕地/人（休閑を含め約1ha、要確認）に合う。0.65は種子以外の非食用（家畜の飼料・醸造・十分の一税・損失）を含む係数として働いており、変えない。名前と説明は実態に合わない（要整理）。
- **畑が広い主因は単収である。** 必要量は4.38百万人×1.84ha/人で、基準単収なら1.02ha/人（予備込み約4.9百万ha）。単収が基準の55%（人口で重みをつけると基準の約55%、1.84/1.02）であることが、約4.0百万haの上乗せになる。人手による上乗せ（0.87百万ha）はその約5分の1。

## 判定

群れが目標に届かない主な原因は、畑が広く、畑仕事が大人の手を使い切って草地を維持する牧夫が足りないことである。畑が広い理由の約8割は単収が基準の55%であること（§7.42・§7.43で残った作物気候の問題）、約2割は人手で耕せる面積まで畑を広げる規則（\`settlementClearance.ts\`の\`max(必要×1.1, laborAffordableAreaHa)\`）である。
