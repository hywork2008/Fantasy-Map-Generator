## 2. 分かったこと

### 2.1 P1の地図の2104は、穀物で止まる

P1の地図の2104は、§8の直し（収穫が倉に入る月）の前に作った地図である。

- 1か月目の醸造に回せる穀物は、5.2万しかない（§8で作り直した地図は26万）。
- 3〜6か月目は、26の市場すべてで穀物が尽き、ビールは作られない。
- ale-cask-20261107など、P1の地図を使った計測の2104の1年目の低さ（飲まれたのは需要の6割前後）は、主にこのためである。

### 2.2 作り直した地図では、作った量より飲まれた量が多い

作り直した地図の2104（今のコード）で、世界全体のビールを数えた。

| 月 | 作った | 他の市場から着いた | 他の市場へ出した | 飲まれた |
| ---: | ---: | ---: | ---: | ---: |
| 1 | 16,317 | 0 | 61 | 16,257 |
| 2 | 12,314 | 4,000 | 0 | 16,314 |
| 3 | 11,478 | 4,667 | 209 | 15,936 |
| 4 | 8,732 | 4,932 | 131 | 13,532 |

- 市場の在庫は毎月0のままなのに、毎月4,000〜4,900のビールが、出ていないのに着いている。
- 着いたビールは、町が自分の市場に売った荷を運ぶキャラバン（売り手が町、買い手が市場）のものだった。

### 2.3 原因: 町の荷が二重に入庫されていた

- 町が自分の市場に売る時（`Markets.sell()`）と、委託が売れて払う時は、その場で荷を市場の在庫に入れる。同時に、売り手が町の取引（Deal）を作る。
- 取引から、町から市場の中心の町へ荷を運ぶキャラバンが作られる（中心の町そのものの売りでは作られない）。
- キャラバンが着くと、荷をもう一度市場の在庫に入れていた（`Caravans.tick`）。
- 全部の財では、町からの荷が値打ちで毎月約2.7万〜3万あり、町が市場に売った値打ち（月16万〜19万）の15〜18%にあたる。
  - 多いのはビール・蝋燭・靴・保存食・道具・彫刻・布である。
- 遅くとも、輸出の倉の導入（4e3a5120e、2026-08-02）からこうなっている。それ以後の計測には、この余分な分が入っている。

### 2.4 「その他」の不足の中身

作り直した地図の2104（今のコード）の1年目について、不足を市場ごとに、生産を止めた理由で分けた。

| 理由 | 需要に対する割合 |
| --- | ---: |
| 穀物 | 0.02 |
| 樽（市場8。醸造の人も樽も無い） | 0.05 |
| 利益（収穫の前） | 0.05 |
| 生産の目標に届いた・順位で負けた | 0.10 |

- 「生産の目標に届いた・順位で負けた」分は、二重に入った荷で市場の在庫が埋まっていたためである。§3の修正の後は無くなった（作った量 ≈ 飲まれた量）。
- 「利益」の分は、収穫の前（3〜6か月目）に、倉に小麦（0.96）しか残っていない市場で起きる。
  - ビールの値段は、4つのレシピ（大麦・小麦・ライ麦・燕麦）の原料の値段の平均（約0.77）から決まる。
  - そのため、値段が1.2〜1.5まで下がる。
  - 小麦で醸造すると、売上税を引いて1割の利幅（`FOOD_PROCESSING_MINIMUM_MARGIN_RATIO`）が取れない。

## 3. 修正

- `Caravans.tick`で、売り手が町のキャラバンが着いた時は、荷を市場の在庫に入れない。荷はすでに在庫にあり、キャラバンは運ぶ様子を見せるだけである。
- 着いた荷の量（`caravanArrivalVolume`、荷役の仕事の需要）は、これまでどおり数える。
- テスト: `caravans.test.ts`の"adds a market's cargo to the buyer's stock but not a town's haul it already sold there"。

## 4. 残ること

1. **収穫の前の醸造の利益。** ビールの値段の原価を、4つのレシピの平均ではなく、市場で手に入る穀物で決めるか。Assize of Aleでは、エールの値段は穀物の値段に合わせて決まった。
2. **エールの値段が基準の値の2倍前後。** 作った量が需要の8〜9割で、在庫が足りない。樽の不足（2101の1割）と、醸造の人のいない市場（2104の市場8）が残る。
3. **市場の金庫と、町への未払い。** 二重に入った荷が無くなって、市場の現金が減った。委託の払いが遅れる市場が増えた。
4. **これまでの計測。** 2026-08-02以後の計測は、町の荷の15〜18%が余分に入った状態のものである。生産・値段・金庫の較正は、この修正の後に見直す必要がある。
