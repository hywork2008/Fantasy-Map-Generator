# 教会の蜜蝋の代金と町の家計（2026-11-13）

[church-wax-20261113.md](church-wax-20261113.md)で、教区の灯り（[church-wax.md](../plan/church-wax.md)）を入れると町の家計が2102で−14%になった。蝋燭の代金によるものかを、同じコードで設定だけを変えて確かめた。

## 1. 条件

- コード: feature/fmg-economy-start-2のHEAD（Advance Timeの高速化をマージした後）。凍結したworktreeで動かした。
- 地図2102、戦争なし・隊商の略奪なし。教会の蜜蝋（`waxCandleKgPerPerson`）0と0.05を比べた。
- 36か月の比較と、3か月の間に町の家計のお金を動かした関数ごとの合計（`setHouseholdWealthFlowObserver`）。
- 測りは[goods.mts](church-wax-pay-20261113/goods.mts)（`FMG_WAX_KG`・`FMG_WEALTH_CALLERS`を加えた）、実行は[run.sh](church-wax-pay-20261113/run.sh)。

## 2. 結果

| 町の家計（千） | 0 | 0.05 | 差 |
| --- | ---: | ---: | ---: |
| 2か月目 | 301 | 291 | −11 |
| 3か月目 | 344 | 319 | −25 |
| 6か月目 | 716 | 675 | −42 |
| 36か月目 | 395 | 341 | −54 |

- 0は前の測定（candle-split）、0.05は前の測定（church-wax）と36か月目まで同じ値になった。違いは、二つの実行がずれたためではなく、設定によるもの。
- 町の家計に入るお金の差は、ほぼ全てが`spendRuralHouseholdsInTowns`（農家が町で使うお金）だった。2か月目は18.0千から7.3千（−10.7千）、3か月目は70.4千から54.9千（−15.5千）。他の関数の差は1千以下だった。
- 2か月目の蜜蝋の蝋燭の代金は約800個 × 値段の比1.8 × 基の値14で約2万。その農村の分が、2か月目の差とほぼ同じになる。3年目の代金は約21万（9,447個）。

## 3. 読み取り

1. 農家が町で使うお金は、毎月の予算（`ruralTownBudget`）の中から、まず市場の在庫の品（靴・獣脂の蝋燭・蜜蝋の蝋燭）を買い、残りを町の職人・店の稼ぎとして町の家計に払う（[rural-town-spending.md](../plan/rural-town-spending.md) §4.2）。蜜蝋の蝋燭の農村の分が、町の家計に入っていたお金の代わりになった。
2. これは仕組みどおりの動きで、不具合ではない。農家の教区の灯りの代金は、町の職人ではなく蝋燭を作る側に払われる。
3. 1人あたりの代金は年に麦約5.3 kg（蜜蝋0.05 kg × 基の値14 × 値段の比約1.6 ÷ 100 kg）で、職人の1年の稼ぎ（麦約300 kg）の約1.8%。中世の値（蜜蝋1ポンド6〜8ペンス、小麦1ブッシェル約6ペンス）でも1人年に麦約3.5 kgで、桁は合っている。
4. 値段の比が1.6〜2と高いのは、蜜蝋が足りず、外からも入った（年約600個）ためと考えられる。
5. 泥炭の採れる量の差（3年目で約−74%）は§4で見た。教会の蜜蝋の影響ではない。

## 4. 泥炭

36か月の出力（wax0・wax0.05）の毎月の泥炭の流れを見た。

| 泥炭（俵） | 0 | 0.05 |
| --- | ---: | ---: |
| 2年目に採れた量 | 1,268 | 1,280 |
| 3年目に採れた量 | 46,065 | 12,130 |
| 500俵を超えた月 | 26・27・29・30・33〜36 | 25・26・28・29・36 |
| 36か月目の在庫 | 1,759 | 1,814 |

- 2年目までは、どちらもほぼ同じだった。3年目の差は、数か月だけ大きく採れる月（1か月に最大約1.2万俵）がどの月に来るかの違いだった。大きく採れた月は、その月のうちに暖房と塩の煮詰め（recipeInput）に使われた。
- 地図全体の木材の在庫と値段は、二つの実行で毎月1%以内の差だった。
- 暖房は、熱あたりの値段の安い燃料から全量を買う（heating.ts \`localHeatingFuels\`）。泥炭の基の値は熱あたり木材と同じなので、値段のわずかな違いで、ある市場の燃料が木材から泥炭へと一度に切り替わる。蜜蝋の設定による小さな値段のずれが、切り替わる月を動かした。
- 泥炭の差は、この切り替えの時期のずれで、教会の蜜蝋の量の影響ではない。安い方から全量を買う決まりは、別の課題とする。
