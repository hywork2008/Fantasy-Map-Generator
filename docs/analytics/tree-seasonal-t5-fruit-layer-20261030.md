# T5 結実層の共通化

作成日：2026-10-30。設計は [BV樹木の季節の姿と結実層の設計](../plan/bv-tree-seasonal-appearance.md) §7・§9・§17。

## 方式

`src/buildings/landscape/fruitLayer.ts` に共通の結実層を置いた。

| 部品 | 内容 |
| --- | --- |
| `FruitSite` | 骨格が出す取り付け点（位置・垂れる向き・安定した順番 `order`・種類・房の番号・大きさ） |
| `FruitSpec` | 実の形（`drupe` 楕円の核果、`bur` 割れたいが）・寸法・果柄・房・段階ごとの配色 |
| `buildFruitLayer` | 取り付け点と仕様から1つのgeometryを作る。ultra・highは実と果柄、mediumは房（または取り付け点）ごとの塊1つ、lowは描かない。`stage` で配色、`density` で `order` による部分集合 |
| `FruitAxis` | 房の軸（ナツメヤシの果柄と小穂）。木部ではなく結実層に入れ、収穫で一緒に外れる |
| 果実の組 | 実1つ（または房）とその果柄を頂点範囲の組 `fruitGroups` として記録する。季節の姿は組単位で残す・外す・縮める |
| `mergeFruitParts` | 既存の生成器の果実部品と果柄を、取り付け点ごとの組にまとめて結合する |

## 適用

| 対象 | 内容 |
| --- | --- |
| オリーブ（O02） | 新しいedition `drupes`。葉群に混ぜた三角形のマーカーをやめ、結実の新梢の葉腋（葉18枚に1か所、約600か所）に3個ずつ、1.4 cmの果柄で2.5 cmの核果を吊るす。unripe＝緑、fruit＝緑・紫・黒の混在、leaf＝実なし。highは25%、mediumは12%の部分集合（mediumは塊） |
| ナツメヤシ（D02） | 新しいedition `bunches`。4本の軸と点をやめ、葉の付け根から弧を描いて出る6本の果柄と、その外側半分から垂れる小穂24本（high・mediumは1本おき）に、楕円の実を7個ずつ付ける。unripe＝黄のハラール、fruit＝茶のタマル、harvested＝果柄の内側3分の1の切り残し、bloom＝房の位置に雌花序（T4の花序を房の位置へ移す）。mediumは房ごとの塊と果柄 |
| ヨーロッパグリ | `fruit` を生成器で描く。緑のいがと同じ取り付け点に、4枚の殻が開いた茶色のいが（内側は淡色、ultraは刺）と2〜3個の光沢のある実。T2の「緑のいがを茶色に塗る」配色は外した |
| 既存7果樹の果柄 | セイヨウナシ・セイヨウスモモ・イチジク・レモン・カカオ・アラビカコーヒー・ヨーロッパグリは、姿を指定したときだけ果柄を木部から果実のmeshへ移す。収穫後・開花では実と一緒に外れ、レモン・カカオの収穫後に残す実は果柄ごと残り、葉の時期の小さい実は取り付け点に向かって縮むので枝から離れない。リンゴは生成器が実のない姿で果柄を描かないため変更していない |

オリーブとナツメヤシは既定の姿そのものの改訂なので、§7.1に従い新しいeditionとして4品質に登録し（作者 Claude Opus 5.5、`basedOn` は同じ品質の元の版）、CE採用表で4品質とも切り替えた。元の版は比較用に残す。lowは両種とも実を描かないため、元の版とジオメトリが同じ。

## 試行と所見（headless Chromium・Metal、単木の斜め視点と近景、実BV）

- ヨーロッパグリの割れたいがは初版で淡い籠のように見えた。殻の外側と内側の面の向きが逆で、内側の淡色が外から見えていたため、向きを直した。殻の開きも初版は閉じた鐘形に近かったため、殻の端を広げて口を大きく開き、実が口から見えるようにした。highは目安25,000を超えた（27,332）ため、殻の分割を減らし刺をultraだけにした。
- オリーブは初版（葉26枚に1か所・2個ずつ）では近景でもまばらだった。葉18枚に1か所・3個ずつとし、ultraの実の分割を6×4へ下げて予算内に収めた。実は2.5 cmで、全体表示ではほぼ見えない（元のマーカーと同じ）。近景では緑の実（unripe）と紫黒の実の混在（fruit）が判別できる。
- ナツメヤシのmediumの塊は初版で、斜めの垂れる向きに合わせたため小さく平たかった。房は全体として鉛直に垂れるので、塊を鉛直にし、房の外形に合わせた。全体表示では房は下に垂れる枯葉の陰に一部隠れる。近景では弧を描く果柄、垂れる小穂、黄の実と茶の実、収穫後の切り残しが判別できる。
- セイヨウナシの葉の時期の小さい実は、取り付け点に向かって縮み、短果枝から垂れたまま残る。
- 実BVでオリーブ・ナツメヤシのultraにEditionの選択（元の版と新しいedition）が出て、新しいeditionの全姿を切り替えられ、`CE adoption: Adopted` と表示された。pageerrorは0件。

## 既定の姿の不変

T4のコミット（HEAD）を `git worktree` に取り出し、BVの全138版を引数なしで生成して、属性・index・mesh名のハッシュを変更後と比べた。138版すべて一致した。新しい8版（オリーブ・ナツメヤシのedition×4品質）が追加された。

## 残る点

- `scripts/verifyBvOliveOrchardReuse.mts`・`scripts/verifyBvDatePalmOrchardReuse.mts` はE01・E02時点の採用版（三角形のマーカー）を評価する一回限りのスクリプトで、CE採用の切り替え後はマーカー数と作者の確認で止まる。記録済みのJSONは当時の計測として残し、スクリプトは更新していない。
- 森林の木の結実（イチイの仮種皮、ナラのどんぐり、シデの苞、§7.2の任意項目）は制作していない。
