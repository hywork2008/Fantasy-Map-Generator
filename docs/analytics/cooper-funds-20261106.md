# 樽屋の資金不足と、売れずに消える町の産物（2026-11-06）

[start-stock-20261105.md](start-stock-20261105.md)§9の続きである。§9では、2101の木材の多い市場（1・6・10・11）で、樽屋が作る段階の資金不足（`execution:funds`）で止まり、エールの需要の約10%が樽で不足するとした。資金がなぜ足りないかを調べた。コードは変えていない。

  - 市場の金庫の残高と、町の金庫の合計も毎月記録する。
- ビールの飲まれた量は、[treeless-trade-20261106.md](treeless-trade-20261106.md)の`base/`のビールの計測（48か月）から、市場のビールの帳簿の月の増分で出した。

## 2. 仕組み

1. 町（Burg）の産物は、その周期の在庫（`BurgProductionState.inventory`）に入る。周期の終わりに`sellInventoryToMarket`で市場に売る。
2. 市場は、金庫の現金で買い取る（`Markets.sell`）。買い取れるのは、次の小さい方までである。
   - 金庫の残高（維持の状態を掛ける）。
   - 町ごとの割り当て（`allocateMarketProcurementBudgets`、金庫の残高を町の人口で分けたもの）。
3. 売れ残った分は、次の周期に持ち越されない。在庫はその周期ごとに新しく作るので、消える。
4. 消えた分の材料と賃金は、町の金庫から払ってある。売れないと町の金庫が減り、次の生産が資金不足（`execution:funds`）で止まる。

### 3.3 樽屋の資金不足

- 2101の市場11では、樽を月136出し、市場が買い取ったのは1だった。樽屋の町は材料と賃金を払ったまま収入が無く、金庫が尽きる（`execution:funds`、月8回）。
- §9の「資金」は、樽だけの問題ではない。町の産物を市場が買い取れないことの一つの表れである。

## 4. 分かったこと

1. **町の産物の約4分の3（値打ちで）が、市場に買い取られずに消えている。** 買い取りは、市場の金庫の現金と町ごとの割り当てで決まる。売れ残りは次の周期に持ち越されない。
2. **ビールの不足の主な原因は、樽でも穀物でもなく、これである。** 作った量はエールの需要の8〜9割あるのに、飲まれているのは3〜4割である。
3. お金は町の金庫に貯まり、市場の金庫に戻らない。市場の金庫に外から入るお金が少ない市場ほど、買い取りが少ない（[market-treasury-cash-20261031.md](market-treasury-cash-20261031.md)§3と同じ形）。
4. 町は、売れない物を作り続けて材料と賃金を失う。生産の決定は、市場の需要と在庫を見るが、市場が買い取れる額を見ない。

## 5. 家計の買い物の代金は市場の金庫に入らない（2026-11-06追記）

Aを実装する前に、買い手の代金がどこに入るかを確かめた。

- 家計は、ビール・ワイン・チーズ・レーズン・シードル・ペリー・牛乳・ぶどうを、市場の在庫から取る（`drawHouseholdDemand`、`foodProcessingLedger.ts`）。この時、代金を払わない。
- 町の家計は、手元の現金のうち蓄えを超える分の20%を、毎月「町の職人と店（服、修理、運送、エール、家賃）」に使う（`spendUrbanHouseholdSurplus`、`householdWealth.ts`）。この額は、その町の金庫（`burg.treasury`）にまとめて入る。市場の金庫には入らない。
- 市場は、町からビールを現金で買い取るが、家計が飲んだ分の代金を受け取らない。家計の飲み物と食品について、市場の金庫は払う一方である。
- これが、お金が町の金庫に貯まり、市場の金庫に戻らない（§4の3）理由の一つである。

このため、Aだけでは、家計が飲んだ分の未払いが返されずに積み上がる。

## 6. 直し方の候補

まだ実装していない。どれもSimulation設定で選べる形にできる。

| 候補 | 何を変えるか | 効くこと | 気をつけること |
| --- | --- | --- | --- |
| A. 委託の買い取り（掛け） | 金庫で払えない分も市場の在庫に入れ、町への未払い（穀物の`ruralGrainPayable`と同じ形）にする。家計や他の町が買った代金から返す | 産物が消えない。買い手がいれば、その場で飲まれる・使われる | 買い手のお金が足りなければ、未払いが積み上がる。返す順番と上限が要る |
| B. 売れ残りの持ち越し | 売れ残りを町の在庫として次の周期に持ち越し、生産の上限から差し引く | 産物が消えない。売れない物を作り続けなくなる | 市場の在庫に無いので、他の町や家計は買えない。飲まれる量は増えない |
| C. 買い取れる額で生産を止める | 生産の決定で、その周期の割り当ての残りを超える分を作らない | 材料と賃金の損が無くなる | 作る量が減るだけで、飲まれる量は増えない |
| D. 市場の金庫の流れを直す | 町の金庫に貯まるお金が、家計の買い物などで市場の金庫に戻る経路を調べて直す | 原因に近い | 範囲が広い。[market-treasury-cash-20261031.md](market-treasury-cash-20261031.md)の続き |

- 飲まれる量を増やすのはAとDだけである。
- §5のとおり、家計が市場から取る飲み物と食品の代金は市場の金庫に入らないので、Aだけでは未払いが積み上がる。
- E. 家計が市場から取る分の代金を市場に払う: 家計の飲み物と食品を市場の在庫から取る時に、町と農村の家計の現金から値段で払い、市場の金庫に入れる。町の家計の使い道（`spendUrbanHouseholdSurplus`）は蓄えを超える分から決まるので、先に払った分だけ自然に減る。Aと組み合わせると、家計の代金で樽屋や醸造所への未払いを返せる。
