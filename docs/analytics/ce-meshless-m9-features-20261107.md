# CE M9 詳細機能の追加受入

2026-11-07。[受入計画](../plan/ce-meshless-release-acceptance.md)の「次に進める作業」第3項を進めた。[機能対応表](../plan/data/ce-meshless-m9-coverage.json)の4群を固定入力で再検証した。旧自動森林の領域snapshotは一部受入とし、旧防御・旧港・急な造成境界は未受入と判定する。第3項全体は未完了で、公開区分は試験運用のまま。

## 実装した変更

- `copyLegacyCity`は旧森林plannerを使って自動森林の確定した境界を一度だけ解決し、セルを持たない独立領域へコピーする。空地の穴、水域・道路・施設などの旧plannerの除外を保持する。取り込み先では`forest`領域として保存・2D・3Dが同じ形状を使う。
- 同じ旧農地に森林が指定されていた場合、森林域を農地領域から除外する。分割による領域数の増減後も、後続のコピーIDで既存領域を上書きしない。
- 森林境界の取り込みは`snapshot`として報告する。旧設定の編集・自動再生成・樹木外観まで変換したとは扱わない。セルごとの開放／森林指定も、旧側で編集する情報として明示する。
- 旧詳細防御の稜堡・幕壁・外堡・堀・掩護道・通路・水門・付属施設・斜堤、城と墓地の部品・通路、船の荷役割当を、まとめた文書属性の報告に加えて個別に`unsupported`として報告する。元文書の保管と稼働する機能への変換を区別する。
- 型検査で既存の小路候補に`origin`・`normal`・`tangent`の型宣言がないことが判明した。実体と利用箇所に合わせて宣言を補った。実行時の生成処理は変えていない。

## 固定入力と判定

[観測JSON](ce-meshless-m9-features-20261107.json)に入力のSHA-256と結果を保存した。入力は`m9FeatureAcceptance.test.ts`で固定した旧生成設定・座標から再生成できる。大きな全量出力は保存していない。

| 機能 | 確認した契約 | 結果 |
| --- | --- | --- |
| 旧防御 | 旧生成器で作った稜堡都市、堀・通路が実在すること、native保存後の元文書復元、省略部品の個別報告 | 元文書を復元し、省略49部品を報告。防御の所有権・標高・外堡・斜堤・通路は変換されないため未受入 |
| 旧港 | 旧生成器の岸壁1、船4、稼働荷役1。船喫水と幅による航行判定、荷役の岸壁・クレーン参照、元文書復元 | 旧側の航行・荷役契約と元文書復元は成功。変換先には航行・荷役リンク・実寸船／表示状態の機能がないため未受入 |
| 旧自動森林 | 3×3の農地、中央の空地穴、隣接水域、4m幅道路。森林plannerとの双方向差分、農地との非重複、native／2D／3D | 空地あり3,200m²、水域追加後2,800m²、道路追加後2,624m²。双方向差分と重複面積は1e-5m²未満。境界snapshotを一部受入 |
| 急な造成境界 | 平坦基盤上の20m高の造成、内側0.25mの壁帯、格子に揃わない境界。独立式と実際の描画三角形の重心座標補間を257点で比較 | 高さ評価の最大誤差0m、描画の最大標本鉛直誤差15m。未受入 |

防御fixtureからは、防御と無関係な`fabric`と`ruralFieldSnapshot`を除いた。通常の旧生成文書は既存の6MiBコピー上限を超えたためであり、上限を引き上げたり、通常のコピー時に元文書を削ったりはしていない。このfixtureでの成功は、大きい旧文書のコピー成功を保証しない。

地形の比較は境界付近の三角形内部も含める。評価器が正しくても、2m間隔の描画格子は0.25mの急な壁帯を表現できない。15mは257点の標本最大で、連続領域での最大誤差の証明ではない。曲線位置の5mm規定を鉛直誤差の保証へ読み替えない。樹木外観・景観再生成・文化設定・他の旧自動景観も受入には含まない。

## 次に進める作業

1. 旧防御プランを独立した領域と参照へ変換する。特に所有権、堀の標高と水、外堡・斜堤の予約、門を通る通路を保存・編集・生成除外まで通して受け入れる。通常の旧生成文書がコピー予算に入らない点も設計する。
2. 港の水深・障害物・開放水面への航路、岸壁／クレーン／船の荷役リンク、実寸船と帆・砲門状態を変換先で稼働させる。
3. 今回の森林境界snapshotから、景観の再生成・外観・他の景観・文化設定へ受入範囲を広げる。
4. 造成境界を描画三角形へ拘束し、三角形内部も含む鉛直誤差の許容値と保証方法を定める。固定グリッドの密度を上げるだけで連続保証としない。

これらが揃ってから公開区分を再判定する。5,000人の施設不足と10秒目標も引き続き正式移行の条件に残る。

港の後続実装は[港受入記録](ce-meshless-m9-harbor-20261107.md)を参照する。上表の未受入判定から、平坦・海港・固定の航行・荷役・実寸船を一部受け入れるところまで進んだ。

景観の後続作業は[景観受入記録](ce-meshless-m9-landscape-20261107.md)で扱った。森林再生成・BV樹種・文化別墓地を一部受け入れ、次は造成境界の描画と連続鉛直誤差へ進める。
