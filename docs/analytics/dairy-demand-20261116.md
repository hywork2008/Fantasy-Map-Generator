# 乳製品の需要を伝統と値段で決めた計測（2026-11-16）

[dairy-demand.md](../plan/dairy-demand.md) の §3.1（伝統の量）・§3.2（値段の弾力）の計測。

## 1. 条件

- 地図2103、36か月、戦争なし・略奪なし。[run.sh](dairy-demand-20261116/run.sh)、記録は [basket.mts](household-basket-20261116/basket.mts)（12か月ごとの市場別の伝統・チーズの値段を足した）。

## 3. 読み取り

1. **値段は上限から下がった。** 中央値は基準の値（14）の約3倍から約1.6倍になった。需要を満たす割合は30%から82%に上がった。
2. **食べた量は減り、牛乳が28%余った。** 値段が基準の値の1.6倍のままなので、値段の項（1.6^−0.8 ≒ 0.69）で需要が伝統の量の約7割に下がる。需要が下がった分、チーズを作らなくなった。
   - 値段が下がりきらないのは、需要の不足が残る市場で値段が上がり、余る市場の値段が下がるまでに時間がかかるためとみられる。値段の最小は10で、牧畜の土地では基準の値より安い。
3. **基準の値段を作る費用から決めること（§3.2）が次の課題。** 今の基準の値14より作る費用が高ければ、1.6倍の値段は釣り合った値段で、需要を下げすぎている。牛乳の農家渡しの値段（2.99）× 10 L/kg だけで約30になり、基準の値14より高い。基準の値段を費用から取ると、値段の項は1以上になり、余った牛乳が使われる見込み。
4. 塩の値段は変わらない。
