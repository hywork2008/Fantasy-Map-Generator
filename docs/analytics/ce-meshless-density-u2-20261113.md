# メッシュなしCE 市壁内の建物の密度の事前調査（U2）

2026-11-13。[受入前の改善](../plan/ce-meshless-pre-acceptance-improvements.md)のU2。市壁の中の土地が何に使われているかを、生成結果の記録（ファブリックの住宅・配置・残地・道路）から測った。目標の姿は、Rothenburg ob der Tauberのように街路に沿って建物が隙間なく並ぶ街区である（ユーザー提示の上空写真・街並み）。

## 訂正（2026-11-13、U3の作業中）

最初の計測は、施設なし（`medieval`）の行も設定に`facilityLayout: "population"`を入れて生成していた。エディターでは方式は設定から決まり（`vectorUrbanMode`）、施設なしの町は施設の土地を見込んで敷地を広げない。施設なしの合成の町の市壁は、施設の土地の分だけ広く測られていた。計測を直し、JSONを置き換え、下の表と「わかったこと」の2を訂正した。FMGの町の施設なしは記述子の円で市壁を描くので、obernの1行（市壁内24%→32%）を除き値は変わらない。需要4倍のJSONの合成3,000人の施設なしは、訂正前の設定のままである。

## わかったこと

1. **区画の割り方そのものは、メッシュありと同じ密度まで建つ。** 需要を4倍にすると住宅は街区の土地の43%（市壁の面積の約38%）まで建ち、メッシュありの0.33〜0.38と並ぶ。区画の中央値も同じ30〜32 m²。区画の割り方を作り直す必要は小さい。
2. **合成の町（CEで単独生成）の市壁は、ほぼ狙いどおりの大きさ。**（訂正）施設なしの空き地は20〜26%で、設計の狙い（区画の8割を建てる、`MESHLESS_TARGET_FILL`）に近い。最初に「約1.8倍大きすぎる」としたのは、施設の土地を見込んだ敷地で施設なしの町を測った誤りだった。ユーザーの「市壁を広く取りすぎ」という仮説は、合成の施設なしの町では当たらない。施設ありの町は、施設の土地（庭を含む）の見込みの分だけ市壁が広い。
3. **FMGの町は逆に、市壁が小さすぎる。** 市壁の面積はメッシュありの中心部の1/2〜1/4で、人口の24〜76%（施設ありでは4〜19%）しか市壁内に住めない。FMGの記述子の町は、合成の町のような需要からの大きさの計算（`walledScale`・`meshlessCityRadius`）を通らず、記述子の`cityRadiusMeters`の円に内接する形で市壁を描く（`editorInput.ts`の`!native`の分岐）。市壁は円の45〜71%（gothengsfeld 51%、erente 45%、obern 71%）しか囲まない。形の面積比（稜堡・多角形）と、回転の候補の縮小（0.94・0.88倍）が効いていると見ているが、内訳は測っていない。「市壁内に空き地が多いのに郊外の住宅が多い」という観察は、この町の種類による。
4. **市壁内の空き地には、需要と関係なく残る分がある。** 区画が全部建っても街区の土地の15〜16%が残る。区画が届かない街区の奥と、区画の間の隙間である。Rothenburgの街区は奥まで敷地が届き、裏同士で接している。
5. **施設の敷地の31〜41%は庭（建物の無い敷地）である。** 施設は最小敷地（`minimumSite`）を置き、触れた区画を区画線まで丸ごと取るので、建物の周りに余白が残る（[施設の街区の埋め方](../plan/ce-meshless-gate-ribbon-growth.md#11-施設モードの街区の埋め方2026-11-11)）。「施設の周りに広場的な余白がある」という仮説は当たっている。
6. **施設の数は市壁内の広さを見ていない。** FMGの施設ありでは施設が街区の土地の25〜50%を取り、住宅は2〜4%に押し出される。施設は人口から要求され（gothengsfeld 235件）、その多くが市壁内（core）を求める。市壁が小さい町では、施設が市壁内を占め、住民は郊外に住む。
7. **郊外の帯は、住む人がいなくても建つ。** 合成3,000人の施設ありでは、市壁外の300棟のうち人の住む住戸は6戸。帯の長さは市壁内に収まらない見込みの住戸から決まるが、見込みと実際が食い違っても、帯の住宅は需要に関係なく建つ（P7a）。
8. **街路と小路は街区の土地の23〜29%。** obernだけ街路が39%と多い（市壁が小さく、幹線が街区を細かく分けている）。

## U3への提案

順に効果が大きいと見込むもの。

1. **市壁の大きさを需要から決める。** FMGの町にも、合成の町と同じ「必要な住戸を収める市壁内の面積」の計算を通し、記述子の円より大きくてもその面積を囲む。（訂正: 見積りの較正し直しは不要だった。）
2. **市壁内は需要で止めず、区画を埋める。** 住戸の需要を満たした後も市壁内の区画は建て、住民の割当ての無い建物は店・作業場・倉庫などの付属の建物とする（メッシュありの1.25倍に合わせる）。人の住まない郊外の帯の住宅は、市壁内が埋まるまで建てない。
3. **施設は建物の外形で区画を取る。** 施設の敷地を最小敷地ではなく建物の外形（と出入口の前の最小限）にし、残りの区画に住宅・付属の建物を建てる。施設同士・施設と住宅が区画線で接して並ぶ（Rothenburgの写真の施設級の建物の並び）。
4. **市壁内の施設の量を市壁内の広さで抑える。** 市壁内に置く施設の土地が街区の土地の一定割合を超える分は、郊外（門の外の帯）に回す。
5. **街区の奥まで区画を届かせる。** 区画の奥行きを街区の奥行きの半分まで伸ばし、裏同士で接するようにする（残地15%を減らす）。

1・2で市壁内の住宅の被覆率をメッシュありの水準に、3・4で施設ありの市壁内を施設なしと同じ水準に近づける。

> 2026-11-13追記: 本書で「列の間の中庭」「区画が届かない街区の奥」とした空き地の大部分は、区画の丸めの不具合で建たなかった区画だった。[訂正の記録](ce-meshless-lot-rounding-u3-20261113.md)を参照。
