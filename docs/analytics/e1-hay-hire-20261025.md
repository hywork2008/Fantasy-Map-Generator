# E1: 干草作りの雇い人と収容力の内訳（2026-10-25）

親計画§7.50の検証記録。比較元は§7.49（[e1-hay-boon-20261025](e1-hay-boon-20261025.md)）。固定入力・設定は同じで、48か月まで実行した。計測のコードは雇い人の変更までで、草地の上限の変更（§7.51）は含まない。

## 変更

`applyHaymakingMutualAid`で、隣接セルの互助で刈りきれなかった干草作業を、同じ市場圏で手の空いている大人に回す。来るのは穀物の収穫の手伝いと同じ移動率（中世25%）の分。農繁期に日雇いが市場圏を動いていたことに基づく。賃金の支払いはまだ扱わない。

## 収容力の内訳（World、36か月、§7.49のコード）

`scripts/auditCarryingCapacity.mts`。牛100人あたり: 目標58 → 草地29（49%） → 年間飼料・越冬の干草は制約なし → 前年の給与率16（57%） → 実頭数9.7。

- 目標の群れに必要な草地は2,750万ha、休閑地の放牧を除いた計画は1,864万ha、実際の割り当ては1,260万ha。588セルで草地の上限に当たっていた。
- バイオーム別（`scripts/auditPastureByBiome.mts`）では、畑を持つ温帯雨林・火山性土壌で、上限で収まるのは必要量の35〜40%。森林系の上限が未利用地の10%のままのため。Worldの居住地は寒く、草の生産は420〜800kg/ha（基準1,500）。
