# 賃金の倍率と、町の金庫・町の主食・家計のお金の出入り（2026-11-17）

[wage-chain-20261117.md](wage-chain-20261117.md) で数えていなかった指標（per-capita-income-scale.md §4）と、農村の家計の収入の内訳を数えた。

## 1. 条件

- 作り直した地図2103、36か月、戦争なし、略奪なし。[run.sh](town-health-20261117/run.sh)。
- 倍率1.5と5。どちらも人手・値の直し（wage-multiple-1300.md §4の手順1・2）の後のコードで、倍率だけが違う。
- 観測（[basket.mts](household-basket-20261116/basket.mts)）に足したもの: 金庫が1未満の町の割合、町の主食（需要・満たした量・払った額・お金の不足・在庫の不足）、家計のお金の出入り（シムの段ごと）。

## 3. 読み取り

1. 倍率5でも、金庫が0の町と町の主食の不足は増えない。per-capita-income-scale.md §4の目安を満たす。
2. **農村の家計の収入は、倍率によらず約130万で同じ。** 収入は、主食・家畜の売り、国の公共の支出、市場の余りの払い出しで、賃金に連動するものが無い。主食の値段は下限0.8のまま。
3. 倍率5で、町の家計は賃金の分だけ増え、農村の家計は少し減る。農村が町で使う額（`getRuralTownNeed`）は賃金に連動して増えるが、収入は増えない。農村の毛布の不足（22% → 19%）はこれによるとみられる。
4. 史実の農村の家は、収穫期の日雇い・荘園の労働・糸紡ぎなどで賃金も得ていた（記憶による理解、史料は確かめていない）。シムの農村には、その賃金の入り口が無い。
