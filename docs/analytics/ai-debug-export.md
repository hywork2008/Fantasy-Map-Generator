# AIデバッグ用スナップショット・エクスポート機能

このドキュメントでは、ローカル開発環境（Vite）における AI連携用デバッグデータ（スナップショット）のエクスポート機能について解説します。

## 機能の概要
Fantasy Map Generator の画面上の操作（マップ生成、時間を進めるなど）によって変化する「軍隊、外交、都市、州」の動的な状態をキャプチャし、AIとの打ち合わせ等で利用するために、ローカルのファイルシステム（`temp/debug` フォルダ）に JSON ファイルとして直接保存する機能です。

### `/api/dev/dump-state` エンドポイントについて
ブラウザ上で動く JavaScript は、セキュリティの制約からユーザーの同意なしにローカルディスクへ直接ファイルを作成・保存することはできません（通常はダウンロードダイアログが開きます）。

この制約を回避するため、`vite.config.ts` の開発用サーバー（`npm run dev`で立ち上がるNode.jsサーバー）にカスタムミドルウェアを追加しています。

#### 動作フロー
1. **ブラウザ側**: UIの「AI連携スナップショット」ダイアログで対象の世代を選択し、エクスポートを実行します。
2. **通信**: ブラウザは、選択された状態データを JSON 形式にまとめ、ローカルサーバーの `/api/dev/dump-state` に対して `POST` リクエストを送信します。
3. **サーバー側 (Vite)**: 
   - `vite.config.ts` 内のミドルウェアがこのリクエストを受け取ります。
   - プロジェクトのルートディレクトリに `temp/debug` フォルダが存在するか確認し、なければ自動生成します。
   - 受け取った JSON データを、タイムスタンプを付与したファイル名（例: `fmg_state_dump_1739000000000.json`）で保存します。
4. **完了**: ファイル保存が完了すると、サーバーからブラウザへ成功レスポンスが返り、UI上に完了の通知が出ます。

## なぜこの仕組みを採用したか
- **シームレスな体験**: ブラウザのダウンロードプロンプトを介さず、ワンクリックで裏側にデータを蓄積していくため、作業（複数世代のログ出力など）のテンポを崩しません。
- **データサイズと管理**: フルサイズのセーブデータ（数十MB）ではなく、シミュレーション・デバッグに必要なデータ（軍隊や外交関係など）のみを抽出し出力しているため軽量です。
- **AIとの連携**: 出力されたファイル群は、ターミナルやIDE側から AI (LLM) へ直接コンテキストとして渡すことができ、効率的にシミュレーションの挙動（Advance Time による軍隊の移動など）の分析が行えます。

## ファイルの保存先
エクスポートされた JSON ファイルは以下のディレクトリに保存されます。

```text
/temp/debug/fmg_state_dump_<timestamp>.json
```

※ `temp/` ディレクトリは `.gitignore` に追加するなどして、コミットに含まれないように運用することが推奨されます。
