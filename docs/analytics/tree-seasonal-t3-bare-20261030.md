# T3 冬枝（落葉の姿）の全落葉樹への展開

作成日：2026-10-30。設計は [BV樹木の季節の姿と結実層の設計](../plan/bv-tree-seasonal-appearance.md) §6・§9・§15。

## 方式

T1のリンゴ・ブナと同じく、各生成器が葉のある時と同じ骨格の上に冬枝を描く。新梢ごとに「出る位置・先端・葉の位置」（`LeafShoot`）を記録し、`winterTwigs` で新梢の途中から外側の葉の位置へ小枝を伸ばす。小枝の数は `WINTER_TWIGS`（low 0・medium 2・high 3・ultra 5）。葉と果実のmeshは登録側（`applySeasonalLook`）が外す。生成器の乱数は姿に依存せず、葉の位置は全品質で同じ。

| 樹種 | 生成器 | 冬の姿の特徴 |
| --- | --- | --- |
| セイヨウナシ・セイヨウスモモ・ヨーロッパグリ | 各専用 | 果柄を描かない。lowは葉の時に省く主枝・新梢を足す（セイヨウナシのlowは新梢を半分にして目安内） |
| イチジク | `commonFig.ts` | 細い小枝の霞ではなく、太く短い枝を最大2本ずつ |
| シデ・ナラ | 各専用 | ナラはやや太い小枝 |
| フユボダイジュ | `smallLeavedLime.ts`、low は `temperateTreeLod.ts` | lowは5方向の主枝と2本の頂枝を描き足す。mediumは小枝1本ずつ。Opus版・Codexの比較用mediumは独自の冬枝を持たないので、同じ樹種の登録された品質の冬の木を表示する |
| シラカバ | `borealTrees.ts` | 垂れる細い小枝。lowは12本の主枝を描き足す |
| ハンノキ | `wetTemperateTrees.ts` | 既存の木質の球果を残し（`bareKeeps`）、high・ultraで枝先に冬の雄花序を3本ずつ吊るす |
| ギョリュウ | `saltTolerantTrees.ts` | 羽状の小枝を落とした赤褐色の細い枝。lowは弧を描く主幹を全長描く |
| ナナカマド | `uplandTrees.ts` | 実も落ちた冬の枝 |
| シダレヤナギ | `sacredGardenTrees.ts` | 小枝ではなく、垂れる枝（むち）を黄緑の茎として全長描く。品質で本数と節数を間引く。low・mediumは枝元から描いて浮かないようにした |

## 目視の所見（実BV、headless Chromium・Metal、12樹種×4品質の冬の一覧）

- 全樹種で、葉のある時と同じ枝ぶりのまま外へ広がる冬の木になった。セイヨウナシは縦長、セイヨウスモモは盃形、イチジクは太く低い枝、ナラは曲がった太い枝、ギョリュウは赤褐色の細い枝が見分けられる。
- シダレヤナギの初版はlow・mediumでむちが枝から浮いた。葉の時のlow・mediumは枝元の短い弧を描かないためで、むちを枝元から描くように直した。
- lowは目安の500三角形に収めるため主枝と一部の側枝だけで、シラカバ・ナナカマド・ギョリュウは細い骨組みに見える。遠景の表示として受け入れる。
- ハンノキの雄花序は全体表示では判別できない大きさで、近景で見える。
- pageerrorは0件。
