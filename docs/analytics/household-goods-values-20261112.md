## 4. 読み取り

1. 品が払える値段になり、長靴と蝋燭は見込みの需要をほぼ満たした（革の品は約8割）。農村の家計の町の額を取り合うことが無くなった。
2. 革は、使い道が出た量の約6割（長靴約195万枚・革の品約80万枚）になり、在庫の増えは年約90万から約14万（2102）になった。値段は下限から離れた（0.27 → 0.45）。
3. 獣脂は使い道が約2倍になったが、出た量の約4割で、在庫はまだ年約28万樽増える（[byproduct-history.md](../plan/byproduct-history.md) §5の2・3、革の仕上げと外への出口）。
4. 町の家計は約2倍になった。品の代金が安くなり、町の家計と市場のお金に残った。
