# 布から衣服を仕立てる量が止まる所（2026-11-17）

[textile-basket-scale.md](../plan/textile-basket-scale.md) §3.7。羊毛4ロットにした後、毛の布・亜麻布が在庫に残り、衣服の在庫が0のままである理由を、生産の記録（町: `UrbanCraftCapacity.productionDiagnostics`、農村: `ruralTextileProduction.homeDiagnostic`）で数えた。

## 1. 条件

- 地図2103、36か月、戦争なし・略奪なし、既定。[run.sh](tailoring-20261117/run.sh)、記録は [basket.mts](household-basket-20261116/basket.mts)（`tailoring` を足した）。3年目の月平均。

- 町の工房の人手（人口点）は月634、うち使われないのが500、織物の仕事が67。
- 「作る目標が0」（`outputTarget`）は、目標の量が0以下の時（`planGoodAction`）。衣服の目標は、家計が払える量 − 市場の在庫 − 手元の在庫（`textileDemand.ts` の衣服の生産の目標）。家計が払える量は財布（手持ちの月5%）で決まる。

## 3. 農村の家の手仕事（月平均、全ての市場の合計、ロット）

| 経路 | 1回目で作った量 | 1回目の主な止まり | 2回目（毛布の人手を衣服へ戻す）で作った量 | 2回目の主な止まり |
| --- | ---: | --- | ---: | --- |
| 羊毛 → 毛の衣服 | 49.1 | 材料29・人手18 | 0.02 | 人手・材料（v1では支払いの端数と記録） |
| 毛の布 → 毛の衣服 | 8.3 | 材料7.6 | 0 | 人手・材料 |
| 麻 → 衣服 | 20.8 | 材料19.7 | 0 | 人手・材料 |
| 綿 → 衣服 | 5.0 | 材料5.0 | 0 | 人手・材料 |
| 羊毛 → 毛布 | 46.1 | 人手43 | — | — |

- 2回目は、ほぼ何も作らない。1回目の記録（v1）では、止まった理由が「支払いが1セントに満たない」（`paymentPrecision`）と出ていた。
- 確かめた結果、誤りではなかった。1回目で、その市場の材料の在庫か、家の人手を使い切っている。2回目に残るのはわずかな量で、その代金が0.01未満になる。記録の理由が、本当の上限を隠していた。
- 記録の理由を直した（`ruralTextileProduction.ts`、代金が0になる時も本当の上限を主な理由に残し、端数は副の理由に足す）。作る量とお金の動きは変わらない。直した後の計測（tailoring-2103.json）では、2回目の止まりは市場の約半分が人手、約半分が材料、端数は約1つ。

## 4. 読み取り

1. **町は、作る目標（家計が払える量）で止まる。** 人手は余っている。目標は財布（§3.2）で決まる。
2. **農村の1回目は、材料（その市場の羊毛・麻の在庫）と人手で止まる。** 
3. **農村の2回目（毛布の人手を衣服へ戻す）は、ほぼ動いていない。** 1回目で材料か人手を使い切っているため。誤りではない。
4. 町の毛布は「在庫が多い」で止まり、毛布の需要の不足（72%）と合わない。毛布の在庫の見方（市場ごとか、全体か）を確かめる。
