# E0 計画停止箇所・家内作業の制約と完了判定（2026-10-23）

計画不採用の未判定箇所を実際の停止ガードへ接続し、家内作業の衣服/寝具両方に、材料・労働・予算・支払丸めの診断を追加した。固定2世界の既存経済結果を変えず、計画診断のunknownは両世界で0になった。

**E0を現行モデルの基準観測・診断として完了とする。** 所得層別配分・未モデル化の技能/設備・家畜肉kgを測定済みとする判定ではない。完了判定とチェック更新より先に、これらの扱いを[統合計画§7.12](../plan/historical-economy-production-consumption-circulation.md)へ理由付きで記録した。追記した適用範囲と後続工程は下表の通り。

## 計画診断の停止箇所

`buildImmediateManufactureCandidate`の最大歩留りが非有限/0以下の場合、材料検査の後でnullを返すが理由を残していなかった。次の実ガードに診断を加えた。

| 診断 | 実際の停止 |
| --- | --- |
| nonPositiveRecipeYield | 最大歩留りが0以下 |
| unboundedRecipeYield | 最大歩留りが非有限（空の材料一覧等を含む） |
| recipeCycle | 下位材料計画が既に辿った商品へ戻る |
| noPreparationAction | 実行可能性検査を通っても、次に作る下位材料の作業が選ばれていない |

材料の存在検査には`0.001`単位の許容がある。この許容より小さい正の必要量に対して在庫0でも材料検査を通る一方、実在庫から求める歩留りは0となる。さらに下位材料の残必要量も許容以内なので準備作業が選ばれず、結果として計画はnullだった。今回、許容・歩留り・採否を変更していない。単位と数量閾値の整合は対象品のE2で確認する。

| 固定12か月の計画診断 | Province | World |
| --- | ---: | ---: |
| 修正前unknown | 9 | 3,239 |
| 修正後unknown | 0 | 0 |
| nonPositiveRecipeYield + noPreparationActionだけの評価 | 9 | 3,239 |
| 上記に材料・労働の併存理由がある評価 | 0 | 697 |
| 上記に採算の併存理由がある評価 | 0 | 4 |

WorldのnonPositiveRecipeYield主因は計3,940回。旧unknownの3,239回だけでなく、以前は後から遭遇した材料/労働・採算だけを記録していた701回も、最初の歩留りガードが主因となった。既知の評価機会を追加したり、原因を二重集計したりしたものではない。採用候補・製造結果は同じ。汎用unknownは将来の未観測停止を検出するため残し、この2世界で0になったことを全世界の証明とはしない。

## 家内作業の制約

既存の`RuralTextileProduction.homeDiagnostic`へ、実際の経路評価を記録する。従来の寝具診断は維持し、衣服も含めて商品・原料・織布の有無・初回/寝具の未使用労働を解放した後の再試行を分ける。見積り関数には実績診断を作らない。

各経路は必要量、現金・在庫・労働による製造上限、実納品、最初に拘束する主因と数値上の併存制約を持つ。価格不明・原料市場行なし・支払精度以下・実引落し失敗も区別する。正の製造量でも必要量を満たさない経路には拘束する主因があるため、主因のある経路数を失敗回数や未充足人数としない。代替経路や再試行の未充足を足し合わせず、家内加工後の残必要量を別に記録する。

| 家内経路の主因・評価回数 | Province | World |
| --- | ---: | ---: |
| 材料 | 103 | 1,887 |
| 支払丸め（0.01通貨単位未満） | 111 | 1,093 |
| 予算 | 2 | 366 |
| 労働 | 0 | 128 |

Worldで材料と労働の数値上の制約が併存した場合も保持する。上表の主因は重複しないが、併存制約の件数は重複する。ゼロ労働で経路評価自体を行わない呼出し、利用可能レシピがない呼出しも別のstatusで記録できる。今回の実績ではすべてevaluatedで、Province 12市場決済、World 193市場決済（12回の全市場決済、途中の市場追加を含む）だった。
