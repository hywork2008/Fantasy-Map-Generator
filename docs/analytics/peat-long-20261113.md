# 泥炭の6年（2026-11-13）

[peat-cut-plan-20261113.md](peat-cut-plan-20261113.md)で、泥炭が年ごとに増えることが36か月で止まらなかった。木材と泥炭を値段で分け（[fuel-price-share.md](../plan/fuel-price-share.md)）、泥炭を1年の平均で掘る（[peat-cut-plan.md](../plan/peat-cut-plan.md)）既定の設定で、どこで落ち着くかを72か月で見た。

## 3. 読み取り

1. 泥炭は4年目から年約23〜25万俵で落ち着いた。暖房の熱の約3%で、沼の採れる量の上限（年約262万俵、[peat-growth-20261113.md](peat-growth-20261113.md)）の約1割で止まった。上限より下で止まるのは、泥炭と木材の熱あたりの値段が3年目から同じになり（在庫で重みの値段の比0.33・0.34）、値段で分ける分がそこで落ち着いたためと考えられる。
2. 年末の在庫は、4年目の約2.0万から6年目の約3.3万俵へ少しずつ増えたが、増え方は年ごとに小さくなった。
3. 町の家計は6年で545千から286千へ下がり続けた。泥炭の変化の前（1〜2年目）から下がっており、泥炭とは別の動きと考えられる。
