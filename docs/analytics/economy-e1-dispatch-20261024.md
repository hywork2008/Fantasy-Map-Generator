# E1 生体の出荷と市場入荷の保存（2026-10-24）

群れからの控除後に文化倍率・産地ボーナスを追加していた経路、四半期キャッシュに控除済み出荷を保持して再搬入する経路、市場側で期待値をもう一度整数化する経路を修正した。

生体は決済ごとに生産希望量を再計算し、倍率・ボーナス・季節係数を適用した後、実在する整数頭数だけを控除して同量を市場へ加える。馬は既存の25頭/商品単位を維持する。セル・種別の処理済み期間と1頭未満の需要端数を保存し、同期間の再実行を防ぐ。不足した整数頭数は繰越さず、端数需要を実在動物の在庫とは扱わない。旧市場catchの期待値は新出荷へ移さない。

詳細モードの既存初期群れの生成規則は利用する。簡易モードには物理群れがなく、同モードの出荷を物理保存の証拠とはしない。出荷観測の前後頭数は保存対象外とし、保存には期間・需要端数だけを追加した。所有者別shipment・輸送中在庫・共通解体は今後の実装である。

[比較JSON](economy-e1-dispatch-comparison-20261024.json)と[全量ハッシュ](raw-observations-20261024.md)を保存した。前回と同じStandardのWorld102 / Province101、遠隔交易on・襲撃offで12か月を確認。両入力とも対象期間15601〜15612の12決済で、種別ごとの群れ控除＝実出荷＝市場入荷が許容差1e-6頭以内に一致した。World計3,500頭、Province計326頭。セルごとの最大誤差はそれぞれ1.14e-13頭、1.43e-14頭で、未追跡群れ由来の出荷は0だった。準備時の初期化は観測開始前であり、この合計に含めない。

Worldの飼料不足率は48.0096%→47.9916%、Provinceは0%を維持。都市穀物不足は両入力0、農村不足はWorld0.03・Province0.01台帳単位のまま。この12か月から長期収束や冬前屠畜の効果を主張しない。

関連テストは市場60件、家畜・飼料62件が成功。固定Provinceの47日＋保存再読込＋30日と連続77日で、出荷台帳・群れ・生体市場在庫・生産cadenceの一致を確認した。経済領域全体の比較では依頼掲示/契約や輸送季節係数に差が出たため、全経済・全世界の保存再現性の成功とはしない。型チェック、変更ソースのBiome、差分空白チェックも成功。監査mtsは既存Biome設定の対象外で、実行によって確認した。

次は、由来・所有者を保持するshipmentと共通解体の接続を進める。肉・脂・皮の質量配分と商品単位の未校正を解決してから冬前の選択的屠畜へ接続する。E1/W1全体は未完了。
