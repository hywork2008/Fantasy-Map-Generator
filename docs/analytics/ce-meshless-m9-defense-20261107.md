# CE M9 旧防御プランの意味変換

2026-11-07。[詳細機能の追加受入](ce-meshless-m9-features-20261107.md)の後続作業。平坦・内陸の固定稜堡都市について、旧防御49部品をセル参照のない防御プランへ自動変換し、一部受入とした。[観測JSON](ce-meshless-m9-defense-20261107.json)に固定入力のSHA-256と結果を記録した。対応表の防御群は`limited`、公開区分は試験運用を維持する。

## 変換したもの

`environment.defenses`に独立した防御プランを追加した。稜堡・幕壁・外堡・堀・掩護道・斜堤・付属施設・通路の形状と所有者を保持する。稜堡・幕壁が参照していたmesh edgeは、壁曲線上の始点・終点のアンカーに置き換える。市民通路は変換済みの門と道路、守備通路は幕壁と外堡への参照を持つ。採用された防御プランにmesh・face・edge・vertexのIDは残さない。

旧コピー処理は、星形の外壁を一定幅の帯へ変換した際の`width-fold`で外壁全体を捨てていた。また、コピー済み壁を最初から固定していたため、門の作成が`fixed-path`で拒否されていた。防御を持つ文書では壁と道路を元の直線区間へ分け、座標と共有点を保つ。鋭い角の質量は防御プランが所有する。門はコピー組立中だけ作成可能にし、検証済みの採用結果を固定する。通常の編集から固定壁を変更できるようにはしていない。

変換は防御プラン単位で行う。所有者、壁区間、門・道路、堀の標高や橋角度が契約を満たさなければ、プランを部分採用せず拒否理由と部品ごとの未対応を報告する。元文書は引き続き復元できる。

## 保存・生成・描画

- **保存と固定所有**：部品ID・所有者・参照・絶対標高・水位をnativeに保存する。欠けた所有者、門、壁、範囲外アンカー、非有限標高を読込時に拒否する。固定防御の改変は依存更新でも拒否する。生成と都市配置のfingerprintに防御を含める。
- **生成予約**：稜堡・外堡・堀・掩護道・斜堤・付属施設・通路を予約領域として都市生成へ渡す。表示用の色や単なる元文書保管に留めず、建物の候補地から除外する。
- **2D／3D**：同じ採用済み防御形状を描く。3Dは各頂点の絶対標高で稜堡・幕壁、堀底・岸、橋を構成する。門の通路で幕壁を切り抜き、堀の範囲では基盤地面も切り抜く。水堀は保存水位で描く。堀底や岸など厚さのない面は二重面を作らない。
- **橋角度**：乾堀と水堀の通過を検査し、共通の`bridgeSkewPolicy.ts`で時代と技術の上限を判定する。橋は2点の直線として保存する。制約を満たさないものを描画側で補正しない。

## 残る制約と次の作業

今回の変換は固定の平坦・内陸プランを対象とする。起伏地形、水際・水門による防御の中断は、地面と水の権威を保持する処理が揃うまで明示的に拒否する。Freeform地形との併存も読込で拒否する。旧城の詳細プラン、詳細防御の編集UIや部品選択は今回の受入に含まない。斜堤に保存標高がない旧形式では、平坦地の薄い面として描くため、これを連続造成の保証とは扱わない。

次は旧港の航行・荷役・実寸船を、変換先で稼働する参照へ変換する。防御の起伏／水際・旧城・編集、景観の再生成・文化、造成境界の連続鉛直誤差も正式移行の条件に残る。人口・施設・生成時間の既存条件も変更しない。
