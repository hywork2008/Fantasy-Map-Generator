# 町のエールの需要を史料に合わせた後の観測（2026-11-03）

設計書: [urban-craft-staffing.md](../plan/urban-craft-staffing.md) §10.5。前の段階は [economy-start-s4-20261103.md](economy-start-s4-20261103.md)。

- 入力: S4と同じseed 2101〜2104・同じ設定で、地図を生成し直した。都市・川・陸地の数はS4と同じである。
- 平和モード、60か月。手順はS4と同じ。`foodprobe.mts`に大麦・小麦・ライ麦・燕麦の在庫と値段、町の主食の充足の割合（`urbanFedShare`）を加えた。

## 1. 変えたこと

- 町（市場にぶどうが入らない町）のエールの需要を、大人1人あたり年48 → 300 Lにした（`ALE_TARGETS.urbanLitersPerAdultYear`）。農村とワインの地域の町は48 Lのまま。
- 樽の1人あたりの目標を、同じ根拠で年0.0125 → 0.078樽にした。

## 4. 分かったこと

- **ビールは利益が出ないので作られない。** seed 2101の6か月の診断では、ビールの計画は「利益が出ない」（`profitability`）が約1,400回、大麦の買い付けの失敗が44回で、実行できたのは7回だった。大麦の財の価値は0.9だが、市場の値段は1.6〜1.9と約2倍ある。原料（大麦1＋樽0.4）が約2.25になり、ビールの値段2.1〜2.7では最低の利益率に届かない。
- **大麦の高値はエールの需要のせいではない。** 同じ地図でエールを48 Lに戻して6か月走らせても、大麦の値段は1.74〜1.85で同じだった。
- **樽は作り置かれ、樽屋は休む。** 樽の目標を6倍にしたので、生成時に月3,900〜7,400ロットの樽が作られた。ビールが増えないので樽は売れず、在庫の上限で樽屋の仕事が止まる。
- 都市人口・主食の充足・町の財布は、ほとんど変わらない。
