# T2 配色・表示だけの季節の姿：全樹種への展開

作成日：2026-10-30。設計は [BV樹木の季節の姿と結実層の設計](../plan/bv-tree-seasonal-appearance.md) §4・§9・§14。

## 方式

既存の生成器は変更せず、`src/buildings/landscape/seasonalLooks.ts` の `applySeasonalLook` が生成済みのモデルに配色の変更と部品の除去をかける。モデルは登録の約束どおり pickables[0]＝木部、[1]＝葉、[2]＝別meshの果実（ある樹種のみ）である。

| 操作 | 対象 |
| --- | --- |
| 葉の配色（紅葉・秋の配色） | 葉のmesh。ナナカマドの実など葉に混ざった部品は色で除外 |
| 果実meshの配色 | 未熟果（レモン・コーヒー）、熟したいが（クリ。開いたいがはT5まで色だけ） |
| 果実meshの縮小 | 葉の姿の小さい緑果（セイヨウナシ・セイヨウスモモ・イチジク、high・ultraのみ） |
| 果実の部分集合 | 収穫後のレモン（15%）、カカオ（30%を小さい緑の若果に） |
| 果実meshの除去 | その他の収穫後、medium・lowの葉の姿 |
| 葉に混ざった部品の除去・配色 | オリーブの三角形の実（完全一致の色）、ナツメヤシの実の点、ギョリュウの花、ナナカマドの実（彩度の高い赤・桃） |

果実の1個ずつは、頂点の共有と位置の一致でつながる三角形の塊として識別する。部分集合は塊の重心の位置のハッシュで選ぶので、同じ木では毎回同じ実が残る。

引数を省略すると `applySeasonalLook` はモデルをそのまま返すため、既定の姿は変わらない。リンゴ・ブナは生成器が姿を直接描く（T1）。フユボダイジュのOpus版（high・light）とCodexの比較用mediumにも同じ配色を通した。

## 目視の所見（実BV、headless Chromium・Metal、3品質×全姿の一覧画像）

- 紅葉：シデ・ナラ・フユボダイジュ・シラカバ・シダレヤナギ・ナナカマドが、樹種ごとの色（黄、褐色、赤）に変わり、形は変わらない。ナナカマドの実は秋も赤いまま残る。
- 落葉果樹の秋の配色（セイヨウナシ・セイヨウスモモ・イチジク・ヨーロッパグリの実・収穫後）は全品質で揃う。
- ギョリュウの葉の姿は桃色の花穂が消え、全品質で緑の羽状の枝だけになる。
- 実の変化（レモンの緑果・コーヒーの緑果・オリーブの緑の実・ナツメヤシの茶色の実・クリの茶色のいが）は小さく、BVの全体表示では判別しにくい。近景で確認できる。立体の実への置き換えはT5。
- 初回、フユボダイジュのmedium（Opus）で紅葉が効かなかった。BVが採用するOpusのmediumの版が姿を受け取っていなかったためで、版の `create` を直して全品質で効くことを確認した。
- 収穫後に果実を外しても、木部に含まれる果柄（リンゴ・セイヨウナシ等）は残る。小さな短い枝として見え、T5で結実層へ移すまで受け入れる。

## 品質間の明るさ

T1で、ブナの紅葉がmediumではultraより明るく見えた。原因を確かめるため、BVの画面の上半分で背景以外の画素の平均輝度を測った（幹・地面の一部を含む概算）。

| 樹種 | 姿 | ultra | high | medium | low |
| --- | --- | ---: | ---: | ---: | ---: |
| ブナ | 夏 / 紅葉 | 85 / 87 | 81 / 83 | 111 / 113 | 118 / 121 |
| ナラ | 夏 / 紅葉 | 84 / 82 | 79 / 77 | 112 / 110 | 117 / 115 |
| シラカバ | 夏 / 紅葉 | 135 / 167 | 134 / 167 | 118 / 153 | 110 / 141 |
| セイヨウナシ | 収穫後 / 秋 | 129 / 126 | 122 / 119 | 105 / 101 | 106 / 102 |

品質間の差は夏の葉にすでにあり、紅葉はその比を保っている。季節の配色が新たに差を作っているのではない。ブナ・ナラのmedium・lowが明るいのは、夏の楕円体の房の較正の問題として後続課題X07に分けた。
