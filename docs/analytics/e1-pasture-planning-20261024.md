# E1: 牧草地の人口比例廃止と36か月比較（2026-10-24）

§7.37の主食用地保護を含む変更前ランタイムと、人口比例を廃止した変更後を、固定Province101・World102で独立に36か月ずつ実行した。Standard・遠距離交易on・隊商襲撃off。冬前屠畜の設定・新たな飼料源・史料未確定の乳/チーズ需要は変更していない。

## 実装と境界

- 既存群れは実コホートの頭数÷現行の飼養密度から面積要求を求める。0頭を初期配置へ戻さず、無効/適性外の種のために新しい土地要求を作らない。世話の労働要求は既存動物に対して残す。
- 未記録の群れは既存牧草地を引き継ぐ。既存面積もない初期配置は、見込主食用地の作業と他職作業を差し引いた実人数の労働予算、生態的面積上限で制限する。初期の種構成は既存バイオーム重みで、史実の需要から求めた目標ではない。
- 既存面積からの移行は従来の年次調整率0.25。土地計画は動物を直接削除せず、頭数は既存の出生/死亡/出荷/超過調整に従う。通常の収容力照会は群れを読まず、確定済み土地契約を使う。
- 種別の土地配分・若齢と成畜の飼養密度・史料校正済みの共同産出目標は今回未変更。実頭数を維持要求へ使うことは、現頭数が適正であるという認定ではない。
