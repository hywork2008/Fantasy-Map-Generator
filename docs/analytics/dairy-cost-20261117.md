# チーズの基準の値段を作る費用から決めた計測（2026-11-17）

[dairy-demand.md](../plan/dairy-demand.md) §3.2の残り。`cheeseReferencePrice` を `productionCost`（新しい既定）にした。比べる相手は [dairy-demand-20261116.md](dairy-demand-20261116.md) の伝統の計測（基準の値14、`goodValue` と同じ）。

## 1. 条件

- 地図2103、36か月、戦争なし・略奪なし、他は既定。[run.sh](dairy-cost-20261117/run.sh)、記録は [basket.mts](household-basket-20261116/basket.mts)。
- 3年目（36か月 − 24か月）、1人・年。
- 基準の値段 = 牛乳の値段 × 10ロット + 塩0.25 bag + チーズを作る賃金（1ロットに牛乳10ロット × `cheeseMakingDaysPerMilkLot` 10日）。牛乳の値段2.99では約30。

## 2. 結果

| | 品の値（14） | 作る費用 |
| --- | ---: | ---: |
| 食べたチーズ | 5.3 kg | 7.3 kg |
| うち市場で買ったチーズ | 2.6 kg | 3.9 kg |
| 満たせなかったチーズの需要 | 1.2 kg | 1.3 kg |
| チーズの需要を満たした割合 | 82% | 85% |
| 飲んだ牛乳 | 2.9 L | 4.0 L |
| 搾れる牛乳（78.6 L）のうち使った割合 | 72% | 98% |
| チーズの値段（中央値 / 最小〜最大） | 21.8 / 10〜31 | 30.5 / 4〜38 |
| 塩の値段 | 0.100 | 0.100 |

- 家計の収入・GDP（goodsVA）の差は1%以内。

## 3. 読み取り

1. 余っていた牛乳はほぼ全て使われ、食べた量は搾れる量の範囲（約7〜8 kg）に戻った。需要を満たす割合も保たれた。
2. 値段の中央値は作る費用（約30）とほぼ同じになった。値段の幅は広がった（牧畜の土地の4から、穀物の土地の38まで）。
3. 塩の値段は変わらない。
4. 牛乳の値段は全ての市場で2.99のまま動かない（牛乳は市場で売り買いされない）。基準の値段の大部分は、この動かない牛乳の値段で決まっている。農家渡しの値段を牛乳の需給で動かすことは残課題。
