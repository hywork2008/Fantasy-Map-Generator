# 家計の籠を家計の側の値で数える（2026-11-16）

[household-basket-scale.md](../plan/household-basket-scale.md) §4の手順1・2。

## 1. 条件

- コードは price-level-20261116 と同じ HEAD に、`wageSubsistenceMultiple` の設定（既定 1.5、動きは同じ）を足したもの。
- 地図2103、36か月、戦争なし、略奪なし。3年目（25〜36か月）を数えた。人口は1,040万人。
- 記録は [basket.mts](household-basket-20261116/basket.mts)、実行は [run.sh](household-basket-20261116/run.sh)。数えたのは次の4つ。
  - 家計が使った品の流れ（`householdFood`・`householdTextiles`・`householdHeating`・`burgDemand` 等）
  - 食品加工の帳簿（`foodProcessingLedger`）
  - 衣服・毛布の帳簿（`textileLedger`・`blanketLedger`）
  - 主食の帳簿
- 注意: 食品加工の帳簿の `householdConsumption`・`unmetDemand` は開始からの累計なので、36か月目と24か月目の差を取った。衣服の帳簿は月ごとの値なので、12か月を足した。

## 3. 読み取り

1. **乳製品は、需要があるのに作られていない。** 需要の1〜2%しか満たされず、値段は上限近くにある。量（供給）の不足である。
   - 需要どおり満たされ、値段が基準の値に戻ったとすると、チーズだけで1人 0.35 SP、主食の1.4倍になる。この場合は籠の比（0.63）を超える。
   - チーズの需要（1人25 kg）が大きすぎる可能性もある。乳製品の設計の時に、需要と作る量の両方の根拠を確かめる。
2. **飲み物は、需要がほぼ満たされている（ビール94%）。その需要が1人20 Lと小さい。**
   - 町の大人300 L・農村の大人48 Lの決まりから考えると、もっと多くなるはずである。農村のエールが市場のビールの需要に入っているかを確かめる必要がある（[urban-craft-staffing.md](../plan/urban-craft-staffing.md) 未決事項16〜18）。
3. **布は、量（51%）と値段の両方が足りない。**
   - 需要を全て満たしても、値は主食の0.16倍にしかならない（籠では0.63）。値段の側の不足は約4倍で、price-level-20261116 で毛織物が史実の0.3倍だったことと合う。
4. **燃料は、薪の量が1人106 kgと少なく、値段も下限（0.27）にある。** 史実の薪の量は数えていない。[fuel-price-share.md](../plan/fuel-price-share.md) で決めた量と比べる必要がある。
5. 肉は量・値段とも籠の比の約4割。需要の決まりはまだ見ていない。

不足の大きい順は、乳製品（量）、布（値段と量）、飲み物（需要の決まり）、燃料、肉の見込み。
