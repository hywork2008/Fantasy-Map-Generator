# CE M9 旧景観の再生成・樹木・文化設定

2026-11-07。[旧港の受入](ce-meshless-m9-harbor-20261107.md)の後続作業。旧森林の領域snapshotから、セルなしの森林再生成・BV樹種・文化別墓地へ進み、一部受入とした。[受入JSON](ce-meshless-m9-landscape-20261107.json)に固定入力のSHA-256と結果を保存した。景観群は`limited`、公開区分は試験運用を維持する。

## 取り込みと再生成

`environment.landscape`に、森林方式ごとの適地、開放域と旧来の除外範囲、元の農地、公園・農地の配置、墓地プラン、植生帯・気温・文明・地域信仰・文化信仰・埋葬profileを保持する。旧meshのface・edge・vertex参照を再生成の入力に使わない。適地の取得時だけ旧plannerを使い、採用後の再生成はnativeデータから行う。元文書を保管していないnative文書でも再生成できる。

- 森林は「明示した森林のみ」「農地」「郊外」の入力領域から再生成する。空地の穴と元の除外範囲を保持し、現在の道・水域・配置物・防御・港・公園・墓地・固定農地をさらに除外する。
- 森林化を解除したときは、元の農地の土地利用を戻す。取り込んだ農地プランは森林と重なる部分を切り分け、畝も穴と境界で切る。固定された農地は森林化しない。農地の全配置・作付けを新しく計画する処理ではない。
- 樹木候補の生成と、植生帯・気温から樹種を選ぶ処理を旧CEから切り出して共用した。nativeは同じ採用済み樹木の位置・樹種・樹冠半径・高さ・向きを2Dと3Dへ渡す。森林の樹冠が開放域や水域を跨がないよう判定する。樹木は公園・墓地の植栽を先に採用し、全体2,048本を上限とする。
- 樹木の3D表示は既存のBV樹種と採用variantを使い、保存した樹冠半径・高さへ合わせる。土地へ収めるために樹木を小さくする処理はしない。モデルは樹種ごとにinstance化し、根の地表基準とローカル原点を保持する。native地形がある場合は、その高さ評価器で幹の基部を置く。

森林の適地・元の除外範囲は、取り込み時点の意図を保持した固定の再生成入力である。旧セル属性を再び編集する機能や、削除した旧施設の用地を自動的に適地へ戻す処理までは追加していない。樹木の配置はnative内で共有・再現されるが、旧SVG／旧3Dのすべての装飾位置と画像の一致を保証しない。

## 文化別墓地と操作

文化別墓地の配置処理を、ポリゴン・入口・水域・樹木可否だけで実行できる関数へ切り出した。旧CEも同じ関数を使う。地域の信仰と文化本来の信仰が異なる文書では、その区別を保存し、地域の信仰と現在の時代・伝統から既存の埋葬presetを選ぶ。

環境パネルへ森林方式・密度、埋葬presetの選択、再生成、地域信仰の適用を追加した。通常の森林再生成で墓地の文化を勝手に切り替えない。地域信仰または埋葬presetの適用を選んだときに、未ロック墓地の聖域・墓標・儀礼施設・通路・植栽を再配置する。墓地全体または部品が固定されていれば、そのプランを変更しない。操作は履歴へ入り、Undoできる。

公園の芝生・小道・植栽、農地の形状・畝・作付け等の記録、墓地の文化・部品形状・穴もnativeへ保持する。公園と農地の全配置を再生成する処理、墓地の専用BV建築意匠や寺院の自動景観まで同等になったとは扱わない。

## 固定受入

従来の3×3農地と空地の穴、水域、道路の固定入力を維持した。別の固定入力には同じ農地に加えて、文化本来の信仰と地域信仰が異なる墓地を置いた。入力コードは`fixtures/legacyLandscape.ts`に保存している。

| 項目 | 結果 |
| --- | --- |
| 森林領域 | 空地あり3,200m²、水域追加後2,800m²、道路追加後2,624m²。旧plannerとの双方向差分と農地重複は1e-5m²未満 |
| 樹木と密度 | 道路ケースは密集19本、疎ら15本。同じ設定で同じ樹木を再生成。上限未満の固定入力で疎らの樹木が密集の部分集合になることを確認 |
| 再生成の独立性 | 元文書のarchiveを外しても再生成・native保存に成功。入力文書を変更しない |
| 気候 | 氷河では森林・樹木を生成せず、温暖な設定へ戻すと同じ領域・樹木が戻る |
| 農地 | 森林化を解除すると元の3,600m²へ復元。中央の400m²の空地へ畝を切り分け、固定農地は全域・元の畝を維持 |
| 樹種と描画 | BV樹種のinstanceを作成。2D樹冠と3Dは同じ樹木データを使う。固定文化入力ではブナ・シデ・公園樹・オーク・マツを保持 |
| 文化別墓地 | 地域信仰の適用後、既存の選択規則で`sunni_wahhabi`を選び、旧文化配置器の部品・通路・植栽と一致。地域信仰と文化信仰の記録を保持 |
| 固定・参照 | 固定墓地を維持。不明な樹木所有者や生成領域の参照を読込時に拒否 |
| UIと履歴 | 環境パネルからの森林方式変更、地域信仰適用、Undoを確認 |

上記は固定入力での契約であり、すべての旧景観・植生帯・都市規模への保証ではない。大きい森林での樹木上限は、森林面積そのものを減らさない。
