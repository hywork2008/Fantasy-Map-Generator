# 国庫の減りと、人口に対する貨幣と経済の大きさ（2026-11-16）

[price-level-20261116.md](price-level-20261116.md) §5の1。国庫が1年目に大きく減り、その後もじわじわ減る理由と、開始時の貨幣が人口から見た経済の大きさに見合うかを数えた。

## 1. 条件

- コードと地図は price-level-20261116 と同じ（HEAD 1f2873421、地図2103、戦争なし・略奪なし）。60か月、`npm run sim` の `--money-flows`（12か月ごと）。
- 実行は [run.sh](money-sink-20261116/run.sh)。集計は sink.py と、会話中に1回だけ実行したスクリプト（年ごとの各処理の差引と国庫の出入り）。人口は1,033〜1,052万人。

## 3. 国庫の出入り（年、千）

| | 1年目 | 2年目 | 5年目 |

| 塩（`saltLogistics`） | +71 | +82 | +84 |
| 知識（`annualKnowledge`） | +43 | +42 | +37 |
| 公共の支出（`taxes:publicSpending`） | **−627** | −303 | −262 |
| 配分・民政（`allocateTreasury`・`civilAdministration`） | −84 | −83 | −79 |
| 造船・開拓統治・財政の出来事など | −35 | −25 | −30 |

1. **1年目の落ち込みは公共の支出による。** 公共の支出が2年目以降の約2倍（62.7万）あり、国庫の開始時の額のおよそ半分を1年で町の金庫・家計へ出した。開始時の国庫が、国庫を「十分」とみなす額（`getComfortableTreasuryLevel()`）を大きく上回り、その超えた分を使い切ったものと読める（閾値の値は見ていない）。
2. **2年目以降の減りは小さい**（年 −0.1〜−1.7%）。税収が5年で −10%（26.8万 → 24.0万）減り、支出も同じ程度に減って、少しだけ追いつかない。税収が減る理由は数えていない。

## 4. 人口に対する貨幣と経済の大きさ

1人・年あたり（SP）。主食の必要量は 0.43 wain で、価格の下限 0.8 SP/wain で 0.344 SP。

| | シム（2〜5年目） | 主食の何年分 | 1500年ごろのイングランド |
| --- | ---: | ---: | ---: |
| 貨幣 | 0.235 | 0.68 | 1.5〜2年分 |
| 家計に入るお金（所得の目安） | 0.23 | 0.67 | — |
| 1年に動いたお金の総額 | 0.53 | 1.5 | — |
| 1人あたりの GDP | — | — | 5〜6年分 |
| 国庫の収入 | 0.038 | 0.11 | 約 0.15〜0.2 |
| 国庫の残高 ÷ 年の収入 | 約 2 年分 | — | 1 年分未満（平時） |

- 人口で比べると、貨幣は史実の約1/3。
- お金で回る経済（家計の貨幣所得）で比べると、貨幣は所得の約1年分ある。史実は GDP の 3〜4か月分。お金の回転は史実の 1/3〜1/4 で、回る経済に比べればお金はむしろ多い。
- つまり足りないのは貨幣より、お金で回る経済の大きさ（貨幣所得）である。家計の貨幣所得は主食の必要量の 2/3 しかない。食料の大部分を自家消費で賄う農村では、ある程度は当然である。それでも史実の1人あたり GDP（主食の5〜6年分）とは1桁違う。原因は [price-level-20261116.md](price-level-20261116.md) §4の1の賃金の尺度（自分の食費×1.5）と同じところにある。
- 国庫の収入の比は史実と同じ桁にある。残高は収入の約2年分で、史実の平時より多い。

## 5. 読み取りと次の作業

1. 開始時の配分を、今の経済に合わせて減らすのは早い。今の経済の大きさは賃金の尺度で小さく抑えられているので、そこに合わせると貨幣も史実の1/3のまま固まる。
2. 先に、1人あたりの所得（賃金・農家の売上）を主食の何年分にするかを決める設計書を作る。目安は史実の GDP（主食の5〜6年分）。その後、貨幣を所得の 3〜4か月分、国庫を年収入の 1 年分未満に配る。
3. 1年目の公共の支出の大きさは、開始時の国庫と「十分」とみなす額の関係で決まる。開始時の配分を見直すときに一緒に扱う。
4. `production:taxes` と `production:burgLoop` が単独で釣り合わない理由は未確認。お金を作ったり消したりしていないかを、別に確かめる。
