## 3. 読み取り

1. 支配者と役人のお金は0まで落ちず、正の値で落ち着き始めた。支配者の蓄えは0年（[character-reserve.md](../plan/character-reserve.md)）なので、手当48 = 生活費40.8 + 手持ちの2%の身分の費用 + 手持ちの10%の余りの使い道、で1人約60に釣り合う。2103は36か月目に1人約65で、ほぼ釣り合った。2102は1人約140で、まだ下がっている。
2. 役人も前の約3倍の手持ちで、下がり方が緩くなった。
3. 町の家計と農村の家計が2〜4%減った。国の金庫はほとんど変わらないので、部局の予算が大きくなった分のお金の行き先（軍の費用、公共事業など）を、この計測では追えていない。お金の流れの記録（11の持ち手）で確かめる必要がある。
