# 行軍中の街の占領

## AIからの質問

1. 判定に使う戦力比: 正式SiegeのFIELD_ATTACK_RATIO(1.3)よりやや低い1.2程度でどうか、あるいは「通過は民兵しかいないので不要な余裕はいらない」と考えて1.0(単純に上回れば占領)にするか。

2. 対象を絞るか: 全ての陸上連隊(ガリソン防衛中も含む)を対象にするか、進軍中(destinationCellが設定されている連隊)だけにするか。ガリソン連隊は基本自国領内にしか目的地を取らないので実害は少ないと思われますが、明示的に絞ってもよいです。

3. 人口への影響: 「現地調達」を演出テキストだけに留めるか、任意で人口をわずかに(1〜2%程度)減らす副作用を足すか。ご要望どおり今回は演出のみ(データ処理なし)で進める想定です。

## 回答

1. 行軍シーズンの村には働き盛りの男手が減っているので`0.2`くらいで良いです。女子供混じりの村人と軍隊の強さを1:1で計算する必要はありません。防衛柵があれば別ですが。現時点では騎馬隊も食料と水だけ奪っていく紳士なので、抵抗も強くない想定です。

2. 防衛隊のいない都市の扱いなので、陸上連隊も都市を占領します。むしろ、自国内に敵が作った飛び地の領土が、敵が帰った後もずっと敵地のままで、自国で再占領しないのはこれが原因では？

3. 人口を微減に加えて、都市の規模に比べて大きな敵軍が通過した場合はWealthとTreasuryが激減するようにして下さい。

これらに加えて都市にはその都市を所有する国を配列で保持したいです。
地図生成時は位置するstateにそのまま帰属していますが、敵軍に占領されたらその敵国のstate番号が最新の所有者として記録されます。
占領された都市を取り返す正当性を確認する為の情報として使う予定です。
