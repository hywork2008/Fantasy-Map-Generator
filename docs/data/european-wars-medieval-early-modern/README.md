# 中世から近世のヨーロッパの戦争

ヨーロッパを主戦場とした戦争の編集カタログである。ランタイムの生成には使わない。第三者の CC0 データでもない。各行は、史料と標準的な概説が名前・年代・当事者・結末を残している戦争に限る。死傷者や賠償額が残っていない項目は、空欄や推定で埋めない。

機械可読な全行は [`european-wars.csv`](./european-wars.csv)。出典は [`sources.csv`](./sources.csv)。

## 範囲

| 項目 | 内容 |
| :--- | :--- |
| 地理 | ブリテン諸島、スカンディナヴィア、欧州ロシア、バルカン、地中海の欧州沿岸と島嶼、イベリア、ビザンツの欧州領。オスマン帝国との戦争は、戦場が欧州にあるものを入れる |
| 始め | 西暦500年以降。プロジェクトの中世初期（おおよそ500年）に合わせた |
| 終わり | 開始が1788年まで。フランス革命戦争（1792年）は、日本でいう欧州の近代に入るため入れない |
| 入れない | レヴァントの十字軍、アメリカ大陸やインドの戦争、封建私戦、一度きりの襲撃や包囲の一覧。レコンキスタのように数世紀続く過程は、一つの戦争として扱わない |
| 例外 | 第4回十字軍は、コンスタンティノープルという欧州の首都を征服したので一行にした。七年戦争とスペイン継承戦争は欧州戦線を書き、同じ条約の欧州外条項は一文だけ触れる |
| 選択 | 通史で名前が通り、当事者と結末が叙述できる戦争。すべての戦争の目録ではない |

## 時代ラベル

`period` は、このプロジェクトの Historical period を開始年に当てたラベルである。通史の呼び方とずれる境界は `notes` に書いた。

| 開始年 | period | プロジェクト上の呼び方 |
| :--- | :--- | :--- |
| 500–999 | `earlyMedieval` | 中世初期 |
| 1000–1299 | `highMedieval` | 中世盛期 |
| 1300–1449 | `lateMedieval` | 中世後期 |
| 1450–1599 | `ageOfExploration` | 大航海時代 |
| 1600–1749 | `maritimeEra` | 海洋時代・近世 |
| 1750–1788 | `preIndustrialEra` | 産業革命前夜。フランス革命の手前なので、このカタログでは近世の末まで含めた |

1453年のコンスタンティノープル陥落は、通史では中世の終わりに置かれることが多い。ラベルは開始年で `ageOfExploration` になる。

## 死傷者と賠償

- 同時代に死者・負傷者の総数が会計されていない戦争は、総数を作らない。`casualty_basis` は `none_recorded`。
- 年代記が一事件について大きな数を書く場合は、その数を年代記の主張として書き、戦争全体の死者にはしない。`casualty_basis` は `chronicle_only`。
- 現代の人口推計を採用したのは、三十年戦争の行だけである。病と飢餓を含む帝国の人口損失で、戦闘死の名簿ではない。`casualty_basis` は `modern_estimate`。アルマダの損耗と、三王国戦争の「推計は一致しない」も同じ区分に置いた。
- 賠償・身代金・貢納・持参金は、概説が一致するものだけ金額を書いた。エディンバラ・ノーサンプトン条約とポリャノフカ条約は概説の金額が割れるので、数値を一つに決めない。
- 金銭の条項が無い戦争には、「賠償金は無い」または「賠償は中心条項ではない」と書いた。ゼロ人死んだ、という意味ではない。

## 列

| 列 | 依頼との対応 |
| :--- | :--- |
| `war_id` | 開始年順の `EW-001` から |
| `name_ja` / `name_en` | 戦争の名前 |
| `start_year` / `end_year` | いつから、いつまで。年単位。日が重要な講和は `settlement` に書いた |
| `period` | 上の時代ラベル |
| `theatre` | 主戦場 |
| `belligerents` | 参戦国・当事者 |
| `victor` | 勝敗の短い判定 |
| `outcome` | 政治的な結果 |
| `casualties` | 死傷者。負傷を分けた数が無いことも書く |
| `casualty_basis` | `none_recorded` / `chronicle_only` / `modern_estimate` |
| `notable_persons` | その戦争で名が残った人物 |
| `causes` | 原因 |
| `settlement` | 講和、降伏、賠償、身代金、貢納、持参金 |
| `source_ids` | `sources.csv` の識別子。セミコロン区切り |
| `notes` | 年代の置き方、入れなかった隣接事件 |

文字コードは UTF-8。各戦争は1行。

## 限界

中世前期は、年代記が破壊を書いても人数と賠償を残さない戦争が多い。その行の死傷者欄が短いのは、欠測である。

イタリア戦争、八十年戦争、三十年戦争のように長い戦争は、通史の単位で一行にまとめた。局面ごとの小条約は `settlement` に畳んだ。

金額と死者のうち、2026-11-16に概説を突き合わせたものは `source_ids` を個別に付けた。それ以外の年代・当事者・条約名は、標準的な概説で一致している範囲に限った。専門のモノグラフで全行を再検証した、という意味ではない。
