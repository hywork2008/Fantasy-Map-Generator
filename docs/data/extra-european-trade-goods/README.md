# Extra-European import goods (Europe-latitude maps)

ヨーロッパ緯度・経度で地図を生成すると、熱帯雨林・サバンナ・熱帯季節林がほぼ現れない。胡椒やゴムのように**そのバイオームにしか存在しえない品**は、在庫も産地も地図上に出ない。このカタログは、中世後期から現代まで欧州向け交易で重要な地位を占めた物品のうち、**域外からの輸入品として商品登録する価値が高いもの**を整理した編集用リファレンスである。

機械可読な全行は [`extra-european-trade-goods.csv`](./extra-european-trade-goods.csv)。出典は [`sources.csv`](./sources.csv)。ランタイムの `GOODS_DATA` は変更しない。

関連する既存計画: [`docs/plan/exchange/`](../../plan/exchange/README.md)、[`docs/simulation/goods.md`](../../simulation/goods.md)。

## ヨーロッパ地図での実装上の要点

`GOODS_DATA` に `distribution: "biome(7)"` だけを足しても、欧州地図ではセル配置抽選に一度も当たらない。輸入品として意味を持たせるなら、次のいずれかが必要である。

1. **`chance: 0` のカタログ品**として登録し、港市・外国商人・地図外ソースから在庫を入れる（推奨）。
2. 既存の包括品（`Spices`, `Dyes`, `Incense`）に残し、フレーバーだけ時代カタログで分ける。
3. 配置競争（1 セル 1 Good、`resourceMaxCells` 上限）を増やす天然配置は避ける。`docs/plan/exchange/04-goods-data-candidates.md` §1.6 と同じ制約。

需要総量は人口 × `DEMAND_TARGET_FACTORS` で固定である。luxury 品を増やすと供給側だけ厚くなる。分割するなら `demandCoverage` を薄く割るか、包括品のカバレッジを下げる。

## 既存 GOODS_DATA との対応（欧州地図で産出しにくいもの）

| :--- | :--- | :--- |

| Spices | `biomeTag("forest") && minTemp(18)` | 南縁以外は出ない。胡椒〜ナツメグを一括 |
| Sugarcane | `biome(7)` | 産出しない |

| Incense | 砂漠・低木 + 高温、または高温の森 | 南縁砂漠以外は出ない |
| Mahogany | 高温の森 | ほぼ出ない |

## 時代別の主役

中世後期の東方香辛料は、ヴェネツィア経由の中継独占が欧州商業の最上層を支えた。15 世紀イングランドでは胡椒 1 ポンドが熟練職人の二日分以上、丁子は五日分近かった。大航海は、この中継を迂回して産地へ直結するための航海だった。

| 時代 | おおよその年 | 構図 | 主役（気候ロック） |
| :--- | :--- | :--- | :--- |
| 中世後期 | 1300–1500 | 紅海・レヴァント中継。ヴェネツィア／ジェノヴァ | 胡椒、肉桂、生姜、丁子、ナツメグ、絹、乳香、象牙、砂糖（まだ少量） |
| 大航海〜重商 | 1500–1700 | 喜望峰直買付。VOC の産地独占。ポトシ銀とマニラ・ガレオン | 上記香辛料＋砂糖、銀、磁器、染料木、のちコーヒー・茶 |
| 消費革命 | 1650–1800 | 東インド会社。嗜好品が都市の日常になる | 茶、コーヒー、カカオ、砂糖、キャラコ、タバコ、藍、コチニール |
| 産業・帝国 | 1800–1914 | プランテーションと戦略原料。海底電信・化学肥料以前 | 綿、ゴム、ガッタパーチャ、キナ、ジュート、パーム油、グアノ、茶・コーヒーの農園化 |
| 現代 | 1914– | 合成代替と残存一次産品。戦略鉱物が比重を増す | 石油、パーム油、カカオ、コーヒー、茶、天然ゴム、ボーキサイト、銅、レアメタル |

砂糖・綿・茶・コーヒー・カカオ・奴隷が香辛料に代わって世界経済の中心になった、という転換は大航海期以降の通説である。

コロンブス交換で**欧州に帰化した作物**（ジャガイモ、トウモロコシ、トマト、トウガラシの一部）は、導入後は輸入品ではなくローカル食料になる。交易品カタログに立てる意味は薄い。タバコは欧州でも育つが、史実の主供給はプランテーションだった。

## 次の実装に進むなら

1. 優先度 A のうち未登録の **Coffee / Cacao / Rubber / Porcelain / Indigo** を 04 の草案どおり `chance: 0` で追加する（欧州地図では天然配置しない）。
2. `Spices` を残したまま **Pepper / Cloves / Nutmeg** を分割するか、Goods Editor のタグだけで足りるか決める。
3. 地図外輸入（港の外国在庫、またはオフマップ市場）が無いと、A 品はカタログにだけ存在する。交易シミュレーションへ載せるなら輸入ソースが本体である。
4. Rubber / Gutta-percha / Guano / Palm oil / Bananas は `availableFrom` 時代ゲート（04 §5）とセット。
5. 天然配置の `chance > 0` を欧州に無いバイオームへ足すのは、世界地図・低緯度地図用に限る。
