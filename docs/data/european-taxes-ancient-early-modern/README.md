# 古代から近世のヨーロッパの税金

ヨーロッパで史料に残る税の編集カタログである。ランタイムの生成には使わない。第三者の CC0 データでもない。各行は、名前、課した主体、課税対象が残り、率か「単一の率が残らない」ことまで言える税に限る。パーセントが史料に無い項目は、空欄や換算で埋めない。

機械可読な全行は [`european-taxes.csv`](./european-taxes.csv)。出典は [`sources.csv`](./sources.csv)。閲覧日は 2026-11-16。

## 範囲

| 項目 | 内容 |
| :--- | :--- |
| 地理 | ブリテン諸島、スカンディナヴィア、欧州ロシア、バルカン、地中海の欧州沿岸と島嶼、イベリア、ビザンツの欧州領。ローマ帝国の税は、欧州の属州か帝国全体の制度として残るものを入れる |
| 始め | 古典期ギリシアから。前200年より前は、このカタログだけの `preClassical` |
| 終わり | 新しい課税の開始は1788年まで。フランス革命の税制と、1799年のイギリス所得税は入れない |
| 廃止年 | 既にある税が1788年よりあとで廃止されたときは、その年を `end_year` に残す。ガベルの1790年、炉税の1689年、窓税の1851年、エーレスンド海峡税の1857年、煉瓦税の1850年、帽子税の1811年 |
| 入れない | アメリカ植民地のアルカバーラとキンタ、レヴァントだけの関税、民俗として語られる初夜権やカッコウ税。オスマンの欧州領の税は、階級ごとのアクチェをこの作業では開いていないので入れない |
| 選択 | 為政者がかけた税のうち、通史で名前が通り、率か定額か「率が残らない」ことが言えるもの。すべての税の目録ではない |

## 時代ラベル

`period` は、開始年をこのプロジェクトの Historical period に当てたラベルである。開始年が空欄の行は、その制度が史料に現れる時代をラベルにした。

| 開始年 | period | 呼び方 |
| :--- | :--- | :--- |
| 前200年より前 | `preClassical` | カタログだけの区分。プロジェクトの古典古代はおおよそ前200年に始まる |
| 前200年–250年 | `classicalAntiquity` | 古典古代 |
| 250–499年 | `lateAntiquity` | 古代末期 |
| 500–999年 | `earlyMedieval` | 中世初期 |
| 1000–1299年 | `highMedieval` | 中世盛期 |
| 1300–1449年 | `lateMedieval` | 中世後期 |
| 1450–1599年 | `ageOfExploration` | 大航海時代 |
| 1600–1749年 | `maritimeEra` | 海洋時代・近世 |
| 1750–1788年 | `preIndustrialEra` | 産業革命前夜。このカタログでは近世の末まで含めた |

`hellenisticAge` はプロジェクトに実装されていないので使わない。

## 税率

- `rate_percent` に入れるのは、史料が一つのパーセントを述べているときだけである。五十分の一、二十分の一、四十分の一、十分の一、所得の二十分の一は、その一つの率を数字にした。
- 分数が二つある税（農村の十五分の一と都市の十分の一）、官職の六十分の一、定額、収穫の分け前、賦役、法的な無能力は、パーセント欄を空欄にする。
- 同じ税がのちに変わったときは、創設時の一つの率を `rate_percent` に置き、あとの変更は `amount_recorded` と `notes` に書く。アルバの三税、カリグラの税、1692年の土地税は、それぞれ別の行か、文章の中の別の数字である。
- 概説が割れる総額は一つに決めない。デーンゲルドのポンド総額、アルバのフロリン総額、ひげ税の端数の歳入は入れない。
- `source_ids` が `GENERAL` だけの行は、標準的な概説が一致する範囲である。勅令や年代記を、この作業で開き直していない行は `sources.csv` にその旨を書いた。
- 専門のモノグラフで全行を再検証した、という意味ではない。年代記と概説が割れる箇所は、一つの数字に畳んでいない。
- ゲーム内の塩価や、`docs/upstream/domain/taxes.md` の税率は史料ではない。

## 列

| 列 | 内容 |
| :--- | :--- |
| `tax_id` | 収録順の `ET-001` から。年代順に並べ直してはいない |
| `name_ja` / `name_en` / `name_original` | 日本語名、英語名、史料上の呼び方 |
| `start_year` / `end_year` | 年。紀元前は負の数。日が重要なものは `levied_by` か `notes` に書いた。空欄は、創設年か廃止年が残っていない |
| `period` | 上の時代ラベル |
| `region` | 課された地域 |
| `polity` | 課した国家・為政者 |
| `category` | `service` `lump_sum` `poll` `customs` `land` `manumission` `harvest_share` `inheritance` `sales` `legal_disability` `excise` `church` `military_commutation` `feudal_incident` `monopoly` `other` |
| `levied_by` | 誰が決め、誰が課したか |
| `payer` | 誰が払うか |
| `what_taxed` | 何にかけたか |
| `rate_percent` | 単一のパーセント。無ければ空欄 |
| `amount_recorded` | 史料に残る額の文章。定額、分け前、等級表を含む |
| `amount_kind` | `percent` `fixed_money` `in_kind_share` `graduated_schedule` `lump_sum` `service` `unrecorded` `legal_disability` `forced_purchase` `military_commutation` `monopoly` `feudal_incident` |
| `oddity` | `ordinary` は通史の基本税。`unusual` は対象や取り方が人目を引くもの。珍妙さの判定は編集上のもので、当時の法的な異常ではない |
| `source_ids` | `sources.csv` の識別子。セミコロン区切り |
| `notes` | 年の置き方、率を空欄にした理由、隣の税との違い |

文字コードは UTF-8。各税は1行。

## 人目を引く税

`oddity` が `unusual` の行は、船を個人に出させるトリエラキア、未婚者の相続制限、カリグラの食料・訴訟・荷役・娼婦への税、ユダヤ人税、尿税、金銀税、死んだ家臣の最良の家畜、娘の結婚時の認可料、領主の水車を強制する製粉のバン、市価より安く取り上げる強制買上、イングランドのユダヤ人へのタラージ、1380年の人頭税、塩の強制購入、売るたびに10%が乗るアルバの十分の一、六品目の従量税、官職の年税、議会を通さない艦船税、炉の数、窓の数、ひげ、煉瓦の個数、帽子の証紙である。

率の欄が空なのは、史料にパーセントが無いからである。尿税とカリグラの食料税は、金額そのものが残っていない。

## 入れなかった税

名前は有名でも、この作業で率か定額を開き直していないものは行にしていない。共和政トリブートゥムの 0.1% という通説の数字、コンメルキオン以前の八分の一、ディオクレティアヌス期のユガティオとアンノナ、ピーターズ・ペンス、カレイジ、イングランドのタラージ、テューダーの補助税、トン数税とポンド税、フランスのエード、タイヨン、フアージュ、サンティエム・ドゥニエ、1695年の結婚・埋葬税、石鹸・蝋燭・新聞・壁紙の物品税、カスティーリャのテルシアスとクルザーダ、オランダの通常物品税、スウェーデンのコントリビューション、ロシアのソウル税、プロイセンのアクツィーゼとコーヒー税、帝国のゲマイナー・プフェニヒ、都市のユダヤ人通行税、オスマンのジズヤとウシュルとイスペンジェとアヴァルズとデヴシルメ、1791年以降のフランス革命税制、1798年の扉窓税、1799年の所得税。

レクス・パピアは、俗に独身税と呼ばれるが、国庫へ払うパーセントではない。相続を受けにくくする法なので、その区別のために一行入れた。

## 限界

開始年のいくつかは目安である。トリエラキアの前480年、メトイキオンとペンテコステの前450年、ガリア四十税の前15年、競売税の6年、アンナテスの1316年、コンメルキオンの800年。ガベルは1341年と1360年の両方の言い方が残るので、行は1360年を置き、創設日は一つに決めない。

ヘルスタルの教会十分の一は、`decima` の通常の意味と MGH の版の存在による。ラテンは照合し直していない。ディジエム、ポーレット、タイユ、スクテージ、煉瓦税と帽子税のペンス表は、勅令の正文を開き直していない。

60行は、古代から1788年までの欧州の税の全数ではない。
