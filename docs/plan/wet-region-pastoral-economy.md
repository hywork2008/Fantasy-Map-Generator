# 多雨地の牧畜中心の暮らしと耕地の上乗せ（2026-10-29）

親計画: [historical-economy-production-consumption-circulation.md](historical-economy-production-consumption-circulation.md) §7.85（E1-5）。関連: [livestock-world-birth-herds.md](livestock-world-birth-herds.md)、[記録（単収の要因）](../analytics/e1-yield-factors-20261029.md)、[記録（収量係数）](../analytics/e1-crop-multiplier-20261029.md)。

## 1. 背景

新しく生成したWorld（seed 102）では、牛の収容力は0.20頭/人で、史料の目標（0.72頭/人）に届かない。耕地が約2 ha/人と広く、草地と牧夫が足りないためである。

- 単収は基準の0.68倍。最も大きく下げる要因は雨（0.69）である。
- 主食の人口のうち年降水量1,200 mm以上が73%を占め、2,000 mm以上は36%を占める（`rainfallBandPeople`）。
- 収量係数の校正（§7.85）で単収は21%上がったが、浮いた耕地の半分は「労働で賄える面積」までの上乗せで埋め戻された。

史実では、多雨で冷涼な土地（アイルランド、ウェールズ、スコットランド高地、ノルウェー西岸、アルプスなど）は穀物に向かず、乳と肉を多く食べる牧畜中心の暮らしだった。穀物の不足を耕地を広げて補うのは、史実に合わない。利用者の決定（2026-10-29）により、多雨地は牧畜中心にする。

## 2. 方針

### 2.1 主食の一部を乳・肉で賄う

各セルの「穀物で賄う主食の割合」（`localStapleShare`）を、雨による穀物の適性で下げる。下げた分は、乳製品・肉（およびその保存品）の食料として、群れの目標に上乗せする。

- 穀物の雨の係数`p`（作物の組み合わせの加重平均）が1を下回る多雨のセルが対象。乾燥で`p`が下がるセルは、灌漑や乾燥に強い作物の扱いが別にあるため対象外とする。
- 穀物の割合 = `max(下限, 1 − 牧畜の割合)`、牧畜の割合 = `最大牧畜割合 × (1 − p) / (1 − WET_TOLERANCE_AT_MAX)`。最大牧畜割合と下限は仮値（0.5、0.4）で、M0で史料と照らす。
- 史料の目安：中世アイルランド・高地スコットランドで、乳製品が食料の熱量の3〜5割（Kelly 1997, *Early Irish Farming*。Dodgshon 1998）。ノルウェーの農家で穀物は熱量の半分前後。

### 2.2 群れの目標と牧夫

牧畜の割合に応じて、そのセルの牛（乳）・羊・山羊の目標頭数を、乳・肉で賄う熱量から求めて上乗せする。牧夫の必要人数は今の式で群れから求めるため、目標が上がれば牧夫も雇われる。草地は、草地の上限（生態の制限）の中で目標に見合う広さとする。

### 2.3 労働で賄える面積までの上乗せ

今の耕地の目標は`max(必要面積 × 1.1, 労働で賄える面積)`（[settlementClearance.ts](../../src/generators/settlementClearance.ts)）。人手が余れば、主食に要らない耕地まで耕す。これを次のとおり改める。

- 上乗せは、需要がある場合（換金作物・都市の穀物需要・家畜の飼料）に限る。主食だけのセルでは、目標を`必要面積 × 1.1`とする。
- 余った人手は、牧夫・林業・手工業の仕事の割り当て（今の職業の配分）に回る。

M0で、上乗せのうちどれだけが市場で売られているか（換金作物・都市への穀物）を測り、全部を外すか一部を残すかを決める。

## 3. 段階

| 段階 | 内容 | 完了条件 |
| --- | --- | --- |
| M0 | 計測のみ。雨の帯ごとの人口・耕地・単収・群れ・牧夫、上乗せの耕地の収穫の行き先（自家消費・市場・腐敗）を記録する | 牧畜の割合の式と仮値、上乗せの扱いが決まる |
| M1 | 2.3を実装する | 単体テスト：主食だけのセルで耕地が必要面積×1.1を超えない |
| M2 | 2.1・2.2を実装する（主食の割合、群れの目標の上乗せ） | 単体テスト：多雨のセルで穀物の割合が下がり、群れの目標が上がる |
| M3 | 固定入力のWorldで24か月・144か月を確かめる | 牛の収容力/人が目標に近づく（0.4以上を目安）、農村・都市の主食と飼料不足が悪化しない |

### 3.1 M0の結果（2026-10-29、[記録](../analytics/wet-region-pastoral-m0-20261029.md)）

- 上乗せ耕地の収穫のうち、市場で買われて食べられたのは約5%で、66%は売れずに余った。上乗せは全部外す（2.3の「需要がある場合」の例外は設けない）。
- 上乗せは400〜2,000mmの帯に集まり、2,000mm以上ではほぼ無い。多雨地の群れを増やすのは2.1・2.2である。
- 牧畜の割合の式は仮値（最大0.5、下限0.4）で採る。穀物の割合は`max(下限, min(getRuralGrainDietShare, 1 − 牧畜の割合))`とし、既存の割合と掛け合わせない。

### 3.2 M1の実装（2026-10-29）

- `planSettlementLandUse`の耕地の目標を`必要面積 × subsistenceReserve`（1.1）とし、`laborAffordableAreaHa`で引き上げない。`laborAffordableAreaHa`は維持の人手不足（`maintenanceShortfallHa`）の判定にだけ使う。
- 食料気候の校正表は、元のファイルのハッシュだけが変わり、値は同じ（再生成で確認）。

### 3.3 M2の実装と12か月の確認（2026-10-29）

- `ruralDiet.ts`に`getWetPastoralDietShare`（雨の多すぎる側の適性`p`から）を加え、`cells.wetPastoralDietShare`として毎年求める。穀物の割合は`max(0.4, min(既存, 1 − 牧畜の割合))`。土地利用の計画には、農村の穀物の割合を`localStapleShare`として渡す（これまでは渡しておらず、計画は穀物の割合を見ていなかった）。`embedded`は対象外。
- 群れの目標は、熱量からの逆算（牛約4頭/人になり史料と合わない。§7.36も未校正の逆算を避けている）でなく、草原の牧畜の上乗せ（`PASTORAL_HEADS_PER_RURAL_PERSON`）を牧畜の割合/0.5に比例させて加える。
- 固定入力のWorldで12か月（M0と同じ条件）:

| | M0 | M2 |
| --- | ---: | ---: |
| 割り当てられた畑（百万ha） | 8.54 | 4.84 |
| 2,000mm以上の畑（百万ha） | 3.79 | 2.00 |
| 牛の目標（頭/人） | 0.61 | 0.74 |
| 牛の収容力（頭/人） | 0.20 | **0.16** |
| 2,000mm以上の牛の収容力（千頭） | 81 | **37** |
| 牧夫（割り当て/必要、千人） | 90/105 | 98/98 |

- **群れは増えず、減った。** 牧夫は足りるようになった。草地の上限のうち開墾地の分は、耕地×0.4（`CLEARED_PASTURE_PER_CULTIVATED_HA`）である（`husbandry.ts`の草地の上限）。休閑地の放牧も耕地に比例する。このため耕地が減ると、草地も一緒に減る。多雨の森林地では、生態の上限（未利用地×上限）が小さく、草地は耕地に付いて開かれた分しかない。
- M3の前に、草地を耕地でなく人（または群れの目標）に結びつける変更が要る。

利用者の決定（2026-10-29）により、開墾地の草地の上限を`max(耕地×0.4, 群れの目標に要る草地)`とした（未利用地・地形の範囲内）。12か月の再確認:

| 年降水量 | 大人の日数（百万日） | 畑仕事（百万日） | 草地の計画（人手の制限なし、百万ha） | 維持される草地（百万ha） |
| --- | ---: | ---: | ---: | ---: |
| 1,200–2,000 | 90.4 | 59.9 | 13.2 | 4.95 |
| 2,000–3,000 | 44.9 | 33.8 | 8.1 | 0.03 |
| ≥3,000 | 35.6 | 35.0 | 6.7 | 0.00 |

- 牛の収容力はWorld全体で0.205頭/人に戻ったが、増えたのは2,000mm未満の帯だけで、2,000mm以上の帯は38千頭のまま。
- 草地の不足、耕地の保護（`staple-arable-protected`）は0件。多雨地では草地の計画そのものがほぼ0になる。原因は、草地が無いセルの最初の計画が、畑仕事と他の仕事の残りの人手で賄える分しか草地を取らないこと（`calculateDesiredPastureAreaHectares`の`bootstrapLaborDays`）。単収170〜237kgでは、穀物の割合が0.4〜0.45でも畑仕事が大人の日数をほぼ使い切る。草地が0のまま次の年も同じ制限を受けるので、0から抜け出せない。

### 3.4 牧畜の世帯の人手を先に牧畜へ（2026-10-29）

利用者の決定（2026-10-29）により、草地の最初の計画を抑える人手の制限（`developmentPotential.ts`の`bootstrapLaborDays`）は、大人の日数×牧畜の割合（`wetPastoralDietShare`）を下回らないこととした。乳と肉で食べる世帯は、畑が残した人手でなく、自分の日数で群れを世話する。多雨地の気温と手間の計測（[記録の追記](../analytics/wet-region-pastoral-m0-20261029.md)）では、多雨地の年平均気温は約4℃で、暖かさで省ける干し草の手間は約2割にとどまり、この制限を緩めないことを確かめた。

### 3.5 M3の結果（2026-10-29、[記録](../analytics/wet-region-pastoral-m3-20261029.md)）

- 牛の収容力は、24か月で0.58、144か月で0.72頭/農村の人になった（変更前は0.23・0.28）。多雨地は0.89頭/人。完了条件の0.4以上を満たす。
- 農村・都市の主食の充足と飼料の不足は、変更前より悪化しない。いちばん低い年の都市の充足は88.2%で、変更前は92.5%（どちらも1308年）。
- 144か月で、都市の人口は0.80→0.67百万人（−16%）、農村は4.10→3.95百万人（−4%）に下がった。畑と市場に出る穀物の余りが減ったためか、原因を分けて確かめる（§4）。

### 3.6 農村の収容力に乳・肉で食べる人を数える（2026-10-29）

M3の後、農村の収容力が約10%低いことが分かった（[記録](../analytics/wet-region-pastoral-m3-20261029.md)）。土地利用の記録があるセルでは「耕せる面積」が割り当てた畑の面積になり、農村の収容力の畑の分は、その畑が穀物で養える人数になる。多雨地の畑は穀物の分だけを養うように縮めたので、乳・肉で食べる人の分がどこにも数えられていなかった。

利用者の決定（2026-10-29）により、多雨のセルの畑の分を、漁・牧畜・採集による穀物の割合を実際の穀物の割合で割った倍率で割り戻す（`ruralDiet.ts`の`getWetPastoralFieldCapacityMultiplier`）。群れの頭数は見ない。群れが実際に出す乳・肉に、穀物の割合・収容力・食料台帳の3つを結びつける版は、後続の課題とする（§4）。

不作の年に農村が少し飢えるのは、中世の舞台としてよい釣り合いとして、利用者の判断（2026-10-29）で残す。

## 4. 未確定事項

- 最大牧畜割合と下限の値、文化（遊牧・狩猟）との関係。
- 乳・肉の食料を主食の計算にどう入れるか（熱量換算の係数、季節性と保存）。穀物の割合（畑）・農村の収容力・食料台帳を、群れが実際に出す乳・肉に結びつける（§3.6は雨の適性からの仮の扱い）。
- 上乗せの耕地を外した時の、穀物の市場価格と都市の主食への影響。
- 世界誕生時点の固定点（[livestock-world-birth-herds.md](livestock-world-birth-herds.md)）が、この変更でどこへ移るか。
- 都市・農村の人口の伸びが小さくなった原因（M3）。市場に出る穀物の余り、都市の主食の価格、移住の圧力のどれが効いているか。
- **後続の調査（保留、利用者の指示 2026-10-29）:** 北方・多雨の地域の人々が、実際に畑より牧畜を優先して人手を割いたか（3.4の前提）。アイルランド・スコットランド高地・ノルウェー・アイスランドの史料で、世帯の仕事の配分と季節（移牧・干し草作り・耕作）を確かめる。
