# 多雨地の牧畜中心の暮らしと耕地の上乗せ（2026-10-29）

親計画: [historical-economy-production-consumption-circulation.md](historical-economy-production-consumption-circulation.md) §7.85（E1-5）。関連: [livestock-world-birth-herds.md](livestock-world-birth-herds.md)、[記録（単収の要因）](../analytics/e1-yield-factors-20261029.md)、[記録（収量係数）](../analytics/e1-crop-multiplier-20261029.md)。

## 1. 背景

新しく生成したWorld（seed 102）では、牛の収容力は0.20頭/人で、史料の目標（0.72頭/人）に届かない。耕地が約2 ha/人と広く、草地と牧夫が足りないためである。

- 単収は基準の0.68倍。最も大きく下げる要因は雨（0.69）である。
- 主食の人口のうち年降水量1,200 mm以上が73%を占め、2,000 mm以上は36%を占める（`rainfallBandPeople`）。
- 収量係数の校正（§7.85）で単収は21%上がったが、浮いた耕地の半分は「労働で賄える面積」までの上乗せで埋め戻された。

史実では、多雨で冷涼な土地（アイルランド、ウェールズ、スコットランド高地、ノルウェー西岸、アルプスなど）は穀物に向かず、乳と肉を多く食べる牧畜中心の暮らしだった。穀物の不足を耕地を広げて補うのは、史実に合わない。利用者の決定（2026-10-29）により、多雨地は牧畜中心にする。

## 2. 方針

### 2.1 主食の一部を乳・肉で賄う

各セルの「穀物で賄う主食の割合」（`localStapleShare`）を、雨による穀物の適性で下げる。下げた分は、乳製品・肉（およびその保存品）の食料として、群れの目標に上乗せする。

- 穀物の雨の係数`p`（作物の組み合わせの加重平均）が1を下回る多雨のセルが対象。乾燥で`p`が下がるセルは、灌漑や乾燥に強い作物の扱いが別にあるため対象外とする。
- 穀物の割合 = `max(下限, 1 − 牧畜の割合)`、牧畜の割合 = `最大牧畜割合 × (1 − p) / (1 − WET_TOLERANCE_AT_MAX)`。最大牧畜割合と下限は仮値（0.5、0.4）で、M0で史料と照らす。
- 史料の目安：中世アイルランド・高地スコットランドで、乳製品が食料の熱量の3〜5割（Kelly 1997, *Early Irish Farming*。Dodgshon 1998）。ノルウェーの農家で穀物は熱量の半分前後。

### 2.2 群れの目標と牧夫

牧畜の割合に応じて、そのセルの牛（乳）・羊・山羊の目標頭数を、乳・肉で賄う熱量から求めて上乗せする。牧夫の必要人数は今の式で群れから求めるため、目標が上がれば牧夫も雇われる。草地は、草地の上限（生態の制限）の中で目標に見合う広さとする。

### 2.3 労働で賄える面積までの上乗せ

今の耕地の目標は`max(必要面積 × 1.1, 労働で賄える面積)`（[settlementClearance.ts](../../src/generators/settlementClearance.ts)）。人手が余れば、主食に要らない耕地まで耕す。これを次のとおり改める。

- 上乗せは、需要がある場合（換金作物・都市の穀物需要・家畜の飼料）に限る。主食だけのセルでは、目標を`必要面積 × 1.1`とする。
- 余った人手は、牧夫・林業・手工業の仕事の割り当て（今の職業の配分）に回る。

M0で、上乗せのうちどれだけが市場で売られているか（換金作物・都市への穀物）を測り、全部を外すか一部を残すかを決める。

## 3. 段階

| 段階 | 内容 | 完了条件 |
| --- | --- | --- |
| M0 | 計測のみ。雨の帯ごとの人口・耕地・単収・群れ・牧夫、上乗せの耕地の収穫の行き先（自家消費・市場・腐敗）を記録する | 牧畜の割合の式と仮値、上乗せの扱いが決まる |
| M1 | 2.3を実装する | 単体テスト：主食だけのセルで耕地が必要面積×1.1を超えない |
| M2 | 2.1・2.2を実装する（主食の割合、群れの目標の上乗せ） | 単体テスト：多雨のセルで穀物の割合が下がり、群れの目標が上がる |
| M3 | 固定入力のWorldで24か月・144か月を確かめる | 牛の収容力/人が目標に近づく（0.4以上を目安）、農村・都市の主食と飼料不足が悪化しない |

## 4. 未確定事項

- 最大牧畜割合と下限の値、文化（遊牧・狩猟）との関係。
- 乳・肉の食料を主食の計算にどう入れるか（熱量換算の係数、季節性と保存）。
- 上乗せの耕地を外した時の、穀物の市場価格と都市の主食への影響。
- 世界誕生時点の固定点（[livestock-world-birth-herds.md](livestock-world-birth-herds.md)）が、この変更でどこへ移るか。
