# 塩の需要と生産の量を史料と照らす（2026-10-30）

関連: [salt-price-pressure.md](salt-price-pressure.md) §4.1、[記録（塩の値段の張り付きの原因）](../analytics/salt-price-pressure-20261030.md)。

## 1. 背景

固定入力のWorld（1302年）では、塩の生産（年161千袋＝9.7千トン）が人の需要（258千袋）の6割余り、家畜を含む需要の13%しか無い。値段は基準の約3倍に張り付き、農村の財布を塩が先に取る。

人口（人の需要からの逆算で約430万人）あたりに直すと、次のとおりになる。

| 項目 | 1人あたり年 |
| --- | --- |
| 生産 | 2.25 kg |
| 人の需要（`SALT_HOUSEHOLD_KILOGRAMS_PER_PERSON_YEAR`） | 3.6 kg |
| 家畜の需要（`SALT_LIVESTOCK_ANNUAL_KG`から） | 約14 kg |

## 2. 史料の目安

| 項目 | 値 | 出典 |
| --- | --- | --- |
| 古代の人の塩 | 1.1〜4.3 kg/年（モデルで2.5 kg、3.6 kgの案もある） | Sodium Chronicles (2026) がまとめた諸説 |
| 古代の牛の塩 | 20〜30 kg/年（モデルで21.5 kg）。今の獣医の推奨は14.6 kg/年 | 同上（Ziółkowski、Cifani、Johansson 2008） |
| 古代の羊・山羊の塩 | 4.5 kg/年 | 同上 |
| 牛の生理的な必要量 | 1日10〜25 g（年3.7〜9 kg）。泌乳の最盛期の乳牛で1日80 g | Marsal（フランス文化省） |
| 羊・小反芻獣の生理的な必要量 | 1日3〜10 g（年1.1〜3.7 kg） | 同上 |
| 近世フランスの強制購入（sel de devoir） | 1人年7 kgまで（料理・保存・チーズ・家畜に使う分） | Gabelle（Wikipedia） |
| 工業化の前の塩の用途 | 量では家畜の餌が最大 | Marsal |

- 牛の20 kgは、古代のモデルの値（20〜21.5 kg）の範囲にあり、生理的な必要量（4〜9 kg）よりは大きい。羊・山羊の1.4 kgは、生理的な必要量の範囲で、古代のモデルの値（4.5 kg）より小さい。家畜の値だけが飛び抜けて大きいとは言えない。
- 生産の1人年2.25 kgは、人の需要だけにも足りず、近世フランスの強制購入の量（7 kg）の3分の1に満たない。品不足の主な原因は生産の側にあるとみられる。

## 3. 確かめること・直し方

| 段階 | 内容 | 完了条件 |
| --- | --- | --- |
| Q0 | 製塩所ごとの能力と実際の生産、生産を止めている要因（季節、働き手の予算、燃料、所有者の現金、在庫の上限）を計測する（固定入力、24か月） | 生産が少ない原因が、製塩所の数か、1か所の能力か、どの制限かが分かる |
| Q1 | Q0の結果で直し方を決め、別の段階として実装する（製塩所の数・能力・制限のいずれか） | 単体テスト |
| Q2 | 固定入力で84か月 | 世界の生産が人の需要を満たし、塩の値段が基準に近づく。1304〜1305年の都市の主食の充足が94.2%・95.6%に戻る |

### 3.1 Q0の結果（2026-10-30、[記録](../analytics/salt-supply-calibration-20261030.md)）

- 製塩所は274か所（すべて煮詰め）、年の能力は298千袋で、世界を作った時の人の需要の1.15倍しか無く、家畜の需要が入っていない。
- 夏〜秋はほぼすべての製塩所が能力の上限まで作るが、冬〜春（2〜4月）は能力の2〜4%に落ちる。所有者の現金と薪は制限になっておらず、買う側の市場が塩の仕入れに使える現金（`saltMarketCash`）が世界の合計で0.4〜1千しか無いことが原因。
- Q1の候補: (a) 冬〜春の市場の現金の不足の原因（`ruralGrainPayable`など）を調べて直す、(b) 能力を家畜の需要に合わせて増やす（既存のセーブの能力の見直しを含む）。(a)を先に行う。
- (a)の追記: 金庫の残高は10月の119千から2月の1.8千に落ち、2月に農村への穀物の未払いが48千ある。秋〜冬の穀物の買い上げが金庫を空にし、春〜初夏まで塩を仕入れられない。直し方（塩の仕入れの掛け払い、穀物の買い上げと塩の仕入れの金庫の分け方など）は未定。

### 3.2 Q1の方針: 塩の掛け売り（2026-10-30）

- 製塩所が新しく作った塩（`paySaltWholesale`の`fresh`）は、買う市場の金庫に現金が足りなければ掛けで売る。現金で払えるだけ払い、残り（品代と運賃）を市場の金庫の`saltPayables`（製塩所id→額）に積む。運賃は製塩所の持ち主が立て替えて運び手に払う。
- 掛けの上限は、その市場のその月の塩の需要（人・家畜・加工）の`SALT_CREDIT_MONTHS`か月分（仮値3）の仕入れ値から、すでにある掛けを引いた額とする。
- 毎月の塩の精算の初めに、市場は塩に使える現金（`saltMarketCash`）で掛けを返し、持ち主の口座に入れる。`saltMarketCash`は掛けを差し引く。製塩所が無くなった掛けは消す。
- 市場の間で古い在庫を回す経路（`fresh`でない）は、今のまま現金だけで払う。
- 中世〜近世の塩の取引では、製塩所（国・領主）から商人への掛け売り・委託販売が普通だった。

### 3.3 Q1・Q2の結果（2026-10-30、[記録](../analytics/salt-supply-calibration-20261030.md)§5）

- Q1: `saltFinance.ts`に`SALT_CREDIT_MONTHS`（3）、`saltPayables`（`marketTypes.ts`）、`saltCreditRoom`・`repaySaltPayables`を加え、`paySaltWholesale`で現金の足りない分を掛けにした。「買う市場に現金が無ければ作らない」単体テストを「持ち主に現金が無ければ作らない」に改め、掛けで売って後で返すテストを加えた（`SALT_CREDIT_MONTHS`を0にすると失敗）。
- Q2: 冬〜春の生産の止まりは無くなり、1300〜1302年の生産は2〜7割増えた。人に売れた塩は需要の4〜5割から6〜7割余りになった。値段は基準の約2.6倍のまま下がらず、農村の人の塩の支払いが年30〜70千増え、その分町で使うお金が減った。1304〜1305年の都市の充足は92.5%・94.2%で、完了条件を満たさない。1303年は掛けが上限に近づいて生産が月ごとに減った。goldenの基準値は更新していない。
- 値段の`pressure`は、家畜を含む1か月の需要に対する在庫で決まる。家畜の需要（人の約4倍）が満たされない限り、生産を増やしても値段は下がらない。

### 3.4 生産が年ごとに減る理由（2026-10-30、[記録](../analytics/salt-supply-calibration-20261030.md)§6）

- 製塩所の数・能力・持ち主の現金・薪は4年間変わらない。減るのは、買う側の市場の金庫の現金（夏〜秋の最大が116.6千→24.3千）で、掛けは返しきれずに積み上がり（最小8.1千→107.1千）、1303年には上限に届く。掛け売りの無い場合も同じく減っており、市場の金庫の現金が年ごとに減ることが根にある。
- 次は、市場の金庫の出入りを経路ごとに記録して、現金がどこへ流れるかを調べる。

### 3.5 市場の金庫の出入りと、2つの修正（2026-10-30、[記録](../analytics/market-treasury-flows-20261030.md)）

- 市場の金庫の年初の残高は減っていない。塩の仕入れに使える現金が減って見えたのは、塩の掛けが差し引かれるためだった。
- 修正1: 余りの分配（`payOutMarketSurplus`）で、塩の掛けの額を市場の手元に残す（`householdWealth.ts`、単体テスト1件）。
- 修正2: 市場の注文・在庫の目標・掛けの上限で、家畜の塩はその月の枠で買える量だけ数える（`saltLogistics.ts`、単体テスト1件）。
- 結果: 都市の財布が尽きた市場は1か所に、1304〜1305年の都市の充足は93.5%・94.8%（完了条件に届かない）。塩の掛けはまだ年ごとに積み上がり、人に売れる塩は1303年に需要の35%まで下がった。塩の仕入れの現金が年ごとに減る残りの理由は未確認。goldenの基準値は更新していない。

### 3.6 掛けの返済の修正（2026-10-30、[記録](../analytics/calibration-peace-20261030.md)）

- 返済の現金を`saltMarketCash`（掛けを差し引いた額）で測っていたため、市場は掛けの2倍を超える現金を持つまで返せなかった。差し引く前の額で返すように直した（`saltLogistics.ts`、単体テストを修正）。
- 平和モードの48か月で、掛けは積み上がらなくなり（残高の最大15〜18千）、生産は年256〜264千袋、人に売れる塩は需要の75〜81%で保たれた。値段は基準の2.4〜2.7倍のまま。都市の充足は1304〜1305年で93.2%・95.1%。
- 進める順序は、(1) 製塩所が人と家畜の需要以上を作る、(2) 塩が通常の値段で流通する、(3) 掛けが正しく返される、とする。(3)はここで直した。(2)を抑える変更（[salt-price-pressure.md](salt-price-pressure.md)§4.2と、注文・在庫目標・掛けの上限を同じ量にした[修正2](../analytics/market-treasury-flows-20261030.md)§2）は、(1)の結果を見て残すか戻すかを決める。

### 3.7 製塩所の能力を今の需要に合わせる（2026-10-30、[記録](../analytics/salt-capacity-to-need-20261030.md)）

- 毎月、産地の国ごとに製塩所の能力を、人・家畜・加工・内陸の供給先の今の需要×1.15（`SALTWORK_OPERATING_RESERVE`）に合わせる（`resizeSaltworksToNeed`、`saltLogistics.ts`、単体テスト1件）。
- 結果: 能力は年約1,600千袋、生産は年523〜556千袋、値段は基準の約1.7倍（前は2.7倍）。生産は注文で決まり、注文は家畜の塩を財布の5%の分しか数えない。都市の充足は1304〜1305年で93.0%・95.9%。1304年の落ち込みは穀物の在庫の不足が主で、塩の変更では動かない。

### 3.8 家畜の塩を需要の全量で注文する（2026-10-30、[記録](../analytics/salt-full-need-orders-20261030.md)）

- 注文・在庫の目標・掛けの上限で、家畜の塩を需要の全量で数える（`saltLogistics.ts`、単体テストを逆の向きに修正）。値段の計算と、家畜の塩の支払いの上限（財布の5%）は残す。
- 結果: 生産は年690〜740千袋、値段は基準の約1.25倍（前は1.7倍）、掛けは積み上がらない。都市の充足は1304〜1305年で92.7%・96.6%。

### 3.9 家畜の塩を掛けで売る（2026-10-30、[記録](../analytics/livestock-salt-on-account-20261030.md)）

- 家畜は需要の全量を受け取り、財布の5%で返済と今月の代金を払い、残りを市場の掛け（`ruralSaltReceivable`、上限は家畜の需要の3か月分）にする。値段は需要の全量で決める（`saltLogistics.ts`、単体テスト2件を修正・1件を削除）。
- 結果: 1年目は生産826千袋、2年目からは掛けが上限に張り付き、生産は471〜616千袋に下がった。値段は基準の1.6〜1.7倍に戻った。家畜の需要の代金は5%の枠の2倍を超えており、掛けでは返しきれない。

### 3.10 家畜の塩を買った割合で数える（2026-10-30、[記録](../analytics/livestock-salt-purchased-share-20261030.md)）

- 家畜の生理的な必要量のうち農家が買った割合を0.4とした（`SALT_LIVESTOCK_PURCHASED_SHARE`、Neckerのpays rédimésの1人18リーヴルに合わせる）。単体テストの期待値3件を直した。
- 結果: 生産は年452〜542千袋で需要（約590千）を下回り、値段は基準の約2倍。原因は燃料（木材）の無い市場8の製塩所22か所（能力月約5.4千袋、需要の約11%）と冬の人手の不足。市場の現金と卸値の式は主な原因ではない。燃料は[製塩所の燃料と塩の調達](saltworks-fuel-procurement.md)で直す。

家畜の1頭あたりの量は、Q0〜Q2の後に、家畜の塩の不足が家畜に何の影響も無い今の扱いと合わせて見直す。

### 3.11 複数の国家にまたがる市場の在庫を国家ごとの割合で数える（2026-10-31、[記録](../analytics/salt-shared-market-stock-20261031.md)）

- 原因: 市場と国家の領域が一致しないので、1つの市場に複数の国家の人が住む。注文は国家ごとに「その国家の分の需要＋3か月の在庫−市場の在庫」で決めていたが、市場の在庫は全体の量を引いていた。どの国家も在庫の全体を自分の取り置きと数え、市場の在庫は1国家の分ほどにしかならなかった。値段は市場の全体の需要で決まるので、値段が高いまま下がらなかった。
- 根拠: 1か国の市場（最大の国家の人口の割合93%以上）は基準の1.0〜1.18倍、複数の国家にまたがる市場は1.25〜3.0倍だった。製塩所の生産が0の国家の多くは、注文が来ていないだけで、能力は空いていた。
- 修正: 国家ごとの注文で、市場の在庫のうち「その国家の需要÷市場の全体の需要」の割合だけを自分の分として数える（`saltLogistics.ts`）。
- 結果: 値段は基準の1.71〜1.86倍から1.07〜1.14倍（1302〜1304年）、生産は月約52千袋から65〜66千袋（需要約61千）。

### 3.12 塩の値段を塩の値付けだけが決める（2026-10-31、[記録](../analytics/salt-price-ownership-20261031.md)）

- 原因: 塩の値段は`priceSalt`が需要と在庫から月に1回決める（前の値段から8割を引き継ぐ）。ところが、商人の市場の間の交易と職人の仕入れも、普通の財と同じ押し上げ・押し下げ（`applyMarketPressure`）を塩の値段に掛けていた。交易は塩の値付けの後に動くので、大きな取り引き1回で値段が基準の4分の1近くまで下がり、それが次の月以降に残った（市場1）。
- 修正: 塩は交易と仕入れで値段を動かさない（`marketPricing.ts`の`hasSettledPrice`）。商人は今までどおり塩を運んで売る。
- 結果: 値段は基準の1.03〜1.09倍、1.2倍以下の人口の割合は87〜100%。家庭の不足はほぼ0。

### 3.13 共有の市場の塩の掛けを国ごとの割合で数える（2026-10-31、[記録](../analytics/salt-shared-market-credit-20261031.md)）

- 背景: [salt-untaxed-value.md](salt-untaxed-value.md)のV2の後も、家畜の塩の不足が年1.4〜1.9万袋残った。製塩所の能力は需要×1.15で、生産は能力の85%であり、能力は上限ではなかった。
- 原因の内訳は3つ。
  1. 国28・15の新しい小さい市場22〜27で、農村の財布が小さいこと（お金）。
  2. 市場1で、買う市場の金庫の現金が上限になること（注文）。
  3. 国28の製塩所の人手の不足（注文）。
- 2の原因: 塩の掛けの余地は、ある国のその市場の3か月分の仕入れ値から、市場全体の塩の掛けを引いていた。共有の市場では、国の数だけ掛けを引いていた。
- 修正: 市場の掛けのうち、その国の需要の割合（§3.11の`stockShare`）だけを引く（`saltCreditRoom`の`share`）。単体テスト1件。
- 結果（48か月）: 市場1の不足は0になった。1303年の家畜の塩の不足は15.7千から8.7千に減った。
- 残る: 国28の製塩所の人手（市場22の町は1.0千人で6か所）と、新しい小さい市場の農村の財布。人手の直し方（能力を人手に合わせて割り振る・季節の農村の手・製塩所を加える）と、煮詰めの1袋142.6時間の根拠は未定。
