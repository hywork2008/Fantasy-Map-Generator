# 軍隊の原則

1. 軍隊の基本的な動きは第一に国境の防衛
2. 軍隊はroutes沿いに動くのでroutesをnodeの繋がりに置き換え、node上に自軍を配置し、敵軍がnodeを通れないようにする。
3. nodeを塞ぐために軍隊の統合や分裂を行い、砦や防壁の防御力と兵士数が拮抗して攻め落とされないように調整する。
4. 防衛と平行して、自国の領土内で敵に占領された都市があれば再占領を目指す。

これが出来て、はじめて敵国への侵攻を考える事が出来る。

## 広い領地はnodesが多い

国土が広い国は敵国との境界線もそれだけ長くなり、必然的に多くのノードを抱える。
敵国への警戒は手厚く、同盟国への警戒はやや薄い。将来的に婚姻外交が正確に実装されれば更に警戒用の軍隊を削減し、敵国へ向ける事が出来る。

### ノードの守備

国境で敵側に都市が無く、自国に防護壁つきの都市がある場合。
防護壁のボーナスと防衛の有利があるので敵より少ない兵士で守備が出来るので、余剰を他のノードに回す余裕がある。
敵の方が有利なノードがあれば、余裕のある軍隊は自軍の余剰を分割し、足りないノードへの移動を開始させる。

既存の軍隊は出ずっぱりで兵の補給が出来ない、或いはしにくい。時間経過とともに兵士になれる若い層が育ち、capitalかcityに余剰の人口が集められ、そこで軍隊が新しく編成され、前線へ合流して回復するという流れが望ましい。
