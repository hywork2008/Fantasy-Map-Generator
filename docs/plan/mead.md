# 蜂蜜酒（Mead）

蜂蜜の取れる土地と量は[honey-forage-lands.md](honey-forage-lands.md)。その§8の1（蜂蜜酒の需要と流通量）を扱う。

## 1. 背景

- 蜂蜜の量を史料に合わせた後（honey-forage-lands.md §6）、家計が採取の約88%を使い、残りの約11%は使い道が無く在庫に積み上がった。値は値打ちの約1/4まで下がった（[honey-biome-20261107.md](../analytics/honey-biome-20261107.md) §4）。
- 町のエールは、森の少ない土地で減らした（[low-habitability-site-bonus.md](low-habitability-site-bonus.md) §4）。ブドウの無い土地の飲み物として、蜂蜜酒を加える。
- 前のコードには蜂蜜酒が無く、Beerの説明に「蜂蜜の飲み物は将来の財」とあるだけだった。

## 2. 史料

### 2.1 量

- Liseitsev, "Tavern revenues and alcohol consumption in the Muscovite state"（[HSE WP 186/HUM/2020](https://wp.hse.ru/data/2020/01/30/1572263623/186HUM2020.pdf)）。
  - 1620年代のモスクワ国の酒場の請負の記録から、酒場の客（町の人の半分と見る）1人あたり年に、蜂蜜酒4.4 L、ビール79 L、蒸留酒29.3 L。
  - 著者は、記録が最大1.5倍ほど少なく出ていると見る。
  - 蜂蜜酒はアルコール約12%とする。
  - 1バケツ = 12 L。
- ポーランドの史料の説明では、蜂蜜酒は祝いの日と豊かな人の飲み物で、リトアニアとルテニアに長く残り、後にウォッカに置き換わった。
- Allsop & Brand Miller: ブドウの無い土地で蜂蜜酒が多く飲まれた。

### 2.2 造り方

- ドモストロイ65章（[beer-studies.com](https://beer-studies.com/en/explorer?geo=88&chrono=485&theme=487&article=490)）。
  - 白い蜂蜜酒は蜂蜜1に水4、普通の蜂蜜酒は1:6、煮た蜂蜜酒は1:7。
  - できた酒は樽に入れた。強い蜂蜜酒は客のためのもの。
- 13〜14世紀のイングランドの写本の造り方: 蜂蜜1に水4。
- ポーランドの等級: czwórniak 1:3、trójniak 1:2（強い）。

## 3. 決めた値

| 項目 | 値 | 根拠 |
| --- | --- | --- |
| 単位 | 1,000 Lの樽（tun）。200 Lの樽5つ | エール・シードルと同じ |
| レシピ | 蜂蜜1.667樽（200 L、280 kg）、樽0.4 | 蜂蜜1に水4（§2.2）。樽は5つの樽の修理分で、エールと同じ |
| 値打ち | 4.5（エールの3倍/L） | 値段の比2〜3倍、ポーランドで3〜7倍（§2.3）。蜂蜜の材料は値打ちで2.5、樽は0.04 |
| 労働 | 0.00015 | 麦芽を作らない。シードルと同じ |
| 需要 | 町の大人1人あたり年5 L | 4.4 L × 町の人の半分 × 最大1.5倍 ÷ 大人0.65 ≒ 5 L |
| ワインの産地 | 0 | 市場がブドウを受け取るなら、町はワインを飲む（エールと同じ判定） |
| 農村 | 市場で買わない | 自家製で、家計の蜂蜜（1人あたり年1 kg）の中に入る |
| 在庫の上限 | 需要の3か月分 | ワイン・干しブドウと同じ |
| 樽の出入り | シードル・ペリーと同じ記録（`orchardCasks`）に入れる | |
| 払う人 | 町だけ | エールと同じ |

- 需要はワールドの設定`fmg-town-mead-liters`（既定5、0〜30、Simulation設定の画面）。
- 保存した地図には`migrateMeadGood`で、その地図の蜂蜜と樽のidを使ってMeadを足す。
- 見込み: 町の人の割合を約10%とすると、蜂蜜酒の蜂蜜は世界で1人あたり年約0.09 kg。蜂蜜の残り（約0.12〜0.15 kg）より少し少ない。

## 4. 計測

結果は[mead-20261107.md](../analytics/mead-20261107.md)（シード2103・2102、12か月）。

- 12か月目に、町の需要の68〜76%が飲まれた。飲まれる量はまだ増えている。値段は値打ちの1〜2倍。
- 蜂蜜の在庫の積み上がりは約1/3〜2/3に減り、値段は値打ちの約0.4〜0.6倍まで戻った（前は約0.26）。
- 需要を全部満たすと、2103では蜂蜜の残りをほぼ使い切り、2102では約半分が残る。

## 5. 未確定事項

1. 蜂蜜酒の器（樽か陶器か）と、寒い土地の粘土（honey-forage-lands.md §8の2）。
2. ワインの産地でも少しは蜂蜜酒が飲まれた可能性。今は0。
3. 蜂蜜酒を造る市場が少ない（在庫のある市場は1/3）ことと、2103で4〜5か月目に造った量が0になった理由。
