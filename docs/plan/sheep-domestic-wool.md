# 国内の羊毛の量と羊の頭数 (Sheep for Domestic Wool) 設計

2026-11-17 設計。[textile-basket-scale.md](textile-basket-scale.md) §3.5の後、[textile-supply-20261117.md](../analytics/textile-supply-20261117.md) で、衣服・毛布を作る量の不足が羊毛の量で決まるとわかったことへの対応。親計画 [historical-economy-production-consumption-circulation.md](historical-economy-production-consumption-circulation.md) E1-3の残課題「羊の頭数の差（荒蕪地の放牧）」を扱う。

## 状態

- §3.1の史料照合を行った（2026-11-17、[wool-sources-20261117.md](../analytics/wool-sources-20261117.md)）。**結論: 羊の頭数の目標（国内の羊毛約0.84 kg・1.3頭/人）は誤りではない。** 史料の国内の羊毛は1人約0.8〜1 kg。§2の概数（1.7〜2.1 kg）は記憶の頭数が多すぎた。
- 食い違いは布の側にある。衣服の量（シム1 kg、史料の国内の毛の布は約0.6〜0.7 kg）と、羊毛から布の歩留まり（シム2.25、16世紀の標準の布で1.31）の両方が多く、羊毛を約3倍要る。直しは [textile-basket-scale.md](textile-basket-scale.md) で行う。§3.2〜§3.3（頭数の目標を変えること）は行わない。輸出の群れ（§3.2の最後）は残課題のまま。

## 1. 問題

| | 1人・年 |
| --- | ---: |
| 刈った羊毛（地図2103、3年目） | 約0.9 kg（全て布に使われる） |
| 衣服（1 kg）と毛布を全て毛で作るのに要る羊毛 | 約2.8 kg |
| 羊（100人あたり） | シム112頭、Allen 1300年 456頭（輸出の群れを含む） |

- 羊の頭数は、土地ではなく頭数の目標（`SHEEP_PER_RURAL_PERSON` 1.3、`livestockHerdTargetPolicy.ts`）で決まる。適地では、その3割を山羊にする。
- 目標の1.3の根拠は、コードのコメントで「国内の羊毛（1人約0.84 kg、1頭0.67 kg）に要る頭数。輸出は市場に任せる」。親計画§7.43の表では「国内需要分で約1.3頭/人」で、0.84 kg の出し方は記録に無い。

## 2. 二つの決まりが食い違う

- **羊の側**: 国内の羊毛は1人約0.84 kg（根拠の出し方は未記録）。
- **布の側**: 衣服1人・年1 kg（1揃い4 kgを4年）× 羊毛2.5 kg/kg（布4 t に羊毛9 t、衣服に布1.11倍）で、羊毛2.5 kg。毛布で約0.3 kg。

どちらかが史実から外れている。手掛かり（未確認、記憶による概数）:

- 1300年ごろの羊毛の刈り取りは、羊2,280万頭（Allen Table 2）× 0.67 kg ≈ 1,500万 kg。
- 輸出は年3万〜4万袋（1袋約165 kg）≈ 500万〜650万 kg とされる（関税の記録。英国国立公文書館の案内は [wool-products-and-sheep-husbandry.md](wool-products-and-sheep-husbandry.md) §2）。
- 残りの国内分は約850万〜1,000万 kg。人口約470万〜500万で、1人約1.7〜2.1 kg。

この概数なら、国内の羊毛は0.84 kg の約2倍で、布の側の需要（2.8 kg、亜麻・麻の衣服を含まない）に近い。

## 3. 仕組み（案）

### 3.1 史料の照合（最初に行う）

1. 1300年ごろの羊毛の輸出の袋数と、1袋の重さ（関税の記録、Lloyd 1977 *The English Wool Trade in the Middle Ages* など）。
2. 羊の頭数・1頭の羊毛（Allen 2005 Table 2、Stephenson 1988）。
3. 国内の羊毛の量 = 刈り取り − 輸出。1人あたりに直す。
4. 衣服の量（1人・年1 kg）と、羊毛から衣服への歩留まり（2.5 kg/kg）を、同じ時代の史料と照らす。毛の衣服と、亜麻・麻の衣服の割合も見る。

### 3.2 羊の頭数の目標

- 目標を、国内の羊毛の需要から決める形にする。`国内の羊毛（1人・年 kg） ÷ 1頭の年の羊毛 × 農村の人数`。国内の羊毛の値は§3.1で決め、設定にする。
- 今の決まり（1.3頭/人）は、§3.1で0.84 kg が正しいとわかれば残し、誤りなら選べる形では残さない（壊れた古い値は残さない方針）。
- 羊毛の輸出の群れ（456頭との差の残り）は、羊毛の輸出の需要が入ってから扱う。この設計では入れない。

### 3.3 土地と飼料が支えられるか（計測）

- 頭数の目標を上げても、牧草地・冬の飼料・牧夫の人手（E1-4・E1-5）で支えられなければ、群れは痩せるか減る。
- 共有地・荒蕪地（Allen Table 1 で耕地の1.7倍、[e1-cleared-pasture-source-20261028.md](../analytics/e1-cleared-pasture-source-20261028.md)）の放牧を、今の牧草の上限がどこまで数えているかを確かめる。足りなければ、荒蕪地の放牧の上限を足す。
- 羊が増えると、羊の乳（チーズ）、肉、獣脂、堆肥も増える。乳製品（[dairy-demand.md](dairy-demand.md)）・肉の値への影響も見る。

## 5. 計測

- 地図2103、36か月と、群れが釣り合うまでの長さ（E1-5で牛・羊は96か月でも増えていた）。戦争なし・略奪なし。
- 見るもの: 羊の頭数（100人あたり）、刈った羊毛（1人・年）、衣服・毛布の需要を満たした割合、飼料の不足・痩せ、牧夫の人手、羊毛・衣服の値段、羊の乳とチーズ。
