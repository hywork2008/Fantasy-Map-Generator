# 自然林・入植・開墾を整合させる広域景観設計

状態: **設計のみ（未実装）**。2026-10-05 に現行コード・史料を再確認して改訂。実装コードは変更しない。

## 1. レビュー結論と適用範囲

問題は「森林セルの都市が森に囲まれること」そのものではなく、**潜在自然植生をセル全面の樹冠として描き、人間の土地利用とその立地条件を表現していないこと**である。森林内の小集落、林業拠点、輸入に依存する港町では、都市の近くまで森がある状態も自然である。一方、農業人口の多い長期定住地域を、都市アイコンの周囲だけ丸く切り抜いた密林として描くのは不自然になる。

本設計の到達点は、RE の Province 規模で、自然植生・農村・都市・交通・水域が連続した景観として読めること。個々の木、家、全農家の経営をシミュレートすることは要求しない。CE との接続には共有の人口・土地利用・市街地範囲を用い、CG は対象外とする。

### 旧案から変更する決定

| 旧案 | レビュー後の決定 |
| --- | --- |
| 森林セルの都市は森に囲まれてはいけない | 集落の実占有地と生産活動を表現する。森林近接自体は禁止しない |
| 市街地→畑→牧草地→薪炭林→自然林の同心リング | 距離による優先度は使うが、実形状は地形・水・交通・既存利用に沿うモザイク |
| 約 1.02 ha/人に統一 | **計算モデルを共有**する。面積は収量・作付率・食料供給・労働力等に依存する |
| 畑の 30〜60% を一律に牧草地にする | 家畜・飼料・採草・林間放牧・輪作との重複を考慮する |
| 技術が高いほど開墾倍率が上がる | 開墾速度、収量、労働生産性を分離。高収量なら同じ需要を狭い面積で満たせる |
| 人口にさらに saturation/100 を乗じる | 確定済み実人口を使用。初期人口設定を二重適用しない |
| 初期化の直前に `forestStock` を減らす | 初期化・必要データ準備の**後**に、一度だけ初期土地利用を確定する |
| 薪需要を恒久開墾に加算 | 伐採・管理林・農地転換を分離。伐採跡を自動で畑にしない |
| 全街道の両側約 60 m を皆伐 | 通行幅と下層植生の管理を分離。歴史上の特定法令を世界共通にしない |
| エルフだけが森林と共存する | エルフ既定の林内都市は維持。人間にも林間利用を認め、文化・生業・個別設定で上書き可能 |

## 4. 自然状態の森林セル

### 4.1 セルは均一な林分ではない

`biome` は気候・生態上の基盤、`forestCover` は森林の潜在容量、土地利用は現在そこを何に使っているかを表す。**開墾しても気候バイオームを grassland に変更しない。** 無人セルも、森林域・自然草地・湿地・岩場・水域を含み得る。既定では大きなまとまりを持った林冠に、立地に理由のある抜けを配置する。乱数の点穴を全面に散らして「自然らしさ」を作らない。

| 環境 | 自然状態の表現 | 入植時の注意 |
| --- | --- | --- |
| 湿潤温帯・熱帯多雨 | 広い連続樹冠と大小のギャップ、異なる林齢 | 森林の生産力と農地の肥沃さを同一視しない。土壌・排水が悪い森林もある |
| 季節性熱帯・乾燥林 | 疎密のある森林、乾季の落葉・草地との遷移 | 雨季/乾季と休閑・樹木農業を考慮。落葉を開墾と判定しない |
| 冷温帯・亜寒帯 | 針葉樹・混交林と湿地・湖・撹乱跡のモザイク | 生育期・温度・土壌の制約により、降水があっても大農地にならない |
| 山地 | 斜面・谷の森林と岩場・高地草原。樹林限界は気候依存 | 標高だけで森を除去しない。緩斜面・段丘等を耕作候補にする |
| 河畔・氾濫原 | 水面、砂礫州、河畔林、湿草地、湿地林の組合せ | 全河川両岸を裸地にしない。取水の便利さと洪水・湛水リスクを両方評価 |
| マングローブ・冠水林 | 水文条件と結びつく樹冠 | 常時水面と、樹木が育つ冠水地を区別。通常の穀物畑は不可、干拓等は別条件 |

森林率の既定値は史実の推定値ではなく校正対象である。既存の `canopy` は樹冠被覆率ではなく樹種構成コードなので、数値被覆率として読まない。`forestCondition` は林齢表現に、`specialFeature` は明示された魔法森林等に使う。気候だけから魔法属性を作らない。

### 4.2 連続性

自然植生のパッチは世界座標と安定した seed で決め、隣接セルで空間相関を持たせる。セルの辺、州境、表示範囲が林縁になることを避ける。容量制約と細かな樹冠のテクスチャを分離し、実面積が変わらない範囲で林縁を一般化する。微細な倒木ギャップまで広域図に穴として描く必要はない。

## 5. 入植・文化・生業のモデル

### 5.1 同じ人口でも景観は異なる

| 集落・利用プロファイル | 広域図で期待する形 |
| --- | --- |
| 長期定住の穀作農村・農業都市 | 複数の村落を核とする畑・休耕地・採草地、残存林、生垣・小林。隣村の開地と合流し得る |
| 新しい開拓集落 | 接続路付近の小さな開地、伐採跡・若齢林と未開拓林。低人口でも過去に開かれた土地があれば残す |
| 港町・交易都市 | 市街地、港、近郊菜園はあるが、穀物の供給域は遠方にもある。都市人口全員分の畑を港の周囲へ強制しない |
| 林業・鉱山・製鉄拠点 | 搬出路、作業地、伐採区画、管理林。燃料需要は大きくても、その全域が穀物畑になるわけではない |
| 牧畜・林間放牧 | 開放牧地と疎林の混在。採草地、飼料作、休耕地利用を区別する |
| 焼畑・樹木農業 | 現作付地、樹木を含む生産地、休閑・再生林。耕作循環の全域を同時に裸地にしない |
| 狩猟採集・漁撈・季節利用 | 小さな居住・作業地と広い利用域。利用域全体を開墾しない |
| 放棄集落・荒廃農地 | 開地→草本・低木→若齢林の遷移。人口ゼロになっても直ちに原生的な森林へ戻さない |

配置には生業、土地保有・共同利用、計画入植か自然発生か、保護林・聖林・狩猟林、紛争・防衛、継続居住年数を反映できるようにする。未実装の属性を既存データであるかのように扱わず、入力元とフォールバックを明記する。

### 5.2 種族と文化

種族へ `forestAffinity: embedded | clears` を必須追加する旧案は採用しない。集落の **land-use profile** を解決し、優先順位を「集落の明示設定 → 文化・生業設定 → ファンタジー種族の既定 → 通常の混合農業」とする。生業が不明な通常集落の既定は推定と記録する。

`highFantasy` / `darkFantasy` での `elf`・`dark_elf` は、旧決定の「小さな林間空地と近接樹冠」を既定として維持する。ただし暗黒エルフが必ず森林居住であるとはせず、地下・都市型等を明示した場合はその設定を優先する。

`embedded` は建築・樹木の共存方式であり、食料需要を 0〜0.1 倍に消す属性ではない。林内栽培、採集、輸入、または明示された魔法的供給とその能力で食料を説明する。供給情報がなければ不足/未解決として残す。地上建物・通路・岸辺の作業場を確保し、樹上建築は専用の共存設定がある場合に許可する。エルフの都市アイコンも樹冠に隠れないようにする。

### 5.3 人口・歴史・技術

- 農村人口 `cells.pop × populationRate` と都市人口 `burg.population × populationRate × urbanization` を区別し、需要台帳で一度ずつ計上する。Burg がない人口セルにも農地・利用地を作る。
- 初期 saturation は人口生成に既に作用する。実人口に再度掛けない。`startingPopulationScaleOfK` の上限 0.6 とも独立した「100% なら全森林開墾」という規則は作らない。
- 初期マップの成熟集落は、過去の利用が成立済みの状態として初期化できる。年次に新規開拓する場合は利用可能労働力・道具・アクセス・経過時間による上限を守る。農業労働と伐根・開墾労働は同じ枠を二重使用しない。
- 技術は、収量、輪作の作付率、維持労働、排水・灌漑、開墾速度に個別に効く。既存計算に入った効果を追加倍率で重ねない。普及率を解決して純関数へ渡し、RE は技術ツリーを直接参照しない。
- 人口減少・一時休耕・戦争直後に土地利用を全再生成しない。維持停止と再生の時間を持ち、短期休耕を直ちに森林へ変えない。

## 6. 数量モデルと面積保存

### 6.1 三つの層を分離する

1. **潜在自然環境**: biome、森林容量、地形、気候、水文。入植で書き換えない。
2. **土地利用の面積と配置**: 市街地、耕作循環地、牧草・採草地、樹木農業/林間放牧、管理林、自然林、その他自然地、道路・作業地等。
3. **植生の状態**: 現在の樹冠、林齢/再生段階、生立木 stock。管理林の伐採や落葉は主用途の変更を意味しない。

第 2 層はセル内面積を分割する。第 3 層はその上に重なる属性とする。たとえば林間放牧地の樹冠と放牧利用を別々の土地面積として加算しない。地上占有地に残す庭木と、密生樹冠で市街地を覆う処理も区別する。

現行 `forestStock` は木材量と被覆代理の両方に使われているため、完全な樹冠率には変換できない。第一段階ではその意味を変更せず「legacy proxy」と明記し、減少を耕地量に直結させない。独立した土地利用台帳を導入するときは、農業・林業・再生・牧畜・野生動物の消費側を同時に移行する。木材 stock の正本を別に増設してはならない。

`landCover` の単一コードは表示・互換用の代表用途として導出する。面積内訳の正本にはしない。`clearedFraction` も保存状態に追加しない。必要なら `convertedForestAreaHa / physicalLandAreaHa` 等、分母を明記した派生値を出す。`1 - stock/capacity` を同名で流用しない。

### 6.2 必要量と実現量

共有純関数は、名前を維持するなら `src/generators/settlementClearance.ts` とし、入力として解決済み環境・人口・生業・生産性・輸入/輸出割当・既存利用・年度を取る。グローバル状態や経済拡張へ依存させない。集落別需要の算出とセル/供給域への配分を分け、都市単独で土地を取り合う逐次ループにしない。

穀物の自給必要面積の基礎式は共有する。

```text
requiredFieldAreaHa = people × stapleNeedKgPerPersonYear
                    / (edibleShare × yieldKgPerSownHa × annualSownShare)
```

現行定数の 200 kg、0.65、450 kg/ha、0.67 なら約 1.02 ha/人になる。これは**休耕を含む輪作面積の基準例**であり、播種面積をさらに足す値でも、全食料・全文化に固定する定数でもない。自給分・輸出分・輸入分を需要台帳で調整し、同じ都市需要を生産地と都市セルで二重に計上しない。

現行経済の `max(自給予備分, 労働力で開発可能な面積)` は輸出余力も含む政策である。今回の共有化で黙って `min(自給需要, 労働力)` に置き換えない。まず現行政策を名前付き入力として維持し、必要面積・政策上の目標・実際に維持できる面積を別々に出力する。既存の自給下限が労働力を超える場合も不足を隠さず診断する。年次開拓でそれを無制限の開墾許可にしない。

実面積は、地形/土壌適性、作物と生育期、季節別水収支、維持労働、開発能力、競合土地利用で制約する。河川が近いだけでは取水可能としない。灌漑設備、揚水・輸送、上流下流の共有水量を確認する。RE に既存の「各河川流量の 10%」計算を残して独立した水予算を作らない。

収量や作付率が 0 の場合、既存関数が返す 0 を「農地需要なし」と解釈しない。需要は残し、その作物では生産不能として別供給または不足へ振り分ける。非穀作プロファイルは食料構成を解決してから式に渡す。輸入データがない港町は輸入成立を捏造せず、推定した地元負担と未解決需要を区別する。

出力には `requiredAreaHa`、`allocatedAreaHa`、`unallocatedAreaHa` と不足理由を持つ。土地/水/食料不足でも無理に湿地や急斜面まで畑にしない。未知の降水量をゼロとして扱わず、モデル既定値を使った推定か、算出不能かを区別する。

### 6.3 市街地・牧草地・薪炭林

- 市街地は可能なら FMG/CE と共有できる実占有形状を優先する。面積だけなら人数と密度の単位付きモデルを使う。旧 `0.02 ha/人口ポイント` を `0.02 ha/人` と読み替えない。移行は人口変換設定を変えたテストを伴わせる。
- 牧草・採草地は家畜と飼料需要に従う。休耕地・刈跡・林間放牧・輪作飼料作ですでに満たす分を差し引く。情報不足ならプロファイル別推定とし、全都市共通の畑比率に固定しない。
- 薪炭・建材・工業木材の需要から、供給可能な管理林と伐採強度を評価する。単位を揃えた場合の目安は `localWoodDemandPerYear / sustainableYieldPerHaPerYear`。供給地は水運や権利にも依存し、必ず都市外周のリングになるわけではない。
- 萌芽更新できる樹種・気候では伐期別の区画を表現し、それ以外は択伐・再植林等のプロファイルを使う。管理林全体を毎年皆伐したり、恒久的な薄い樹冠としたりしない。係数は校正対象。

### 6.4 面積と stock の不変条件

- `1 ha = 10,000 m²`。FMG 座標・RE 描画単位・m・ha を入口で明示的に変換する。
- セルの `area` と境界ポリゴンから測った面積の一致も検査する。丸めや海岸クリップで差がある場合は補正方法を記録し、描画可能面積を超える予算を無理に配置しない。数値誤差の許容値は単位付きで定義し、実際の未配置面積を誤差に含めない。
- 相互排他的な主用途面積の合計は利用可能陸域面積以下。水域、重なった道路・市街地、共有農地を二重加算しない。残余は自然地として必ず分類する。
- 森林転換量は**新しい用途と現存森林の交差面積**から得る。既存の自然草地へ畑を配置しただけでは森林を減らさない。湿地・岩場など耕作不適な非森林地を「空いている農地」と数えない。
- 各利用パッチの stock 割当の合計をセルの正本に一致させ、転換時はその場所に存在する分だけ減らす。伐採だけなら森林用途は残り、再生はその用途・立地の容量内で行う。`0 ≤ forestStock ≤ forestCover` を維持する。
- 恒久開地への再侵入を防ぐため、再生可能容量を土地利用から計算する。現行の `capacity - 全耕地率` を機械的に拡張すると、元から非森林の畑まで森林容量から引くので不可。
- 初期の歴史的開墾で取り除いた木材を現在の市場在庫に付与しない。年次の転換・伐採で得られる材は一度だけ資源取引に渡す。

## 7. 空間配分: リングから連続した利用域へ

### 7.1 二段階の処理

**FMG が実面積予算と粗い立地・供給関係を決定し、RE がその予算内の詳細形状を生成する。** RE は面積需要・経済状態を再計算しない。隣接 Province の開き方によって結果が変わらないよう、粗い割当は表示範囲に依存させない。

1. 世界のセル/アクセスグラフ上で需要を生産候補へ割り当てる。集落を含むセルだけでなく農村と周辺セルを対象にし、セルごとの総量・安定した利用パッチ ID/アンカー・供給先を確定する。
2. RE は元セル ID と世界座標の seed で詳細化する。粗い配置と既存の道路・水域・都市形状を守り、ポリゴンをクリップして予算まで充填する。中心点/頂点だけで交差判定しない。穴・細い河川・海岸横断も除外する。
3. 自然の非森林適地、既存開地、アクセスの良い適地、追加伐採が必要な場所の順を基本にする。ただし保護地・権利・既存生業を優先する。
4. 距離は優先度の一要因。斜面、渡河、道路、湿地、輸送手段を加えた到達コストを使う。農民の日々の通作圏と、都市の遠距離食料調達圏を分ける。
5. 複数集落で同じ土地や水を予約しない。安定した ID と明示された配分規則で決定し、入力配列順による先着取りを避ける。Burg のない農村セルには人数を増やさない描画用アンカーを置ける。
6. 行政境界では利用域を切らず、表示範囲の最後でクリップする。国境でのアクセス制約は明示的に扱う。世界全体の粗い割当を参照するため、表示外の都市・村の需要も消えない。
7. 詳細化で置ききれない面積は `unplacedAreaHa` として記録する。半径拡大で水面等を侵食せず、細分化または粗い農地面の表示へフォールバックする。RE を開くだけで世界状態を修正しない。

都市の近くには菜園、集落間には畑のまとまり、難利用地や河畔には森を残すという傾向は使えるが、全方位に連続した五重リングを生成しない。方格・短冊・不整形・段々畑は文化と地形に応じた候補。方格を世界の X/Y 軸へ一律に揃えない。

FMG の粗い標高や RE の補間 heightfield から精密な耕作適性が判明したとはみなさない。利用可能な解像度で斜面コストを近似し、不明な土壌・入植年・撹乱履歴はプロファイル既定として記録する。データがないのに、個別の火災年や歴史的開墾事業を実在した出来事として生成しない。

### 7.2 道路・河川・城壁

道路は通行面、維持される路肩、下層植生管理、記号の余白を区別する。狭い林道は樹冠下を通り得る。広い治安伐開や防火帯は設定がある場合だけ付加し、線記号を見せる余白で農地面積を増やさない。

河川の水面は樹冠から除外するが、河畔林を一律に削らない。岸の空地は砂礫州・曳舟道・港・耕作・防衛等の根拠で作る。渡河は既存の到達性と橋を使い、農地を置くためだけに勝手に新しい橋を生やさない。**橋は河川の進行方向に直角かつ最短**とする原則を維持し、マスク処理で河道・橋形状を動かさない。

城壁前の空地は、城壁形状・防衛方式・時代・維持状態に応じて設ける。無城壁都市や廃墟へ一律の射界リングを付けない。遺跡やダンジョンの固定半径の裸地もやめ、現在活動しているか・再生中かで分ける。

## 8. 状態の所有権・初期化・年次更新

| 項目 | 経済拡張 OFF | 経済拡張 ON |
| --- | --- | --- |
| 需要・条件の供給 | 本体の静的プロファイルと実人口。欠測は推定フラグ付き | 既存農業・灌漑・食料供給・技術・家畜・木材需要の解決済みスナップショット |
| 面積・配置モデル | 共有純関数 | 同じ共有純関数。経済側が条件を渡す |
| 初期確定 | 本体の一つの土地利用書込み窓口が確定 | 同じ窓口で確定。経済 reconcile は初期化を再実行しない |
| 年次 | 静的。人口等の編集時は明示的な再計算 | 開墾・維持・放棄・再生を順に確定し、新しい revision を公開 |
| RE の動作 | 読取専用のスナップショットを詳細化 | 同左。開く回数で開墾や伐採が進まない |

初期化の順序は「バイオーム・人口・都市・経路 → stock の初期化 → 技術・生業・必要な経済条件の準備 → 共通土地利用計画の一度だけの確定 → 消費側・RE へ公開」。現行の拡張初期化内部で reconcile が呼ばれる経路も整理し、この順序を契約としてテストする。単に main.ts の直後へ一行足すだけでは完了としない。

書込み窓口は本体側に置き、経済拡張の `reconcileForestClearanceForAgriculture` は計画要求のアダプターへ移行する。OFF と ON の二つの writer で同じ差分を適用しない。既存の forest stock の simulation ownership を維持し、Frontier Expansion も同じ窓口へ開拓要求を渡す。`frontier-expansion.md` の用語と競合する場合でも、本設計では `forestCover` を入植によって変化させない。

年次更新では、前回の土地利用を保ちつつ人口・供給・水・労働の変化を反映する。放棄地は回復段階を持つ。市街地・現耕作地・維持中の交通/防衛施設を再生対象から除く。既定の年 2% の stock 回復を、全気候・全林齢の樹冠回復時間とみなさない。

megacity の `includeUrbanFoodDemand: false` は**都市直下の穀作需要の重複除外**として維持する。市街地・庭・交通まで消さない。食料は Food Ledger 等の供給地側で一度だけ計上する。OFF/ON は入力条件が同じなら一致を要求し、実際の輸入・技術・灌漑が異なる世界まで同面積を要求しない。

## 9. データ契約と RE 描画

### 9.1 記述子の追加仕様

次の名称は提案であり既存フィールドではない。詳細型の確定時にも単位・正本・欠測規則を維持する。

| 対象 | 主な情報 |
| --- | --- |
| descriptor 全体 | `landUseModelVersion`、`landUseRevision`、対象年/季節、世界座標の seed、既存の座標スケール、`authoritative / estimated / legacy` の由来 |
| cell | `sourceCellId`、`physicalLandAreaHa`、biome の安定キー/タグ、既存属性の `forestCover / forestStock / forestCondition / canopy / specialFeature`、農村実人数、用途別面積予算、必要な粗い配置アンカー |
| settlement | `cultureId / raceKey`、解決済み `landUseProfile`、実人数、市街地の ha/形状、供給割当参照。セルの全農地を各都市へコピーしない |
| 利用パッチ | 安定 ID、元セル ID、主用途、面積、幾何/アンカー、維持/休耕/放棄/再生段階、任意の管理林方式・樹冠表現属性 |
| 診断 | `unallocatedAreaHa / unplacedAreaHa`、不足理由、欠測・推定項目。未知と実際の 0 を区別 |

`cultivatedAreaHa` を既存経済値から渡す場合は、輪作休耕を含む値であることを契約に明記する。必要なら `annualSownAreaHa` を別の内訳として渡す。RE で再び休耕率を掛けて面積を拡張しない。草原等の非森林セルも同じ農地契約に含める。

`RegionSiteDescriptor` のバージョンと `RegionDocument`/RE 保存ファイルの移行を扱う。document に用途ポリゴンを保存し、SVG だけの一時マスクにしない。元 seed、revision、生成版を記録する。ユーザー編集した利用地は保持し、自動再生成で上書きする範囲を分ける。

### 9.2 旧マップと情報不足

旧 descriptor に土地利用がない場合は、ハンドシェイクで副作用のない共有推定を行い、推定スナップショットとして渡す。単独の旧 RE ファイルには同じ共有推定の互換アダプターを使う。これは移行時の一度だけであり、新形式の RE が常に需要を計算し直す仕組みにはしない。

stock のない旧森林を森林ゼロとは扱わない。逆に stock の減少分を全て畑に復元しない。人口等が足りない場合は自然植生と既知の市街地/経路だけを保証し、農地量の不明を残す。情報不足を「飢餓が発生した」「無人だから原生林だ」と断定しない。拡張の ON/OFF 切替・保存読込は既存状態を継承し、初期開墾を追加しない。

### 9.3 レイヤーと縮尺

地形の陰影・山岳、自然植生、土地利用、水域・交通、都市記号を分離する。丘陵/山岳にも樹冠を重ねられる構成にし、標高だけで植生を決める旧分類を更新する。

農地の**同じポリゴン**を地表描画と密生樹冠の除外に用いる。農地面積表示だけが増えて森が残る状態を防ぐ。果樹園・生垣・林間放牧は専用の疎な樹木表現を使い、自然林と同じ密なパターンを戻さない。

小縮尺では用途のまとまりと林縁だけ、中縮尺では畑・牧草・管理林の違い、大縮尺では区画模様を出す。実面積/マスクは m・ha に基づき、ズームしても変わらない。都市アイコン・ラベルの halo は可読性専用で、物理的な伐開には数えない。模様の画面密度は調整しても土地利用の境界を移動させない。

地域全体に細かな 250 m 方格を無制限に生成しない。セルの粗い候補を空間索引で絞り、表示縮尺に応じて詳細化を遅延する。細部の省略は集計面積を変えず、表示範囲や配列順によって乱数列がずれない方式にする。

## 10. 実装フェーズと受入条件

### フェーズ A: 契約・互換性

人口/面積/stock の単位を監査し、共通入力・需要政策・面積台帳を確定する。経済式を本体から直接 import せず、必要な純粋計算を共通モジュールへ抽出し、拡張側は互換ラッパーで接続する。既存の経済計算結果を変える箇所と、表示だけの変更を分けて検証する。技術アクセサと `landCover` は調査済みとする。

### フェーズ B: 初期土地利用と共有化

OFF/ON 共通の一度だけの初期計画、農村を含む粗い空間割当、面積保存を実装する。農業・stock・再生・牧畜・野生動物の読取を整合させる。推定と正本の違いを descriptor へ出す。初期版は静的スナップショットまでで成立させ、全生業の精密計算は必須にしない。

### フェーズ C: RE の可視化

descriptor と保存形式を移行し、自然林の疎密、利用ポリゴン、河畔林、山林、縮尺別描画を実装する。`farmland.ts` の独立した需要・水予算と固定円マスクを置換する。文化別形状・エルフ既定もここで適用する。

### フェーズ D: 年次・高度な利用

既存の経済年次更新へ接続し、放棄/再生、管理林の伐期、輸送・供給圏、入植段階、特殊生業を拡充する。B/C が完成する前から将来属性を確定済みの史実として描かない。

### 必須テスト

- 固定需要で収量が倍になれば必要面積は半分になる。技術の二重適用がなく、実現面積は別に制約される。
- 同じ確定人口では saturation を変えても再計算結果を変えない。農村のみのセルにも利用地ができ、都市需要を二重計上しない。
- 初期化直後の stock が計画値を保持する。同一 revision の再適用、RE 開閉、保存読込、OFF/ON 切替で再減算しない。
- 自然草地を耕作しても森林転換にならない。伐採だけでは畑にならない。管理林・林間放牧・休耕を含め面積の二重計上がない。
- 人口ポイント/実人数、距離設定、m/ha/描画単位が整合し、アイコンサイズ・ズームで物理面積が変わらない。
- 水面・湿地不適地・急斜面・市街地とのポリゴン交差を防ぐ。区画の一部だけがセル/海岸を横切る場合も検証する。
- 配列を並べ替えても同じ結果。隣接 Province の共有域、異なる表示範囲、再読込で同じ利用パッチが現れる。
- 河川流量と耕地予算を複数集落で二重使用しない。供給域が表示外でも都市直下へ農地が再生成されない。
- 通常市街地に密生樹冠が侵入しない。embedded は小空地と近接樹冠を両立し、需要は消えない。全 profile に「必ずリング 0〜2 が無樹木」を要求しない。
- 維持中の開地は再生せず、放棄後は段階的に回復する。河道と既存の直交・最短橋を土地利用処理が変更しない。

### 目視シナリオ

| シナリオ | 合格する景観 |
| --- | --- |
| 無人の湿潤温帯林 | まとまった樹冠と自然な抜け。都市の円形空地や方格畑がない |
| 小さな開拓村と成熟した農村域 | 前者は局所的開地、後者は複数の開地の連なりと残存林。均一なドーナツにならない |
| 大都市・輸入港 | 市街地と近郊用途が見え、食料供給は他セル/遠方にもある。海へ畑が張り出さない |
| 寒冷林・山地・冠水林 | 農地は限られ、山林/河畔林を残す。降水だけを根拠に全面開墾しない |
| 熱帯の焼畑・樹木農業 | 作付地・休閑林・樹木生産地が混在する |
| 林業/鉱山都市 | 伐採・作業区画と再生林があり、伐採量全てが穀作地にならない |
| エルフ都市、人間の林間利用、個別設定した暗黒エルフ都市 | 種族名だけで全て同じ円や植生にならず、居住形態と供給に一貫性がある |
| 廃村、州境を跨ぐ隣接村、3 段階のズーム | 遷移、境界の連続性、面積と形状の安定を確認できる |

実装時の対象チェックは RE だけで完了としない。例: `npx vitest run src/region-editor src/controllers/region-editor-handshake.test.ts src/generators/forestStock.test.ts src/generators/initialPopulationCohorts.test.ts src/extensions/economy/generators/agriculturalLandUse.test.ts src/extensions/economy/generators/forestStock.test.ts` に新設の共通モデル・保存移行テストを加える。架空のテストファイルを既存として扱わない。構造変更時は本体/経済拡張のビルドと所有権・依存境界のチェックも行う。

## 11. 決定事項と残る校正

**確定**: 同心リングを実形状にしない。自然林と人為利用を分ける。人口・需要の二重計上をしない。農地は共有式と供給域から決める。エルフの林内都市を既定として維持する。初期計画の writer は一つ。RE は新形式の経済需要を再計算しない。農地/樹冠マスク/面積表示は同一の利用データを使う。橋の直交・最短原則を保持する。

**実装前に校正する値**: 市街地の人口単位と密度、非農業生業の食料構成、燃料/工業木材需要と管理林収量、開墾労働・伐期・再生時間、通作/輸送コスト、自然植生パッチのスケール、縮尺別描画閾値。旧版の固定 1.02 ha/人、牧地比率、60 m 皆伐幅、開墾倍率を暫定値として無条件に復活させない。

**適用の境界**: 実際の歴史景観には地域差が大きい。本書の表はゲームの景観プロファイルであり、特定文化が常に同じ土地利用をしたという歴史的断定ではない。変更は本設計書のみで、上記機能・テストはまだ実装していない。
