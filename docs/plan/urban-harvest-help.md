# 町の人が刈り入れと干し草を手伝い、その月の町の仕事を減らす

## 1. 背景

[hay-labor-capacity-20261114.md](../analytics/hay-labor-capacity-20261114.md)で、冬を越す頭数の干し草に要る日数のうち、農村の空いている大人の手で賄えるのは約73%で、残りの不足（地図2102で17.7百万日、2103で8.6百万日）は、干し草の月が穀物の刈り入れと重なり、畑仕事で大人の手が埋まる土地に集まっていた。農村の手は食（畑・家畜）でほぼ使い切られ、食以外に手を取っているのは町の人だった。

- 町の人は、穀物の刈り入れにだけ、同じ市場圏の不足に大人の5%（中世）〜15%（近世の後）が出る（`applyRegionalHarvestHelp`）。
- 干し草の手伝い（`applyHaymakingMutualAid`）は、同じ国の隣の土地と同じ市場圏の農村の手の空いた大人だけで、町の人は出ない。
- 町の人が出ても、その月の町の工房の働き手は減らない。

## 2. 史料

- 1388年のケンブリッジ法（12 Ric. 2 c.3〜5）：刈り入れの時、職人と手工業者は穀物を刈り集めるために働かされる。刈り入れに要る職と、名の通った親方は除く。
- 1563年の職人規制法（5 Eliz. c.4）：治安判事と町の長は「干し草または穀物の刈り入れの時」、職人と手工業者に、日ごとの賃金で穀物・干し草を刈り、集める仕事をさせることができる。
- どちらも、町の職人が刈り入れと干し草の月に畑へ出ることを前提とし、出た職人の分だけ町の仕事は止まった。

## 3. 決める仕組み

1. 設定`urbanHarvestHelp`：`cornAndHay`（既定）か`legacy`（今の決まり）。
2. `cornAndHay`の時、市場ごとに、その月に町から出られる手を「町の大人 × 人口の率 × 都市化 × 出る割合（設定`urbanHarvestHelpShare`、既定0.5、0〜1） × 刈り入れの月の働ける日数（`WORKABLE_DAYS_PER_ADULT_PER_MONTH × PEAK_MONTH_WORK_MULTIPLIER`）」とする。時代による割合（5/10/15%）は使わない。
3. その手を、まず穀物の刈り入れの不足（`applyRegionalHarvestHelp`）に、残りを農村の手伝いの後に残る干し草の不足（`applyHaymakingMutualAid`）に回す。
4. 使った日数を、市場の中の町に大人の数の割合で分け、町と月ごとに持つ（`townHarvestHelperDays`）。
5. 町の工房（`produceForBurg`）は、その月の手伝いの日数を人口の点に直した分（日数 ÷ 刈り入れの月の働ける日数 ÷（人口の率 × 都市化））を、職人の働き手から引く。
6. `legacy`の時は、町の手伝いは時代の割合で穀物の刈り入れだけに出て、町の工房の働き手は減らさない。

## 4. 見込み（計測の前の計算）

[hay-labor-capacity-20261114.md](../analytics/hay-labor-capacity-20261114.md) §4.2の町の大人の日数（干し草の月に25日ずつ出た時、2102で23.0、2103で15.6百万日、同じ市場圏の不足の90%・98%を埋められる）から、出る割合0.5で、刈り入れの月の働ける日数を倍にした手で数え直した。

| | 2102 | 2103 |
| --- | ---: | ---: |
| 干し草の足りない日数（百万日） | 17.7 | 8.6 |
| 町の手で埋まる割合 | 74% | 94% |
| 町の手伝いに使う日数（百万日） | 13.05 | 8.05 |
| 町の大人の年の働ける日数に占める割合 | 約5% | 約4% |

- 3月の餌の不足は、2103でほぼ0、2102で約4分の1まで減る見込み。
- 町の工房は働き手の約18〜22%しか使っていないので（年の割合で4〜5%の働き手が減っても）、作る品の量の減りは小さい見込み。刈り入れの月に働き手が使う量を下回る町だけで減る。

## 5. 計測の計画

北緯30°の地図2枚（2102・2103）、36か月、戦争なし・隊商の略奪なし。`legacy`と`cornAndHay`を一度ずつ比べる。§4の見込みから外れたら、計測を重ねる前に理由を数えて記録する。

1. 3月の餌の不足（土地の数と量）、干し草の刈り取りの計画に対する割合。
2. 町の手伝いの日数、町の工房の作った品の量（職ごと）。
3. 持ち手ごとのお金（農村・市場・町の家計・町の金庫）。

## 6. 未確定事項

1. 町の手伝いへの賃金（1563年法は日ごとの賃金）。今は日数だけで、お金は動かさない。
2. 刈り入れに要る職（鍛冶・車大工など）と大きな親方の除外。今は職を選ばず、働き手から一律に引く。
3. 市場の中の町への分け方（大人の数の割合）と、市場の町から遠い土地への手伝い。

## 7. 結果

[urban-harvest-help-20261114.md](../analytics/urban-harvest-help-20261114.md)（12か月目で止めた）。町の手伝いは1年に12.66百万日出て、町の工房の作った品の減りは0.11%と見込みどおり小さかったが、干し草は0.9%しか増えなかった。刈る量の上限と職業の割り当てが見る干し草の不足が、どちらもその月にいる頭数の計画（`calculateHusbandryDemand`の`hayWorkers`）から出ており、冬を越す頭数の計画になっていなかったため。

干し草の人手の計画を冬を越す頭数にした後（同じ記録の§6）、人手の不足は計画の約5%で、町の手伝いがその約3分の1を埋めた。刈る量を最も多く止めているのは蓄えの目標で、3月の餌の不足の残りは人手ではなく干し草の計画の大きさか土地の間の偏りによる。

36か月（同じ記録の§7）で、3月の餌の不足は地図2103で6〜12%から1%未満に、足りない土地は約1割になった。2102は4月に約1%の不足が残る。持ち手のお金の差は1.2%以内。
