# 木の灰と炭酸カリウム

## 1. 背景

[cold-land-clay.md](cold-land-clay.md) §6の3で、寒い森の土地のガラスは炭酸カリウム（`Potash`）の少なさで止まると見た。調べると、次のことが分かった（[wood-ash-20261107.md](../analytics/wood-ash-20261107.md) §2.1）。

- ガラスを止めているのは、炭酸カリウムではない。
  - 寒い市場のガラスは、大部分が国の船の持ち帰る贅沢品（`navyImport`）だった。
  - 地元のガラスの量は、職人の贅沢品の需要の割り当てで決まる。
- 灰（`Ash`）と炭酸カリウムは、使う分だけ作られていた。値と物量は、史料から大きく外れていた。

| | モデル | 史料 |
| --- | --- | --- |
| 灰（50 kgの袋）の値 | 1.5（1 kgで穀物の15倍） | 1 kgで穀物の約0.09倍 |
| 炭酸カリウム（120 Lの樽、120 kg）の値 | 3（1 kgで穀物の10倍） | 1 kgで穀物の2〜7倍 |
| 炭酸カリウム1樽の灰 | 1.5袋（75 kg） | 約1.2 t（灰の約10%が炭酸カリウムになる） |
| 灰の出どころ | 木材を灰にする職人（1袋に木材1.2山） | 炉の灰、開墾の火、ほかの火の残り |

- 家計は、暖房と炊事で木材を燃やす（シード2103の0〜4℃の市場で、町と農村を合わせて年約8万山）。その灰は、どこにも戻らなかった。

## 2. 史料

### 2.1 灰から炭酸カリウム

- 普通の木の灰からは、重さで約10%の炭酸カリウムが取れる。灰を浸して、その液を鉄の鍋で煮詰めた（[Potash](https://en.wikipedia.org/wiki/Potash)）。
- ニューイングランドでは、炭酸カリウム1トンに広葉樹の灰450〜500ブッシェルを使った（[Plainfield Historical Society](https://plainfieldmahistory.org/potash/)）。
- 1795年のジェファソンの覚え書き（[Founders Online](https://founders.archives.gov/documents/Jefferson/01-28-02-0203)）:
  - 木材1コードから、灰が2ブッシェル取れる。
  - 灰1ブッシェルは9セントで売れる。
  - パールアッシュ（精製した炭酸カリウム）は、イングランドで1トン40ポンド。
- 1770年ごろのニューイングランドの相場では、炭酸カリウムは1トン30ポンド、パールアッシュは40ポンドだった（[Adverts 250 Project](https://adverts250project.org/tag/pearl-ash/)）。
- アメリカでは、1790〜1804年に炭酸カリウムが1トン200〜300ドルで売れた（[Suiter](https://suiter.com/patent-of-the-day-pot-ash-and-pearl-ashes/)）。
- 1800年の小麦は1ブッシェル1.33ドルだった（[those were the days](https://thosewerethedays.substack.com/p/grocery-and-other-retail-prices-in-6b5)、出典の弱い一般向けの記事）。

### 2.2 灰の出どころ

- リトアニアの森では、切った木を森のはずれの小屋で、灰・炭酸カリウム・タール・炭・板にした。15世紀のリトアニアの輸出の約15%が、タール・灰・ピッチだった（[Kaunas city register 1561–1564](https://www.researchgate.net/publication/373527458_Kaunas_city_register_of_1561-1564_as_a_source_of_information_about_the_management_and_sale_of_forest_commodities)）。
- 17世紀半ばのリガでは、灰とタールが主な輸出品だった（[The Daugava River in the Early Modern Period](https://www.researchgate.net/publication/367644176_The_Daugava_River_in_the_Early_Modern_Period_A_Border_an_Obstacle_and_a_Trade_Route)）。
- ロンドンは1480年代から、羊毛を洗う石鹸のために木の灰を輸入した（[A Potash Primer](https://daily.jstor.org/a-potash-primer/)）。
  - 「石鹸の灰」は木の灰のことで、炭酸カリウムの材料になった。灰汁を取った残りは、肥料にされた（[Dictionary of Traded Goods: Soap ashes](https://www.british-history.ac.uk/no-series/traded-goods-dictionary/1550-1820/soap-ashes-soy)）。
- ドイツの灰焼きは、森の枯れ木と、家々の炉の灰を集めた（[Ash burner](https://en.wikipedia.org/wiki/Ash_burner)）。

灰は、売れる木材を買って焼くものではなかった。灰の出どころは次の2つである。

- 市場に出ない森の木（開墾の火、森の灰焼き）。
- 炉の灰を集めたもの。

## 3. 決めた仕組み

### 3.1 値と物量

穀物は1荷（465 kg）1.2、1 kgで0.00258である。

1. 炭酸カリウム1樽（120 kg）の灰を、1.5袋から24袋（1.2 t、10%）にした（`POTASH_ASH_SACKS_PER_BARREL`、[woodRecipeContracts.ts](../../src/extensions/economy/generators/woodRecipeContracts.ts)）。
2. 灰1袋（50 kg）の値を、1.5から0.012にした（`ASH_SACK_VALUE`、1 kgで穀物の0.09倍）。
   - 根拠は、ジェファソンの灰1ブッシェル（約21 kg、袋のかさ0.6 kg/L）9セントと、小麦1ブッシェル（27 kg）1.33ドルである。
3. 炭酸カリウム1樽の値を、3から0.9にした（`POTASH_BARREL_VALUE`、1 kgで穀物の3倍）。
   - イングランドのパールアッシュ（1トン40ポンド、小麦1クォーター43〜78シリング）では約2.3〜3.1倍、炭酸カリウムはその約3/4。
   - アメリカの炭酸カリウム（1トン200〜300ドル、小麦1.33ドル）では4.5〜6.8倍。
   - 1樽の灰の費用（24袋 × 0.012 = 0.29）は、値の約1/3になる。ジェファソンの数字でも、灰は炭酸カリウムの値の1/5〜1/3である。残りは、浸す・煮詰める手間と、その燃料である。
4. 灰を木材から作るレシピをなくした。
   - 木材1.2山（市場で約0.3）で、0.012の灰1袋を作ることになり、成り立たないため。
   - 灰は、町の炉の灰（3.2）と、レンガ・蒸留酒・燻製・レールの燃料の副産物から来る。
5. 灰の建設の需要（`demandCoverage: { construction: 0.2 }`）をなくした。
   - 建設の予算の一部を値で割り当てるため、値を1/125にすると、町が年に数千袋の灰を買った（[wood-ash-20261107.md](../analytics/wood-ash-20261107.md) §2.2）。
   - 灰の使い道は、炭酸カリウムとチーズのレシピにした。

### 3.2 町の炉の灰

[hearthAsh.ts](../../src/extensions/economy/generators/hearthAsh.ts)。

1. 町の家計が暖房と炊事で燃やした木材の灰を、市場が家計から買う（流れの種類`hearthAsh`）。
   - 灰の量は、木材1山（6.5 t）に0.83袋（乾いた重さの1%を灰とし、その80%を集める。物量の契約の既存の値）。
   - 市場の値で、市場の金庫から、木材を燃やした量に応じて町の家計に払う。
2. 買うのは、市場の在庫を、灰の使う量（レシピと町の需要）の3か月分にするまでとする。
   - 灰を使う量は、毎月の移動平均で数える。
   - 使い道の無い炉の灰は、畑に撒かれたとして数えない。そのため、在庫に積み上がらない。
3. 灰を使う前の市場も、炭酸カリウム1樽分（24袋）までは買う。最初の煮詰めを始められるようにするため。
4. 農村の炉の灰は、家で灰汁と肥料に使ったとして、市場に出さない。

### 3.3 保存した地図

- 灰と炭酸カリウムの値は、`migrateWeightRepricing`で、元の既定の値（1.5、3）のままの時だけ替える。
- 灰の木材のレシピと建設の需要は、`migrateHearthAshGoods`で、既定のまま（元の`{Wood: 1}`か物量の契約の`{Wood: 1.2}`、建設0.2だけ）の時だけ消す。
- 炭酸カリウムのレシピは、既存の移行（`migrateSmeltingFuelAndAshGoods`）が毎回`POTASH_ASH_SACKS_PER_BARREL`にそろえる。

## 4. 計測

結果は[wood-ash-20261107.md](../analytics/wood-ash-20261107.md)（シード2102・2103、12か月）。

- どちらの計測でも、粘土とガラスの砂を寒い土地に加えた。
- 灰は、ほとんどが町の炉から来るようになった。炉から買った量は、0〜4℃の市場で年748〜1,033袋。
- 灰の在庫は、使う量の数か月分に収まった。
- 灰をレシピに使った量は、2102で116 → 4,638袋、2103で46 → 1,615袋。
- 炭酸カリウムは、2102で約45%、2103で約20%増えた。値段は約3から1.2〜1.8に下がった。
- 石鹸は約40%、ガラスは30〜50%増えた。寒い市場の地元のガラスは、少ないまま（§5の1）。
- チーズは変わらない。

## 5. 未確定事項

1. 地元のガラスの量は、職人の贅沢品の需要の割り当て（`craftDemandCalibration`の`Glass`、`categoryResidual`）で決まる。寒い森の土地のガラス小屋（§2、[cold-land-clay.md](cold-land-clay.md) §5.2）に合わせるかは、まだ調べていない。
2. 森の灰焼き（市場に出ない森の木を、森で灰と炭酸カリウムにする）と、開墾の火の灰は入れていない。リトアニアとリガの輸出の規模にするには、これが要る。
3. 炭酸カリウムを煮詰める燃料（木材）は、レシピに入れていない。
