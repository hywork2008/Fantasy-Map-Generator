# ロングボウの素材

イギリス産のロングボウ用イチイなら、最も妥当なのは既存の **`Temperate deciduous forest`** です。

イチイは針葉樹ですが、英国では温帯の広葉樹林・混交林に混じって生え、特に南部〜中部の**水はけのよい白亜質・石灰岩質土壌**に多く見られます。南北ダウンズやチルターン丘陵のイチイ林は代表例です。[Plantlife](https://www.plantlife.org.uk/plants-and-fungi/yew/) [Woodland Trust](https://www.woodlandtrust.org.uk/trees-woods-and-wildlife/habitats/caledonian-forest-and-native-conifer-woods/)

したがって計画上は、新しい「イチイ林バイオーム」を作るより、次のように扱うのがよいです。

```text
biome: Temperate deciduous forest
canopy: mixed
soil: calcareous
drainage: wellDrained
forestCover: ancient
resource: yew
```

`centralEuropeanGreatForest` でも希少なイチイ資源を産出させる余地はありますが、**イングランドの良質なロングボウ材の主要産地**としては `Temperate deciduous forest` を基本にするのが正確です。`Temperate coniferous forest` に置くのは、樹種として針葉樹であっても、生育景観としては適切ではありません。
