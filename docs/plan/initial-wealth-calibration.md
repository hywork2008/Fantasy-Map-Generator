# 開始時の富の逆算 (Initial Wealth Calibration) 調査

2026-10-17 調査。是正は未着手。

## 状態

- 目的: 国家・都市・人物などがゲーム開始時に持つべき富を、経済が落ち着いた後の統計から逆算する。高額商品の流通を調整する前提として、買い手に金銭的な余剰があるようにする([approach-commerce-quarters.md](approach-commerce-quarters.md) §10)。
- 結果: **現状の経済には落ち着く先(定常状態)がなく、逆算できない**。お金は家計・都市・市場から国庫へ一方向に流れ続け、家計は数年で尽き、市場の農民への未払いは際限なく増える(§3)。開始時の配分を増やしても枯渇が遅れるだけになる。
- 先に流れの循環を閉じ、その後で逆算する(§5)。
- 調査用に追加した API: `observe/wealth`(sim:server)と標本の `wealth` 詳細(`npm run sim -- --sample-detail wealth`)。実装は `scripts/lib/observeViews.mts` の `wealth()`。

## 1. 現在の開始時の配分

`src/extensions/economy/generators/economyStartMode.ts` の `balanced`(新規地図の既定):

| 保有者 | 開始時の配分(人口点あたり) |
| :--- | :--- |
| 都市の金庫 `burg.treasury` | 15 |
| 国庫 `state.treasury` | 1.5 |
| 家計(都市 `householdWealth`・農村 `ruralHouseholdWealth`) | 8 |

このほか、収穫までの食料と、国家・人物への一時金を配る(1 年目は過渡期で、経済の本番は 2 年目以降)。

### 3.3 読み取れること

1. **家計からお金が抜け続ける**: 農村の家計(人口の 97% 前後)は開始時の 8 から減り続け、1.5〜6 年で尽きる。都市の家計は 1 か月目で既に 0。
2. **国庫と一部の人物に溜まる**: seed 101・102 では国庫が毎年増え続け、支配者・中央官僚の富も増える。seed 103(市場 25)は国庫も伸びず、支配者の富も尽きる。
3. **都市・市場・商人はほぼ全員 0**: 2 か月目以降、都市の金庫と市場の現金は 0 付近に張り付き、商人の 9 割以上が無一文。
4. **農民への未払いが際限なく増える**: 市場は農民が売る穀物をすべて買い取る(`foodProduction.ts settleFarmgatePayment`)が、売り先は都市の小売だけで、その都市の家計は空。代金を払えない分が `ruralGrainPayable` に積み上がり、国庫の 30〜700 倍の速さで増える。現金の流れとしては「払われていない」ので、農民の家計にも入らない。

## 4. なぜ逆算できないか

逆算は「十分な時間の後に各保有者の残高が一定の範囲に落ち着く」ことが前提で、そのときの 1 人あたり残高を開始時に配れば、過渡期なしで本番の状態から始められる。現状は:

- 家計・都市・市場・商人の行き着く先は **0**。0 を配ると開始直後に経済が止まる。
- 国庫・未払いの行き着く先は **無限大**(年々増える)。
- 開始時の配分を増やすと、枯渇する時期が配分 ÷ 流出速度(家計で 1 人あたり年 1.3〜5)だけ遅れるだけで、行き着く先は変わらない。

高額商品も同じで、市場の在庫目標を一度満たした後に続く需要がないのは、買う側(家計・商人・都市)に残高がないことと整合する([approach-commerce-quarters.md](approach-commerce-quarters.md) §4.4)。

## 5. 是正の順序(案)

### 5.1 お金の出入りの計測(調査、シミュレーションを変えない)

残高だけでは「どこから来てどこへ行くか」が分からない。お金を動かす関数(金庫・家計・市場の debit/credit)に記録点を置き、保有者の種類ごと・理由ごとの月次の出入り(例: 家計 → 国庫: 人頭税、市場 → 農民: 農産物代金、国庫 → 消滅: 維持費)を `observe/moneyFlows` として出す。記録のみで、経済の値は変えない。

### 5.2 循環を閉じる(シミュレーションの変更、別設計)

5.1 の結果に基づいて決める。現時点で見えている候補:

| 候補 | 内容 |
| :--- | :--- |
| 国庫の支出を家計へ | 兵の給与・公共事業・役人の俸給が「消滅」ではなく、都市・農村の家計(賃金)や市場(購入)へ入るようにする |
| 市場の穀物の買い取り | 売れる見込みの分だけ買う、または未払いを一定期間で帳消し・農民の自家保有に戻す(現状は無限に積み上がる) |
| 都市の家計の収入 | 製造業の賃金以外(サービス・小売・運送の賃金)を家計に入れる |
| 商人の利益 | 交易・小売の利益を商人の人物や市場の資本に残す |

### 5.3 開始時の配分の逆算(本調査の本来の目的)

5.2 の後に同じ方法(§2)で 15 年回し、2 年目以降の 1 人あたり残高の分布(中央値と四分位)が一定の範囲に収まることを確認してから、

- 保有者の種類ごとの開始時の配分 = 定常期の 1 人あたり残高の中央値(人口・都市規模・役職で回帰)
- 人物の富 = 役職別の定常期の分布から抽出

とする。`economyStartMode.ts` の `balanced` を更新し、`provisioned` / `subsistence` はその倍率として定義し直す。

### 5.4 高額商品の流通の調整

5.3 で家計・商人に余剰が生まれた後に、[approach-commerce-quarters.md](approach-commerce-quarters.md) §10 の遠距離交易(継続的な需要、商人組織の到達範囲)を調整する。

## 6. 注意

- 調査は province 規模・2 国家の地図。国家数・市場数の多い全球規模の地図で同じ傾向かを 5.1 の段階で確認する。
- 国庫の構造的赤字の調査([treasury-structural-deficit-investigation.md](treasury-structural-deficit-investigation.md))は維持費率を是正済み。本調査で国庫は増加傾向で、家計の枯渇はそれとは別の問題。
- 都市金庫の均衡化([burg-treasury-equilibrium.md](burg-treasury-equilibrium.md))で配分を 5→15 に上げた経緯がある。本調査では都市金庫は 2 か月目で 0 付近になっており、配分の増額では解決しないことと整合する。
