# 蜜蝋を港から出す（wax-export）

## 1. 問題

教区の灯りを入れた後（[church-wax.md](church-wax.md)）、蜜蝋は採れた量の約8割が蝋燭に使われるようになったが、地図2102で年約1.05万採れ、約0.81万使われ、在庫が年約0.3万ずつ増える（[guild-spending-20261114.md](../analytics/guild-spending-20261114.md)のspend-2102、3年目）。在庫で重みを付けた値段は基の値の約1.7倍と高いままで、別の市場は年約600を外から入れている。蜜蝋は蝋燭を作らない市場に溜まっている。

## 2. 史料

- 中世の北ヨーロッパで、蜜蝋は遠くへ運ばれる大きな交易の品だった。ハンザの町は、ノヴゴロドとプロイセン・リヴォニアの森の蜜蝋を、リューベックからブルッヘ・ロンドンへ運んだ。イングランドの教会の蝋の多くは、この輸入の蝋だった。
- 蜜蝋は傷まず、何年も持つ。
- 新しい使い道（封蝋・蝋板・鋳物の型・薬）は、蝋燭に比べて量が小さかった。

## 3. 設計

- 設定`beeswaxExport`（`staple`が既定、`off`で今の決まり）。
- `staple`の時、蜜蝋を皮・獣脂と同じ港の積み出し（byproductExport.ts、[byproduct-export.md](byproduct-export.md)）に加える。港のある市場は、自分の使う分の`byproductExportReserveMonths`か月分を超えた蜜蝋を、毎月`byproductExportShare`まで出し、同じ値の外の品（地図で作れない品）と替える。出せる量は、替えに取る外の品の値の上限を皮・獣脂と分け合う。
- 蜜蝋は、使う分を超えて傷む決まり（[byproduct-disposal.md](byproduct-disposal.md)）から外す。
- 新しい使い道の品は置かない。

## 4. 未確定事項

- 港の無い市場に溜まる蜜蝋は、今は出口がない（皮と同じ課題）。
- 外の品の値の上限を皮・獣脂と分け合うので、蜜蝋を出すと皮・獣脂を出す量が減ることがある。
- 封蝋などの小さな使い道は入れていない。

## 5. 結果

[wax-export-20261114.md](../analytics/wax-export-20261114.md)（地図2102・2103、36か月）。

- 港から出た蜜蝋は年に数百（採れた量の約2〜4%）で、在庫はまだ年約2,500（2102）ずつ増える。
- 蜜蝋の多い市場ほど値段が高く（在庫で重み約1.7〜2.0倍、平均約1.2倍）、在庫が周りの市場へ流れない。次は、在庫の多い市場で蜜蝋の値段が下がらない理由を調べる。
- 革と獣脂を出す量、蝋燭、お金の持ち手の差は5%以内。
