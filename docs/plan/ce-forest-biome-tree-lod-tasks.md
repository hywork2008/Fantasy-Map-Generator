# CE森林LOD用・全バイオームのBV樹木モデル作製タスクリスト

作成日：2026-10-29

## 1. 目的と対象

CEの森林地帯でバイオームに応じた樹木を描くため、BV樹木の `low / medium / high / ultra` を揃え、BVで比較でき、CEが採用した版をLODに使用できる状態にする。モデル作製を中心に、樹種選択・CEへの接続・見た目と性能の確認までを完了条件に含める。

対象は標準カタログの全29バイオームと、既存BVの全20樹種。バイオーム間で同じ樹種を共有し、同じモデルを重複作製しない。海・氷雪・新しい溶岩面などは、自然の立木を配置しない判断も「対応」に含める。草・灌木・枯木の新規モデル、森林の土地被覆生成の全面改修、季節表現は別作業とし、必要が判明したものを記録する。

関連設計：

- [CEの森林と郊外](ce-forest-surroundings.md)
- [BVモデルの作者とCEの採用](bv-model-authorship-ce-adoption.md)

- シナノキ `garden_parkland` とイチイ `sacred_yew` は、4品質のfactoryとBVの版登録が既にある。作り直しを前提とせず、比較・接続・性能の再確認を行う。
- 残る18樹種には単一の `default` モデルがある。既存モデルを自動的に「ultra完成」とは数えない。形状・寸法・描画量を評価し、再利用できればultraへ登録し、必要な場合だけ改修する。
- 20樹種×4品質で80枠。作成時点で8枠に実装があり、残る72枠は評価・作製待ち。内訳は縮約3品質の54枠と、既存defaultを評価するultraの18枠。作者違いの比較版はこの枠数とは別に管理する。
- 樹種登録からLOD対応を判定する基盤は実装済み。ただし、樹種を追加しただけで全距離の見た目と性能が完成するわけではない。森林側には集合林冠と簡略立木もあり、混交林を増やす際は地点ごとの候補と予算方針を確認する。
- シナノキは距離選択＋`quality-first`、イチイは画面サイズ選択＋`bounded`。新樹種は方式と予算方針を明記し、シナノキの予算迂回を全樹種へ暗黙に広げない。

## 5. 1樹種を完了するための共通チェック

各T項目は以下を満たしてから「CE・BV受入」を完了にする。作業記録には樹種ID、品質ごとの版ID、採用版、目視比較の所見・計測値・再現手順を残す。

### 5.1 形状と4品質

- [ ] 既存default／採用版の寸法、三角形数、材質数、枝・根・葉の構成を記録する。BV説明の参考資料を確認し、追加の植物学的判断には参照元を付ける。
- [ ] ultra：既存の詳細モデルを評価し、樹種の特徴が確認できる基準モデルを確定する。
- [ ] high：ultraと主要な幹・枝の骨格、樹冠外形を共有し、葉や針葉束の描画量を減らす。
- [ ] medium：枝段と樹冠の隙間を残し、個別葉を枝葉の房・葉群へ縮約する。別樹種の汎用球・円錐へ置換しない。
- [ ] low：遠景でも樹種を区別できる輪郭・色・代表的な枝／根を残す。ヤシ、傘状樹冠、支柱根、細い柱状樹冠を同じ塊にしない。
- [ ] 全品質で向き・原点・地表基準・樹高・樹冠幅を揃える。BVの実寸とCEの候補寸法への正規化を分けて確認し、切替時の移動・浮遊・大きさの跳びを抑える。
- [ ] 斜め・側面・俯瞰・林内から比較する。色と陰影、裏面、重なり、枝葉の穴を確認する。

low 500三角形以下・medium 3,000以下を初期の制作目安とする。既存の段階モデルの検査を参考にした目安であり、全樹種の実装済み上限ではない。high・ultraの上限、材質・属性・メモリはF0で実測して決める。単なる同一モデルの別名登録や、品質を下げても描画量が減らない実装は完成扱いにしない。例外は樹形上の理由と実測を記録する。

### 5.2 登録とCEへの接続

- [ ] `TREE_DEFINITIONS[species].lod` に4品質のfactory、`selection`、`budget`、基準樹高を登録する。新樹種を追加する場合は樹種一覧とBV説明も更新する。
- [ ] `TREE_VARIANTS` に作者・品質・派生元・履歴を正しく登録する。既存作者のdefaultを流用しても、作業していない品質や作者へ誤って帰属させない。
- [ ] 競合版がある品質は `CE_ADOPTION` で1つを選び、日付と理由を記録する。単独版の暗黙採用と区別する。
- [ ] BVで全品質・作者別の版・CE採用表示を確認し、mediumが別樹種になる等の誤登録を防ぐ。
- [ ] CE森林で近景から遠景まで確認し、モデル品質と森林全体の `light / standard / high` を混同しない。集合林冠・簡略立木を使う範囲でも樹種の輪郭・色との整合を確認する。
- [ ] 新樹種は原則 `bounded` から校正する。距離方式を選ぶ場合の既存境界は40／120／400 m。既存シナノキの `quality-first` は維持し、新樹種で使用する場合は全域負荷を計測して根拠を記録する。
- [ ] 同じ樹種を公園・墓地等でも使う場合、バイオーム名への追加分岐なしに段階LODが反映されることを確認する。

### 5.3 品質保証と記録

- [ ] 不正座標・ゼロ寸法・破損した法線・透明材質等がないことと、CEのprototype化で必要な属性・色を保持できることを確認する。
- [ ] 同じseedで位置・回転・寸法を保ち、道路・水域・建物・穴へ樹冠がはみ出さないことを確認する。根が広い樹種も候補の許容範囲内へ収める。
- [ ] LOD切替で元の簡略木と二重描画されず、非採用時は元の行列が復元されることを確認する。
- [ ] 複数樹種、5樹種目への視点移動、採用版の切替、品質切替、ビュー開閉で欠落・資源の継続増加がないことを確認する。
- [ ] 関連テスト、BV／CEの目視比較の所見、品質別の三角形・draw calls・メモリ、再現手順を記録して台帳を更新する。
