## 1. 目的と判断基準

日常生活で必要になる食料・衣服・寝具・燃料・住居・道具・サービスについて、必要量、入手量、支払額、作る人の労働と所得をつなぐ。都市の工房だけでなく、農村の自給・家庭内加工・有償委託・市場購入を含める。

「最適化」は世界全体の生産額や労働稼働率の最大化を意味しない。各主体が所有する材料・設備・現金と、地域・季節・技術・制度の制約内で仕事と支出を選び、その結果として持続可能な生活水準を形成することを目標とする。休閑、農閑期、家事、病気、扶養、移動時間を失業や浪費と一括りにしない。

史実に近づける対象は、地域・時代ごとの生産性、季節性、実質賃金、家計支出、産業構成、都市と農村の交換である。全世界で同じ消費量・都市化率を強制しない。平常時の説明できない飢えや資金枯渇を除き、不作・戦争・地金不足・制度による困窮は原因と伝達経路を説明できる状態にする。

優先順位は、①数量と会計の整合、②生存の土台(食料と一次生産の規模)、③生活必需品と所得の接続、④供給と運転資金の持続性、⑤史料範囲による校正、⑥政策と表現への反映とする。消費を増やすための無償在庫・賃金・資金の追加を通常の解決策にしない。

### 1.1 労働と土地の配分原則

基本は「生存に必要な最低限の食料を先に確保し、残る労働と土地を優先度の高い必要へ順に回す」。ただし次の補正を加え、単純な一列の順番待ちにはしない。

1. **優先されるのは最低限の必要量**。最低限の食料・燃料・衣服・住居を満たした後の追加分は、食料の上積みと衣服・寝具等を限界的な必要度で比べる。寒冷地の燃料・衣服は、食料の上積みより優先度が高くなり得る。
2. **土地は質で用途が分かれる**。耕作に向かない高地・荒地・湿地、休閑地・刈跡・共有地の放牧は穀物と競合しない。食料優先は、耕作可能な土地を牧草地へ回すかどうかの判断に適用する。
3. **労働は月ごとに配分する**。農繁期の労働は食料が優先するが、農閑期の労働は紡績・織布・修繕・運搬へ回る。年間の余力をまとめて数えない。
4. **一次生産は複合生産として扱う**。羊・牛は肉・乳・チーズ・皮・堆肥・牽引を同時に生み、堆肥と畜力は穀物収量を支える。羊毛のためだけに飼う群れとして規模を決めない。
5. **交易・地代・制度は配分を変える**。地代・税の現金納付、領主直営地や修道院の大規模群れ、輸出向けの特化(中世イングランドの羊毛など)では、地域内の需要と自給の順序から外れた配分が起きる。この場合は代わりに食料を得る交易経路と、決定する主体を明示する。
6. **群れ・牧草地の規模は需要と飼料で決まる**。羊毛・肉・乳・皮の需要(輸出を含む)と冬の飼料・牧夫労働で支えられる頭数を上限とし、土地の適性と人口比例の定数だけで決めない。

### 1.2 材料が余った時の判断順

ある原料の在庫が増え続ける場合、使い道の追加より先に次を順に判定する。

1. 記録・丸め・在庫の場所(市場・倉庫・輸送中・家計)による見かけの余剰ではないか。
2. その原料の生産量・単位あたり収量が§4.0の基準範囲に入っているか。生産側の頭数・面積・労働・飼料が互いに整合しているか。
3. 範囲内であれば、需要側(必要量、予算、加工能力、流通)のどこで止まっているか。
4. それでも余る場合に限り、史料で裏づけのある用途を追加する。

2を省いて3・4へ進まない。羊毛の作業(goods T8の続き)はこの手順で扱い、「在庫を使い切る」ことを完了条件にしない。

したがって作業順は「食料の充足と一次生産の規模を史実の桁で確認する→食料を確保した家計が衣服・寝具をどう更新し、農村の支出が都市の加工所得へ戻るか」とする。原毛の用途追加や委託織布の再実装から始めない。

## 3. 循環の共通契約

### 3.1 現金と生産資本を分ける

現金Mには国庫・都市・市場・商会・ギルド・家計・個人・抽象集団・遺産と、実際に引き落として保管する決済資金を一度だけ含める。商品・土地・設備・船・車両・家畜・出資持分・債権を現金へ重ねて加算しない。予約額は引落し済み現金と区別し、二重に数えない。

```text
世界の期末現金 − 期首現金
  = 明示的発行 − 明示的廃棄 + 地図外からの純流入 + 説明されない差額
```

国内取引・地図内の国際取引・人物詳細化・相続・国境変更は世界合計を変えない。国家別集計では越境移転と集計上の帰属変更を分離する。難破・盗賊も現金が消えたのか別所有者へ移ったのかを定義し、すべての損失を自動的に通貨廃棄としない。

生産資本は、材料在庫・仕掛品・設備・建物・輸送資産とそれぞれの所有者・稼働状態・維持更新費を追う。利益、減価、在庫評価差と現金収支を混同しない。新たな大規模な企業システムを前提にせず、既存の都市会計等が何を代理しているかを先に明示する。

### 3.2 物量と所有権

```text
期末所有在庫 − 期首所有在庫
  = 生産・採取 + 購入・受領 − 販売・引渡し − 加工投入 − 最終使用 − 損耗・廃棄
```

市場、農家備蓄、家計材料、港待ち、移動中、委託中を境界として、移動は送出側と受入側を対応させる。世界集計では内部移動を相殺する。副産物、容器、家畜の出生・死亡・と畜も別の発生理由で説明する。

製造、直接搬入、市場販売、家計納品、最終使用を別々に記録する。布から衣服への加工は同じkgが残るだけの保存式ではなく、材料投入、製品、副産物、廃棄物のレシピで照合する。耐久財は購入・保有・使用・修繕・更新を分け、購入した衣服を毎月消滅させる前提を置かない。

### 3.3 労働と土地

大人・子ども等の人口から作業能力を導く際、人口点、実人数、人日、人月の境界を明示する。個人の詳細化は労働供給を増やさない。

農業・牧畜・採掘・通常工房・委託・造船・輸送・建設・公共事業・サービス・家事について、同じ地域と月の労働を二重使用しない。季節移動は送り出し側から差し引き、移動時間と移動先の受入条件を持つ。職の定員・求人・予測雇用・実作業・賃金支払をそれぞれ別指標とする。

土地は耕地・休閑地・牧草地・林間放牧・森林・果樹園を一度ずつ計上し、種別の飼養上限を同じ面積から重複して導かない。配分の順は§1.1に従う。

### 3.4 需要と支払い

必要量、購入希望、予算のある注文、納品、実使用、未充足を分ける。自給・委託・市場購入は同じ必要量を減らし、材料注文と完成品需要を重複させない。未払いは債務として残し、賃金や農産物代を支払済みの所得とみなさない。

家計支出→売手の現金→材料・賃金・輸送費・税・維持費→家計や所有者の所得という相手勘定を追う。出資は投資家から事業側への資金移管で、利益を発生させる処理ではない。

- [ ] 農繁期、家庭内加工、都市工房、委託、基幹産業、輸送、建設、家事の作業枠を月ごとに照合する。既存の年齢別労働と季節移動を再利用する。
- [ ] port残課題T40の手順上限を、材料・採算・需要制約と分離して測る。maxStepsの増加だけで需要のない生産を作らない。
- [ ] 未使用枠を、実際の求職者と、農閑期・技能不足・設備不足・家事・地域間移動不能に分ける。総労働余力を任意の職へ即時転用しない。
- [ ] サービス業・行政・輸送・公共事業などについて、雇用表示に対応する支払主体、実支払、現物給付、賦役を確認する。求人だけで移住者を受け入れ続けない。
- [ ] 実質所得を、支払済み賃金と自給現物、扶養人数、生活費で評価し、§4.0の農業従事割合・食費割合と比べる。名目賃金率の引上げだけで支払不能事業を増やさない。

完了条件: 同じ労働を通常生産と委託等で再使用せず、表示雇用のうち実所得を伴う部分を識別できる。農繁期に工芸・輸送が縮む影響を含め、都市・農村双方の生活費と受入人口を説明できる。
扱わないこと: 賃金率の一律引上げ、工房枠の拡大。

### E5: 需要に応じた生産と運転資金の回収を整える

前提: E1〜E4。

- [ ] 生産候補は支払能力のある残需要・既存在庫・入荷/委託予約・原材料と設備・技術・作業枠・資金で評価する。必需品、実注文、保存加工、通常販売の配分と上限を明示する。
- [ ] 全商品の「利益÷労働」順位への一括変更は、goods設計§23で不採用となった結果を引き継ぐ。対象品群で需要充足、回収期間、材料費込み採算を比較し、単位に依らない選択規則を小さく導入する。
- [ ] 材料代の支払から製造・売却・賃金支払・再仕入れまで、誰が運転資金を立て替えるかを追う。都市金庫・市場資本・家計・商会の代理関係を明示する。
- [ ] 短期在庫と売れ残りを在庫月数・年齢・受注残で分け、§1.2の順で判定する。極上品、Salt、Beeswax等はgoods T10〜T12とluxury §14.4へ接続し、副産物のために不要な主製品を増産しない。
- [ ] Rennetはgoods T13の適格未離乳個体の出荷・輸送・と畜への追跡を接続し、通常の供給とCheeseへの影響を確認する。全家畜への一律回収で埋めない。
- [ ] 設備・輸送資産の維持更新と修繕需要を回収可能な売上に含め、利益配分と再投資を区別する。採算不良の事業は減産・転職し、救済する場合は支払元を示す。

完了条件: 増産時の材料・作業・支払元と、販売後の資金回収先が対応する。必需品不足と売れ残りの同居が改善するか、残る制約を定量説明できる。生産量だけ増えて家計購入・更新が増えない変更を改善と判定しない。

### E6: 輸送・所有・委託決済の途切れを閉じる

前提: E2、E4・E5の対象取引。

- [ ] goods T1〜T6・T20に従い、陸の1頭/1台の重量・容積、群れの牧夫/飼料、川の方向差、船の燃料占有、季節、回航、容器再使用を費用と能力へ接続する。既存の船倉・休航実装と重ねない。
- [ ] 運賃積みの受取先、倉敷料の所有者、雇車損失補償、商会出資の持分に応じた利益・損失を精算する。運賃の受領全額を利益とせず、運送労働・飼料・資産更新へ回す。
- [ ] 買手の予約、前払い、配送、引渡し、受取代金、期限切れ・事故・取消で、商品と現金と予約労働の解除を一度だけ行う。受取不能を無償補填しない。
- [ ] 同月・同市場の委託は現行範囲を維持する。E0〜E5で時間・地域をまたぐ必要が実証された場合に限り、家計所有材料・仕掛品・納期・前払/後払・取消返金の別設計を作る。
- [ ] 薄い出港の混載・多寄港は、陸の物理上限と既存予約修正後に実損失を測って採否を決める。輸送件数の増加を目的にしない。

完了条件: 買手から売手への決済と輸送費の受取が一致し、配送待ち資金をいつ回収できるか観測できる。輸送資産の損失が所有者または契約上の負担者へ反映され、同じ船・車両・材料を重複予約しない。

### E7: 史料範囲で校正し、初期状態を組み直す

前提: E1〜E6の対象循環が成立していること。§4.0の基準は既にE0で確定しているため、ここでは基準の追加と全体の再確認、初期状態の再推定を行う。

- [ ] 史料の時代・地域・階層・製法・単位・対象年齢・観測年を記録し、直接値、換算値、類推、ゲーム仮定を区別する。数値採用時には原典・研究機関等の資料を再確認する。
- [ ] 基準プロファイルは前近代の一地域・一時期から広げる。中世欧州と大航海時代の計測を混ぜず、異なる文化・近代技術は別プロファイルとして後から比較する。
- [ ] 物量・レシピ→必要労働→実質賃金/家計→価格と収益→物流/資金回収→初期配分の順で校正する。通貨単位の変更と歴史価格の変更を同時に行わない。
- [ ] 個人・抽象家計・遺産・未帰属現金の重複、国境変更、新都市・経済再有効化、国内施設/研究支出の受取先を再確認する。過去の相続問題は現行口座実装で解消した部分を除く。
- [ ] 修正後の季節循環と現金保有月数から開始時の家計・事業・公会計・個人口座の配分を見積もる。総初期通貨と配分変更を別々に記録し、master互換プロファイルを黙って置き換えない。
- [ ] 造幣と国外収支による変化を、国内循環不良と分ける。信用拡張や紙幣を必需品不足の即効策にせず、必要ならmoney-supply計画の後続設計へ送る。

完了条件: 採用係数の根拠と不確実性が追跡でき、校正に使わなかった世界でも主要傾向を確認する。定常値を持たない世界では、初期金を単一平衡値から逆算したと主張せず、季節・成長・災害の範囲として示す。

### E8: 政策・日常生活・地図へ結果を伝える

前提: E7の基準成立。

- [ ] 政策は税、公共支出、備蓄、交易/移動制限、出資等の主体が変更できるものに絞る。レシピの物量や単位整合を難易度調整に使わない。
- [ ] 家計に「買えない理由」、事業に「作れない/売れない理由」、国家に税・賃金・救済・造幣の流れを表示する。現在の不足と将来の需要見込みを区別する。
- [ ] RE/CEの農地・牧草地・市場・商人区・工房・倉庫へ、実面積、実作業、取扱量、荷待ちを渡す。推定・実測を区別し、表示生成が経済を変更しないようにする。

完了条件: 政策の変更がどの主体の資金・作業・消費へ伝わったか説明できる。人物の表示人数やCEの建物数が通貨・労働・生産量を発生させない。

## 5. 計測と受入判定

### 5.1 必須指標

| 軸 | 記録する値 | 誤判定を避ける比較 |
| --- | --- | --- |
| 生存 | 1人あたり食料供給・消費、端境期の不足、耕地/牧草地面積、種別頭数、飼料充足、牧夫充足、採毛・乳・肉・皮の産出 | §4.0の基準範囲、潜在産出と実産出、市場在庫と全人口の必要量 |
| 生活 | 必要量・保有・更新・自給・購入・委託納品・未充足、燃料の季節不足 | 衣服だけでなく寝具等の悪化、都市/農村・所得層の差 |
| 生産 | 実製造、直接搬入、材料投入、副産物、損耗、在庫月数、受注残、採否理由 | 売れ残り減が需要増か廃棄増か、取引が内部振替か最終使用か |
| 労働 | 月別の供給、予定、実作業、移動、未使用理由、支払済み賃金、未払賃金 | 通常工房・委託・農繁期・輸送の同時使用、求人と所得の差 |
| 資本 | 主体別現金、拘束資金、債務、材料/仕掛品/設備、売上、維持更新、出資損益、回収日数 | 現金と評価額、投資元本と利益、貯蓄と資金消失 |
| 物流 | 発注・照合・予約・出発・到着・納品、重量/容積利用、待機日数、費用内訳 | 船不足と季節休航、取引件数と配送物量/金額 |
| マクロ | 発行/廃棄/域外収支、物価、実質所得、人口/扶養、国庫等の保有比率 | 国家間の移管と世界合計、人口増と一人当たり額 |

### 5.2 実験の進め方

1. 既存の観測基盤を使い、同じ保存入力・日時・設定・乱数から変更前後を比較する。最初は12か月を月次観測し、短期の流れと季節の差を確認する。
2. 一つの原因を変更した比較を基本とし、単位だけ、配分だけ、レシピだけ、選択規則だけを分離する。丸め許容は会計精度と演算回数から先に決め、結果に合わせて広げない。
3. 対象循環に複数年の在庫・更新寿命・群れの移行が関係する場合だけ、期間を36か月または更新周期まで延ばす。初期過渡と準備期間を明記する。12か月から長期均衡を主張しない。
4. 基準世界で原因が解消した後、未使用の独立世界を一つ選ぶ。中世北半球の冬季・内陸・港湾等は変更の影響に応じて選び、一度に多数シードを回さない。
5. 通貨や更新需要の長期持続性を判定する最終段階では、必要期間と測定対象を説明して別の実験として実施する。従来の50〜100年観測を通常変更ごとに繰り返さない。

初期残高・需要・材料の追加で症状を隠していないこと、説明されない現金/物量差と労働超過を生んでいないことを共通受入条件とする。生活充足・実質賃金・一次生産の目標範囲はE0で§4.0として確定し、後段で変える場合は理由を本書に記録する。史料未確定の値に見せかけの精度や一律許容率を置かない。

過去のmoney-supply計画の「一人当たり現金±30%」等は、その期間・設定の校正目安として参照する。同書§11.12の上方逸脱を含む記録を保持し、今回の全時代共通の史実条件にはしない。

## 7. 最初に着手する作業と保留事項

**最優先はSalt**(2026-10-23、[goods残課題T11](goods-physical-units-remaining-tasks.md))。塩は生存に必須で、必要量が人口から直接決まる一方、S2で労働・燃料・季節へ、S3で現金決済へ接続した。T11のS0(量の基準)はE0の一部として完了した。S1(需要)・S2(生産)・S3(代金)をE1〜E2の最初の対象品として実装した。S4で持ち主ごとの売上・費用の帰属を分けた。S5の専売・塩税も既存議会・徴税請負に接続した。次はE0の残りへ戻る。S5の国の専売・塩税はE8の政策の最初の事例とする。ただしS5はS3で代金が流れるまで着手しない。

Salt以外にはE0の「§4.0の基準の確定」と「食料・一次生産・衣服/寝具を同じ12か月で測る基準観測」が残る。Saltの優先工程を妨げない範囲で進め、次にE1で、食料の充足と牧草地・群れ・採毛の規模を基準範囲へ合わせ、羊毛の余剰が生産側の過大によるものかを判定する。その後、対象品のE2を閉じ、E3の衣服/寝具配分とE4の実支払・作業枠を確認し、E5で材料取得失敗・採算・手順上限のうち支配的な原因から直す。

その後、E6で売却代金と運送所得・拘束資本を接続し、E7で歴史的な範囲と独立世界を評価してから初期富を再推定する。この順序により、消費不足の原因を初期金不足と決めつけず、労働余力を生産能力と取り違えず、余った原料を消費するために需要を作り続けることを避ける。

羊毛の作業(goods T8の続き・羊毛計画の未チェック項目)は、E1の完了条件を満たした時点で供給側を閉じる。需要側の残り(衣服と寝具の配分等)はE3へ移し、フェルト・調度・軍需・帆・羊毛脂の追加は§1.2の判定で必要とされた場合に限る。

全商品の同時再校正、全世界の同時代化、複雑な信用/銀行制度、多月の委託制度、一般的な企業会計の全面刷新、CE/BVの大規模描画改修は初動の前提にしない。必要性が観測で確認できた項目は、理由・対象・既存台帳との責務を示して別設計へ分け、その都度CHANGELOGへ登録する。

### 7.1 Salt S0の初回監査（2026-10-23）

[用途別基準・入力・比較表・残課題](../analytics/salt-s0-baseline-20261023.md)を追加した。province-101（590年）とworld-102（1929年）を各1月から12か月観測し、入力・ソースハッシュ付きの終了JSONを保存した。両者の保存年が異なるため、S0の「同じ年月」の比較は未達として残す。保存年の書換えや完了条件の緩和は行っていない。

現行の料理用3.6 kg/人/年は文化省の概括範囲内だが、対象人口あたりの実納品は3.217 / 3.399 kg。さらに開始時全人口の24.39% / 22.29%が塩台帳の対象外で、不足にも計上されない。実加工投入は0.001167 / 0.004098 kg/対象人/年で、固定枠2.4 kgを実消費とは扱えない。産出は4.524 / 4.431 kg/対象人/年であり、絶対量の大きさだけで過剰生産と判定しない。

既存の品別観測ビューへ塩の台帳・塩業所・輸送記録を複写する読取専用項目を追加し、30日決済の0回/2回を取り逃さず記録する監査スクリプトを追加した。経済の係数・レシピ・口座には変更を加えていない。市場＋塩専用輸送の境界に残る物量残差も記録し、未確認値・未説明差額を補正で閉じていない。初回時点ではS0全体とE0全体を未完了とした。S0の残りは次節で閉じた。

### 7.2 Salt S0完了とS1への引継ぎ（2026-10-23、同日追補）

Worldも36か月走行し、前工程の変更前ランタイム4ファイルとのSHA一致を確認して比較した。実供給は農村3,141,091.420→3,139,209.730、都市675,260.070→673,085.370台帳単位となり、ここでも改善は観測されなかった。全量出力4件のSHAと地域別・全期間の派生比較を保存し、不足の主因解決やE1完了とは扱わない。

### 7.41 家畜を人口と耕地から規模決定し、越冬飼料と整合させる（E1-2〜E1-6、2026-10-24）

利用者の指摘（越冬飼料の不足を追い続け、頭数そのものが人口・作付に対して適正かを見ていなかった）を受け、先に全体の桁を確認した。固定Province101（農村43.4万人、耕地94.6万ha）の開始時の牛は234頭、馬153頭、羊1,403頭、World102（農村358万人、耕地1,281万ha）でも牛3.2万頭・馬2.8万頭で、耕地100haあたりの役畜は0.03〜0.5頭だった。中世イングランドの再構成（播種地4〜6haに役畜1頭、1人あたり牛0.3〜0.4頭）より2〜3桁少ない。原因は、放牧種の頭数をバイオームの産出率でしか按分しておらず、「Temperate rainforest」等`arable`タグのない森林バイオームでは牛・羊の容量が0になっていたこと。Provinceでは40.8万haの牧草地に家畜がほぼいない状態だった。越冬飼料の不足はこの過小な群れの上で測られていた。

**実装**（[記録](../analytics/e1-herd-scale-20261024.md)）:

- **E1-2/E1-3 需要からの頭数目標**（`livestockHerdTargetPolicy.ts`、`husbandry.getLivestockHerdTargets`）: 役畜＝維持耕地×0.08頭/ha（休閑込み）、馬の比率は時代別（盛期中世0.25）、牛は役牛1頭に雌牛・育成牛1頭、羊は農村1人あたり1頭、適地では羊の3割を山羊に、草原・ステップでは牧畜民の上乗せ（牛0.5・羊2・馬0.2/人）、ラクダは適地のみ0.1/人。牛・羊・馬は人が住む所なら飼い、山羊・ラクダ・牧畜上乗せのみバイオームに依存する。乳・チーズ等の製品別逆算は§7.36の未校正需要を全世界の頭数に掛けることになるため目標に使わない。
- **牧草地の決め方**: 計画面積＝Σ目標頭数×1頭あたり必要面積（年飼料乾物÷その地点の牧草成長×利用率0.8）−放牧休閑の牧草換算面積（休閑＝耕地の33%、乾物400kg/ha）。生態上限・初期の労働上限・既存の年25%移行と牧夫充足はそのまま。種別の土地按分はバイオーム重みをやめ、目標頭数の飼料必要量で按分し、収容力は目標を超えない（草が余っても家畜を増やす理由にしない）。
- **飼料の整合**: 飼料台帳・干草計画・冬前屠畜の牧草量は、牧草地＋放牧休閑の同じ面積を使う。旧密度（成長量＝必要量でちょうど飽和し干草の余地がない）をやめ、利用率で夏の刈り取り余地を持たせた。
- **E1-3 産出の接続**: 放牧種の市場出荷を「人口×バイオーム率」から群れの年増加と収容力超過分の1/12へ置換。管理群は収容力がある限り満率で繁殖し、余剰を売る（旧ロジスティック繁殖では収容力到達で出生0＝肉0だった）。馬・ラクダの実需要に農用役畜・牧畜用を加えた。
- **E1-4 採毛**: 成羊の脂付き羊毛を時代別に（盛期中世0.7kg、Stephenson 1988のc.1300年1.3〜1.7lb、近世0.85〜0.9、改良種期1.3〜2.5kg）。仔羊はその0.4倍。旧1.44kgは約2倍過大だった。Wool 1 lot=1.5tは不変。
- **E1-5 移行と収束**: 収容力を超える成畜の年次調整率を0.1→0.55（3回の秋で当初超過の9%未満）とし、当年仔は売却用に残す。旧バイオーム按分で過小に作られた既存群れは、新規発見の群れと同じ初期水準（収容力の60%）まで一度だけ引き上げる（economy sliceの`livestockHerdScaleBaseline`、保存後は再実行しない）。収束判定は「36か月で頭数が収容力の±10%以内、収容力超過頭数が10%未満」とする。
- **E1-6 主食**: 排水前の湿地を耕作0としていたため、Provinceの農村人口の61%（26.4万人）が耕地0のセルに住み、耕作可能地のあるセルの住民だけで畑を耕していた。排水前でも島・自然堤防・フェン縁辺を耕したことから、排水前の湿地は排水後上限の30%を耕作可能とした（`UNDRAINED_WETLAND_ARABLE_SHARE`）。

**36か月の固定比較**（Standard・遠距離交易on・隊商襲撃off、変更前＝HEAD 10517e9）: Provinceの36か月後の牛は214→43,010頭、羊1,312→333,773頭、飼料未充足0.4%。Worldは牛2.4万→51万頭、羊13.7万→228万頭、直近12か月の飼料未充足は24%→29%（頭数約14倍の上で、寒冷地の冬季不足が残る）。収容力超過は全種10%未満。主食の農村供給（3年目）はProvince 54.9%→56.6%、World 93.6%→93.8%。詳細は記録md。

関連テスト（husbandry・faunaPopulation・livestockFeed・woolProduction・developmentPotential等、economy generators 254ファイル）を実行し、本変更前から失敗している2件（constructionEmployment Brickレシピ、foodClimateCalibration指紋）以外は成功。型チェック・Biome・シミュレーション境界チェック成功。

**未解決として残すこと**:

1. **主食不足の支配原因は単収**。Provinceの平均単収は95kg/播種ha（基準450kg）、WorldでもCentral European great forest 74、Temperate rainforest 112kg/haで、降水が作物のECOCROP上限（大麦・ライ麦2,000mm等）を超えるセルが多い。耕地が1人2〜3haに膨らみ労働を飽和させ、牧夫の人手も奪っている。湿地修正でProvinceの農村供給は2・3年目に62.1%/56.6%（変更前61.0%/54.9%）と小幅改善に留まる。修正先は[staple-crop-climate](staple-crop-climate.md)の多雨側の作物適性と降水換算であり、オフライン校正表（`foodClimateCalibration.json`、既存の指紋テストは本変更前から不一致）を伴うため本工程では変更していない。**次はこれを最優先とする。**
2. 牧夫不足: 畑で労働が埋まるため、Provinceの収容力は目標の約4割（牛4.5万/11.9万）。役牛の世話を耕作者自身の作業として扱うか、1の単収修正で耕地が縮んだ後に再評価する。
3. 係数（役畜/ha、羊/人、牧畜上乗せ）は史料の桁に収めたモデル方針で、ページ単位の照合は未了。豚・鶏は対象外。

### 7.42 単収低下の原因・家畜係数の史料照合・豚/鶏（調査、2026-10-24）

[調査記録](../analytics/e1-yield-and-livestock-sources-20261024.md)。コード変更なし。

- モデルの基準単収450kg/播種haは、イングランド1300の純単収約432kg（Broadberry et al. Table 2）と一致する。実際の単収が63〜126kgに落ちる原因は2つ。
  - 耕地の降水中央値が1,500〜3,700mmで、主穀のECOCROP上限を超え、超過時の残存適性が0.1〜0.2になる。
  - 森林を一律`humus`土壌とし、小麦・ライ麦・大麦に×0.55が掛かる。
  - 降水換算を一律に変えると乾燥地の単収が下がるため、多雨側の応答と開墾した森林の土壌分類を直す。
- 結果として耕地は2〜3ha/人（史実約1ha）に膨らみ、農作業の人手が飽和して牧夫も不足している。
- 家畜の史料値（Allen 2005 Table 2、Broadberry Table 4）: 役畜0.29/耕地ha、馬40%、非役用の牛は役牛1頭あたり約2頭、羊は国内需要分で約1.3頭/人（輸出込み3.4〜4.8）、豚約0.2頭/人、羊毛0.64〜0.67kg（0.7は妥当）。
  - §7.41の0.08/haと馬25%は単収修正と同時に改める。
- 豚・鶏の容量は人口点（実人口の1/1,000）で計算されており、豚は史実の約1/300。

**次は作物気候の修正（土壌分類・多雨応答・オフライン校正表の再生成）を行い、続けて家畜係数を史料値へ改めて36か月比較する。**

### 7.43 作物気候の修正・家畜係数の史料化・豚/鶏（2026-10-24）

[検証記録](../analytics/e1-yield-herd-20261024.md)。§7.42の調査に基づき、次のことを行った。

- 開墾した温帯林の土壌を穀作向きのloamにした。
- 多雨側の作物適性を、ECOCROP上限で0.6、超過分は平方根で逓減するようにした（[staple-crop-climate](staple-crop-climate.md)のv1規則を置換）。
- オフライン校正表を再生成した。
- 家畜係数を史料値にした: 役畜0.29/耕地ha（上限0.36/人）、馬40%、非役用の牛は役牛1頭あたり2頭、羊1.3/人、豚0.2/人。鶏1/人は出典のない仮置き。
- 豚・鶏を実人口から計算するよう直した。

- 平均単収: 96→253kg、158→287kg

関連テスト（stapleCrops・husbandry・faunaPopulation・livestockFeed・foodClimateCalibration等）、型チェック、Biome、境界チェックは成功した。economy/data/generatorsの範囲で残る失敗は、変更前から失敗している既存分だけ（constructionEmploymentのBrickレシピ、city-editor 8ファイル、lichRealms）。

**次は、Provinceの3年目の主食低下（初期備蓄の取り崩し後の収穫不足）と、牧夫不足で牛の収容力が目標の約4割に留まる原因を、月別の畑作業と牧畜作業の配分から調べる。** 単収はなお基準の55〜65%で、気温係数の史料照合も残る。
