# CEの高さモードと都市・セル別の高さ制限

作成・実装: 2026-10-26
関連: [高さ分布とコア面積](ce-building-height-variation.md)

## 1. 操作と既定

単独CEの新規生成は既存の高さ分布ポリシーを既定とする。Documentパネルの「建物の高さモード」で以下を切り替える。

- 高さにばらつき（既定）: 現行の地域・用途別分布と階高の微差。分布が対応している欧州の中世〜大航海時代に適用する。
- 一定の階数（従来）: 変更前の人口・時代に基づく共通階数と固定階高。城外や用途別の従来の差は残す。

モードの切替は生成済みの都市にも適用し、人口容量を再計算する。街路・敷地は変えない。コア面積の拡張は都市の再生成で行う。旧保存の未指定モードは従来のまま読み込む。

都市全体の上限はDocumentパネル、セル別の上限はセル選択時のInspectorで設定する。各欄は以下の2種類。

| 欄 | 単位・扱い |
| --- | --- |
| 最大階数 | 地上階を含む整数。空欄は指定なし。0は一般建物の建築禁止 |
| 屋根を含む最高高さ | m。建物の基準地盤面から屋根頂部まで。空欄は指定なし。0は建築禁止 |

都市とセルの指定が重なる場合、各項目の小さい値を使う。セルの欄を空にするとセル固有の指定を解除し、都市全体の上限に従う。階数上限とm上限の両方があれば両方を満たす。

対象は一般住宅、店舗住宅、工房、通常の倉庫・物置・厩舎などの通常敷地の建物。ユーザー確認により、城・教会・塔などの固有施設・ランドマークや城壁・橋は別扱いとした。固有施設の3Dモデルを高さ方向に押し潰す処理は加えない。専用の施設生成経路への高さ制限は別の拡張とする。

## 2. 保存契約

`buildingHeightPolicy` の有無で高さ分布と従来方式を区別する。既定は `defaultGenerationSettings()` が設定し、旧保存をロードしたときは自動補完しない。

任意の `BuildingHeightLimit` を追加した。

```ts
interface BuildingHeightLimit {
  maxStoreys?: number;
  maxHeightMeters?: number;
}
```

都市の指定は `CityDocument.buildingHeightLimit`、セルの指定は `FaceProperties.buildingHeightLimit`。都市の指定は生成設定・worker・共有レシピへ渡す。セルの指定は入力meshへ保存する。JSONと共有の入力で型・範囲を検証し、都市の指定とレシピの矛盾を拒否する。

階数は0〜200の整数、高さは0〜2,000 mの有限数を受け付ける。これは入力検証の範囲であり、生成する時代の階数上限や建築技術を引き上げる値ではない。上限の有効値は時代の上限と合わせて判断する。現代の法律の標準値を組み込んだものではなく、地図ごとに指定する規制の基盤である。

制限はUndo/Redo・保存・読込・再生成に保持する。セル分割は元の指定を継承し、セル結合は両セルの厳しい指定を継承する。完成セルから粗い生成入力へ戻す必要がある場合はセル中心を含む元セルへ投影し、重なる指定は厳しい方を使う。元セルが広い場合には制限範囲が保守的に広がるため、再生成後にセル境界を確認できる形とする。

セル別指定を持つmeshは、人口生成による自動再メッシュで置き換えない。既存の窓内でのコア拡張は可能だが、窓外への無制限な拡張は行わない。「新しいグリッド」を作る明示操作はセル編集を作り直し、都市全体の設定は継承する。

## 3. 階数・描画・人口容量

`buildingHeightLimits.ts` に上限の合成・検証・合法階数・入力への継承を集約した。`buildingFloors.ts` は用途別の階高と分布モードの階高差を共有し、容量側と描画側が同じ階高でm上限を判定する。

1. 初期階数を都市・セルの上限で制限する。
2. 人口調整の増階候補にも同じ上限を渡す。
3. 床の合計高と少なくとも0.15 mの屋根余地が収まる階数を選ぶ。
4. 屋根の立上がりは残る高さ以内にする。階高を縮めて階数を水増ししない。
5. 1階も収まらなければ一般建物を描かず、その敷地の住宅容量を0とする。

集約表示は確定階数に合わせてテンプレートと容量を更新する。階数・屋根・窓・木骨の高さは同じmassingから導く。高さ制限のために敷地を細分割したり、建物を細長くしたりしない。

固定セルの建物も、明示された上限より高く描かない。セルのロックはセル自体の編集を止めるため、Inspectorの上限欄は編集不可とするが、都市全体の上限は通常建物に有効とする。

上限で人口が収まらない場合は、既存のコア拡張規則を使う。拡張できなければ未配置人口を報告し、上限を破って増階しない。一定階数モードでも制限を有効にし、小区画化や充填率の増加で帳尻を合わせない。

人口計画の `heightPolicyVersion: 1` は分布の期待容量、`2` は一定階数＋高さ制限の面積校正を表す。未指定は従来式のまま。保存済みの都市の切替では固定フレームを保持するため、従来の面積見積もりを残す場合があり、計画の版と表示モードは必ずしも一致しない。既存の人口profile ID・versionは変更しない。
