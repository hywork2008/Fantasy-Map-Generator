# カスティーリャ石鹸（白い固い石鹸の財）

## 1. 背景

[barilla-soap.md](barilla-soap.md) §3.4と§5の3・6の続き。

- バリラは、取れた市場とその近くのガラスと石鹸にしか使われず、遠くへ運ばれなかった（[barilla-soap-20261108.md](../analytics/barilla-soap-20261108.md) §3）。
  - 取引の蓄えは、品の需要の割合から作る。
  - 材料の需要は、作った品ごとに基準の値で最も安いレシピ1つから取る。
  - ガラスも石鹸も、最も安いのは炭酸カリウムのレシピで、バリラの材料の需要は0だった。
- 史料のバリラの遠くへの取引は、値段でなく質のためだった。白い固い石鹸（カスティーリャ、マルセイユ）は、柔らかい黒い石鹸と別の品として売られた（§2）。
- そこで、オリーブ油とソーダの白い固い石鹸を、柔らかい石鹸（`Soap`）と別の財`Castile Soap`にする。その材料の需要がバリラを求める。

## 2. 史料

### 2.1 値段

- 1778〜1781年ごろのサントンジュ（アンテザンとマタの家計の買い物）で、白い石鹸1リーヴルは2.5ソル、黒い石鹸は1.25ソルだった（[Guichet du Savoir](https://www.guichetdusavoir.org/question/voir/38651)、histoirepassion.euの引用）。白い石鹸は黒い石鹸の2倍。
- 1637年のイングランドの布告は、鯨油の石鹸を1ポンド3.5ペンス、オリーブ油と菜種油の石鹸を4.5ペンスまでとした（1.3倍）。白い石鹸は、ブリストルの黒い石鹸と比べられた（[Stern Center, JHU](https://sterncenter.library.jhu.edu/early-book-collections/english-popish-soap-controversy/)）。
  - 油の違いの比べで、固い石鹸と柔らかい石鹸の比べかどうかは書かれていない。値打ちは、白と黒を比べたサントンジュの2倍を使う。
- セビーリャの王立の石鹸工場の1ポンドの値段は、1602年に18マラベディ、1643年に30マラベディと決められた（[Carmona & Donoso 2004](https://www.sciencedirect.com/science/article/abs/pii/S0278425404000055)）。

### 2.2 取引

- トリアーナの石鹸は「カスティーリャ」の名で、18世紀までフランドル・イングランド・アメリカへ送られた（[Sevilla la Leyenda](http://sevillalaleyenda.blogspot.com/2018/06/sevilla-reales-almonas-de-triana.html)）。
- 共和暦5年（1796〜97年）、港の取引が戻ったマルセイユには、ソーダ2,187 tとバリラ2,648 tが入った（[La savonnerie marseillaise de 1800 à 1815, Provence historique 1987](https://cinumedpub.mmsh.fr/Provence-historique/Pdf/PH-1987-37-147_04.pdf)）。
- 灰の仕入れは、シチリアとサルデーニャの灰、エジプトとアリカンテのソーダだった（[Revue des Deux Mondes, À Marseille - Savons et Bougies](https://fr.wikisource.org/wiki/%C3%80_Marseille_-_Savons_et_Bougies)、[Savon de Marseille](https://fr.wikipedia.org/wiki/Savon_de_Marseille)）。

### 2.3 工場のソーダ

- 海の封鎖でスペインのソーダが絶え、1809年からルブラン法の工場のソーダに代わった。1810年にはブーシュ＝デュ＝ローヌに14のソーダ工場があり、1813年にはマルセイユに62の石鹸工場があった（[Savon de Marseille](https://fr.wikipedia.org/wiki/Savon_de_Marseille)、Provence historique 1987）。
- 工場のソーダの純粋なオリーブ油の石鹸は固すぎ、少しの種の油を足して直した（Revue des Deux Mondes）。

## 3. 決めた仕組み

### 3.1 財

[goods-generator.ts](../../src/extensions/economy/generators/goods-generator.ts)の`Castile Soap`。

| 値 | 決め方 |
| --- | --- |
| 単位 | 樽（120 L、120 kg）。`Soap`と同じ |
| 値打ち | 12。`Soap`（6）の2倍（§2.1）。贅沢品の需要の`fine`の段（10以上）に入る |
| 需要の割合 | 生活用品0.4、贅沢品0.6。`Soap`と同じ |
| タグ | `luxury`、`ritual`。遠くへ運ぶ値打ちの高い荷になる |
| レシピ1 | 油0.65樽、バリラ0.38樽（[barilla-soap.md](barilla-soap.md) §3.1） |
| レシピ2 | 油0.65樽、ソーダ灰0.12樽。バリラ46 kgのソーダ約14 kg。ガラスのレシピのソーダ灰1樽がバリラ3.2樽にあたるのと同じ比（0.38 ÷ 3.2） |

- `Soap`の油とバリラのレシピは除き、`Soap`のレシピは炭酸カリウムの3つと苛性ソーダの1つに戻す。
- 値段は、`Soap`とガラスと同じく、市場が材料を持つレシピ（無ければ作れるレシピの最も安いもの）から作る（`STOCKED_RECIPE_PRICED_GOODS`）。工業のソーダ灰の前は、ソーダ灰のレシピを「油だけ」として値段に入れない。
- 職人の組合の分野は`victualling`、1樽の労働量は`Soap`と同じ0.0002、運びの分類は`chemicals`。
- 国の技術の衛生の圧力（`soapGlassPressure`）は、`Soap`とこの財の在庫の和で見る。

### 3.2 需要

- 町の贅沢品の予算は、段ごとの割り当て（小さい町で30%、ほかの町で35%）の`fine`の段で`Castile Soap`を買う。`fine`の段のほかの品は、香・コーヒー・茶・酒・マホガニーなど。
- 消費の需要の割合は、品の需要の割合で分ける。`Soap`の消費の需要の割合は約3%減る（5.38×10⁻³から5.20×10⁻³、2103）。
- 材料の需要は、`Castile Soap`の最も安い作れるレシピ（工業のソーダ灰の前はバリラ）から取る。バリラの材料の需要は、町の人1人あたり0から2.6×10⁻³になる（2103）。バリラの無い市場も、取引の蓄えでバリラを求める。

### 3.3 保存した地図

- 移行`migrateCastileSoapGood`が、`Castile Soap`の無い地図に足す。油・バリラ・ソーダ灰のIDは、その地図のものを使う。
- [barilla-soap.md](barilla-soap.md)の移行`migrateBarillaSoapRecipe`は除いた。その移行で`Soap`に足した油とバリラのレシピは、`migrateCastileSoapGood`が除く。

## 4. 計測

[castile-soap-20261108.md](../analytics/castile-soap-20261108.md)。北緯30°の地図2枚、24か月。

- カスティーリャ石鹸は、バリラの取れる市場で年15〜25樽作られた。2103では、石鹸そのものが8〜14℃の市場から14〜18℃と8℃未満の市場へ運ばれた（13〜24か月目に4樽）。
- 町の家計は1樽も買わず、人物の贅沢品が24か月で2.6・2.7樽買っただけ。在庫は24か月目に41〜46樽積み上がった。`fine`の段では割合あたりの値段の安い品から買い、白い石鹸（基準の値で20）は酒・香・コーヒー（12）や茶（10）より高い。
- バリラの遠くへの取引は起きず、2103の輸出と輸入は約5分の1に減った。取れた市場が自分の白い石鹸に使う。
- 柔らかい石鹸の買い物が、13〜24か月目に2102で約2割、2103で約5割減った。訳は調べていない。

## 5. 未確定事項

1. 値打ちの比。サントンジュの2倍の1か所だけ。イングランドの1637年の値段は1.3倍。
2. 種の油。工場のソーダの石鹸は、少しの種の油を足した（§2.3）。種の油の財は無い。
3. 柔らかい石鹸の油。北の柔らかい石鹸は獣脂のほか、鯨油・菜種油でも作った（§2.1）。`Oil`は鯨油を含むが、`Soap`のレシピに`Oil`は無い。
4. マルセイユの斑の石鹸（`savon marbré`）。白い石鹸と別の品として作られた。
5. 白い石鹸の需要（§4）。贅沢品の段の中で酒や茶と割合あたりの値段で比べると買われない。暮らし向きの良い家が柔らかい石鹸の代わりに買う、質の違いとしての需要が要る。
6. 柔らかい石鹸の買い物の減り（§4）。
