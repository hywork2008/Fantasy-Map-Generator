## 1. 観察

Cultures set が Fantasy のマップで Fast-Forward を使うと、次が同時に目立つ。

1. **名前付き人物一覧に無職が残る。** エルフ等は余生が長いので、辞任した官職者・補充で新規生成された後任が何世代分も生存したまま残る。
2. **初期の国勢人口が多産多死種族並み。** 巨人以外の長寿種族は生成時の人口密度を絞っていない。
3. **人口を減らすだけでは軍事が壊れる。** 兵力は人口から直接出る。
4. **短命種と長命種が互いを滅ぼしていない現状も微妙。** 差が出ない膠着に見える。意図した限定戦争（lore）としては実装されていない。

1 と 2 は別層である。Fast-Forward は 1 を可視化しただけで、2 は生成時から存在する。3 と 4 は「人口＝兵力、質も外交も種族を見ない」ことの表裏である。

## 4. 名前付き人物が溜まる直接原因

初期宮廷の間引きは既にある。

```ts
// src/extensions/characters/raceRoster.ts
// elf 750 → ~0.32, dwarf 350 → ~0.46, human 75 → 1.0, goblin 50 → ~1.22
raw = sqrt(75 / max(30, lifespan))  // clamp 0.2–1.4
```

`selectCentralOffices` / `shouldGenerateSparseRole` / 継承時の `fillBudget` はこれを使う。**溜まる本体は初期生成ではなく、時間経過の辞任→新規生成である。**

辞任は種族を見ない人間時計である。

```516:529:src/extensions/nobility/generators/characterLifecycle.ts
            if (personalCause && P(0.1 * deltaYears)) { /* closeOffice */ }
            if (stress > 150 && P(0.1 * deltaYears)) { /* closeOffice */ }
            if (shouldResignFromMartialEnnui(...) && P(0.1 * deltaYears)) { /* closeOffice */ }
```

条件が揃うと **年あたり約 10%** で辞任する。空席は現職同士の席替えのあと `createPerson` で埋める。再利用は現職だけ。引退者は候補に入らない。

死者は `characterPruning.ts` が猶予後に除く。生存無職は対象外。引退者は `processRetiredCharacterEffects` で Burg に人口・城壁・広場・神殿ボーナスを足すが、一覧上の称号は空のままなので「無職」に見える。

Fast-Forward は `core:demographics` を定率に置換し manpower ゲートを 7日→30日に粗くする（`advance-time-fast-forward.md`）。Nobility の加齢・辞任・継承は置換しない。人間寿命なら辞任者は数年で死ぬ。エルフ寿命 750 なら、同じ年10%の辞任が何世紀も生存レコードを残す。

二次ソース: ギルド継承・市場管理者・辺境領主・連隊指揮官も空席を新規人物で埋める。武官・領主は `shouldGenerateSparseRole` で初期は薄いが、死亡・空席のたびに新規が足される。

## 5. 人口・出生が種族化されていない箇所

| 項目 | 実装 | 種族差 |
| :--- | :--- | :--- |
| セル収容力 K | バイオーム適性。巨人・ドワーフ地下だけ `environmentalSurvival` | エルフ等なし |
| 初期飽和 | K の 60%（`INITIAL_POPULATION_FRACTION_OF_K`） | 全種族同じ。「疫病後の回復」想定 |
| 初期ピラミッド | 子 40% / 男成人 22.05% / 女成人 22.95% / 老人 15% | 全種族同じ人間型 |
| マクロ出生 | `demographicBirthRate` × 成人女性 × `roomForGrowth` | 全域同じ |
| `RaceFertility` | 名前付き世帯と将来の tick 出生用に校正済み | **マクロ人口に未接続** |
| 年齢帯ラベル | `populationAgeBands.ts` が成熟・寿命で表示だけ変える | バケツ実体は人間のまま |
| 名前付き密度 | `raceCharacterDensity` | 初期宮廷のみ |

つまり「長寿種は置換水準、短命種は多産」は人物カタログ上の数字であって、セル人口の時間発展には効いていない。Fast-Forward の定率人口成長も種族を見ない。

## 6. 軍事と外交が種族を見ない箇所

- 連隊規模は州人口（とフロンティア配置）から決まる。
- 部隊 `power` は兵科定数（歩兵 1、騎兵 1.6 等）。種族倍率なし。
- エルフ個人スキルは `martial -8` / `prowess +6`（`raceSkillBias.ts`）。これは名前付き人物の中央値であり、連隊の質ではない。
- 指揮官補正 `commanderPowerMultiplier` は個人 martial を勝敗スコアにだけ掛ける。死傷は実兵数ベース。
- civic stance（diplomatic / distant / enemy_colony / bound）は宮廷構成と混合国家の可否に使う。外交AI補正は **未実装**（`multi-race-geopolitics.md` Implementation status）。

lore は「1兵=1兵なら長寿種は総力戦で持たない。限定戦争と辺境が前提」である。実装は 1兵=1兵のまま、限定戦争AIが無い。開始時の人口密度が近いので兵力も近く、Fast-Forward は軍事をさらに粗くする。結果が「どちらも滅ぼさない」に見える。これは設計した均衡ではなく、**差が出ないシミュレーション**である。

## 7. 単一ノブでやってはいけないこと

1. **人口だけ減らす。** 兵力・税・労働が一緒に落ち、短命種が長命種を押し潰す。
2. **巨人の 0.1 をエルフへコピーする。** 理由が体サイズであり、文明として薄すぎる。
3. **初期宮廷をさらに間引くだけ。** 既に薄い。肥大は辞任時計と新規生成である。
4. **膠着を壊すために好戦度だけ上げる。** 質補正なしだと、Fast-Forward 数百年で敵コロニーが外交コアを人数で食べる。
5. **人口カットと兵質を別PRで出す。** 片方だけマージしたマップは壊れる。

## 8. 方針: 4層で補償する

目標:

- 生成直後の **州あたり総戦力** は種族間で大きく割れない（目安 0.8〜1.2 倍）。
- **短期・局地** は長寿種が勝ち、**長期の総力戦** は短命種が消耗で勝つ。
- 名前付き人物は役職者＋少数の予備に留まり、Fast-Forward 後も無職が何世代分も残らない。
- 標準 Fast-Forward で一方の種族が地図から消えない（絶滅は例外）。

人口・兵力・名前付き人物を同じ値で動かさない。

### 8.1 名前付き人物（軍事に触らない。最初にやる）

- **在任期間を種族時計へ。** 辞任確率を `deltaYears * (人間寿命 / その種族寿命)` にするか、期待在任 = `(lifespan - maturity) * 0.2〜0.3` にする。エルフの Marshal が 10 年で暇になって辞めるのがおかしい。
- **空席は先に無職の同国人を再任用。** `createPerson` はプールが空のときだけ。席替えを現職以外の生存無職にも広げる。
- **生存無職の上限。** 国あたり引退名士は 2〜4 人（地域貢献ボーナス用）。超過は一覧から外すか、死者と同様にアーカイブ。
- **UI。** 役職も role もない行は「引退名士」と出す。デフォルトで隠してもよい。空欄＝無職に見えるのがノイズである。
- **Fast-Forward。** 人口・manpower と同様、人物の新規生成も間引く。粗く進めた年だけ毎年新 Marshal を生まない。

これだけで軍事バランスは変わらない。一覧肥大の本体はここで消える。

### 8.2 国勢人口（見た目と経済。兵力は 8.3 と同時）

`environmentalSurvival.populationCapacityMultiplier` を長寿種にも足す。値は巨人と別にする。

| 種族 | K 倍率 | 理由 |
| :--- | ---: | :--- |
| Giant | 0.1（現状） | 体サイズ |
| Dwarf | 0.3（現状・地下） | 坑内生態 |
| Elf / Dark Elf / Draconic | **0.35〜0.50** | 低出生・領域排他。文明としては残る |
| Demon | 要校正（寿命 180。巨人ほど疎でない） | Distant。長寿だがエルフほどではない |
| Human / Amazones | 1.0 | 基準 |
| Orc | 1.0〜1.2 | 戦争氏族 |
| Goblin | 1.2〜1.5 | 群れ |
| Beastfolk | 1.0 前後 | 短命・Distant |

初期ピラミッドも種族化する。`createInitialPopulationCohorts` の 40/45/15 は人間専用にする。

- 長寿・低出生: 子が少なく、成人・長老が多い（安定した古い社会）
- 人間: 現状
- ゴブリン等: 子が多い

出生は既にある `RaceFertility` をマクロへ接続する。長寿種は置換水準、短命種は多産＋高い幼年死。長寿種の初期飽和は 60% より高め（古くから満に近い）にすると、「衰退からの回復」ではなく「古い低密度文明」になる。

**人口カットと兵力補正は同じ PR で入れる。**

### 8.3 軍事は「人数 × 質 × 補充速度」

```
戦力 = 兵数 × 種族の兵質 × (技術・指揮官・補給)
補充速度 ∝ 出生と成人割合
消耗耐性 ∝ 人口
```

開始時の総戦力が種族間で揃うように質を上げる。目安:

| 種族 | 兵数 | 兵質（目安） | 補充 |
| :--- | :--- | ---: | :--- |
| Elf / Dark Elf | 少ない | 2.5〜3.5 | 遅い |
| Dwarf | 中 | 1.5〜2 | 遅め |
| Draconic / Giant | さらに少ない | 個人は高いが集団戦は苦手（martial ペナルティと整合） | 遅い |
| Human / Amazones | 基準 | 1 | 基準 |
| Orc | 多め | 0.8〜1.2 | 速い |
| Goblin | さらに多い | 0.4〜0.6 | 最速 |

こうすると:

- **短期戦・局地戦** — 長寿種が勝つ
- **長期の総力戦** — 短命種が消耗で勝つ
- **平時** — どちらも相手を消しきれない

「どちらも滅ぼしていない」を、差のない膠着から **非対称で均衡** に変える。エルフの `martial -8` は個人スキル用のままにする。少人数精鋭は部隊補正、個人は「集団戦は苦手、個人武勇は高い」で整合する。

`strategic-planner.ts` の侵攻判断は現状生の兵数だけを見る（`docs/plan/char.md` の未解消）。兵質を入れるなら、実戦闘と見積もりの両方に同じ倍率を掛ける。片方だけだと AI が精鋭を「弱い少人数」と誤認して突っ込む。

### 8.4 外交AI（Fast-Forward が歴史になる条件）

質補正だけ入れて外交をそのままにすると、Fast-Forward 数百年で敵コロニーが数で外交コアを削る。

- **Diplomatic core**（人間・エルフ・ドワーフ）: 限定戦争、対外脅威では同盟可
- **Distant**（巨人・竜・ダークエルフ・デーモン・獣人等）: 孤立、侵攻には報復、征服戦争は稀
- **Enemy colony**（ゴブリン・オーク・蜘蛛）: 辺境への絶え間ない圧力。奥地の行政占領は難しい

これで Fast-Forward は「国境がゆっくり動く」になり、「永久膠着」でも「種族絶滅」でもなくなる。lore は既に書かれている。欠けているのは AI 修飾である。

## 10. 校正の合格条件

- Fantasy セット、Fast-Forward 50 年で、エルフ国の生存無職が人間国の数倍に膨らまない。
- 生成直後の平均戦力（兵数×質）が種族間で大きく割れない。
- 100 年の総力戦では短命種が押し、単年の会戦では長寿種が残る。
- 外交AI後、標準 Fast-Forward で一方の種族が地図から消えない（絶滅は例外）。
- 巨人の 0.1 とドワーフ地下 0.3 は変えない。エルフ帯は 0.35〜0.50 に留める。

## 11. 未決（実装前に決める数値）

調査時点では方針のみ。次は校正対象であり、本書の結論ではない。

- エルフ帯の K 倍率の一点（0.35 / 0.40 / 0.50）
- 部隊質の一点（エルフ 2.5 か 3.5 か）
- 生存無職上限（国あたり 2 か 4 か、辺境領主を含めるか）
- デーモン（寿命 180）をエルフ帯に入れるか、人間寄りにするか
- 引退名士を Overview のデフォルトから隠すか、ラベルだけ付けるか

人口を先にいじると軍事が壊れる。先に人物の時計を種族化し、密度を変えるときは兵質を必ず同時に入れる。
