FMG 港モデル: 実装前 / 実装後

設計書: fmg-harbour-model.md(2026-10-17、未実装)。図は概念図で、実際の座標・縮尺ではない。

セルの辺 描いた川 航路 ● 都市 / ◆ 岸壁(quay)

1. 河口の港町: 都市・岸壁・航路の位置

現状はセルで決めた値(航路の端点)と描いた形で決めた値(都市・海岸)が混ざり、後から都市だけを寄せる。実装後は岸壁(描いた岸の上)を基準に、都市・航路を 1 回で決める。

Before(現状)

  • 都市が自分のセルの外・海のセルへ寄る(H1違反)
  • 川の交差が描いた海岸の外(海上)にある
  • 航路の端点はセルの辺。都市(描いた海岸基準)と食い違う
  • 航路が描いた陸をかすめる / 貫く

After(実装後)

  • 都市は自分のセルの陸の上(H1)
  • 岸壁は描いた岸の上かつ都市のセル内(H2)、都市との距離は帯内(H3)
  • 航路は岸壁から出て、全区間が水の上(H4)
  • 川は描いた海岸で切られ、交差は陸側のみ

2. 川の航路: 河口での折り返し

Before

  • alongRiverToBurg が川のセル列の末尾(海のセル)まで下り、都市へ折り返す

After

  • 川の中心線に沿い、河口港の岸壁より海側へ出ない(H4)

3. 船の種類: 外洋の船は川を遡らない

Before

  • 区別は航路の navigation のみ。港側に受け入れ種別が無く、保証できない

After

  • 各港が vessels を持つ。河口港だけが両方を受け、荷を積み替える(H5)

4. 生成の順序

Before: 港・都市位置・海岸・航路が別々の段階で決まり、後から修復する。After: 固定順序で 1 回ずつ。

Before

都市配置(セル)→ 港の選択(haven・流量)→ 海岸を描く(港に依存)→ 海の航路(セルgraph)→ 都市を寄せる(河岸/海岸)→ dualPortPlacementTask(読込時も)→ reconnectRelocatedBurg*(端点の付け替え)

After

G1 都市のセル→ G2 海岸と川を確定(川を海岸で切る)→ G3 岸の区間(形∩セル)→ G4 港の選択+岸壁→ G5 都市の位置→ G6 航路(岸壁起点)→ G7 道と橋→ G8 検査 H1〜H6

G8 で不適合の港は invalid にして航路を作らない。都市は動かさない(H7)。

5. データモデル

BeforeAfter
港の表現burg.port / seaPort / riverPort / waterAccess.port が別々。航路の有無からも推定pack.harbours: Harbour[]。都市は burg.harbours のみ。旧フラグは有効な港から算出(互換のため保存時に書き出し)
河口の都市海港 + 河川港の 2 フラグkind: "estuary" の港 1 つ(積み替え)
航路の端点セルと haven の共有辺の中点岸壁 quay(描いた岸の上)
航路の所属港を外しても航路が残る港に属し、港が無ければ消える(H6)
船種航路の navigation航路の vessel + 港の vessels
海岸の固定portCoastPlacement: "pinned"(港のセルの辺を固定、循環依存)岸壁の周辺だけ局所的に描き直し(未決: 実現性)
保存データの修復読込時に都市を動かして直す不適合の港を invalid にするだけ。再生成は Tools から明示実行(H7)
