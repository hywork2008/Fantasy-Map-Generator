# CEのセル標高: 生成プリセットと標高ブラシ

作成日: 2026-10-24
状態: 2026-10-24 実装。平面を既定のまま、斜面・中央高・中央低・谷を生成時にセルへ書き、標高ブラシで上げ下げ・ならし、川の頂点列は陸の川床が下流へ上がらない向きに直す。

## 1. 目的

CEで単独生成した地図は、陸のセルの `elevation` がすべて 1 m である。FMGから開いた都市だけが、連携した高さ場をセルへ写す。起伏のある町を、セルの標高のまま作れるようにする。

- 生成時に、今の平面に加えて地形のプリセットを選べる。
- FMGの Heightmap 編集（`editHeightmapButton`）のように、ブラシで標高を上げ下げできる。
- 川は、標高の低い方から高い方へ流れない。

高さ場モード（`ce-terrain-field-mode.md` の `terrain.field`）は別の地面である。本設計はセルの標高を変える。高さ場を選んでいるあいだ、3Dの地面は高さ場のままである。

## 2. 現状

- メッシュ生成は陸セルを `elevation: 1` にする（`generators/mesh.ts`）。
- `applyTerrain` は、`plan.fmgElevations` があるときだけ `landElevation` で上書きする。単独生成は `descriptor` を持たないので、この写しは起きない。
- `SiteConfig.relief`（Relief (hilltop)）は合成敷地の高さ場と町の型にだけ効く。セルの標高は変えない。
- 川は地理の回廊を歩いた頂点列で、上流から下流の順に保存する（`RiverGroup.vertices`）。標高は見ていない。
- セルの標高は検査欄の数値で1セルずつ変えられる。面を塗るブラシはない。
- 2Dの塗りは区の色で、標高では塗らない。3Dは `cellRelief` がセルの標高を水平なセルと土手・擁壁にする。

## 3. プリセット

生成設定 `elevationPreset`。未設定と `flat` は今の挙動（FMGの高さがあればそれ、なければ 1 m以上の現状値）。

| 値 | 地形 |
| --- | --- |
| `flat` | 平面。既定 |
| `slope` | 山の斜面。一方が高く、反対側が低い |
| `dome` | 地図の中心が高く、周囲が低い |
| `basin` | 地図の中心が低く、周囲が高い |
| `valley` | 一本の谷。谷筋が低く、両側が高い |

高さはメートルで、0.1 mに丸める。陸の下限は 1 m。低い側は 2 m、高い側は `2 + amplitude`。`amplitude` は図枠の一辺の 4% で、12 m以上 80 m以下。600 mの図枠で約 24 m、1,200 mで 48 mの起伏になる。

斜面と谷の向きは、川があればその川の下流方向を下りにする。川がなく海岸があれば、水面の重心へ下る。どちらもなければシードから方位を決める。中心は地図原点（都市の中心）である。

`flat` 以外を選ぶと、FMGから写したセル標高の代わりにプリセットを書く。海のセルはあとから標高 0 のままである。城の予約セルとロックしたセルは変えない。

高さ場テンプレートとプリセットは同時に選ばない。一方を選ぶと、もう一方は平面またはオフに戻す。

## 4. 川が上らないこと

川の頂点ごとに、接する陸セルの最低標高を川床とする。海のセルは川床に入れない（岸を海面まで削らない）。

1. 一方の端だけが海に接するなら、その端を下流にする。
2. そうでなければ、陸の川床が 0.5 mより高い端を上流にする。
3. 上流から下流へ歩き、川床が前より高い陸セルを、前の川床まで下げる。上げない。ロックしたセルは変えない。下限は 1 m。平らな区間は許す。

生成のあと、標高ブラシの一画のあと、検査欄でセル標高を変えたあと、川を描き終えたあとに同じ処理を行う。頂点の順が川の向きである。

## 5. 標高ブラシ

ツール `elevation`。FMGのブラシのうち、上げる・下げる・ならすをセル単位で行う。半径は既存のブラシサイズ（セル数）。強さは中心でのメートルで、縁へ直線的に弱くなる。ポインタの移動量に比例し、同じ場所に止めても積み上がらない。海とロックしたセルは塗らない。陸は 1 mより下げない。

2Dでは、陸が 1 mを超えるセルに半透明の標高の色を重ねる。低い側は薄い緑、高い側は茶色。区の色は残る。3Dは既存のセル標高の地面をそのまま使う。

## 6. 保存

プリセットは生成設定であり、結果の標高はセルに保存する。文書の版は上げない。共有リンクの設定に `elevationPreset` を含める。未知の値は無視する。

## 7. 範囲外

- 高さ場の格子をブラシで彫ること。
- 川の経路を標高に合わせて引き直すこと。経路は今のまま、向きと川床の段差だけを直す。
- `SiteConfig.relief` の意味を変えること。
