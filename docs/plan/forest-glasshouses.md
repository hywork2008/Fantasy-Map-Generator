# 森のガラス小屋

## 1. 背景

[wood-ash-potash.md](wood-ash-potash.md) §5の1の続き。寒い市場の地元のガラスは、ほとんど作られていなかった（[glass-houses-20261107.md](../analytics/glass-houses-20261107.md) §2）。

- ガラスは、町のガラス職人の仕事として数えていた。
  - 職人の数は、町の人口1,000人に陶工2人とガラス職人0.3人。ガラスに使えるのは、その1/4である。
  - 1荷（465 kg）に27人月かかる。
- 寒い市場の町は小さい（0〜4℃の市場で平均1,238〜1,420人）。1つの町が作れるのは月約0.03荷になり、材料が足りない判定と作れる量の0で止まっていた。
- 職人の表の出典の欄には、もともと「ガラスそのものは森のガラス小屋から来た」と書いてあった。

## 2. 史料

- ドイツの森のガラス（[Waldglas](https://de.wikipedia.org/wiki/Waldglas)）:
  - 1 kgのガラスに、積んだ木材約1 Rm（約0.7 Fm）を使った。
  - その80〜85%は、炭酸カリウムを取るために灰にした。
  - 小屋1つは、年に2,000〜3,000 Fmの木材を使った。森20〜30 haにあたる。
  - 材料は、重さで灰2に石英の砂1。
  - 小屋には、10を超える家族が住んだ。
- 1763年のリーゼンゲビルゲの小屋は、38人が働いた。ガラス職人10人、火夫3人、少年8人、木こり15人、荷造り2人で、炉を焚いたのは年24週（[Die Glasgewinnung im Riesengebirge](https://jbc.jelenia-gora.pl/Content/41097/45559_Glas_Worbs_Goerlitz.pdf)）。
- 中世のイングランドのガラスは、ウィールドなどの家族の小さな森のガラス小屋で作った（[Early modern glass in England](https://en.wikipedia.org/wiki/Early_modern_glass_in_England)）。
- 小屋は、近くの森を切り尽くすと移った（[Forest glass](https://en.wikipedia.org/wiki/Forest_glass)）。

炭酸カリウムのガラスは、町の職人ではなく、森の小屋が自分の木を焼いて作るものだった。

## 3. 決めた仕組み

[forestGlasshouses.ts](../../src/extensions/economy/generators/forestGlasshouses.ts)。毎月、町の暖房の後に動く。

### 3.1 小屋の大きさ

| 値 | 決め方 | 結果 |
| --- | --- | --- |
| 1年の木材 | Waldglasの2,000〜3,000 Fmの中ほど | 2,500 Fm |
| 1 kgの木材 | 1 Rm ≈ 0.7 Fm | 0.7 Fm |
| 1年のガラス | 2,500 ÷ 0.7 | 約3.6 t（7.7荷） |
| 働き手 | リーゼンゲビルゲの38人（木こりを含む） | 1荷に59人月 |
| 1荷の木材 | 0.7 × 465 kg | 325 Fm（木材32.5単位） |

- 1荷に59人月は、町の職人の27人月より多い。小屋の数には、木を切り、灰にし、炭酸カリウムを取る仕事が入るため。
- 炉を焚く季節（年24週）は分けず、毎月同じだけ作るとする。

### 3.2 毎月の仕事

1. 小屋を持てるのは、人の住む森のセル（バイオームのタグ`forest`）のある市場である。
2. 作れる量の上限は、次の小さい方。
   - 市場の森のセルの農村の人の1%（`GLASSHOUSE_MAX_RURAL_SHARE`、仮の値）が、小屋で働くとした量。
   - 森のセルが、その月に切れる木材の1%（農村の木材と同じ割合）。
3. 作るのは、市場のガラスの在庫を次の大きい方にするまで。
   - 町の人口に応じたガラスの下限（`getCalibratedMonthlyLots`、町の人9,000人に月1荷）の1か月分。
   - ガラスを使う量（町の買い物・贅沢品・レシピ・建設）の移動平均の3か月分。
4. 木材は、`harvestWood`で森のセルから切る。市場の木材の在庫は使わない。切れた木材の分しか作らない。
5. ガラスの砂（`White sand`）は、ガラスのレシピ（砂と炭酸カリウム）の砂の量を、市場から買う。炭酸カリウムは、小屋が自分の木の灰から取るので買わない。
6. お金は次のように動く。
   - 農村の家計が、砂の代金を市場の金庫に払う。
   - 市場の金庫が、ガラスを市場の値段で買い、農村の家計に払う。
   - ガラスの値段が砂の代金を下回る時は、作らない。
7. ガラスは、流れの種類`forestGlass`で市場の在庫に入る。

### 3.3 町のガラス職人

- 小屋のある市場（作れる量の上限が0より大きい）では、町の職人の下限（`remainingCalibratedLots`）をガラスについて0にする。町はガラスを作らない。
- ガラス職人は、実験用のガラス器などの仕上げの仕事に残る。
- 小屋の無い市場（森の無い市場）は、これまでどおり町がガラスを作る。

### 3.4 保存した地図

- 財とレシピは替えないので、移行は要らない。
- 市場の帳簿（`forestGlasshouses`）は、最初の月に作る。

## 4. 計測

結果は[glass-houses-20261107.md](../analytics/glass-houses-20261107.md) §4（シード2102・2103、12か月）。

| 12か月の合計（荷） | 2102 base | 2102 new | 2103 base | 2103 new |
| --- | ---: | ---: | ---: | ---: |
| 町のガラス | 136 | 0 | 47 | 0 |
| 小屋のガラス | 0 | 374 | 0 | 246 |
| 国の船の持ち帰り | 229 | 169 | 384 | 245 |

- 0〜4℃の市場の地元のガラスは、2102で6 → 30荷、2103で6 → 57荷になった。
- 国の船の持ち帰りは、2102で26%、2103で36%減った。
- 町がガラスを作らなくなり、炭酸カリウムをレシピに使う量は約4割減った（2102で129 → 81樽）。
- 小屋の木材は、作ったガラスから約1.2万（2102）と8千（2103）単位で、家計の暖房（2102で約30万）の数%である。

## 5. 未確定事項

1. 森の農村の人の1%という上限は、仮の値である。中世の森の土地の小屋の密度の史料で決めたい。
2. 8℃以上の森の市場でも、町がガラスを作らなくなる。地中海の町のソーダガラス（ヴェネツィアなど）は町で作ったので、ソーダのガラス（`Soda Ash`のレシピ）や暖かい土地では町に残すかを調べる。
3. ガラスのレシピの炭酸カリウム（1荷に0.5樽、60 kg）は、史料（砂の約半分の重さ）より少ない。町のガラスの材料の量は、まだ替えていない。
4. 炉を焚く季節、小屋の移動（切り尽くした森）、木材の運び出しの手間は入れていない。
5. 小屋の木材を切った量は市場の流れに入らない（森の上で使う）。市場の帳簿の`woodFelled`で見る。
