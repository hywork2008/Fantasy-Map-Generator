# 家畜の塩の支払いを農村の財布の割合までにする（2026-10-30）

関連: [fodder-purchase-demand-cap.md](fodder-purchase-demand-cap.md) §4、[記録](../analytics/fodder-purchase-demand-cap-20261030.md)の最後の追記。

## 1. 背景

`saltLogistics.ts`の家畜の塩は、毎月、必要な量・市場の在庫・農村の財布の全額のうち最も小さい量を買う。家畜の飼い葉（`LIVESTOCK_FEED_CASH_SHARE`、財布の5%）のような支出の割合の上限が無い。

飼い葉の買い上げを需要までにした後（7a6c3a5ad）、市場1では農村の財布に現金が入った年に、家畜の塩に35.5千（変更前は5千程度、同じ年の穀物の代金の約2倍）を払った。農村が町で使うお金は、塩を払った後の財布の割合で決まるので、町にお金が回らず、1304〜1305年に都市の主食の充足が下がった（市場1で94%→77%、93%→72%）。

塩が足りない家畜には、今は何の影響も無い（`monthlyUnmetLivestockBags`に記録されるだけ）。

## 2. 方針

- 家畜の塩の1か月の支払いを、農村の財布の`SALT_LIVESTOCK_CASH_SHARE`倍までとする。仮値は飼い葉と同じ0.05。
- 人の塩（`saltFinance.ts`）は変えない。
- 足りない塩は、これまでどおり不足として記録する。不足が家畜に与える影響（乳・成長）は、この計画では入れない。

1頭あたりの塩（牛20 kg/年）は、今の乳牛の推奨（1日30〜60 g、年11〜22 kg）の上の端にあたる。中世の小さな牛ではもっと少なかったとみられる。値の見直しは後続とする。

### 3.1 S1・S2の結果（2026-10-30、[記録](../analytics/livestock-salt-cash-share-20261030.md)）

- S1: `saltLogistics.ts`に`SALT_LIVESTOCK_CASH_SHARE`（0.05）を加えた。単体テストを1件加えた（割合を1にすると失敗することを確かめた）。
- S2: 家畜の塩の支払いは3〜4割減り、1304〜1305年の都市の主食の充足は91.1→92.0%、92.0→93.6%。完了条件（94.2%・95.6%）は満たさない。浮いたお金の多くを人の塩が取り、市場1では塩の合計がほぼ変わらなかった。goldenの基準値は更新していない。
- 上限が国×市場の需要ごとに重なっていたので、市場ごとに1か月の枠を1つにした（単体テストを2か国が同じ市場で買う形に直した）。1304〜1305年は93.5%・94.4%に上がったが、まだ完了条件に届かず、1306年は94.8%（基準95.4%）に下がった（[記録](../analytics/livestock-salt-cash-share-20261030.md)§5）。残りは塩の値段の張り付き（§4）として扱う。

## 4. 未確定事項

- `SALT_LIVESTOCK_CASH_SHARE`と、1頭あたりの塩の量（`SALT_LIVESTOCK_ANNUAL_KG`）の史料との照合。
- 塩の不足が家畜に与える影響。
- 人の塩の支払い（市場1で年20千余り）は、量（必要の7〜9割）でなく、値段がほとんどの市場で基準の約3倍に張り付くことによる。在庫が1か月分以下だと`priceSalt`の`pressure`が3になり、在庫が3か月分の目標に届かないため。人の塩に財布の上限は設けない（[記録](../analytics/rural-salt-bill-20261030.md)）。値段の扱いは未定。
