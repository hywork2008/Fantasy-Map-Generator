# 国の予算を全ての収入から決める

## 1. 背景

[stipend-funding-20261114.md](../analytics/stipend-funding-20261114.md)で、支配者と中央の役人のお金が1年目で0になるのは、手当の元の予算の収入（`allocateTreasury`に渡す`budgetIncome`）が人頭税の分だけで、1か月5.5〜122（地図2103）と、国の金庫（1.8万〜14.7万）の0.1%に満たないためと分かった。売上税と関税は国の金庫に入るが、予算には入らない。王家の手当は20か国全てで支配者の生活費を下回った。

## 2. 決める仕組み

1. 予算の収入に、その月の売上税と関税（既に国の金庫に入っている分）を足す：`budgetIncome = (人頭税ほか + 売上税 + 関税) × (1 − 行政の費用の割合) × 出来事の倍率`。部局（軍・尚書・財務・諜報・教会・公共事業）の予算と、役人の手当（部局の予算の12%、下限・上限つき）が収入に合わせて大きくなる。
2. 王家の財布（`householdPurse`）に、王家の割合の分だけでなく、支配者の手当の下限（1か月48）に足りるまで国の金庫から入れる。今は、割合の分が下限より小さいと、下限が財布に無く払われなかった。
3. 設定`stateBudgetIncome`：`allRevenue`（既定、1と2）か`pollTax`（今の決まり）。

## 3. 見込み

- 1か月の後（地図2103）、予算の収入は5〜35倍（69〜685）になり、20か国全ての支配者が手当の下限48以上を受け取った。生活費（48.5〜49.8）には、手持ちの2%の身分の費用が入るので、手持ちは約360で釣り合う。
- 国の金庫から部局・王家・役人に回るお金が増え、役人と支配者が町で使う。

## 4. 計測の計画

北緯30°の地図2枚（2102・2103）、36か月、戦争なし・隊商の略奪なし。`pollTax`（[heirless-estates-20261114.md](../analytics/heirless-estates-20261114.md)の出力）と`allRevenue`を比べる。

1. 身分ごとの手持ち（支配者・中央の役人）。
2. 国の金庫・町の家計・市場のお金。

## 5. 未確定事項

1. ギルドの親方の手当（工房の稼ぎを元にする、[stipend-funding-20261114.md](../analytics/stipend-funding-20261114.md) §6）。
2. 部局の予算が大きくなった時の、軍の費用の割合と戦の備え。

## 6. 結果

[state-budget-income-20261114.md](../analytics/state-budget-income-20261114.md)。支配者と役人のお金は0まで落ちず、正の値で落ち着き始めた（支配者は蓄え0年で1人約60に釣り合う。地図2103は36か月目に約65）。役人の手持ちは前の約3倍。町の家計が2〜3%、農村の家計が2〜4%減り、部局の予算が増えた分の行き先は未確認。
