# 売れ残った収穫を農家の蓄えに残す（2026-10-29）

関連: [wet-region-pastoral-economy.md](wet-region-pastoral-economy.md) §3.8、[記録（落ち込みの原因）](../analytics/wet-region-herd-food-20261029.md)。

## 1. 背景

固定入力のWorldを読み込んだ後の1303〜1305年に、都市の主食の充足が80.8〜91.6%に下がる（§3.8の後。変更前も94.4〜96.0%）。災害・寒冷化ではない。

`foodProduction.ts`の月ごとの収穫の精算は、次の順に収穫を分ける。

1. 農家の蓄え（穀物を食べる人×1年分、`RURAL_HOUSEHOLD_FOOD_RESERVE_YEARS`）に足りない分を、農家が取る。
2. 残り（卸）を、市場が蔵の上限（`storageCap`）まで買う。
3. それでも残った分（`unsoldHarvest`）は、どこにも入らずに消える。

コメントは「残りは農家が持つ」としているが、コードは持っていない。1年目に0.45〜0.61（都市の需要の約2年分）が消え、2〜3年目は農家の蓄えの補充が市場への卸を先に取って、市場の在庫が尽きた。

## 2. 方針

- 市場が買わなかった卸は、出したセルの農家の蓄えに戻す。上限は、蓄えの目標（1年分）に余りの蓄え`RURAL_HOUSEHOLD_SURPLUS_STORE_YEARS`（1年分）を足した量とする。上限を超えた分は、これまでどおり消える（家畜の餌・醸造・腐敗など、台帳の外の用途とみなす）。
- 目標を超えた蓄え（余り）は、月ごとに減る。年の率`RURAL_HOUSEHOLD_SURPLUS_ANNUAL_LOSS`は0.15（仮値）。穀物の倉の年の損失は、伝統的な貯蔵で1〜2割とされる。目標までの蓄えは、今の扱い（損失なし）のままとする。
- 余りの蓄えは、農家が次の年に食べる。次の収穫では、蓄えが目標以上なので補充が要らず、収穫の全部が市場への卸になる。これで、不作や需要の増えた年に市場への卸が減らない。
- 市場が余りの蓄えを買い戻す経路は作らない（後続）。

`unsoldHarvest`は、蓄えに戻した後の、本当に消えた分を表すように変える。

## 3. 段階

| 段階 | 内容 | 完了条件 |
| --- | --- | --- |
| H1 | 2を実装する | 単体テスト：市場が買わなかった卸が農家の蓄えに上限まで戻り、余りは月ごとに減る |
| H2 | 新しい固定入力（`docs/analytics/inputs/wet-pastoral-birth-20261029/world-102.fmg`）で84か月、変更前と比べる | 1303〜1305年の都市の主食の充足の落ち込みが浅くなり、その後の年が悪化しない |

### 3.1 H1・H2の結果（2026-10-29、[記録](../analytics/unsold-harvest-household-store-20261029.md)）

- H1: `foodProduction.ts`に`RURAL_HOUSEHOLD_SURPLUS_STORE_YEARS`（1）と`RURAL_HOUSEHOLD_SURPLUS_ANNUAL_LOSS`（0.15）を加え、市場が買わなかった卸を出したセルの蓄えに上限まで戻した。`unsoldHarvest`は戻した後に消えた分になった。単体テスト（`foodProduction.test.ts`）を直し、余りの減りのテストを加えた。
- H2: 1301年に消えた収穫は0.445→0.031。都市の主食の充足のいちばん低い年は80.8%→94.2%、農村は96.3%→99.6%。完了条件の前半を満たす。1306〜1307年の都市の充足は変更前より0.9〜1.4ポイント低く、原因は未確認。

### 3.2 1306〜1307年の都市の充足（2026-10-29）

変更後に1306〜1307年の都市の充足が0.9〜1.4ポイント低いのは、在庫切れでなく、市場9・10など数か所の都市の世帯がお金を使い切ったためである。変更前は1303〜1305年に在庫が無く、食べられない代わりにお金が残っていた。変更後はその年に食べて払い、財布が尽きた。もとからある都市の収入の不足が表に出たもので、H1の扱いは変えない。goldenの基準値は、d8359de08とH1の変更に合わせて更新した。

## 4. 未確定事項

- 市場9・10などで、都市の世帯の収入が穀物の代金に足りない原因。[記録](../analytics/urban-money-flows-20261029.md)で、差は交易でなく後背地の農村が町で使うお金（1,000人あたり154と389）にあり、増える市場の農村は飼い葉・燃料を売って外からお金を得、減る市場の農村は塩と飼い葉の支払いでお金が出ていくことが分かった。お金が戻る経路（減る市場が売れるもの、塩・飼い葉の値段）の扱いは未定。
- 余りの蓄えの上限（1年分）と損失の率（0.15）の史料との照合。
- 余りの蓄えを、不作の年に市場が買い戻す経路。
