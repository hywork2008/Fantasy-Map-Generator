Problem — mutation ordering, redraw choice, cache invalidation, and simulation notifications leak across every caller.

Solution — deepen one module around read, dispatch, and subscribe; emit revisioned ChangeSets after each commit.

  • locality: writes in one module
  • leverage: one commit, all adapters
  • interface shrinks for editors
  • tests hit one interface

Problem — hidden SVG output is also the style and layer-state interface, so WebGL correctness depends on DOM mutation and manual scheduling.

Solution — move style, layer visibility, label layout, and saved overlay layout behind a presentation module.

  • locality: style has one owner
  • leverage: all adapters read once
  • SVG becomes disposable output
  • DOM-free tests become possible

Problem — one shallow implementation mixes SVG output, core state, extension state, migration, and live DOM replacement.

Solution — put legacy and chunked-binary adapters at one codec seam; decode, migrate, and validate before replacement.

  • locality: migrations live with codec
  • leverage: unknown slices survive
  • load failure preserves world
  • SVG export stays independent

Top recommendation

WorldRuntime first

It creates the commit seam needed by presentation, rendering, simulation, 3D invalidation, and the later archive codec without replacing pack/grid in the first phase.
