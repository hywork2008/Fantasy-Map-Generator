# 立場のある人物の生成プリセット

- 状態: Implemented core（2026-10-22。選択プリセット・人数プレビュー・分割生成・越境教会設定・御用契約を実装。制度ごとの拡張定員は明示編集で設定する）
- 日付: 2026-10-22（設計初稿 2026-10-19）
- 対象: Characters Overview / Organizations & families の種類別・組織別の選択生成
- 基礎設計: [組織・役職台帳と必要時の NPC 生成](medieval-european-nobility-holdings.md)

## 実装メモ（2026-10-22）

- Characters Overview → Organizations & families の「プリセットで生成」から使用する。種類別 13 種類と「組織別の構成員」を組み合わせ、対象国家・組織・活動国・役職範囲を指定する。条件と開閉状態はタブ切り替え後も保持する。
- プレビューは人物・個人枠・契約・定員を追加しない。役職の対象席、兼任を除いた実人数、生成済み人数、新規人数、空席、所属未確定の席を表示する。初期の抽象在職席と退任後の空席を分け、後者は通常の生成から除外する。
- 実行計画を固定して 25 席ずつ詳細化する。計画・進捗・名前付きの条件は世界台帳へ保存し、中断後に再開できる。就任者・選択適格性・役職/組織設定・世界日時の変化は再プレビューを要求する。残りの計画だけの破棄も可能。
- 既存台帳プロバイダーが意味分類を供給する。独自役職の分類・職業・定員・主要領主属性、組織種別・軍編制を画面から明示編集できる。既存の定員を保ち、幹部プリセットを選んだだけでは役員や幕僚の新席を追加しない。家政・ギルド等の拡張役職は組織の「役職を追加」と分類編集を組み合わせて設定する。
- 「国境を跨ぐ教会組織を設定」はユーザーが選んだ信仰・都市・推定信徒比率・教区規模から、教会型の本部・近接都市の司教区・都市拠点を作る明示操作。都市代表は教区司祭の一席を兼ねる。同じ信仰の複数教会が同じ都市で推定信徒数を重複利用しないよう比率の合計を検証する。国家から活動中の教会へも辿れる。
- 信仰分布は候補に限り、少数派拠点は都市を手動追加する。既存司教領の司教と新設教会の司教を氏名や場所だけで同一人物にしない。必要な場合は「兼任・就任を設定」で同じ個人枠を共有する。既存 Cleric の在職枠は、明示作成した最初の都市拠点へ引き継ぐ。
- 御用契約は顧客組織・供給組織・担当役職の枠番号・品目を明示する。契約を設定/終了しても人物や収支を増やさない。担当者は既存の商会主等と同じ個人枠を使う。
- 実装: `src/extensions/characters/roster/preset*.ts`, `presets.ts`, `institutions.ts`、UI: `RosterPresetPanel.tsx`, `RosterInstitutionSetup.tsx`。保存項目は既存 v1 台帳への任意項目追加とし、旧セーブとの互換性を保つ。
- 中世以外・各政体の官職表の充実、宗教制度ごとの専用名称・教会行政の史実再現は本実装で完了したものとはしない。存在する席と明示作成した制度をプリセットで選択する。

## 方針

人物の生成・削除に伴う所持金、兼任時の資産、死亡・相続の通貨保存は、[人物資産のライフサイクル](character-wealth-lifecycle.md)で別途設計する。

「全国家の元首」「この教会の各都市の司祭」「主要な貴族とその御用商人」のような目的を、保存可能な選択条件へ変換する。プリセットは役職・在職枠を検索するもので、クリックだけで組織の定員や国家の制度を増やさない。世界生成と一覧表示では人物を生成せず、内訳のプレビュー後にユーザーが実行する。

役職・職業・社会的身分を区別する。ギルド長は役職、鍛冶師は職業、貴族は身分であり、鍛冶師全員をギルド長として選ばない。国王が軍の最高司令官を兼ねる、司教が領主を兼ねる、商会主が御用商人を兼ねる場合は、席を複数表示して同じ人物を再利用する。

本書の人数係数はゲームの世界構築用の初期案であり、中世ヨーロッパ全域の史実定員ではない。文化・時代・政体・宗教制度のプロファイルで名称、席の有無、定員式を差し替える。司教・神父等は中央集権的な教会型プロファイルの表示名で、すべての宗教へ適用しない。既存台帳の定員があればそれを優先し、変更には別の「制度・定員を編集」操作を必要とする。

## 共通の人数と選択規則

- 基準日は世界の現在日。過去の元首や歴代ギルド長を含める場合だけ履歴検索へ切り替える。退役・滅亡・廃止済み組織は既定で除外。
- 必要席数は対象役職の定員合計。在職者数は有効な Appointment の個人枠を重複排除した人数。未詳細化の在職者と真の空席を区別する。
- 今回の生成対象は未詳細化の在職枠。初期台帳で個人レコードを省略している在職枠も、安定した席キーから実体化できる。真の空席を埋める「後任を選任」は別操作で、通常の生成では行わない。
- `新規 Character 数 = 選択された在職個人枠のうち Character がない枠の数`。席の合計から単純に既存人物数を引かず、兼任と他プリセットとの重複を解決してから計算する。
- 同一人物か不明な複数席を氏名や同じ都市という理由で自動統合しない。確定した兼任関係は台帳で共有する。未確定の兼任案はプレビューで提示し、確定しなければ別人物として数える。
- 各プリセットは基本・拡張を選べる。「代表者だけ」「幹部まで」「組織全体」の範囲を明示する。下位組織・家族・兵卒・徒弟は明示選択しなければ含めない。
- 生成の既定はメモ用。シミュレーション開始、後継自動生成、家族の詳細化、ロック変更は独立した選択で、プリセット実行に付随して有効にしない。

以下の記号は選択範囲内の有効な台帳の件数。S = 国家、R = 陸上部隊、F = 艦隊、H = 世俗領主職、A = 行政官区、C = 都市、M = 市場、K = 商会、G = ギルド。表の式は席数で、兼任を除いた人数ではない。

### 主要な貴族の判定

既定は「王制かつ世俗領主制がある国家」の現役世俗領主職を対象に、次のいずれかを満たすものをすべて選ぶ。

1. 制度上の上級領主職（公・伯等。ただし表示文字列ではなく制度上の層で判定）。
2. 君主の直属封臣で、男爵・honour 保有者等の独立した領主権を持つ。
3. 上記に属さなくても、当該制度で定義された広域統治・辺境統帥の権限を持つ。

人数上限や「各国上位 10 人」で間引かない。ユーザーは「直属のみ」「上級のみ」「全領主」を切り替えられる。爵位がない有力者を含める場合は領主権の属性を使う。土地面積や称号の文字列だけで公・伯を推定しない。複数 Holding を同じ人物が保有していれば、その権原は複数行、人物は 1 人として扱う。

行政官としての Sheriff、法人を代表する司教・修道院長、国王の直轄地は既定の世俗貴族から除外する。「宗教領主を含む」を選ぶと対応する法人代表の席を追加し、司教本人を宗教プリセットと共有する。

### 軍団長と部隊長

現行の `state.military` は軍団という階層を保証しない。UI は「軍事指揮官」を標準名称とし、編制種別が未設定なら「部隊長（編制未分類）」と表示する。「軍団長のみ」の結果を全 regiments の数で水増ししない。軍団組織を作る場合は編制を編集する別手順を使う。

現在の兵力 80 の閾値は人物検索の条件には使わない。新モデルでは兵力がある独立部隊に責任者席を置き、80 未満では小隊長・隊長等の文化別名称を使う。兵力 0 の予備組織は既定では除外し、現役指揮官の在職記録がある場合だけ表示する。移行時に欠ける席は台帳更新で補い、Character は生成しない。

## 組織別プリセット

組織を選んだ際に以下を提案する。同じ種類別プリセットを所属・関係で絞ったものなので、別系統の人物を作らない。

| 組織 | 代表者だけ | 幹部まで | 組織全体を選ぶ場合 |
| --- | --- | --- | --- |
| 国家の中央政府 | 元首と別人なら政府首班 | 中央執行官職・制度上の合議構成員 | 宮廷家政団・軍・地方組織を個別チェック。国家の全人口は含めない |
| 王家・貴族家 | 当主 1。既存領主と共有 | 家令、財務担当、護衛責任者を各 1、必要なら礼拝担当 1 | 使用人・家政騎士は既存定員。配偶者・子・後継者は家系オプションで別選択 |
| 陸上部隊・艦隊 | 指揮官 1 | 副官 1、補給責任者 1。大部隊の幕僚は編制表を優先 | 兵員台帳の残り。在職指揮官・幕僚も兵力内に数え、兵員数へ追加しない |
| 都市行政 | 市長・執政・城代の対象席 | 参事会、徴税責任者、治安責任者の定員 | 都市にある商会・宗教等は管轄が異なるため別チェック |
| 教会・修道院・騎士団 | 法人代表 1 | 教会は司教等、修道院は副院長・会計等の制度別席 | 下位教区・都市拠点、修道士・団員は個別チェック。一般信徒は含めない |
| 商会 | 商会代表 1 | 現行基本は代表・書記・護衛の 3 席 | 支店長は支店ごと 1、従業員は商会台帳にある定員のみ |
| ギルド | ギルド長 1 | 拡張案は長 1、役員 2、会計 1、書記 1 の計 5 席 | 現行基本は長 1＋徒弟 2。5 席への拡張は別途制度編集。全職人を会員扱いしない |
| 市場 | 市場管理者 1 | 現行基本は管理者 1＋商人 2 の計 3 席 | 商店主・卸売人は市場の所属台帳にある席。市場の利用者全員を所属させない |

小規模な家・組織では家令と財務担当等の兼任を制度に明示できる。兼任を設定しない場合は席数どおりの別人としてプレビューする。従業員定員が未設定なら「組織全体＝人口の何％」と勝手に補完しない。

## 国境を跨ぐ宗教組織

### 信仰、組織、配置を分ける

Religion は信仰・教義のまとまりであって、必ずしも一つの組織を意味しない。同じ信仰に属する独立教会、分派、修道会をそれぞれ Organization として持てるようにする。国教だから国家の子組織に固定することもしない。

主たる組織階層の例は `世界 → 教会本部 → 大管区 → 司教区 → 都市教区・聖堂`。修道会は教会本部への関係を持つ別の枝に置く。司教区は国境を跨げ、国家ごとに司教を複製しない。宗教上の管区は Province と別物。地理的配置は burg/cell、国家との関係は活動領域・公認・保護等のリンクとして保存する。

国家画面からは「この国で活動する宗教組織」を表示し、同じ組織への参照を辿る。組織の本拠国を選んでも国外の支部を当然には含めず、「主所属を辿る」「国内拠点を検索」「国境を跨ぐ下位組織を含む」を区別する。

### 教会型プロファイルの席と人数

| 階層 | 初期案の定員 | 導出・兼任 |
| --- | --- | --- |
| 教会本部 | 最高指導者 1 | 単一首長制の場合のみ。合議制ならその制度の席数 |
| 大管区 | 大司教・管区長 1/管区 | 所属司教区の 1 席を兼ねる制度では人物は共有 |
| 司教区 | 司教 1/教区 | 初期案は対象都市拠点 8 件を目安に近接集約。`ceil(拠点数/8)` は区域作成の目標数であり、既存区域・地理的分断・手動指定を優先。国家数から算出しない |
| 都市代表 | 司祭長・主任司祭 1/都市拠点 | その都市の司牧責任者。司教と同じ役職ではない。司教座都市でも、兼任指定がなければ司教とは別席 |
| 都市教区 | 神父・教区司祭 1/教区拠点 | 宗教組織ごとの都市信徒数 U に対して初期案 `max(1, ceil(U/3,000))` 教区。都市代表はこの中の 1 席を兼任し、別に上乗せしない |
| 聖堂 | 聖堂主任 1/聖堂 | 都市代表や教区司祭との兼任を設定可。建物数をすべて独立教区数とはしない |
| 修道院 | 修道院長 1/法人 | 領主としての修道院長と同一人物。修道士の定員は別 |
| 騎士修道会 | 総長 1、支部長 1/支部 | 宗教代表・軍事指揮・領地代表の役割を共有可 |

既定の `urban-clergy` は都市代表だけを選ぶので、対象都市拠点数が基本席数になる。「教区司祭全員」を選ぶと教区席の集合に置き換え、都市代表を二重加算しない。「司教・上層部も含む」「修道院も含む」は独立した追加。

3,000 人/教区と 8 都市/司教区は人口史の主張ではなく、編集可能な世界構築パラメーター。宗教・地域・時代別に変更し、UI は各行に定員の根拠を表示する。農村教区は都市プリセットに含めず、農村拠点・人口を使う別の拡張とする。

### 対象都市の決め方

1. 既存・手入力の宗教拠点と所属組織を最優先する。少数派の礼拝所、国外の支部も対象にできる。
2. `burg.temple` やセルの代表宗教だけでは、その都市の宗教組織・信徒数・神父数を確定できない。これらしかない都市は「所属未確定」の候補にする。
3. 「信仰分布から拠点を補完」をユーザーが別途実行した場合のみ、組織への対応規則と推定信徒比率を指定し、拠点案・都市信徒数 U・信頼度をプレビューする。世界人口係数を適用した都市人口を使う。同じ宗教に複数組織がある場合は配分を要し、各組織へ全信徒数を重ねて与えない。
4. 明示的に全都市へ布教拠点を置く設定も可能だが、「既存拠点の司祭を生成」と区別する。拠点がない都市を、聖職者が未生成な都市として数えない。
5. 現行の都市 Cleric 席は所属を確定してから新組織の役職へ対応付け、人物とメモを保持する。名称が Cleric だけという理由で教会型組織に所属させない。

## 御用商人と有力経済人

御用商人は商会の種類ではなく、顧客である国家・宮廷・家・宗教法人との関係。契約は `patronOrganizationId / supplierOrganizationId / representativeSlotId / domain / validFrom / validUntil` を持つ。個人商人の場合も商人事業体を介して参照できる。御用契約を生成しただけで売上・国庫支出・兵站供給が増えないよう、経済処理との接続は別途明示する。

既存契約がない組織には「御用商人の設定案」を提示できる。初期案は次の品目別の窓口で、別々の商人が必要という意味ではない。

| 顧客 | 設定案の窓口 | 席・人物の数え方 |
| --- | --- | --- |
| 王室・中央政府 | 食料・生活必需品、武具・軍需、金融・遠隔交易の 3 窓口 | 契約ごと担当 1。単一商会・同一担当なら 1 人でもよい |
| 主要領主家 | 食料・家政、武具の 2 窓口 | 家ごとに必要性を指定。領主全員へ自動契約しない |
| 教会・修道院 | 食料・日用品、建築・典礼用品の 2 窓口 | 自給・自営なら外部委任なしも可 |
| 軍組織 | 補給品の 1 窓口から開始 | 補給責任者は内部役職、御用商人は外部契約担当なので区別 |

「全国家・全貴族の御用商人」は選択顧客の有効な契約代表の和集合。「御用商会の幹部まで」は担当代表と商会役職の和集合。契約相手が未設定なら不足件数として示し、近隣の商人を黙って御用にしない。

ギルドは都市×職能だけでなく法人 id を持てるようにし、同じ都市・職能で複数法人がある世界も扱う。現行の知識ストック由来ギルドは既存 id を引き継ぐ。ギルド長の職業はその職能を基本とするが、商会書記・会計・護衛は役割に合う職業・技能を使う。

## 操作と保存

世界・国家・組織の各画面に「プリセットで選ぶ」を置く。選択画面で、種類、対象国家/組織、直接所属/下位を含む、活動地域、基本/拡張、既存人物の扱いを指定する。主所属と活動地域の条件は AND/OR を明示し、「国内で活動」だけなら国外本部の国内支部も拾う。世界画面ではすべての有効国家が既定、国家画面ではその国家が既定になる。

結果は `国家または越境組織 → 組織 → 役職 → 個人枠` で表示。種類を混ぜず、組織名・役職名で安定ソートし、パンくずと選択条件をタブ切り替え後も保持する。各行に以下を表示する。

- 役職・職業・所属・勤務地・管轄、定員と根拠、適用した制度プロファイル。
- 対象席数、在職個人枠数、生成済み実人数、今回の新規人数、空席、未確定の兼任・所属。
- 除外理由、プロバイダー不足、ロック競合。数値が未確定なら「人数未確定」とし、0 と区別する。
- 既存 Character は再利用し、名前・メモ・所在・家族・錠前を変更しない。役職に不整合があれば要確認にし、置き換えない。

複数プリセットを同時選択できる。必要席・人物を和集合にしてから生成計画を固定し、確認以後の新設組織は勝手に対象へ加えない。対象の就退任・廃止が変わった場合は実行前またはバッチ境界で再検証し、変化分を表示して再確認する。完了済みの人物は保持し、中断後は未完了分だけ再開する。

保存対象はプリセット定義の id/版、選択条件、任意の独自ラベル、生成計画と完了キー。既定プリセットの将来更新で保存済みの独自条件を無言変更しない。「この条件を再実行」は現時点の在職者を再検索し、「中断計画を再開」は固定済み計画を使う。

## 実装用の分類と検索契約

`roleClass` は生成能力等の既存用途を維持し、検索に必要な意味を別の安定キーで追加する。表示名・翻訳文・id の末尾による職種判定をプリセット本体に書かない。

| 追加要素 | 内容 |
| --- | --- |
| 組織の種別 | government / household / military / religious / company / guild / market 等。軍編制・宗教法人は下位種別を持つ |
| 役職の意味キー | headOfState、headOfGovernment、centralExecutive、unitCommander、secularLord、territorialAdministrator、religiousHead、bishop、urbanClergyLead、parishClergy、companyHead、guildHead 等 |
| 役職の属性 | 権限・世俗/宗教・制度上の層・職業候補・互換プロファイル・兼任規則・選択根拠。`landed` だけで貴族を判定しない |
| 組織の地理・所属 | nullable な本拠国、活動国一覧、配置拠点、地理的管轄、宗教/宗教組織の参照。単一 `stateId` は互換用とし、越境組織を架空国家へ入れない |
| 関係の型 | patronage、religiousAffiliation、jurisdiction、branchOf 等の期間付き関係。法人と個人枠は型付き参照で区別 |
| 複合選択 | roleIds / seatKeys / slotIds の集合と理由、基準日時、入力台帳版、重複排除済み実行計画 |

定員の席キーは役職 id＋ordinal、在職個人は就任期間に対応する安定 id を使う。後任に同じ個人 id を再利用しない。複数 Appointment の同一人物化をモデル・生成・集計で一貫させる必要がある。現行 PersonSlot の単一 `roleId / organizationId` だけを正本にすると兼任を失うため、主所属の表示用参照として残し、有効な Appointment 群を在職の正本にする。

各プロバイダーが意味キーと人数根拠を供給し、検索エンジンが `条件 → 対象席 → 有効在職枠 → 重複排除 → 未詳細化枠` を返す。NPC 生成器はその結果だけを詳細化し、組織探索や制度補完を内部で行わない。

## 数値例

すべて説明用の世界で、未知の兼任・空席なしとする。

| 条件 | 対象席数 | 対象実人数 / 今回新規 |
| --- | --- | --- |
| 単独元首の国家 4、全員未詳細化で国家元首を選択 | 4 | 4 / 4 |
| 上記で首脳へ拡大、中世基本 6 席/国、先に作った元首以外は兼任なし | 24 | 24 / 20 |
| 陸上部隊 9、艦隊 3。うち陸上部隊長 1 人は既存軍務長官の兼任 | 12 | 12 / 11（首脳の生成後） |
| 主要領主職 30、在職者 26 人。うち 2 人は首脳として詳細化済み | 30 | 26 / 24 |
| 3 国に跨る教会の都市拠点 18、司教区 3。本部首長 1。各都市代表と司教・首長は別人 | 都市代表のみ 18、上層部追加で 22 | 未詳細化なら 18 / 18、追加込み 22 / 22 |
| 上記の 18 拠点のうち信徒 7,000 人の都市が 1、他は各 3,000 人以下。神父全員を選択 | 都市教区 20（3＋17）。都市代表の独立加算なし | 未詳細化なら 20 / 20。先に都市代表 18 人を作成済みなら 20 / 2 |
| ギルド 12、商会 5、市場 8。互いの代表兼任なし | 長だけ 12＋5＋8＝25 | 未詳細化なら 25 / 25 |
| 御用契約 16、担当商人 9。そのうち 4 人は詳細化済み商会主 | 16 の契約担当関係 | 9 / 5（契約数は役職定員に加算しない） |

複数行の人数をそのまま合算して世界の人物総数としない。各対象の個人枠 id の和集合で集計する。

## 実装順と受け入れ条件

1. 役職の意味分類・人数根拠と複合選択を追加。元首、首脳、軍事指揮官、主要/全領主、都市責任者、商会主、ギルド長のプリセットを既存台帳に接続する。
2. 型付き関係と御用契約、越境組織・宗教拠点を追加。所属未確定の都市聖職者を移行し、宗教上層・都市司祭プリセットを有効化する。
3. 幕僚・家政・ギルド役員等の制度編集、補完案、独自プリセットの保存・再実行を追加する。未対応項目は理由付きで無効表示する。

受け入れ条件:

- 一覧・プレビュー・条件保存だけでは Character、契約、教区、定員が増えない。
- 元首→首脳、司教→宗教領主、御用担当→商会主の順序を変えても、同一枠を二重生成しない。同一入力・個人枠の詳細は選択順に依存しない。
- 軍団未分類、小部隊、非王制、非封建王制、無政府状態、共同統治、職位空席を区別し、存在しない元首・領主・軍団長を補わない。
- 一つの越境教会の同一司教を国ごとに複製しない。国外支部と少数派拠点を活動地域から検索できる。
- 宗教拠点・兼任が未確定なら、未確定件数を示し、確定範囲だけの実行を選べる。
- プレビューと実行の新規人数が一致する。ロック済み・既存人物は保全し、真の空席の選任は別操作にする。
- 大規模な選択は分割・中断・再開でき、NPC を作っても人口・兵力・収入・契約支出を増やさない。
