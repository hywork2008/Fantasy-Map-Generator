# GROUP別の集落生成と道路接続の分離

2026-10-03のユーザー提案に基づく設計案。実装済みの機能ではない。

## 現状

FMGの既定GROUPはcapital、city、town、village、hamlet、fort、monastery、caravanserai、trading_post。GROUPは編集・追加可能である。fortにはcitadel=true、walls=false、plaza=false、port=false、caravanseraiにはport=false、plaza=true等の属性を与えているが、CEではburg.groupを生成方式の選択に使っていない。Standaloneのサイズ、layout、Feature設定も建物用途と外部道路の接続を十分に表現していない。

## 設計

GROUPから生成プロフィールの既定値を選ぶ。ただしGROUPそのものに道路数を固定しない。人口規模、集落の機能、街区配置、外部道路の接続、時代・文化の建築様式を別の設定とする。

FMG入力の外部道路は入力された陸路の形状と境界到達を正本とし、プロフィールを理由に追加しない。Standaloneでは外部接続を明示してから合成道路を作り、その道路に対応する出入口だけを計画する。最低3出入口の補充は廃止する設計とする。

| GROUPまたは生成プロフィール | 建物・配置の既定案 | Standaloneの接続既定案 |
| --- | --- | --- |
| capital / city / town | 民家・商業・行政・宗教施設。規模と時代に応じて構成 | 分岐型。初期3方向、変更可能 |
| village / hamlet | 民家・農作業施設主体 | 通過2方向、末端1方向等を選択 |
| post_town（新しい生成プロフィール） | 街道沿いの細長い町並み、宿、馬屋、荷扱い・中継施設 | 通過2方向 |
| caravanserai | 宿泊・倉庫・家畜置場と中庭を持つ複合施設。周辺集落は別に扱う | 通過2方向。施設の入口数とは別 |
| trading_post | 交易・倉庫・荷扱いを中心に小さな居住部分 | 末端1方向を既定、通過や分岐へ変更可能 |
| fort | 駐屯施設、兵舎、指揮所、物資庫、訓練空間、必要に応じて厩舎 | 接続路1方向を既定、変更可能。防御門数とは別 |
| monastery | 宗教施設、共同居住、食堂、作業・菜園等 | 接続路1方向を既定、変更可能 |

上表の本数は歴史的な必須条件ではなく、Standaloneの初期値案。宿場にも街道の分岐点があり、fortも幹線上に置ける。外部接続が2方向でも中庭施設や砦の門を2個にする必要はない。

### 宿場町と隊商宿

旅行者と荷物の移動を支える機能を共通プロフィールとして再利用し、形態を分ける。

- 宿場町: 街道に沿う町並みと複数の宿・居住・商業施設。日本の宿場には本陣・脇本陣、旅籠、馬や人足の中継を扱う問屋場／人馬会所がある。
- 隊商宿: 中庭を囲む宿泊・交易施設を持つ形態を選択可能とする。すべてのcaravanseraiを同じ平面へ固定しない。

参考: [国土交通省・矢掛の歴史地区](https://www.mlit.go.jp/tagengo-db/R6-00470.html)、[国土交通省・妻籠宿の人馬会所](https://www.mlit.go.jp/tagengo-db/R1-01502.html)、[UNESCO・The Persian Caravanserai](https://whc.unesco.org/en/list/1668/)、[ICOMOS評価書](https://whc.unesco.org/document/199666)。

### fortの人口・住宅

fortを民家中心の都市にcitadelを付けるだけの表現にしない。居住需要を世帯用住宅と共同宿泊・兵舎の収容力に分ける必要がある。FMGのdwellingsをそのまま「兵舎の建物数」に換算しない。既存の住宅比較CSVにも、民家数と共同居住の収容力を混同しない指標が必要になる。

## 実装順序案

1. FMG入力の外部道路と出入口の対応を修正し、本数補充・放射方向のフォールバックを分離する。
2. Standaloneへ接続形式（通過2／末端1／分岐3・4／孤立0）を追加し、共有リンクに保存する。
3. GROUPからのプロフィール解決と明示指定を追加する。未知・カスタムGROUPは通常集落にフォールバックし、明示プロフィールを優先する。
4. 街道沿いの宿場型と中庭型の隊商宿を生成する。
5. fort／monasteryの専用建物構成と人口収容力を実装する。

旧リンクは既存の合成・用途設定を再現できる互換処理を用意する。新しい道路修正で見た目や住宅数が変わる箇所を回帰テストとCSVで確認する。
