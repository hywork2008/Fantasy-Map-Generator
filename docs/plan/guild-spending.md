# ギルドの金庫を町で使う（guild-spending）

## 1. 問題

[town-money-drain-20261114.md](../analytics/town-money-drain-20261114.md)で、地図2102の町の家計が年ごとに減るのは、お金が地図から消えるのではなく、ギルドの金庫に年約13万が溜まって戻らないためだった。ギルドは作った品の売上（税の後）の35%（guildTreasury.ts `GUILD_PROFIT_SHARE`）を受け取るが、使うのは知識への支出と親方の手当（年約0.4万）と、町の金庫が快適な水準を下回った時の払い戻し（`payoutStrugglingBurg`）だけで、金庫に上限も他の使い道もない。

## 2. 史料

- 中世のギルドと兄弟団（confraternity）の会計は、会費・入会金・罰金で集め、守護聖人の祝日の宴、礼拝堂の灯りと司祭、会員の葬式と追悼のミサ、病気や貧しい会員と寡婦の救済、施しに使った（ロンドンの同業組合の記録、イングランドのギルドの1389年の申告）。
- 金庫に大きな額を持ち続けることは少なく、多くは年ごとに使い切るか、土地や家を買って地代を得た。

## 3. 設計

- 設定`guildSurplusUse`
  - `spend`（既定）：毎月の生産の後（production-generator.ts、`payoutStrugglingBurg`の後）、各ギルドは金庫のうち手元に残す分を超えた額の`guildSpendRate`（既定0.08、0〜0.5）を、その町の家計に払う（`creditHouseholdWealth`）。
  - `keep`：今までの決まり。
- 手元に残す分は、親方の手当（`GUILD_MASTER_STIPEND`）の`guildReserveMonths`か月分（既定1、0〜24）。新しいギルドを作る時の元手（`seedNewGuildWorkingCapital`）と違い、乱数を使わない決まった値にする。
  - 最初の案は12か月分（地図2102で201.6）だったが、地図2102のギルドの金庫は6,433あり、1か月後の平均は約7で、12か月分を超えたのは4つだけだった（[guild-spending-20261114.md](../analytics/guild-spending-20261114.md) §3）。ほとんど使われないので1か月分にした。
- 毎月8%なら、ギルドの金庫は収入の約1年分で落ち着く。兄弟団は会費をその年のうちに使った。
- 払う先は町の家計だけにする。祝宴の食べ物や灯りの蝋燭を品として買う形にはしない。

## 4. 未確定事項

- ギルドの使う額のうち、教会の灯り（蜜蝋の蝋燭）や祝宴の食べ物として品を買う分は入れていない。
- 土地や家を買って地代を得ることは入れていない。
- 新しいギルドの元手の乱数（`backPayCycles`）と、手元に残す分の決まった値は合わせていない。
- 親方のいない小さなギルドの金庫（ほとんどが数か月分の手当より少ない）を、どう扱うかは決めていない。

## 5. 結果

[guild-spending-20261114.md](../analytics/guild-spending-20261114.md)（地図2102・2103、36か月）。

- 最初の案（手元に12か月分、毎月5%）では、手元に残す分を超えるギルドがほとんど無く、金庫は増え続けた（§3の変更の理由）。
- 手元に1か月分、毎月8%では、ギルドの金庫は2年目の終わりから増えなくなり、2102で約17.5万、2103で約10.5万で落ち着いた。
- 町の家計は36か月目に+20%（2102）・+23%（2103）。作った品と使った品の差は2%以内。
- 同じ暦の月で比べると、町の家計は2年目にまだ減る。ギルド以外の動きは次の課題とする。
