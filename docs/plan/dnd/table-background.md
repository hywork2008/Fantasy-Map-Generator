## 0. 結論

FMG を 5e の卓の背景にする変更は、**中世ヨーロッパで校正した経済と人口を、卓が読める形に出すこと**と、**人が死ぬ理由に脅威の死を足せること**である。5e の価格表、クラスの人口、町ごとの常勤司祭で、校正を置き換えない。

卓が使うのは次の四つである。

1. **町の摘要。** 人口、今いる席、今月その席がしていること、店頭の値段、近くの危険、直近の死因。新しい住人は作らない。
2. **席の活動。** 月の解像度で、役職と既にある世界の状態からラベルを出す。一日の日程は持たない。
3. **背景ラベル。** 5e の背景名は、既存の席の読み替えである。能力値、技能、起源の特技は持たない。
4. **脅威の死。** `DeathCause` に `predation` を足す。脅威の生成が `none` の地図では 0 である。既定の設定はオフで、今の人口動態と同じである。

100 万人の王国に名前のある冒険者 500 人は置かない。0.05% は国家への注記であり、Character ではない。割合は地図生成のオプションで、既定は 0.05% である。治療とポーションは、小さい都市へ回せるほどは作らない。結果として大都市にしか出回らない。全ての町の神殿が売る状態にはしない。

## 1. 範囲

対象は、卓が一つの町と一つの国家を読むときに足りない出口である。

次は本書では変えない。

- セル収量、畑と漁の人手、財の基準価格、職業の人数、生活費の段、銀貨を内部単位にする換算。
- 脅威の発生、Danger が居住適合 `s` を下げる式、Cultures set が Marches と脅威を束ねる結合、軍隊の討伐年数、仕事板の報酬。
- 冒険者を manpower の台帳へ入れること。復活を人口の死因から引くこと。衛生と疫病の経路。
- 呪文データ、魔法の品のデータを入力にすること。
- 世界生成時の NPC 一括生成。

5e のプレイヤーキャラクターは、FMG の Character でなくてもよい。既に操作している人物がいるときは、その人物の滞在 Burg、店頭の売買、請けた仕事を摘要に含める。クラスレベルは FMG に保存しない。

## 2. 卓が世界に聞くこと

摘要が答える質問は、この七つに限る。答えの材料がシミュレーションに無い質問は、空欄のままにする。文を作って埋めない。

| 質問 | 材料 | 材料が無いとき |
| :--- | :--- | :--- |
| この町はどれくらいか | Burg の人口、市場、所属、城壁の有無 | 人口 0 なら摘要を出さない |
| 誰がいるか | この Burg を対象にする役職の席。生成済みなら名前、未生成なら席の名だけ | 席が無い職は行を出さない |
| 今月何をしているか | §5 の活動ラベル | 既定は `in_seat` |
| 何が買えるか | その Burg の店頭在庫と現在の値段 | 在庫 0 は「今は無い」 |
| 治療や魔法の品は買えるか | 置いていない | 行は「売っていない」。`common` を採るまで埋めない |
| なぜ危ないか | 町のセルの Danger、最も近い怪物の名前、開いている討伐の仕事 | 脅威モード `none` では危険の行を出さない |
| 最近何が起きたか | 直近の死因、価格の大きな変動、席の空き | 事象が無い行は省く |

噂の生成器、クエスト文、ダンジョンの中身は作らない。討伐の仕事が既に掲示されているなら、その掲示を摘要が示す。

## 3. 死因は既存の台帳に脅威の死を足す

### 3.1 今ある死因

`DeathCause` は `combat`、`famine`、`natural`、`disease`、`other` である。人口概況は国家ごとの人数を、直近約 40 日分だけ持つ。

`simulateDemographics` はセルと Burg の両方で、子供、成人男性、成人女性、老年を持つ。自然死として数えるのは老年と子供である。飢餓は収容を超えたときの減少、疫病は水の安全が閾値を下回る Burg の減少である。戦闘死は兵力と会戦から入る。`other` は都市労働の移動などで使われている。

Danger は居住適合を下げ、住む人を減らす。これはストックである。死因は、住んでいる人からのフローである。適合を下げる式に、同じ危険を死因としてもう一度掛けない。

### 3.2 足すもの

`predation` を死因に足す。意味は、獣と怪物による人の死である。盗賊と戦争は `combat` と `other` のままである。標準の Cultures set（脅威モード `none`）では、この死因を 0 のままにする。中世の校正地図の死亡を、後から怪物の死へ読み替えない。

対象は成人男性と成人女性だけである。子供と老年の死は、今どおり自然死である。アンデッド国家（`isUndeadState`）には掛けない。

死亡率は、今の `cells.danger`（0〜255）から取らない。この数値は仮の加算で、設計が練られていない。人類の国家では勝つのが難しい rarity 5 が居座っていても 255 には届かない。人類が倒せる範囲の弱いものが密集すると、加算で 255 になる。同じ 255 が、災厄の膝元と、弱い群れの重なりの両方を指す。数値の大小で死の桁を決めると、この二つが入れ替わる。

rarity 5 の近くに人がいるときの死は、成人 1,000 人あたり年 8 人ではない。数万から数十万人が、数日で死ぬ。日数と人数の式は、危険度をやり直してから置く。[danger-layer.md](../danger-layer.md) の rarity 5 は、想定として CR 25〜30+（神格・エピック級）と書かれている。その帯は実装された尺度ではない。D&D 準拠で死因を脅威に結ぶときは、CR とその分布を設計し、実装してから年率を書く。

採用しない比例は、記録として残す。`fullDangerRate = 0.008`、`floor = 32`、危険度 255 の農村で成人 1,000 人あたり年 8 人、城壁で 0.15、という読みである。コードの既定にはしない。

設定がオフのあいだは死亡 0 である。人口動態へ入れる場所は、成人のバケットと `recordDeaths(stateId, people, "predation")` のままである。人口ポイントから表示人数への倍率は、自然死と同じ `populationRate` を使う。子供と老年の式、疫病の式、適合 `s` の式は、危険度のやり直しでも動かさない。適合の減衰と死因は、別の掛け算のままである。

### 3.3 名前のある人物

名前のある人物は人口ポイントの外側の顔である。顔の死を、人口の減少に足し引きしない。

そのステップで、そのセルまたは Burg の `predation` が 1 人以上あるときに限り、そこに席を持つ生存者から 1 人を、その死亡の顔にする。選択は自動で行う。手で置く事象にはしない。確率は、その場の成人に対する今回の死亡数の割合を超えない。死亡が 1 人未満の村では、村長は死なない。顔が死んだら Character の死亡として席を空け、人口概況の人数は人口動態が記録した人数のままである。顔の分を `recordDeaths` に足さない。年率が危険度のやり直し待ちなので、この自動選択もそれより前には動かない。

復活で一人を戻す接続は、[magic-agrarian-economy.md](magic-agrarian-economy.md) §10 の 6 で決めた。席と、その一人の人口を同時に戻す。本書の実装順には入れない。捕食の死亡を、復活の式で帳消しにはしない。

### 3.4 討伐との関係

軍隊の討伐と仕事板は、既存のとおり Danger を下げる。翌年の `predation` は、やり直したあとの危険度を読む。今の 0〜255 を閾値にして 0 にはしない。討伐の完了に、追加の死亡ボーナスは掛けない。一度の仕事で、その国の脅威の死を 0 にはしない。

### 3.5 保存

古い保存データの死因合計に `predation` が無いときは 0 として読む。過去の死亡を再分類しない。設定がオフの地図は、人口の数値が今のビルドと同じである。

## 4. 経済は校正した台帳のまま、町の札だけ足す

### 4.1 正本

値段、在庫、賃金、生活費の正本は、今の経済である。内部単位は銀貨である。金貨と銅貨は表示の換算であり、既定は 12 進である。5e で慣れた 10 進の金貨換算は、全体の表示には導入しない。同じ財布が画面ごとに別の枚数になる。

町の札は、滞在する Burg の店頭から、そのときの値段を写す読み取り専用である。札が値段を決めない。

札に出す品は、既にある財のうち卓が最初に聞くものに限る。

| 札の行 | 読み元 |
| :--- | :--- |
| 主食を 1 人・日 | その市場の主食価格と、1 人・年 200 kg からの 1 日分。台帳の荷の単位で割り、新しい財は作らない |
| 飲み物 1 杯分 | 店頭にあるエール、ワイン、蜂蜜酒のうち最も安いもの。単位は既存の小売ロット |
| 履物 | 店頭の長靴。在庫が無ければ行だけ「今は無い」 |
| 刃物 | 店頭に武器の財があるときだけ、その財の名と値段。無い町に長剣の定価を置かない |
| 寝泊まり | 宿屋の財は無い。行は、`common` の生活費（生産サイクルあたり 0.15 銀貨）を 1 日に割った参照値であり、購入ボタンは付けない |
| 治療、ポーション | 供給が届いた大都市の店頭だけ。小さい都市は「売っていない」。生産量でそうなる（§4.3） |

日雇いの賃金は、その Burg の労働市場に表示用の賃金があるときだけ札に添える。無いときは生活費の参照値だけを残す。

名前のある人物の生活費（徒弟の小遣いから君主の宮廷まで）は、その人物の画面に既にある。5e の日額生活表では置き換えない。札に「5e の生活水準」の列は作らない。

### 4.2 パーティーが買うとき

購入は、既存の Character Market の店頭売買である。摘要からの購入経路は作らない。一隊が 1 週間の食料を買っても、王国の需給の項は足さない。冒険者 500 人分の需要を市場から引くかどうかは、農業文書の未確定のままである。本書は引かない。

ポーションと魔法の品を皮革・穀物・武具の在庫に混ぜない。怪物の素材も、皮の市場へ流さない。

### 4.3 治療が町にある、にしたいとき

治療とポーションは、全ての町では売らない。小さい都市に回せるほどは生産しない。結果として大都市にしか出回らない。禁止の町リストは置かない。作る量が足りないので、小さい都市の在庫が空になる。

大都市の人数の閾値と、1 年に作る量は、まだ置かない。置くときも、主食・皮革・武具の在庫には混ぜない。村の司祭を冒険者枠の外の常勤にはしない。0.05% の注記（§7）から、町へ術者を配分しない。摘要の行は、その Burg の店頭に在庫があるときだけ値段を写す。無い町は「売っていない」である。

## 5. NPC は席と月の活動で足りる

### 5.1 誰を人物にするか

人物は、今の台帳と同じである。国家、軍、領主、都市の代表、市場の管理者と商人、ギルドの長、教会の席を、ユーザーが生成したときに名前がある。鍛冶職人の全員、農民の全員、兵士の全員は、職業の人数のままである。5e の背景を揃えるために、隠者、放浪者、孤児、芸人、犯罪者の人口は作らない。

未生成の席は、摘要に席の名だけを出す。クリックで生成する操作は、既存のプリセットに残す。摘要を開いただけでは Character を作らない。

### 5.2 活動は月のラベルである

活動は Character の位置を変えず、生産も変えない。既存の効果が既に労働を動かしているとき（町の刈り入れ手伝い、戦争、討伐）、ラベルはそれに合わせる。ラベルのために二本目のカレンダーは持たない。

解像度は月である。週の市、一日の時間割、時刻は持たない。シミュレーションが月より細かくその人の居場所を知らないためである。

| ラベル | 条件 | それ以外 |
| :--- | :--- | :--- |
| `in_seat` | 既定 | |
| `on_campaign` | 所属国家が戦争中で、役が指揮官である | 平和なら `in_seat` |
| `on_cull` | その国家に進行中の軍隊討伐がある指揮官、または請けた討伐仕事が開いている人物 | 掲示が無い町の住人には付けない |
| `on_route` | その商人個人に、出発地と到着日を持つ輸送が結び付いている | 結び付きが無い商会主は `in_seat`。市場の輸送在庫だけでは人を外に出さない |
| `retired_local` | 役を辞し、その Burg で地域貢献の対象になっている | |

町の行として、既存の農事暦からその月の農村の仕事を一つ出す。播種、干し草、刈り入れ、屠畜のいずれか、暦が示すものだけである。これは無名の農村人口のラベルであり、ギルドの親方を畑へ移動させない。親方が工房にいることと、町の職人が刈り入れに出ていることは、別の行である。南半球で暦の月が反転する既存の扱いがあるなら、それに従う。無い文化に、北半球の月を新設しない。

プレイヤーが請けている建設または討伐の仕事は、その人物の活動として既にある状態を出す。新しい仕事の種類は足さない。

### 5.3 技能と性格

9 能力と 12 性格は、今の人物の画面に残す。5e の 6 能力値へ変換しない。武勇が高い人物をファイターとして数えない。変換表を置くと、軍の 1% と冒険者の 0.05% が同じ人物の上で二重になる。

## 6. 5e の背景は席の読み替え

背景は表示用の内部 id である。2014 年版と 2024 年版で英語の通称が違うものは、内部 id を一つにし、表示名の表を後で差し替えられるようにする。背景の特徴文、技能の一覧、起源の特技は書かない。

| 内部 id | 付ける席 | 付けないもの |
| :--- | :--- | :--- |
| `noble` | `ruler`、`central_officer`、`province_lord` | 裕福な商人 |
| `soldier` | 連隊の指揮官、艦隊の指揮官 | 町の守備だけを持つ城代。城代は `guard` |
| `guard` | 都市の城代、守備の席 | 野外の連隊 |
| `acolyte` | `religious`、神殿の Cleric の席 | 学識が高いだけの役人 |
| `artisan` | ギルドの長、ギルドの徒弟の席 | 市場の管理者 |
| `merchant` | `merchant`、市場の管理者、商会の代表 | 親方 |
| `sailor` | 船の席、港の海上の役 | 港町に住むだけの人 |
| `farmer` | 農村の名主または荘の役が席としてあるときだけ | 州の人口からの自動割り当て |

次の背景は自動では付けない。`charlatan`、`criminal`、`entertainer`、`hermit`、`outlander`、`sage`、`urchin`、`folkHero`。悪徳商人の二つ名は、`charlatan` の自動付与にしない。ユーザーが人物メモでどれかを選んだときだけ、その id を保持する。メモはシミュレーションを変えない。

一人が複数の席を持つときは、既存の生活費と同じく、最も高い身分の席の背景を一つ出す。ほかの席は肩書として残る。背景を二つ装備させない。

## 7. 冒険者は人数の注記であり、名簿ではない

[magic-agrarian-economy.md](magic-agrarian-economy.md) の基準（人口の 0.05%、うち術者 38%、階層の割合）を、国家の人口に掛けた整数の注記として出せるようにする。出力は人数の表である。Character、クラスレベル、所在地の町、は作らない。

100 万人なら、活動中 500、階層 1 が約 350、階層 2 が約 120、階層 3 が約 25、階層 4 が約 5、という既存の切り上げである。端数は国家ごとに四捨五入し、世界合計を別途合わせる処理はしない。人口が小さい国家では 0 でよい。

この注記は、脅威の死の率にも、店頭の需要にも、神殿の治療にも掛けない。掛けると、0.05% が経済と人口を動かし始める。農業文書が避けたものである。

割合は地図生成の設定 `adventurerActiveShare` で、既定は 0.0005（0.05%）である。0 のとき注記は出さない。0 より大きいとき、国家画面の注記はその割合を使う。軍の 1% を超える値は警告する。画面に出すこと自体は人口も店頭も変えない。

## 8. 町の摘要

純粋関数が、Burg 一つと、そのときの世界の読み取り専用の状態から、次の塊を返す。描画の置き場は後回しである。町の編集に固定しない。いくつかの街を統括する、冒険者ギルド地方支部のような席を置く予定で、摘要はその側で読む。支部の数、管轄、経済は本書では設計しない。人口概況のダイアログには、国家の死因列として `predation` を足す。摘要の本体は、その支部から見た町である。

塊:

1. 人口、市場名、国家、州、城壁の有無。
2. この Burg に対象を持つ席。名前または「未生成」。背景 id。活動ラベル。
3. 農村の今月の仕事が暦から取れるとき、その一行。
4. §4 の札。
5. 脅威モードが `none` でないとき、この町のセルの Danger、最も近い怪物の名前とレアリティ、開いている討伐掲示。
6. 直近 40 日の、この国家の死因。町単独の死因は集計が国家単位なので、町の数としては出さない。
7. 同じ 40 日に、この町の席が空いた、または埋まった事実があるとき、その一行。

文章の地の文は組み立てない。各行はラベルと値である。

空の町、市場の無い町、拡張が無効で席が読めない町でも落ちない。読めた行だけを出す。

## 9. 設定

| 設定 | 値 | 既定 | 意味 |
| :--- | :--- | :--- | :--- |
| `tableBrief` | on / off | off | 摘要を出す。描画の置き場は冒険者ギルド地方支部まで接続しない。off でも経済と人口は今と同じ |
| `threatMortality` | off / on | off | on でも、危険度をやり直すまで成人は減らさない。オフでは `predation` は 0 |
| `adventurerActiveShare` | 0〜0.01 | 0.0005 | 地図生成のオプション。活動中の冒険者の割合。0 なら注記は出ない。0.01 は軍と同数なので警告する。人物は作らない |

`tableBrief` が off でも、`threatMortality` は独立である。摘要の置き場が後回しでも、死亡率の欄は別である。危険度をやり直す前は、on でも死亡は 0 のままである。

脅威モード `none` では、`threatMortality` が on でも式の結果は 0 である。設定の組み合わせで、標準の地図の人口を変えない。

保存した地図に `threatMortality` と `tableBrief` が無いときはオフとして読む。`adventurerActiveShare` が無い保存は注記を出さず、0 として読む。新しく生成する地図の既定は 0.0005 である。マイグレーションで人口を書き直さない。

## 10. 決定

1. **卓の背景は、校正したシミュレーションの読み出しである。** 5e の価格、生活費、クラス人口を正本にしない。
2. **新しい住人は作らない。** 名前は既存の席の生成に限る。冒険者 0.05% は国家の注記である。
3. **活動は月のラベルである。** 位置と生産を変えない。カレンダーを新設しない。
4. **背景は席からの表示ラベルである。** 隠者、犯罪者、芸人、学者、放浪者、孤児、民衆の英雄は自動生成しない。6 能力値へは変換しない。
5. **死因 `predation` は、脅威モードが `none` でない地図の成人にだけ足す。** 子供と老年は自然死のまま。Danger の適合減衰はそのままである。既定はオフ。年率は今の 0〜255 から取らない。
6. **顔の死は自動で、そのステップの人口死の代表にする。** 人口概況に人数を足さない。復活は死因を消さない。年率が動く前には選ばない。
7. **治療とポーションは、小さい都市へ回せるほどは作らない。** 結果として大都市にしか出回らない。主食・皮革・武具の在庫には混ぜない。全ての町の神殿が売る状態にはしない。
8. **硬貨の 12 進は維持する。** 10 進の表示モードは足さない。
9. **冒険者の割合の既定は 0.05% で、地図生成のオプションで変える。** 名簿は作らない。
10. **摘要の置き場は後回しにする。** いくつかの街を統括する冒険者ギルド地方支部を置く予定で、町の編集に固定しない。
11. **農村の名主の席は新設しない。** `farmer` を付ける席が無い町では、背景を空のままにする。

## 11. 実装の順

各段は、前の段のテストが通ってからにする。人口を変えるのは、危険度をやり直したあとの 4 だけである。4 は、そのやり直しの設計が終わるまで書かない。摘要の描画（2 の UI）は、冒険者ギルド地方支部の設計まで書かない。

1. **死因の欄。** `DeathCause` と人口損失の合計、テレメトリの複製、人口概況の列に `predation` を足す。記録関数は 0 のまま呼べる。古い保存は 0。関連テストは `populationLossTracker.test.ts` と人口概況が合計を読む箇所。人口動態の式は変えない。
2. **摘要の純粋関数と札。** フィクスチャの Burg、席、店頭から §8 の塊を作る。描画は後回しで、`burg-editor` に節を足さない。購入は付けない。価格の計算テストは、既存の市場価格を写すことだけを見る。治療とポーションの行は、在庫が無い町で「売っていない」になることだけを見る。
3. **活動と背景。** 席と月と戦争・討伐のフラグからラベルと背景 id を返す。`farmer` の席は新設しない。生産量の期待値は変えない、を既存の雇用テストの対象外のままにして、この関数の単体テストだけを足す。
4. **脅威の死。** 危険度のやり直しと、D&D 準拠なら CR とその分布の実装のあとで、`threatMortality` が on のとき成人バケットから引く。テストは、脅威モード `none` で人口がビット単位で今と同じこと、rarity 5 の近傍が年 8/1,000 の比例にならないこと、子供の自然死が `predation` に混ざらないこと。今の危険度 255 を合格基準にしない。地図全体の多シード検証はしない。
5. **顔の死。** 4 で 1 人以上死んだセルに席があるときだけ、代表を 1 人まで自動で選ぶ。人口概況の合計が増えないこと。
6. **冒険者の注記。** 地図生成の `adventurerActiveShare` が 0 より大きいとき、国家画面に人数の表を出す。既定は 0.0005。セル収量、需要、Character 生成には接続しない。

## 12. 採用しない読み

- 5e の装備価格（長剣を金貨十数枚、など）を、市場の武器の `value` に書き込む。校正した銀貨価格と、卓のゲーム価格は別の体系である。
- 3.5e の町生成で、1 レベルのクラス保持者を人口の数パーセント置く。軍 1% と二重になる。農業文書 §9 と同じく採らない。
- ギルドの親方、司祭、宿の主人を、町の人口あたり一定人数で新しく生成する。席が無い職は、摘要に行が無い。
- 脅威の死を `natural` や `other` に混ぜて、列を増やさない。卓が「FMG の死因に何が足されたか」を見られなくなる。
- Danger の適合減衰を弱めて、その分を死因に移す。ストックとフローを相殺すると、居住の分布が動く。
- ポーションを薬種ギルドの生産にする。需要の転移は、濃さ `common` を採る設計まで始めない。
- 摘要の文章を、出来事のテンプレートから生成する。値の無い行を、それらしい文で埋めない。

## 13. 決定した事項

1. **脅威の死の年率は、今の危険度からは取らない。** 0〜255 は仮の加算である。人類の国家では勝つのが難しい rarity 5 が居座っていても 255 に届かず、人類が倒せる弱いものが密集すると 255 になる。この数値で判断すると矛盾する。危険度の再設計が先である。D&D 準拠にするときは、CR とその分布を設計し、実装する。rarity 5 の近くでは、数万から数十万人が数日で死ぬ。成人 1,000 人あたり年 8 人にはしない。実装の 4 は、その再設計のあとである。
2. **治療とポーションは大都市にしか出回らないようにする。** 小さい都市に回せるほどは生産しない。禁止リストではなく、供給不足の結果である。全ての町の神殿が売る状態にはしない。大都市の閾値と生産量は、その品を設計するときに置く。
3. **活動中の冒険者は 0.05% でよい。** 地図生成の設定で変える。既定は 0.0005。0 のとき注記は出ない。経済と名簿は動かない。
4. **摘要の置き場は後回しにする。** いくつかの街を統括する、冒険者ギルド地方支部のようなものを置く予定である。それまで描画は足さない。純粋関数の形は §8 のままである。
5. **顔の死は自動で行う。** 年率の実装より前には動かない。
6. **農村の名主の席は新設しない。** `farmer` は、既存の席があるときだけ付ける。

## 14. 次に進める作業

コードはまだ変えない。次の設計は危険度のやり直しである。今の 0〜255 を年率に比例させる実装は書かない。D&D 準拠で結ぶときは、CR とその分布をその設計に含める。rarity 5 の近傍は、数日で数万から数十万人が死ぬ規模を受けられるようにする。治療の生産量、冒険者ギルド地方支部、摘要の描画は、そのあとである。冒険者 0.05% は地図生成オプションとして [magic-agrarian-economy.md](magic-agrarian-economy.md) 側でも確定した。セル収量は変えない。
