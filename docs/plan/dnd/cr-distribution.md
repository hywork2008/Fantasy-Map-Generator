## 0. 結論

人の死の桁は、危険度のバイトから取らない。種類カードの **CR**（5e の脅威度、整数）と、そのカードの **`appetite`** と **`motives`** から取る。

CR はレアリティの帯の中の一点である。個体は振らない。帯の位置が、その食性が許す人数の表を選ぶ。食性をまたいで掛け算しない。`people` と `slaughter` を両方持っていても、予算は一つである。

人が住める段の死は、個体あたりの年間予算である。既定は、Beast が年 8 人、Dire Beast が年 20 人、Greater Monster が年 260 人（いずれも成人）。レアリティ 4 と 5 の `catastrophic` は年率にしない。出現のときに一度だけ、Arch-Beast は成人 57,000 人まで、Calamity は成人 300,000 人までである。日数は 3 日と 7 日で、引き算は人口動態の 1 ステップにまとめる。

実際に死ぬ人数は、その個体が支配するセルに残っている成人を超えない。適合で無人になった中心を、死者で埋めない。予算に足りない分は、居ない人を作って補わない。

重なった個体は、セルごとに一人だけが支配する。いちばん高いレアリティ、同じなら近い方、それも同じなら `i` の小さい方である。危険度の加算がやめたことの、死因側である。

## 1. バイトと頂点からは離す

[danger-calculation.md](danger-calculation.md) が死因へ渡してよいと書いたのは、覆っているレアリティ、その個体までのホップ、適合のあとに残る成人、である。本書はその三つと、支配している個体のカードを読む。

読んでならないのは、`cells.danger`、`danger / 255`、失われた適合の割合、頂点の表（48、72、140、200、255）である。獣の中心が 48 であることは、年に 48 人死ぬことではない。

`threatRarity` が 0 のセルは、怪物の半径に入っていない。獣害だけが危険度を上げていても、`predation` は 0 である。`threatRarity` は「誰かが覆っているか」の早見であり、人数の桁ではない。桁は支配している個体のカードから取る。古い保存で `threatRarity` が無いセルは、次の再計算まで 0 として読む。

レアリティ 3 以上の中心は適合が 0 なので、毎年の滴下にしない。死者が出るのは、成人がまだいる肩と、`catastrophic` の出現のときだけである。

## 2. CR の帯

セッション4の帯を、種類カードの制約として確定する。レアリティ 1 と 2 は、メモでは CR 1〜10 にまとまっていた。食性の上限が違い、頂点も 48 と 72 で違うので、ここで分ける。レアリティ 5 の「30+」は、死の桁をさらに上げる開いた端にしない。上限は 30 である。テラスクとティアマトはどちらもこの端で、同じ予算を分ける。

頂点の表へは換算しない。CR が 1 上がっても、危険度のピークは動かない。

| レアリティ | CR | セッション4の代表例（この帯に収まるもの） |
| ---: | :--- | :--- |
| 1 | 1〜4 | ダイアウルフ（1）、オーガ（2）、マンティコア（3） |
| 2 | 5〜10 | トロール（5）。メモの「1〜10」の上側 |
| 3 | 11〜16 | ビホルダー（13）、ヴァンパイア（13）、パープルワーム（15） |
| 4 | 17〜24 | ピットフィーンド（20）、リッチ（21）、クラーケン（23） |
| 5 | 25〜30 | テラスク（30） |

カードの `cr` は、その段の帯の整数だけを許す。帯の外、小数、31 以上はデータエラーである。実行時に近い値へ寄せて死者を出さない。死者は 0 である。`appetite` が [monster-nature.md](monster-nature.md) の段の上限を超えるカードも、同じように死者 0 である。`catastrophic` をレアリティ 1〜3 に書いて、事象の表へ落とさない。

未知の `type`（ダンジョンの `bossType` を含む）は、これまでどおりそのレアリティの既定行を使う。その行の `cr` も使う。`bossType` ごとのカードは、まだ作らない。

個体は `cr` を持たない。討伐で減るのは `power` だけで、CR は残る。`power` が 0 の個体は、どのセルも支配しない。

## 3. 既定の五種

出現数と `power` は変えない。媒体はすべて `land` のままである。

| `type` | 段 | CR | 狙い | appetite | 人の死 |
| :--- | ---: | ---: | :--- | :--- | :--- |
| Beast | 1 | 2 | `stock` `people` | `seasonal` | 成人 年 8 人 |
| Dire Beast | 2 | 5 | `stock` `people` | `persistent` | 成人 年 20 人 |
| Greater Monster | 3 | 13 | `people` `slaughter` | `persistent` | 成人 年 260 人 |
| Arch-Beast | 4 | 21 | `people` `slaughter` | `catastrophic` | 出現の一度、成人 57,000 人まで。3 日 |
| Calamity | 5 | 30 | `slaughter` | `catastrophic` | 出現の一度、成人 300,000 人まで。7 日 |

Greater Monster の 260 人は、肩に人がいるときの年間予算である。国の人口を毎年空にする量ではない。Arch-Beast と Calamity の人数は年率の既定値ではない。

`slaughter` だけの Calamity も、人の死の対象に入る。`people` と `slaughter` は、どちらか一方で足りる。

## 4. 人の死が立つとき

次をすべて満たすときだけ、人の死の予算が立つ。

1. 脅威モードが `none` でない。
2. 設定 `threatMortality` が on である。off では予算を計算しない。
3. カードの `appetite` が `none` でない。
4. `motives` が `people` か `slaughter` を含む。`stock` だけ、`property` だけ、のカードは人を殺さない。
5. そのプールがアンデッド国家（`isUndeadState`）でない。

`stock` の頭数と `property` の金額は、本書では置かない。穀物のセル収量も変えない。`blight` は、その死の仕組みの名前である。別の人数を足さない。`disease` のカードでも、死因は `predation` のままで、既存の `disease`（水の安全）には混ぜない。`speed`、`size`、`resilience`、`innate`、`innateScale` は人数を倍率しない。`speed` が決めるのは、事象の日数だけである。

子供と老年は、この予算に入らない。自然死の式は動かさない。兵力として成人バケットから既に出ている兵士は、ここから引かない。戦闘死にもしない。

### 5.6 一つのセルが無人にならない上限

年間予算は半径全体の天井である。一つのプール（農村セル、または Burg）から、その年に引ける成人の割合には上限がある。

| appetite | そのプールの成人に対する年あたりの上限 |
| :--- | ---: |
| `rare` | 0.5% |
| `seasonal` | 1% |
| `persistent` | 4% |

上限を超えた分は、他のセルへ回さない。居る人が予算より少ないときは、引ける人数が減る。ハムレット一つが、上位怪物の半径予算を全部受けて空になる、を避けるための上限である。

ステップの長さが `deltaYears` のとき、そのステップの予算は年間予算 × `deltaYears`、割合の上限も × `deltaYears` である。成人の残数を超えては引かない。1 年を通すと年間予算に一致する。端数の人は、人口ポイントと同じく浮動小数のまま持つ。日ごとに整数へ丸めて、年 8 人が毎日 0 人になる、にはしない。

## 6. 事象

`catastrophic` は、個体の出現に一度だけ立つ。年率にしない。`deltaYears` を掛けて、長いステップで何度も起こさない。

日数は叙事の長さである。人口動態は 1 ステップで全額を引く。台帳に日数の欄は足さない。摘要が後でカードから読んでよい。

| `speed` | 日数 |
| :--- | ---: |
| `immediate` | 1 |
| `fast` | 3 |
| `ordinary` | 7 |
| `slow` | 10 |

既定の Arch-Beast は `fast` なので 3 日、Calamity は `ordinary` なので 7 日である。どちらも「数日」の中に収まる。季節の長さにはしない。

| ---: | ---: |
| 17 | 21,000 |
| 18 | 30,000 |
| 19 | 39,000 |
| 20 | 48,000 |
| 21 | 57,000 |

この列が「数万」を受ける。CR 17 の 21,000 人が下限、CR 24 の 84,000 人がこの段の上限である。

### 6.2 レアリティ 5 の事象（成人、一度）

| CR | 人数 |
| ---: | ---: |
| 25 | 100,000 |
| 26 | 140,000 |
| 27 | 180,000 |
| 28 | 220,000 |
| 29 | 260,000 |

この列が「数十万」を受ける。CR 25 の 100,000 人が下限、CR 30 の 300,000 人が上限である。割合の上限（§5.6）は掛けない。天井は、支配しているプールに残る成人の合計だけである。

肩に成人が 50,000 人いるとき、Calamity は 50,000 人をそのステップで引く。却下した比例（成人 1,000 人あたり年 8 人）なら 400 人である。この 50,000 人は、その比例ではない。肩に成人が 400,000 人いるときは 300,000 人までで、残りは生きる。肩に成人が居ないときは 0 人である。300,000 人に届かせるために、無人の中心へ死者を作らない。

### 6.3 いつ一度とするか

事象は年率ではない。引く回数は、個体につき一度である。

- 生成で最初から居る個体は、地図を開いた時点で済みにする。`threatMortality` が on で、脅威モードが `none` でないときは、その場で成人を引き、`predation` に載せる。時間を進めていない地図の人口と、人口概況の当期の死因は、この死者を含む。
- 生成の `rankCells` の中では引かない。適合で人口を置いたあと、ダンジョンのボス源まで含めて怪物が揃い、国家がセルに付き、`initSimulationClock` のあと、利用者の時間進行より前に、生成の最後で一度引く。適合が無人にした中心の人数は、死者にしない。
- この生成のパスでは、年間予算（Beast の 8 人など）は引かない。年間予算は、時間を進めた人口動態から掛かる。
- 生成のとき設定が off なら、引かずに済にする。あとから on にしても、その出現はやり直さない。
- ロードした個体にフラグが無いときは、済として読む。保存済みの人口を、ロードの瞬間に掛け直さない。
- `power` が戻ること、討伐で `power` が減ることは、新しい出現ではない。フラグを未済に戻さない。
- プレイ中に新しい個体が生まれ、そのとき設定が on なら、未済で作る。次の人口動態ステップで一度だけ引く。生成の地図には、後から生まれた個体の死者は最初から載らない。

半径のセルがすべて自分より高いレアリティに支配されているときも、そのステップで済にする。死者は 0 である。上位の個体が後で消えてから、下位の事象をやり直さない。同じステップで支配セルが分かれているときは、それぞれの事象が自分のセルだけを引く。同じ成人に二つの予算は乗らない。

## 7. セルへの分布

塗りの媒体マスクとホップは、[monster-nature.md](monster-nature.md) と [danger-calculation.md](danger-calculation.md) と同じである。`dist < power` のセルだけが対象である。水棲が岸へ写した陸 1 ホップは、写した水面セルの `dist` のまま対象に入る。岸の内側は入らない。航路の船は、この人数に入れない。

セルを支配するのは、そのセルを覆う個体のうち、次の順で最初の一つである。

1. レアリティが高い。
2. `dist` が小さい。
3. 源が怪物なら、ダンジョンのボス源より先である。
4. `i` が小さい。

危険度の貢献が最大の個体、ではない。災厄の肩でバイトが獣の 48 に負けても、支配は災厄のままである。これは `threatRarity` が最高レアリティであることに合わせる。

年間予算も事象の予算も、その個体が支配するプールだけに配る。支配セルが一つも無い年間個体は、そのステップでは 0 を配る。予算を次の年へ繰り越さない。

プールは二つある。農村セルの成人（男性 + 女性）と、そのセルにある Burg の成人である。別々の人として重みを付ける。農村の人数に Burg を足してから、もう一度 Burg を引かない。

プールの重みは `成人 × (power - dist) / power` である。二乗もしない。頂点も掛けない。重みの合計が 0 なら、その個体のそのステップは 0 である。

配分は、予算 × そのプールの重み / 重みの合計、である。年間モードでは、さらに §5.6 の上限と、そのプールの成人の残数で切る。事象では、成人の残数だけで切る。

男性と女性には、今の人数の比で分ける。片方しか居ないときは、そちらから引く。両方 0 なら、そのプールは 0 である。

国家の無いセルでも、プールに成人が残っていれば引く。`recordDeaths` は国家 id が 0 のとき何もしないので、人口概況の列には出ない。隣の国家へ付け替えない。定住パターンが無主のセルを空にする処理は、今のままである。その消去を `predation` に読み替えない。

暗幻想の Cultures set は定住パターンが Marches で、初期人口が少なく、危険度 80 以上は最初から人が居ない。既定の Calamity の半径のうち、人が居られるのは危険度が 80 未満の肩だけである。予算の 300,000 人は、その肩に成人がそれだけ残っているときに届く天井である。Marches の肩がそれより少ないときは、残っている成人が死者の全部である。

## 8. 人口への入れ方

生成の事象は、`simulateDemographics` の外である。セルと Burg の合計人口を、引いたあとのコホートの和に戻す。国家の人口集計は、生成末尾で画面が読む集計をもう一度行う。軍の生成はやり直さない。兵力へ既に移した成人はバケットに居ないので、この死者に入らない。

時間を進めたあとの年間予算と、プレイ中に生まれた個体の事象は、`simulateDemographics` の中である。無主のセルを空にする処理のあと、出生と自然死の前に、成人だけを引く。出生は、そのステップを生きた成人女性から計算される。子供、老年、飢餓、疫病、適合の式は、本書では行を変えない。生成で済にした個体の事象は、このステップで繰り返さない。

引いた表示人数を、国家ごとに合計して `recordDeaths(stateId, people, "predation")` へ渡す。`people` は表示人数である。人口ポイントを、そのまま人数として渡さない。

ポイントへの戻しは次である。

- 農村: 表示人数 / `populationRate`
- Burg: 表示人数 / (`populationRate` × `urbanization`)

割る数が有限の正でないプールは、そのステップでは飛ばす。`populationRate` の既定は 1,000、`urbanization` の既定は 1 である。成人 8 人を農村から引くときは、ポイント 0.008 を成人バケットから引き、台帳には 8 を足す。

顔のある死亡の選び方は、[table-background.md](table-background.md) のままである。本書の実装より前には選ばない。顔の分を `recordDeaths` に足さない。復活は、この死者を帳消しにしない。

討伐は `power` を変えたあと、危険度を一度だけ描き直す。同じ年の死者に、完了ボーナスを足さない。一つの仕事で、その国の `predation` を 0 にしない。翌ステップの年間予算は、描き直したあとの支配を読む。

## 9. 保存

- 古い死因合計に `predation` が無いときは 0 として読む。過去の死亡を再分類しない。
- 事象のフラグは個体の任意の真偽である。無いときは済である。
- 設定 `threatMortality` が保存に無いときは off である。
- 脅威モード `none` の地図は、設定が on でも結果は 0 である。標準の地図の人口は、この式では動かない。
- ロード時に `rankCells` をやり直さない。既にいる人口を、ロードで掛け直さない。

---

## 10. 採用しない読み

- `danger / 255`、`fullDangerRate = 0.008`、下限 32、危険度 255 で成人 1,000 人あたり年 8 人、城壁で 0.15。
- 頂点 48 や 72 に比例した年率。重なった獣のバイトは 48 で頭打ちでも、死者を頭数だけ足す読み。
- 食性の頻度と量を、別々の数に戻して掛け、同じ桁を二本の経路で作る。
- `people` と `slaughter` の両方で予算を倍にする。`blight` の段でさらに倍にする。
- CR の帯の中点や、レアリティの番号だけから人数を出し、カードの CR を無視する。
- CR 31 以上を「30+」として、300,000 人より上の桁を足す。
- 適合で無人の中心に、減った人数と同じ死者を作る。肩が予算に満たないとき、差額の人を作る。
- 事象を毎年繰り返す。済のフラグを、設定を on にしたときや、ロードのときに未済へ戻す。生成の事象を、最初の時間進行まで遅らせる。
- 上位の事象が済んだあとで、その陰に居た下位の `catastrophic` をやり直す。
- 子供と老年を、事象の人数に含める。アンデッド国家の成人を引く。
- 獣害の危険度（深林の 65 まで、を含む）から `predation` を出す。
- 家畜の頭数や建物の被害で、穀物のセル収量を変える。
- この人数のために、出現数、`power`、適合の係数、討伐年数 1 / 2 / 3 / 5 / 8 を動かす。

## 11. 実装するときの確認

コードは、この文書だけでは変えない。入れるときは [table-background.md](table-background.md) の段 4 である。関連テストだけを見る。地図全体の多シード検証はしない。危険度 255 を合格基準にしない。

固定点は次である。

- 脅威モード `none` では、`threatMortality` が on でも人口がビット単位で今と同じである。off でも `predation` は 0 である。
- Beast（CR 2、`seasonal`）の年間予算は 8 人である。成人 2,000 人だけの半径では、割合上限 1%（20 人）より小さいので 8 人を引く。48 に比例した人数にはならない。
- Dire Beast（CR 5、`persistent`）は年 20 人、Greater Monster（CR 13、`persistent`）は年 260 人である。Greater の中心の成人 0 は、年間の滴下 0 である。
- 成人 200 人だけのプールに Dire Beast の 20 人が当たるとき、4% の上限は 8 人である。20 人は引かない。余った 12 人は他へ回さない。
- Calamity（CR 30）の事象は 300,000 人まで、1 ステップ、`deltaYears` を掛けない。成人 50,000 人の肩では 50,000 人であり、400 人（年 8/1,000）ではない。成人 0 の中心では 0 人である。
- Arch-Beast（CR 21）の事象は 57,000 人までである。日数の意味は 3 日で、台帳の人数は 1 ステップ分である。
- 同じセルを獣と災厄が覆うとき、支配は災厄である。獣の年間予算は、そのセルには乗らない。
- 同じレアリティの獣が二つ覆るとき、近い方が支配する。そのセルの死者は一本である。
- `appetite = none`、または `motives` が `stock` だけのカードは、CR が帯の中でも人の死は 0 である。
- レアリティ 1 に `catastrophic` を書いたカードは、データエラーとして 0 である。57,000 人の表は使わない。
- 子供の自然死は `predation` に混ざらない。アンデッド国家の成人は減らない。
- フラグの無い保存個体は、事象を再実行しない。
- `threatMortality` が on の生成で、肩に成人 50,000 人が居る Calamity は、時間を進めない開いた地図の成人を 50,000 人減らし、当期の `predation` を 50,000 にする。その後の人口動態 1 ステップは、同じ個体の事象を繰り返さない。年間予算の 8 人は、この生成では引かない。
- `threatMortality` が off の生成は、人口が今のビルドと同じである。
- 農村の表示 8 人は、`populationRate` 1,000 でポイント 0.008 であり、台帳の `predation` は 8 である。
