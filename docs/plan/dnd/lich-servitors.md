## 0. 結論

死者由来の使役を許す文化は、多数種族のキーが `lich` である文化である。判定は `isLichCulture` と `isLichState` のままである。新しい文化型も、宗教も、`magicDensity` の値も、この許可には使わない。

この文化の死者は、今の三つの置き場に分かれたままである。

| 置き場 | 中身 | 職 |
| :--- | :--- | :--- |
| 人口の点 | リッチの国家のセルと町の成人バケット。人口動態では出生も死亡も飢餓もせず、戦まで静止する | 今の経済が成人に割り当てる仕事のまま。第二の畑番は足さない |
| 名簿 | 支配者だけがリッチ。ほかの役はゾンビが 0.65、外れたらスケルトン | 役職の種族である。労働力の頭数には足さない |
| 蘇生した連隊 | 敵との戦争で、そのセルの埋葬の残りを一度だけ消費する。スケルトンの `power` は 0.7、ゾンビは 0.55。`rural` も `urban` も 0 | 兵士だけ。畑、坑、工房、城壁の番には数えない |

フレッシュゴーレムは、この三つのどれでもない。ストーンゴーレムは、死者の使役に入れない。

生きた国家は、`magicDensity` が `common` でも、畑の人手をスケルトンで置き換えない。100 万人の畑の 5% に常勤の術者約 1,400 人が要る、という算定は、その置き換えを採らない根拠のままである。

---

## 1. 文化の範囲

リッチは支配者に限り、地図全体で `MAX_LICHES_PER_MAP`（2）を超えない。リッチになれない生成は、ゾンビ、次いでスケルトンへ落とす。この上限とフォールバックは変えない。

リッチの文化が地図に無いとき、死者の使役は無い。埋葬の残りは地面に留まる。蘇生の連隊は出ない。

`magicDensity` の `off`、`rare`、`common` は、この文化の有無を切り替えない。文化セットがリッチを出さなければ、濃さを上げても畑のスケルトンは出ない。文化セットがリッチを出せば、濃さが `off` でも、今の人口の静止と、戦争の蘇生は残る。

---

## 2. 許す死者と、許さない死者

日々の支配が要るスケルトンを、生きた農民の代わりに雇う読みは採らない。24 時間で命令を捨て、やり直しが射程 10 フィート、という作業仮説は、その雇用の制約として残す。採用しない雇用に、毎日の枠と神殿の定員は置かない。

| 死者 | 本書 |
| :--- | :--- |
| 人口の点 | リッチの国家では、今の成人バケットが労働の頭数である。術者 1 人あたり 8 体、という維持は掛けない |
| 名簿のゾンビとスケルトン | 0.65 でゾンビ、外れがスケルトン。支配者はリッチ。頭数の式には足さない |
| 蘇生のスケルトンとゾンビ | 連隊だけ。セルの人口には足さない |
| フレッシュゴーレム | 置かない。一体の高位の儀式を、守衛の定員にしない |
| ストーンゴーレム | 対象外。製作伝統は、別の設計のままである |
| 物体の活性化、見えざる召使い、目覚めた動植物 | [fantasy-world-agenda.md](fantasy-world-agenda.md) §2.2 のまま、労働に数えない |

町の `zombieShare` は、欠けるとき 0.75 で始まり、年ごとに `deltaYears × 0.02` だけ減り、0.05 を床にする。肉が骨へ寄る、という今の減衰である。名簿の 0.65 とは別の数であり、本書では揃えない。

## 3. 蘇生の連隊

`raiseUndeadOnCellEntered` の条件は、そのままである。

- 入ったセルは陸である。
- 平和ではなく、双方の外交が敵である。
- 入った側と、セルの持ち主の、ちょうど一方がリッチの国家である。
- そのセルの埋葬の残りが 0 より大きい。

残りは一度で消費する。ゾンビの割合は、そのセルの文化の葬儀の `zombieShare` である。火葬は `remainFraction` が 0 なので、残りが無く、蘇生は 0 である。これが、死者の使役を拒む側の仕組みである。新しい宗教の旗は足さない。

リッチの国家自身は、人口動態で死なない。自分のセルへ、年次の死者から残りを積まない。蘇生の材料は、相手の土地に既にある残りである。

連隊が消えても、消費した残りは地面へ戻さない。国家が消えたときの連隊は、今の軍事の片付けに従う。危険度のバイトには書かない。

---

## 4. 維持する者

維持の定員は置かない。

冒険者の 0.05% からも、神殿やネクロポリスの別枠からも、スケルトン 1 体あたりの術者を出さない。支配者のリッチは、体ごとの毎日の支配者ではない。

人口は、出生と自然死と飢餓をスキップする今の分岐のまま静止する。命令が切れた日に人口を減らす処理は足さない。

---

## 5. 命令が切れたあと

脅威度へは戻さない。

人口の点も、蘇生の連隊も、`pack.monsters` にしない。`cells.danger` を、この使役の差分で描き直さない。破壊された連隊を、怪物の出現にはしない。

24 時間後に自分を守るだけになる、という読みは、畑の雇用を採らなかったので、連隊の寿命にも人口の寿命にも掛けない。連隊を毎年消し、危険度へ移す処理は足さない。

---

## 6. 法と外交

外交の関係値に、死霊術のペナルティは足さない。

戦争で敵地に入ったときの蘇生は、今の敵同士の条件の中にある。友好の土地や、自国のセルを、平時に掘り返す処理は足さない。

火葬のように残りが 0 の葬儀は、蘇生の材料を持たない。土葬の `remainFraction` 0.8、ミイラの 0.95、鳥葬の 0.12、水葬の 0.05、風葬の 0.45 は、今の表のままである。禁じる宗教を、葬儀と別に新設しない。

ストーンゴーレムは、この禁忌に入れない。

---

## 7. 労働から外れた人

`ruralLaborRelease` は、食料の余剰で町へ移る今の移動のままである。魔法で畑を解雇する経路にはしない。

リッチの国家は飢餓で人口を減らさないので、この移動の入力に、使役の余りは出ない。失業の新しいバケットは置かない。生きた国家でも、スケルトンを雇った分の農民を町へ出す処理は置かない。雇う経路が無いからである。

セル収量の式は、リッチのセルでも生きたセルでも同じである。アンデッドだから収穫が増える倍率も、減る倍率も掛けない。

食料の需要は、リッチの国家を除外していない。下水の負担が 0 であることは、食べない、を食料需要のゼロにすることではない。水系の負担 0 と、臭い `clamp01(zombieShare × 0.85)` は、今のままである。

---

## 8. 採用しない読み

- リッチ以外の文化が、濃さ `common` で畑のスケルトンを持つ。
- 畑の 5% を、常勤の術者約 1,400 人で置き換える。
- 人口の点とは別に、同じセルへ労働用のスケルトンを足す。
- 蘇生の連隊を、`cells.pop` や畑の人手に足す。
- フレッシュゴーレムを、守衛の定員として毎年作る。
- ストーンゴーレムを、この文化の労働に含める。
- 名簿の 0.65 と、町の `zombieShare` を、一つの割合に揃える。
- 命令の期限切れを、危険度の源にする。
- 死霊術の外交ペナルティを、関係値に足す。
- 火葬以外に、蘇生を禁じる宗教の新しい旗を置く。
- `ruralLaborRelease` を、魔法労働の解雇にする。

## 9. 実装するときの確認

コードは、この文書だけでは変えない。関連テストだけを見る。地図全体の多シード検証はしない。今の動きを、次の契約として残す確認である。

- 多数種族が `lich` でない国家は、`magicDensity = common` でも、成人バケットの外にスケルトンの労働力を持たない。
- リッチの国家の農村は、人口動態の 1 年で成人の合計が変わらない。出生も飢餓の減少も 0 である。
- 敵地への進入で蘇生した頭数は、そのセルの `pop` に足さない。埋葬の残りは、その進入のあと 0 である。
- 火葬のセルは残りが 0 で、蘇生は起きない。
- 蘇生の前後で、`cells.danger` は一致する。
- 同じ作物・同じ人口のセルの収量は、国家がリッチでも生きていても一致する。
- 町の `zombieShare` が 0.75 のリッチの国家は、1 年で 0.73 になる。名簿の配分 0.65 は、その減衰では変わらない。
