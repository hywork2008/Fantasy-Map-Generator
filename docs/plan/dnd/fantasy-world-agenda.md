## 0. この文書の役割

現実の人口・農耕・軍・技術で組んである FMG に、ファンタジーの世界観を足すとき、**どの差をモデルに入れるか**を先に列挙する。方向を決めた項目は §10 にまとめる。新しい設定の数値と既定値は、まだ書かない。

食料と豊穣については [magic-agrarian-economy.md](magic-agrarian-economy.md) が既に算定している。あの文書の既定は `magicEconomy = off` で、セル収量は変えない。本書の項目を実装するときも、あの決定を上書きしない。上書きするなら、あの文書を改訂する。

各項目は次の四つを持つ。

1. 現実側で FMG が既に持っているもの。
2. ファンタジー側で、そのモデルが黙っていては表せないこと。
3. 後の設計で決める問い。
4. その問いが効く世界の濃さ（§1）。

## 1. 濃さを先に分ける

同じ「魔法がある」でも、人口に対する術者の厚さが違うと、文化への効きが別物になる。項目ごとに、どの濃さで初めて考える価値があるかを書く。

| 濃さ | 内容 | 文化・経済への効き |
| :--- | :--- | :--- |
| `off` | 今の FMG。魔法も、魔法由来の労働も無い | 現実側のモデルのまま。魔法は実在せず、医学と科学技術が本筋である |
| `rare` | [magic-agrarian-economy.md](magic-agrarian-economy.md) の基準。活動中の冒険者は人口の 0.05% で軍より少なく、術者はその一部 | 王国の平均収量と平均死亡率はほぼ動かない。魔法が実在するので、医学と科学技術は迷信として扱われる（§6.5） |
| `common` | 神殿、ギルド、村の呪術師が冒険者枠の外にいる。缶詰め呪文やポーションが町で買える | 魔法の医療、法、教育、灯りの需要、労働の置き換えが、制度として現れる。科学が迷信であることは `rare` から続いている |

怪物の濃さは魔法の濃さと独立である。この二つは Cultures set から分けて持つ（§10）。魔法が稀でも災厄は居る。魔法が街にあっても怪物は居ない、を選べる。今の `culturesSet`（`highFantasy` / `darkFantasy`）は、種族・居住パターン・脅威を一度に切り替える。実装では、既存のセーブが今の組み合わせを再現できるようにする。項目の値は [density-knobs.md](density-knobs.md) に置いた。

`Agents.md` の注意はここにも効く。Fantasy 系の Cultures set は定住パターンを Marches にし、初期人口が少なくなる。人口を前提にした試験や、人が足りて初めて立つ経済は、その地図では前提が崩れる。

## 2. 使役による労働力

人を雇う代わりに、何に仕事をさせるか。忌避の線はゴーレムという名前では引かない。ストーンゴーレムのように石を材料にする工作物は忌避が薄い。スケルトンやフレッシュゴーレムのように、死者を由来とするものを使役するかどうかが、文化の問いである（§10）。

### 2.1 現実側

労働は人の日数である。畑は成人 140 日/年、30 日/ha（`settlementClearance.ts`）。軍は人を台帳から在営へ移す（`manpower.ts`）。職人は町の人口から出る。死者は労働に戻らない。道具は人の生産性を上げるが、人を置き換えない。

### 2.2 ファンタジー側で分けるもの

同じ「無料の労働者」としては扱わない。制約は [magic-agrarian-economy.md](magic-agrarian-economy.md) と同じ作業仮説であり、外部の呪文データからは取らない。

| 手段 | 材料と忌避 | 置く制約 | 労働として数えるときの条件 |
| :--- | :--- | :--- | :--- | :--- |
| スケルトンなど、日々の支配が要るアンデッド | 死者。文化が許すかどうかの対象 | クレリックとウィザード。中位の枠で 1 体、または既存 4 体の支配を 24 時間延ばす。やり直しは射程 10 フィート。期限が切れると命令を捨て、自分を守るだけになる。金貨は要らない | 術者が毎日その場にいる常勤。冒険に出た日は維持できない |
| フレッシュゴーレム | 死者の体。忌避はスケルトンと同じ側 | 量産の呪文にはしない。作成は高位、長い儀式、多額の費用で、一体がすでに強敵の階位 | 畑の人手の式には入れない。文化が死者の使役を許すとき、守衛や限られた職の候補になる |
| ストーンゴーレム | 石。死者の体ではない。忌避は薄い | 量産の呪文にはしない。作成は高位、長い儀式、多額の費用で、一体がすでに強敵の階位。街の守衛にはなる | 死者の使役の候補には入れない。畑を耕す工房にするのは、文化としての製作伝統を新設する場合だけ |
| 物体の活性化 | 手元の器物 | 集中が続く短時間。季節労働にならない | 数えない |
| 見えざる召使い | 実体の無い家事 | 短時間。筋力は 2 で、所持の上限は約 30 ポンド | 家事の一部。畑、鍛冶、荷役の単位にはしない |
| 目覚めた動植物 | 生きた動植物を人格にする | 高価な素材（瑪瑙 1,000 gp 相当）を消費し、知性 10 の人格になる。30 日の従属のあと独立する | 労働者ではなく、もう一人の住人 |

前の算定では、畑労働の 5% をスケルトンで替えると、100 万人あたり常勤の術者が約 1,400 人要る。基準の冒険者 500 人より多い。`rare` では王国の労働力にならない。

### 2.3 残した候補と、その中で後で決めること

死者由来の使役は、後の文化が名指しできる候補に残す（§10）。ストーンゴーレムは、この候補に入れない。

候補の中で、文化を名指しするときに決めること:

- 許す死者の範囲。日々の支配が要るスケルトンだけか、フレッシュゴーレムのような一体も含むか。職は畑、坑道、城壁の番、工房のどれに限るか。
- 維持に人の枠を毎日使うなら、その術者は冒険者人口から出すのか、神殿やネクロポリスの定員として別枠か。
- 命令が切れたあとの事故（暴走、食人）を、脅威度へ戻すか。戻すなら、死者の使役は労働を増やすと同時に Danger の供給源になる。
- 人を雇うより死者の使役が安いとき、刑死者と戦場の死体の法を、どの宗教が禁じるか。禁じる国と行う国が同じ地図に居るとき、交易と外交のペナルティを既存の外交に足すか。ストーンゴーレムはこの禁忌に入れない。
- 労働から外した人は町へ移るのか、失業として残るのか。`ruralLaborRelease` は食料余剰の移動であって、魔法労働の解雇ではない。

石を材料にする工作物を、稀な一体の守衛のままにするか、ドワーフのルーンや神像のような製作伝統にするかは、死者の使役とは別の設計である。独自の製作伝統にするなら、材料・年数・壊れ・技術グラフとの関係をそこで書く。

`off` と `rare` の既定では、死者の使役を経済に接続しない。名指しした文化の設計まで、畑の人手の式には入れない。

## 3. 絶え間ない怪物と、その備え

怪物が討伐で尽きるのか、間引いても戻るのか。戻るなら、軍と冒険者は何を恒常的に負担するのか。

### 3.1 現実側

脅威の相手は他の国家と、獣害・盗賊である。軍は人を食う。城壁と砦は建設費と維持費を持つ。Danger レイヤーは、Fantasy の Cultures set 以外では脅威の生成をしない（`resolveThreatCultureMode` はそれ以外を `none` にする）。

### 3.2 今あるファンタジー側

| 仕組み | いまの動き |
| :--- | :--- |
| 脅威の発生 | `highFantasy` はレアリティ 1〜2 が中心で、3 は 0〜2 体、4〜5 は無い。`darkFantasy` は災厄 1〜2、上位獣 2〜4 を含む（`threatProfiles.ts`） |
| 居住 | セルの `danger` が居住適合 `s` を下げ、人口が伸びにくい。塗りは [danger-calculation.md](danger-calculation.md)。適合の式は不変 |
| 定住パターン | Fantasy の Cultures set は Marches と、居住に使う土地の割合の低下に結び付く |
| 軍隊の討伐 | 国家あたり同時 2 件まで。準備費用と、レアリティに応じたクリア年数（1 / 2 / 3 / 5 / 8 年）。国庫の多年事業 |
| 冒険者の間引き | 町の仕事板。報酬は個人の所持金。軍隊 1 年分の力の決まった割合だけ危険度を削る。負傷と、稀な死亡がある |
| ダンジョン | 数十年〜数百年で自然発生する。ボス討伐で地図上から消える。内部と戦利品は未接続 |
| 生態 | 荒野の生態は年次で進む。危険度の再計算と、死んだ怪物の整理がある |

「絶え間ない」は、このうち自然発生と生態の回復を、討伐が打ち勝つ速度より高くする、という読みである。今のコードは、その比較を世界観の設定としては持っていない。クリア年数はあっても、「討伐した翌年に同じ密度へ戻るか」は項目として分かれていない。

### 3.3 備えが現実と違う点

人の敵なら、勝ったあとに土地が居住域へ入る。怪物が生態か呪いで補充されるなら、勝っても居住域は恒久的に狭い。Marches の低い人口は、その結果の一つの形である。備えの費用は、戦時の臨時費ではなく、平時から続く。

平時から続くもの:

- 常備軍 1%（既存）。怪物の間引きに回す割合と、対人戦争に残す割合を分ける必要がある。両方に同じ 1% を使うと二重計上になる。
- 城壁、砦、街道の護衛。対人の防衛と共用できるものと、怪物にしか効かないもの（夜警、聖別、結界）を分ける。
- 冒険者への報奨。国庫から個人へ出る。軍の給与とは別の支出で、同じ危険度を削る。
- 居住しない緩衝帯。耕さず、通さず、討伐のたびに人が死ぬ土地。生産はゼロで、費用だけが残る。

災厄（レアリティ 5）は、討伐の対象というより地図の条件である。単一の連隊や一隊の冒険者の仕事にしない、という既存の説明を維持する。

### 3.4 決定と、残る問い

補充は最初から二本にする。獣は生態（`ecology`。繁殖し、間引きは収穫に近い）。災厄とダンジョンは呪術（`occult`。信仰・門・呪いから戻り、討伐は維持作業）。一つの型にはまとめない。`static`（倒せば減ったまま）は、この二本の既定にはしない。

海の怪物は陸と同じレアリティの梯子に乗る。塗るのは水面と岸の 1 ホップだけで、内陸の円にはしない（[monster-nature.md](monster-nature.md)）。航路の損失は、まだ置かない。

同じ年に同じ個体を誰が削るかは [replenishment.md](replenishment.md) で閉じた。マクロの事業がある個体はその年は軍隊が書き、個人は力を引かない。事業が無い個体は、その年の最初の個人契約だけが書く。

残る問い:

- 緩衝帯の幅をセル数で持つか、危険度の閾値で「人口ゼロ」にするか。今は適合が下がるだけで、ゼロとは限らない。
- 備えの費用を、既存の公共事業（道路 12、港 150、穀物倉 100）と同じ台帳に足すか、軍の維持に含めるか。
- 怪物が尽きた国家は、世代を経て Marches から標準の定住へ移れるか。移れるなら「絶え間ない」は世界の既定ではなく、文化か宗教の選択である。
- 航路の損失。海の怪物の塗りは決めた。船がどれだけ沈むかは、まだである。

`off` では脅威生成をしない、が今の動きである。`rare` の冒険者は、この備えの担い手にはなるが、軍の人数を置き換えない（§4）。

## 4. 冒険者と兵士の力量差、および関係

人口の 0.05% の冒険者と、人口の 1% の兵士は、同じ「戦う人」ではない。

### 4.1 現実側

兵士は頭数である。連隊は現員と定員を持ち、質は兵科と練度で、個人のレベルは無い。戦死は成人男子の台帳から落ちる。冒険者という職業は無い。

### 4.2 力量を、同じ尺度に置かない

個人のレベルは、ダンジョンの中の強さである。FMG の連隊の `power` は、野戦の部隊の強さである。次の対応は、討伐の仕事に限った換算であり、国家間の戦争の式に流用しない。人数は農業文書の 100 万人・活動中 0.05% から来る。

| 階層 | レベル | 100 万人の基準人数 | 一人が担える仕事 | 担えない仕事 |
| :--- | :--- | :--- | :--- | :--- |
| 1 | 1〜4 | 約 350 | 獣、盗賊、護衛。兵士一人よりは強いが、分隊の代わりにはならない | 城の守備、会戦の一翼 |
| 2 | 5〜10 | 約 120 | より強い個体の討伐、少人数では入れない場所。地方の英雄 | 軍の代替。野戦では隊の方が範囲を持つ |
| 3 | 11〜16 | 約 25 | 都市や地方を一つの事件から救う。軍の指揮を一人で代行はできない | 国境の常時防衛 |
| 4 | 17〜20 | 約 5 | 国家の危機に一度だけ効く。願いは定常の政策にしない | 人口 1% の軍が持つ面積の支配 |

術者はこの人数の一部である。兵士の側に、同じレベルの術者は既定では居ない。軍の魔術師を置くなら、それは §1 の `common` か、宮廷の定員であり、連隊の兵科を自動では増やさない。

逆に、兵士が冒険者より優れる局面がある。持久、補給、城の維持、占領、数による封鎖である。冒険者は点で強く、面を保持しない。災厄は両方の外に置く。

### 4.3 関係

決めるべき社会関係は、強さの表とは別である。

- **命令系統。** 兵士は manpower の台帳に入り、徴兵で民間から減る。冒険者は台帳の外に置く。戦時の召集例外は置かない。国家が雇うときだけ契約で結ぶ。500 人を軍 1 万人に足したり、軍から差し引いたりしない。
- **法的地位。** 報奨金、通行の許可、怪物の独占討伐権、私戦の禁止。許可のない討伐は、軍にとっては密猟か私兵である。
- **退役。** 階層 2 以上が町に残ると、士官、ギルドの長、自治の有力者に入りうる。名簿の無職肥大（長寿種の既存問題）と同じく、生存したまま職を離れた強者を剪定しないと一覧が膨らむ。
- **対立。** 軍は秩序、冒険者は個別の依頼と戦利品で動く。同じ怪物の功績を両方が主張する。仕事板と `ThreatCullProject` の既存の分離を、この対立の受け皿にする。
- **補充。** 兵士の損失は成人男子から戻る。冒険者の損失は 0.05% の中のさらに一部で、人口動態の死亡率には足さない。階層 4 の死亡だけ、復活の費用が払えるかを別問題にする（§7）。

### 4.4 後で決める問い

- 討伐貢献の換算（一人の階層 → 軍隊のクリア年数の何割か）を、既存の「軍隊 1 年分の決まった割合」から、階層で変えるか。
- 士官の何割を退役冒険者にするか。0 なら軍と冒険者は社会的に没交渉である。戦時の強制召集は置かない（§10）。怪物の前線が手薄になる年は、その結果として残る。
- 兵士が階層 1 の冒険者より弱い、という描写を、連隊の `power` に反映するか。反映すると対人戦争のバランスが変わる。反映するのは対怪物の仕事だけ、に留めるのが安全である。

## 5. 怪物と人の棲み分けに、FMG が要る設定

棲み分けは一つのスライダーではない。今は Cultures set が種族、定住パターン、脅威発生を束ねている。魔法の濃さと怪物の濃さは、ここから独立した二つのノブにする（§10）。項目名と移行は [density-knobs.md](density-knobs.md) に置いた。表のほかの行は、この決定では開いたままである。

| ノブの候補 | 今どこにあるか | 分けないと起きること |
| :--- | :--- | :--- |
| 魔法の濃さ `off` / `rare` / `common` | 無い。農業文書の `magicEconomy` は食料側だけ | 怪物のいる地図が、自動で術者社会になる |
| 脅威の型 `none` / `frontier` / `dark` | `culturesSet` が `threatProfiles.ts` を選ぶ | 歴史的な種族構成のまま災厄だけ置きたい、ができない |
| 補充 `static` / `ecology` / `occult` | 生態の年次と、ダンジョンの自然発生が別々に存在し、一つの設定ではない | 「倒し切れる世界」と「維持し続ける世界」が同じクリア年数になる |
| 居住の切れ目 | `danger` が適合 `s` を減衰。ゼロの閾値は無い | 人が怪物の中心に薄い密度で住み続ける |
| 緩衝帯 | 明示の幅は無い。Marches は地図全体の居住割合 | 国境の森だけ無人、という配置ができない |
| 討伐の担い手 | 軍の多年事業と、個人の仕事板 | 冒険者を消した世界でも仕事板が残る、または軍が怪物を見ない |
| 知的な敵を国家にするか、危険度の印にするか | 種族国家と Monster 配列は別 | オークの王国と「オークという怪物」が二重に出る |
| 地下・非人間の面 | 地下は第 2 の地図にしない、という設計がある。実装は未了 | ドワーフの坑と地表の村が同じセルの人口を奪い合う |
| 聖域・結界で危険度を局所的にゼロにするか | 無い | 神殿の町が、周囲の Danger と無関係に安全か危険か決められない |
| 海 | 陸の脅威生成 | 航路だけ安全、または海も同じ梯子、を選べない |
| 定住パターンとの結合 | Fantasy の Cultures set が Marches を連れてくる | 人が多い標準定住で、かつ怪物がいる試験がしにくい |

魔法の濃さと怪物の濃さは、Options の独立項目にする。種族と定住パターンは Cultures set に残す。既存のセーブが、今の `highFantasy` / `darkFantasy` と同じ組み合わせを再現する移行は [density-knobs.md](density-knobs.md) に置いた。緩衝帯、海、地下、聖域は、独立項目にしない。

## 6. ポーション、回復魔法、科学の発展

魔法が実在する世界では、医学と科学技術は迷信として扱われる（§6.5）。人口の死亡率は、この決定では下げない。

### 6.1 現実側

化学と医学は、需要、ギルド、学術、試作の失敗、最短年数で進む（[chemistry-medicine-knowledge-accumulation.md](../chemistry-medicine-knowledge-accumulation.md)）。年数が来たから解禁、ではない。個人の健康は衛生と、設計上の `medicalCare` を見る。コレラと水の設計は、人口の病死を別経路で扱う。薬草は森の採取品として既にある。魔法のポーションという財は無い。

技術グラフは中世から宇宙開発まで繋がっている。魔法がこのグラフのノードをスキップすると、「魔法が便利だから科学が止まる」と「魔法が測定と製作を助けるから科学が速くなる」の両方が、同じノードに効いてしまう。

### 6.2 治療の手段を分ける

| 手段 | `rare` での人口への効き | `common` で制度になるもの |
| :--- | :--- | :--- |
| 治療の傷、癒しの言葉 | その場に術者がいるときの個人の回復。1 日に数人 | 街の診療。術者の定員が要る |
| 初級回復（毒、病、盲目、麻痺の一つ） | 流行の最中に、一人の司祭が 1 日に数人 | 衛生の代替にはならない。病の原因は残る |
| 上級回復、再生 | 金貨を消費。四肢と衰弱。エリートと冒険者 | 障害の社会的意味が、払える者だけで変わる |
| 復活 | 300〜25,000 gp と高レベル。名前のある死者 | 継承、葬儀、君主の死が、払える家だけで止まる |
| 回復のポーション | 魔法の品として、冒険者の携帯薬に限る。醸造は畑の産物ではない | 店で買えるなら、薬種ギルドの需要を奪う |
| 食料の浄化 | 毒と病。腐敗の時計は止めない | 水道と公衆衛生のノードを飛ばす理由にはしない |

`rare` では、王国の死亡率、幼児死亡、飢餓死亡を変えない。変えてよいのは、名前のある少数と、その場に居合わせた冒険者である。これは農業文書の決定と同じ境界である。

### 6.3 科学が遅れる経路と、速まる経路

迷信として扱うとき、技術グラフのどこが退くかを経路で分ける。一つにまとめると、止める箇所が曖昧になる。

| 経路 | 中身 | 技術グラフへの入れ方の候補 |
| :--- | :--- | :--- |
| 需要の転移 | ポーションと祈祷で足りるので、薬種・病院・公衆衛生への支出が減る。需要シグナルが立たない | `medicineDemandPressure` を下げる。ノードの条件は変えない |
| 説明の閉鎖 | 占いと神託が「なぜ」を閉じ、自然哲学の試行が減る | `naturalPhilosophy` の年次蓄積に係数を掛ける |
| 人材の移動 | 素質のある者が学院へ行き、工房と大学の頭数が減る | ギルドとアカデミーの従事者を、魔法職へ移す。`rare` では人数が小さすぎて効かない |
| 測定の代替 | 識別、製作、念話が、計測器と通信の必要性を下げる | 該当ノードの需要だけを下げる。グラフ全体は止めない |
| 加速 | 同じ呪文が、実験の失敗を減らし、遠くの標本を取り寄せる | 係数を上げる側。阻害と同時に既定では入れない |

人数が少ないことと、知識の地位は別である。術者が数百人に満たないので、回復が王国の死亡率を動かすことはない。薬を買う市場も町の需要に届かない。それでも、魔法が実在するなら、医学と科学技術は迷信として扱われる（§6.5）。需要と学術の蓄積は、術者が制度になるのを待たない。

衛生そのものは残す。祈りの水はコレラの経路を断たない。水と汚物の設計を、魔法の有無で飛ばさない。

### 6.4 後で決める問い

- ポーションを、薬草から作る非魔法の薬（既存の薬種に吸収）にするか、魔法の品（冒険者の閉回路で、市場の穀物にしない）にするか。出回る範囲は決まった。小さい都市へ回せるほどは作らず、結果として大都市にしか置かない（[table-background.md](table-background.md) §13）。
- 割引の強さ。魔法があるとき医学と科学技術を迷信とする、は §6.5 で決めた。`medicineDemandPressure` と `naturalPhilosophy` をどれだけ下げるか、遅延を宇宙開発まで伝播させるかは、まだ置かない。加速の経路は入れない。魔法が実験を速くする、とは読まない。
- 復活は、払った一人を名前と人口の両方へ戻す、で決めた（[magic-agrarian-economy.md](magic-agrarian-economy.md) §10 の 6）。王国の死亡率の式は変えない。
- 軍医と従軍司祭を、戦傷の回復率に足すか。足すと戦争の人的損耗が魔法の濃さで変わり、manpower と矛盾しうる。

### 6.5 決定

現実の科学文明では、効くのは医学と科学技術で、魔法はイカサマである。魔法が実在する世界では、この評価が逆になる。効くのは魔法で、医学と科学技術の方が迷信として扱われる。

`rare` だから歴史どおりの薬種・病院・自然哲学の需要が立つ、という読みは取らない。信じられる説明が魔法側にあるなら、術者が人口の 0.05% でも、それらの業は胡散臭いものとして後景に退く。`common` を待たない。

魔法が無い `off` の地図は、今の歴史モデルのままである。こちらでは医学と科学技術が本筋である。

この決定が動かすのは、知識の地位と、それへの支出・蓄積である。王国の死亡率、幼児死亡、飢餓死亡は変えない。衛生とコレラの経路は残す。蝋の需要と交易路は、この決定に含まれない。

## 8. 既に決めてあり、本書で開かないこと

[magic-agrarian-economy.md](magic-agrarian-economy.md) より。

- セル収量の既定は変えない。植物成長は、術者がその畑に立った年の、その円だけである。
- グッドベリーと食料の創造は、市場の穀物にしない。
- 漁業の必要人手は変えない。
- 願いは定常の農政・産業政策にしない。シミュラクラムの連鎖は経済に入れない。
- 活動中の冒険者の基準は人口の 0.05%。軍の 1% を超えない。3.5e の「残り 91% が平民」は、冒険者 9% とは読まない。
- 魔法の効果量は、農業文書が置く作業仮説である。外部の呪文一覧や魔法の品の一覧からは取らない。

本書の §2 は、あの文書が「採用しない」としたアンデッド労働を、経済の既定に戻すものではない。死者由来の使役を、文化として後で許す候補に残しただけである。ストーンゴーレムは、その候補に含めない。

## 9. 後で設計するときの順

実装は、この順で設計書を分けてからにする。一つの設定で全部を切らない。

1. **棲み分けのノブ**（§5）。魔法の濃さと怪物の濃さは Cultures set から分ける、で決まった。項目名、既存セーブの移行、Cultures set に残すものは [density-knobs.md](density-knobs.md) に置いた。実装はまだである。
2. **補充と討伐**（§3）。設計は [replenishment.md](replenishment.md)。獣は生態の冬の回復、災厄とダンジョンは呪術、同じ年の力の書き手は一つ、ダンジョンの出現は `monsterDensity`、で閉じた。実装はまだである。
3. **力量と身分**（§4）。冒険者は manpower の外に置く、で決まった。戦時の召集例外は置かない。討伐の換算を書き、戦争の `power` には足さない。
4. **治療と技術**（§6）。魔法がある世界では、医学と科学技術を迷信として扱う（§6.5）。死亡率は変えない。係数は、棲み分けのノブのあとで設計する。
5. **死者の使役**（§2）。候補に残す、で決まった。対象はスケルトンやフレッシュゴーレムなど死者由来のもの。ストーンゴーレムは忌避が薄く、この候補には入れない。畑の人手の式には、その文化を名指しする設計まで入れない。
6. **§7 の行**。その行が指している既存システムを改修するときに、その行だけを設計する。

## 10. 決定と、残る問い

数値の既定値と、コードへの接続はまだしない。

1. **分ける。** 魔法の濃さ（`off` / `rare` / `common`）と怪物の濃さは、Cultures set から独立した二つのノブにする。種族と定住パターンを、術者の有無や脅威の発生と一緒に切り替えない。緩衝帯、海、地下、聖域は、この回答では置かない。
2. **二本にする。** 獣の補充は生態。災厄とダンジョンの補充は呪術。一つの型にまとめない。
3. **外に置く。** 冒険者は manpower の台帳に入れない。戦時に国家が召集する例外も置かない。国家が雇うときは契約である。兵士の 1% と二重にはしない。
4. **医学と科学技術は、魔法のある世界では迷信である。** 詳細は §6.5。`rare` だから歴史どおりの需要が立つ、という読みは取らない。魔法が無い地図は、今の歴史モデルのままである。王国の死亡率は変えない。蝋の需要と交易路は、この回答に含まれない。まだ決めていない。
5. **残す。** 残すのは、死者を由来とする使役を、後の文化が名指しできる余地である。スケルトンやフレッシュゴーレムがこれにあたる。ストーンゴーレムのように石を材料にする工作物は忌避が薄く、この余地には入れない。守衛か、別の製作伝統の問いである。

今の収穫式には入れない。畑の 5% をスケルトンで置き換えるには、100 万人あたり常勤の術者が約 1,400 人要る。`off` と `rare` の既定では接続しない。文化を名指しする設計で、どの死者をどの職に限るか、維持する術者を誰が雇うか、命令が切れたものを危険度に戻すか、禁じる宗教との外交を足すか、を決める。
