# 食料経済の栄養価監査: 設計とテスト

`docs/plan/fauna-biome-realism.md`のPhase J〜Nで行ったMilk/Cheese等の較正作業を踏まえ、「実際の人口が必要とするカロリー・タンパク質を計算し、初期に生産される商品（Cheese等）がそれをどの程度満たすか」を検証する。

---

## 0. 決定記録

**2026-08-07 調査開始**: ユーザーから「マップ生成直後の人口から必要なタンパク質・カロリーを計算し、最初に作成されるチーズその他の商品がそれらをどの程度満たすか設計・テストして下さい」との依頼。

**調査で判明した前提（重要）**: economy拡張の「食料」会計は、実は**2つの独立した系統**に分かれている。

1. **食料台帳（Grain/主食専用）**: `foodProduction.ts`/`foodLedgerConsumption.ts`が担う、飢饉・備蓄追跡の専用パイプライン。Explore agentで全面的にトレースした結果、供給側（`agriculturalLandUse.ts`の`foodPotential`、`supported`＝実人数ベース）・需要側（`ruralPopulation`/`urbanPopulation`、いずれも`pop × populationRate`で実人数化）は**両方とも一貫して実人数スケール**であることを確認した（**CONSISTENT**、単位不整合バグ無し）。`agriculturalLandUse.ts`の`STAPLE_NEED_KG_PER_PERSON_YEAR`=200kg/人/年は文字通りの実キログラム値であり、これを起点に現実の栄養science と直接照合できる。
2. **通常のGoods/Market需要充足系統**（Cheese/Milk/Fish/Game/Wine等、Grain以外の食料財全て）: `production-generator.ts`の`demandCoverage.food`/`getDemandTargets()`は、burg単位の「人口ポイント」（`burg.population`、populationRate未乗算）で一貫しており、これはこれで内部整合的だが、**食料台帳の実人数スケールとは全く別の通貨**——両者の間に共通の換算軸は存在しない。Grain自身の`biomeOutputByTag`エントリも実際には`production-generator.ts`/`markets-generator.ts`の3箇所のガードで明示的に除外されており、Grainの市場在庫は食料台帳だけが書き込む（Explore agent確認済み）。

この結果、**Grain（主食）の栄養充足率は既存データから厳密に検証できるが、Cheese/Milk等の「1ユニットが実世界で何kg/Lに相当するか」は、コードベースのどこにも定義されていない**（`unit`フィールド——"wain"/"jug"等——はフレーバーラベルに過ぎない）。今回の設計作業で、後者について新たに現実的な換算規約を定める必要があった。

**設計方針**: 2段階（Tier）構成とする。
- **Tier 1（Grain、厳密）**: 既存の`STAPLE_NEED_KG_PER_PERSON_YEAR`=200kgを、現実の穀物栄養価（カロリー/タンパク質）と直接照合。
- **Tier 2（Cheese/Milk、新規設計）**: 「1 Milkユニット＝4L」「1 Cheeseユニット＝40kg」という**新規の換算規約**を導入（既存データからの逆算ではなく、日用品・荷車積みの規模感から選んだプレースホルダー、§9.3方針通り較正TBD）。乳製品の現実の栄養プロファイルと、現実の搾乳→チーズ変換比（約10L牛乳→1kgハードチーズ）を用いて算出する。

**実装**: `src/extensions/economy/generators/nutritionAudit.ts`（新規）+ `nutritionAudit.test.ts`（14件、全件green）。Playwrightで実際に生成したマップの実人口・実Milk/Cheese在庫を読み出し、上記モジュールと同じ計算式を手動再現して検証した。

## 1. Tier 1: Grain（主食）の栄養充足率——既存較正の答え合わせ

現実の穀物（全粒小麦を基準）: 約3,400 kcal/kg、タンパク質約120g/kg（乾燥重量ベースの一般的な値）。

`STAPLE_NEED_KG_PER_PERSON_YEAR`=200kg/人/年が実際に提供する栄養:
- カロリー: 200kg × 3,400kcal/kg = **680,000 kcal/年/人**（約1,862 kcal/日）
- タンパク質: 200kg × 120g/kg = **24kg/年/人**（約65.7g/日）

現実の必要量（WHO/FAO基準、人道支援の最低ライン——WFP/SPHEREの「1日2,100kcal」基準を、年齢・性別・活動量が混在する集団全体の平均として採用）:
- カロリー: 2,100 kcal/日 × 365.2425日 = **767,009 kcal/年/人**
- タンパク質: 0.83g/kg体重/日 × 平均体重60kg ≈ 50g/日 × 365.2425日 = **18.26kg/年/人**

**充足率**:
| 指標 | Grain単独の充足率 |
| :--- | :--- |
| カロリー | **約88.65%**（680,000 / 767,009） |
| タンパク質 | **約131.42%**（24 / 18.26） |

**評価**: 既存の200kg/年という較正値は、驚くほど現実の栄養science と整合している。カロリーは約89%——「穀物だけでは足りず、Cheese/肉/魚等の補完が必要」という現実の理解と一致する、リアルな不足幅（約11%、約87,000 kcal/年/人）を残す。タンパク質は穀物単独で目標グラム数を超過する（現実にも穀物は量さえ十分ならタンパク質量そのものは充足しやすいことと整合——ただしアミノ酸組成の「質」は本監査の対象外、§3参照）。

**結論**: Tier 1は既存の較正が正しかったことを裏付ける、ポジティブな検証結果。

## 2. Tier 2: Cheese/Milkの新規換算規約と、Tier 1が残す不足分に対する寄与

### 2.1 新規換算規約（設計、既存値からの逆算ではない）

| 財 | 規約 | 根拠 |
| :--- | :--- | :--- |
| Milk（1ユニット="jug"） | 4 L | 日常的な水差し・壺のサイズ感 |
| Cheese（1ユニット="wain"） | 40 kg | 荷車積みの中規模な取引量 |

現実の栄養プロファイル:
- 牛乳: 640 kcal/L、タンパク質33g/L
- ハードチーズ: 4,000 kcal/kg、タンパク質250g/kg
- 搾乳→チーズ変換比: 約10L牛乳 → 1kgチーズ（現実の酪農における一般的な比率）

### 2.2 Playwright実地検証

Medieval Europeプリセットで新規生成したマップ（実人口 約497万人——マップ全体の合計、`pack.cells.pop × populationRate`の合計 + burg人口 × populationRate × urbanization）で計測:

| 時点 | 実人口 | Milk市場在庫 | Cheese市場在庫 |
| :--- | ---: | ---: | ---: |
| 生成直後（tick 0） | 5,013,437 | 753.7 | 44.4 |
| 5年後 | 4,972,320 | 4,870.7 | 90.4 |

Tier 1が残す不足分（5年後時点、人口4,972,320人で計算）:
- カロリー不足分 = (767,009 − 680,000) kcal/人/年 × 4,972,320人 ≈ **4,330億kcal/年**

Milk（4,870.7ユニット）+ Cheese（90.4ユニット）の実栄養価:
- Milk→チーズ換算: 4,870.7 × 4L = 19,482.8L → ÷10 = 1,948.28kg チーズ相当 → 1,948.28 × 4,000kcal/kg ≈ **779万kcal**
- Cheese現物: 90.4 × 40kg = 3,616kg → 3,616 × 4,000kcal/kg ≈ **1,446万kcal**
- 合計 ≈ **2,225万kcal**

**不足分に対するカバー率**: 2,225万 / 4,330億 ≈ **0.0051%**——地図全体スケールでは事実上ゼロに近い。

**より意味のある指標（1人あたり）**: Cheese現物3,616kg ÷ 人口4,972,320人 ≈ **0.73 g/人**（5年間累計）。1人が5年かけて手にできるチーズはひとつまみにも満たない。

### 2.3 解釈——これは今回の一連の修正が失敗した証拠ではない

Phase J〜Nを通じて、Milk/Cheeseの生産量自体は**桁違いに改善**している（Phase L修正前はCheese/Vinegar/Wineが7年経っても在庫0だった状態から、生成直後から非ゼロで安定成長する状態へ）。相対的な改善は極めて大きい。

問題は**絶対スケールの隔たり**にある: マップ全体の人口は数百万人規模だが、Milk/Cheeseの生産量は現状「数千ユニット」規模——両者の間には5〜6桁のギャップがある。これは現実の食生活とも整合する側面がある（チーズは歴史的にも大半の人口にとって主要カロリー源ではなく、穀物を補完する副次的・贅沢品的な食品だった）が、**もしCheeseが「地域住民の食生活に体感できる程度に寄与する」ことを意図するなら、現在の生産スケールは主食の代替たりえない**——これはMilk産出レート（Phase Nで一度15分の1に引き下げ済み）を「さらに」引き下げる方向の調整ではなく、**むしろ地域単位（burg/market単位）で見た時に、その地域の住民がどの程度Cheeseにアクセスできるかを見る方が実態を捉えやすい**、というのが今回の監査の結論である。

## 3. 今回の監査でモデル化していない事項（既知の限界）

- **タンパク質の質（アミノ酸組成）**: 穀物のタンパク質は必須アミノ酸組成が動物性タンパク質（乳製品・肉・魚）に比べて不完全——「グラム数だけなら足りている」という本監査のTier 1の結論は、現実の栄養学が重視する「質」の観点を捨象している。Cheese/Milk等の動物性タンパク質は、量的な充足率が小さくても質的な価値は別途大きい可能性がある。
- **地域偏在**: 今回の検証は地図全体の合計値のみ。実際には牧畜が盛んな地域とそうでない地域でCheeseへのアクセスは大きく偏るはずで、地図全体平均では実態を過小評価/過大評価しうる。
- **Fish/Game/Preserved food/Wine等、他の食料財**: 今回はMilk/Cheeseチェーンに限定して検証した。他の食料財（特にFish/Game、狩猟・漁業由来の動物性タンパク質源）も同様の手法で栄養価監査ができるはずだが、それぞれに新規の「1ユニット＝何kg」規約が必要になり、今回はスコープ外。
- **Milk/Cheeseのユニット換算規約（§2.1）は暫定値**: 他のGoodsとの整合を取った体系的な単位系ではなく、この監査のために新規に設計した第一次近似。§9.3方針同様、較正TBD。

## 4. まとめ

| 項目 | 結果 |
| :--- | :--- |
| Grain単独のカロリー充足率 | 約88.65%（現実的な不足幅を残す、妥当な較正） |
| Grain単独のタンパク質充足率 | 約131.42%（量的には十分、質は別問題） |
| Cheese+Milkが埋める残りカロリー不足の割合（地図全体、5年後） | 約0.0051%（絶対スケールで見ると無視できる水準） |
| Cheese+Milkの生産トレンド | 健全に成長中（Phase L〜Nの修正が機能している証拠） |

Grain（主食）の栄養モデルは既に妥当に較正されていることが確認できた。Cheese/Milkは「地図全体の栄養供給源」としては現状ほぼ無視できる規模だが、これは今回の一連の修正の失敗ではなく、そもそも数百万人規模の人口と数千ユニット規模の乳製品生産の間に横たわる、意図的に埋めていない絶対スケールの隔たりによるもの。地域単位での「体感できるアクセス」を今後の較正の指標にすることを推奨する。
