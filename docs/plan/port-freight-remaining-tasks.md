# 港の荷待ち・港の倉庫・陸の車両: 残る課題のタスクリスト

状態: 2026-10-20 作成。[port-freight-queue-and-warehouses.md](port-freight-queue-and-warehouses.md)(以下「元の設計」)の §10.18 までの実装の後に、まだ対応していない課題をすべて集めた。
元の設計の各節の「残る課題」・§9 の未決・§10.2 の実装しなかったことから拾い、後の節で対応したもの(取り消し線のもの)は除いた。

各タスクの「出典」は元の設計の節番号。「場所」は手を入れる見込みのファイル。

## 1. 海と港

- [x] **T1 倉敷料**(2026-10-20、元の設計の §10.20)
  - 出典: §4.4、§5.2、§10.2、§10.11
  - 今: 港で待つ荷は費用を払わない。§10.11 で海の荷の待ちを一季節(90 日)延ばしたので、港の倉庫の費用が史実より安い。
  - やること: 港で待つ荷が、枠・日あたり `PORT_STORAGE_FEE` を港の都市(倉庫の持ち主)に払う。収容力を超えた荷は倍額。§7.2 の指標(運転資金不足 / 成立、支払いの比)を見て額を決める。
  - 場所: `portWarehouses.ts`、`exportStaging.ts`、`caravans.ts`

- [ ] **T2 収容力を超えた荷の傷みの割増**
  - 出典: §4.4、§10.2
  - 今: 収容力を超えて岸に積んだ荷も、倉庫の中の荷と同じ速さで傷む。
  - やること: 収容力を超えた分の食料の傷みを早める(案 1.5 倍)。T4(隊商を港で分ける)の後でないと、荷が港の倉庫に入らないので効かない。
  - 場所: `portWarehouses.ts`、穀物の傷み([grain-storage-life.md](grain-storage-life.md))

- [x] **T3 期限を過ぎた荷を港で売る**(2026-10-20、元の設計の §10.20。倉庫の荷(`ExportStagingLot`)は出発地に戻すまま)
  - 出典: §4.4、§10.2
  - 今: 期限を過ぎた荷は出発地の市場に戻る。
  - やること: 港の都市の市場で、地元の価格の `STALE_SALE_DISCOUNT` 倍(案 0.7)で売り、差額を商会の損にする。港を持たない市場の荷(§10.7)は、別の市場の港で売ることになる。
  - 場所: `exportStaging.ts cancelStaleLots`、`caravans.ts waitForTransport`

- [x] **T4 隊商を港で分ける**(2026-10-20、元の設計の §10.19)
  - 出典: §4.1(P4)、§10.2、§10.11
  - 今: 陸と海の区間を 1 つの隊商で進む。港の倉庫の収容力は、荷の行き場としては効いていない。
  - やること: 陸の区間の隊商が港の倉庫に荷を降ろし、海の区間は港の倉庫から船に積む。T2・T5 の前提。
  - 場所: `caravans.ts`、`exportStaging.ts`、`portWarehouses.ts`

- [x] **T5 川と海を通る荷の予約**(2026-10-20、T4 と同じ仕組みで対応。元の設計の §10.19)
  - 出典: §10.11
  - 今: 川で港へ下り海へ出る荷は、出発のときに川船と港の船を同時に予約する。どちらかが空くまで出られない。
  - やること: T4 の後、川船だけで港まで下り、港で船を待つ。
  - 場所: `caravans.ts`、`merchantTransportAssets.ts`

- [ ] **T6 倉庫を建てる費用**
  - 出典: §5.2、§10.2
  - 今: 倉庫は無償で建つ。
  - やること: 枠あたり `PORT_WAREHOUSE_COST_PER_SLOT` を、港の市場の商会の資本から払う。払えなければ建てない。お金の校正への影響を §7.2 の指標で確かめる。
  - 場所: `portWarehouses.ts`

- [ ] **T7 運賃積みの運賃を誰が受け取るか**
  - 出典: §9(未決)、§10.2
  - 今: ほかの市場の船に積んでも、運賃は出発地の運送業者の収入になる。
  - やること: 船の持ち主の市場の運送業者に払うか、船の持分を持つ商会に払うか([corporation.md](corporation.md) の持分の扱い)を決めて実装する。
  - 場所: `merchantTransportAssets.ts`、運賃の扱い(`freightUnitCost`)

- [ ] **T8 船の注文のきっかけ**
  - 出典: §4.7(P3)、§10.2、§10.8
  - 今: §17.2(long-distance-merchant-reach-capital.md)のまま。予約できなかった枠が、自前の船も借りられる船もない市場だけに残るので注文する。
  - やること: 「港の荷待ちが、泊まる船と着く船の積載の `HULL_ORDER_BACKLOG_MONTHS`(案 2)か月分を超える状態が続く」をきっかけにする。T10 の量の減りを、船を増やして戻す手段にもなる。
  - 場所: `transportAssetOrders.ts queueSimulationReplenishment`、造船の拡張

- [ ] **T9 荷待ちの数え方**
  - 出典: §10.6(「未」のまま)
  - 今: 荷待ちに、満載を待って荷を集めている隊商も数える。§10.10 で、港に残す船を需要の分だけにしたので、空いた船を抱え込むことは減った。数え方そのものは変えていない。
  - やること: 出発の時期を過ぎても船のない荷と、船がなく予約できなかった荷だけを数えるかを、§10.10 の後の挙動で確かめてから決める。
  - 場所: `portWarehouses.ts collectSeaDemandSlots`

- [ ] **T10 船の往復による海の量の減り(world の地図)**
  - 出典: §10.8、§10.9、§10.10
  - 今: 船が 1 航海ごとに荷を探すか空船で戻るので、world-102 の 3 年目の高額品の取引は §10.7 の後(304 件)に戻っていない(§10.10 の後 147 件)。world の地図では港の間が遠く、30 日以内に着ける船が少ない。
  - やること: 原因を、船の数(T8)、回航の判断、照合の流れの変化に分けて調べる。
  - 場所: `merchantTransportAssets.ts repositionIdleHulls`、`portWarehouses.ts`

## 2. 陸の輸送と車両

- [ ] **T11 陸の荷の出荷を試すのが月に 1 回**
  - 出典: §10.11、§10.12〜§10.18 の残る課題
  - 今: 出荷を試すのは生産の周期の初めだけ。車両が出払った市場では小さな荷が 1 か月待ち、続けて出払うと期限を過ぎる。陸の荷も積み込みに入って車両を待たせると、待つ隊商が増えて取り消しが増えた(§10.11 で 122 件)ので入れていない。
  - やること: 毎日の更新で、車両が戻ったときに倉庫の陸の荷の出荷を試す、などを試して取り消しの増減を計測する。§10.14 で地元の運送人を雇えるようになった後の状態で測り直す。
  - 場所: `caravans.ts`、`exportStaging.ts`

- [ ] **T12 world-102 の 3 年目の、陸の枠で止まる組**
  - 出典: §10.10、§10.11、§10.18
  - 今: world-102 の 3 年目の `noTransport` は 77〜250 件で、多くは陸の枠で止まる組(海の枠ではない)。§10.14 の地元の運送人の後も残る。
  - やること: どの市場・経路で止まるかを調べる。照合の陸の枠(`buildTransportRoom`)と、出発時の車両の割り当てのずれも見る。
  - 場所: `tradeTransportRoom.ts`、`merchantTransportAssets.ts`

- [ ] **T13 隊商が失われたときの車両と馬**
  - 出典: §10.17、§10.18
  - 今: 隊商が失われても、自前の車両は修理に入って 30 日で戻り、馬も失われない。
  - やること: 失われた隊商の車両の一部(またはすべて)と、その馬(`MerchantLandAssetBalance.draftAnimalHeads` の分)を失うようにする。盗賊・戦争による損失(`TradeSecurity`)との関係を決める。
  - 場所: `merchantTransportAssets.ts settleCaravan`

- [ ] **T14 Horses の 1 head と、軍の騎兵の馬の需要**
  - 出典: §10.17、§10.18
  - 今: 車両では市場の Horses 1 head を馬約 25 頭として買う(値段と Leather のレシピから決めた)。軍の騎兵の馬の需要が何頭を 1 head と数えているかは、まだ揃えていない。
  - やること: 軍の需要(`militaryResources.ts` などの Horses の消費)の数え方を調べ、1 head の大きさを 1 つにする。馬具を揃えた §10.18 と同じく、古い保存の読み替えが要るかを確かめる。
  - 場所: `militaryResources.ts`、`metallurgWork.ts`、`transportAssetOrders.ts`

- [ ] **T15 馬のない市場の車両**
  - 出典: §10.17
  - 今: 市場に Horses の在庫がないと、車両を造れない(province-101 の 15 市場のうち 5 市場)。
  - やること: 牛(荷車・荷馬車を牛に牽かせる)、ラバ、駱駝(荷駄)で代える選択肢を、時代・文化圏とあわせて検討する。
  - 場所: `transportAssetOrders.ts`(`TransportAssetBlueprint`)

- [ ] **T16 届けた先で車両ごと売る取引がほとんど起きない**
  - 出典: §10.13、§10.17
  - 今: 5 年で数台。車両の要る拠点の市場は自分で荷を送り出す側で、車両の余る市場から荷が届くことが少ない。
  - やること: 余った車両を、要る市場へ回送して売る(空の隊)ことを入れるか、今のままでよいかを決める。
  - 場所: `transportAssetOrders.ts sellArrivedVehicles`、`merchantTransportAssets.ts`

## 3. 生産・軍需

- [ ] **T17 武器・弾の国の注文と、調整の表の月の量**
  - 出典: §10.18
  - 今: Arms と Bullets は、調整の表(`craftDemandCalibration.ts`)では軍の台帳から量を取る品(`militaryLedger`)だが、国の注文を月の量に足していない。国の注文が月の量を超えると、§10.18 の前の馬具と同じく造りきれない。
  - やること: 国の注文の進み具合(完成した量 / 注文の量)を地図ごとに測り、足りなければ馬具と同じく、国の注文の残りから市場の在庫を引いた分を月の量に足す。
  - 場所: `production-generator.ts buildRemainingCalibratedLots`

## 4. 季節・時代(元の設計の P6)

- [ ] **T18 季節の休航**
  - 出典: §4.6、§10.2
  - 今: 冬も船が出る。§10.11 で、海の荷が一季節長く待てるようにだけした。
  - やること: 出港日(`tradeSailSchedule.ts`)に休航の月を足す。
  - 場所: `tradeSailSchedule.ts`

- [ ] **T19 収穫月の雇い足しの制限**
  - 出典: §3.3、§10.2
  - 今: 雇える台数は 1 年中同じ。
  - やること: 収穫月は、牽く家畜と人手が農作業に取られるので、雇える量を減らす(案 0.5 倍)。§10.14 の地元の運送人の台数にも掛ける。作物暦([farm-labour-calibration.md](farm-labour-calibration.md))を使う。計測で穀物の流れが偏るときに入れる。
  - 場所: `merchantTransportAssets.ts hireCap`、`refreshLocalCarriers`

## 5. 校正(仮の値)

- [ ] **T20 地元の運送人の台数**
  - 出典: §10.14
  - 今: 農村人口 1,000 人あたり荷駄 0.2・荷車 0.2・荷馬車 0.1 台(1 台は実物 20 台ほどの隊)。仮の値。
  - やること: 史料で、農村の牽く家畜と荷車の数、雇って運べる割合を調べて決める。
  - 場所: `merchantTransportAssets.ts LOCAL_CARRIERS_PER_THOUSAND_RURAL`

- [ ] **T21 村の車大工の人数**
  - 出典: §10.16
  - 今: 農村人口 1,000 人あたり 0.3 人。仮の値。
  - やること: 史料で、村の車大工・馬具師の数と、運送人の車を造る割合を調べて決める。
  - 場所: `transportAssetOrders.ts RURAL_TRANSPORT_CRAFT_PEOPLE_PER_THOUSAND`

- [ ] **T22 港の倉庫の初めの値と大きさ**
  - 出典: §9(未決)、§10.4
  - 今: province-101・world-102 では多くの港で、倉庫が初めの値(人口 × 40 枠)のまま。取扱量が人口に比べて小さい。§5.3 の 1 棟の大きさ(B 型)と枠あたりの床面積も目安のまま。
  - やること: 海の交易の多い world の地図で収容力の分布を見る。初めの値を地図の作成時の人口で決めてよいかを決める。CE で描いた大きさを Bryggen・日本橋の河岸の図と比べる。
  - 場所: `portWarehouses.ts`、`quayWarehousePlacement.ts`

## 7. 未決と計測

- [ ] **T26 回航で船の集まる港の偏り**
  - 出典: §9(未決)
  - 今: §10.10 で、回航の割合の上限(半分まで)をやめ、需要の残りで行き先を決めるようにした。偏りが大きすぎないかは測っていない。
  - やること: 港ごとの泊まる船の数と荷待ちの分布を測る(T27 とあわせて)。

- [ ] **T27 §8 の計測項目をまとめて取る**
  - 出典: §8
  - やること: 港ごとの荷待ちの枠と待ちの日数の分布(中央値・90%)、船の積み荷の比(自分の市場の荷 / ほかの市場の荷)、回航した船の数、陸の雇った枠・日と注文した車両の数、港の倉庫の収容力の分布と型の数を、province-101(5 年)・world-102(3 年)で一度にまとめて取る。
