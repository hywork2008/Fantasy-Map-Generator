# 結論の出た問い

調べ終えた問い、採らなかった案、許容した残りを、テーマごとに一か所に置く。次の作業や原因の仮説を出す前に、この表で同じ問いを探す。表にある問いは、「再開の条件」を満たす新しい数字が出た時だけ開き直し、開き直す時はこの表の行を書き換える。

各行の書き方：問い・結論・根拠（記録へのリンク）・再開の条件。調べ終えた時と、案を採らなかった時に、その作業の中で行を足す。
