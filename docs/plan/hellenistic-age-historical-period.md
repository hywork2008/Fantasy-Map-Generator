# Historical period: ヘレニズム時代（hellenisticAge）の追加設計

## 状態

**設計のみ・未実装（2026-10-16）。** [classical-antiquity-historical-period.md](./classical-antiquity-historical-period.md) の決定事項8（`hellenisticAge` を将来追加する）を受けた別文書。古典古代・古代末期（P0〜P3）の仕組みの上に、さらに古い1時代を足す。

---

## 1. 要約

- 追加する値は `hellenisticAge`（c. 前330–前30、アレクサンドロスの東征からプトレマイオス朝の滅亡まで）。`HISTORICAL_PERIODS` の先頭、`classicalAntiquity` の前に入る。
- 性格は「科学・機械学は古代の頂点だが、ローマ型の土木（コンクリート・舗装軍道網・長距離水道）と広域統一行政はまだ無い」時代。§2.3 の比較表のとおり、古典古代とは得意分野が入れ替わる。
- P0 で時代の一覧と比較関数を共通化したため、追加の手間の大半は時代ごとの表に1行足すことになる。新しい仕組みが要るのは、ヘレニズム固有の軍事（象・サリッサ密集陣）と大型ガレーだけ。

## 2. 調査: ヘレニズム時代の知識・技術

### 2.1 到達点

| 分野 | 状況 | 年代の目安 |
| --- | --- | --- |
| 科学・数学 | エウクレイデス『原論』、アルキメデス（浮力・てこ・円周率）、エラトステネスの地球周長測定、ヒッパルコスの三角法と歳差。アレクサンドリアのムセイオンと図書館 | 前300〜前130 |
| 機械 | クテシビオスの押し上げポンプ・水時計、アルキメデスの螺旋揚水機、ビザンティオンのフィロンの機械書（最初の水車の記述を含む）、アンティキティラ島の機械 | 前3〜前1世紀 |
| 軍事技術 | ねじり式投射機の完成（前4世紀半ば）、攻城塔ヘレポリス（前305）、シラクサ防衛のアルキメデスの機械（前212） | — |
| 軍事編制 | サリッサ密集陣（マケドニア式）、重騎兵（ヘタイロイ）、戦象（セレウコス朝・プトレマイオス朝）、東方のカタフラクト。常備は王の近衛と傭兵が中心で、ローマ型の職業軍団ではない | — |
| 海軍 | 大型多段櫂船（五段櫂船、デメトリオスの十六段櫂船、プトレマイオス4世の巨艦）。灯台ファロス（c. 前280） | — |
| 都市 | ヒッポダモス式の格子街区、アゴラ・ストア・劇場・ギュムナシオン。アレクサンドリア・アンティオキア・セレウキアは数十万人規模 | — |
| 上水 | 都市の水道は短く、ペルガモンの圧力配管（c. 前180）が最先端。長距離の重力式水道網と公衆浴場の普及はローマ期 | — |
| 建築・土木 | 切石の石造、木組み屋根。水硬性コンクリートは無い（ローマで前2世紀から）。道路は舗装されないものが大半 | — |
| 文字・知識 | パピルス、ペルガモンの羊皮紙（前2世紀）。ギリシア語の共通語（コイネー）。ポリスの市民男性の識字はローマ期の地方より高いとされる | — |
| 貨幣・商業 | アッティカ基準の銀貨（テトラドラクマ）が東地中海の共通通貨。銀行・両替。ローマのような単一帝国の統一市場は無く、王国ごとに分かれる | — |
| 農業・動力 | 二圃式と軽い犂。水車は記述が現れる程度。風車・鐙・三圃式は無い | — |
| ガラス | 鋳造・コア成形。吹きガラスは前1世紀末で、この時代の終わり | — |

## 3. 既存システムへの対応

`HISTORICAL_PERIODS` に足せば、型で網羅されている表（§3.1 of the antiquity plan）はコンパイルエラーで漏れが分かる。それ以外の判定は次のとおり。

| システム | ヘレニズムの値 | 根拠・備考 |
| --- | --- | --- |
| 技術の開始段階（`EARLY_PERIOD_START_STAGE`） | `classicalAntiquity` の行を写し、`urbanCoveredDrainage` を known、`commercialFinance` を known、`mathAstronomyGeography` を demonstrated に上げる | 天文・地理はこの時代が頂点。mathAstronomyGeography は橋の skew tier 1 のゲートでもあるが、adopted 未満なので tier 0 のまま（AGENTS.md） |
| 橋 | tier 0（石造15°・木造20°）、渡河長 300 m、単径間 20 m | ローマ型の大アーチ橋はまだ少ない |
| 都市上水 | 上限 `{ waterLifting: 0.5, municipalSanitation: 0.45, sanitaryEngineering: 0.05 }`、`ancientCivicWaterworksFloor` は首都級だけ tier 2 | 揚水機械はあるが長距離水道網は無い |
| 識字 | 古典古代と同程度（貴族 60/50、平民 18/10） | ポリスの市民教育 |
| 都市形態 | 標準2階・最大3階 | 高層集合住宅はローマ期 |
| 舗装道路の拠点数 | 中世と同じ（最大3） | 舗装軍道網はローマ期 |
| 軍事 | 騎兵 ×1.0、歩兵 ×1.1、攻城兵器あり | サリッサ密集陣と重騎兵の併用 |
| 艦隊 | 国有分はガレー（古代2時代と同じ `galleysForStateHulls`） | 多段櫂船は §4 で検討 |
| 文化・宗教 | ローマ・ギリシア系は `classicalPolytheism`・`classical`（`classicalAntiquity` の行が前の時代も覆う仕様のまま） | `traditionEra` は最初の行がそれ以前も覆う |
| CE の城 | `ancient-castra`（アクロポリスとして描かれる） | 将来、専用の `hellenistic-acropolis` を検討 |
| 風車 | 無し（`WINDMILL_PERIODS` に入れない） | — |

## 4. 新しい仕組みが要るもの

1. **戦象**: 新しい unit（type `mounted`、power 高、crew 多、象の入手に地域制限）。象の産地（南アジア・北アフリカ相当のバイオーム）を持つ国だけが徴募できる仕組みが要る。既存の騎馬の家畜容量（`refreshMountedCapacity`）と同じ形で「象の頭数」を Economy に持たせるかが論点。
2. **大型多段櫂船**: ガレーの上位級（`role: "warship"`、乗員 400 前後）を足すか、ガレー1級のままにするか。
3. **アクロポリス型の城**: CE の城の様式を1つ足す。
