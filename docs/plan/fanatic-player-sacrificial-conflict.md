## 1. プレイの中心

プレイヤーは「人間の争いと死を神に捧げる」教義を持つ結社の一員となる。国家の征服や自国の勝利は手段であり、目的は **自分たちの働きかけによって、多くの国の人間を争いに巻き込み、戦争による死を奉納すること**。他国同士の戦争、教団軍による遠征、同じ信仰内部の分裂も使える。

ただし、世界は思いどおりには動かない。平和的な君主を排除しても後継者がさらに和平を進めることがある。強い兵器は短期決戦を生み、双方への支援は教団包囲網を生む。戦死者が増えれば、税・寄進・食糧・新兵・布教相手も減る。**布教の成功、戦争の成功、奉納の成功は別々に評価する。**

将軍草案から継承する原則は、PC の肩書だけで国家全体を動かさないこと、行動に従う人物・資産を明示すること、実際に動ける軍がなければ開戦を成立させないこと。将軍が「兵の服従」を扱うのに対し、本設計は「教会網・有力者の支持・敵対感情・教団への疑惑」を扱う。

舞台は架空の国家・神格・宗教で構成する。暗殺・工作・兵器開発は対象、必要資源、期間、判定、世界状態への効果を持つゲーム内プロジェクトとして表現する。

## 2. 信仰と結社を分ける

宗教地図の同一色をすべて狂信者として扱わない。同じ宗教内に、普通の信徒、和平派、教会組織、秘密結社が共存する。高 Piety も自動的な好戦性や結社への服従を意味しない。

例として「赤き暁の聖餐会」を置く。表向きは戦没者の鎮魂と救貧を行い、内側には「戦場で失われた命が眠る神を養う」という教義を持つ。既存宗教の内部派閥として始めても、独立教団・国教として始めてもよい。名称・神・表向きの活動は変更可能。

| 層 | 意味 | 主な変化 |
| :-- | :-- | :-- |
| 信仰人口 | 地域の通常の信徒。結社員とは限らない | 布教、改宗、離反 |
| 教会拠点 | 教会・修道院・神殿。所在地は burg | 建立、閉鎖、接収、管理者交代 |
| 結社支部 | 拠点に接続する組織。信仰人口とは別の所属 | 支部設立、追放、地下化 |
| 協力者 | 結社への忠誠または取引関係を持つ個人 | 登用、拒絶、告発、寝返り |
| 動員資産 | 実際に使える寄進・施設・補給・兵力 | 消費、移送、喪失 |

公然教団でも全員が秘密教義を支持するとは限らない。支部ごとに穏健派／奉納派の支持を持ち、過激な命令への拒否、分裂、指導者交代を可能にする。

## 3. 開始立場と権限

狂信者は独立した職業クラスではなく、所属結社と信条の組合せ。実行権限は現在の役職、所属、所在、預かった資産から判定する。下位職のまま世界に影響する遊びも完結させ、昇進を必須にしない。

| 立場 | 最初にできること | 預かる資産 | 制約と固有の危機 |
| :-- | :-- | :-- | :-- |
| 遍歴修道士 | 現地布教、教義研究、支部間の連絡、人物との関係形成 | 私財、個人的な協力者 | 遠隔支部へ命令できない。移動と現地活動は同時にできない |
| 地方司祭 | 教区運営、寄進集め、地方有力者への働きかけ、支部設立 | 教区の承認済み予算 | 司教・領主の監督。献金流用が露見すると失職 |
| 修道院長 | 人材養成、研究後援、他国支部への資金提供 | 修道院資産、研究席、連絡網 | 食糧・維持費・内部支持が必要。研究施設の接収に弱い |
| 宮廷司祭／高位聖職者 | 君主への進言、外交仲介、後継候補支援、聖戦支持の取りまとめ | 宮廷への接近権、教会内の発言力 | 国庫・軍命令は持たない。君主や上位教会から更迭される |
| 教団長 | 支部への依頼、教義方針、奉納対象の指定、教団軍の編成 | 教団資産、服従する支部・軍 | 地方支部は命令を拒否できる。領土・主権は自動取得しない |
| 宗教国家の指導者 | 正式な宣戦、戦費配分、国営研究、教団外交 | 通常の君主としての国庫・軍＋別会計の教団資産 | 臣民・軍の忠誠は別。領土喪失、財政破綻、反乱 |

開始設定では既存の生存人物に役職と小規模な支部を割り当てられる。宗教国家ルートは実際の landed ruler を選ぶ。称号の文字列に「教皇」があるだけでは国家権限を与えない。

## 4. 資源と世界の反応

以下は新設する設計値。人物の既存能力値と混同しない。金額・日数・閾値は初期調整値であり、ゲーム速度に合わせて検証する。

| 指標 | スコープ | 用途／増減 |
| :-- | :-- | :-- |
| 教団資金 | 結社・支部 | 寄進で増加、維持・後援・作戦で減少。国庫と別会計 |
| 布教基盤 | 支部、0–100 | 布教・地域サービスで増加。追放・戦災・教義露見で減少 |
| 奉納派支持 | 支部、0–100 | 過激な命令への賛否。通常の信仰人口を表さない |
| 結束 | 結社、0–100 | 指令の履行・継承の安定。損耗、資金偏在、裏切りで低下 |
| 影響力 | 結社→人物、0–100 | 面会・提案受諾の補正。人物の意思を上書きしない |
| 疑惑／証拠 | 国家→結社 | 疑惑は捜査の契機、証拠は接収・告発・国際協力の根拠 |
| 対立圧力 | 国家ペア、0–100 | 争点の強さ。外交関係の Enemy や開戦認可とは別 |
| 戦争疲弊 | 戦争参加国 | 損耗・補給難による和平要求。奉納派支持とは別 |
| 奉納累計／恩寵 | 結社 | 累計は実績、恩寵は消費資源。別々に保存する |

疑惑は活動停止で徐々に下がるが、証拠は時間だけで消えない。作戦の成否と露見は独立に判定する。成功して露見、失敗して未発覚、責任は不明だが捜査が始まる、といった結果を用意する。

## 5. 基本ループと作戦の処理

1. 地図上の支部・宮廷・隣国関係・進行中の戦争を観察する。
2. 現地活動または支部への依頼を選び、対象・資源・期間・目的を予約する。
3. 協力者が受諾するか判定し、受諾後に進行する。拒否なら未使用の予約資源を戻す。
4. 作戦完了時に効果と露見を別々に解決し、関係者が応答する。
5. 危機が開戦へ進んだ場合、軍事シミュレーションが戦闘と死者を確定する。
6. 有効な奉納契約に該当する死者を計上し、恩寵・内部対立・世界の反撃へ返す。

作戦状態は `proposed → committed → resolving → completed / failed / cancelled`。中断時は未使用資源のみ返す。死亡・逮捕・役職喪失・支部接収は対象作戦を再検証する。PC 自身が働く長期活動は移動・他の専従ジョブと排他。委任活動も担当者、支部容量、維持費を消費する。

進行は暦日による期限、研究は既存の年次評価、軍事は既存の時間進行規則に従う。ロードや PC の切替で抽選をやり直さず、作戦 ID と保存済みの乱数状態で結果を固定する。

## 6. プレイヤーが取れる行動と結果

### 6.1 布教・組織・根回し

| 行動 | 条件・負担・期間の目安 | 成功時 | 失敗／副作用 |
| :-- | :-- | :-- | :-- |
| 現地布教 | 現地滞在、14–30 日 | 布教基盤、接触できる人物が増える | 教義が受け入れられず停滞。露骨な戦争礼賛は通報される |
| 救貧・鎮魂事業を運営 | 拠点、継続する資金・物資、30 日〜 | 地域との関係、寄進、協力候補が増える | 資源は実際に消費。援助された住民が戦争に協力する保証はない |
| 支部を設立 | 現地の協力者、布教基盤、設立費、30–90 日 | その burg に継続活動・委任の枠ができる | 当局の拒否、上位教会の処分。全土への効果はない |
| 奉納教義を説く | 支部、人材、30 日 | 奉納派支持が上がり、聖戦・奉納契約への支持を得る | 穏健派の離脱・告発、通常の寄進減少 |
| 有力者へ根回し | 面会可能な人物、贈与または継続的関係、14–60 日 | 特定の提案への支持。好戦派将軍や後継候補との協力 | 拒絶・費用損失。人物の性格、利害、君主への忠誠で抵抗 |
| 聖戦支持を取りまとめる | 複数支部の支持、教団内の権限、30–90 日 | 指定国家への開戦提案に宗教的支持を加算 | 他宗派の反対声明、支持国の条件追加、教会分裂 |
| 後継候補を支援 | 実在候補、継承制度への接点、60–180 日 | 後継者選定や就任後の関係に補正 | 候補の敗北・方針転換。王位を直接書き換えない |

### 6.2 国家間の工作と和平妨害

工作は「架空の事件・争点カード＋人物の反応」で解決し、現実の実行手順は扱わない。対象ペアに支部または協力者との接点が必要。

| 行動 | 条件・負担・期間の目安 | 成功時 | 失敗／副作用 |
| :-- | :-- | :-- | :-- |
| 国境・聖地の争点を政治問題化 | 既存の争点、現地基盤、30–60 日 | 対立圧力と強硬派支持が一時増加 | 共同調査や譲歩で争点が解消。教団への疑惑 |
| 相手国への疑念を生む工作 | 両国の接点、作戦費、30–90 日 | 期限付きの不信修正。外交提案の受諾率が低下 | 矛盾の発覚で両国が接近、教団を共同捜査 |
| 強硬派の政治活動を後援 | 対象人物の受諾、資金、30–90 日 | 開戦提案への支持と発言力が増える | 相手は資金だけ受け取ることもある。支持した人物に依存 |
| 和平交渉を妨害 | 進行中の和平案件、接点、14–30 日 | 交渉を一段階遅延、または追加条件を発生 | 仲介者の信用が上がり交渉が前進。延期回数には上限 |
| 平和的な為政者の暗殺を企図 | 実在・生存する人物への接近可能性、担当者、費用、30–90 日 | 成功時は既存の死亡・継承処理へ渡し、後継者が政策を再評価 | 失敗、逮捕、告発、支部閉鎖。成功しても殉教的評価により和平派が強まる可能性 |
| 戦時の融資・補給契約を申し出る | 受諾国、余剰資金・物資、輸送可能性 | 補給不足の緩和で戦争継続の選択肢が増える | 未返済、輸送損失、敵国からの敵視。支援だけで敵軍を操作できない |
| 敵対する双方を支援する | 双方の個別受諾、別々の資源予約 | 一方的な崩壊を遅らせうる | 二重取引の発覚、禁輸、共同で教団を攻撃。長期戦になる保証はない |

暗殺では「人物を殺す判定」と「望む政治結果になる判定」を分離する。対象死亡後は、実際の後継候補、継承争い、軍の忠誠、当事国の利害を使う。後継者を都合よく新規生成して好戦性を保証しない。

同じ対象への同種工作は同時に 1 件、失敗後は原則 90 日の再準備期間。対立修正は期限付き、同系統の累積には上限を設ける。ボタン連打で必ず Enemy にする経路を作らない。

### 6.3 兵器開発・軍事化

| 行動 | 条件・負担 | 成功時 | 失敗／副作用 |
| :-- | :-- | :-- | :-- |
| 兵器研究を後援 | 研究可能な施設・人材・既存技術の前提、年次資金 | 既存の知識・試作・実証へ寄与 | 試作失敗、費用増大、施設接収。技術段階は飛ばさない |
| 軍需生産を後援 | 採用済み技術、原料、労働、製造施設 | 実在の装備供給を増やす | 食糧・民需との競合、財政悪化、敵への技術拡散 |
| 装備供与を提案 | 在庫・輸送・受領者の同意 | 指定された軍の更新・補充 | 横流し、輸送損失、停戦で契約終了 |
| 教団軍を募る | 指導権、支持者、募集人口、給与・装備・糧食 | 所属・忠誠が明確な連隊を編成 | 奉納教義への反発、脱走、人口と生産力の低下 |
| 聖戦遠征を命じる | 自軍の指揮権、行軍可能な陸上兵力、補給・目標 | 実際の移動・戦闘・包囲へ進む | 出征拒否、敗北、教団拠点への反攻 |
| 外国軍務官に独走を要請 | 協力関係、軍務官本人の受諾 | 将軍草案と同じ服従・陸上戦力条件を評価する | 君主への告発、将軍更迭、教団への制裁 |

研究方針は「動員維持」「防御強化」「攻城能力」「野戦装備」など既存技術に接続する効果カテゴリで選ぶ。独自の研究ポイントや製造レシピは追加しない。高威力の装備でも、戦争の短期終結や抑止によって奉納数が減る。

教団軍の非国家所有は後期実装。第一スライスで中立国家 `states[0]` に兵を押し込まない。宗教国家なら既存の国家軍、外国将軍なら明示的に受諾・服従した軍を使う。教団への寄進と国庫支出も一つの残高として扱わない。

## 7. 危機から開戦への移行

**対立圧力が高いだけでは開戦しない。** 当事国に「抗議／調査／譲歩／動員／開戦」の応答を発生させる。軍事的見通し、財政、君主の気質、和平派・強硬派、同盟・従属関係を評価する。

初期判定案は、適用可能な指標を 0–100 に正規化し、`p = clamp(0.5 + (支持側評価 - 抵抗側評価) / 200, 0.05, 0.90)`。技能だけでなく関係・資源・制度的権限を含め、未定義値は中立値とする。権限・接点・有効兵力の不足は確率低下ではなく実行不可。暗殺の実行成否と、政治判断の受諾は別の評価器を使う。

| 状況 | 国家・軍の決定 | 認可と命令の扱い |
| :-- | :-- | :-- |
| 通常の関係悪化 | 抗議・調査に留まる | 外交修正のみ。認可なし |
| 工作を受けた君主が開戦を決断 | 当事国の正式な国家戦争 | 当該ペアだけ PC 起因の危機を根拠に認可 |
| 将軍が君主に反して出征 | 本人受諾＋服従判定が成功 | 将軍草案の独走認可・軍命令制限を再利用 |
| PC が宗教国家の君主 | 通常の君主権限で宣戦 | 通常のプレイヤー戦争＋結社の因果記録 |
| 主権を持たない教団の遠征 | 教団軍だけが参加 | 非国家交戦モデル完成後に提供 |

`playerDirected` では、PC が作戦を確定するときに「成功すれば A 国と B 国の戦争へ進む可能性」を明示する。作戦の対象ペア・有効期限を持つ危機レコードだけが、新設する仲介経路を通じて開戦できる。敵対関係の変化を監視して NPC 全員に自律開戦を許可する実装にはしない。

同盟参戦や第三国への波及は別ペア。第一スライスでは自動参戦させず、危機の追加として提示し、プレイヤーがゲーム内でその拡大を選んだ場合だけ認可する。autonomous では通常の AI 判断が追加戦争を起こせるが、それだけで結社への奉納権は付かない。

正式な君主の戦争は発案者の司祭が死んでも継続する。将軍独走の終了は将軍草案に従う。作戦取消は未発生の効果を止めるだけで、既に成立した他国の戦争を取り消さない。

## 8. 奉納と恩寵

### 8.1 何を生贄として数えるか

戦闘前に教団が「この戦争／戦域を神に捧げる」と奉納契約を結ぶ。契約には戦争 ID、対象側、期間、担当支部、維持費を持たせる。敵味方双方を捧げる教義でもよいが、同じ死者を二重に数えない。

計上には以下の両方を要求する。

- **関与**：教団の作戦が開戦の因果レコードに含まれる、実際に自軍が参戦する、または受領済みの補給・装備支援が対象戦争に有効である。
- **奉納の維持**：契約が戦闘前から有効で、担当支部と担当者が活動可能、維持費が支払われている。

無関係な世界の戦死者を自動で回収できない。戦闘後の契約追加、過去の年代記、開戦回数、軍の解散・移管・再生成を奉納数に使わない。

`捧げた人数 = 対象戦闘で確定した人間の死者 × 有効な奉納割合`。端数は契約内で繰り越す。種族が混在する世界では死亡側の種族別内訳を要求し、国家の多数派だけで全員を人間とみなさない。種族内訳が得られない場合は「種族未確定」と別表示し、人間の実績には加算しない。

既存の包囲・小競り合いには兵数減少から得る `attackerDead` / `defenderDead`、`deadA` / `deadB` がある。これを死亡イベントの候補とし、戦力単位の `attackerCasualties` や年代記の概算値を人数として読まない。新しい奉納処理は既存の人口減算を再実行しない。

第一スライスは戦闘死のみ。将来の捕虜奉納は捕虜集団の人数・所有・生死を持つモデルができてから追加する。戦死済みの者を捕虜に戻さない。飢餓・疫病・難民も独立した死亡因果モデルができるまでは奉納点に換算しない。

### 8.2 報酬と終局目標

表示上の「奉納累計」は実人数。「恩寵」は規模による暴走を抑えるため、一定期間の奉納数から逓減換算する消費資源。通常の Piety や教団資金へ自動変換しない。

| 恩寵の使用 | 効果 | 代償・制限 |
| :-- | :-- | :-- |
| 神託 | 対象人物の判断傾向や危機の推定精度が一定期間上がる | 意思の強制や確定結果の予知ではない |
| 熱狂の祝福 | 奉納派支部の結束、または対象教団軍の士気へ期限付き補正 | 穏健派の離反。国家全軍には掛からない |
| 聖遺物の覚醒 | 既存効果体系に収まる局所補正を解禁 | 維持費、拠点への注目、奪取の危険 |
| 大奉納 | 累計・複数国への関与・維持中の拠点条件で終局イベント | 準備が公知となり、対教団連合が阻止に来る |

超自然効果は開始設定で「実在／信仰のみ」を選ぶ。「信仰のみ」では恩寵を教団内部の権威として扱い、神託は情報網、祝福は儀礼による士気へ置き換える。

実績は「奉納累計」「実際に戦闘が起きた関与国家数」「結社存続」を別表示する。国家数は少数の同じ国を分裂・再統合して稼げないよう、国家の系譜で重複排除する。大奉納の目標値は開始人口・国家数に応じて固定し、極小世界でも到達可能にする。自軍の死も計上するが、喪失人口・装備・信頼は戻らない。

## 9. 世界側の対抗行動と敗北後

| 主体 | 主な対抗行動 | プレイヤーに生じる結果 |
| :-- | :-- | :-- |
| 平和的な君主 | 共同調査、譲歩、教会との協定、強硬派の更迭 | 争点が消え、根回し先を失う |
| 上位教会・穏健派 | 教義批判、破門、指導者交代、教区への監査 | 正統性と寄進が減る。宗教の信徒すべてが敵になるわけではない |
| 国家当局 | 捜査、資産凍結、支部閉鎖、逮捕 | 作戦停止、資金・拠点喪失 |
| 外国政府 | 教団情報の共有、支援拒否、外交圧力 | 工作可能な国と輸送経路が減る |
| 軍・協力者 | 拒命、離脱、寝返り、告発 | 指令対象から外れる。軍の忠誠は再評価 |
| 住民 | 寄進停止、移住、和平運動 | 基盤・収入・募集人口が縮む |
| 対教団連合 | 根拠のある共同制裁、条件を満たせば拠点への戦争 | 教団自体が戦争の標的になる |

疑惑だけで世界中が真相を共有しない。観測された事件、入手済み証拠、外交的な共有先で反応範囲を決める。PC 向けの因果ログと、各国家が知っている責任は別データ。

失職は下位職・地下活動への移行、拠点喪失は残存支部への退避、分裂は小規模結社としての再出発につなげる。移動は既存の burg 間移動に従う。逮捕中は移動・現地作戦を停止。PC 死亡後は既存のキャラクター選択で後継者に切り替えられるが、私的な影響力は自動相続しない。生存する委任担当者の作戦は結社の権限が残れば継続する。

## 10. プレイ例

### 地方司祭のまま二国を戦わせる

国境都市で支部を育て、隣国との聖地争点を知る。地元の強硬派に働きかけ、君主へ開戦を提案させる。君主が共同管理案を選べば戦争にならず、次の活動先を選び直す。開戦した場合は事前の奉納契約を維持し、実戦の死者を計上する。教団の関与が判明すると、司教が PC を解任するか、支部が PC を擁護して分裂する。

### 修道院長が軍拡を後押しする

複数国の研究と装備調達を後援する。装備が行き渡るまで年単位で待つ間に財政や政権が変わる。防御側が強化されれば戦争が長引く場合もあるが、攻撃側が開戦を諦めれば奉納は得られない。支援先が短期勝利した場合も、研究は成功、奉納戦略は失敗となる。

### 平和的な君主を排除した結果が裏目に出る

支援した好戦派候補の即位を期待して暗殺を企図する。実行に成功しても正統な後継者が即位し、被害国と隣国が共同捜査を始める。教団の証拠が見つかれば両国の対立圧力が下がり、PC の修道院が接収される。行動成功だけを勝利としない代表イベントとする。

### 宗教国家が自ら聖戦を起こす

国営研究と徴募へ資金を配分し、自国軍で出征する。奉納を優先して戦争継続を提案しても、軍の損耗、国庫、住民の不満が蓄積する。停戦して教団網を立て直すか、内部分裂を受け入れて大奉納を急ぐかを選ぶ。支配領域が広くても、寄進も人材も枯れれば活動できない。

## 11. 既存実装との接続と新設部分

以下の「確認済み」は本草案作成時のローカルコードに基づく。参照先の Draft を実装済み API として扱わない。

| 領域 | 確認済み／参照設計 | 本設計で追加するもの |
| :-- | :-- | :-- |
| 宗教地図 | `src/generators/religions-generator.ts` | 信仰 ID と分離した結社・支部・個人所属 |
| 個人の信仰 | `CharacterOrigin.religionId`、既存の Piety / Intrigue など | 結社 membership と役職ごとの権限。信仰 ID から推測しない |
| 開戦 | `conflictDirector.ts` は現在 origin `"player"` を双方へ書き、Enemy にする | 危機の由来・対象・期限を検証する仲介層 |
| 将軍独走 | [将軍草案](marshal-player-unauthorized-war.md) の非対称 origin と服従モデルは Draft | 外国 NPC 軍務官の受諾経路。PC 本人限定の HUD ハンドラをそのまま流用しない |
| 戦闘死 | `battle-resolution.ts`、`localSkirmish.ts` が兵数減少と人口損失を処理 | 共通の死亡イベント、種族内訳、奉納 ledger |
| 技術後援 | [PC 技術バイアス草案](player-character-technology-bias.md) | 同じ資金・知識・物証チャネルを利用する宗教結社の支払主体 |
| 移動と時間 | 既存の PC 移動・時間進行を利用 | 活動の排他、期限、委任先の有効性検証 |

### 11.1 データの責務（すべて提案）

- `ReligiousFaction`：結社 ID、信仰 ID、神格・教義、指導者、資産、結束、支部一覧。
- `ReligiousChapter`：結社 ID、burg ID、管理者、活動容量、基盤、奉納派支持、接収状態。
- `FactionMembership`：人物 ID、結社 ID、役割、権限、忠誠。個人の信仰とは別。
- `ReligiousOperation`：作戦 ID、提案者・担当者、対象、予約資産、開始・期限、状態、保存乱数、効果 ID。
- `ConflictCrisis`：国家ペア、因果作戦 ID、対立修正、各国の判断、PC が選んだ波及範囲、有効期限。
- `FactionEvidence`：事件 ID、疑惑を持つ国家、証拠強度、既知の責任者、共有先。
- `SacrificeContract`：結社、戦争 ID、対象側、担当拠点、期間、維持状態、因果関与 ID。
- `CombatDeathEvent`：永続イベント ID、戦争 ID、日時・場所、陣営ごとの死亡人数・種族内訳。戦闘の確定処理だけが発行する。
- `SacrificeLedger`：イベントごとの配賦、契約 ID、累計、恩寵、期間集計。死亡を発生させる責務は持たない。

結社データは専用の namespaced slice へ保存し、欠落は機能未使用として扱う。旧セーブの宗教色から結社を自動生成しない。削除された国家・burg・人物への参照はロード時と行動確定時に検証する。

同一国家ペアに複数の原因があるため、結社 ID を origin の代用品にしない。国家戦争は通常認可、将軍独走は独走認可とし、別の戦争インスタンスに原因を複数記録する。既存認可を上書きしない。契約はペアだけでなく戦争 ID に結び、終戦後の再戦へ引き継がない。

複数結社が同じ死亡へ権利を持つ場合は、有効契約の奉納割合を正規化し、合計を 1 以下にする。イベント ID 単位で処理済みを保存し、再送・再読込を無効果にする。人口、死者イベント、ledger の更新は一つの確定単位とし、途中のセーブで二重加算・取りこぼしを作らない。

### 11.2 時間進行と整合性

Week / Month / Year で軍事進行が抑制される現行方針を維持する。長期進行中に作戦が開戦段階へ到達したら、その日時で停止して危機を表示し、Advance Day へ案内する。戦闘を飛ばした期間の死者を推計して奉納しない。

履歴生成では PC 作戦の新規実行を停止する。autonomous 対応は後続段階とし、第一スライスの操作 UI は `ck3e` かつ `playerDirected` のみ。D&D 向けの教団冒険・非国家戦争は別拡張とする。

## 12. UI

既存 PC パネルに「信仰・結社」を追加し、地図の burg／人物／国家ペアを対象として選ぶ。別の戦争地図は作らない。

行動カードには目的、対象、必要権限、拘束期間、費用、利用する協力者、効果の見込み、露見の見込み、開戦しうる国家を表示する。不可能な行動は「現地支部がない」「君主の承認が必要」など理由を表示する。工作確定時にだけゲーム内の確認を行い、結果の国家意思決定は自動で進める。

結果画面は「作戦自体の成否」「各国・後継者の応答」「実際の戦争」「奉納への寄与」を分けて示す。公的年代記には各国に知られている事件を書き、PC 用の秘密ログには真の因果を書く。地図には支部、活動中の作戦、奉納対象戦域、露見した拠点を重ねる。

## 13. 段階実装と受け入れ条件

| 段階 | 提供内容 | 完了条件 |
| :-- | :-- | :-- |
| A：結社と作戦基盤 | 所属・支部・権限・資源予約・期限・保存、布教と根回し | 地方司祭が一拠点を運営でき、無権限の国庫・軍操作ができない |
| B：最初の一周 | 争点工作→両国判断→当該ペアの開戦→戦闘死→奉納、疑惑・閉鎖 | 地方司祭のまま成功・開戦拒否・露見の各分岐を遊べる |
| C：政治と研究 | 暗殺・継承、和平妨害、研究・装備後援、宗教国家開始 | 後継者が和平を選ぶ、技術成功でも奉納が減る結果が出る |
| D：越境軍事 | NPC 将軍への要請、非国家教団軍、教団分裂・対教団連合 | 忠誠のない軍は動かず、教団軍だけの戦争を国家と区別できる |
| E：拡張 | 捕虜奉納、超自然終局、autonomous / 他プリセット | 各基盤の人口・交戦・能力モデルに接続してから解禁 |

B は外交ラベル変更だけで終わらせず、有効な軍目標・行軍・防御側の応戦まで通す。死亡イベントと種族内訳が未接続なら奉納報酬 UI を公開しない。

実装時に固定する重要な検証例：

- 同一宗教でも非結社員の軍・資産を操作できない。高 Piety の和平派が勧誘を拒める。
- 開戦工作の成功後も君主が調査・和平を選びうる。死亡後継承は通常経路を一度だけ通る。
- 作戦対象外のペアへ playerDirected 認可が漏れない。既存の通常戦争・独走認可を上書きしない。
- 行軍不能な軍しかない場合に攻勢が成立しない。近衛の非行軍を維持する。
- 人口減算済みの戦闘死を奉納で再減算しない。戦力損耗、軍再生成、過去ログから加算しない。
- 同じ死亡イベントの再送・ロード・複数契約で合計奉納数が実際の対象死者数を超えない。
- 非人間・種族未確定の死者を人間の目標へ加算しない。
- 失職・逮捕・拠点接収で作戦権限が失効し、委任作戦は実際の担当者と権限に従う。
- 年単位の進行で戦争が無通知に発生したまま時間だけ進まない。旧セーブは結社なしでロードできる。

最初からすべての暗黒教団要素を揃えるのではなく、B で「一人の司祭が世界の戦争に介入し、その死を自分の神へ捧げ、代償を受ける」一周を完成させる。その上で役職・研究・軍・終局の選択肢を増やす。
