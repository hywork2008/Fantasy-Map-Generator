# 性格から見立てる対人相性

実装: `src/extensions/characters/relationshipCompatibility.ts`  
表示: ツールタブ → 人物の相性 → `RelationshipCompatibilityDialog`（人物選択＋`RelationshipCompatibilityPanel`）

## 型と根拠

一般・恋愛フレーバーの意味IDから、一般の型8種と恋愛の型6種を選ぶ。
翻訳文そのものは比較しない。複数の特徴がある場合は、ルールの上から優先する。
嫉妬と思いやりは型とは別の補助特徴として残す。

- 一般: 気遣い、信義、理詰め、冒険、駆け引き、利得追求、静穏、調整。
- 恋愛: 恋愛回避、約束重視、情熱、多情、自立、歩調調整。

文化の婚姻規範・容姿の評価は恋愛フレーバー生成に引き継ぐ。
「約束重視」は一夫一妻だけを意味しない。

## 組み合わせ

友情45・恋愛35・衝突20を中立の初期値として、型の組み合わせによる増減を加える。
定義は `socialRules` と `romanticRules`。加点は物語用の設計値であり確率ではない。
組み合わせは対称とし、既存の方向付きの連帯感・恋愛感情とは区別する。
未定義の型の組み合わせは、相互に極端な相乗効果も摩擦も生じない「中立（初期値維持）」として扱う。

| 組み合わせ例 | 見立て |
| --- | --- |
| 理詰め × 理詰め、自立 × 自立 | 男女でも相談相手・友情に育ちやすい |
| 恋愛回避 × 恋愛回避 | 静かな友情。恋愛は進みにくい |
| 情熱 × 情熱 | 友情にも恋愛にも育ちやすい |
| 約束重視 × 多情 | 関係への期待が衝突しやすい |
| 強い嫉妬を持つ情熱型同士 | 惹かれ合っても衝突しやすい |
| 調整 × 調整、歩調調整 × 歩調調整 | 衝突が極めて少なく、穏やかに調和しやすい |

### 年齢差と規範・特異な嗜好

- **未成年の絶対保護**: 15歳未満の児童が含まれるペアは、個人的恋愛の対象外として `恋愛0`（`underageProtection`）。
- **規範派（高名誉／高敬虔／高合理）**:
  - 同世代（±10歳以内）に対しては安心感から衝突が緩和（衝突-10、`orderlyGenerations`）。
  - 大年齢差（20歳以上）に対しては世間体・教会法・世代差への懸念から恋愛を抑制し衝突が増加（恋愛-25、衝突+20、`generationGapConcern`）。
- **特異な嗜好（倒錯・規範無視）**:
  - **好色老翁の執着（`lecherousPursuit`）**: 45歳以上で低名誉・低敬虔かつ高大胆／強欲／狡猾の年長者は、若年成人（15〜22歳）に対し年齢差を無視して惹かれやすい（恋愛+25）。ただし相手への負担や周囲の嘲笑（スキャンダル）により激しい衝突を伴う（衝突+35、波乱見立て）。
  - **年長者への思慕（`matureAffection`）**: 若年（18〜30歳）で低名誉または高執着の人物は、20歳以上年上の落ち着いた年長者に強い庇護感や思慕を抱きやすい（恋愛+20、衝突+15）。

### 身分格差と時代背景（Historical Period）

- **身分の隔たり（`classDivide`）**:
  - 上級貴族・王族と平民・農奴・奴隷など、身分格差が大きいペアは周囲の社会的圧力により衝突が増加し、恋愛の進展に障壁がかかる。
- **時代背景（`historicalPeriod`）による変遷**:
  - **中世期（Medieval）**: 身分固定と教会規範が強く、身分差障壁は最大（恋愛上限25、衝突+35、`classDivideMedieval`）。
  - **近世期（Exploration / Maritime）**: 商人層台頭により身分差障壁が緩和（恋愛上限35、衝突+25）。
  - **近代以降（preIndustrial以降）**: 身分制度の解体とロマン主義により、身分差ペナルティは最小化（上限なし、衝突+10、`classDivideModern`）。

### 性的指向・種族・近親・死者の扱い

- **異性・同性**: 異性であること自体では恋愛に加点しない。同性同士は既存世界の初期傾向に合わせ、恋愛感情の記録がなければ恋愛の見立てを45以下に抑え、友情を基本とする。どちらかに正のfavorがあればこの制限を外すが、両想いや性的指向を推定しない。
- **種族差**: 異種族間の既存の社会的障壁も、恋愛感情の記録がなければ恋愛の上限25として反映する。
- **恋愛回避型**: 恋愛回避型が含まれる場合も上限25。
- **近親・本人除外**: 本人・確認できる親子・きょうだい・祖父母孫は恋愛0。
- **死者と過去の伴侶の扱い**:
  - 死者であっても、二人の性格から導かれる本質的な相性スコア（惹かれやすさ）は0にリセットしない。
  - **追憶の愛（`bereavedLove`）**: すでに配偶者（`spouseIds`）または深い好意（`favor > 0`）が存在した死別相手に対しては、喪失と貞節の証として相性と見立てを維持して表示する。
  - 生前に面識のない死者については「故人（`deceased`）」として現在進行形の恋愛候補からは区別する。

表示の「高い」は60以上、「中程度」は35以上、それ未満は「低い」。
最終見立ては衝突60以上を優先し、恋愛も60以上なら「惹かれ合っても衝突しやすい（volatile）」。
友情65以上・恋愛60以上は両方、それ以外は恋愛60以上、友情60以上、状況次第の順。

## 表示と保存

初期対象は存命の知人（どちらかからの連帯感・好意の記録あり）、同じ所在地、
既存の直接交流条件を満たす人物。全存命人物への切替、名前検索、3軸の並べ替え、
30人ずつの追加表示が可能。まだ出会っていない人物については、出会った場合の見立て。
死別した伴侶や重要な故人も確認可能。

表示時に再計算し、型や相性をセーブへ追加しない。
`computeInitialSolidarity` で、友情・衝突から次の補正を1回加える。

`clamp(round(((友情 - 45) - (衝突 - 20)) / 4), -20, 20)`

他の政治・役職・嗜好などの計算を維持し、対象に応じた思いやりを使う。
恋愛スコアは連帯感へ加点しない。既存の関係スコアの一括再計算やfavorの変更は行わない。
専用ダイアログを開いたり比較元を変えたりするだけでは、保存データを変更しない。
