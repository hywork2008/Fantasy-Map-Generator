# 刈れなかった干し草を後の月の二番草から刈り足す

## 1. 背景

[urban-harvest-help-20261114.md](../analytics/urban-harvest-help-20261114.md) §10で、地図2102の4月に餌の足りない307の土地を調べた。干し草の計画（1年1,898百万kg乾物）は冬を越すのに足りていた。しかし7月（本刈りの次の月で、穀物の刈り入れと重なる）に、人手で刈れる分が計画の35%しかなく、503が刈れなかった。刈れなかった分は後の月に回らない。8〜9月の人手は計画の日数とほぼ同じだけしか割り当てられず、計画の日数が刈る量の上限になるためである。8〜10月には、刈られずに残った草が約1,250あった。

10月の記録（親計画§7.66）は、本刈りの月に干し草を畑仕事より優先させる案だけを調べて採らなかった（主食の不足に移るため）。後の月に回す案は§7.47で「次」に挙げられたまま、調べられていなかった（[settled-questions.md](settled-questions.md)）。

## 2. 史料

- チェルシーの荘園（ウェストミンスター修道院、1367〜68年）では、慣習保有農の賦役で草地を刈り、二番草の干し草（second hay crop）は雇った人手が6日かけて刈った。14世紀半ばの評価では、草地の刈り取り2回分（2 mowings）を£8と見積もっている（[VCH Middlesex vol.12, Chelsea: Economic history: Agriculture](https://www.british-history.ac.uk/vch/middx/vol12/pp146-150)）。
- 中英語では二番草を rowen と呼び、秋に刈って運び込んだ（"The secunde crop thei carie hom roweyn"）。
- 共同の草地（Lammas meadow）は、刈り取りの後、8月1日（ラマス）から共同の放牧に開かれた。二番刈りは、荘園の直営地や個人の草地のものである。

## 3. 決める仕組み

1. 設定`hayCatchUp`：`aftermath`（既定）か`legacy`（今の決まり）。
2. `aftermath`の時、年1回の職業の割り当てで、近隣・市場圏の農村・町の人の手伝いの後にも残る干し草の不足（`haymakingShortfallDays`）を、その月の後の`hayCatchUpMonths`か月（既定3、1〜4）に回す。
3. 回す先の月で使うのは、その土地の大人が暦の全ての仕事（畑仕事を含む）を割り当てた後に残る日数だけで、早い月から使う。畑仕事の日数は減らさない（§7.66の判断と同じ）。
4. 回した日数は牧畜の暦に足し、土地と月ごとに持つ（`hayCatchUpDays`）。
5. 刈り取り（`getHusbandryLaborBudget`）では、その月の干し草の人手の上限を「計画の日数 ＋ 回した日数」とする。刈る量は、今までどおり刈れる草（立ち草＋余りの伸び）と蓄えの目標で止まる。

## 4. 見込み（計測の前の計算）

[hay-catchup-20261115.md](../analytics/hay-catchup-20261115.md)（2102、1か月目の割り当ての暦、百万日、刈る量は3日/t）より。

| 307の土地 | 7月 | 8月 | 9月 | 10月 |
| --- | ---: | ---: | ---: | ---: |
| 暦の後に空いている大人の日数 | −11.1 | 0.0 | 1.0 | 1.9 |
| 刈らずに残った草（百万kg、§10） | 636 | 306 | 542 | 407 |
| 刈れる余りの伸び（草 − 放牧） | | | 約313（9月の刈りの後） | 約184 |

- 7月に刈れなかった503（1.51百万日）は、9月に約313（人手1.0百万日 = 333）、10月に約184（草の分）まで刈り足せる。合わせて約500で、ほぼ全量。
- 蓄えに入るのは乾燥の損失の後で約420。3〜4月の不足71を上回るので、この307の土地の4月の不足はほぼ0になる見込み。
- 地図全体（4,435土地）では、9〜10月に空いている大人の日数が47〜56百万日あり、刈り足しに要る日数（2103の§6で人手の不足は計画の約5%、0.56百万t = 約1.7百万日）より十分大きい。
- 3〜4月の餌の不足は、両方の地図で要る量の0.2%未満になる見込み。お金・作った品はほとんど変わらない。

## 5. 計測の計画

北緯30°の地図2枚（2102・2103）、36か月、戦争なし・隊商の略奪なし。比べる先は[urban-harvest-help-20261114.md](../analytics/urban-harvest-help-20261114.md) §7の出力（`legacy`と同じ）。§4から外れたら、計測を重ねる前に理由を数えて記録する。

1. 3〜4月の餌の不足（量と土地の数）、干し草の蓄え。
2. 刈り足しの日数と月。
3. 持ち手のお金。

## 6. 未確定事項

1. 刈り足しの手を、近隣と市場圏の手の空いた大人に広げるか（今はその土地の大人だけ）。
2. 二番草の質（一番草より落ちる）と、共同の草地の8月からの放牧との取り合い。
3. 雇った刈り手への賃金（チェルシーは日払い）。今は日数だけで、お金は動かさない。

## 7. 結果

[hay-catchup-20261115.md](../analytics/hay-catchup-20261115.md) §3。3〜4月の餌の不足は約4分の1（2103で0.01〜0.14%、2102で0.11〜0.30%）、足りない土地も約4分の1になった。見込みの0.2%未満に対し、2102の4月だけが0.23〜0.30%で少し上回った。作った品は−0.15〜−0.29%、持ち手のお金の差は1.6%以内。
