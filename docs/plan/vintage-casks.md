# 収穫のための樽

## 1. 背景

[vintage-labour-20261110.md](../analytics/vintage-labour-20261110.md) §3で、葡萄と果物を搾る労働を直した後、町のエールを飲んだ量が23〜25%減った。その主な理由は、収穫の月（4〜8月）の樽の不足だった。

- 樽職人は、市場の家の飲み物の月の需要に合わせて、毎月同じだけ樽を作る（`getMonthlyHouseholdContainerDemand`、`floorFromHouseholdDrinks`）。
- 空の樽は、月の詰める量の2倍を超えると、市場の在庫に戻され、ほかの樽と同じに売られる（`releaseSurplusContainers`）。
- ワイン・シードル・ペリーは、年1回の収穫で1年分の樽を詰める。飲まれて戻った空の樽は、次の収穫を待たずに在庫に戻され、エールに使われた。収穫の月には、樽が足りなかった。
- 樽を作った量は、労働を直す前と後で同じ（2103で年約12万）だった。

## 2. 史料

- 中世のボルドーでは、葡萄は醸造者に売られ、醸造者は樽職人と商人と取引した。町の人の多くが、直接・間接にワインの取引に関わった（Estreicher、[Wine and France: A Brief History](https://www.cambridge.org/core/journals/european-review/article/wine-and-france-a-brief-history/7CB9F6C094C3833A05FE519132BBF551)）。
- 14世紀、ブリストルだけで、ボルドーとバイヨンヌから年2万トン（樽）のワインが入った（同）。北ヨーロッパでは、樽は船の荷の主な入れ物だった（[Barrel](https://en.wikipedia.org/wiki/Barrel)）。
- 樽職人が収穫の前に樽を作り置いたことを、数で示した史料は見つからなかった。

## 3. 決めた仕組み

- 市場のセルで葡萄・林檎・梨が実った市場は、次の収穫で詰める空の樽を取っておく（`getVintageCaskEmptiesTarget`、[foodProcessingLedger.ts](../../src/extensions/economy/generators/foodProcessingLedger.ts)）。
  - 量は、その市場のワイン・シードル・ペリーの1年分（在庫の上限と同じ12か月、ワインはワインの土地の8 Lの需要）を樽で詰める分から、前の収穫で詰めてまだ中身のある樽を引いたもの。
  - 収穫の直後は、樽がみな詰まっているので、取っておく量はほとんど無い。飲まれて空の樽が戻るにつれて、取っておく量が増える。
- 空の樽の目標は、月の詰める量1か月分に、この取っておく量を足したもの（`getContainerEmptiesTarget`）。
  - 目標に足りない分は、今までどおり3か月で新しい樽として樽職人の需要に入る。
  - 在庫に戻すのは、月の詰める量の2倍と取っておく量を超えた分だけである。

## 4. 計測

計測は[vintage-casks-20261110.md](../analytics/vintage-casks-20261110.md)（北緯30°の地図2枚、24か月、2年目）。

- 収穫の月の樽の不足は無くなった。ワインは71〜72%から77〜78%、シードルは41〜51%から48〜63%になり、エールの足りない分は約半分になった。
- 樽職人は2.7倍作り、樽の在庫は1年で約15万に積み上がった。取っておく量から市場の在庫のワイン・シードルの樽を引いていないためと見られる。
- 蜂蜜酒は54〜62%から12〜15%に落ちた。理由は未調査である。
- 樽職人の不足から市場の在庫の新しい樽も引いた計測（[cask-stock-20261110.md](../analytics/cask-stock-20261110.md)）では、作った量は約1割減っただけで、蜂蜜酒は21〜22%に留まった。エールに使った樽は1.8倍になった。
- このため取り置きを外した（`getVintageCaskEmptiesTarget`は削除）。在庫の樽を数える直しだけを残し、樽の作り過ぎと蜂蜜酒の落ち込みは無くなった（同 §5）。収穫の月の樽の不足は、値段を見ない量の決まりの見直し（[drink-price-allocation.md](drink-price-allocation.md) §6）で扱う。
