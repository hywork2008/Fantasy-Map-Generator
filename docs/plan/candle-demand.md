# 蝋燭を全ての人に

## 1. 背景

[byproduct-history.md](byproduct-history.md)で、モデルの出る獣脂（1人年約2.6 kg）は1711年のイングランドの獣脂の蝋燭（1人年約2.6 kg）とほぼ同じで、積み上がるのは使い道が細いためと読んだ。蝋燭の需要は町の人だけの1人年1 kg（仮値）で、地図2102では作った蝋燭が1人年約0.1 kg、獣脂の使い道は出た量の約4%だった。

## 2. 史料

- 1711年のイングランドの課税の記録で、獣脂の蝋燭は年約3,000万ポンド（約1.36万t）、人口約530万で1人年約2.6 kg（Fouquet & Pearson）。
- 1784年のピットの見積もりで、貧しい家でも年10ポンド（約4.5 kg）、家の平均で約30ポンド（約13.6 kg）。家を5人とすると、貧しい家で1人年約0.9 kg（Crowley）。
- 農村の家では、獣脂の蝋燭を家で浸して作った（[byproduct-history.md](byproduct-history.md) §2.2）。

## 3. 今の決まり

| | 決まり |
| --- | --- |
| 需要 | 町の人1人年1 kg、1ブロック100 kg（[craftDemandCalibration.ts](../../src/extensions/economy/generators/craftDemandCalibration.ts)の`Candles`）。町の金庫が買う |
| 作り方 | 油・蜜蝋・獣脂のどれか1単位から1ブロック |
| 手間 | 1ブロック0.15人月。町の蝋燭・石鹸の職人（`chandlery`、町の人1,000人に2人） |

## 4. 決める仕組み

### 4.1 農村の人も

- 履物（[leather-uses.md](leather-uses.md) §4.1）と同じに、町の需要の床に、その町の市場の農村の人の分（町の人の割合で分けた分）を足す。
- 1人年の量は設定`candleKgPerPerson`（既定1 kg）。1711年の約2.6 kgより低く、ピットの貧しい家（1人約0.9 kg）に近い中世の値とした。
- 農村の人の分は、農村の家計が町で使う月の額から払う（履物と同じ）。

### 4.2 村の蝋燭作り

- 農村の家が浸して作る分の手間を、村の蝋燭作り（設定`ruralChandlersPerThousand`、既定は農村の人1,000人に0.5人）として、市場の町の`chandlery`の人数に足す。
- 1人年1 kgを1日25 kgで浸すと、1,000人で年40人日で、0.5人は余裕を持たせた値である。

### 4.3 釣り合いの見込み（2102）

全ての人1人年1 kgで年約2万t、獣脂で約19万樽（出る獣脂49万樽の約4割）。値段の安い獣脂から作られると見る。

## 5. 設定

| 設定 | 既定 | 意味 |
| --- | --- | --- |
| `candleDemand` | `everyone` | `everyone`（4.1）か`townsOnly`（今の決まり） |
| `candleKgPerPerson` | 1 | 1人年の蝋燭のkg |
| `ruralChandlersPerThousand` | 0.5 | 農村の人1,000人あたりの村の蝋燭作り |

## 6. 計測の計画

北緯30°の地図2枚（2102・2103）、36か月、戦争なし・隊商の略奪なし。[byproduct-pricing-20261111.md](../analytics/byproduct-pricing-20261111.md)のnewと比べる。

1. 蝋燭を作った量と、獣脂の在庫・値段・使い道。
2. 町の金庫・町の家計・農村の家計のお金。

## 7. 未確定事項

1. 中世の1人あたりの蝋燭の量（1711年より前の数）。
2. 油・蜜蝋の蝋燭との分け方（今は作り方の選び方による）。
3. 獣脂の他の使い道（革の仕上げ・車軸）と、地図の外へ売る出口（[byproduct-history.md](byproduct-history.md) §5）。
4. 値付けの材料の需要は作り方の初めの材料（油）を見るため、獣脂の値段に蝋燭の需要が入らない。

## 8. 結果

[candle-demand-20261111.md](../analytics/candle-demand-20261111.md)。作った蝋燭は約4倍（2102で2.0万から8.9万ブロック）、獣脂の使い道は8〜10%から21〜24%になったが、見込みの需要の約44%にとどまった。農村の人の分を払う農村の家計の町の額を履物と分け合い、長靴と革の品が約17%減った。獣脂はまだ積み上がる。
