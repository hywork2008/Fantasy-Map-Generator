# 製塩所の燃料と塩の調達の選び方

作成: 2026-10-30

## 1. 背景

固定入力（`docs/analytics/inputs/wet-pastoral-birth-20261029/world-102.fmg`、平和モード）の24か月目に、State 10の煮詰め式の製塩所22か所の生産がずっと0だった（[計画](salt-supply-calibration.md)§3.8の後の調査）。

- 22か所はすべて市場8にある。市場8の陸の112セルはすべて`borealPeatland`（泥炭地）で、森林が無く、木材の在庫が1度も入らない。木材の値段は1.36〜1.57で、隣の市場16（同じState 10、木材の値段0.25〜0.31、在庫1〜2千）より5倍以上高い。
- 煮詰めには塩1袋につき決まった量の木材が要る（`saltProduction.ts`の`boilingWoodKgPerKg`）。木材の在庫が0だと生産も0になる。
- State 10は産地の国なので、他国の製塩所から塩を買わない（`saltLogistics.ts`の`supplierOperations`は自国の製塩所があればそれだけを使う）。市場8・16は塩の在庫が0のままで、値段は基準の約3倍、人の塩は月1,542袋不足した。
- 泥炭を表す財は無い。暖房（`heating.ts`）も木材と石炭しか使わず、市場8の農村は燃料を自給できていない（`ruralFuelWood` 0）。

歴史的には、森の無い海岸や湿地では泥炭を掘って燃やし、塩を煮た例がある（フリースラントの泥炭の塩、Selnering）。木材を船や荷車で運び込む例、煮詰めをやめて塩そのものを買う例もある。

## 2. 方針

燃料と塩の調達を、決まった順序ではなく、製塩所ごと・月ごとに一番安い手段から選ぶ。安さは、市場の外へ出るお金に割増しを掛けて比べる。

### 2.1 手段

| 手段 | 1袋あたりの費用 | 支払いの行き先 |
| --- | --- | --- |
| P. 泥炭を掘って燃やす | 掘る・乾かす・運ぶ労賃 | 自分の市場の農村（市場の中で回る） |
| W. 自分の市場の木材を燃やす（今の動き） | 木材の値段 | 自分の市場の農村 |
| I. 隣の市場の木材を運び込んで燃やす | 木材の値段＋運賃 | 木材の代金は相手の市場へ。運賃は運ぶ側へ |
| S. 煮詰めずに他の製塩所の塩を買う | 卸値＋運賃 | 相手の市場。国家が違えば他国 |

### 2.2 実効の費用

```
実効の費用 = 市場の中で払う分 + 外へ払う分 × (1 + 流出の割増し) [+ 他国への上乗せ]
```

- 流出の割増しは、その市場のお金の苦しさで決める。目安は、手元の現金がこの1年の支払いの何か月分あるかと、貨幣の物価水準（`moneyLevel`）。余裕のある市場は0に近く、苦しい市場ほど大きい（仮値の上限0.5）。
- これは「外へ払うと自分たちの市場の金回りが減って苦しくなる」という経験則の代わりである。
- 他国への上乗せは初めは0とし、測ってから決める。
- 係数は仮値とし、定数に一本化して後から校正する。

### 2.3 泥炭

- 新しい財`Peat`（燃料、単位は荷車1台）を加える。森の財ではないので、木材から作らない。泥炭地・湿地・荒れ野（`borealPeatland`・`wetland`・`heathMoorland`）のセルの農村が、自分の燃料と市場への売り物として掘る。
- 熱量は木材の単位で換算する（乾いた泥炭は木材の重さあたりほぼ同じ熱量、かさは大きい）。値は出典を付けて定数にする。
- 掘れる量は、セルの泥炭の量と農村の人手で決める。泥炭は年単位では尽きない扱いとする（数百年の採掘による減少は後続）。
- 暖房でも木材の次の燃料として使う（石炭の前）。

F1でSを先に入れるのは、今ある財と仕組み（他国からの仕入れ）だけで済み、市場8・16の不足をすぐに埋められるためである。P・Iが入ると、実効の費用の比較で自然にP・Iが選ばれる市場が出る。

## 4. 木材が運ばれない理由の候補（F0で確かめる）

1. 地図の生成（FMGの`routes`）で、市場8と周りの市場の間の経路がつながっていない。商人の交易は経路の上でしか動かないので、つながっていなければ値段の差があっても運ばれない。
2. 木材のかさ。木材（`Wood`）は10 m³を1単位とする財で（`goodCargoMeasure.ts`）、建材の`Timber`は別にある。薪・焚き木を表す別の財は無いが、`Wood`がすでに燃料の木（暖房・煮詰め・炭焼きに使う）を表しているので、小分けの問題ではなく、1単位あたりの運賃が値段に比べて高すぎるかどうかの問題になる。
3. 商人の交易の側の扱い（積荷の選び方で木材が後回しになる等）。

### 4.1 遠距離の木材の移動の史料

- 陸路の薪は遠くへ売られない。『史記』貨殖列伝の「百里不販樵、千里不販糴」（薪は百里＝約40 kmを越えて売らず、穀物は千里を越えて売らない）。京都へは大原の女性が30〜40 kgの薪を頭に載せて約15 km運んだ。
- 水運の薪・木材は遠くへ動く。ローマの価格令から、荷車の運賃は川船の10倍を超え、川船は海船の3.9〜7.8倍。中世のカイロのゲニザ文書には、ナイルの船で薪を30荷運んだ運賃（1荷3¼ディルハム）がある。アルプスの木材はポー川・ローヌ川で筏に組んで運ばれ、ウィーンの宮廷の薪も森から道・川を経て運ばれた。
- 塩の燃料: リューネブルクの製塩は周りの森を切り尽くし、燃料の木が生産の上限になった。フリースラント・フローニンゲンでは11〜14世紀に塩を含む泥炭を掘り、灰から濃い塩水を作って泥炭の火で煮た（北フリースラントのルングホルト）。15世紀の半ばからは、オランダが運河で安く運べる泥炭でフランスの天日塩を煮直し、リューネブルクの塩より安く売った。
- まとめ: 陸路で市場をまたいで薪を運ぶのは、近い距離に限られる。遠くへは川・海の水運で動く。森の無い産地は、地元の泥炭を燃やすか、塩そのものを運び込む。

## 5. 未確定事項

- 木材が運ばれない理由（§4）。経路の生成や商人の交易の不具合であれば、手段Iを製塩所の買い付けとして作るより先に、そちらを直す。
- 手段Iの運賃は、陸路は近い距離だけ、水路は遠くまでとなるように、§4.1の比に合わせる。
- 流出の割増しの形と上限、他国への上乗せの値。
- 泥炭の熱量・掘る人手・セルあたりの量の出典。
