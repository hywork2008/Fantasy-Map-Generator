# 装備カタログ（歴史・神話伝承・RPG）

古今東西の武器・防具・装身具の名称と装備部位の対応を整理した参照データ。実装用スキーマではなく、loadout 細分化・styleKey・品目命名の下敷き。

史実・神話伝承・ゲームフィクションは**フォルダを分けて**ある。混ぜない。

| 項目 | 値 |
| :--- | :--- |
| **Date** | 2026-09-04 |
| **Status** | 調査メモ（実装非拘束） |
| **Related** | [character-loadout-and-readiness.md](../character-loadout-and-readiness.md)（現行 v1 スロットは `body` / `weapon` / `accessory` / `mount`） |

## フォルダ

| パス | 内容 |
| :--- | :--- |
| `historical/` | 考古・図像・兵書に根拠がある実在装備。RPGでも同名で出る型（刀、ロングソード、バックラー等）もこちら |
| `mythology/` | 神話・叙事詩・民話・宗教伝承の**固有名**装備（エクスカリバー、ミョルニル、草薙剣、アイギス等） |
| `fiction/` | ゲーム・フィクション由来の型名（タワーシールド、ミスリル、スタデッドレザー）と RPG の装備欄 |
| `00-slots.csv` | 三者が共有する正規スロット定義 |
| `sources.csv` | 根拠の一覧（`corpus` 列で所属）。各フォルダにも対応分のコピーあり |

振り分け:

| attestation | 置き場 |
| :--- | :--- |
| `historical` / `both` / `legendary/historical` | `historical/` |
| `mythology` / `epic` / `folklore` / `religious_legend` | `mythology/` |
| `rpg_common` | `fiction/` |

実在しつつゲームにも出る型は史実側。神話の固有名は神話側。ゲームが神話名を型として使う場合（「アイギス」が最上位盾の一般名）は、固有は `mythology/`、一般型は `fiction/`。

`mythology/` の各行には `tradition`（ギリシア、北欧、神道等）・`associated_figure`（所持者）・`source_text`（出典）を足してある。寸法・重量は文学的誇張が多く、多くは `n/a`。

## スロットの読み方

- `slot` は本カタログの正規 ID（`00-slots.csv`）。1 品目が複数欄を塞ぐ場合は `occupies` に列挙する（両手武器は `main_hand+off_hand`）。
- `fmg_v1_slot` は現行 Character.loadout への落とし込み。細分化前は胴甲も衣服も `body`、盾も両手武器も一次武器側に畳む想定。
- RPG 独自の「アクセサリ2」「指輪2」は `accessory` の多重スロットとして扱う。
- 神話側ではアイギスのように盾／胸甲／外套で描写が揺れるものがある。`slot` は最も一般的な用法、揺れは `notes`。

## 数値の扱い

史実側の寸法・重量は**目安レンジ**（完成品の復元・実測）。フィクション側はゲーム数値を含み、史実と混ぜない。神話側の「関羽の82斤」「アイアースの七層」は文学表現であり、実寸として使わない。

材質接頭辞（銅・鉄・鋼・ミスリル等）は品質帯。史実側の型名には載せない。

## 盾の大きさ・形状・重量（早見・史実）

詳細は `historical/01-shields.csv`。

| 名称 | 形状 | 寸法の目安 | 重量の目安 | 覆う範囲 | 持ち方 |
| :--- | :--- | :--- | :--- | :--- | :--- |
| バックラー | 円（まれに角） | 直径 15–45 cm（典型 25–40） | 0.5–2 kg（典型 ~1） | 拳〜前腕 | 拳握り |
| タージ（スコットランド） | やや凸の円 | 直径 45–55 cm | 2–3.5 kg | 胴中央 | 腕紐 |
| ヴァイキング円盾 | 円（ほぼ平坦） | 直径 70–95 cm（Gokstad ~90–94） | 3–5.5 kg | 密集時は肩〜腿 | ボス後ろのセンターグリップ |
| アスピス（ホプロン） | 深い凸円 | 直径 80–100 cm | 6–8.5 kg | ファランクスで顎〜腿 | 腕帯＋手握り |
| スクトゥム（帝政） | 曲面の矩形 | 高さ 94–110 cm × 幅 60–84 cm | 6–10 kg | 肩〜膝 | ボス握り |
| カイトシールド | 杏仁／涙滴 | 高さ 90–130 cm × 上幅 50–70 cm | 4–6.5 kg | 首〜脛（特に騎馬の左脚） | 腕紐＋ギーグ |
| ヒーターシールド | アイロン底型（上辺丸い逆三角） | 高さ 45–80 cm × 幅 35–55 cm（残欠例 60–82 × 47–54） | 1.5–3.5 kg | 胴 | 腕紐＋ギーグ |
| パヴィース | 高い矩形 | 高さ 96–150 cm × 幅 50–80 cm | 6–16 kg | 立てれば全身 | 腕紐＋支柱（据え置き） |

神話の盾（アイギス、アキレウスの盾、アイアースの七層盾、アンキレ）は `mythology/01-shields.csv`。ゲームのタワーシールドは `fiction/01-shields.csv`。

## 対象外

- 近代火器の細部（マスケット以降は `historical/06-weapons-ranged.csv` に代表種のみ）
- 現代創作の固有名（トールキンの指輪、ゲームオリジナルの固有神器）。型として定着したミスリル等は `fiction/`
- 乗り物そのもの（スレイプニル等は `mythology/11-accessories.csv` の mount に最小限）
