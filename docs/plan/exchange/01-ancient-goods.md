# 古代の交易品(青銅器時代〜古典古代)

実史イメージ: メソポタミア・エジプトの都市文明成立から、ギリシャ・ローマ・漢の帝国交易まで(〜500 年頃)。

## 交易の構図

- **錫と銅の長距離調達** — 青銅は銅と錫の合金だが、錫の産地(ブリタニア、イベリア、中央アジア)は文明中心から遠く偏在した。青銅器時代の長距離交易網はほぼ錫のために張り巡らされ、産地の枯渇・途絶は文明の危機に直結した。
- **穀物艦隊** — アテネは黒海沿岸から、ローマはエジプト・北アフリカから穀物を海上輸送して大都市人口を養った(アンノナ制)。穀倉地帯の掌握が覇権の条件。
- **フェニキアの地中海網** — レバノン杉・貝紫・ガラス・ワインを積んで植民市(カルタゴ等)を結ぶ。貝紫はアクキガイから微量しか採れず「皇帝の紫」として同重量の銀を超える値がついた。
- **香料の道** — 南アラビア(乳香・没薬)から隊商がアラビア半島を縦断。ラクダの家畜化が前提条件。
- **絹の道とインド洋モンスーン交易** — 漢の絹がパルティア経由でローマへ。ローマは胡椒・真珠・宝石の対価として銀を流出させ続け、元老院で奢侈批判が起きるほどだった。
- **琥珀の道** — バルト海の琥珀が陸路でアドリア海へ。北欧と地中海を結ぶ最古級の南北交易路。

## 時代フレーバー演出のポイント

- **存在しないもの**: 火薬・大砲(既存の `gunpowderEraEnabled` で制御済み)、磁器・コーヒー・カカオ・ジャガイモ・トウモロコシ・タバコ・蒸留酒(Liquor は蒸留技術としては時代先行だが許容範囲)。
- **強調すべきもの**: Tin / Copper / Bronze の戦略性(`warEconomyType: "strategic"` は設定済み)、Grain の海上大量輸送、Incense / Silk / Spices の超高付加価値・小容量という交易プロファイル(既存 `GOOD_TRADE_PROFILES` の rarity/distancePremium 高設定と整合)。
- **鉄 vs 青銅**: 時代内でも前期(青銅中心)と後期(鉄普及)で武具レシピの主材が入れ替わる。既存の Arms / Tools / Harnesses が Iron と Bronze の両レシピを持つ設計はこの過渡期表現としてそのまま使える。
