# 中世の交易品(〜15 世紀)

実史イメージ: イスラム商業圏の成立、ヴァイキング交易、ハンザ同盟、地中海海洋共和国(ヴェネツィア・ジェノヴァ)、モンゴル平和下のシルクロード最盛期、サハラ縦断交易、インド洋ダウ船交易。

## 交易の構図

- **羊毛⇔毛織物の南北軸** — イングランドの原毛がフランドルの織布都市へ渡り、毛織物として還流。羊毛輸出税は英国王の最大財源で、大法官は今も「羊毛の袋(Woolsack)」に座る。
- **ハンザ同盟の北方物産** — ベルゲンの干鱈、スコーネの塩ニシン(四旬節の魚需要)、ノヴゴロドの毛皮と蜜蝋、バルトの穀物・木材・タール・麻。リューネブルクの岩塩がニシン加工を支えた。
- **地中海の中継独占** — ヴェネツィア・ジェノヴァがレヴァント経由の香辛料・絹・明礬を中継。明礬(毛織物染色の媒染剤)は毛織物産業の戦略物資で、産地(フォカイア→トルファ)の支配は外交問題になった。
- **サハラ縦断交易** — マリ帝国の金(マンサ・ムーサの喜捨でカイロの金相場が暴落)と、タガーザの板状岩塩が同重量で交換されたと伝わる。塩・金・奴隷・馬のラクダ隊商。
- **ヴァイキング〜ルーシの河川路** — 毛皮・奴隷・蜜蝋・セイウチ牙をヴォルガ/ドニエプル経由でイスラム銀(ディルハム)・ビザンツ絹と交換。グリーンランドの一角獣(Narwhal)の角は「ユニコーンの角」として同重量の金を超える値で売れた。
- **インド洋ダウ船交易** — グジャラート・ベンガルの綿布、マラバールの胡椒、セイロンのシナモン、中国の磁器・絹がモンスーンに乗って行き交う。
- **茶馬古道** — 宋の茶とチベット・西域の軍馬を交換する国家管理交易。

## 時代フレーバー演出のポイント

- **戦略物資の主役交代**: 古代の錫に代わり、羊毛(織物産業)・明礬(染色)・船舶用品(海運)・硫黄(火薬前夜)が「押さえるべき中間財」になる。明礬・硫黄の追加でこの構図が再現できる。
- **教会需要**: 蜜蝋(蝋燭)・ワイン(聖餐)・香(Incense)・写本(Books)は宗教施設が安定した大口需要者。`demandCoverage` 上は luxury / utilities でカバーされるが、将来 religion multiplier で寺院都市の需要を厚くする拡張余地がある。
- **一角獣の角**: 中世で最も「ファンタジー適性」の高い交易品。極北海域のみ産出・超高値・王侯需要という設定がそのまま史実(グリーンランド・ノルド人の経済はほぼこれで持っていた)。
- **火薬時代への接続**: `gunpowderEraEnabled` が false の「騎士の時代」でも Saltpeter は既に配置される設計。Sulfur を追加しても同様に「原料だけ流通し完成品(Gunpowder)が存在しない」中世後期の状態を表現できる。
