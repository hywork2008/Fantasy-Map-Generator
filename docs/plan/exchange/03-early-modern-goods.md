# 近世の交易品(大航海時代〜18 世紀)

実史イメージ: 喜望峰ルート開拓、コロンブス交換、ポトシ銀とマニラ・ガレオン、東インド会社(VOC / EIC)、三角貿易、北方毛皮交易、大西洋タラ漁。

## 交易の構図

- **香辛料の直買付** — ポルトガルが喜望峰ルートでヴェネツィアの中継独占を迂回。のちに VOC がナツメグ・クローブ・メースの産地(バンダ諸島・モルッカ諸島)そのものを武力で独占し、供給量を焼却処分で統制した。
- **銀の世界循環** — ポトシ銀山(1545 発見)の銀がスペイン経由で欧州へ、またマニラ・ガレオンで太平洋を渡り、絹・磁器の対価として明・清に吸い込まれた。世界初の「グローバル通貨」。
- **コロンブス交換** — ジャガイモ・トウモロコシ・カカオ・タバコ・唐辛子・バニラが旧大陸へ、小麦・サトウキビ・コーヒー・馬・牛が新大陸へ。ジャガイモは北欧の人口爆発を支えた。
- **三角貿易** — 欧州の工業製品(織物・銃・酒)→西アフリカ、奴隷→カリブ・アメリカ、砂糖・ラム・タバコ→欧州。砂糖プランテーションが近世大西洋経済の心臓。
- **毛皮とタラの北方経済** — ビーバー毛皮(フェルト帽の大流行)が北米内陸開拓を、クロテンがロシアのシベリア征服を駆動。グランドバンクスの塩鱈は「海の銀」。
- **東インド会社の消費革命** — 茶・コーヒー・インド綿布(キャラコ)・磁器が欧州の日常を変えた。キャラコは在来毛織物業を脅かし輸入禁止法(キャラコ論争)を招くほどの破壊力。
- **船舶用品(Naval Stores)の戦略化** — バルト海のタール・麻・マスト材は海軍国の生命線で、封鎖されれば艦隊が維持できない戦略物資だった。

## 時代フレーバー演出のポイント

- **「白い金・黒い金」**: 砂糖・磁器・胡椒など、産地独占と大量海運が結びついた品が時代の主役。既存の `GOOD_TRADE_PROFILES` は distancePremium の高い品を遠隔地交易に誘導する設計なので、新規品(Porcelain, Coffee, Cacao)も同系のプロファイルを与える。
- **新作物の意味**: Potatoes / Maize は「価値が低く、遠隔地交易には向かないが、痩地・高地の食料事情を一変させる」品。交易品というより**入植・人口シミュレーション側への効果**(biomeOutput で寒冷・高地バイオームの食料産出を底上げ)が本体。
- **ゴムの扱い**: 史実では本格利用が 19 世紀のため、近世マップでは無効化(時代ゲート)か「異国の珍品」としての少量流通に留めるのが妥当。goods.md の要望(ゴムの木/ゴム)は熱帯雨林バイオームの特産として実装可能。
- **既存カタログとの親和性**: 近世は既存 73 品目が最も厚くカバーしている時代(船 3 種・火薬・大砲・タバコ・茶が既にある)。不足はコロンブス交換系の新作物と消費革命系の嗜好品に集中している。
