## 1. 目的

地図生成直後と最初の数年に、FMGが置く正式なギルド会館と、CEが描く職人街・会館を、町で実際に働いている職人に合わせる。

- C: 職人のいない会館を開かない。会館の開設と解散が3年ごとに繰り返されないようにする。
- D: 町の手工業の大部分を占める財（保存食・ビールなど）に、正しい労働量と業種を与え、CEの職人街に反映する。

## 2. 現状

### 2.1 観測（4枚の世界地図、seed 2101〜2104、1300年）

| 項目 | 値 |
| --- | --- |
| 生成時の会館のうち、職人が0人の会館 | 112/130・136/153・114/120・131/141 |
| 36か月目の会館（生成時から） | 130→58・153→77・120→78・141→72 |
| 60か月目にガラス・計器・印刷の会館で職人がいるもの | 0 |
| 手工業のうちギルドの業種に属する割合 | 生成直後6〜15%、5年後15〜25% |
| CEの職人街21区画がすべて「業種なし」の都市 | 全都市の52〜63%（60か月目） |
| 保存食を作る都市（5年後） | 71.5%（2位はビール18%、布16%） |

### 2.2 会館の置き方（C）

- 生成の最後に`GuildChapters.seedAfterGenerate`が、国ごと・業種ごとに立地点数（`scoreGuildChapterSuitability`）の高い都市へ会館を置く。閾値は0.35で、上限は国の都市数/10（1〜6）、1都市に4つまでである。
- 点数の職人の項は0.15〜0.55しかなく、残りは森・港・首都・人口・市場で決まる。たとえば木工は「森0.25＋港0.2＋市場0.15」、計器は「首都0.3＋人口0.35＋市場0.2」で、職人がいなくても0.35を超える。
- 年次の`settleAnnual`は、技術ストックが0.02未満のまま3年たった会館を解散し、15%の確率で同じ点数の基準で新しく開く。職人がいない会館は、3年ごとに解散と再開設を繰り返す。
- 非公式の実践の昇格（`promoteTenuredInformal`）は、ストックが約0.39に達した実践だけを会館にする。生成時のストックは年次更新1回分の0.15なので、生成時には昇格が起きない。
- 業種の時代の条件はFMG側に無い。1300年の地図で印刷の会館が16〜19できる。CE（`planGuildFacilities`）は印刷の会館を大航海時代より前には描かないが、FMGの会館は残る。
- 石工の実務者は`Lime`などのレシピ財の職人だけで、建設の石工（`ConstructionOperation.masonWorkers`）は数えない。石工の会館は、石切り場と建設需要の点数だけで立つ。大工と木工の関係も同じである。

### 2.3 手工業の業種（D）

- 業種は`CRAFT_DOMAIN_BY_GOOD_NAME`（`guildKnowledgeTypes.ts`）の29財だけに付く。食品と贅沢品は「ギルドの対象外」として外されている。
- **業種の無い財には、労働量の較正も無い。** `laborPointsForLots`は、`GOOD_DEMAND_CALIBRATION`にも`UNCALIBRATED_LABOR_POINTS_PER_LOT`（現在は木炭だけ）にも無い財に、1ロットあたり労働1ポイント（人口率1000で1,000人月）を掛ける。
- 保存食だけを作る町では、月0.07ロットに職人70人が就いていた（1ロットあたり約1,000人）。保存食1ロットは0.9 tの塩漬けで、実際の手間は数人日である。手工業の人数の大半は、この1ポイントで生まれた数字である。
- 1300年の地図で作られる、較正の無いレシピ財は次のとおり（5年後に作っている都市の割合）。保存食71.5%、ビール18.0%、タール9.2%、木炭1.0%（木炭は較正あり）、宝飾品0.3%、彫刻0.3%、香水0.2%、蝋燭0.2%、タペストリー0.2%、美術品0.1%。ほかに、ワイン・酢・灰・煉瓦・消石灰・材木・紡ぎ車・燻製チーズ・干し果物・干しぶどう・干し魚・林檎酒・梨酒・石鹸・楽器・聖遺物も較正が無い。

### 2.4 CEの職人街と会館

- `economyWardMix`は、21区画の職人街を`SiteGuild.practitioners`の比で業種に分ける。業種の無い職人は数えないので、業種の付いた職人がいない町では21区画すべてが「業種なし」になる。
- 業種は街区の位置にだけ効く（`craftsmanScore`）。皮革は川の下流、繊維は外向きの門、冶金・木工・石工は大量貨物の門の近くである。職人街の建物の用途は、業種にかかわらず`["residential", "craft"]`である。
- 会館（`planGuildFacilities`）は`SiteGuild.status === "chapter"`なら職人0人でも描き、業種ごとの付属の置き場（漂白場・皮なめし場・材木置場など）も描く。
- BVには、パン屋（10）・鍛冶場（11）・醸造所（15）・織物と皮革の工房（20）・木工の工房（21）・皮なめし場（22）のモデルがある。CEの職人街の建物には使われていない。

## 3. 方針

### 3.1 C: 会館は職人のいる都市にだけ開く

**C1. 開設の条件に実務者を加える。** 生成時（`seedAfterGenerate`）と年次（`settleAnnual`の`addBestChapter`）の両方で、その都市・業種の実務者（`collectGuildPractitioners`）が`CHAPTER_MIN_PRACTITIONER_PEOPLE`人以上の時だけ開く。初期値は3人とする（`craft-demand-calibration.md`の「3人の木工が残る」と同じ最小の工房）。立地点数は、条件を満たした都市の順位付けにだけ使う。

**C2. 時代の条件をFMG側にも置く。** CEの`planGuildFacilities`と同じ規則を`guildChapters.ts`に置き、共通の定数にする。

| 業種 | 正式な会館を開ける時代 |
| --- | --- |
| 印刷 | 大航海時代（ageOfExploration）以降 |
| そのほか | 盛期中世（highMedieval）以降 |

盛期中世より前の地図では、実践（技術ストック）だけが残り、会館は開かない。既存の会館は、時代が下がっても消さない（時代は通常下がらない）。

**C3. 建設の職人を実務者に数える。** `collectGuildPractitioners`に、建設の石工を石工（masonry）、大工を木工（woodworking）の実務者として加える。人数は実人数の建設雇用（床3人・最大12人の規則）から取る。石切り場の作業員は、すでに点数の項（`quarryWorkersByBurg`）にあるので、実務者には加えない。

- 効果: 石工・木工の会館が、建設の続く町に職人付きで立つ。中世の都市で石工と大工の組合が早くからあったことに合う。
- 影響: 技術ストックが`Lime`・`Barrels`などのレシピ財の生産ボーナス（`getGuildBonus`、最大25%）にも効く。建設の職人の多い町で、これらの財の生産が増える。§5の観測で確かめる。

**C4. 再開設の間を置く規則は作らない。** C1で職人のいない会館は開かないので、解散は「職人がいなくなって3年たった会館」だけになる。同じ都市にまた職人が集まれば、会館を開き直してよい。

**C5. 生成時の会館は、生成時の職人の数に左右される。** 生成直後の手工業は、落ち着いた値の約3分の1である（`economy-start-20261102.md` §1）。C1の後は、生成時の会館が今より少なくなる（主に繊維・冶金・少数の皮革）。生成直後の経済を落ち着いた状態に近づける改善B（別の設計書）が入れば、同じ規則で会館が増える。Cは、Bを待たずに実装してよい。

### 3.2 D: 手工業の労働量を較正してから、業種を付ける

**D1. 較正の無いレシピ財に労働量を与える（先にやる）。** `UNCALIBRATED_LABOR_POINTS_PER_LOT`に、1300年前後の地図で作られる財の、1ロットあたりの人月を加える。需要の行（`GOOD_DEMAND_CALIBRATION`）は作らず、労働量だけを与える。需要の上限を新しく掛けると、保存食の供給が変わり、塩・家畜・食料の調整（`salt-*`・`livestock-*`の記録）に響くためである。

初期の見積もり（実装の時に出典を確かめて直す）:

| 財 | 1ロット | 見積もり（人月/ロット） | 考え方 |
| --- | --- | ---: | --- |
| 保存食 | 0.9 t（樽詰め） | 0.5 | 魚や肉の下ごしらえ・塩漬け・樽詰めで1人1日約60 kg |
| ビール | 1,000 L | 0.2 | 麦芽作りから仕込み・樽詰めまで、1,000 Lに約5人日 |
| 林檎酒・梨酒 | 1,000 L | 0.15 | 粉砕・搾り・樽詰め |
| タール | 1樽 | 0.1 | 炉の番と樽詰め（木を切る手間は原料の木材に含まれる） |
| 酢 | 1樽 | 0.05 | 仕込み済みの酒からの発酵の管理 |
| 蝋燭 | 100 kg | 0.15 | 獣脂を溶かし浸し掛けで1人1日約25 kg |
| 石鹸 | 1樽 | 0.2 | 煮詰めと型詰め |
| 煉瓦 | 1 wain | 0.3 | 成形・乾燥・焼成 |
| 消石灰 | 1袋 | 0.02 | 消化と袋詰め |
| 材木 | 1本 | 0.1 | 製材（木挽き） |
| タペストリー | 20 kg | 10 | 高機で1人月約1 m²、1枚約10 m² |
| 宝飾品・彫刻・美術品・楽器・聖遺物・香水 | 1点 | 1〜6 | 品ごとに出典で決める |

人月を`laborPointsForLots`の単位（人口率1000での労働ポイント）にするには、1,000で割る。見積もりの値は、§5のD1の観測で「保存食だけの町の職人が人口1,000人あたり数人〜十数人」になるかを見て確かめる。

**D2. 既存の業種に入る財を表に加える。**

| 財 | 業種 | 理由 |
| --- | --- | --- |
| タペストリー | 繊維 | 織物職人の仕事 |
| 紡ぎ車・材木・楽器 | 木工 | 指物師・木挽き・楽器作りは木工の組合に属した |
| 煉瓦・消石灰・彫刻 | 石工 | 煉瓦積み・石灰焼き・石彫り |
| 宝飾品 | 冶金 | 金銀細工（独立の組合が多かったが、この粗い分類では冶金とする） |

**D3. 食品の業種を2つ加える。**

| 業種 | 財 | 史実の組合 |
| --- | --- | --- |
| `victualling`（食品加工） | 保存食・干し魚・燻製チーズ・干し果物・干しぶどう・酢・蝋燭・石鹸 | 肉屋・魚屋・塩蔵業。蝋燭と石鹸は肉屋の獣脂を使う獣脂業 |
| `brewing`（醸造） | ビール・林檎酒・梨酒 | 醸造業の組合（ロンドンは1438年に認可） |

- ワインとポマースワインは、農村のぶどう園の仕事なので業種を付けない。
- チーズは酪農の特例（`dairy.ts`）で作られるので、この表には入れない。
- タール・木炭・灰は、森の中の炭焼き・タール焼きの仕事で、町のギルドではない。業種は付けない。CEにはD4の「業種の無い職人」の内訳として渡す。
- 美術品・聖遺物・香水は、業種を付けない（画家の組合などは町に1つあるかどうかで、粗い分類に合わない）。

`CRAFT_KNOWLEDGE_DOMAINS`に2つを加えると、次のものが一緒に変わる。

| 対象 | 対応 |
| --- | --- |
| `scoreGuildChapterSuitability`（網羅的な`switch`） | 2業種の点数を加える。食品加工は職人＋市場＋人口、醸造は職人＋川（水）＋市場 |
| `getGuildBonus`（技術ストックによる生産ボーナス） | 他の業種と同じに効かせる。保存食とビールの生産が最大で`GUILD_BONUS_MAX`（25%）増える。§5で確かめる |
| `OCCUPATIONAL_CALIBRATION`の行 | 2行を加える（町の人口1,000人あたりの目安。出典はD1と一緒に確かめる） |
| `GUILD_DOMAINS`（`src/services/burgSiteEconomy.ts`と`src/city-editor/data/siteEconomy.ts`） | 2つを加える。CEの古い保存（2業種を知らない）は、知らない業種を捨てる今の読み込み（`DOMAINS`の集合）のまま |
| 多言語化（`src/i18n/locales/*.json`のギルド業種名、CEの会館名） | 2つを加える |
| Guild Overview・Calibration Overviewの表 | 業種の一覧から自動で増えることを確かめる |
| `guildSuccession.ts`（師弟、現在は冶金だけ） | 変えない |

**D4. CEへ「業種の無い職人」の内訳を渡す。** `BurgSiteEconomy`に任意の欄`otherCrafts?: { kind: "forestWorks" | "luxury" | "other"; people: number }[]`を加える。生産ループ（`runWorkerLoop`）の業種別の集計に、業種の無い財の人数を3つの区分で加えて取る。

- `forestWorks`（タール・木炭・灰）: CEは職人街に数えず、町の外縁に置き場（BV 13の燃料置き場）を置く。
- `luxury`（美術品・聖遺物・香水）と`other`: 職人街の「業種なし」の区画に数える。

**D5. CEの職人街と会館。**

- `craftsmanScore`に2業種の位置の規則を加える。食品加工は市場広場の近くで、川があれば下流（肉屋の血や内臓を流す。皮革と同じ考え）。醸造は川か井戸の近くで、大量貨物（穀物）の門の近く。
- `planGuildFacilities`の付属の置き場は、2業種とも今は加えない（屠畜場・麦芽小屋は後の課題）。会館は共通のギルド会館（BV 28）を使う。
- 職人街の建物に、業種ごとのBVの工房モデル（パン屋・醸造所・鍛冶場・織物と皮革の工房・木工の工房）を使うことは、この設計書の範囲外とし、§7に残す。

| C3 | 石工・木工の会館と実務者、`Lime`・`Barrels`・`Ropes`の生産、建設雇用 |

| D2・D3 | 手工業のうち業種に属する割合、2業種の会館と技術ストック、保存食・ビールの生産量（ボーナスの効果） |

## 6. 未決事項

1. C1の最小人数（3人）。実務者の数え方（技術の飽和は12人）と合わせて、2〜6人の幅で観測して決めてもよい。
2. D1の労働量の見積もり。出典を確かめる。とくに保存食は魚と肉で手間が違うので、レシピごとに分けるかどうか。
3. D3で加える2業種の技術ボーナスを、ほかの業種と同じに効かせるか。保存食の生産が増えると、塩の需要も増える。
4. D3の名前。`victualling`（食品加工）を肉屋・魚屋・獣脂業にまとめるか、`butchery`と分けるか。
5. 盛期中世より前の地図で、会館を一切開かないか（C2）。初期中世にも商人ギルドや一部の職人組合はあった。

## 7. この設計書の範囲外
