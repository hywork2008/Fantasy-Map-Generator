## 0. 結論

- FMG の川を実在の谷へ寄せる方式（`snapRiverToValley`）はやめる。FMG の川は約21kmのセルから作るので、実在の谷と道筋が合わない。半径6kmで寄せても尾根を越える区間が残り（R8・T7、ユーザーの確認画像）、寄せ先も高さのわずかな差で変わる（T7：最大7.5km）。
- 逆に、谷を FMG の川に合わせて作る。川の線に沿って、谷底・側壁・尾根を持つ横断面を地面から差し引く。寸法（深さ・幅・側壁の角度）と側壁の形は、実在の日本の川 23,720 断面の実測から取る（[記録](../analytics/japan-valley-profiles-20261117.md)）。
- 深さは、その川の周りのセル高さの起伏で決める。起伏の大きい山地では峡谷、平地では浅い谷になる。
- 実在DEMのある Japan でも同じ谷を彫る（実在の谷とは別の位置に谷ができるが、川は必ず谷底を流れる）。DEMの無い地図では双線形のセル高さに彫る。どちらも同じ高さ関数で、窓の地面とタイルに効かせる。
- 海抜0m未満の土地（ゼロメートル地帯）はこの設計では扱わない。

## 1. 実測からわかったこと

| 項目 | 値（中央値） | 使い方 |
| :--- | :--- | :--- |
| 側壁の形 | 深さによらずほぼ直線。0.1→0.11、0.5→0.45、0.9→0.88 | 横断面の曲線を一本の表にする |
| 峡谷の側壁 | 谷底脇が急（0.2→0.30）、尾根の手前で再び急 | 峡谷用の別の曲線 |
| 尾根まで | 3〜4km（峡谷 2.7km） | 谷の片側の幅 |
| 半深幅 | 浅い谷 0.9〜1.4km、深い谷 2.4〜3km | 深さから幅を引く |
| 側壁の角度 | p50 3〜11°、p90 9〜22°、峡谷 12° | 見栄え重視なら p90 側 |
| 谷底幅 | 0.4〜1km（格子の下限を含む） | 川幅と合わせて平らな底 |
| 左右比 | 浅い谷ほど非対称（深さ150m以上で 1.2〜1.6） | 片側の尾根を低くする揺らぎ |
| 谷底の標高と深さ | 谷底 0–200m で 71m、1000m 以上で 256m | 起伏が無いときの既定の深さ |

## 2. 高さ関数

`valleyMetersAt(x, y)` を、今の `createLocalTerrainField` の河川掘り下げ（幅300m・最大30m）と置き換える。

1. 川の折れ線（`Rivers.addMeandering` の点と幅）を、窓に掛かる分だけ線分索引に入れる（今の `PointIndex` を流用）。
2. 地点ごとに、最寄りの川までの距離 `d` と、その点の谷の寸法を求める。
   - 深さ `D`：川の両側のセルの最高点と川のセルの高さの差（起伏）× `reliefShare`（初期値0.6）。上限は実測 p90 に合わせ、谷底の標高ごとの既定値を下限にする。
   - 片側の幅 `W`：深さから実測の表で引く（例：深さ300mで 2.4〜3.6km）。峡谷の寸法を選ぶ条件（深さ300m以上かつ両側の起伏が大きい）を満たせば `W` を峡谷の値（2.7km）にし、曲線も峡谷用にする。
   - 谷底の半幅 `F`：川幅の半分と、実測の谷底幅の半分の大きい方。
3. 高さ = 元の地面 − `D` × (1 − 曲線((d − F) / W))。`d ≤ F` は谷底（元の地面 − `D`、ただし下流へ単調に下がるよう、川に沿った最小値で抑える）。`d ≥ F + W` は元の地面のまま。
4. 谷底の標高は、川に沿って上流から下流へ単調に下がるように、今の「上流からの最小値」を使う。
5. 揺らぎ：側壁に、川に沿って1〜2kmおきの支谷（小さな切れ込み）と、左右の尾根の高さの差（左右比）を種から足す。どれも `F + W` で0に戻す。

元の地面は、DEMがあればDEM、無ければセルの双線形。谷は元の地面から引くだけなので、谷の外は今と同じ。

## 3. 見栄えの調整口

`LocalTerrainTuning.valley`（URL `ltValley*`）。

| 口 | 初期値 | 意味 |
| :--- | :--- | :--- |
| `enabled` | true | false で今の掘り下げ（300m・30m） |
| `reliefShare` | 0.6 | 起伏のうち谷の深さに回す割合 |
| `widthScale` | 1 | 実測の幅に掛ける。小さいほど峡谷らしい |
| `gorge` | true | 峡谷の寸法・曲線を選ぶか |
| `spurs` | true | 支谷と左右差の揺らぎ |
| `maxDepthM` | 800 | 深さの上限 |

## 4. 調整の進め方

| 回 | 内容 | 測る値 |
| :--- | :--- | :--- |
| V0 | 横断面の曲線と寸法表、`valleyMetersAt` の純粋関数とテスト（谷の外は元の地面、谷底は下流へ単調、`F + W` で連続） | 単体テスト |
| V1 | 戦争用の窓（セルの双線形の地図）に入れる。Japan 以外のテンプレートで、山地の川を撮る | 見た目、描き直しの時間 |
| V2 | Japan（タイル）に入れる。タイルの高さに谷を足す方法（タイル作成時に窓の中だけ足す）を決める | 見た目、タイル作成の時間 |
| V3 | 峡谷の条件・揺らぎ・調整口の既定値を決める | 試験地点の比較画像 |

## 5. やらないこと

- FMG の川の道筋を変えない（シミュの川のまま）。
- `cells.h` に谷を書き戻さない。
- 海抜0m未満の土地の扱い（別の課題として保留）。
- 実在の谷へ寄せる処理（`snapRiverToValley`）の改良。谷を作る方式に置き換える。
