# 蜜蝋の値段を在庫と需要で決める

## 1. 背景

[wax-export-20261114.md](../analytics/wax-export-20261114.md)で、蜜蝋を港から積み出しても在庫は年約2,500個（地図2102）増え続け、在庫で重みを付けた値段（基の値の1.7〜2.0倍）が市場の単純な平均（約1.2倍）より高かった。在庫の多い市場ほど値段が高く、蜜蝋は隣の市場へ流れない。

## 2. 今の決まり

- 蜜蝋は蜂蜜を採る時に出る副産物で、作り方もセルの分布も無い。毎月の値付けの1つ目の段（分布・鉱山・炉の品）にも2つ目の段（作り方のある品）にも当たらない。
- `SLAUGHTER_BYPRODUCTS`（革・獣脂・凝乳酵素）は在庫と町の目標で値付けされる（[byproduct-prices.md](byproduct-prices.md)）が、蜜蝋は入っていない。
- そのため値段を動かすのは、毎月の`applyLocalTradePriceBias`の掛け算（在庫による押しは最大±0.18、市場ごとの固定の偏り`getMarketBias`は約±0.2）と、買われる時の値上げ（`applyMarketPressure`）だけである。掛け算は月ごとに重なるので、偏りが負の市場や蝋燭職人のよく買う市場では、在庫が多くても上限（3倍）へ上がり続ける。

## 3. 決める仕組み（案）

### 3.1 蜜蝋を1つ目の段に

- 蜜蝋を、革・獣脂と同じく1つ目の段で値付けする（`getRawGoodTargetPrice`：基の値 ×（需要+5）÷（在庫+5）、下限0.25倍・上限3倍）。
- 需要は、市場の町の蝋燭（Candles）の目標の量 × 蜜蝋の作り方の量（1個）とする。蝋燭の典型の作り方が油でも、教区と貴族の灯りは蜜蝋で作ったので、蜜蝋を含む作り方の量を使う。
- 買われる時と交易の押しからは、革・獣脂と同じく外す（`isPricedByTownTargets`）。

### 3.2 設定

- `beeswaxPricing`: `stockAndDemand`（既定、3.1）か`legacy`（今の決まり）。`byproductPricing`が`legacy`の時は、蜜蝋も今の決まりになる。

## 4. 見込み

- 蜜蝋の在庫の多い市場で値段が下限に向かい、在庫で重みを付けた値段が単純な平均より低くなる。
- 安い市場から高い市場へ、交易で蜜蝋が流れやすくなる。蝋燭の元値が下がる。
- 蜂蜜を採る農家の副収入は下がる（蜜蝋の値は売った時の値段で数える）。

## 5. 計測の計画

北緯30°の地図2枚（2102・2103）、36か月、戦争なし・隊商の略奪なし。`beeswaxPricing`の`legacy`と`stockAndDemand`を比べる。

1. 蜜蝋の在庫、単純な平均と在庫で重みを付けた値段。
2. 蜜蝋の積み出し・交易・使った量、蝋燭の作った量。
3. 町の家計・農村の家計。

## 6. 未確定事項

1. 下限でも需要より多い蜜蝋の行き先（傷まないため、在庫は残る）。
2. 蜜蝋の家の需要（`demandCoverage`の灯り）を需要に入れるか。

## 7. 結果

[wax-pricing-20261114.md](../analytics/wax-pricing-20261114.md)。在庫が需要より多い市場は全て下限（0.25倍）になり、在庫で重みを付けた値段は基の値の約1.8〜2.0倍から約0.26倍になった。蝋燭の材料の蜜蝋は約12%増え、外からの蜜蝋は約半分、在庫の増えは年約2,600から約1,300（2102）に減った。蜜蝋の在庫はほぼ全て港の市場にあり、港の無い市場に溜まるという推測は外れた。下限でも余る分は残る（§6の1）。お金の差は±3%以内。
