# 市場の飼い葉の買い上げを需要までにする（2026-10-30）

関連: [unsold-harvest-household-store.md](unsold-harvest-household-store.md) §4、[記録（都市と農村のお金の流れ）](../analytics/urban-money-flows-20261029.md)。

## 1. 背景

`livestockFeed.ts`の`harvestLivestockForage`は、農家が自分の干し草を取った後に残った草を、市場が金庫のお金で全部買い上げる（価格の0.8倍、金庫の残高まで）。穀物の買い上げ（`foodProduction.ts`）には「売れる分と蔵の上限まで」という制限があるが、飼い葉には無い。

固定入力のWorld（1305年）では、草の余る市場（6・5・4・21）が、使う量48千ロットに対して65千ロットを買っていた。その代金が農村に入って町で使われ、都市の財布を潤す。草の多くを自分の群れが食べる市場（多雨地の牧畜の市場を含む）には、この流れが無い。需要の無い物にお金を払うことが、市場の間の財布の差の主な原因になっていた。

## 2. 方針

- 市場ごとに、この1年に家畜の餌として売れた飼い葉の量（`fodderAnnualUseLots`、毎月11/12を掛けてその月の売れた量を足す）を食料台帳に持つ。
- 草の買い上げは、`max(0, fodderAnnualUseLots × FODDER_STOCK_YEARS − 市場の在庫)`ロットまでとする。`FODDER_STOCK_YEARS`は1（仮値）。干し草は夏に取れて冬に使われるので、月でなく年の量を上限にする。
- 記録が無い市場（古いセーブ、最初の月）は、その月の家畜の注文（`getLivestockFodderOrderLots`）の12倍で始める。
- 買われなかった草は、刈られずに立ったまま残る（`unharvestedKg`に入る、今の扱いと同じ）。

## 3. 段階

| 段階 | 内容 | 完了条件 |
| --- | --- | --- |
| F1 | 2を実装する | 単体テスト：売れた量と在庫から決まる上限を超えて草を買わない |
| F2 | 固定入力（`docs/analytics/inputs/wet-pastoral-birth-20261029/world-102.fmg`）で84か月、f3241c832と比べる | 草の余る市場の買い上げが使う量に近づく。都市・農村の主食の充足と飼料の不足が悪化しない。都市の財布が尽きる市場が増えない |

### 3.1 F1・F2の結果（2026-10-30、[記録](../analytics/fodder-purchase-demand-cap-20261030.md)）

- F1: `livestockFeed.ts`に`fodderAnnualUseLots`（食料台帳）と`FODDER_STOCK_YEARS`（`livestockFeedPolicy.ts`）を加えた。単体テストを1件加えた。`livestockFeed.test.ts`の「carries actual summer hay into winter...」は、この変更の前（f3241c832）から失敗している。
- F2: 家畜の餌として売れた飼い葉は0.21→0.12百万ロット、飼料の不足は変わらない。増える市場の都市の財布は1306年以降に1割余り減り、減る市場は1307年に増えて、差は縮んだ。ただし1304〜1305年に都市の主食の充足が3ポイント余り下がり（94.2→91.1%、95.6→92.0%）、完了条件を満たさない。goldenの基準値は更新していない。

## 4. 未確定事項

- 1304〜1305年の都市の主食の充足の低下は、7割余りが市場1のお金の不足だった。市場1では、農村が草を市場に売って飼い葉として買い戻す要らない循環（1303年に売り18.5千・買い13.9千）が、市場の金庫から農村へお金を戻す主な経路だった。止めると農村が町で使うお金が13.4千→0.7〜5.0千に減り、同じ年の穀物の値上がり（0.73→1.53）と重なった（[記録](../analytics/fodder-purchase-demand-cap-20261030.md)の追記）。その後の調べで、金庫のお金は余りの分配や現金の収穫の代金として農村へ戻っていたが、家畜の塩（`saltLogistics.ts`、財布の全額まで買える）が先に取り、1303年に35.5千（変更前は5千程度）を払っていたことが分かった。家畜の塩の支出に財布の割合の上限を設けるかは未定。
- `FODDER_STOCK_YEARS`の値と、軍の調達の分を需要に含めるか。
- 草の余る市場の農村の収入が減った後、町の財布の釣り合いがどう変わるか（F2で測る）。
