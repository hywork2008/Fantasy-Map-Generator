# 中世ヨーロッパ風の街並み：プロシージャル生成の規約とガイドライン

本ドキュメントは、自然で説得力のある中世ヨーロッパ風の街並みをプロシージャル生成するための、一般的なルールとベストプラクティスをまとめたものです。Watabou's Medieval Fantasy City Generatorなどの類似の成功した生成ツールの設計思想や、都市工学的なアプローチに基づいています。

## 1. 全体的なアプローチ：道路中心かブロック中心か

中世の都市は、現代のグリッド状の都市とは異なり、地形や歴史的成長に応じて「有機的」に発展していくのが特徴です。

*   **道路中心（ボトムアップ・アプローチ）**: 血管が伸びるように道路を生成し、後からその隙間に建物を配置する手法。地形（川、丘、海岸）に沿って自然に曲がる道路網を作りやすく、中世らしさを表現するのに適しています。
*   **ブロック中心（トップダウン・アプローチ）**: 都市全体を大きな区画（ブロック）に分割し、それを再帰的に細分化していく手法。初期の分割点を工夫したりボロノイ図（Voronoi diagram）を活用することで、現代的すぎない自然な街区を形成できます。

## 2. 階層的な生成プロセス（Hierarchical Generation）

説得力のある都市を作るには、重要度の高いものから順に配置していく階層構造が重要です。

1.  **主要ノードの配置（ランドマーク）**: まず、城、大聖堂、中央広場、港、主要な城門など、街の核となる施設を配置します。
2.  **主要幹線道路の接続**: 上記のランドマーク同士や、街の外部へと繋がる主要な道路を引きます。これらは最も太く、比較的直線的（または地形に最も忠実）なルートを取ります。
3.  **細分化（二次・三次道路）**: 主要道路で囲まれたエリアの内部を、細い路地で埋めていきます。中世の街並みでは、これらの細道は曲がりくねっていたり、行き止まりがあったりします。
4.  **区画（Allotments）の割り当て**: 最終的に道路で囲まれたブロックの境界に沿って、建物の区画を割り当てます。すべての区画は必ずいずれかの道路に面している必要があります。

## 3. 空間・土地利用の制約と論理

*   **密度勾配（Density Gradient）**: 一般的に、街の中心部やランドマークの周辺は建物が密集し（富裕層や商業地域）、周縁部や城壁の外に向かうにつれて密度が下がり、農地やスラム、工業エリアへと移行します。
*   **地形への適応**: 道路や建物は地形を無視しません。急な斜面を無理に登るのではなく等高線に沿って道が作られたり、川岸に沿って街が発達する様子をシミュレートすることが、自然さの鍵となります。
*   **防衛と城壁（Defensive Logic）**: 中世都市の最大の特徴は「城壁」の存在です。初期段階で城壁の境界線を決定し、その内部という限られたスペースの中で道や街区が発展・密集していくという制約を持たせることが効果的です。

## 4. よく用いられるアルゴリズム

自然な街並みを生成するために、以下のようなアルゴリズムが組み合わせて使用されます。

*   **ボロノイ図（Voronoi Diagrams）**: ブロックや地区（District）の非線形で自然な境界を決定するのに非常に効果的です。
*   **L-System**: 道路網の分岐や成長をシミュレートするのに適しています。
*   **Wave Function Collapse (WFC)**: 建物のモジュールやタイルの配置において、「道路の隣には玄関が来る」「壁の隣には壁が来る」といった局所的なルールを破綻なく満たすのに強力です。
*   **エージェント・シミュレーション**: 仮想の住人が移動しながら街を開拓していくシミュレーションを行い、動的で生活感のある道路網を形成するアプローチ。

## 5. 実装へのアドバイス

*   **すべてを一度に作らない**: 全体像の生成から始め、徐々に細部（道路→区画→建物→屋根）へと解像度を上げていくステップ・バイ・ステップのアプローチをとります。
*   **不完全さを許容する**: 数学的に完璧な配置よりも、少しのノイズや歪み、不規則な区画がある方が、中世らしさ（有機的成長の結果）を感じさせます。
