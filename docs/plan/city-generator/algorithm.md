# 中世ヨーロッパ風都市生成アルゴリズム

本ドキュメントは、従来のボロノイ分割（トップダウン方式）による構造的矛盾を解消し、実際の歴史的な都市形成プロセス（ボトムアップ方式）および中世ヨーロッパの都市形態（アーバン・モルフォロジー）に基づいた新しいランダム生成アルゴリズムの仕様を定義する。

## 1. 基本思想
自然界の細胞分割のような数学的トップダウン（ボロノイ図）ではなく、**「道が伸び、道沿いに家が建つ」**というボトムアップのアプローチを採用する。建材の制約から生まれる直角・四角形ベースの建築と、地形や生活動線から生まれる有機的な道路網を融合させる。

## 2. 道路網と街区の形成

### 2.1 道路の連続性とルーティング
*   メインストリート（太い道）は、地形（等高線や河川）や古い街道、主要拠点（門や広場）を結ぶ**「なだらかで連続した曲線」**として生成する。
*   ジグザグな直線の繋がりではなく、交通の動線を意識した自然なカーブを描く。
*   **例外処理**: 太い道が教会や城など大規模な敷地を貫通することは避ける（生成時に迂回させる、あるいは施設を避けてルーティングする）。

### 2.2 街区（ブロック）の形状
*   連続する道路が交差・分岐することで街区が形成される。
*   湾曲した道に囲まれるため、街区はボロノイのような常に凸多角形である必要はなく、**三日月型や一部がえぐれた凹多角形**になることも頻繁に許容される。
*   計画都市的な区画では、厳密な直角のグリッド状（碁盤の目）の街区も生成パターンとして含める。

## 3. 敷地分割と建物の配置

### 3.1 バーゲージ・プロット（細長い短冊状の敷地）
*   街区の内部は、メインストリートに対して**ほぼ直角に交わる細長い長方形**（バーゲージ・プロット）に分割する。
*   これは、当時の税金や商業的価値が「通りに面している間口の広さ」に依存していた歴史的背景を反映している。家は通りに面して狭い間口を持ち、裏側（庭や工房など）に向かって奥深く伸びる。

### 3.2 建築物の形状ルール
*   **四角形ベース**: 整えられた建材の制約により、家の形は四角形の組み合わせとし、隣り合う辺は**直角**を基本とする（斜めに組み合わせることは基本的にしない）。
*   建物は真上から見た時、例外を除いて四角形で生成する。
*   城や城壁についている塔は四角、あるいは極めて丸に近い多角形とする。

### 3.3 土地と建物の関係（隙間の許容）
*   交差点などで街区や敷地が三角形になった場合でも、**隙間を無理やり建物で埋めない**。
*   三角の土地であっても、道路（住宅の辺）と平行になるように四角い建物を配置し、余った角地は空き地や庭としてそのまま残す。

## 4. ボトムアップの発展プロセス

アルゴリズムは以下のシミュレーション的プロセスを経て都市を成長させる：

1.  **拠点（Node）の配置**: 最初の家、あるいは核となる施設を建てる。
2.  **目的地の配置**: 家から離れた場所に作業所・移動先（Node）を作る。
3.  **経路（Path）の接続**: 家から作業所へ移動する道を引く。この時、道は家の辺と平行に面するように接続される。家の出入り口は辺にあり、角から斜めに出る事はあまりない（街区の角に建てられる家の軒数は、辺に建てられる軒数より少ないため）。
4.  このプロセスを反復し、道に沿って新たな家（四角形）が連なるように密集していく。

## 5. 街の中にある施設

生成される街には、以下の代表的な建造物・施設を配置する。

*   **住居・生活施設**
    *   住居 (平民の家、商人の館など)
    *   井戸・水飲み場
*   **商業・産業施設**
    *   広場・市場 (マーケットプレイス)
    *   ギルドホール (組合の集会所)
    *   店舗・工房 (鍛冶屋、パン屋など)
    *   水車小屋・風車小屋
    *   倉庫
    *   酒場・宿屋
*   **宗教・公共施設**
    *   教会・大聖堂
    *   修道院
    *   市庁舎
    *   病院・救貧院
*   **農業関連**
    *   農地・菜園
*   **防衛・軍事施設**
    *   防護柵
    *   櫓・見張り塔
    *   防護壁
    *   城壁・城門
    *   城・砦
