# 14. 史実・都市形態学レビュー（docs/plan 全体）

**作成日**: 2026-07-13  
**対象**: `docs/plan/` 計画書一式（01–13 および背景資料）  
**目的**: 中世ヨーロッパ都市のアーバン・モルフォロジーを、計画が正しく捉えているかを調査・評価する。

---

## 1. 総合評価

| 観点 | 評価 | コメント |
|------|------|----------|
| 形態の因果（何が何を決めるか） | ◎ | 立地→骨格→道→壁→街区→敷地→建物の順序は歴史的にも説得力がある |
| 敷地・フロンテージ原則 | ◎ | 中世町家の本質をよく押さえている |
| 道路網の性格 | ○ | 有機成長・T字路傾向は妥当。数値目標は仮説寄り |
| 城壁・郊外・耕地 | ○ | 典型像として正しい。成長リング等は意図的に後回し |
| 地区・施設配置 | ○ | 常識的で良い。階級・時代差は粗い |
| 地域多様性 | △ | NWヨーロッパ・城壁都市寄り。地中海・東欧・無壁市は弱い |
| 時代幅 | △ | 「中世」を一時点の静止画として扱っている |
| メトリクスの史実根拠 | △〜○ | 形態原理の代理指標として有用だが、考古学的平均ではない |

**結論**: 生成アプリの設計思想としては優秀。  
問題は「史実の完全モデルか」ではなく、「中世都市の**形態的制約**をアルゴリズムに落とすのに妥当か」であり、その問いに対しては **Yes（条件付き）**。

### 実務的な位置づけ

```
史実の都市そのもの ──────────────── × ── 本計画
史実の形態制約を満たす「ありえた町」 ── ○ ── 本計画
```

ランダム生成の仕様書として `docs/plan` は、学術的に大筋正しく、実装可能な粒度まで落ちている。  
「史実再現 GIS」ではなく、「中世都市形態学の制約付きジェネレータ」としては方向を誤っていない。

**主対象の明示（本レビューの勧告）**:  
現状の正典はおおむね **北西ヨーロッパの城壁市・13–15 世紀的完成形** である。地中海中庭型・運河都市・ローマ格子残存型は別プリセットとして拡張する（[15-region-presets.md](15-region-presets.md)）。

## 2. よく捉えられている点（史実・研究と一致）

### 2.1 ボトムアップ（道が先、空間分割が後）

ボロノイで「セル＝街区」を切るのを禁止し、動線としての道から面を得る方針は正しい。  
中世の有機都市では、先に交易路・渡河点・門–市場動線があり、その間が埋まって街区になる、という順序が一般的である。パイプライン（S1–S9）はこの因果をそのまま計算順序にしている。

参照: Conzen の町プラン分析（street system / plot pattern / building fabric の三層）。計画の段階的解像度と対応する。

### 2.2 バーゲージ・プロットとフロンテージ

「狭い間口・深い奥行・道に直角」の短冊敷地は、イングランドの *burgage* 法制を超えて、北西欧の町割りの**形態**として広く見られる。計画が「法制ではなく形態」と注記している点も正確。

| 計画の値 | 史実の目安 | 判定 |
|----------|------------|------|
| 間口 4–12 m（中央 ~6 m） | 1–2 パーチ（約 5–10 m）が多い。例: Hungerford で約 11 yards ≒ 10 m 前後 | 妥当 |
| 奥行 20–50 m | 例によっては 20 ロッド（約 100 m）級もある | **やや浅い側に偏り** |
| 縦横比 2–5 | 短冊定義として実用的 | 妥当（深めの史実例は比 8–15 もあり得る） |

「袋地に建物を建てない」「三角地を無理に埋めない」も、史実の隙間・中庭・空き地と整合する。

### 2.3 建物＝矩形合成・ゼロセットバック・共有壁

木造・石造の規格材・梁スパンの制約から、主屋平面が直角・矩形ベースになる、という説明は形態学でも建築史でも標準的。  
中世町家が通りに直接面する（セットバックほぼゼロ）のも正しい。ブルージュ型の「狭い間口で妻側を通りに向ける」記述も、北西欧商業都市の街並みイメージとして妥当。

### 2.4 城壁・門・郊外（faubourg）・耕地

- 壁内密／壁外疎  
- 門は幹線と壁の交点  
- 門外リボン状郊外  
- 開放耕地の短冊（furlong / selion 的パッチワーク）  

これらは中世城壁都市の教科書的構図。皮なめしを壁外下流に置くのも、悪臭・水質の歴史的配置として定番。

### 2.5 立地アーキタイプ

河港・丘上・港・街道交差という 4 類型は、中世都市の成立因の圧縮として妥当。  
参照都市（ローテンブルク、シエナ、ブルージュ、ヨーク、カルカソンヌ、クルムロフ）も、地図で形態を確認しやすい良いセット。

### 2.6 広場類型とバスティード

三角・紡錘（街道町）・方形（計画都市）の区別、および bastide 的グリッドは史実にある。  
教会身廊の東西軸も、ラテン西方教会の原則として正しい（例外はある）。

### 2.7 検証メトリクスという発想

「中世らしさ」を完全には数値化できないが、**形態制約の代理指標**（接道率、直角率、凹街区、密度勾配）を置く方針は、研究・生成の両面で健全。主観レビューだけに頼らない点は計画の強み。

## 3. 部分的に正しい／注意が必要な点

### 3.1 T字路支配（M5: 60–85%）

有機成長の町で三叉路が多い、という**定性**はよく言われる。  
ただし「壁内交差点の 60–85% が次数 3」は、特定都市の大規模計測に基づくというより、**生成上の目標値**に近い。

- 十字路も市場・計画拡張・旧ローマ道では普通  
- 時代が下ると交差点の「整形」も起きる  

→ **原理は正しいが、数値は仮説**。史実の「合格線」として固定しすぎない方がよい。

### 3.2 都市規模（15 / 40 / 100 ha）

城壁内 15–100 ha は、小さな市場町〜中規模城壁都市として無理はない。  
ただし「大都市 100 ha」は、パリ・フィレンツェ等の上位都市から見ると小さめ。計画の「大」は「このアプリ内の大」と読むのが適切。

人口密度の目安として城壁内 ~100–150 人/ha がよく引用される。敷地数×世帯係数 5 という HUD 推定は粗くても方向性は悪くない。

### 3.3 幹線の曲がり制限（最大 40° 等）

「緩い連続カーブ」「等高線沿い」は丘上都市で特に妥当。  
ただし中世の道は、地割り・所有境界・既存建物で**急な折れ**も起き得る。スムージング後の上限 40° は**見た目の連続性のための工学的制約**であり、考古学的上限ではない。

### 3.4 地区区分（market / noble / craft / poor…）

中世に「近代的ゾーニング」はない。それでも、

- 市場周辺に商業  
- 城・大聖堂付近に権力・富裕  
- 悪臭業種は周縁・下流  
- 壁際が相対的に低位  

という**傾向**は多くの都市で観察される。距離ベース割当はこの傾向の近似として妥当。  
弱い点は、同一街区の混在（1 階店舗＋上層住居、職住一体）がモデル上あまり表現されないこと。

### 3.5 塔の間隔 40–70 m

弓の射程・城壁塔の配置としてよく語られるオーダー。地域・時代・再建でばらつくので、**代表値**として扱うのがよい。

### 3.6 奥行 20–50 m の短さ

計画の奥行は「バーゲージ 1 列＋裏庭」を想定した実用レンジ。  
イングランドの典型例では奥行がさらに長いことがあり、**北英・アイルランド型の超長尺プロット**はカバーしきれない。欧州大陸の町割りや、街区奥行 50–90 m で背中合わせ 2 列、という設定自体は合理的。

## 4. 見落とされがちな史実・計画のギャップ

### 4.1 地域様式の偏り（最大の論点）

計画の「正典」はおおむね次に偏っている。

- **北西ヨーロッパ**の城壁市  
- **木造・半木造・狭い間口の町家**  
- イングランド的 *burgage* の形態語彙  

一方、次は薄い、または未モデル化:

| 類型 | 計画での扱い | 史実上の重要性 |
|------|--------------|----------------|
| 地中海の中庭型（広い間口・浅い奥行・パティオ） | 注記のみ・将来 `regionPreset` | 伊・南仏・イベリアで中心的 |
| 旧ローマ格子の残存 | ほぼなし | 伊・仏・英の一部で骨格を規定 |
| 運河都市（ブルージュ型水路網） | 参照都市にはあるがアルゴリズムは道路中心 | 低地商業都市の本質 |
| 無城壁の市場町 | village モード以外弱い | 実際は多数 |
| 二重城壁・成長リング | バックログ | 形態の時間層を示す重要現象 |
| ユダヤ人居住区・外国人商人区 | なし | 社会空間としては重要（実装は要配慮） |

→ 拡張計画は [15-region-presets.md](15-region-presets.md) に分離する。

### 4.2 時間＝静止画

中世は 11–15 世紀で、市場核の成立・城壁の新設・ペスト後の再編・後期の石造化などが重なる。  
計画は **「ある時点の完成形」** のスナップショットであり、非ゴールとも整合する。史実の都市というより **「史実にありそうな完成した町の形態」**。

### 4.3 所有・法制・課税

間口課税・バーゲージ保有・ギルド規制は形態の**原因**として触れられているが、生成には入っていない。  
経済シミュレーションなしという非ゴールとしては正しいが、「なぜ間口が狭いか」の因果は背景知識に留まる。

### 4.4 教会・世俗の複合

大聖堂プレシンクト、教区教会の間隔、修道院の壁外配置は妥当。  
ただし司教都市・王権都市・帝国自由都市・修道院都市で核の配置が異なり、1 ルールでは足りない。

### 4.5 広場＝「道路空間」モデル

市場が「道の膨らみ」であるという把握は、紡錘形・三角市場で特に正しい。  
囲郭された方形広場（計画都市・後期）は「街区を空けた」性格が強く、planned 時の区別は妥当。

### 4.6 メトリクスの過信リスク

| メトリクス | 史実との関係 |
|------------|--------------|
| M1 フロンテージ | 形態原則として強い |
| M2–M3 間口・縦横比 | 北西型には合う。地中海型には合わない |
| M5 T字路率 | 定性は良い。帯域は設計目標 |
| M7 凹街区 | 「凸限定禁止」のガードとして正しい |
| M8 直角率 | 建材制約の近似として良いが、100% 史実ではない |
| M11 密度比 | 方向性は正しい。1:0.3:0.05 はオーダー感 |

**読み方の勧告**: 「メトリクス合格＝史実的」ではなく、**「メトリクス不合格＝形態原則の破綻」**。  
必須帯（M1, M8, M9, M10, M12）と目標帯（M4, M5, M11）に分けるとよい。

## 5. 設計原則・禁止事項のレビュー

| 原則／禁止 | 史実的妥当性 |
|------------|--------------|
| 道が先・建物が後 | ◎ |
| すべて接道（建物可敷地） | ◎（中庭・修道院内は例外だが precinct で扱う） |
| ボロノイ禁止 | ◎ |
| ランダムウォーク禁止 | ◎ |
| 凸街区限定禁止 | ◎ |
| 三角地の無理な充填禁止 | ◎ |
| 建物は常に矩形 | ○（強い近似。塔・アプス等は例外） |

ここは計画の最も堅い部分である。
