# 09. 地区（土地利用）・施設・ランドマーク（S7・S9）

## 1. 地区割当（S7）

地区は街区単位で割り当てる。基準は **「広場・門・水・風下」への距離** であり、乱数はタイブレークにのみ使う。

| 地区 | 割当規則 | 密度（敷地建蔽率目安） |
|------|---------|--------------------|
| market（商業核） | 広場・artery に接する街区。壁内中心部 | 70–90% |
| trade（商人） | market の外周。港湾都市では岸壁沿い | 60–80% |
| noble（貴族・富裕） | 城・大聖堂プレシンクト隣接。高所・風上 | 40–60%（庭が広い） |
| craft（職人） | 中間帯。水を使う業種は川沿いに引き寄せる | 50–70% |
| poor（貧困） | 壁際・門周辺の残余街区。低地・風下 | 60–80%（小さく密） |
| religious | プレシンクトとその門前 | プレシンクト内配置 |
| castle | 城プレシンクト | 同上 |
| suburb | 壁外リボン（[06-walls.md](06-walls.md) §3） | 20–40% |
| farmland | 耕地帯 | 0% |

- **密度勾配**: 同一地区内でも広場からの距離で建蔽率・階数を線形に減衰させる（`docs/spec.md` §3）。
- 風向はシードから 1 方位決め、悪臭業種（皮なめし・食肉）と poor を風下・下流に、noble を風上・上流に寄せる。

`docs/bottom-up.md` §3 の施設リストを、以下の配置規則表として実装する。各施設は「敷地の use と建物 kind の上書き」として実現し、専用の生成コードを乱立させない。

| 施設 | 個数（中都市） | 配置規則 |
|------|--------------|---------|
| 大聖堂/主教会 | 1 | S2 プレシンクト（広場隣接、東西軸） |
| 教区教会 | 街区群 300 m 半径ごとに 1 | 各地区の street 交差点近くの敷地を拡張して確保 |
| 市庁舎 | 1 | 広場に面する最良フロンテージ敷地 |
| ギルドホール | 2–5 | artery 沿い、market/trade 地区 |
| 店舗・工房 | 多数 | market/craft の接道敷地（kind = shop/workshop） |
| 宿屋・酒場 | 門ごとに 1 + 広場周辺 2–4 | 門前広場・広場・artery 沿い |
| 井戸・水飲み場 | 交差点 150 m 間隔 | 3 叉路以上の交差点の道路空間内 |
| 市場十字/晒し台 | 1 | 広場の中 |
| 倉庫 | 港/川沿いに 3–8 | harbor 岸壁・橋周辺。大きめ矩形・低層 |
| 水車小屋 | 1–3 | 川の堰候補点（[04-terrain.md](04-terrain.md) §2） |
| 風車 | 0–2 | 壁外の高所セル |
| 修道院 | 0–1 | S2 プレシンクト（市街縁・壁外） |
| 病院・救貧院 | 1 | 門の外の街道沿い |
| 皮なめし工房 | 2–4 | 壁外・川の下流岸（固定規則） |
| 城・砦 | 1 | S2 プレシンクト |

## 3. ランドマークの実体化

- S2 で確保したプレシンクト内に、[08-buildings.md](08-buildings.md) §5 の例外形状で主要建物を置く。
- プレシンクト内部は小道 + 付属建物（回廊、厩、礼拝堂）+ 緑地で構成し、外周は壁または柵で囲む。
- **視覚的階層**: ランドマークの高さは一般建物の 3–8 倍（大聖堂の塔 60–90 m、城キープ 25–40 m、教区教会 15–25 m）。スカイラインの検証は目視チェックリスト（[11-validation.md](11-validation.md) §3）で行う。

## 4. 不変条件

- すべての街区がちょうど 1 つの地区に属する。
- market 地区は広場に接する。poor は広場に接しない。皮なめしは壁内に存在しない。
- 井戸は道路空間内にあり建物と重ならない。
- 施設の個数が上表レンジ内（メトリクスで計測）。
