# 07. 街区抽出・バーゲージ・プロット分割（S6・S8）

本ステージが v1 との差が最も出る場所である。目標は **「通りに直角に並ぶ細長い短冊敷地の連なり」**（バーゲージ・プロット）であり、これはボロノイでは原理的に作れない（`docs/current.md` §1）。

## 1. 街区抽出（S6）

1. `RoadGraph` の面抽出（half-edge 左回り走査、[05-roads.md](05-roads.md) §4）で閉領域を得る。外面は捨てる。
2. 各面から「道路占有ポリゴン」（道幅 + 広場 + 門前広場 + 壁占有帯）を差し引いた残りが街区リング。**このクリップ結果を以降の全ステージが共有する**（v1 のように各所で inset 量を再発明しない）。
3. スリバー処理: 最小幅 < 6 m または面積 < 80 m² の街区は道路空間（または隣接街区）に併合する。
4. 街区の各辺に接道情報（`BlockFrontage`: どの道路・どのランクに面するか）をタグ付けする。行き止まり alley に面する辺も接道である。
5. **凹多角形をそのまま保持する**。凸分割・凸包化は禁止。三日月型・L字型は正しい姿。

想定される街区の統計（organic 地区・壁内）: 面積 300 m²–1.2 ha、奥行 30–90 m（バーゲージ・プロット 1–2 列分）。1.2 ha 超の街区は S5 に差し戻して alley を追加する（パイプライン内の局所ループとして実装可）。

## 2. バーゲージ・プロット分割（S8）

### 2.1 歴史的パラメータ

| 項目 | 値 | 根拠 |
|------|----|------|
| 間口（frontage width） | 4–12 m（中央値 ~6 m、対数正規分布） | 1–2 パーチ。間口課税により狭くなる |
| 奥行 | 20–50 m（街区奥行の半分まで） | 表に店/住居、裏に工房・庭・家畜小屋 |
| 縦横比（奥行/間口） | 中央値 2–5 | 短冊であることの定義 |
| 敷地の向き | 接道辺に**直角** | 短冊は通りから背割り線へ垂直に伸びる |

地区による変調: market 地区は間口がさらに狭く密（4–7 m）、noble は広く（10–20 m、方形に近い）、suburb は粗い（8–15 m）。

> **用語と地域性の注意**: 「バーゲージ (burgage)」はイングランド・アイルランドの法制度上の呼称である。ただし「通りに狭い間口で面し奥へ細長く伸びる短冊状敷地」という**形態**自体は汎ヨーロッパ的で、独語圏の Hofstatt、仏バスティードの区画割にも同型が現れる。本書のアルゴリズム（フロンテージ帯ピーリング）は形態の再現であって英国法制の再現ではないため、地域様式を変える場合もアルゴリズムは共通のまま、間口分布・奥行・縦横比のパラメータセット（将来的な `regionPreset`）だけを差し替える。例: 地中海系の中庭型（間口広め・浅め・中庭必須）を追加する場合は §2.1 の表を地域別に複製して調整する。

### 2.2 アルゴリズム: フロンテージ帯のピーリング

現行 `lots.ts` の peel 方式は方向性が正しいので、これを以下の仕様に整えて再実装する:

```
1. 街区の接道辺を商業価値順にソート（artery/広場 > street > alley）
2. 価値の高い接道辺から順に:
   a. その辺に平行な帯（strip）を奥行 d = 20–50 m で切り出す
      （帯の奥行は敷地列 1 列分。街区中心を越えない）
   b. 帯を接道辺に垂直な線で間口ごとにスライス
      間口は対数正規分布からサンプル。角地は最後に残った端数を吸収
   c. 各スライスに frontage（道路 ID・接道スパン）を記録
3. 向かい合う接道辺からも同様にピール（背中合わせの 2 列 = 街区奥行 50–90 m の標準形）
4. 残った中央部（backland）:
   - 面積 < 300 m² → 隣接敷地の庭として併合
   - それ以上 → use = garden / orchard / yard の袋地敷地とする。建物は建てない
```

### 2.3 不変条件（このステージの成否判定）

- **フロンテージ保証**: 建物可（use が garden/yard 以外）の敷地の ≥ 98% が接道スパンを持つ。
- 縦横比の中央値 ∈ [2, 5]、間口の P10 ≥ 3 m・P90 ≤ 15 m（地区変調込みの全体分布）。
- 敷地は所属街区の内部に完全に収まり、相互に重ならない（面積誤差 ε 以内）。
- 分割後の合計面積 ≈ 街区面積（欠損 < 5%）。

### 2.4 特殊ケース

- **三角形街区・鋭角コーナー**: 最長の接道辺からのみピールする。鋭角部分（内角 < 35°）は敷地にせず空地のまま残す。**無理に埋めない**（`docs/algorithm.md` §3.3）。
- **凹街区**: 凹頂点で帯が折れる場合は、接道辺ごとに独立した帯として処理してよい（帯同士の重複は後勝ちでクリップ）。
- **湾曲した接道辺**: 辺列を曲率で分割し、ほぼ直線とみなせる区間（弦との偏差 < 2 m）ごとにピールする。スライス線は各区間の弦に垂直。
- **計画都市地区**: 間口をほぼ一定（6 m ± 0.5 m）にし、整然とした列を作る。アルゴリズムは同じでパラメータのみ変える。
- **プレシンクト**: 分割対象外。敷地 1 個（use = precinct）としてそのまま通す。

## 3. やってはいけないこと

- ボロノイ・重心分割・再帰的二分割（v1 方式）による敷地分割。二分割は内部に袋地を量産する。
- 接道方向と無関係な軸（グローバル X/Y 軸）でのスライス。
- 袋地への建物許可。
- 「埋め残しゼロ」を目指すこと。隙間・空地は中世都市の実態であり、メトリクスも充填率 100% を要求しない。
