# 06. 城壁・城門・城壁外（S4・S6b）

城壁は中世都市の最大の形態決定要因である。「壁の内は密、外は疎」という密度の断絶が絵の説得力を作る。

## 1. 壁線の決定（S4）

壁は幹線（S3）確定後・街路（S5）より前に引く。歴史的にも「既にある市街と街道を囲うように壁を築き、その内側が後から密集する」順序である。

1. **囲うべき範囲の推定**: 広場アンカーを中心に、幹線に沿って「市街化予定域」を求める。具体的には、幹線上を広場から `r = 都市半径` だけ辿った到達点集合 + プレシンクトの外周点をとる。
2. **壁線**: 上記点集合の凸包を取り、12–20 頂点に単純化 → 頂点を半径方向に ±10% 揺らす（`wallShape: "organic"`）か正多角形に整える（`"polygon"`）。
3. **地形適応**:
   - 川沿い都市では壁を川岸まで引き、川を天然の堀として使う（川側の壁は岸に平行）。
   - 急斜面・崖は壁線として優先的に利用する（hillTop）。
   - 壁は水域を横断しない。川が市街を貫く場合は水門（2 箇所）を設け、壁はそこで川を跨ぐ。水域との交差が3回以上になる場合（川の蛇行部等）は、はみ出た蛇行部を壁内に含めるか壁外に切り捨てるよう壁線をスナップ・調整し、交差を最大2回（入・出）に制限する。
4. **門**: 壁と幹線の交点に置く。**交点以外に門を作らない・門以外で幹線が壁を跨がない**（跨ぐ幹線が多すぎる場合は S3 の再利用ボーナスを強めて幹線を束ねる）。門数が `numGates` に合わないときは壁線を微調整して交差数を合わせる。
5. **塔**: 壁に沿って 40–70 m 間隔（弓の射程の重複を意識した歴史的間隔）。形は正方形または 8 角形以上の「ほぼ丸」（`docs/algorithm.md` §3.2）。門の両脇には必ず一対の塔。
6. **堀**（オプション）: 壁の外側 5–10 m を幅 8–15 m で周回。川と接続して良い。

## 2. 壁の占有空間

- 壁体の厚み 2–3 m + 内側の壁内周回路（[05-roads.md](05-roads.md) §3.2）+ 外側の空地（堀まで）を「壁占有帯」とし、街区・敷地・建物から除外する。
- 門の内側には小さな門前広場（10–20 m 四方の道路空間の膨らみ）を作る。市場副次核・宿屋の立地になる。

## 3. 城壁外（S6b）

壁外を「何もない空間」にしない。史実の壁外は以下で構成される:

1. **リボン状郊外（faubourg）**: 各門から続く街道の両側 100–300 m に、壁内より粗い敷地列（間口 8–15 m）と建物を並べる。密度は門から離れるほど指数的に減衰。
2. **耕地（Open-field system）**: 郊外の外側に、歴史的な開放耕地制の構造を再現した農地を配置する。壁外の広大な空間を約150〜250m四方の大きなブロック（Furlong/耕区）に分割し、各ブロックごとに固有の耕作角度を持たせる。その内部を幅10〜20mの平行な条地（Strips / Selions）にスライスして生成する。これにより、隣り合う耕区で条地の向きが直交したり斜めになったりする、中世特有の美しいパッチワーク（キルト）状の田園風景を描画する。
3. **壁外施設**: 修道院、絞首台の丘、風車（高所）、水車（川の堰）、皮なめし工房（川の下流側 — 悪臭・水質汚染のため壁外下流が定位置）、癩病院（街道沿いの遠隔地）。
4. **壁外空地帯**: 壁の外周 30–50 m は防衛上の射界確保のため建物を置かない（耕地・牧草地は可）。

## 4. 不変条件

- 壁リングは単純閉曲線（自己交差なし）で、広場・大聖堂・全 artery 街区を内包する。城はアーキタイプにより壁線上（縁）に置かれてよい。
- 門は必ず `numGates` 個、すべて artery/highway 上。
- 壁内の建物敷地密度 : 壁外近傍 : 耕地帯 = おおよそ 1 : 0.3 : 0.05（[11-validation.md](11-validation.md) で計測）。
