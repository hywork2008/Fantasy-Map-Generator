# 塩の値を税の無い値段にする

作成: 2026-10-31。根拠の計測: [urban-money-shortfall-20261031.md](../analytics/urban-money-shortfall-20261031.md)§6。

## 1. 問題

- `Salt.value`は0.45（60 kgの袋）で、1 kgあたり穀物の3.5倍である。これは近世フランスの塩税の重い地方（grandes gabelles）の値段に当たる。
- 税の無い値段と比べると、約7倍高い。
  - 英国1340年: 0.35〜0.6倍。
  - フランスの税の無い地方: 0.15〜0.25倍。
  - モデル自身の製塩所の作る費用: 約0.5倍。
- 塩税は`saltPolicy.taxRate`（既定0）として別にある。基の値にも税が入っていると、税を2回数えることになる。
- 卸値の下限が値×0.5（0.225）なので、製塩所に払う額の約86%（年約22万）が持ち主の国の利益になる。これは家計の収入の約20%にあたる。
- この利益が、人数と家畜に応じた見えない税として働いている。農村の大きい市場から、首都と製塩所のある市場へお金を移し、町を貧しくしている（同記録§1〜§4）。

## 2. 方針

### 2.1 値

| | 今 | 新しい値 |
| --- | ---: | ---: |
| `Salt.value`（60 kg） | 0.45 | **0.08** |
| 1 kgあたり（穀物 = 1） | 3.5 | 0.62 |

- 0.08は、製塩所の煮詰めの費用（物価1で約0.064、`unitCost`×1.05で約0.067）に、少しの利幅を足した値である。
- 0.08は、史料の税の無い値段（0.15〜0.6倍）の上の端よりやや高い。モデルの費用を割らないことを優先した。
- 穀物の値段が上がると賃金も上がるので、作る費用も上がる。その分は、卸値の`unitCost×1.05`の項が引き受ける。

### 2.2 卸値と小売りの値段の式は変えない

- 卸値は`max(値×0.5, 産地の値段×0.8, unitCost×1.05)`のままとする。値×0.5は0.04で費用より下になるので、下限は作る費用が決める。製塩所が費用を割って売ることは無い。
- 小売りの値段の基準は`max(値×物価, saltLandedUnitCost)`のままとする（`priceSalt`）。遠い市場では、運び賃の分だけ高くなる。
- これで、塩の値段は費用と運び賃で決まるようになる。「普通の値段」（塩の優先順位の2）は、この値段を指すことにする。

### 2.3 塩税

- 重い塩税は、国の政策（`saltPolicy.taxRate`、`collectSaltTax`）だけで表す。この変更では、国の政策の既定（0、open）は変えない。
- 国の金庫は、塩の利益（年約22万）を失う。給与・軍・建設がどれだけ減るか、国が塩税を使うかどうかを、V2で測る。
- 減りが大きすぎる場合は、既定の塩税を設けるかを別の段階として決める。値に税を戻すことはしない。

### 2.4 古い保存

- `WEIGHT_REPRICING`のSaltを`[3, 0.08]`に変える。さらに、0.45のままの保存を0.08にする移行を加える。
- 移行は、利用者がGoods editorで変えた値を残すため、値が0.45のままの時だけ行う。
- 市場の塩の値段は、`priceSalt`が毎月基準に向けて動かすので、移さない。

## 3. 影響を見る所

| 所 | 内容 |
| --- | --- |
| 農村・町の塩の支払い | 約5〜6分の1になる。家畜の塩の上限（財布の5%）と掛けの余地が、同じお金で多くの袋を買える |
| 製塩所の持ち主（国） | 売り上げは作る費用＋運び賃程度になる。持ち主の現金が足りないと生産できない（`paySaltInputs`）ので、国の金庫が尽きないかを見る |
| 塩の掛け（`saltPayables`、農村の掛け） | 額が小さくなり、返しやすくなる |
| 保存食・塩漬け（`winterSlaughter`の`saltPricePerKg`、Preserved foodのレシピ） | 塩の費用が下がり、利幅が広がる |
| 塩の交易の運び賃 | 運び賃（`saltFreightPerBag`）は変わらないので、値段に占める割合が大きくなる。遠くの市場の塩の値段の差が広がる |

## 4. 段階

| 段階 | 内容 | 完了条件 |
| --- | --- | --- |
| V1 | 値、`WEIGHT_REPRICING`、0.45からの移行、単体テストの期待値 | 関連の単体テストが通る |
| V2 | 固定入力・平和モードで84か月。基準（V1の前）との比較 | 下の確認の表 |

V2で確かめること:

1. 塩の優先順位
   - 製塩所の生産が人と家畜の需要以上ある。
   - 塩の値段が作る費用と運び賃の近くにある。
   - 掛けが返されている。
2. 家畜の塩の不足が減る。
3. 市場14・15・16・21の町の家計の財布、町が買う肉の割合、budgetGap。
4. 国の金庫と給与、国の支出の減り方。
5. 都市の主食の充足が悪くならない。

## 5. 未決の事項

- 値の0.08は、作る費用から決めた仮値である。史料の英国の値段（Bridburyの孫引き）は、原典で確かめていない。
- 国の財政が塩の利益に頼っていた分を、どう埋めるか（V2の結果による）。
