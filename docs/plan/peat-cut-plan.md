# 泥炭を掘る量を1年の平均で決める（peat-cut-plan）

## 1. 問題

[peat-growth-20261113.md](../analytics/peat-growth-20261113.md)で、木材と泥炭を値段で分けた後（[fuel-price-share.md](fuel-price-share.md)）、泥炭を採る量が冬の後に使った量の約2倍に跳ねた。peatSupply.tsは「使った量の平滑（1/6）× 6か月 − 在庫」まで掘る。平滑が短いので、冬の数か月の使う量を半年分の目安にし、春に掘りすぎて在庫が積み上がり、値段が下がって泥炭の分がさらに増えた。

## 2. 史料

- 泥炭は春（4〜5月）に掘り、夏に乾かし、秋に運び込んで冬に燃やした。家は1年分をまとめて掘った（アイルランド・スコットランドの turbary、ノーフォークの泥炭の掘り跡）。
- 掘る量は、その冬に燃やした量ではなく、1年に燃やす量の見込みで決まった。

## 3. 設計

- 設定`peatCutPlan`
  - `yearlyAverage`（既定）：使った量を1年の平滑（1/12）で数え、その6か月分まで在庫にする。
  - `smoothedDraw`：今までの決まり。使った量の平滑（1/6）の6か月分。
- どちらも、煮詰めの塩田の分かっている必要（`knownDraw`）は今までどおり下限にする。
- 1年の平滑は`peatSupply.yearlyDraw`に保つ。保存した地図に無い時は、今の`smoothedDraw`から始める。
- 沼の採れる量の上限（`potential`）と、農家の自分の炉の分は変えない。

## 4. 未確定事項

- 掘る月を春に限ること（季節の掘り方）は入れていない。1年の平滑で、冬の山に追う動きを弱めるだけにした。
- 6か月分の在庫の目安は、今までどおり。

## 5. 結果

[peat-cut-plan-20261113.md](../analytics/peat-cut-plan-20261113.md)（地図2102・2103、36か月）。

- 3年目の初めの跳ね方は約2.4倍から約1.4倍になり、採った量は使った量に近づいた。36か月目の在庫は約半分。
- 3年目の泥炭は約2割減ったが、年ごとに増えることは変わらない。沼の採れる量の上限（暖房の熱の約3割）へ向かうと考えられ、長い実行で確かめる。
- 塩の量とお金の持ち手は1%以内の差。
