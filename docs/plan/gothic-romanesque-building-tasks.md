# BV向けゴシック建築・ロマネスク建築の追加タスク

作成日: 2026-10-21

## 目的と対象

BV（Building Viewer）に追加する、実在の著名建築を原型とした3Dモデルの候補。
ゴシック建築10件、ロマネスク建築10件を挙げる。番号は管理用であり、知名度の順位ではない。
各項目の特徴はモデル制作の着眼点で、正確な寸法・平面・建設段階は着手時に追加調査する。
年代は主な建設・改築の時期の目安であり、創建年や全体の完成年とは区別する。

BVには**ウィンザー城の聖ジョージ礼拝堂**（English Perpendicular Gothic）が既に登録されているため、新規追加には数えない。
既存の汎用教区教会・修道院モデルとは別に、実在建築ごとの平面・立面・輪郭を持つモデルを追加する。
本書では候補を保存する。CEへの自動配置は各モデルの追加とは別タスクとする。

## ゴシック建築

- [x] **G01. ノートルダム大聖堂（Notre-Dame de Paris）** — フランス／パリ。主に12〜14世紀。フランス・ゴシック。
  - 再現の重点: 西正面の双塔と三つの入口、バラ窓、身廊と交差廊、後陣を囲むフライング・バットレス。
  - 注意: 尖塔・彫像には後世の復元が含まれる。中世の姿と現存外観のどちらを再現するか明記する。
  - 参考: [大聖堂公式・外部建築](https://www.notredamedeparis.fr/en/understand/architecture/exterior-architecture/)、[西正面](https://www.notredamedeparis.fr/en/understand/architecture/the-western-facade/)。
- [x] **G02. シャルトル大聖堂（Chartres Cathedral）** — フランス／シャルトル。主に12〜13世紀。フランス盛期ゴシック。
  - 再現の重点: 形の異なる左右の尖塔、三入口の西正面、交差廊、周歩廊と放射状礼拝堂。
  - 注意: 西正面の旧部分と、火災後の本体再建、後世の北尖塔を同一時期の建築として扱わない。
  - 参考: [UNESCO](https://whc.unesco.org/en/list/81/)。
- [ ] **G03. アミアン大聖堂（Amiens Cathedral）** — フランス／アミアン。主に13世紀。フランス盛期ゴシック。
  - 再現の重点: 高い身廊、大きな窓、三入口の彫刻的な西正面、後陣の控壁群。
  - 参考: [UNESCO](https://whc.unesco.org/en/list/162/)。
- [ ] **G04. ランス大聖堂（Reims Cathedral）** — フランス／ランス。主に13世紀以降。フランス盛期ゴシック。
  - 再現の重点: 双塔、深い入口と尖頭切妻、バラ窓、小尖塔・彫像列による縦方向の輪郭。
  - 注意: 世界遺産を構成する旧サン＝レミ修道院・トー宮殿は、このモデルの対象に含めない。
  - 参考: [UNESCO](https://whc.unesco.org/en/list/601/)。
- [ ] **G05. ケルン大聖堂（Cologne Cathedral）** — ドイツ／ケルン。1248年着工、1880年完成。盛期ゴシックの構想を継承。
  - 再現の重点: 高い透かし彫りの双尖塔、五廊式の本体、交差廊、後陣のフライング・バットレス。
  - 注意: 現存する完成形には19世紀の施工部分が大きく含まれる。中世都市向けには建設途上の状態を別途検討する。
  - 参考: [UNESCO](https://whc.unesco.org/en/list/292/)。
- [ ] **G06. サント・シャペル（Sainte-Chapelle）** — フランス／パリ。13世紀、1248年献堂。レイヨナン・ゴシック。
  - 再現の重点: 上下二層の礼拝堂、上堂の大きなステンドグラス窓、細い控壁、急勾配屋根。
  - 注意: 西のバラ窓には15世紀のフランボワイヤン様式が見られる。尖塔も含めて再現年代を確認する。
  - 参考: [建物公式・歴史](https://www.sainte-chapelle.fr/en/discover/history-of-the-sainte-chapelle)、[バラ窓](https://www.sainte-chapelle.fr/en/discover/the-rose-of-the-apocalypse)。
- [ ] **G07. ソールズベリー大聖堂（Salisbury Cathedral）** — イギリス／ソールズベリー。主に13世紀、塔・尖塔は14世紀。イギリス・ゴシック。
  - 再現の重点: 長い低層の本体と高い中央尖塔、二組の交差廊、東端の礼拝堂、回廊。
  - 注意: 本体と塔・尖塔の建設時期を区別する。
  - 参考: [大聖堂公式・建設史](https://www.salisburycathedral.org.uk/discover/history/the-cathedral-through-the-years/)。
- [ ] **G08. ミラノ大聖堂（Duomo di Milano）** — イタリア／ミラノ。1386年着工、近現代まで施工。イタリアにおける国際ゴシック。
  - 再現の重点: 幅広い五廊式の本体、淡色の大理石、多数の小尖塔、屋上テラスと控壁。
  - 注意: 現在の正面・主尖塔・多数の小尖塔には近世以降の施工が含まれる。現存外観をそのまま中世の完成形にしない。
  - 参考: [大聖堂公式・建設史](https://www.duomomilano.it/en/art-and-culture/the-cathedral/)、[屋上と尖塔](https://www.duomomilano.it/en/art-and-culture/the-terraces/)。
- [ ] **G09. ブルゴス大聖堂（Burgos Cathedral）** — スペイン／ブルゴス。主に13〜16世紀。スペイン・ゴシック。
  - 再現の重点: 西正面の双尖塔、装飾的な交差部の塔、ラテン十字形の本体、付属礼拝堂。
  - 注意: 双尖塔や現在の交差部の塔は初期の本体より後の段階。完成形の対象年代を指定する。
  - 参考: [UNESCO](https://whc.unesco.org/en/list/316/)。
- [ ] **G10. ブルッヘ市庁舎（Bruges City Hall / Stadhuis）** — ベルギー／ブルッヘ。1376〜1421年。世俗ゴシック。
  - 再現の重点: 縦長の窓が並ぶ正面、装飾された壁面、隅の小塔、急勾配の屋根。
  - 注意: 教会以外の都市建築の候補。後世の彫像・修復部分を調査し、隣接する別建物とは分ける。
  - 参考: [ブルッヘ公式観光・市庁舎](https://www.visitbruges.be/en/things-to-do/culture-and-heritage/stadhuis-city-hall)。

## ロマネスク建築

- [ ] **R01. シュパイアー大聖堂（Speyer Cathedral）** — ドイツ／シュパイアー。主に11世紀。ラインラント・ロマネスク。
  - 再現の重点: 四本の塔、東西の大きな建築量塊、半円後陣、小アーケード、重厚な石造壁。
  - 注意: 現存の西構えは19世紀のもの。中世の復元と現存外観を区別する。
  - 参考: [UNESCO](https://whc.unesco.org/en/list/168/)。
- [ ] **R02. ダラム大聖堂（Durham Cathedral）** — イギリス／ダラム。主に11世紀末〜12世紀。ノルマン・ロマネスク。
  - 再現の重点: 大きな身廊・交差廊、太い柱、半円アーチ、初期のリブ・ヴォールト。
  - 注意: リブ・ヴォールトがあっても全体をゴシックに分類しない。現存の中央塔上部や東端などの後世部分は別途調査する。
  - 参考: [UNESCO](https://whc.unesco.org/en/list/370/)。
- [ ] **R03. ピサ大聖堂（Pisa Cathedral）** — イタリア／ピサ。主に11〜12世紀。ピサ・ロマネスク。
  - 再現の重点: 列柱廊を重ねた正面、多廊式の本体、交差部のドーム、大理石の色分け。
  - 注意: 斜塔・洗礼堂・墓所は独立した建物。大聖堂のモデルと混同せず、必要なら追加モデルとして扱う。
  - 参考: [UNESCO・大聖堂広場](https://whc.unesco.org/en/list/395/)。
- [ ] **R04. モデナ大聖堂（Modena Cathedral）** — イタリア／モデナ。1099年着工、主に12世紀。北イタリア・ロマネスク。
  - 再現の重点: 切妻正面、彫刻付き入口と張り出す玄関、小アーケード、三つの後陣。
  - 注意: バラ窓などの後補部分を区別する。隣接するギルランディーナの塔は別モデルとして扱う。
  - 参考: [UNESCO](https://whc.unesco.org/en/list/827/)。
- [ ] **R05. ヴェズレーのサント＝マドレーヌ聖堂（Vézelay Basilica）** — フランス／ヴェズレー。主に12世紀。ブルゴーニュ・ロマネスク。
  - 再現の重点: 長い身廊とナルテックス、半円アーチ、明暗の石材で縞状に見えるアーチ、入口の彫刻。
  - 注意: 内陣などにゴシック部分がある。ロマネスクの身廊と後世の改築を区別する。
  - 参考: [UNESCO](https://whc.unesco.org/en/list/84/)。
- [ ] **R06. サン＝セルナン聖堂（Basilica of Saint-Sernin）** — フランス／トゥールーズ。主に11〜12世紀。巡礼教会型ロマネスク。
  - 再現の重点: レンガと石材、長い身廊、広い交差廊、周歩廊と放射状礼拝堂、八角形の鐘塔。
  - 注意: 鐘塔上部などに後世の施工が含まれる。塔全体を11世紀の形としない。
  - 参考: [トゥールーズ公式観光](https://www.toulouse-tourisme.com/en/activite/saint-sernin-basilica/)。
- [ ] **R07. コンクのサント＝フォワ修道院教会（Abbey Church of Sainte-Foy）** — フランス／コンク。主に11〜12世紀。南フランスのロマネスク。
  - 再現の重点: 短い身廊と幅広い交差廊、後陣と小礼拝堂、入口の「最後の審判」のタンパン。
  - 注意: 斜面に収まる凝縮した平面を重視する。現存正面の塔上部は修復史を確認する。
  - 参考: [コンク公式観光・建築解説](https://www.tourisme-conques.fr/fr/conques/www.tourisme-conques.fr/fr/conques/abbatiale)。
- [ ] **R08. サンティアゴ・デ・コンポステーラ大聖堂（Santiago de Compostela Cathedral）** — スペイン／サンティアゴ・デ・コンポステーラ。主に11〜12世紀、後世に大規模改築。巡礼教会型ロマネスク。
  - 再現の重点: ロマネスクの本体平面、交差廊、周歩廊、プラテリーアス門、「栄光の門」。
  - 注意: 著名な現存西正面はバロック。ロマネスクとして作る場合は中世復元の範囲・根拠を明示し、不明部分を断定しない。
  - 参考: [大聖堂公式・建築](https://catedraldesantiago.es/en/cathedral/)、[栄光の門と西正面の改変](https://catedraldesantiago.es/en/portico-de-la-gloria/)。
- [ ] **R09. マリア・ラーハ修道院教会（Maria Laach Abbey Church）** — ドイツ／ラーハ湖畔。主に11世紀末〜13世紀。ラインラント・ロマネスク。
  - 再現の重点: 東西の内陣、六本の塔、半円後陣、西側の「パラディース」と呼ばれる前庭。
  - 注意: 教会と前庭を対象とし、修道院の生活棟全体は別途範囲を決める。
  - 参考: [修道院公式・教会と修道院](https://www.maria-laach.de/unser-kloster/kirche-und-kloster/)。
- [ ] **R10. サンタンブロージョ聖堂（Basilica of Sant'Ambrogio）** — イタリア／ミラノ。主に11〜12世紀の改築。ロンバルディア・ロマネスク。
  - 再現の重点: 赤レンガ、四辺を柱廊に囲まれた前庭、二層のアーケード正面、非対称の二本の鐘塔。
  - 注意: 古代の創建とロマネスク期の姿を区別する。鐘塔同士の年代差と修復部分も確認する。
  - 参考: [聖堂公式・建築群](https://www.basilicasantambrogio.it/en/complesso-monumentale)、[歴史](https://www.basilicasantambrogio.it/en/storia)。

## 実装記録

- G01: `src/buildings/landmarks/notreDame.ts`。復元尖塔を含む現存外観の簡略モデル。BVの `Gothic landmarks` に登録。正面寄り3D表示・上面図・南側立面図、接地・塔高・資源解放のテストを確認。
- G02: `src/buildings/landmarks/chartres.ts`。左右で異なる尖塔・交差廊の玄関廊・放射状礼拝堂を備える現存外観の簡略モデル。BV登録、3D・上面図・南側立面図、接地・外形・特徴部位・資源解放を確認。

## 着手順の提案

最初はG01（ノートルダム）、G06（サント・シャペル）、R01（シュパイアー）、R10（サンタンブロージョ）を候補とする。
大聖堂・小規模な宮廷礼拝堂・重厚な塔付き教会・前庭付き教会という輪郭の違いを比較できるため。
次にG07（イギリス）、G09（スペイン）、G10（市庁舎）、R03（ピサ）で地域・用途の幅を広げる。
これは制作上の提案であり、史料に基づく知名度の順位ではない。

## 各タスクの完了条件

1. 再現する年代・状態（現存外観／特定年代の復元）と、対象建物・付属部分の範囲を記録する。
2. 平面、主要寸法、立面の出典を確認し、推定寸法と省略部分を明記する。写真のみから測量済みの精度をうたわない。
3. 専用3Dモデルを作成し、BVの一覧から選択できる状態にする。
4. BVで正面・側面・背面・上面、実寸スケール、接地、特徴的な塔・屋根・控壁の形状を確認する。
5. 出典・再現年代・省略範囲をBVから確認できるようにし、完了した項目に実装先を追記する。

既存の[欧州向け汎用モデル追加タスク](medieval-european-model-tasks.md)と併用する。
BVの登録箇所は[main.ts](../../src/building-viewer/main.ts)、既存のゴシック礼拝堂は[stGeorgesChapel.ts](../../src/buildings/chapels/stGeorgesChapel.ts)を参照する。
