# 飲み物の値段による配分

## 1. 背景

[vintage-casks-20261110.md](../analytics/vintage-casks-20261110.md)で、二つのことが起きた。

- 樽は作り過ぎて、値段が約0.06から0.03〜0.04に下がった。それでも樽職人は作り続けた。
- 蜂蜜酒は12〜15%しか満たされなかった。それでも値段で作り手が増えることも、ほかの飲み物へ移ることも無かった。

町の飲み物の需要は、1人年何Lという量で決まる。飲み物の間の配分も、値段ではなく「ワインの土地の度合い」で決まる。値段は在庫に応じて動くが、その値段が需要と作る量に戻る道がほとんど無い。このため、ある品を直すと別の品が崩れ、また量の決まりで直すことが続いた（[raisin-trade.md](raisin-trade.md)、[vintage-labour.md](vintage-labour.md)、[vintage-casks.md](vintage-casks.md)）。

この設計書は、まず飲み物について、配分を値段で決める仕組みに置き換える方針を示す。作る量の側（樽職人などの床）は§6で扱う。

## 2. 今の決まり

### 2.1 需要

町と市場の家の飲み物の月の需要は`getMonthlyHouseholdDemand`（[foodProcessingLedger.ts](../../src/extensions/economy/generators/foodProcessingLedger.ts)）で決まる。

| 飲み物 | 誰の | 1人年 | 配分の決まり |
| --- | --- | --- | --- |
| エール | 町の大人 | 48〜約300 L（`ALE_TARGETS`） | ワインの土地の度合いと森の割合で48 Lへ寄せる（`getTownAleLitersPerAdultYear`）。水の危険で最大50%増やす |
| ワイン | 市場の全ての大人 | 1 L＋（8 − 1 L）× 度合い（`WINE_TARGETS`） | 度合い |
| 蜂蜜酒 | 町の大人 | 5 L × (1 − 度合い)（`fmg-town-mead-liters`） | 度合い |
| シードル・ペリー | 市場の全ての大人 | 6 L・3 L（`ORCHARD_TARGETS`） | なし |

- 「ワインの土地の度合い」（`getWineCountryShare`）は、過去12か月に作ったワインを、ワインの土地の1年の需要で割ったものである。値段は入っていない。
- どの飲み物の需要にも、値段の弾力はかかっていない。値段の弾力の仕組み（`applyPriceElasticity`、[priceElasticity.ts](../../src/extensions/economy/generators/priceElasticity.ts)）はあるが、使われているのは`calculateGoodDemand`を通る品だけである。家の需要で値段を決める品（`isPricedByHouseholdDemand`、`isOrchardDrink`）は、これを通らない。

### 2.2 買うこと

`drawHouseholdDemand`は、需要を市場の在庫から引き、家の財布で払える分だけ取る。

- 足りない分は、そのまま「満たされない需要」になる。ほかの飲み物へは移らない。
- 移る道は、白い石鹸が無い分を柔らかい石鹸で補う一つだけである（`settleFoodProcessingHouseholds`）。

### 2.3 値段

家の需要で値段を決める品の値段は、材料の費用に、利幅 × 需要と在庫の比（0.25〜3倍）を足したものである（`marketPricing`、[markets-generator.ts](../../src/extensions/economy/generators/markets-generator.ts)）。

- 値段は在庫と需要の比で動く。在庫が積み上がると下がり、品薄なら上がる。
- しかしその値段は、§2.1の需要の量を変えない。

### 2.4 作る量

- 葡萄・林檎・梨を搾る量は、需要の1年分から在庫を引いた分（`getFoodProcessingProductionHeadroom`）と、セルの労働の上限で決まる。
- エールは、家の需要の上限の中で、最初に作る順番を持つ（`dailyBeverageGoods`、[production-generator.ts](../../src/extensions/economy/generators/production-generator.ts)）。
- 樽は、家の飲み物の需要から決まる床（`floorFromHouseholdDrinks`、`getMonthlyHouseholdContainerDemand`）まで、利幅に関わらず作る。
- 蜂蜜酒は、利幅の順に並べる2段目で作る。

## 3. 史料

- 中世のイングランドでは、エールの値段は穀物の値段に合わせて決められた（Assize of Bread and Ale、1266年頃、[Wikipedia](https://en.wikipedia.org/wiki/Assize_of_Bread_and_Ale)）。エールは毎日の飲み物で、値段が上がっても飲む量は大きくは変わらなかったと見られる。
- 町の人はエールを買い、農村の家は自分の穀物で造った（Bennett 1996、`ALE_TARGETS`の注）。
- ワインの土地の町はエールをあまり造らず、ワインを飲んだ（[grape-season-and-wine-country.md](grape-season-and-wine-country.md)）。北の土地のワインは輸入品で、値が高く、多くの人には祝いの飲み物だった。
- 飲み物の間で、値段に応じてどれだけ移ったかを数で示した史料は、まだ調べていない（§7の1）。

## 4. 決める仕組み（案）

### 4.1 総量と配分に分ける

町の大人の飲み物を、「液体の総量」と「その中の配分」に分ける。

1. **総量**：1人年の飲み物の量。今のエール・ワイン・蜂蜜酒・シードル・ペリーの量の和を、土地の型ごとの基準とする。総量にかかる値段の弾力は小さくする（毎日の飲み物なので、−0.1程度）。
2. **配分**：総量を飲み物ごとに分ける。分け方は、各飲み物の「好み」と、町の値段で決める（多項ロジット）。

   ```
   share_d = w_d × (p_d / p̄_d)^(−σ) / Σ_k w_k × (p_k / p̄_k)^(−σ)
   ```

   - `w_d`：その土地の好み。今の量の決まりから求める（ワインの土地ではワインが重く、森の無い牧畜の土地ではエールが軽い）。
   - `p_d`：前の月の町の値段（1月遅れ、`applyPriceElasticity`と同じ）。`p̄_d`はその飲み物の基準の値（`good.value` × 物価の水準）。
   - `σ`：代わりやすさ（値段の差に対する移りやすさ）。初めは1〜2の間で試す。
3. **在庫の無い飲み物**：市場に在庫が無い飲み物の取り分は、在庫のある飲み物へ移す（同じ月の中で一度だけ）。今の石鹸の補いと同じ形である。

### 4.2 ワインの土地の度合い

度合いは、好み`w_d`の側に残す。ワインを作る土地では、ワインが好まれ、ほかの飲み物の好みは小さくなる。

- 今は、度合いがそのまま需要の量を決めている。案では、度合いは好みを変えるだけで、実際に飲む量は値段で決まる。ワインが高ければ、ワインの土地でもエールが飲まれる。

### 4.3 作る量への戻り

- 搾る量の上限（`getFoodProcessingProductionHeadroom`）と、エールの上限は、§4.1の配分後の需要を使う。配分は前の月の値段で決まるので、同じ月の中で循環しない。
- 蜂蜜酒は、需要が値段で増え、利幅も値段で上がるので、2段目の利幅の順で作られやすくなる。

### 4.4 Simulation settings

- 代わりやすさ`σ`と、総量の値段の弾力を、Simulation settingsに既定値つきで置く。
- 「配分の決め方」として、今の量の決まり（度合いによる）と、値段による配分を選べるようにする。測り比べた後、今の決まりを残すかを決める。

## 5. 置き換えるものと残すもの

| | 扱い |
| --- | --- |
| `getTownAleLitersPerAdultYear`の度合いによる寄せ | 好み`w_Beer`の計算に移す |
| 蜂蜜酒の × (1 − 度合い) | 好み`w_Mead`の計算に移す |
| ワインの 1 L ＋ 7 L × 度合い | 好み`w_Wine`の計算に移す |
| 水の危険によるエールの増し | 残す（エールの好みを上げる） |
| 森の割合によるエールの寄せ | 好み`w_Beer`の計算に移す |
| 農村の飲み物（セルの蓄えから） | 変えない |
| 干し葡萄・牛乳・チーズ | 変えない（飲み物の後で、同じ形にするか決める） |
| ワインの土地の度合いの定義（`getWineCountryShare`） | 残す |

## 6. 作る量の床（別の段階）

樽職人の床（`floorFromHouseholdDrinks`）は、値段が下がっても減らない。飲み物の配分とは別の問題なので、この設計書では方針だけ記す。

- 床を、需要の量ではなく、在庫の月数（需要の何か月分を超えたら作らない）で止める。
- または、床の分も利幅が負なら作らない。
- [vintage-casks.md](vintage-casks.md)の取っておく空の樽の量の誤り（市場の在庫のワイン・シードルの樽を引いていない）は、これとは別に直す。

## 7. 計測（予定）

- 北緯30°の地図2枚（2102・2103）、24か月、2年目。今の決まりと、値段による配分を比べる。
- 見るもの：
  - 飲み物ごとの飲んだ量・足りない量・値段。
  - 町の大人1人の総量。
  - 蜂蜜酒の作り手。
  - ワインの土地の度合い。
- 揃えるもの：σが小さい時に、今の量の決まりとほぼ同じ配分になること（今の決まりを再現できることを確かめる）。

## 8. 未確定事項

1. 飲み物の間で、値段に応じてどれだけ移ったかの史料（σの根拠）。
2. 総量の基準。今の量の和は、土地の型ごとに大きく違う（エールの土地で約300 L、ワインの土地で約60 L）。
3. 好み`w_d`を、今の量の決まりから求めるか、土地の型の表として持つか。
4. 市場の全ての大人が飲むワイン・シードルと、町の大人だけが飲むエール・蜂蜜酒の、人の範囲の違いをどう揃えるか。
5. 樽職人などの床（§6）を、値段で止めるか、在庫の月数で止めるか。
