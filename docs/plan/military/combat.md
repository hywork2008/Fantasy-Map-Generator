# 戦闘可能な距離

戦闘は同一セルのみ

## 修正内容

Advance Time 時の背景戦闘（LocalSkirmish）が、距離半径内の敵とも戦ってしまう問題を直しました。

### 変更点

src/extensions/nobility/generators/localSkirmish.ts

• 以前: 陸軍は SKIRMISH_CONTACT_RADIUS（50 map units）以内、艦隊は航路上 NAVAL_SKIRMISH_CONTACT_RADIUS（100）以内なら交戦
• 現在: 同じ packed cell（regA.cell === regB.cell）にいる場合のみ交戦

隣接セルや座標が近いだけでは戦闘しません。敵と同じセルに到達してから背景戦闘が起きます。

### テスト

localSkirmish.test.ts を同じセル条件に合わせて更新し、9件すべてパスしています。

• 同セルで圧倒的戦力 → 殲滅・占領
• 別セル（座標はほぼ隣）→ 戦闘なし
• 艦隊も同セルのみ交戦（航路接続だけでは不可）

## 質問

1セルの大きさを考えると大砲や投石機でも同一セル内のみ戦闘可能で、ロケットミサイルなどが無いと隣のセルまで届かないと思いますが、どうですか？

## 回答

その理解で問題ないと思います。同一セル限定は、このマップのスケール感と技術水準にかなりよく合っています。

セルの実距離感

このプロジェクトではだいたい次の換算です。

• 実距離 ≒ map units × distanceScale（デフォルト distanceScale は 3 → 1 map unit ≒ 3 km）
• 歩兵の移動は 約 28 km/日（regimentMovement）

パックセルは Voronoi なので形はまちまちですが、セル中心間はおおよそ 十数〜数十 map units になりやすく、distanceScale = 3 だと 隣セル中心までだいたい数十 km のオーダーです。1セルは「町とその周辺平野」くらいの戦略区画であって、戦場の一角ではありません。

兵器射程との比較

|兵器|実効〜最大射程の目安|
|--|--|
|弓・弩|数百 m|
|投石機・トレビュシェ|200〜350 m 前後|
|近世〜ナポレオン期の野砲|有効 1〜2 km 程度|
|近代野砲・ロケット|十数〜数十 km|
|長距離ミサイル|隣セルを優に超える|

隣セルまで届くのは、近代火砲〜ロケット／ミサイル級です。投石機や大砲（近世以前のイメージ）では、**隣のセルにいる敵連隊を「隣接セルから撃破する」**のは地図スケールでは無理があります。

旧 SKIRMISH_CONTACT_RADIUS = 50 map units は、デフォルト換算で おおよそ 150 km。これは大砲どころか、近代ロケットでも「常時その距離で連隊同士が毎日潰し合う」には広すぎます。

ゲーム抽象としての意味

同一セル条件は、物理学の厳密再現というより次の抽象として妥当です。

1. 同じ戦場に入った（同じ戦略区画に両軍が重なった）ときだけ背景戦闘する
2. 隣にいるがまだ行軍中の敵とは、接触するまで戦わない
3. 遠距離射撃は、セル内部の戦術描写（将来の Battle Screen や攻城）に任せる

つまり「隣セルから砲戦できない」のではなく、隣セルにいる時点ではまだ砲兵射程の外（戦略マップ上は非接触）、というモデルです。

将来もし拡張するなら

今の同一セルルールを崩す必要は薄いです。技術時代が進んだときにだけ、例えば次のような拡張で足ります。

• 射程ユニット／技術フラグがあるときだけ、隣接セルへの弱い砲戦・爆撃を許可
• それでも通常は 同じセル or 共有辺の隣接1ホップ までに制限
• ミサイル級は別システム（戦略打撃）として扱い、通常の連隊 vs 連隊の毎日戦闘には混ぜない

───

結論: 大砲・投石機前提なら「同一セル内のみ戦闘可能」は妥当です。隣セルまで届くのはロケット／ミサイル級の話で、現状のファンタジー〜近世寄りの軍事モデルでは、今回の修正の方がスケールに合っています。
