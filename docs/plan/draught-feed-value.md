# 役畜の餌の値打ち（2026-11-16、調べただけ）

## 1. 問い

足りない月に予算を広げるかを、食べられない餌1 kgの値打ちで決めている（[livestock-feed-shortfall.md](livestock-feed-shortfall.md) §10.2、`getUnfedValuePerKg`）。2102の足りない土地では、群れの餌の約2割を馬が食べるのに、馬は肉に数えず、値打ちが薄まっていた（[fodder-residual-20261116.md](../analytics/fodder-residual-20261116.md) §4）。馬の働く値打ちを数えるかを調べた。

## 2. 今のコード

1. 役畜の頭数は、耕地1 haあたり0.29頭（`DRAUGHT_HEADS_PER_CULTIVATED_HA`）と農村の人口で決まる。そのうち時代ごとの割合（`getHorseDraughtShare`）が馬、残りが牛（耕す牛）である（`husbandry.ts`の群れの目標）。
2. 役畜の頭数は、群れの目標を決めるだけで、耕す量・畑の広さ・収穫には戻ってこない。役畜が痩せても死んでも、畑仕事は変わらない。
3. 馬が失うものは、肉にならないので、痩せでは何も無い。死ねば頭数が減る。締めで売れば市場に出る。
4. 耕す牛は、肉は数えているが、働く値打ちは数えていない。

## 3. 判断

1. 馬の働く値打ちを、値打ちの計算に足すことはしない。シミュレーションの中で役畜の働きが何も生んでいないので、足せば、何も失わないものに餌を買うことになる。
2. 馬が死ぬ手前・売られる手前は、売る手前の土地への予算（`nearCull`の条件、worthの中でも有効）がすでに守っている。
3. 歴史では、春に耕す馬に燕麦を与えた（Langdon）。これを表すには、痩せた役畜が春の耕しを減らす形が要る（下の案B）。

## 4. 調べていない案

- 案A：馬・耕す牛の働く値打ちを、耕しを雇う代金で数える。シミュレーションに戻る先が無いので採らない（§3の1）。代金の史料も探していない。
- 案B：痩せた役畜が、3〜4月の耕しの人手（`allocateRuralOccupationsFromCalendar`の畑の上限）を減らす。値打ちは、減った耕しで失う収穫になる。
  - 見込み：2102の4月に痩せた土地は約20、使った蓄えは1割前後で、その土地の春の耕しが数%減る程度。世界の収穫にはほとんど出ない。
  - 影響の範囲は§6で数えた。

## 5. 再開の条件

役畜の頭数を耕す量や収穫に結ぶ時（案B）。

## 6. 案Bの影響の範囲（2026-11-16、計算のみ）

### 6.1 つなぎ先

1. 人手の不足が収穫を減らす道は、1月の割り当てが土地と月ごとに出す`cropLaborShortage`である。これを年で足した`cropLaborCoverage`（1−働けなかった日÷畑の日）が、農村の食料の生産（`foodProduction.ts`）と町の食料の見込み（`urbanFoodCapacity.ts`）に掛かる。
2. 案Bは、痩せた月に`cropLaborCoverage`を下げればよく、割り当ての`currentDays`（畑・移住・人手の放出）には触れなくて済む。§4の「大きな変更」は言い過ぎだった。
3. ただし、`cropLaborCoverage`は1月に1回だけ決まる。痩せは2〜4月に生まれるので、その月にその土地の値を下げ直す仕組みが要る。

### 6.2 大きさ

- 穀物の暦で、畑の仕事のうち据え付け（耕し・種まき）は20〜22%（`stapleCrops.ts`の`labourByStage`）。役畜が要るのは主にここである。
- 冬の穀物は秋に、春の穀物は3〜4月に種をまく。4月の畑の日は、年の畑の日の1割前後と置く（暦の重みは数えていない）。
- 2102の4月に1%より多く足りない土地は約20（[fodder-residual-20261116.md](../analytics/fodder-residual-20261116.md) §4）。使った体の蓄えは、不足が1か月の餌の1〜22%なので、0.5〜11%である。
- 役畜の力の減りを「使った蓄え×0.5」と置くと、最大で約5.5%。
- その土地の`cropLaborCoverage`の下がりは、約0.1（4月の割合）×5.5%で、最大0.6%前後。世界の収穫では0.01%に届かない。
- 値打ちに直すと：食べられない餌1 kgが失わせる収穫は、肉（約0.0002）よりずっと小さい見込みで、予算を広げる決まり（worth）が干し草を買う側に変わることは、まず無い。

### 6.3 判断

案Bは、今の不足の大きさでは結果がほとんど変わらないので、今は入れない。歴史の筋（春に耕す馬に燕麦）は、穀物を与える決まりに「耕す月の役畜」を足す形で、不足がもっと大きい地図や時代で効いてから考える。

再開の条件：痩せた土地が多い（例えば4月に足りない土地が全体の1%を超える）地図・設定が出た時。
