# 地図の生成の直後に人々が持っているもの

作成: 2026-10-30

## 1. 背景

地図の生成の直後の冬に、人々が持っていないとおかしいのに配られていないものがあり、最初の数か月の需要と値段が跳ね上がっていた。塩は市場の在庫0から始まり、値段は基準の1.7倍から始まった（[塩の供給の校正](salt-supply-calibration.md)§3）。

固定入力（`docs/analytics/inputs/wet-pastoral-birth-20261029/world-102.fmg`、平和モード）で、0・1・3・12か月目を調べた。

| 項目 | 開始時 | 12か月目 | 判断 |
| --- | --- | --- | --- |
| 住居の充足（`buildingStock`、町385か所） | すべて0 | 中央値0.17 | 町は住民がいるのに家が無い扱い。都市の受け入れ容量（下限50%）・建設の雇用・都市の生産に効く |
| 衣服（Garments・Linen・Wool）の市場の在庫 | どの市場も0 | ほぼ0 | 値段は値打ちの1.2〜1.8倍に上がる |
| 塩の市場の在庫 | 0 | 目標の6割 | 値段は基準の1.7倍から |
| 陶器・硬貨・煉瓦・粘土・道具 | 在庫0 | 在庫0〜少し | 値段は値打ちの1.3〜2.9倍に上がり続ける |
| 町の手元のお金（1人あたり、10%・中央値・90%） | 165・168・176（ジニ0.03） | 79・186・299（ジニ0.33） | 開始時は平等すぎ、貧富の差は1年かけて生まれる |
| 農村の手元のお金（市場ごと） | ジニ0.20 | ジニ0.18 | 市場の間の差はあり、変わらない |
| 暖房の不足 | 3.6% | 0% | 最初の月だけ |
| 市場の穀物の在庫 | 67千 | 0に近い（22市場のうち19が空） | 食糧の帳簿との関係を確かめる（§4） |

## 2. 方針

地図の生成の直後の町と村は、すでに人が住んでいる。前の年に作られた物と、その年に建っていた家を、生成の時に一度だけ置く。進めた後の世界には置かない（`isUnadvancedWorld`、経済のスライスの`startProvisioning`で一度だけ）。

## 3. 内容

### 3.1 住居

- 新しい町の住居の充足を1にする。FMGの生成でスラム（`burg.shanty`、人口の大きい町）を持つ町は0.85（仮値、`SHANTY_START_HOUSED_SHARE`）にし、残りはバラック住まいとする。
- 保存された住居が0の町（世界の誕生の時点で保存された地図）も同じに置く。0より大きい町は保存のまま。
- 実装: 新しい地図は`constructionEmployment.ts`の`generate()`。読み込んだ地図は`generate()`を通らないので、`settleStartProvisioning`から`seedStartHousing`を呼ぶ。

### 3.2 塩

- 市場ごとに、その市場の人・家畜・加工の需要の3か月分（`SALT_MARKET_RESERVE_MONTHS`）を在庫に置く。
- 製塩所の能力は、生成の後に置かれた家畜を含めた需要に合わせ直す（`resizeSaltworksToNeed`）。
- 実装: `saltLogistics.ts`の`seedWorldBirthSaltStock`。

### 3.3 衣服と寝具

- 市場ごとに、家庭の衣服と毛布の買い替えの3か月分（仮値、`START_TEXTILE_STOCK_MONTHS`）を在庫に置く。衣服は普通の`Garments`、毛布は`Wool Blankets`。
- 実装: `startProvisioning.ts`。

### 3.4 後続

- 陶器・硬貨・煉瓦・粘土・道具など、他の在庫0の財は、食べ物と穀物の調査（§4）の後に、置くかどうかを決める。
- 町の手元のお金の貧富の差を開始時から付ける。目安は12か月目に自然にできる差（ジニ0.3前後）と史料。

## 4. 食べ物と穀物の調査（2026-10-30）

記録: [測定](../analytics/start-provisioning-20261030.md)§3。

- 魚・獲物・貝は、生のまま市場に出ない作りである（`markets-generator.ts`の`planCellFoodRescue`の流れ）。セルの中で食べ、セルの備え（干物・塩漬け）に回し、残りを加工品（`Preserved food`・`Stockfish`等）にして市場へ出す。生のまま市場に入るのは冷蔵の輸送だけ。市場の在庫0と値段の上昇は表示の上のことで、不足ではない。
- 市場の`Grain`の在庫は、食糧の帳簿の`exportable`（在庫−次の収穫までの取り置き）の写しで、実際の在庫ではない。12か月目の実際の在庫は約7.9万（取り置き6.6万）で、空ではない。
- 12か月目の都市の主食の不足（約3.1千、都市の需要の14%）は、年の区切りに新しく立った市場18〜22で起きた。新しい市場の帳簿は最初の消費の時に空で作られ（`foodLedgerConsumption.ts`の`emptyFoodLedger`）、その町の人々の穀物は元の市場の帳簿に残る。農家のお金は`moveRuralPursesWithFarms`で畑と一緒に移るが、穀物の在庫は移らない。24か月目にも新しい市場23・24で同じことが起きた。

### 4.1 新しい市場への穀物と塩の移転（2026-10-31、[記録](../analytics/salt-price-ownership-20261031.md)§3）

- 市場の線が引き直され、穀物を一度も持ったことの無い新しい市場ができた時、移った人々（セルの人口と町の人口）の割合だけ、元の市場から穀物と塩を移す（`newMarketProvisions.ts`）。
- 穀物は、元の市場が次の収穫まで取り置く分（`exportReserve`）のうち移った人々の割合だけ。取り置きを超える分は元の市場に残る。年齢の区分と仕入れの単価はそのまま移す（`stapleCropInventory.ts`の`transferStapleCropShare`）。
- 塩は、元の市場の在庫のうち移った人々の割合。
- お金は動かさない。市場・商会・商人を分ける設計（持ち主が自分で在庫を運ぶ・売る）は、今の経済の課題を解いた後の課題として先送りする。
- 結果: 12か月目の新しい市場の都市の不足3,106は0になった。

### 4.2 世界の誕生の時の畑（2026-10-31、[記録](../analytics/world-birth-fields-20261031.md)）

- 原因: 世界の誕生の畑の計画（`replanWorldBirth`）が年ごとの更新として計画され、同じ年のうちの開墾が0になり、保存された時の小さい畑（必要の81%分）がそのまま残った。開始時の農家の蓄えが不足を埋め、それが1303〜1304年に底を突いて、都市の充足が落ちた。
- 修正: 世界の誕生の計画は、何世代も住んできた人々が過去に拓いた畑として、開墾の上限なしに人々の必要に合わせる（`agriculturalLandUse.ts`の`worldBirth`）。世界の誕生の時に保存された地図も、開始の備えとして1回だけ計画し直す（`startProvisioning.ts`、版2）。
- 結果: 畑の能力は最初から穀物を食べる人を上回る。1304年の都市の主食の充足は92.9%から98.8%、都市の人口は減らずに増える。

## 5. 未確定事項

- 町の家庭が穀物を買えない不足（お金、1301年の252から1307年の4,943へ増える）。開始時の貧富の差と合わせて見る。
- 市場・商会・商人の分離（先送り）。
- スラムの町の住居の割合（0.85）の根拠。

## 6. すべての財の開始在庫（2026-11-04の決定）

### 6.1 決定

- 地図を作った直後の市場には、お金や穀物と同じく、すべての財を「この程度はあるはず」という量だけ置く。ゲームの開始の時点で、需要と供給が釣り合った状態にする。
- その量は、シミュレーションの計測から決めた線を既定値とする。
- 樽もこれに含める（[urban-craft-staffing.md](urban-craft-staffing.md)の未決事項16）。§3.2〜3.3の塩・衣服・毛布の「需要の3か月分」も、この線に置き換えるかを同じ計測で確かめる。
- 将来、Simulation設定で飢饉の開始（在庫を線より少なく）や飽食（多く）を選べるようにする。今は作らないが、線に倍率を掛けられる形にしておく。

### 6.2 線の決め方（案）

財の在庫は、その市場で月に使われる量で割って「何か月分」で表す。市場の大きさが違っても同じ線が使える。

1. **計測。** 固定入力の地図4枚を、平和モード・襲撃なしで5年進める。毎月、市場ごと・財ごとに、在庫と、その月に使われた量（財の流れの記録`setGoodFlowObserver`の`sink`の合計。家計・レシピの原料・建設・軍・輸出の出発など）を記録する。
2. **線。** 3〜5年目（生成の直後の揺れが収まった後）の「在庫 ÷ 月に使われた量」の中央値を、財ごとの既定の月数とする。市場の間のばらつき（10〜90%点）も記録する。
3. **開始の時の量。** 開始の時に月に使われる量は、まだ動いていないので分からない。月に使われる量の線も、計測から「市場の人口1,000人あたり」で出す。その財の作り手か原料が無い市場（ぶどうの無い市場のワインなど）は、計測でも在庫が0に近いので、地域の別（その財の原料が市場に入るか）で分ける。
4. **在庫の線に入れない財。** 主食（食料の帳簿が扱う）、生のまま市場に出ない魚・獲物（§4）、家畜（群れの帳簿が扱う）、船・荷車（輸送の資産が扱う）は、それぞれの仕組みの開始の量に任せる。

### 6.3 段階

| 段階 | 内容 | 完了の条件 |
| --- | --- | --- |
| P1 | 計測の手順と、財ごとの月数・1,000人あたりの量の表（`docs/analytics`） | 4枚の地図で、財ごとの線とばらつきが出る（2026-11-05、§6.4、[記録](../analytics/start-stock-20261105.md)） |
| P2 | 線の表をコードに置き（計測の出典付き）、`settleStartProvisioning`で一度だけ置く。版を上げる | 1〜3か月目の値段の跳ね上がり（値打ちの1.3倍超）が、線のある財で無くなる（2026-11-06、§6.6。鉄の地金は3か月目、馬具は6か月目に値打ちの近く） |
| P3 | Simulation設定に、開始の在庫の倍率（既定1）を置く | 倍率0.5・2で開始の在庫が変わる |

P1の計測は、この線を入れる前の版で行う。入れた後の版で計り直すと、線が自分の結果に引きずられるので、P2の後の確認は値段と不足だけを見る。

### 6.4 P1の結果（2026-11-05、[記録](../analytics/start-stock-20261105.md)）

7e21fecで作った地図4枚（seed 2101〜2104）を、60か月計った。§6.2の前提と違う結果になった。

- **在庫の線**: 3〜5年目の月末の在庫は、ほとんどの財で0か月分である（ビール0、樽0.09、衣服・毛布・亜麻布・ろうそく0）。作った分は、その月のうちに売れる。線を引くと多くの財で0になり、置くと釣り合った状態から離れる。
- **開始の後の生産**: 1〜3か月目から3〜5年目と同じか多い（ビール・樽・道具・ろうそく・塩）。開始時の値段の高さは、物の不足から来ていない。
- **高値が続く財**: 1〜3か月目に値打ちの1.3倍を超える財の多くは、12か月目と3〜5年目にも高い（粘土3.0、ワイン、亜麻布の服、香辛料、飼料、矢、コーヒー）。値段の決め方か作り手の配置の問題で、開始の在庫では直らない。
- **開始の時だけ高い財**: 次の財に限られる。
  - 鉄の地金: 1年目は2.2〜2.7倍、3〜5年目は1.17倍。
  - 燻製チーズ: 1〜4か月目。
  - ビール・樽: 1か月目だけ。
- **主食**: 2103・2104では、最初の収穫の前の2〜3か月目に、醸造に回せる穀物がほぼ0になる。主食は食料の帳簿の開始の量の問題である（§6.2の4）。
- **樽（未決事項20）**: 2〜5年目もエールの需要の7〜33%が樽で不足し、続いている。開始の在庫では直らないので、樽の下限を直す。

P2は「全部の財に線の在庫を置く」から、次の3つに分けて決め直す。

1. 開始の時だけ高い財（鉄の地金ほか）は、原因を個別に見る。
2. 高値が続く財は、値段の決め方の問題として扱う。
3. 樽の下限と、主食の開始の量を直す。

### 6.5 樽と開始時の穀物（2026-11-06、[記録](../analytics/start-stock-20261105.md)§5）

- **樽**: 下限を、市場の家計の飲み物（水の安全の上乗せを含むエール、ワイン、シードル）が使う樽から決めるようにした（[urban-craft-staffing.md](urban-craft-staffing.md)の未決事項20）。2102〜2104では、樽による不足がエールの需要の7〜33%から1〜10%になった。
- **開始時の穀物**: 市場の倉に、開始の月から最初の収穫までに町の人と醸造が使う穀物と、町の取り置き3か月分を置くようにした（`getStartHarvestBridge`）。収穫は、市場のセルの収穫の暦から見積もる。前の量（町の需要の6か月分）は下限に残した。2103・2104では、1年目の穀物による不足が0.29・0.40から0.09になった。
- **鉄の地金**:
  - 3〜5年目には、使用の約8か月分を在庫に持って釣り合う。開始時の在庫は13〜14しかなく、炉の生産で在庫が積み上がるまで、2年近く値打ちの2倍前後の値段が続いた。
  - 同じ形の財は、馬具、銅・金の地金、贅沢品の一部である。
  - P2は「在庫を何か月分も持って釣り合う財に、線の在庫を置く」に絞る。市場ごとの使用量（作り手・炉のある市場とない市場）の出し方は、これから決める。

### 6.6 P2: 線の在庫（2026-11-06、[記録](../analytics/start-stock-20261105.md)§7）

- **線の決め方**: §6.2の「何か月分」の線は、ほとんどの財で0になる（§6.4）。在庫を持って釣り合う財では、値段の式（値打ち ×（需要＋5）÷（在庫＋5））が、在庫を式の需要の近くまで積み上げたところで止まる。そこで線を「その市場の式の需要」とし、測った月数の表は置かない。
- **置き方**: 開始の備え（版3）が印を付け、その後の最初の値付け（`initializeMarketPrices`）で、対象の財の在庫を各市場の式の需要まで満たす（`startLineStock.ts`）。倍率`START_LINE_STOCK_FACTOR`（既定1）は、P3で設定にする。
- **対象**: 鉄の地金と馬具。銅の地金は、炉の無い市場で値段が高いまま残ったので外した。
- **副作用**: 1年目は鉄が安いので、道具と武器が多く作られる（道具は2.5〜3倍、武器は約2倍）。道具の値段は6か月目に0.42〜0.49まで下がり、3〜5年目にはほぼ元に戻る。武器は3〜5年目も前より安い（0.47〜0.64、前は0.50〜1.06）。都市人口の差は±0.2ポイント以内。

### 6.7 収穫が倉に入る月（2026-11-06、[記録](../analytics/start-stock-20261105.md)§8）

- **直したこと**: その月の収穫は、その月に食べて醸造した後に倉に入る。開始時の穀物の計算（§6.5）は、収穫がその月の初めに入るとしていたので、1か月分少なかった。これを直した。
- **結果**: 1年目の穀物による不足は、2103で0.09 → 0.04、2104で0.09 → 0.02になった。
- **残る点**:
  - 他の市場への輸出・隊商・傷みと、1か月目の醸造の上乗せを、開始の量に数えていない（6か月で世界全体の約3.5万）。
  - 収穫の遅い市場では、7か月目にまだ醸造の穀物が尽きる。
  - 2104の2〜7か月目に、穀物とは別の理由でビールが少ない月がある。
