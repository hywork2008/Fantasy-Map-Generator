# Diplomacy & History Generation Updates

本ドキュメントでは、歴史生成（Diplomacy History）における直近の変更点、およびそれに伴うNobility（為政者）拡張機能への影響について解説します。

## 1. 戦争発生条件の厳格化と「因縁（Blood Feud）」の修正

歴史の自動生成時において、無作為に遠方の国と戦争が起こる不自然な状況を防ぐため、および過去に戦争をした国同士が再度戦争を引き起こす（War II, War III...）ようにするための調整を行いました。

### 主な変更点

- **隣接国への制限**: 戦争を仕掛ける対象（`validDefenders`）の条件として、自国と国境を接していること（`states[attacker].neighbors.includes(d)`）を必須としました。これにより、地理的に遠く離れた海を隔てた国への理不尽な宣戦布告がなくなり、歴史的なリアリティが向上しています。
- **「Enemy」ステータスの考慮**: これまでは一度戦争を行って関係が「Enemy（敵対）」に悪化すると、システム上攻撃対象のリスト（RivalまたはSuspicionのみ）から除外されてしまい、同じ国同士で二度と戦争が起きないバグがありました。今回の修正で「Enemy」も正しい攻撃対象としてリストアップされるようになり、一度火蓋が切られた国同士は、その後も歴史ループのなかで「War II」「War III」と因縁の戦争を繰り返すようになりました。
- **時系列の正常化**: それぞれの戦争イベントに付与される `yearsAgo`（何年前に発生したか）の値を、歴史生成のループ回数（Attempt）に連動させるよう修正しました。これにより、Relations History ウィンドウ内で必ず「無印 → II → III」という正しい時系列順で表示されるようになります。

## 2. 為政者の嫌悪感（Nobility拡張機能との連動）

上記の歴史生成による泥沼の戦争（Blood Feud）は、ただ国家間のステータスを変えるだけでなく、**Nobility（為政者）拡張機能がONの場合には為政者個人の感情（Affinity）に直接的な悪影響を及ぼす**ようになります。

### ヘイト（嫌悪感）の蓄積ロジック

- **基本ペナルティ**: そもそも国同士が「Enemy（敵対）」である場合、為政者同士の好感度には一律で `-50` のペナルティがかかります。
- **戦争回数に応じた追加ペナルティ**: これに加えて、両国間で過去に起こった戦争（Campaigns）の回数をカウントし、**1回の戦争につき `-20` の好感度ペナルティ**を追加で与えるようにしました。
  
**【例】過去に「War III（第3次戦争）」まで勃発している二国間の場合**

- 基本ペナルティ: `-50`
- 戦争回数ペナルティ: `3回 × -20 = -60`
- **合計好感度への影響: `-110`**

このように、歴史の中で何度も血を洗う戦争をしてきた国同士は、世代が変わっても為政者の間に**修復不可能なレベルの極限の嫌悪感**として根付くようになります。これにより、Coreの歴史生成システムとNobilityのキャラクターシステムがより深く連携し、ドラマチックな世界観を構築します。
