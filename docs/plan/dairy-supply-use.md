## 1. 問題

地図2103の3年目、1人・年あたり。

| | 量 |
| --- | ---: |
| 搾れる牛乳（`cellHarvest`、牛・山羊・羊の全て） | 79 L |
| 飲んだ牛乳 | 0.3 L（需要 20 L の1%） |
| 食べたチーズ | 0.5 kg（需要 25 kg の2%） |
| チーズにした牛乳（`processingConsumption`） | 5.2 L |

- 搾れる牛乳の約93%は、どこにも使われずに「作られなかった」扱いになる。`planCellFoodRescue` は、計画に入らなかった分を記録しない。
- チーズの値段は基準の値（14）の約3倍。乳製品の値（主食の0.09倍）は、籠の比（0.63）の約1/7。

## 2. 原因

牛乳は、飼っている土地（セル）の中で、次の3つに分けられる（`markets-generator.ts` の `settleCellFreshFood` と `cellFoodRescue.ts`）。

1. **その場で飲む分**: 土地の人の牛乳の需要まで。ただし、加工する量の5%まで（`maxFreshHouseholdShare` 0.05）。
2. **蓄えるチーズ**: 牛乳の需要の3か月分（`CELL_FOOD_RESERVE_MONTHS`）まで。このチーズは飢饉の備えで、主食が足りない四半期にしか食べない（`emergencyReserveDemandUnits`）。
3. **市場へ出すチーズ**: `getCellPreservedFoodExportDemand` の、土地の人口点あたり月0.1ロット × 値段の押し（最大1）まで。チーズに直すと、1人・年約1.2 kg。

チーズの需要（市場の全ての人、1人・年25 kg）に比べて、3の上限は約1/20しかない。2のチーズはふだん食べないので、農家の乳製品の消費はほぼ0になる。

搾れる量そのものも足りない。

- チーズ25 kg（牛乳10 L/kg で250 L）と牛乳20 Lを足すと、1人・年270 L要る。搾れる量（79 L）はその約3割。
- 搾乳の量（`ANNUAL_LITERS_PER_LACTATING_FEMALE`: 牛500 L、山羊150 L、羊75 L）も、需要（`DAIRY_TARGETS`）も、コード中で「史料で確かめていない値」とされている（`dairyProductionPolicy.ts`、`foodLots.ts`）。
- 史料の手掛かり（`dairyHistoricalReferences.ts`）:
  - Biddick（1989）のピーターバラ修道院の1307年: 乳牛247頭で、チーズ16,342 lb（1頭あたり約30 kg）、バター3,290 lb。
  - DeWitte & Slavin（2013）: 乳を出す牛1頭に年100ガロン。

## 3. 方針

1. **市場へ出すチーズの量を、市場の需要の不足で決める。** 固定の上限（人口点あたり月0.1ロット）をやめる。
   - 市場のチーズの需要 × 蓄えの月数 − 在庫を、牛乳のある土地に搾れる量の比で分ける。
   - 果樹の飲み物（`getFoodProcessingProductionHeadroom` × `getOrchardMaterialCapacity`）と同じ形にする。
   - 加工の人手（`CELL_FOOD_PRESERVATION_LABOR_SHARE` 0.15）の上限は残す。
2. **農家が自分の牛乳とチーズを食べる。** 土地の人の分の需要（牛乳20 L、チーズ25 kg × その土地の人数）を、その土地の牛乳から先に満たす。お金は動かさない（自家消費）。主食の自家消費と同じ扱いにする。
   - 市場のチーズの需要は、町の人と、自分の牛乳で足りなかった農家の分にする。
   - 飢饉の備えの蓄え（2）は残す。
3. **需要と搾る量の値は、この設計では変えない。** 1・2を入れた後に、搾れる量（79 L）が需要の何割を満たすかを測る。そのうえで、`DAIRY_TARGETS` と搾乳の量を史料と照らす作業を別に行う。
   - Biddick の1頭30 kgのチーズは、牛乳に直すと約300 L/頭。今の牛500 L × 乳を出す割合0.375 ≒ 繁殖群の1頭あたり188 L と同じ桁にある。
4. 設定:
   - `cellCheeseSale`: `demandGap`（新、既定）/ `fixedShare`（今の決まり）
   - `ruralDairyUse`: `eat`（新、既定）/ `reserveOnly`（今の決まり）

## 4. 影響

- 農家の乳製品が自家消費になる。GDP の主食以外の部分が増える（籠の乳製品）。お金の流れは変わらない。
- 市場へ出るチーズが増える。値段は上限から下がり、町の家計がチーズに使うお金が増える。チーズを作る土地の農家の収入（市場の値段の農家の取り分）も増える。
- 牛乳を多く使うと、子に飲ませる乳（`livestockFeed` の乳の戻り、[settled-questions.md](settled-questions.md) 22〜23行の「乳の戻り」）との取り合いが起きないかを確かめる。今の `getMilkOutput` は、子に飲ませる分を引いた後の搾れる量として扱っている（要確認）。
- 塩（チーズ1 tに0.25 bag = 15 kg）の需要が増える。

## 5. 計測

- 地図2103、36か月、戦争なし・略奪なし。[basket.mts](../analytics/household-basket-20261116/basket.mts) で、今の決まりと新しい決まりを比べる。

| 指標 | 見込み |
| --- | --- |
| 飲んだ牛乳・食べたチーズ（1人・年） | 搾れる量の範囲で増える。チーズは最大約7 kg |
| 搾れる牛乳のうち使った割合 | 7% → 大きく増える |
| チーズの値段 | 上限から下がる |
| 塩の値段・在庫 | 大きく崩れない |
| 籠の乳製品の比（主食に対して） | 0.09 → 0.3前後 |

## 6. 未確定事項

- 乳製品の需要（チーズ25 kg）の根拠。町と農村、地方（牧畜の地域と穀物の地域）で違ってよいか。
- バターが無い。籠の「バター・チーズ」の半分近くはバターである。
- 乳を出す季節（今は3〜10月の8か月で、半球・気温によらない）。
- 子に飲ませる乳と、搾る乳の分け方（§4）。

## 7. 牛乳の人手（計測で追加）

- 品の目録の牛乳の人手（`preservationLaborPerUnit` 0.08）は人口点の単位のままで、牛乳1,000 Lに80人・月かかっていた。土地の人の15%の人手では、牛乳の約19%しか扱えなかった。
- 果物（`CELL_FRUIT_PROCESSING_WORK_DAYS_PER_LOT`）と同じく、1,000 Lあたりの大人の作業日数で数える。設定 `cheeseMakingDaysPerMilkLot` は既定10日（仮値）、1〜60日。
- 今の値は単位の誤りなので、選べる形では残さない。この直しは `cellCheeseSale`・`ruralDairyUse` のどちらの決まりにも効く。

## 8. 農家が食べる割合（計測で追加）

- §7の後、農家の需要（25 kg）が作れる量（約8 kg）を上回り、農家が全部食べて町への売りが0になった。
- 荘園はチーズの多くを売った（Biddick 1989 のピーターバラ修道院）。農家が食べるのは、自分の牛乳の `ruralCheeseEatShare`（既定0.5、仮値）までとする。残りは市場向けのチーズにする。
