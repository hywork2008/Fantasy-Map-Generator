# 革の使い道

## 1. 背景

[household-goods-pay-20261111.md](../analytics/household-goods-pay-20261111.md) §3.1で、革（Leather）の在庫が1年分の約3倍に積み上がった（北緯30°の地図2102、36か月で802万）。ブラウザで何年も回した地図でも、同じように積み上がった。

- 皮は、家畜（牛）をつぶした時に1頭1枚（`LEATHER_HEADS_PER_ROLL`、[slaughter.ts](../../src/extensions/economy/generators/slaughter.ts)）と、狩りの獲物から出る。作り方（recipe）は無く、需要も値段も見ない。
- 2102では年に290万枚出た。地図の人は約2,030万（農村1,830万、町200万）なので、1人年0.14枚である。
- 使い道は長靴（Boots）・馬具・武具・本・市場の投資で、出た量の約2%だった。
- 在庫が増えても、値段は基の値の1.7〜2倍で下がらない（§7の3）。

## 3. 史料

- 中世には、職人は秋・冬・春に働き、夏は農作業をした。皮革職人の場合、夏の間に多くの皮や毛皮が傷み、それを肥料や膠（にかわ）に使った。生産は中世に増え、用途も武具・衣料・履物のほか、家具や日用品に広がった（竹之内一昭「中世ヨーロッパの皮革 1. 宮廷と修道院における皮革製造」、[皮革技術センター](https://www.hikaku.metro.tokyo.lg.jp/Portals/0/images/shisho/shien/public/158_2.pdf)）。
  - 修道院には鞣し・鞍造り・楯造りの工房があった（10世紀のザンクト・ガレンの見取り図）。15世紀のニュルンベルクの絵には、鞣し工・靴屋・馬具屋が描かれている（同）。
  - オークの樹皮による鞣しは、完全に鞣すまで18か月以上かかった。のちに15か月に縮めた（同）。
- 17世紀末のイングランドで、グレゴリー・キングは、人口550万に年1,200万足、1人年約2足の靴を見積もった。同じころの請願は、1人年3足とした（Riello, *The Boot and Shoe Trades in London and Paris in the Long Eighteenth Century*, UCL PhD 2002, 表3.1。*A Foot in the Past*, OUP 2006）。
- 18世紀のイングランドでは、靴作りが全ての革の60〜70%を使った（同）。皮をとるために牛をつぶしたのではなく、肉のためだった（Riello, "Nature, production and regulation in eighteenth-century Britain and France: the case of the leather industry", *Historical Research* 81, 2008）。
- 1枚の牛の皮（約55平方フィート）からは、靴が約14足、長靴が約8.5足とれる（[Circumfauna](https://circumfauna.org/leather-sludge-data)、今の皮の大きさ）。使える面積の割合は65〜80%である（[United Leather](https://unitedleather.com/blog/how-many-square-feet-in-a-cowhide)）。

## 4. 決める仕組み（案）

### 4.1 履物を農村の人にも

- 長靴（Boots）を、町と農村の全ての人の履物とする。
- 1人あたりの年の足数（設定`footwearPairsPerPerson`）を、中世の既定1足、近世（Historical periodがearly modern以降）2足とする。中世の数は史料が無く、キングの2足の半分とした（§8の1）。
- 1ロット20足に、革2枚とする（1枚から約10足。中世の牛は今より小さく、底革も同じ皮からとる）。
- 農村の人の分は、農村の家計が町で使う月の額から払う（[rural-town-spending.md](rural-town-spending.md) §4.2の在庫を持つ品）。`householdGoodsPayment`が`free`の時は、町と同じく払わずに取る。

### 4.2 革の品（新しい品）

- 新しい品「革の品」（Leather Goods）を置く。ベルト・袋・財布・手袋・水袋・桶・鞍・家具の張り革など、靴以外の日用品をまとめる。
- 1人あたりの革の量を、履物の革の半分（設定`leatherGoodsShare`、既定0.5）とする。靴作りが革の60〜70%を使ったこと（Riello）から、残りの30〜40%を靴以外とした。
- 作るのは町の皮革職人（`leather`の分野）で、作り方は革1枚から1ロットとする。町と農村の人が買う（履物と同じ払い）。

### 4.3 夏の皮の傷み

- 6〜8月に、鞣されずに市場の在庫にある皮の一部が傷み、肥料と膠になる（設定`summerHideLoss`、月の傷みの割合、既定0.1）。
- 傷んだ皮は、`spoilage`として在庫から出す。肥料と膠の品は今は無いので、作らない（§8の3）。

### 4.4 釣り合いの見込み（2102）

| | 1人年 | 2102の年 |
| --- | ---: | ---: |
| 出る皮 | 0.14枚 | 290万 |
| 履物（1足、10足に1枚） | 0.10枚 | 203万 |
| 革の品（履物の半分） | 0.05枚 | 102万 |
| 馬具・武具・本 | | 1万 |
| 合計の需要 | 0.15枚 | 306万 |

中世の既定で、需要が出る皮とほぼ釣り合う。近世（2足）では需要が皮の約2倍になり、値段が上がる。足りない分は、羊・山羊・子牛の皮を数えていないためである（§8の2）。

## 5. 設定

Simulation settingsに次を置く。既定は新しい決まりとし、今の決まり（町の人だけ年0.25足、革の品無し、傷み無し）も選べるようにする。

| 設定 | 既定 | 意味 |
| --- | --- | --- |
| `footwearDemand` | `everyone` | `everyone`（4.1）か`townsOnly`（今の決まり） |
| `footwearPairsPerPerson` | 中世1、近世2 | 1人年の足数 |
| `leatherGoodsShare` | 0.5 | 革の品の革の量、履物の革に対する割合。0で革の品を作らない |
| `summerHideLoss` | 0.1 | 6〜8月の、鞣されない皮の月の傷みの割合 |

## 6. 変えるもの・変えないもの

- 変える：長靴の需要（農村の人も、足数、1ロットの革）、新しい品の革の品、夏の皮の傷み。
- 変えない：皮が出る量（牛1頭1枚、狩り）、馬具・武具・本の作り方。

## 7. 計測の計画

北緯30°の地図2枚（2102・2103）、36か月、戦争なし・隊商の略奪なし。今の決まりと比べる（[goods.mts](../analytics/household-goods-pay-20261111/goods.mts)の測り）。

1. 革の在庫・値段・出入り。在庫が1年分を超えて積み上がらないか。
2. 長靴・革の品の満たした割合と値段。
3. 皮革職人の人数と、町の家計・農村の家計のお金。
4. 値段：在庫が減った時に、革の値段が下がり・上がりするか。下がらない理由（元値の付け方）は、別に調べる（[household-goods-pay-20261111.md](../analytics/household-goods-pay-20261111.md) §5の1）。

### 7.1 結果

[leather-uses-20261111.md](../analytics/leather-uses-20261111.md)。革の在庫の増えは年290万から約160万（2102）に減ったが、まだ積み上がる。減りのほぼ全部は夏の傷みで、長靴は靴屋の上限のため見込みの需要の約5%しか作られない。

## 8. 未確定事項

1. 中世の1人あたりの履物の足数の史料。今はキングの2足（1690年代）の半分とした。
2. 羊・山羊・子牛の皮。今は牛の皮だけが革になる。羊の皮は羊皮紙と手袋・本の装丁に使われた。
3. 傷んだ皮から作る肥料と膠の品。
4. 鞣しにかかる時間（15〜18か月）を、皮から革になるまでの在庫として持つか。
5. 獣脂・搾り滓のワインなど、ほかの積み上がる副産物（[household-goods-pay-20261111.md](../analytics/household-goods-pay-20261111.md) §3.2）。
