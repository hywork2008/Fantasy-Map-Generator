# 特殊・少数・先住民族圏の埋葬文化と都市形態

人類の歴史には、普遍的な一神教や世界宗教の教義にとどまらない、地域の極限環境、生態系、宇宙論、あるいは都市衛生の極限状態から生まれた極めて特異かつ高度な埋葬文化が存在する。
これらは、ファンタジー世界や異文化都市の設計において、既成概念を打破する強力なインスピレーションを提供する。

---

## 1. ゾロアスター教（拝火教）：沈黙の塔（ダクマ / Dakhma）

古代ペルシアから現代のインド（ムンバイのパールシー共同体）に受け継がれるゾロアスター教の葬礼は、神学的な純潔性と環境衛生の極致である。

### 1.1 神学原理：聖なる四大元素の非汚染
- **死体＝最大の悪と不浄**:
  善神アフラ・マズダの被造物の中で、死は悪神アンラ・マンユ（アフリマン）がもたらした最大の腐敗である。死の瞬間、死体悪魔（ナス / Nasu）が遺体に取り憑き、猛烈な汚染源となる。
- **土葬・火葬・水葬の絶対禁止**:
  神聖なる**「火」**（火葬による汚染厳禁）、**「大地・土」**（土葬による大地の汚染厳禁）、**「水」**（水葬による水源の汚染厳禁）に死体を触れさせることは大罪とされる。
- **唯一の解決策：日光と猛禽による白骨化（露出葬）**:
  遺体を太陽光（フワルヘシャエタ）とハゲワシ（ハゲタカ）やカラスに晒し、肉を素早く消滅させ、骨のみを浄化する。

### 1.2 建築空間とゾーニング
- **都市からの完全な隔離**:
  風上や水源から遠く離れた、乾燥した岩山の頂や不毛の丘陵（都市から数キロメートル以上離脱）に建設される。
- **円形無天井石造塔（ダクマ）**:
  - 外観：高さ5〜8m、直径数十メートルの円筒形の堅牢な切石・漆喰積みの塔。外壁には窓や開口部がなく、鉄の重厚な扉が1箇所あるのみ。屋根はなく、青空に開かれている。
  - 内部構造（同心円状の石台 / パヴィ / Pavi）:
    - **外側の円環**: 成人男性の遺体を安置する窪み。
    - **中央の円環**: 成人女性の遺体を安置する窪み。
    - **内側の円環**: 子供の遺体を安置する窪み。
  - **中央の骨穴（アストダーン / Astodan / 納骨竪穴）**:
    塔の中央に掘られた深い井戸。鳥によって肉が綺麗に食べ尽くされ、太陽光で完全に脱色・乾燥した骨は、数ヶ月後に専任の葬送司祭（ナササラール / Nasasalars）によって中央の骨穴へと掃き落とされる。
    骨穴の底には木炭と砂・石灰の多層フィルターが敷かれており、雨水によって風化した骨粉が大地や地下水を汚染することなく自然に浸透・濾過される環境配慮構造を持つ。
- **付属施設：サグディード（Sagdid / 犬の視線）の儀礼室**:
  死体悪魔を追い払う霊力を持つとされる「四つ目の犬（目の上に斑点のある犬）」を遺体に対面させる儀礼を行う前室。

## 2. 草原ステップ遊牧民（スキタイ・フン・突厥・モンゴル）

黒海北岸からアルタイ山脈、モンゴル高原に至るユーラシア大草原の騎馬遊牧民の埋葬文化。

### 2.1 クルガン（Kurgan / 巨大墳丘墓）
- **景観と立地**:
  平坦で見渡す限りの地平線が広がるステップ草原において、河川の段丘や交通の要衝となる尾根の上に築かれた土と石の巨大な人工丘陵。
- **パジリク古墳（凍土墳墓 / アルタイ山脈）**:
  - 地下数メートルの深さにカラマツの丸太を組んだ二重の木室（ログハウス）を作り、巨石を積み上げてマウンドを形成。
  - アルタイの厳しい気候により、墓室内に浸入した水が凍結して**永久凍土ブロック**を形成。これにより、2500年前の遺体（全身にグリフォンや獣文の精緻なタトゥーが残る首長や巫女）、毛織物の絨毯、革製馬具、木製四輪車が奇跡的に無傷で残存した。
- **馬の殉葬（Horse Sacrifice）**:
  遊牧民にとって馬は来世への旅路に不可欠なパートナーであった。首長の墓室のすぐ外側の竪穴に、金銀や青銅の豪華な面繁頭（馬面）を装着した十数頭から数十頭の軍馬が整然と屠殺・埋葬された。

### 2.2 石人（バルバル / Balbal）
突厥（チュルク）やクマン人のクルガンの周囲、あるいは草原の街道沿いに直立する人型の立石。
右手に聖杯（盃）を持ち、左手で腰のサーベル（湾刀）の柄を握る髭を蓄えた戦士の姿が彫られる。生前に打ち倒した敵の数だけバルバルを立てたとされ、来世で敵が自らの召使いとして仕える呪術的意味を持った。

### 2.3 モンゴル帝国の絶対秘密埋葬
チンギス・ハンをはじめとするモンゴル帝国のハーンたちの埋葬は、あらゆる記念碑や墳丘を拒絶した。
- **起輦谷（キレンコク）の伝承**:
  ハーンの遺体を大樹の洞または地下深くの墓穴に埋めた後、**千頭の馬を走らせて地表を踏み鳴らし、完全に平地に戻した**。その後、草木を植えて自然林と一体化させ、場所を完全に隠蔽した。葬送に関わった兵士や目撃者は全員処刑され、現代に至るまでその正確な位置は歴史の謎に包まれている。

## 3. 海洋民族・ポリネシア・オセアニア

太平洋の島々（ポリネシア、ミクロネシア、メラネシア）に生きる人々の海と祖霊に根ざした死生観。

### 3.1 カヌー埋葬（Canoe Burial）と海葬
- **カヌー＝魂の乗り物**:
  航海カヌーは生者の移動手段であると同時に、死者の魂が祖先の神話的故郷（ハワイキ / 楽園）へと大海原を渡って帰還するための聖なる舟であった。
- **棺としてのカヌー**:
  古いアウトリガーカヌーを半分に切断して棺とし、遺体を納めて海岸の洞窟やサンゴ礁の岩棚に安置する、あるいは沖合深くへと流す。

### 3.2 頭骨台・スカルハウス（Skull Shelves / メラネシア）
ソロモン諸島やニューギニアにおける二次埋葬儀礼。
- 遺体をまず土中または樹上に安置して白骨化させた後、**首長の頭蓋骨（スカル）のみを慎重に回収・洗浄**する。
- サンゴ石を積み上げた聖なる小島や岬の祠（スカル・ハウス）に、祖先の頭蓋骨を海を向くように一列に並べる。祖先の霊力（**マナ / Mana**）がそこに宿り、部族の豊漁と戦争の勝利を保障すると信じられた。

## 4. 北米先住民族（ネイティブ・アメリカン）

### 4.1 樹上葬・足場埋葬（Scaffold & Tree Burials）
大平原の移動狩猟民（ラコタ・スー族、シャイアン族、ブラックフット族など）。
- **足場架構（Scaffold）の構造**:
  4本の太い丸太の柱を立て、高さ2.5〜3mの位置に木製の足場・デッキを組む。
- **儀礼と死生観**:
  遺体を最も美しいビーズ刺繍の施された鹿革の衣服で装飾し、バッファローの毛皮の毛布で幾重にも包んで革紐で固く縛り、足場の上に安置する。愛用の弓矢、パイプ、日用品が添えられる。
  大地を掘り返して母なる大地を傷つけることを避け、大精霊（ワカン・タンカ）が支配する風と天空、鳥たちに遺体を委ねる思想。肉体が完全に風化した後、親族が骨を回収して聖なる丘に納める。

### 4.2 北西海岸の墓標トーテムポール（Mortuary Poles）
ハイダ族、トリンギット族などの木造海洋定住部族。
- 巨大なベイスギ（レッドシダー）を彫り抜いたトーテムポール。
- **遺骨収蔵**: 亡くなった大首長の火葬された遺灰・遺骨箱を納めるため、トーテムポールの最頂部または背面に専用の四角い空洞が彫り込まれ、一族の紋章（ワシ、カラス、シャチ、クマ）がその守護者として誇らしげに彫刻された。

### 4.3 ミシシッピ文化のマウンドビルダー（Mound Builders）
西暦800〜1400年頃、カホキア（現代のセントルイス近郊）などの都市文明。
- **巨大基壇マウンド（Platform Mounds）**:
  手作業で土を盛り上げた巨大な四角錐台（カホキアのモンクス・マウンドは底面がギザのピラミッドに匹敵）。頂部に首長の館や葬祭殿が建ち、その地下や周囲に歴代支配者の墓が築かれた。
- **象徴的動物マウンド（Effigy Mounds）**:
  蛇（サーペント・マウンド）や鳥の形を立体的に模した長大な土塁墓。

## 5. 先史メガリス・巨石文化（Megalithic Traditions）

新石器時代から青銅器時代にかけて、西ヨーロッパ沿岸部、地中海、極東（朝鮮半島）に見られる巨石構造物。

### 5.1 ドルメン（支石墓 / Dolmen）
- 直立させた2〜4個の巨石（支石）の上に、数十トンの巨大な板状の天井石（上石）を載せたテーブル状の構造。
- 朝鮮半島には世界の半数以上（約3万基）のドルメンが集中し、平野部や河川沿いに点在して古代首長の権力を誇示する。

### 5.2 パッセージ・グレイブ（羨道墳 / Passage Grave）
- 代表例：アイルランドの**ニューグレンジ（Newgrange / 紀元前3200年頃）**。
- 直径80m、高さ11mの白い石英で覆われた巨大な円形墳丘。内部に19mに及ぶ切石積みの細長い通路（羨道）があり、十字形の玄室へと通じる。
- **天文学的設計**:
  入口上部に設けられたルーフボックス（採光窓）により、**1年で最も夜が長い「冬至（Winter Solstice）」の日の出の瞬間だけ、朝日が羨道を一直線に貫いて最奥の玄室の床を約17分間黄金に照らし出す**。死の暗闇に生命の光が蘇る再生のモニュメント。

## 6. 近代都市地下巨大集積（都市衛生の極致）

### 6.1 パリのカタコンベ（Catacombes de Paris）：地下骨壁迷宮
中世以来のイノサン墓地の崩壊（1780年、過密により死体集積土壁が隣の地下室に崩壊）と悪臭・公衆衛生危機を受け、パリ市が断行した世界最大の地下改葬事業。

- **旧採石場地下坑道の転用**:
  パリ市街の地下20mに広がる古代ローマ時代以来の石灰岩採石場跡を利用。
- **600万体の骨の芸術的集積**:
  市内各所の教会墓地から掘り起こされた約600万体の遺骨が、夜間に覆面馬車で運ばれ、地下坑道内に整然と集積された。
  大腿骨や脛骨を前壁に石垣のように精緻に積み上げ、その間に頭蓋骨で十字架やハート形、ライン模様を描く装飾的な「骨の壁」が数キロメートルにわたり続く。入口には「止まれ、ここは死の帝国である」の銘文。

### 6.2 カプチーノ派納骨堂（パレルモ・ローマ）：直立ミイラの地下回廊
- シチリア島パレルモの**カプチーノ派修道院地下納骨堂（Catacombe dei Cappuccini）**:
  遺体を亜塩素酸パイプの部屋で8ヶ月間乾燥させ、酢で洗浄して藁を詰め、生前の修道服や正装（貴族、軍人、学者、子供の洗礼服）を着せて壁面のフックに直立させて針金で固定。約8000体のミイラが立ち並ぶ地下回廊。「現世の富や美の虚しさ」を生者に警告する生々しいメメント・モリ空間。
