# ダルマ系・東洋宗教圏の埋葬文化と都市形態

東洋・南アジア・東アジアの宗教体系（仏教、ヒンドゥー教、儒教、道教、神道）は、アブラハム一神教とは対照的な死生観を持つ。
「輪廻転生（Samsara）からの解脱」「四大元素（地・水・火・風・空）への肉体の還元」「祖先崇拝と孝道」「風水による大地の気（龍脈）の循環」「死の穢れ（ケガレ）と神域からの隔離」が、都市空間における墓地や火葬場の配置を決定づけた。

---

## 1. 仏教（Buddhism）

仏教における死者儀礼は、釈尊（ブッダ）の涅槃と火葬を起源としつつも、伝播した地域（南伝上座部、チベット密教、中国・日本大乗）の気候・風土・統治制度と融合し、極めて多彩な空間形態を生み出した。

### 1.1 インド根本仏教：ストゥーパ（Stupa / 仏塔）と巡回動線
- **火葬と仏舎利（遺骨）の分骨**:
  紀元前5世紀、釈尊の遺体はクシナガラで火葬され、残された遺骨（仏舎利 / 舎利）は8大国の王たちによって八等分（分骨）された。
- **ストゥーパの形態**:
  遺骨を納めた半球形のマウンド（アンダ / 卵）、その頂部に天蓋（チャトラ）、周囲に石造の玉垣（ヴェーディカー）と四方の門（トラーナ）が巡らされた（代表例：**サーンチーの第一ストゥーパ**）。
- **右繞（うにょう / Pradaksina）の儀礼動線**:
  信徒はストゥーパの周囲に設けられた環状通路を、ストゥーパを常に右手に見て時計回りに歩きながら瞑想・礼拝した。この求心的な円形動線は、後世のすべての仏塔建築の原型となった。

### 1.2 東南アジア上座部仏教（Theravada / タイ・ミャンマー・カンボジア）
- **寺院（ワット / Wat）境内での火葬塔（メル / Men）**:
  死者は白布で包まれ棺に入れられ、寺院境内の広場に設けられた火葬塔で焼かれる。
  火葬塔は仏教の宇宙観における聖山**「須弥山（メル山）」**を模した壮麗な多層の金色・白漆喰の尖塔建築である。
- **チェディ（Chedi / 白い小仏塔）群の回廊配置**:
  火葬後の遺骨や遺灰は、寺院の回廊沿いや外壁の内側に整然と立ち並ぶ高さ2〜4mの白い釣鐘型仏塔（チェディ）の中に納められる。
  寺院の境内全体が、白く輝く無数のチェディによって荘厳な小宇宙を形成する。

### 1.3 チベット密教（Vajrayana / チベット・ブータン・モンゴル）
チベット高原の極度に過酷な自然環境（標高4000m超、燃料となる木材の極度の不足、凍結して掘削不可能な岩盤）から、世界で最も特異な葬法が発達した。

- **鳥葬（天葬 / ジャートール / Jhator）**:
  - **チュルカル（鳥葬台）の立地**: 都市（ラサ等）や大僧院から数キロ離れた、風吹きすさぶ岩山の山頂や高台の平坦な巨岩。
  - **解体儀礼**: 専門の職能者（ロギャパ / Ragyapa）が読経の中で遺体を解体し、骨を石のハンマーで砕いてツァンパ（大麦の粉）と混ぜる。
  - **最後の布施**: 口笛で呼び寄せられたヒマラヤハゲワシ（ハゲタカ）の群れが肉と骨粉を完全に食べ尽くす。肉体を他の生命（鳥）に施すことで、最期の功徳を積むとともに、魂が肉体への執着を断ち切って転生へ向かう儀礼。
- **チョルテン（Chorten / 仏塔）と高僧の座棺ミイラ**:
  一般民が鳥葬に付される一方、ダライ・ラマなどの活仏（リンポチェ）や高僧は、塩漬けにして乾燥ミイラとされ、金箔で覆われて豪華な金銀・宝石造りのチョルテンの内部に座った姿勢で永遠に安置された（ポタラ宮内の歴代霊塔）。
- **巡礼動線（コルラ / Kora）**:
  チョルテンや僧院の周囲にはマニ車（回転経輪）が連なり、巡礼者が五体倒地を繰り返しながら周回する。

### 1.4 中国大乗仏教（禅宗・浄土宗）
- **塔林（Forest of Pagodas / 歴代住持墓）**:
  寺院の裏山や隣接する丘陵林に設けられる。
  代表例：河南省登封の**少林寺塔林**（唐代〜清代の石造・煉瓦造仏塔240基以上が現存）。
  歴代住持や高僧の遺骨を納めた3層・5層・7層の奇数層（仏教の吉祥数）の石塔が、森のように立ち並ぶ。塔の形（八角柱、四角柱、瓢箪形、円筒形）は時代や功績によって異なる。
- **普同塔（納骨総塔）**:
  一般の修行僧や庶民の遺灰を合葬する巨大な納骨塔。

### 1.5 日本の仏教墓地：中世〜近世寺檀制度
日本は、仏教伝来以降、世界で最も特異かつ整然とした「寺院境内墓地システム」を構築した。

- **中世：両墓制（りょうぼせい）と五輪塔**:
  - **両墓制**: 死者の遺体を埋める**「埋め墓（野墓・山墓）」**と、村の近くや寺に建てて供養する**「参り墓」**を地理的に完全に分離した制度。死体の腐敗と死の穢れを恐れつつ、先祖の霊を供養するための民俗的知恵。
  - **五輪塔（Gorinto）**: 下から「方（地）・円（水）・三角（火）・半月（風）・宝珠（空）」を重ねた石塔。宇宙の構成要素に肉体が還元されることを意味する。
- **近世江戸時代：寺檀制度（檀家制度）の都市工学**:
  - 江戸幕府はキリシタン弾圧と戸籍管理（宗門改め）のため、全国民を特定の仏教寺院（檀那寺）に強制的に所属させた。
  - この結果、**「全国のすべての寺院の境内に信徒の墓地が併設される」**という都市構造が法的に確立された。都市（江戸、京都、大坂）では、寺町（寺院が集められた特定区画）の背後すべてが広大な墓地群となった。
- **近代〜現代：先祖代々墓と火葬率99%**:
  - 遺骨を納める地下納骨室（カロート）の上に、長方形の竿石（「〇〇家之墓」）を立てる。
  - 付属設備：花立（一対）、水鉢、線香立、木製の卒塔婆を立てる塔婆立、墓誌（戒名を刻む石板）。

## 2. ヒンドゥー教（Hinduism）

ヒンドゥー教において、肉体は一時的な衣に過ぎず、魂（アートマン）は不死である。火葬の炎（アグニ神）は遺体を神への最後の捧げ物（アンティエシュティ / Antyeshti）として浄化する。

### 2.1 火葬ガート（Cremation Ghats）：水辺の解脱空間
- **聖なる河川と階段状プラットフォーム（ガート）**:
  聖地バラナシ（ワーラーナシー）をはじめとするガンジス川河岸の階段状敷地。
  代表例：**マニカルニカー・ガート（Manikarnika Ghat）**、ハリシュチャンドラ・ガート。
- **都市構造と産業連関**:
  - **薪の集積場（Woodyards）**: 一体の火葬に約300〜400kgの良質な木材（マンゴー、バニヤン、白檀などの香木）が必要。河岸には巨大な薪の山が壁のように積み上げられる。
  - **永遠の火種**: 何百年も絶やされることなく燃え続ける聖なる火種を管理する不可触民（ドーム / Dom）の頭領の館。
  - **解脱の家（Mukti Bhavan）**: 死期を悟った高齢者や病人が、バラナシで死を迎えて輪廻からの解脱（モークシャ）を得るために滞在する臨終の宿。
- **儀礼プロセス**:
  遺体は川の水で清められ、布（男性は白、既婚女性は赤やオレンジ）に包まれ、竹の担架に乗せられる。薪の壇の上に置かれ、長男が火を放つ。燃え尽きた遺灰は聖なる母なるガンジス川へ直接流される。

### 2.2 サマーディ（Samadhi / 聖者の土葬廟）
- 火葬されない例外：
  ヒンドゥー教において、**サドゥー（苦行者・聖者）、子供、妊婦、蛇に噛まれて死んだ者**は、すでに不純な現世の業を脱している、あるいは純粋であると見なされ、火葬されない。
  重石をつけて川の深みに沈める（水葬）、あるいは大地の穴に座禅を組んだ姿勢で埋葬される（土葬）。
- 偉大なグル（導師）のサマーディ（廟）は、神聖な巡礼地・小寺院となり、信徒が祈りを捧げる焦点となる。

## 3. 儒教・道教・東アジア風水（Confucianism & Feng Shui）

中国、台湾、朝鮮半島、ベトナム、琉球（沖縄）に共通する死生観は、「祖先崇拝」「孝道」「風水地理（地理学と占術の統合）」である。

### 3.1 風水墓地（背山臨水と龍脈）
死者の骨が豊かな大地の「気」に包まれることで、その子孫に富、長寿、官吏登用（科挙合格）の繁栄がもたらされる（同気感応）。

- **四神相応の地形選定**:
  - **玄武（主山）**: 墓地の背後に聳える高く険しい山。外部からの冷たい風を防ぎ、龍脈の気を蓄える。
  - **青龍（左山）**: 墓地の左側を緩やかに包み込む尾根（東、男性、陽）。
  - **白虎（右山）**: 墓地の右側を低く包み込む尾根（西、女性、陰）。青龍よりやや低いことが吉とされる。
  - **朱雀（案山・朝山）**: 墓地の前方にある平坦な小丘。
  - **明堂（水）**: 墓の前を緩やかに蛇行して流れる川や池。気を留め、逃がさない。
- **都市と山岳ネクロポリスの分離**:
  都市城壁内には一切墓を作らず、都市を取り囲む郊外の丘陵・山腹一面が広大な祖先墓地となる（例：南京の紫金山、北京の西山）。

### 3.2 亀甲墓（きっこうばか / 琉球・台湾・福建）
中国南部（福建省・広東省潮汕）から台湾、沖縄にかけて広く分布する独特の巨大石造墓。
- **形態的特徴**:
  丘陵の斜面を削り、漆喰と石で築かれる。
  中央の屋根が亀の甲羅の形（長寿の象徴）をしており、その周囲を取り囲む張り出し壁が全体として**「母親の胎内・子宮（母胎回帰）」**を象徴する。
- **前庭（庭 / トゥー）**:
  墓の正面に広々とした石畳の庭が設けられ、清明祭（シーミー）の季節には親族数百人が集まり、墓の前で重箱料理を広げてピクニックのような祝宴を開く。

### 3.3 宗族（Clan）と祠堂（Ancestral Hall）の二重構造
- **都市内の祠堂**:
  村落や都市の中心部に、一族の歴代の位牌（木製の祖先札）を並べた豪華な瓦葺き建築「宗祠」「家廟」を建てる。日常の祭礼はここで行われる。
- **山野の祖墳**:
  実際の遺骨は風水吉地の山腹に土葬され、年に一度の清明節に一族総出で山に登り、「掃墓（墓掃除）」と紙銭（冥界で使う模擬紙幣）の焼却を行う。

## 4. 神道（Shinto / 日本）

神道は、日本古来の自然崇拝・アニミズムを基盤とし、**「死の穢れ（黒不浄 / ケガレ）」を極度に忌み嫌う**宗教である。

### 4.1 神域からの完全な排除とゾーニング
- **神社境内への埋葬の絶対禁止**:
  神社（神の住まう神聖な領域）の敷地内には、墓地は絶対に存在しない。
  身内に死者が出た神職や信徒は、一定期間（忌中）、神社に参拝することや鳥居をくぐることが禁じられる。
- **都市における隔離**:
  死に関わる空間（墓地、火葬場、処刑場）は、神社の神域から地理的に遠く離れた山裾や河原、都市の風下に厳格に隔離された。

### 4.2 神葬祭と奥津城（おくつき）
明治維新以降、神道方式で葬儀を行う「神葬祭」が公認され、専用の神道墓地が作られた。
- **奥津城（奥城 / Okutsuki）**:
  神道信徒の墓の呼称。「奥深く静かな城（住まい）」の意。
- **墓石の形態**:
  仏教の竿石が平らな頭部を持つのに対し、神道の墓石は頂部が**四角錐（ピラミッド状）に尖った形状（神標 / かみつくり）**をしている。これは神籬（ひもろぎ / 神の依り代）や三種の神器の剣の切っ先を象徴する。
- **装飾**:
  線香や仏花ではなく、榊（サカキ）の枝、酒、米、塩を供えるための石造の台（玉串案）が設けられ、入口に小さな石造鳥居が建てられることもある。
