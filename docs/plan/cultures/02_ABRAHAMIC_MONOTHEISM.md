# アブラハムの一神教圏の埋葬文化と都市形態

ユダヤ教、キリスト教、イスラム教のアブラハム系一神教は、「唯一神による天地創造」「現世の終末と最後の審判」「肉体の復活（Resurrection）」を中核的な教義として共有する。この死生観により、原則として**火葬はタブー視（異教の風習・神の創造物の破壊）され、土葬（Inhumation）が至上命題**とされた。
しかし、各宗教および宗派・時代によって、都市における墓地の配置、建築形態、過密度、装飾に対する姿勢は劇的に異なる。

---

## 1. ユダヤ教（Judaism）

### 1.1 古代ユダヤ（第二神殿期〜タルムード期）
- **死の穢れ（トゥマー / Tumah）と市外隔離**:
  旧約聖書・レビ記の律法に基づき、死体は最も重い穢れの源泉と見なされた。そのため墓所はエルサレムの城壁の外、ケドロンの谷やオリーブ山の山腹などの石灰岩丘陵に設けられた。
- **コッキーム（Kokhim）と二次埋葬（オシレギウム）**:
  家族単位の岩窟墓。墓室の壁面に奥行き約2mの細長い横穴（コッキーム）が放射状に穿たれ、そこに遺体を一次安置した。
  約1年後、肉体が完全に腐敗して白骨化すると、骨を収集して石灰岩で作られた装飾小箱**オッスアリ（Ossuary / 骨箱）**に納めて奥の棚に保管した。この二段階埋葬により、狭い岩窟墓で何世代にもわたり同一墓室を利用できた。
- **オリーブ山（Mount of Olives）の聖地墓地**:
  終末の日に救世主（メシア）がオリーブ山に降臨し、そこから最初の肉体復活が始まると預言されたため、世界中のユダヤ人がオリーブ山への埋葬を熱望した。

### 1.2 中世〜近世：過密なゲットー墓地
ヨーロッパ各地でユダヤ人がゲットー（隔離居住区）に押し込められた時代、ユダヤ人墓地は都市の周縁部に厳格に制限された。

- **土地拡張の禁止と多層盛土埋葬**:
  キリスト教徒の都市参事会はユダヤ人墓地の面積拡張を許可しなかった。一方、ユダヤ法（ハラハー）では**古い遺骨の掘り起こしや改葬が厳格に禁止**されていた。
  その結果、既存の墓地の上に新たな土を何層も運び込んで盛り土し、その上に新たな死者を埋葬することを繰り返した（最大10〜12層）。
- **代表例：プラハ旧ユダヤ人墓地（Starý židovský hřbitov）**:
  約1ヘクタールに満たない狭隘な敷地に、約1万2000基の墓石（マツェヴァ / Matzevah）が前後左右に傾きながら折り重なるように密集する特異な景観を形成した。
- **墓標と祈りの習慣**:
  墓石には家系（コーヘンの祈りの手、レビ族の水差し）や職業を表す精緻な浅浮彫が刻まれた。
  花はすぐに枯れてしまうため供えず、参拝者は永遠性と不変の記憶を象徴する**「小石（Pebble）」**を墓石の上に置いて祈りを捧げた。

### 1.3 現代正統派・超正統派（ハレディ / Haredi）
- **土葬の絶対性と解剖の拒絶**:
  死後迅速（可能な限り当日中）に土葬。防腐処理、遺体解剖、火葬は死体損壊（ニヴール・ハメット）として絶対的に禁止される。
- **シュラウド（タフリヒーム）直接土葬**:
  イスラエル国内では棺を用いず、無地の白い亜麻布の布（タフリヒーム）で遺体を包み、直接土の穴に横たえて埋める（人は土から生まれ土に還る）。国外では底に穴を開けた簡易な木棺を用いる。
- **男女分離と質素な長方形石板**:
  超正統派の墓地では、男女で区画が厳格に分けられる。墓石は華美な彫刻を一切排した直方体の平坦な石板が整然と並ぶ。

## 2. キリスト教（Christianity）

### 2.1 初期キリスト教：地下カタコンベ（Catacombs）
紀元2〜5世紀、ローマ帝国による迫害期から公認初期にかけて、ローマ郊外のアッピア街道などの地下に掘削された巨大な地下墓所網。

- **軟質凝灰岩の坑道網**:
  地価の高い地上を避け、地下数層にわたる迷路状の坑道（幅1m前後、高さ2m前後）を延々と掘削。
- **空間構成**:
  - **ロクリ（Loculi）**: 通路の両壁に上下何段にも穿たれた長方形の遺体収納棚。テラコッタ瓦や大理石板で漆喰密閉。
  - **アルコソリウム（Arcosolium）**: 富裕層や殉教者向けのアーチ型墓窪み。
  - **キュービクル（Cubiculum）**: 家族用または小集会用の地下小礼拝室。
- **壁画と信仰**:
  魚（イクテュス）、善き羊飼い、ノアの箱舟など初期キリスト教のフレスコ画。殉教者の遺骨（レリック）を核として地下礼拝が行われた。

### 2.2 西欧中世カトリック：教会境内墓地（Churchyard）と骸骨堂
中世盛期〜後期において、死者は都市共同体から排除されず、**都市の中心部（市壁内）**に留まった。

- **教区教会（Parish Church）との同居**:
  信徒は自らが洗礼を受けた教区教会の境内（Churchyard）に埋葬される権利を持った。
  教会堂内部の祭壇近く、床下石板墓は聖職者や領主・大商人などの特権階層の席であり、一般庶民は教会の周囲の草地に埋葬された。
- **土地循環とシャネルハウス（Charnel House / 納骨堂）**:
  市壁内の限られた教会境内では数十年で土地が飽和する。そのため、肉体が土に還った頃を見計らって古い骨を掘り起こし、敷地の一角に建てられた**納骨堂（オッスアリ / カルネル）**の屋根裏や半地下に積み上げた。
  代表例：パリの**イノサン墓地（Cimetière des Innocents）**。周囲を囲む回廊の屋根裏に数万体の頭蓋骨と大腿骨が整然と積み上げられた。
- **説教十字架（Calvary）とイチイ（Yew）**:
  教会墓地の中央には石造の説教十字架が立ち、司祭が野外説教を行った。
  敷地の周囲には不老不死と復活の象徴であり、有毒ゆえに家畜の放牧を防ぐ**セイヨウイチイ**が植えられた。

### 2.3 東方正教会（Eastern Orthodoxy）
ビザンティン帝国、ロシア、ギリシャ、東欧の伝統。

- **木造建築と八端十字架**:
  ロシア・東欧の正教墓地では、白樺の木立の中に木造の切妻屋根付き八端十字架（下部の足置きが傾いた三段クロス）が林立する。
- **墓前祝宴儀礼（ラドニツァ / Radonitsa）**:
  復活祭（パスハ）の翌週、遺族は総出で墓地に集まり、墓前に敷物を広げて赤く染めたイースターエッグ、ピロシキ、クリーチ（パン）、ウォッカを飲食し、死者と共にキリストの復活を祝う。墓地は恐ろしい場所ではなく、生者と死者の交感の場である。

### 2.4 プロテスタント諸派の改革（Reformation）
16世紀の宗教改革は、墓地のあり方を空間的・神学的に根本から変革した。

- **教会内埋葬の廃止と市外移転**:
  マルティン・ルターやジャン・カルヴァンは、煉獄（Purgatory）の存在を否定した。死者のためのミサや免罪符が神学的に無意味となったため、教会内に遺体を埋める特権的慣行を「偶像崇拝」「不衛生」として糾弾した。
  ジュネーヴの**プレンパレ墓地（Cimetière des Rois）**のように、墓地は市壁の外や教会の外の世俗共同墓地へと移転された。
- **偶像破壊と平等の美学**:
  聖人の彫刻、祈りを促す十字架像、豪華な天使像は排除された。
- **ピューリタン（清教徒 / ニューイングランド）**:
  死の冷厳な事実と現世の儚さを強調する**「メメント・モリ（死を思え）」**のシンボル。スレート石板の墓標に、歯を剥き出しにした「有翼の頭蓋骨（Death's Head）」、砂時計、ツルハシとシャベルが彫られた。
- **クエーカー（友会徒）**:
  徹底した霊的平等主義に基づき、個人の顕彰を罪悪と見なした。墓石は完全に同一サイズの低い平らな石板のみ、あるいは名前すら刻まない完全な無標識芝生墓地を採用した。

### 2.5 19世紀近代：ヴィクトリア朝景観・田園墓地（Garden / Rural Cemetery）
産業革命期の爆発的な都市人口集中により、中世以来の市壁内教会墓地は破綻した（死臭が充満し、井戸水を汚染し、コレラ流行の温床となった）。

- **都市衛生改革と公営墓地令（1850年代）**:
  英国のロンドン埋葬法（Burial Acts）をはじめ、欧州各都市で市街地内の埋葬が法的に全面禁止された。
- **景観田園墓地運動の勃興**:
  郊外の広大な起伏ある丘陵地帯に、イギリス式風景庭園の手法を取り入れた広大な公園型墓地が建設された。
  代表例：パリの**ペール・ラシェーズ墓地（Père Lachaise）**、ロンドンの**「偉大なる七つの墓地（Magnificent Seven）」**（ハイゲイト墓地など）、ボストンのマウント・オーバーン墓地。
- **建築と景観**:
  ゴシック様式の壮大な礼拝堂、エジプト風オベリスク、ギリシャ神殿風家族霊廟、曲がりくねった散策路、外来種の樹木（レバノン杉など）。日曜日には市民がピクニックに訪れる都市の緑地レクリエーション空間となった。
- **コロンバリウムと火葬の復活**:
  19世紀末、衛生工学の進展と土地節約のため火葬運動（Cremation Society）が勃興し、近代的火葬場と骨壺を納めるコロンバリウム回廊が併設されるようになった。

## 3. イスラム教（Islam）

### 3.1 イスラム法（シャリーア）の基本埋葬原則
イスラム教の葬礼は、預言者ムハンマドの言行録（ハディース）に基づき、極めて簡素で迅速、かつ平等であることが求められる。

- **迅速な土葬（24時間以内）**:
  死後、遺体は近親者によって奇数回（3回以上）水と香油で丁寧に洗浄（グスル / Ghusl）され、縫い目のない純白の木綿布（カファン / Kafan）で包まれる。
- **キブラ（Qibla）への配向**:
  墓穴の底に側面の窪み（ラフド / Lahd）が掘られ、遺体は棺を使わず直接土の中に置かれる。遺体は**右脇を下にして横たえられ、顔を聖地メッカのカアバ神殿の方向（キブラ）**に向けられる。
- **華美な構造物の禁止思想**:
  正統な教義では、墓の上に建物を建てたり、石膏で固めたり、座ったりすることは禁欲的に諫められる。盛り土は地表から一握り（約20〜30cm）程度とし、雨風で自然に平地に戻るのが理想とされる。

### 3.2 スンニ派（Sunni）：郊外マクバラと厳格派
- **都市外壁外のマクバラ（Maqbara）**:
  ダマスカス、カイロ、バグダードなどのイスラム都市では、市壁の主要門（バブ）の外側に広大な共同墓地が広がった。
- **頭石と足石（Headstone & Footstone）**:
  長方形の土盛りの両端に、頭と足を示す2本の簡素な石柱が立つ。頭石にコーランの章句（「すべての魂は死を味わう」「神に属し神へ還る」）と故人の名前がアラビア文字カリグラフィーで刻まれる。
- **厳格主義（ワッハーブ派 / サウジアラビア）**:
  18〜20世紀に勃興したワッハーブ派は、聖者崇拝や偶像崇拝（シルク）を徹底的に排斥した。
  マディーナの歴史的な**ジャンナトゥル・バキー墓地（Jannat al-Baqi）**にあった預言者の家族や教友たちの豪華なドーム霊廟をすべて重機で平地化・破壊した。現代のサウジの墓地は、柵で囲われた砂利の平原に、名前も刻まない自然石が頭と足に置かれただけの究極の水平空間である。

### 3.3 シーア派（Shia）：聖廟都市と巡礼墓地
シーア派（特に十二イマーム派）では、歴代イマーム（預言者の血統）の霊廟の近くに埋葬されることで、審判の日にイマームの執り成し（シャファーア）を受けられると信じられる。

- **ナジャフのワディ・ウス・サラーム（Wadi-us-Salaam / 平和の谷）**:
  初代イマーム・アリーの廟が鎮座するイラク・ナジャフに広がる、**世界最大の墓地**。
  - 面積：約6平方キロメートル（東京ドーム約130個分）。
  - 埋葬者数：600万人以上。1400年以上にわたりイラク、イラン、南アジア、レバノンなど世界中のシーア派信徒の遺体が運ばれ埋葬され続けている。
  - 景観：乾燥した砂漠の平原に、無数の黄色の焼成煉瓦造りの墓柱、小さなドーム屋根、家族用の地下墓室（猛暑を避けるカタコンベ）が地平線の果てまで隙間なく密集する異形のメガ・ネクロポリス。
- **カルバラー（イマーム・フサイン廟）**:
  殉教の地カルバラーの聖廟周辺にも同様の大規模な巡礼墓地が発達。

### 3.4 オスマン帝国様式（Ottoman Empire）：街角のトゥルベとイトスギ
オスマン帝国下のイスタンブールやバルカン諸都市では、死は日常から隔離されず、都市景観の美的な一部として統合された。

- **トゥルベ（Türbe / 独立ドーム霊廟）**:
  スルタン、母后、大宰相、軍司令官の墓。モスク複合体（キュッリエ）の庭や、大通りに面した一等地に八角形や六角形のドーム石造建築として建てられた。通りに面して真鍮の透かし格子窓があり、通行人は歩きながら足を止め、窓越しに棺に向かって祈りを捧げることができた。
- **身分を象徴する彫刻墓石（Mezar Taşları）**:
  大理石の墓柱の頂部に、死者が生前に帯びていた地位を示す**「立体的なターバン（帽子）」**が精緻に彫刻された。
  - イェニチェリ軍団のフェズ帽、ウラマー（法学者）の平たいターバン、大宰相の巨大な卵型ターバン、スーフィー各教団特有の帽子。
  - 女性の墓標には、帽子ではなく美しい花束、バラ、ブドウ、果物の精緻な浮彫。
- **イトスギの並木（Cypress Groves）**:
  墓地には常に濃緑のイタリアイトスギが植えられ、木漏れ日と鳥のさえずりが満ちる「生者と死者が憩う緑の庭園」として親しまれた。

### 3.5 スーフィー聖者廟（Sufism / Qubba & Dargah）
北アフリカ（マグリブ）から南アジア（インド・パキスタン）にかけてのスーフィー文化圏。

- **クッバ（Qubba / 白いドーム廟）とダルガー（Dargah）**:
  奇跡を起こした聖者（ワリー / マラブー）の墓の上に、白漆喰で塗られた丸いドーム屋根の霊廟が建てられる。
- **巡礼と都市核の形成**:
  聖者の命日祭（ウルス / ムーセム）には数万人の巡礼者が集まり、音楽（カッワーリー等）や祈りが捧げられる。聖者廟を中心として周囲にバザール、宿坊、そして信徒たちの墓地が同心円状に拡大し、聖者廟自体が一つの都市核として機能する。
