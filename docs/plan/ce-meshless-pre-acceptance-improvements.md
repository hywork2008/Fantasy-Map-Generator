# メッシュなしCE 受入前の改善（2026-11-12の課題一覧）

2026-11-12。出典は`docs/temp/day-by-day/1112.md`の「CE メッシュなし」。ここに挙げた課題をすべて終えてから、[M9 受入と公開判断](ce-meshless-release-acceptance.md)の受入条件の確認に進む。

## 2. U0の結果（2026-11-12）

### 2.1 公園に施設が重なる

原因: 施設モードの施設は住宅より先に区画を取る（`placeFacilitiesOnLots`）が、公園の区（ward `park`）を除いていなかった。公園は住宅の後に「住宅の無い街区」を芝生にする（`layoutVectorParks`）。施設が取った区画の住宅は外されるので、施設の建つ街区も空きと判定され、施設の上に芝生が敷かれた。

再現: 3,000人・楕円の市壁・`medieval-facilities`の固定入力4件のうち、seed `b2`（仕立て工房、27 m²）と`c3`（織物工房、128 m²）で重なった。

修正:

- `placeFacilitiesOnLots`に施設を置かない街区の判定（`barredCell`）を加え、公園の区の区画を最初から使用済みにした。
- 公園の空きの判定に「施設の建つ街区でない」ことを加えた（二重の防御）。

修正後は4件とも重なり0、公園の数は修正前と同じ。回帰テストを`parks.test.ts`に1件加えた。

### 2.2 城門の両脇の塔の近くの塔

原因: 市壁の塔（`curtainTowersAlong`、間隔70 m）は、門の中心から市壁の厚さ×3の範囲だけを除いていた。門の両脇の塔（`gateMassesAt`）は門の中心から 開口/2＋厚さ×1.6 まで張り出すので、その外側すぐに市壁の塔が建つことがあった。

修正（メッシュなしの`renderers/vector/structureMassing.ts`のみ）: 門の両脇の塔の外縁と市壁の塔の外縁の間が、塔の通常の間隔の半分（35 m）より狭くなる塔を省く。メッシュありの同じ判定（`nearGate`）は変えていない。

テスト: `structureMassing.test.ts`に、市壁の塔と門の両脇の塔の頂点間の距離が30 mを超えることを加えた。修正前は28.7 mで失敗した。

### 2.3 市壁の内外の建物数・人口

生成パネルの完成都市の表示（段階「住宅と完成都市」）に、市壁の内／外の住宅の棟数、施設の棟数、人口、市壁内の人口の割合を加えた（`vectorWallShares`）。市壁の無い町では出さない。

- 内外の判定は、配置は外側の市壁の輪の内外、ファブリックの住宅は街区の`inside`。
- 人口は住民の割当て（配置が先、ファブリックの住宅が後、それぞれ市壁内が先）と同じ順に住戸を埋め、埋まった住戸に比例させる。郊外の帯は需要に関係なく建つ（P7a）ので、市壁外の棟数は人口の割に多く出る。

固定入力（合成・楕円の市壁・seed `c3`、区画の建築率100%）での値:

| 方式・人口 | 住宅 内／外 | 施設 内／外 | 人口 内／外（内の割合） |
| --- | --- | --- | --- |
| medieval 3,000 | 613／126 | 0／0 | 2,906／94（97%） |
| medieval-facilities 3,000 | 481／81 | 120／23 | 2,744／256（91%） |
| medieval-facilities 5,000 | 835／127 | 203／42 | 4,676／324（94%） |

この入力では市壁外の126棟のうち人の住む住戸は21戸だけで、残りは需要を超えて建った帯の住宅である。U2 では FMG の都市でも同じ表示で内外の比を見る。

## 3. 残る課題の初期調査

### 3.1 U1 門

- 門は道路・川が市壁の線と交わる所に置かれる（`pipeline.ts`の`gateWall`）。合成入力は街道の方位を等分にばらしている（`syntheticVectorInput`、3〜6本）が、FMGの都市は FMG の道路をそのまま取り込むので、同じ方位から来る2本が隣り合う門になる。
- 市壁の形の回転（48段）は、交わる角度20°以上と角からの距離だけを見ている（`wallCrossingsFit`）。門同士の間隔は旧市壁（`blocked`あり）でしか見ていない。
- 方針の案: 市壁の外で近い方位の街道を1本にまとめて1つの門へ入れ、門の本数を街道の交通量の順に決める。門の手前の区間は市壁の法線方向へ曲げて直角に通す。軍事の門の屈曲は、敵国へ向かう街道の識別（FMGの記述子の道路の情報）を確かめてから決める。

### 3.2 U4 郊外の街区

- 郊外の土地は街道に沿った帯（`raiseVectorRibbonLand`）として作られ、帯は道の曲がりごとの直線の片に分けて合成している。街区の分割は帯の形とは別に行われるので、帯が曲がっても街区は長方形のまま道を貫く。どこで長方形になるか（帯の分割か、街区の計画か）はまだ確かめていない。

## 4. 生成版
