# 副産物の値段を在庫と需要で決める

## 1. 背景

[byproduct-prices-20261111.md](../analytics/byproduct-prices-20261111.md)で、革（Leather）がほぼ全ての市場で基の値の3倍（上限）に張り付き、獣脂（Tallow）は在庫が4.7倍になっても動かないことを確かめた。長靴と革の品も、在庫が約1年分あるのに上限近くにある。値段で需要と供給を釣り合わせるという見直しの目的に反する。

## 2. 今の決まり

- 毎月の値付けは、セルに分布のある品・鉱山・炉の品（1つ目の段）と、作り方のある品（2つ目の段）だけを通す。家畜をつぶした時に出る革・獣脂・凝乳酵素（Rennet）は、どちらにも当たらない。
- 在庫に入る時は値段を動かさず、買われる時だけ上げる（`applyMarketPressure`）。
- 長靴・革の品の値付けの需要は`calculateGoodDemand`（町の人数 × 日用品の割合）で、町が買う量の目標（`householdPurchase`の較正の行）と別である。

## 3. 決める仕組み（案）

### 3.1 副産物を1つ目の段に

- 作り方もセルの分布も無く、つぶした家畜か狩りから出る品（革・獣脂・凝乳酵素）を、1つ目の段で値付けする（`getRawGoodTargetPrice`：基の値 ×（需要+5）÷（在庫+5）、下限0.25倍・上限3倍）。
- 需要は、市場の月の材料の需要（その品を材料に使う品の、町の目標の量 × 材料の量）と、市場の家の需要の和とする。
- 買われる時の値上げ（`applyMarketPressure`）は、ほかの毎月値付けされる品と同じに残す。

### 3.2 町が目標を買う品の需要

- 較正の行に`householdPurchase`がある品（長靴・革の品・蝋燭）は、2つ目の段の需要を、町が買う量の目標（`getCalibratedMonthlyLots`の市場の合計）とする。

### 3.3 設定

- `byproductPricing`: `stockAndDemand`（既定、3.1と3.2）か`legacy`（今の決まり）。

## 4. 見込み

- 革は、出る皮（2102で月約24万）に対し、材料の需要（月約5万）と在庫（91万）から、下限の0.25倍まで下がる。長靴の元値も約1/12になり、長靴・革の品の値段は、在庫が需要より多い市場で基の値の0.25〜1倍に下がる見込みである。
- 町が上限の値段で買っていたお金（2102で年約570万の見積もり）が大きく減り、町の家計と金庫の減りが止まる見込みである。
- 獣脂も下限に向かう。蝋燭・石鹸の元値が下がる。

## 5. 計測の計画

北緯30°の地図2枚（2102・2103）、36か月、戦争なし・隊商の略奪なし。[footwear-capacity-20261111.md](../analytics/footwear-capacity-20261111.md)と比べる。

1. 革・獣脂・長靴・革の品の、在庫の重みを付けた値段と在庫。
2. 町の家計・町の金庫・農村の家計・市場のお金。
3. 長靴・革の品・蝋燭・石鹸の作った量と買った量。

## 6. 未確定事項

1. 値段が下限に張り付いた副産物の捨て方（在庫の上限）。下限でも需要より多い分は、傷み・捨てる仕組みが要る（[household-goods-pay-20261111.md](../analytics/household-goods-pay-20261111.md) §5の2）。
2. 家畜の値段に、副産物の値段を返すか（皮と獣脂が安いと、つぶす値打ちが下がる）。
3. 測りの値段を、在庫で重みを付けた値に直す（goods.mts）。

## 7. 結果

[byproduct-pricing-20261111.md](../analytics/byproduct-pricing-20261111.md)。値付けだけを変えた初めの版では、靴屋が革を買うたびの値段の押し（`applyMarketPressure`）が月の値付けを打ち消し、革は上限の3倍に残った。そこで、`stockAndDemand`の時は、副産物と町の目標で買う品（`isPricedByTownTargets`）を、売り・買い・交易の押しから外した（エールやワインと同じ扱い）。これで革・獣脂・長靴・革の品は下限近くまで下がり、長靴と革の品は約2.5倍作られ、町の家計の減りは約7割から約5割になった。革と獣脂の在庫はまだ積み上がる（§6の1）。
