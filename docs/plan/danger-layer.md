# 脅威度（Danger Layer）およびモンスター実装の完了

計画に基づき、ダークファンタジー世界向けに人口分布へ影響を与える「脅威度」レイヤーとモンスターの実装を完了しました。

## 実装内容

### 1. データ構造の拡張 (State Layer)
- `src/types/models.ts` に `Monster` インターフェースを追加しました。
- `src/types/PackedGraph.ts` の `PackedGraph` に `monsters: Monster[]` を追加し、`PackedGraphCells` に各セルの脅威度を保存するための `danger: TypedArray` を追加しました。

### 2. 生成ロジック (Generator Layer)
- `src/generators/threats-generator.ts` を新規作成しました。
  - 世界のカルチャーセットが "darkFantasy" の場合にのみ作動します。
  - モンスターをレアリティ（1〜5）に応じて生成します。レアリティ5の「Calamity（災厄）」クラスは世界に1〜2体発生し、広範囲に高い脅威度（power: 50）を及ぼします。
  - レアリティに応じた数のモンスター（Beast, Greater Monster, Arch-Beastなど）が配置され、周辺のセルに対して距離減衰しながら脅威度を伝播させます。
- `src/main.ts` の `rankCells` に処理を組み込みました。
  - 算出された `danger` の値に基づいて、セルの居住適合度（`packCells.s`）を減衰させる処理を追加しました。これにより、脅威度の高いエリアの人口（`packCells.pop`）が伸びにくくなります。

### 3. 描画・UI処理 (Renderer / Editor Layer)
- `src/renderers/danger-renderer.ts` を作成し、脅威度のヒートマップを描画する仕組みを追加しました。D3の等高線（`contourDensity`）を用いて、ダークファンタジーにふさわしいMagmaカラーマップで描画します。
- `src/initViewLayers.ts` と `src/context/viewContext.ts` に `<g id="danger">` SVGレイヤーを追加しました。
- `src/store/layerState.tsx` と `src/controllers/layers.ts` を更新し、レイヤーパネルに「Danger」トグルを追加しました。これにより、UIからいつでも脅威度マップを表示・非表示に切り替えられます。

## 将来の拡張性について
`Monster` のデータとして `type` や `power`、`rarity` を定義して配列として保持しているため、将来的にMarkerやEncountersシステムと連動させる準備が整っています。

## セッション2: Dangerレイヤーの調整

Calamity級のモンスターがDangerレイヤーの最も濃い部分（一番危険な場所）に配置されない理由は、**現在の脅威度（Danger）の計算式と、ランダム配置による「重複」の仕様**にあります。

具体的には `src/generators/threats-generator.ts` において、以下の3つの要因が絡んでいます。

1. **脅威度は「足し算」で蓄積される（上限255）**
   各モンスターが周囲のセルに及ぼす脅威度は単純に加算されていき、最大255でストップします。
   `cells.danger[cell] = Math.min(255, cells.danger[cell] + d * 4);`

2. **Calamityの広大すぎる影響範囲**
   Calamity級は `power`（伝播距離）が `50` に設定されています。半径50セルというのは、1万セルのマップにおいては**マップの半分以上を覆い尽くすほどの広大な範囲**です。
   Calamity自身の中心地点での脅威度は `50 × 4 = 200` と高いですが、範囲が広すぎるために「マップ全体を底上げする広大な高原」のような役割になってしまっています。

3. **下位モンスターの密集による局所的なピークの発生**
   マップ上には Arch-Beast(power 30) や Greater Monster(power 20)、Beast(power 5) が合計で数十体ランダムに配置されます。
   もしこれらが偶然数体近くに密集すると、それぞれの脅威度が足し合わされ、`120 + 80 + 80 = 280 (上限255)` となり、簡単に最大値に到達してしまいます。

**結果として：**
Calamityがポツンと単独でいる場所（脅威度200）よりも、「中〜小型モンスターが偶然密集している場所」（合算されて脅威度255）の方が色が濃くなってしまい、「一番濃い場所にCalamityがいない」という状態が起きています。

## セッション3: Dangerレイヤーの調整2

**解決案**
「より強力なモンスターがいる場所ほど、確実に色が濃くなる（危険になる）」ようにしたい場合、以下のような修正が考えられます。

* **案1: 足し算ではなく「最大値（MAX）」を取るようにする**
  複数のモンスターの影響範囲が重なった場合、数値を足すのではなく「一番高い数値を採用する」仕様に変更します。これにより、小型の群れがCalamityの脅威度を超えることがなくなります。
  また、Calamityの中心が最大値(250)になるように乗数を調整します。
  ```typescript
  cells.danger[cell] = Math.max(cells.danger[cell], Math.min(255, d * 5));
  ```

* **案2: 距離の減衰を非線形（指数関数など）にする**
  影響力を単なる引き算ではなく、中心地だけが極端に高く、離れると急激に減衰する計算式にします。これにより、Calamityの中心だけが鋭く255のピークを描くようになります。


## セッション4: D&D 脅威度への換算

ご提示いただいた `src/generators/threats-generator.ts` のコード（影響範囲を表す `power` の値）と、「Rarity 3でも半径数十キロの人口をゼロにする」という設定から、**D&D（ダンジョンズ＆ドラゴンズ第5版）の「脅威度（CR: Challenge Rating）」**に当てはめると以下のようなスケールになると考えられます。

FMG（Fantasy Map Generator）の1セルは半径数キロ〜数十キロ（広大な面積）を持つため、その領域の人口をゼロ（居住不可）にする存在は、D&Dの基準で見てもかなり高レベルな「地域そのものを変異・破壊するモンスター」に該当します。

---

### Rarity 5: Calamity (災厄)
**想定D&D 脅威度 (CR): 25〜30+ （神格・エピック級）**
*   **設定上の特徴:** `power: 50`。コードに `Unkillable / Multi-state alliance required`（討伐不可 / 複数国家の同盟が必要）とある通り、世界の存亡に関わる歩く自然災害です。
*   **D&Dの代表例:** テラスク（CR 30）、ティアマトやバハムートといった神々のアバター、最強クラスのデーモン・ロード。
*   **解説:** 単一の英雄パーティーでは到底太刀打ちできず、複数の国家が軍隊と魔術師を総動員してようやく足止めできるかどうか、というレベルです。大陸の半分を不毛の地へと変える影響力を持っています。

### Rarity 4: Arch-Beast (大魔獣)
**想定D&D 脅威度 (CR): 17〜24 （第4階梯：世界のマスター）**
*   **設定上の特徴:** `power: 30`。コードでは `Regional bosses`（地域ボス）とされています。
*   **D&Dの代表例:** エインシャント・ドラゴン（古竜）、クラーケン、リッチ、ピット・フィーンド。
*   **解説:** 一つの王国や広大な地方全体を壊滅させ、支配する力を持っています。D&Dにおいても、このクラスのモンスターは「地域効果（Regional Effects）」を持ち、巣から数マイル〜数十マイルにわたって天候を荒れ狂わせたり、大地を毒の沼に変えたりするため、必然的に一般人は住めなくなります。

### Rarity 3: Greater Monster (上位モンスター)
**想定D&D 脅威度 (CR): 11〜16 （第3階梯：領域のマスター）**
*   **設定上の特徴:** `power: 20`。「半径数十キロのセルの人口をゼロにする」影響力。
*   **D&Dの代表例:** アダルト・ドラゴン（成竜）、ビホルダー、ヴァンパイア、パープル・ワーム。
*   **解説:** 巨大な森、山脈、あるいは一つの都市国家そのものを根城にし、周囲数十キロの村落を全滅・放棄させる存在です。一般兵の軍隊では犠牲が大きすぎるため、国家が熟練の冒険者を雇ってようやく討伐できるレベルです。Rarity 3の時点で、すでに人間社会にとって致命的な脅威です。

---

#### （参考） Rarity 1〜2: Beast (獣・下位モンスター)
**想定D&D 脅威度 (CR): 1〜10**
*   **設定上の特徴:** `power: 5`。`Background threats`（背景的脅威）。
*   **D&Dの代表例:** オーガ、トロール、マンティコア、ダイア・ウルフなど。
*   **解説:** 一つの村や街道を脅かす程度の存在。影響範囲は限られていますが、それでも一般の農民にとっては恐ろしいモンスターであり、駆け出し〜中堅の冒険者が対処する相手です。

### まとめ
「半径数十キロの人口をゼロにする」という事実から逆算すると、**Rarity 3の時点で「一個師団の軍隊を単騎で蹂躙できる強さ（CR 11以上）」**を持っていると解釈するのが最も自然です。

Rarity 3〜5のモンスターは単なる「強い敵」ではなく、その存在自体が周囲の環境を汚染・破壊し、一般人の生存を許さない**「環境災害（ハザード）そのもの」**として機能していると言えます。まさにダークファンタジーにふさわしい、絶望的な設定スケールです。
