# 余った蜜蝋を蝋の地代・十分の一税として教会に納める

## 1. 背景

[wax-pricing-20261114.md](../analytics/wax-pricing-20261114.md)で、蜜蝋を在庫と需要で値付けすると、需要より在庫の多い市場は全て下限（0.25倍）になった。それでも在庫は年約1,300個（地図2102、採れる量の約13%）増え続ける。蜜蝋は傷まないので、皮・獣脂の傷む決まり（[byproduct-disposal.md](byproduct-disposal.md)）は当てはまらない。

## 2. 史料

- 中世のドイツ・低地地方には、教会に毎年決まった量の蝋を納める「蝋の地代を払う人」（Wachszinsige, cerocensuales）がいた。納めた蝋は祭壇の灯りに使われ、市場には出なかった。
- 蜂の巣の十分の一税（蝋と蜂蜜）も教会に納められた。1407年の Bexley の遺言では、灯りを保つために蜂を教会に遺した（[church-wax.md](church-wax.md) §2）。
- 奉納の蝋燭（願掛け・巡礼）は、蝋が安い年ほど多く灯された。

## 3. 決める仕組み（案）

- 毎月、全ての市場で、蜜蝋の在庫のうち使い道の`waxKeepMonths`か月分（既定12）を超えた分の`waxTitheRate`（既定0.1）を、教会への蝋の地代・奉納として在庫から出す。お金は動かない（納める人は蝋で払う）。
- 使い道は、港の積み出しで使う市場ごとの月の使い道（`byproductExport.ts`の`updateUse`）をそのまま使う。
- 流れの分類は`waxTithe`とする。
- 設定`waxSurplus`: `tithe`（既定）か`keep`（今の決まり）。`waxKeepMonths`（0〜60）、`waxTitheRate`（0〜0.5）。

## 4. 見込み

- 在庫が使い道の1年分を超えた市場だけで減るので、蝋燭屋の材料は減らない。在庫の増えが止まり、使い道の1年分あたりで止まる。
- 値段は下限のままか、少し上がる。

## 5. 計測の計画

北緯30°の地図2枚（2102・2103）、36か月、戦争なし・隊商の略奪なし。`waxSurplus`の`keep`（[wax-pricing-20261114.md](../analytics/wax-pricing-20261114.md)の新しい決まりの出力）と`tithe`を比べる。

1. 蜜蝋の在庫・値段、教会に納めた量。
2. 蝋燭の材料・作った量・積み出し。
3. お金。

## 6. 未確定事項

1. 蝋を納める先（教会・修道院）の置き場所。今は市場の在庫から消えるだけ。
2. 蜂蜜の十分の一税。

## 7. 結果

[wax-tithe-20261114.md](../analytics/wax-tithe-20261114.md)。36か月では、在庫が使い道の12か月分を超え始めた地図2102の一部の市場だけで納められ（3年目に406個）、3年目の在庫の増えは年約1,340から約980に減った。2103は12か月分に届く市場が無く、効きは出ていない。蝋燭の材料・値段・お金は変わらない。長い年月では、市場の在庫が使い道の約1年分で頭打ちになる上限として働く。
