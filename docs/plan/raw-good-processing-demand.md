# 生の産物の値段に、加工で使った量を入れる (Raw Good Processing Demand) 設計

2026-11-18 設計。[raw-floor-20261118.md](../analytics/raw-floor-20261118.md) §2の2の対応。

## 状態

- 実装済み（2026-11-18）。計測は [rural-income-20261118.md](../analytics/rural-income-20261118.md) §6。羊毛は値の0.30 → 0.56、亜麻0.57 → 0.77、家畜は0.25 → 0.53〜0.69。農村の収入は増えない。`src/simulation/__golden__/node.json` を更新、browser.json は未更新。

## 1. 問題

- 生の産物（`good.distribution` のある品）の値段は、値 × (需要 + 5) ÷ (在庫 + 5) で、下限（値の0.25）から上限（3倍）までに収める（`getRawGoodTargetPrice`）。
- 需要（`calculateGoodDemand`）は、町の人口 × 品ごとの係数と、農村の布の注文の材料で、町の工房が作り方で実際に使う量を数えていない。
- 地図2103で、羊毛は在庫が1か月分（433ロット、使う量479ロット/月）に満たないのに、値段が値の0.30だった。亜麻（0.57）・麻（0.88）も同じ形の可能性がある。

## 2. 変更

- 作り方が市場の在庫から生の産物を使った量（`recipeInput` の流れ、町の工房と農村の機織りの両方）を、市場ごと・品ごとに数える（`market.rawProcessingUse`）。
- 値段を決める時に、需要 = max（今の需要, 前の値段の決め以降に使った量）とする。和にしないのは、今の需要に農村の機織りの注文が入っていて、二重に数えるため。数えた量は値段を決めた後に0に戻す。
- 羊毛は、立っている群れから刈る品で、土地の分布（`distribution`）も作り方も無い。そのため生の産物の値段の決めに入らず、売り買いの押し（`applyMarketPressure`）だけで値の0.30まで下がっていた。`withProcessingUse` の時は、羊毛も同じ決めに入れる。
  - 同じく分布も作り方も無く、作り方の材料になる品（オリーブ・葡萄・硫黄・軽石など）は、まだ入れていない（§4）。
- 設定 `rawGoodDemand`: `withProcessingUse`（新、既定）/ `modelOnly`（今の決まり）。

## 3. 見込み

- 羊毛・亜麻・麻の値段が値に近づく。羊毛を使う町の工房と農村の機織りの材料費が上がる。
- 農村の収入への効きは小さい（羊毛の売りは年数万）。農村の収入の多くは主食の売りで、主食の値段の下限は別の課題（[raw-floor-20261118.md](../analytics/raw-floor-20261118.md) §2の4）。

## 4. 未確定事項

- 分布も作り方も無い他の材料の品（Olives・Grapes・Plums・Figs・Pomace・Sulfur・Volcanic Ash・Pumice など）の値段の決め方。穀物・金属の延べ棒・副産物・果物・牛乳は、別の決まりで値段を決めている。
