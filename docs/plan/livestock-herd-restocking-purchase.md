# 群れの不足を市場からの買い入れで補う（2026-10-28）

親計画: [historical-economy-production-consumption-circulation.md](historical-economy-production-consumption-circulation.md) §7.72（E1-5）。

## 1. 背景

Worldの144か月の計測（§7.72、[記録](../analytics/e1-herd-cells-20261028.md)）で、牛のセルは二つに分かれた。

- 収容力に達したセル（収容力の約52%）。自然増を毎月市場へ出荷している（牛で年約19万頭、§7.70）。
- 収容力の0.6倍未満のセル（収容力の約45%）。最初の年次更新で、土地利用が整う前の小さい草地をもとに群れが置かれ、その後に草地が約13倍に広がった。出荷はなく、群れは自然増の上限（牛年19.3%、馬年15.0%）でしか増えない。

現在、新しく広がった草地を埋める手段は自然増だけである。史実では、開墾地や新しい保有地の家畜は家畜市・定期市で買い入れて揃えた。このため、収容力を下回るセルの農家が地元の市場から家畜を買う流れを加える。初期化のやり直し（家畜を無から作る）は採らない。

## 2. 目標と完了条件

- 群れの不足の大きいセルが、出荷のあるセルの売った家畜を買い入れて、数年で収容力に近づく。
- E1-5の収束判定（§7.41）: World 144か月で、牛・馬・羊の頭数が収容力の±10%以内、収容力超過10%未満。
- 家畜・現金の保存則: 市場の在庫の減少＝群れの増加（実頭数で）、農村の財布の減少＝市場の会計の受取。家畜は無から作らない。
- 飼料不足（直近12か月）・農村の主食・耕地/人が、§7.71の値（2.4%・98.9%・2.19ha）から悪化しない。
- 地元の市場の家畜の価格が、買い入れで暴騰し続けない（年平均で変更前の2倍未満を目安とする）。

## 3. 買い入れの仕組み

### 3.1 誰が、いつ買うか

- 買い手は、セルの群れの飼い手（農村の世帯）。対象は放牧の群れ（`isGrazedLivestockGood`）。庭先の家畜（豚・鶏）は対象外とする。
- 買う条件: 1月の年次更新の後の頭数が、そのセルの収容力の`RESTOCK_THRESHOLD`（案0.9）倍を下回ること。出荷の条件（頭数＋自然増＞収容力）を満たすセルは買わない。同じセルが同じ月に売りと買いをしないことをこれで保証する。
- 時期: 春の家畜市（4〜5月）に限る案を第一とする。冬を越す飼料は収容力（冬の制限、§7.45）で決まっているので、冬の前に頭数を増やしても飼料は足りる。月ごとに少しずつ買う案は、出荷との順序の問題が増えるため採らない。

### 3.2 何頭買うか

- 1年に買う上限は、収容力との差（収容力×`RESTOCK_THRESHOLD`−頭数）に`RESTOCK_ANNUAL_SHARE`（案0.5）を掛けた頭数。1年で埋めずに2〜3年かける。急な買い付けで価格が跳ねるのを避け、史実の段階的な揃え方にも合う。
- 市場の在庫（実頭数＝市場単位×`animalsPerMarketHead`）と、農村の財布（`getRuralHouseholdWealth`）の`RESTOCK_WEALTH_SHARE`（案0.2）を超えない。
- 同じ市場の複数のセルが買う場合は、不足頭数に比例して在庫と予算を分ける。セルの順番で先着にしない（結果がセルの並び順に依らないようにする）。

### 3.3 買った家畜の年齢層

- 家畜のロット台帳（`livestockLots.ts`）に出所の年齢層（`cohortHeads`）があるロットは、その年齢層で群れに加える。
- 年齢層の不明な分は、繁殖用として加える。買い入れの目的は群れを増やすことで、史実でも若い雌牛・繁殖用の家畜を買ったため。老いた家畜は買わない（市場の老いた家畜は屠畜・食肉向けに残る）。
- ロットの所有を市場からセルの群れ（所有者 `herd:<cell>`）へ移し、所在をセルにする（`moveOwnedLivestock`の考え方）。群れに入った時点でロットは群れの年齢層に合流し、以後はロットとして追わない。

### 3.4 支払いと記録

- 価格は市場の買値（`customerBuyPrice`相当）。支払いは農村の財布から引き（`debitRuralHouseholdWealth`）、市場の会計（`marketTreasury.balance`）が受け取る。`buyMarketGoods`のBurg宛ての処理とは分け、買い手をセルにした専用の処理にする（農村はBurgに属さないため）。
- 財の流れの記録（`recordGoodFlow`）に区分`herdRestock`を加える。出荷（source）と買い入れ（sink）を分けて集計できるようにする。
- 遠方の市場からの買い付けは行わない。地元の市場の在庫は、既存の市場間の交易で動く。

## 4. 影響と注意点

- 出荷のあるセルの家畜を、不足のセルが買うことになる。今は市場に出た家畜は屠畜・羊毛の材料などに使われているため、その分の肉・皮・羊毛の供給が減る。計測で確かめる。
- 価格の上昇は出荷のあるセルの収入になる。財布の上限（3.2）で農村の購買力を超えないようにする。
- 不足のセルの群れが増えると、そのセルの飼料・干草の人手が増える（§7.63〜§7.66）。飼料不足の悪化を見張る。
- 羊は全体で収容力に達しているが、セルごとには下回るセルがあり得る。羊も同じ規則で買うが、羊の超過（§7.71で8.3%）を増やさないことを確かめる。
- 簡易モード（`ruralEcosystemDetail` が `simplified`）では群れを追わないため、買い入れも動かさない。

## 5. 段階

| 段階 | 内容 | 完了条件 |
| --- | --- | --- |
| P1 | 計測のみ。春の時点で、セルごとの不足頭数、地元の市場の家畜の在庫（実頭数）、農村の財布を記録し、買い入れの上限がどれで決まるかを見る（コードの振る舞いは変えない） | 市場ごとに、不足頭数に対する在庫・予算の比が分かる |
| P2 | 3章の買い入れを実装する。定数（`RESTOCK_THRESHOLD`・`RESTOCK_ANNUAL_SHARE`・`RESTOCK_WEALTH_SHARE`）はP1の結果で決める | 単体テスト: 保存則（頭数・現金）、売りのセルが買わない、並び順に依らない比例配分、簡易モードで動かない |
| P3 | World 144か月で2章の完了条件を確かめる。羊・肉・羊毛の供給と価格の変化も記録する | 2章の条件を満たす。満たさない場合は原因を記録し、定数か仕組みを見直す |

## 6. 未確定事項

- 春の家畜市の月（4〜5月）を地域・気候で変えるか。最初は全域で同じとする。
- 地元の市場に在庫がない場合に、隣の市場から買い付ける（家畜追いの移動）か。最初は行わず、P3で不足が残る市場を確かめてから決める。
- 初期化（`rebaseGrazedHerdsToDemandScale`）の時期のずれ自体（§7.72の案1）は、この計画では直さない。買い入れで埋まらない場合に改めて検討する。
