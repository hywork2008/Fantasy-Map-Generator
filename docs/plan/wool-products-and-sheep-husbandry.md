### 3.1 共有面積の重複要求がある

`getGrazedCarryingCapacity`は同じ`pastureAreaUsed`に、牛0.5・馬0.4・羊3・山羊2.5・ラクダ0.15頭/haを**種ごとに独立に**掛ける。`calculateHusbandryDemand`も各種が全面積を使える前提で牧夫需要を合算する。

監査の「面積要求」は各セルで`Σ(実頭数 / 種別のモデル密度)`を計算したもの。例えば100 haに羊300頭・牛50頭・山羊250頭を同時に置けば、個別の上限は満たしても300 haを要求する。12か月後の最大例はコードの面積要求で約4.96倍だった。

これはコード自身の基準に照らした重複要求の診断で、実測の過放牧率ではない。複合放牧の補完性、休閑地・林間放牧・冬飼料、年次の群れと牧草地の調整速度は別途扱う。それでも種ごとに同じ土地を無制限に再使用する現在の定式化は修正対象になる。

近年追加された土地台帳の`resolved-livestock-land`は、維持する牧草地面積を与える。**土地の区画が重複していないことと、その面積から種別の飼養上限を重複計算しないことは別**である。台帳導入だけでこの問題は解消していない。

### 3.2 採毛量は頭数・年齢・労働・市場供給を分ける

現在は全年齢の羊に月0.08枚、1枚1.5 kg、すなわち労働充足時に年1.44 kg/頭を平滑供給する。新生仔・成羊、実際の毛刈り季節、品種・原毛/洗毛の区分は持たない。生後1年未満の全個体に成羊と同じ採毛量を与える点は見直す。

今回の頭数と出力から逆算した労働充足相当は5〜6%。台帳で維持する放牧面積・既存の群れと、現在の採毛を賄う労働は一致していない。頭数×1.44 kgをそのまま市場供給量と比較しない。

BiddickのPeterborough研究には群れの推計に平均1.25 lb/枚を使う箇所があり、現行の1.5 kgより小さい比較例となる。ただし推計用の平均・地域・時期・羊毛の状態を確認してから校正に使う。ヨーロッパ全体の固定値へ置き換えない。[Biddick, The Other Economy](https://publishing.cdlib.org/ucpressebooks/public/book/the-other-economy-pastoral-husbandry-on-a-medieval-estate.html)

### 3.3 在庫増は全人口に対する羊毛過剰の証明にはならない

12か月の羊毛の市場流入は714.175 t、記録された材料購入は0.313 t。既存在庫59.160 tから773.229 tへ増えた。一方、両一般衣服の更新需要は2,301.179 lotに対し家計消費44.151 lot、**約1.92%**だった。1 lotは1,000人分であり、この地図では年約230万人分の更新需要に対し、約4.4万人分しか消費していない。

この更新需要を全て4 kg/揃いの一般衣服と仮定すれば製品約9,205 t/年で、全て軽い亜麻布衣服としても約4,970 t/年になる。どちらも素材構成を決める試算ではなく、都市の実製造・市場消費と全人口の必要量の桁が違うことを示すもの。農村の自家紡績・織布・仕立てと都市への加工委託を含む供給能力の確認が必要である。

市場流入714 tを捨てるために商品需要を作るのではなく、この実人口の必要量・実際に買える量・家庭内生産を先に対応させる。今回の1人約1頭という羊比率だけから全世界の群れを過大と認定しない。

在庫は市場のみで倉庫・輸送中・都市内材料を含まない。市場流入・引落しと末在庫には既存の丸め/記録差もあり、完全な世界の物量台帳ではない。多数のシードや期間・技術の違う地図での一般化はしていない。

## 5. 牧羊量を見直す順

1. `sum(heads / density)`を共有面積と照合する診断を維持し、種別に牧草地・飼料を配分する。牛・羊・山羊等の全種に各々100%を与える計算を解消する。
2. 牧草地の維持・休閑地・林間放牧・乾草・冬期飼料を一度ずつ計上し、通年の飼養可能頭数を出す。羊用面積だけ削って他種や耕地との重複を隠さない。
3. 実際の群れと牧夫の人数・犬・季節仕事を対応させる。面積の維持と採毛・給餌に使える労働を区別し、従事者の必要量を種別配分後の頭数から求める。
4. 年齢・品種・時代・地域に応じる毛刈り可能頭数と年間原毛kgを定義する。既存Wool 1 lot=1.5 tの変更と生産性の校正は別の移行とする。
5. 羊を肉・乳・皮・堆肥・繁殖・羊毛の複合生産として評価し、需要と飼料が支える群れへ段階的に調整する。係数変更時に既存動物を即座に大量削除しない。
6. 製品追加、共有土地修正、採毛校正、農村の加工供給を別条件で比較し、羊毛在庫・衣服/寝具不足・乳肉供給・牧夫賃金・交易への寄与を区別する。

Wool Blanketsを追加し、衣服とは独立した寝具更新を都市・農村の実購入へ接続した。古代から使用可能とし、中世技術などの解禁条件は設けない。以下の数値はすべて**モデル仮定**であり、古代ローマや中世の実測値ではない。

| 項目 | 採用値 |
| :--- | :--- |

| 原料 | Wool Cloth 250 / 0.95 / 4,000 lot（布263.158 kg、仕上げ歩留まり95%） |

| 家計予算 | 各都市財布・農村財布の現金残高の5%を、その月の衣服・寝具の共通上限とする |

- Wool Clothからのみ製造し、安い麻・綿への置換は行わない。労働・職業配分・ギルド領域・物性・輸送枠・日英名を登録。既存Garmentsの職業内配分を内陸・港とも0.02ずつ毛布へ分け、織物領域の配分合計を維持した。
- 毛布の`demandCoverage`は空にし、衣服一式の需要や都市の一般消費からは引き落とさない。製造候補・製造実行の両方を支払可能な寝具注文と市場/都市内在庫で制限し、交易・価格計算も寝具の独立した注文を参照する。通常衣服も市場実行時の交易需要・製造余地・ギルドの注文判定を家計の支払能力で制限する。
- 都市は既存のBurgMarketLedger.householdWealth、農村は既存のFoodLedger.ruralHouseholdWealthから支払う。片方の不足をもう片方の財布で肩代わりしない。既存の初期資金処理を利用し、毛布用の追加資金は作らない。財布や商品がない部分カタログでも無料消費へ戻さない。
- 同じ5%枠から衣服を先に購入し、その必要額を除いた予算で毛布を購入する。衣服が欠品しても、その確保額を寝具へ使い回さない。商品の購入予算は市価を使い、衣服の素材代替は安い在庫から、少ない在庫は各財布の未充足・支払可能注文に比例配分する。
- 支払いを通貨の小数第2位で切り下げてから消費量を求める。各家計の減額とmarketTreasury.balanceへの入金を一致させ、対応する市場在庫だけを減らして`householdTextiles`へ記録する。都市財政に全農村分を負担させない。小額すぎて支払えない残量も無料消費にしない。
- 衣服のtextileLedgerと寝具のblanketLedgerを分離し、必要量・実消費・不足・都市/農村の実消費・支出と累計支出を保存する。旧台帳に追加項目がなければ累計支出0から開始する。通常の市場オブジェクト保存を使用する。`migrateWoolBlanketGoods`は既存Wool Clothの保存IDでレシピを解決し、追加済み商品・編集レシピ・価格・在庫は維持する。
- 羊毛監査スクリプトも衣服と毛布の消費lotを商品IDで分離した。毛布100枚と衣服1,000人分を同じ更新量として集計しない。寝具必要量・消費・各支出も観測する。

制限: 家庭ごとの実所有在庫や引越し、更新不足の繰越はまだ持たず、所有目標から定常更新量を計算する。家計予算5%は食費を含む年間実測家計から校正した値ではなく、食糧決済前に現金を使い切らないための暫定上限。既存の一般サービス支出も残るため、家計全体の支出構成は今後の校正対象。現段階の農村供給は都市工房と市場交易からの購入であり、家庭内加工・加工委託の新規供給は未実装。都市の既存加工上限を全農村人口の更新需要に合わせて引き上げたわけではない。実地図での長期需給比較は未実施で、衣服・寝具不足や羊毛滞留の解消は判定しない。
