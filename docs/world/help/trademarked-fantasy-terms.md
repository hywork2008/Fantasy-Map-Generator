# ファンタジー用語の商標・著作権リスク早見表

種族名・アイテム名・モンスター名など、本プロジェクトの生成コンテンツ（マップの種族、Goods、ダンジョン/モンスター名など）で使う固有名詞のうち、商標・著作権上の使用リスクがある語をまとめる。きっかけは [ミスリルが使えなくなるとか言う話が出てたけどホントにやばかったのはD&D｜みし](https://note.com/mith_mmk/n/n0fcf59b98ce1) の指摘（映像化・ゲーム化ではミスリル等の権利が確保されているが小説ではOK、リッチ・トレント等のD&D発モンスター名もNGという主張）。本ドキュメントではその主張を一次情報（トールキン財団/ミドルアース社の商標登録、WotCのOGL Product Identity リスト、実際に改名が起きた事例）で裏取りし、**記事の主張のうち事実と食い違う部分を修正した上で**整理する。

法的な助言ではなく、創作上のリスク回避のための実務メモである。最終判断が必要な場合は法務相談を推奨する。

---

## 1. 権利構造は2系統ある

| 権利者 | 対象 | 及ぶ範囲 |
| :--- | :--- | :--- |
| **トールキン・エステート／トールキン・トラスト** | 『指輪物語』『ホビットの冒険』等の文芸著作権 | 文章そのものの複製・翻案。個々の固有名詞（単語そのもの）はこの著作権では通常保護されない |
| **ミドルアース・エンタープライズ社**（旧 Tolkien Enterprises／Saul Zaentz Company から派生、2022年に Embracer Group が買収） | 映像化・ゲーム化・商品化の**商標**（`Middle-earth`, `Mithril`, `Balrog`, `Orc` 等多数を USPTO に登録） | **商業利用（映像・ゲーム・グッズ等の"商品/サービス区分"での使用）**。小説の地の文で一般名詞的に使う分には商標の「商業上の使用」に該当しにくく、行使のハードルが高い |
| **Wizards of the Coast（Hasbro）** | D&D オリジナルのモンスター名・固有名 | Open Game License（OGL）で公開した SRD のうち、明示的に **Product Identity（PI）** と指定した語は非公開のまま。第三者作品での無断使用は避けるべきとされる |

`note.com` 記事の「映像化・ゲームでは権利確保、小説はOK」という整理は、**この2系統の混同ではなく実際に成立する区別**である。ミドルアース社の商標は USPTO 登録上「ビデオゲーム」を含む商品/サービス区分を持ち（[Trademarkia: MITHRIL](https://www.trademarkia.com/mithril-87261001)、[Middle-earth Enterprises Licensing](https://www.middleearth.com/licensing)）、ゲームというメディアはまさにその行使対象に含まれる一方、小説の地の文で「ミスリル」という一般名詞的な単語を使うこと自体は、商標法上の「商業上の使用（商品・サービスの識別表示としての使用）」に当たりにくく、行使事例も乏しい。

## 2. 使用に注意が必要な語

### 2.1 トールキン由来（ミドルアース社の商標範囲）

| 語 | リスク | 実例・根拠 |
| :--- | :--- | :--- |
| **Hobbit（ホビット）** | 高 | TSR は D&D 初期版で「Hobbit」種族を使用していたが、トールキン財団の抗議を受け「Halfling」に改名した（[ja.wikipedia.org: ダンジョンズ&ドラゴンズに関する論争](https://ja.wikipedia.org/wiki/%E3%83%80%E3%83%B3%E3%82%B8%E3%83%A7%E3%83%B3%E3%82%BA%26%E3%83%89%E3%83%A9%E3%82%B4%E3%83%B3%E3%82%BA%E3%81%AB%E9%96%A2%E3%81%99%E3%82%8B%E8%AB%96%E4%BA%89)）。以来ゲーム媒体での「Hobbit」使用は業界的に忌避されている |
| **Mithril（ミスリル）** | 高（表記そのまま使う場合） | ミドルアース社が `MITHRIL` を商標登録（登録番号5237074、[Trademarkia](https://www.trademarkia.com/mithril-87261001)）。D&D は 3版以降 **`Mithral`** という別綴りを正式採用しており、これは Tolkien の綴りとの意図的な差別化と見られている（[Mithral - D&D Wiki](https://www.dandwiki.com/wiki/SRD_Talk:Mithral)） |
| **Ent（エント）** | 高 | D&D 自身が Tolkien の「Ent」をそのまま使っていたが、法的懸念から独自名 **Treant** に改名した経緯がある（[1d6chan: Treant](https://1d6chan.miraheze.org/wiki/Treant)、[Ent - Wikipedia](https://en.wikipedia.org/wiki/Ent)）。**Treant 自体は"安全な代替名"であり NG ではない**（§4 参照。note.com 記事の「トレントもNG」という記載はこの経緯の誤読と考えられる） |
| **Balrog（バルログ）** | 高（表記そのまま使う場合） | D&D 初期版で使用していたが Tolkien の著作権懸念で「Type VI Demon」に、後に「**Balor**」（ケルト神話由来の固有名を流用）に改名した（[Balor - D&D Lore Wiki](https://dungeonsdragons.fandom.com/wiki/Balor)）。「炎の鞭を持つ悪魔」という**設定・意匠そのもの**を模倣する場合、名前を変えても侵害リスクが残り得る点に注意 |
| **Middle-earth / Orc / Balrog 等の固有名詞** | 商標登録が広範 | ミドルアース社は多数の語を USPTO に登録済み（[Tolkien Gateway: Middle-earth Enterprises/Copyrights](https://tolkiengateway.net/wiki/Middle-earth_Enterprises/Copyrights)）。ただし "Orc" 単体は北欧・古英語起源の一般的なファンタジー用語として広く流通しており、実務上は無警戒に使われている（後述 §4） |

### 2.2 D&D（Wizards of the Coast）オリジナルのモンスター名

WotC の Open Game License（OGL）SRD には、公開される Open Game Content と非公開の **Product Identity（PI）** の区分があり、以下はオリジナル SRD（v1.0a〜3.5）で明示的に PI 指定された固有モンスター名（[EN World フォーラムの整理](https://www.enworld.org/threads/3-5-beholders-mind-flayers-yuan-tis.60435/)、[SRD-OGL_V1.1.pdf](https://media.wizards.com/2016/downloads/SRD-OGL_V1.1.pdf)）:

| 語 | 実例 |
| :--- | :--- |
| **Beholder（ビホルダー）** | 集英社『BASTARD!!』単行本化時に「鈴木土下座ェ門」へ改名・意匠変更、FF1のリメイク版で「イビルアイ／デスアイ」に改称（[ビホルダー問題 - FFdic Wiki*](https://wikiwiki.jp/ffdic/%E3%81%9D%E3%81%AE%E4%BB%96/%E3%80%90%E3%83%93%E3%83%9B%E3%83%AB%E3%83%80%E3%83%BC%E5%95%8F%E9%A1%8C%E3%80%91)）。名前だけでなく「目玉が浮遊し複数の触手/眼柄を持つ」という**意匠の模倣自体**が問題視される点に注意 |
| **Gauth（ガウス）** | Beholder の亜種。同じく PI |
| **Carrion Crawler** | PI |
| **Displacer Beast** | PI |
| **Umber Hulk** | PI |
| **Mind Flayer / Illithid** | PI |
| **Yuan-ti** | PI |
| **Githyanki / Githzerai** | PI |
| **Tanar'ri / Baatezu**（デーモン／デビルの種族区分名） | PI |

これらは「D&D独自の意匠・設定を伴う固有種族名」であり、一般名詞ではない点が Orc/Dragon/Elf との違い。**Marilith（マリリス）のような個別の悪魔名も、この PI カテゴリ（Tanar'ri 配下の固有種）に準じるものとして慎重に扱うのが無難**（公式PIワードリストには単独では見当たらなかったが、根拠となる一次資料を確認できておらず要検証）。

## 3. note.com 記事の主張のファクトチェック

| 記事の主張 | 検証結果 |
| :--- | :--- |
| ミスリル等トールキン語は映像化・ゲーム化で権利確保、小説はOK | **概ね正しい**。§1参照。ミドルアース社商標のビデオゲーム区分登録が根拠 |
| ホビットはゲームで使用不可 | **正しい**。D&D自身が過去に改名させられた実例あり |
| ハーフリングはグレーゾーン（『指輪物語』本文でホビットの言い換えとして既出のため） | **妥当な指摘**。トールキン自身が地の文で "halfling" を使っている以上、ミドルアース社が独占的商標権を主張しにくいという論理は法的にも筋が通る |
| **リッチ（Lich）は使用不可** | **裏付けが取れず、誤りの可能性が高い**。WotC の公開 PI 語リスト（§2.2）に Lich は含まれておらず、"lich" は古英語 "lic"（死体）由来の一般的な民俗・神話語彙。Warcraft の "Lich King"、Diablo など多数の作品で無警戒に使われており、係争の実例も見当たらなかった。記事が具体的にどの用例を指していたかは不明（特定の固有名を持つ有名リッチ・キャラクターや、公式ステートブロックの丸写しを指していた可能性はある） |
| **トレント（Treant）は使用不可** | **誤りの可能性が高い**。§2.1の通り、Treant は D&D が Tolkien の "Ent" を避けるために**自ら作った代替名**であり、SRD の Open Game Content として広く流通している（Pathfinder 等、他のd20系ゲームでも無警戒に採用）。「Ent はNG、その安全な言い換えである Treant もNG」という記事の趣旨は経緯の取り違えと考えられる |

**結論**: 記事の骨子（トールキン語＝映像/ゲームでは要注意・小説は比較的自由、D&Dのオリジナル固有モンスター名も別途要注意）は一次資料で裏付けられる。ただし個別の語の当てはめ（特にリッチ・トレント）には誤りが含まれる可能性が高く、本ドキュメントの §2 の表を正としたい。

## 4. 実務上ほぼ問題ない語（安全な代替・一般名詞）

| 語 | 理由 |
| :--- | :--- |
| **Treant** | D&D自身が作った Tolkien 回避名。OGL Open Game Content。他社ゲームでも常用 |
| **Halfling** | D&D自身が作った Hobbit 回避名。トールキン本文にも同義語として登場するためミドルアース社側も独占主張しづらい |
| **Balor** | Balrog の D&D 側回避名（ケルト神話由来） |
| **Mithral**（"i" を "a" に変えた綴り） | D&D公式の意図的な差別化綴り。"Mithril" とだけ完全一致させなければ実務上のリスクは大幅に下がる |
| **Lich** | 古英語由来の一般名詞。WotCのPIリストにも含まれず、業界で広く無警戒に使用 |
| **Orc, Elf, Dwarf, Dragon, Goblin, Troll, Giant, Vampire, Werewolf, Unicorn, Phoenix, Griffon** 等 | 北欧神話・民間伝承・中世文学由来の公有（パブリックドメイン）語彙。特定企業の創作物ではない |
| **Adamantine**（"Adamantium" ではなく） | ギリシャ語 *adamas*（征服されざるもの）由来の古典語。Marvel の "Adamantium"（Wolverineの爪、商標）とは綴りが異なる別語として整理されている（[Adamantine - Wikipedia](https://en.wikipedia.org/wiki/Adamantine)） |
| **Orichalcum** | プラトン『クリティアス』由来の古典語。特定企業の商標ではない |
| **Cold Iron** | 欧州民間伝承（鉄が妖精を退ける）由来の一般的なフォークロア語彙 |

## 5. 本プロジェクトへの適用

- [docs/temp/fantasy-races.csv](../../temp/fantasy-races.csv) は既に **Halfling** ・ **Treant** を候補種族名として使用しており、本調査の結論と整合する（安全側）。実装時もこの表記のまま進めてよい。
- [docs/plan/fantasy-culture-set-goods.md](../../plan/fantasy-culture-set-goods.md) §4.2 で交易品候補として挙げた **"Mithril Ore" / "Mithril Silver"** は綴りの見直しが必要。**`Mithral Ore`** 等、D&D公式に倣った差別化綴りへの変更を推奨（同ドキュメントに要修正フラグを追記済み）。
- 今後、種族・モンスター・アイテムの新規命名を行う際は、まず本表の §2（要注意語）に一致しないか確認し、該当する場合は §4 の代替語か、独自の造語を優先する。
