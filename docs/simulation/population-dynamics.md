# 人口動態・時間経過シミュレーション設計 (Population Dynamics)

本ドキュメントは、FMG（Fantasy Map Generator）における時間経過（Advance Time）に伴う、現実的な人口増減・人口ピラミッドの変化・およびフロンティア開拓をシミュレートするための設計仕様です。

## 1. 基本コンセプト：環境収容力（K）と60%スタート

FMGのコアエンジンがバイオームや地形から算出する初期人口（`pack.cells.pop` および `burgs.population`）は、**「その土地が養える最大限界人口（環境収容力 ＝ K）」**として扱います。

ゲーム開始時（地図生成完了時）の世界は、ペストのような大疫病や長きにわたる戦乱によって**「環境収容力の 60% まで人口が落ち込んでいる状態」**（または未開拓の森が多く残る発展途上の状態）として初期化します。
これにより、各セルに **40% の開拓の余地（roomForGrowth）** が生まれ、時間経過とともに自然な人口増加と辺境への進出が促されます。

## 2. データ構造：簡易コホート（年齢階層）モデル

厳密な1歳ごとの計算を避け、計算リソースを抑えるため、人口を4つのバケツ（コホート）に分割して管理します。各 Burg（都市）および Cell（地方）にこのデータを持たせます。

| コホート | 対象年齢 | 特徴 | 初期状態での割合目安 |
| :--- | :--- | :--- | :--- |
| **子供 (Children)** | 0〜14歳 | 労働・兵役前。男女比1:1。 | 全体の約 40% |
| **成人男性 (Male Adults)** | 15〜49歳 | 主要労働力。**兵役の主軸**。戦争で激減する層。 | 全体の約 22.5% |
| **成人女性 (Female Adults)**| 15〜49歳 | 主要労働力。**出生数のベース**となる層。 | 全体の約 22.5% |
| **老人 (Elders)** | 50歳以上 | 兵役対象外。自然死の確率が高い層。 | 全体の約 15% |

* ※ 上記の合計値が、開始時点では 環境収容力 `K` の 60% となるように初期分配されます。

## 3. 時間経過 (`advanceTime`) 時の処理フロー

`advanceTime(deltaYears)` が呼ばれた際、各セル・都市に対して以下の順序で演算を行います。

### 3.1 加齢によるシフト (Aging)
経過年数 `deltaYears` に応じて、各バケツの人口を上の年齢階層へスライドさせます。
* 例：15年幅の「子供」バケツからは、`deltaYears / 15` の割合が成人に移行する。

### 3.2 戦争ショック (Demographic Shock)
その期間内に国家間で戦争が行われていた場合、**「成人男性」のバケツからのみ**直接的な戦死者（例: 動員数の10〜30%）を引き算します。
これにより、人口ピラミッドがいびつ（女性・老人余り）になります。

> **拡張設計**: 兵力台帳との整合は `docs/plan/military/manpower-ecosystem.md`。  
> 春／秋の戦争→食料不足→性別を問わない餓死は同ドキュメント §18（`foodStress`）。

### 3.3 出生と自然死（ロジスティック成長）
出生数は「成人の総数」ではなく、**「成人女性の数」**に依存して計算されます。
また、現在の総人口が環境収容力 `K` に近づくほど出生率が下がる（または死亡率が上がる）ロジスティック関数を適用します。

```javascript
const currentTotal = children + maleAdults + femaleAdults + elders;
const K = initialCalculatedPopulation; // バイオームから算出された本来の適性度

// 土地の余裕度合い（0.0 〜 1.0）
const roomForGrowth = Math.max(0, 1 - (currentTotal / K));

// 出生数（女性の数 × 自然増加率 × 土地の余裕度）
const births = femaleAdults * baseGrowthRate * deltaYears * roomForGrowth;
```

**【効果】**
戦争で男性が激減しても、女性が残っていれば出生率は維持されるため、戦後には急速な人口回復（ベビーブーム）が発生します。

## 4. フロンティア開拓と新都市（Burg）の誕生

時間経過によって人口が順調に増加し、特定のセルや都市で `currentTotal` が `K`（`capacity`）を超える（`src/generators/demography-simulator.ts`の`roomForGrowth < 0`、閾値は100%——95%ではない）と、**「余剰人口の流出（Spillover）」**が発生します。

### 4.1 移住先の選定
余剰人口は、隣接するセル（`cells.c[i]`）の中から以下でスコアリングして最良の1件へ優先的に流出（移住）します（`demography-simulator.ts`のneighborループ）。
1. **居住可能な陸地であること**（`h>=20`）、**居住適性スコア（`cells.s`）に余裕がある**（人口が容量`capacity`未満）ことが前提条件。
2. スコアは基本 **居住適性スコア（`cells.s`）** に、**川沿いなら+50**、**自国領なら+100** を加算した値——降雨量（`prec`）を直接見るロジックは無い（居住適性スコア自体が降水量等を織り込んで算出されているため、間接的には反映される）。
3. **モンスター/Dangerを直接フィルタするロジックは無い**。危険地帯は間接的に容量が下がることでしか反映されない（居住適性スコア経由）。

### 4.2 開拓村（Pioneer Village）の成立
Burgが存在しない地方セルに余剰人口が流れ込み続け、そのセルの人口が一定の閾値（例: 1000人）を超えた場合、そこに新たな **開拓村（Burg）が自動生成（スポーン）** されます。

* 新しいBurgは、元の都市と同じCultureとStateを引き継ぎます。
* これにより、「平和な時代が続くと、川沿いの肥沃な土地に沿って次々と新しい村が開拓されていく」という歴史的な都市拡張プロセスが、追加のチートなしで自然にシミュレートされます。

## 5. UIへの反映

* **Population ピラミッド表示**: 各BurgのDetailsダイアログ等で、この4つのバケツ（男女比）を可視化する簡易バーグラフを表示します。これにより、プレイヤーは「先の戦争の傷跡（成人男性の凹み）」を視覚的に楽しむことができます。
* **人口成長率チャート**: Stateダイアログなどで、時間経過に伴う人口のV字回復や、Kに達して横ばいになるロジスティック曲線をグラフ化します。
