# 国家塩業と都市への塩流通

`Salt` は気候セルから自然発生する一般 Good ではなく、国家が管理する必需品である。塩業所を持てるのは、海または host が `salt` と分類した塩湖に接する国家だけである。塩業所はその水域に接する市場セルに置かれ、塩田として記録される。海・塩湖のどちらにも接しない国家は塩を生産せず、全量を他国の市場商人から購入する。

## 数量契約

`Salt` の `unit: "bag"` は **60 kg** と仮定する。これは Cheese のレシピが 1,000 kg のチーズに 0.25 bag を使うため、塩分が約 1.5% になる量であり、一般的なチーズの塩分水準（約 1.5–1.7%）と整合する。 [Wisconsin Center for Dairy Research](https://cdr.wisc.edu/cheese-faqs) 家計の基準は年3.6 kg。S1で人口比例の加工枠2.4 kgを廃止し、加工は前回の実際のSalt recipeInputの市場引落しを補充見込みにする。放牧家畜はFaunaの実頭数から別の補給計画を出す。固定6 kg/人という供給目標は使用しない。

これは栄養学上の推奨摂取量ではなく、料理と保存を含むシミュレーション上の計画値である。10 g/日（3.6 kg/年）は考古学的な消費モデルの基準例であり、保存を含む中世後期の年間消費は地域によって 15–16 kg 程度という推計もある。 [Anatolia salt-production model](https://www.cambridge.org/core/journals/european-journal-of-archaeology/article/model-of-salt-production-and-consumption-patterns-in-bronze-age-anatolia/B0A2D8BFF1947DC1566724CC8AF5101A), [late-medieval German estimate](https://erenow.org/common/beyond-bratwurst-history-food-in-germany/6.php)

新規の塩業所の年間能力は、有効国家の市場圏の家計・家畜・記録済み加工からの補充計画に、最寄りの内陸輸入国向けの計画と15%の操業余力を加えたものになる。大国は一施設あたり900 bag/年を目安に複数拠点へ分割される。既存セーブの能力はS1で再生成・増額しない。物理的な作業・燃料・季節の制約はS2で接続する。

2026-10-23 S0監査・同日完了追補: 上記の6 kgは現行の供給目標であり、史実の確定消費量ではない。加工用2.4 kgは備蓄枠で、実際の加工投入と区別する。料理用は文化省の概括3.5〜4 kg/人/年と照合できるが、保存込み15〜16 kgは原典未確認のため採用基準にしない。用途別の採否、対象外人口、1300年・High Medievalの新規2世界の同条件比較、旧入力の観測は[Salt S0記録](../analytics/salt-s0-baseline-20261023.md)を参照する。地域別総量と家畜の年間購入給塩量は「基準なし」と確定。係数は変更していない。次はS1（需要）。

## 月次フロー

2026-10-23 S1追補: [需要接続・暫定係数・12か月比較](../analytics/salt-s1-demand-20261023.md)を参照。旧6 kgはS0監査時の値として上記の記録を保持する。現在の加工補充は実投入の履歴であり、同じ材料を再引落ししない。無所属はstateId=0の消費区分で必要量と不足を記録し、既存の地元市場の在庫のみを受け取る。国家配送は発注しない。市場未割当は需要を不足として記録する。放牧5種の補給計画は史実未校正、未測定の自然控除は0とし、全家計の必要量を給塩より先に確保する。次はS2。

1. 生産月の先頭で、既に出発した `SaltShipment` の残り移動日数を 30 日進める。到着した貨物だけが着地市場の在庫になる。
2. 同じ国家に属する各市場圏の人口（都市人口と市場に属する農村人口）から、月間の供給必要量を算出する。市場は供給目標の三か月分までを物理備蓄として持つ。
3. 海・塩湖を持つ国家の塩業所は、家計販売・加工で減った在庫と備蓄不足を補う量だけを生産する。内陸国は自国の塩業所を使わず、国内の市場不足を同じ商人プールへ発注する。年間能力は供給可能な上限であり、使われない保存加工枠を毎月全量生産する義務ではない。
4. 生産分または既存の発地余剰を `SaltShipment` として出発させる。国内・国外を問わず、出発時に発地市場から取り除き、移動中は市場在庫に数えない。発地国・着地国、発地・着地市場、数量、推定移動日数、残日数、状態、到着時単価を記録する。
5. 着地市場は家計分の 3.6 kg/人/年を販売して在庫から差し引く。残る備蓄は保存食・チーズなど既存レシピの入力に使える。

国内の基礎供給を優先し、内陸国家は他国の塩業所へ配送を依頼する。`SaltShipment`は物量の配送契約であり、一般のcaravan/dealとは別の輸送中在庫を持つ。家計の受取と国家間配送の代金は未決済（S3）で、「販売」や記録された価格を支払済み所得と扱わない。

## データと診断

Economy の simulation slice は次を保持する。

- `saltworks`: 海・塩湖に接する生産国のセル・発地市場・類型・能力・当月生産量
- `saltShipments`: 輸送中・直近到着済みの国内卸売配送
- `stateSaltLedgers`: 国家ごとの人口、必要量、生産量、輸出入量、出発量、到着量、輸送中量、家計販売量、不足量

`Salt` は `chance: 0` かつ `demandCoverage: {}` とし、旧来のバイオーム生産と utilities 需要から除外する。旧セーブに残る Salt のセル割当も、通常の農村生産経路では供給されない。

塩業所が発地市場へ実際に卸した量は、Goods Editor の `Cumulative Market Output` / `Actual Output` と市場別の生産集計へ記帳される。`Projected Production` もその月の塩業所実出力を industrial site として含む。
