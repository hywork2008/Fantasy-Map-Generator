# Frontier 初期国家配置: 成長ポテンシャルと早期干渉の指針

この文書は、Settlement pattern が **Frontier**、かつ Starting state spacing が
**Spread apart** の場合に、初期国家をどこへ配置するかの設計指針である。

目的は地図上の見た目だけを均等にすることではない。各国家が自国の陸続きの
開拓可能地を確保し、同程度に成長したときに、他国の開拓前線を早期に塞ぎにくい
開始配置を作ることである。

実装の入口は `src/generators/settlementFoundation.ts` と
`src/generators/frontierStartPlacement.ts`。開始モード一般の仕様は
[`frontier-start-modes.md`](frontier-start-modes.md) を参照すること。

## 1. 設計目標

1. すべての初期国家が、国家に属する農村人口と開拓余剰人口を持って開始する。
2. 開始後しばらくは、各国が陸続きの有望な未開地へ進める。
3. 同一の開拓可能地を複数国が最初から奪い合わないよう、国家間の競合を遅らせる。
4. 海を隔てた landmass は、見かけの Euclidean 距離が短くても独立した開拓領域と
   みなす。海越えは陸上移動より高コストであり、初期の代替経路ではない。
5. 国家数、地形、気候が異なっても、特定の国家だけが初手から必敗にならない。

これは国家の面積、港の数、または首都間の直線距離を均等にすることとは異なる。
揃えるべきなのは、国家が到達できる **将来の開拓ポテンシャル** である。

## 2. 必ず守る不変条件

### 2.1 Foundation と国家の整合

Frontier の人口は Settlement Foundation が作る定住圏のセル集合に置かれる。国家を
作る際には未所属セルの人口をクリアする。これは、国家外の定住圏人口がセル容量を
先に埋め、国家の開拓余剰人口を奪い続ける問題を防ぐために意図的に必要である。

従って、首都または Starting realm を Foundation region 外の河川・港へ移動しては
ならない。そうすると国家の農村人口がゼロになり、資金や隣接未開地があっても
開拓者を出せなくなる。

**不変条件:** 初期国家の首都セルと Starting realm の周辺には、その国家が継承する
Foundation 人口が存在すること。

### 2.2 海と landmass

別 feature の陸地は初期の陸上拡張では接続していない。開始地点を選ぶ際には、
異なる landmass 間の距離を実質的に無限大として扱い、同一 landmass 内だけで
前線の距離を評価する。

これは「島なら一国ずつ優先する」という意味ではない。十分大きな大陸には複数国を
置ける。反対に、小島を一国の発展圏として扱うことも避ける。

### 2.3 首都の水資源

初期首都は大きな landmass 上の河川を優先する。Seaborne では true ocean harbor が
必要であり、同じ Foundation region 内の港だけへスナップする。湖・河川の drain が
解決しただけの擬似海港は seaborne 開始地点にしない。

## 3. 配置に使うべき評価量

### 3.1 面積は一次フィルタであり、最終目的ではない

land feature のセル数 `A_i` は小島を除外し、初期国家をどの landmass に配るかを
決めるための入力である。初期国家数を `N`、候補 landmass の合計セル数を `A` とすると、
単純な目安は `A / N` セル/国である。

この値に近い、またはそれを超える島・大陸を独立の開始領域として優先する。大島が
三つで四国家なら、面積の大きい順に一国ずつ置き、四国目を最大の大島へ戻す。この
配分は港セルの本数では決めない。

ただし、セル数だけでは河川密度や乾燥地を表せない。最終的な採用と割当は次節の
成長ポテンシャルで判断する。

### 3.2 開拓ポテンシャル

開始圏 `r` の開拓ポテンシャル `P(r)` は、初期に利用できる人口と、陸続きで次に
入植できる場所の価値を合わせた量とする。

```text
P(r) = initialRuralPopulation(r)
     + futureSubsistenceCapacity(r)
     + riverAccess(r)
     + coastLakeSpringAccess(r)
```

実装時の各項は次のように定義する。

| 項 | 内容 |
| --- | --- |
| `initialRuralPopulation` | Foundation region が国家に継承する農村人口。ゼロは開始失格。 |
| `futureSubsistenceCapacity` | 道路・海越えを使わず、一定の陸上移動コスト内にある未開地の居住容量。気温、降水量、地形、危険度を反映する。 |
| `riverAccess` | 河川セル数ではなく、陸上移動コスト内にある河川沿いの居住容量の合計。孤立した一本の川は低く、肥沃な流域・河川網は高くなる。 |
| `coastLakeSpringAccess` | 海岸、湖、湧水、十分な雨水農業が供給する低〜中程度の定住価値。 |

海を挟むセルは `futureSubsistenceCapacity` と `riverAccess` に含めない。これにより別の
continent は近く見えても、初期には互いの開拓余地を減らさない。

### 3.3 国家数を含む配分

全候補圏のポテンシャル合計を `P_total` とすると、目標は
`P_target = P_total / N` である。

landmass `i` に配る国家数 `n_i` は、`P_i / n_i` が `P_target` に近づくように決める。
まず各有力 landmass に一国ずつ置き、残りは追加しても一国あたりの値が最も高い
landmass に置く。この手順は、四国家・三大島なら概ね `2 : 1 : 1`、二大陸なら状況に
応じて `2 : 2` または `3 : 1` を選べる。

`A_i / N` による面積配分は、`P_i` がまだ実装されていない段階の近似としてだけ用いる。
面積が大きくても乾燥して河川も遠い地域を、同じ価値の開始圏と仮定してはならない。

## 4. 推奨アルゴリズム

1. **候補 landmass を列挙する。** 水、1セル島、Starting realm を収められない landmass、
   true ocean harbor が必要なのに持たない seaborne landmass を除く。
2. **各候補の有効面積とポテンシャルを測る。** `A_i` と `P_i`、利用可能な河口・港・
   河川流域を算出する。
3. **国家枠を landmass に割り当てる。** `P_i / n_i` の最小値を最大化する
   max-min 配分を行う。面積順位は同点解消と初期近似に使う。
4. **各 landmass 内で Foundation region を作る。** 同一 landmass に複数枠がある場合だけ、
   陸上距離と資源ポテンシャルで離す。別 landmass 同士には距離ペナルティを課さない。
5. **人口を region ごとに配る。** `dispersed` では一つの高得点河口に人口予算を集中させず、
   各 homeland が開拓者を出せる農村人口を持つようにする。
6. **首都を region 内に確定する。** 河川優先、seaborne は region 内の true ocean harbor。
   region 外へのスナップは禁止する。
7. **生成後に監査する。** 各国家について、農村人口、余剰人口、初回候補セル数、
   `P(r)`、同一 landmass 上で最も近い他国までの陸上距離を記録する。

## 5. 失敗パターンと対策

| 失敗パターン | 原因 | 対策 |
| --- | --- | --- |
| 国家の開拓が0セルのまま止まる | 首都が Foundation 外で、未所属人口のクリア後に国家の農村人口がゼロ | 首都・港スナップを Foundation region 内に制限し、国家継承人口を監査する。 |
| 定住圏の非国民が周辺容量を埋める | 未所属人口を残したまま国家が開拓者を出す | 未所属セルの人口クリアを維持する。開始圏は人口を継承できる位置に置く。 |
| 分散配置でも全国家が一島に集まる | 港セル単位の選択、または同一島の候補数が多い | landmass ごとに面積・ポテンシャルを集計し、国家枠を先に配る。 |
| 小島の国家が初手から詰む | 直線距離の大きさを優先し、小島の将来容量を無視 | `A_i` と `P_i` の最低値を満たさない島を開始候補から除外する。 |
| 大陸のすぐ横の大島を不当に除外する | `feature.group === "continent"` を絶対条件にする | feature group は補助情報に留め、相対面積と `P_i` で大島を評価する。 |
| 一本しかない孤立河川の国家が負ける | 河川セルを首都条件にしただけで、周辺流域の規模を見ない | `riverAccess` を将来居住容量で評価し、最低 `P_target` を満たさない開始圏を除く。 |
| 乾燥地・無河川地が必敗 | 開拓が河川に過度に依存し、雨水農業・湧水がほぼ価値ゼロ | 降水量が最低条件を満たす土地に低いが有効な雨水農業容量を与える。真の砂漠は依然として候補外にする。 |
| 別 continent を近距離の競争相手と扱う | SVG 座標の Euclidean 距離だけを使う | land feature が異なる場合は初期の競合距離を無限大として扱う。 |

## 6. 非目標

- 全国家の面積、人口、河川本数を完全に同一にすること。
- 不毛な砂漠・極寒地にも必ず国家を置くこと。
- 海越え植民を初期陸上開拓と同じコストで扱うこと。
- 国家数を優先して、明らかに敗北確定の開始地点を作ること。

候補地が `P_target` を満たさない場合は、国家数を減らすか、既存の高ポテンシャル
landmass に追加の homeland を置く方が、形式的に全 landmass を使うより望ましい。

## 7. 受け入れ基準

新しい配置ロジックは、少なくとも次を自動テストと生成後監査で満たすこと。

- 初期国家全てに正の農村人口と開拓余剰人口がある。
- 同一 landmass 上の国家だけが初期競合距離の比較対象になる。
- 大島が複数ある場合、最初の国家枠は各大島へ一つずつ配られる。
- 追加枠は、追加後の `P_i / n_i` が最も大きい landmass に配られる。
- 小島、孤立河川、乾燥地の開始圏は `P_target` の最低比率を満たさなければ選ばれない。
- seaborne 首都は true ocean harbor かつ自らの Foundation region 内にある。
- 400年程度の同一条件シミュレーションで、開始位置だけを理由に一国だけが0セル開拓へ
  固定されない。

この文書の `P(r)`、距離コスト、最低比率は設計値であり、実際の人口・開拓シミュレーション
の観測結果に基づいて調整する。
