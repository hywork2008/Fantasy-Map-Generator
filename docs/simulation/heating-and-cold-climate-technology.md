# 暖房・寒冷地技術

Economy 拡張は生産・交易後の月次決済で、市場領域の世帯暖房を決済する。需要は都市・農村人口、現在月の季節補正後の屋外気温、既存の暖房・断熱技術から求める。

- 木材は優先燃料であり、気温が低いほど消費量が増える。Wood の市場在庫を直接減らすため、伐採・森林ストック・交易と同じ供給制約を受ける。
- Coal は Wood で満たせない暖房需要だけを補う。Coal は Wood より高い熱量を持つが、使用比率は `coalSmokeExposure` として記録され、都市の `healthPressure` を上げ、結果として `burg.sanitation` を下げる。
- 寒い月が継続する市場領域は、`forestryKnowledge`、`heatingTechnology`、`insulationTechnology` を年次で蓄積する。暖房・断熱は必要燃料を減らし、林業知識はその市場領域の未耕作森林の回復速度を最大 50% 高める。

これらの知識は地図生成時の気候だけでは即時に得られない。寒冷な居住を約 36 か月以上継続するほど成熟し、暖かい地域では緩やかに減衰する。台帳は `Market.heatingLedger` に保存されるため、セーブ／ロード後にも燃料履歴と技術の蓄積が残る。
