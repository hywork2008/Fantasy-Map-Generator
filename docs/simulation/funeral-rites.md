# 葬儀の風習とリッチによる死者の蘇生

死者の処分は文化の風習として地図生成時に1つ割り当てられる。死者が出るたびに葬送用の資材を消費し、遺体が残る風習ではセルごとに累計遺体を記録する。土葬文化の地域にリッチ（Lich）が出ると、その累計遺体がスケルトン／ゾンビの兵士として蘇り、生者の敵になる。

## 儀礼

| 儀礼 | 主な歴史的対応 | 消費資材 | 蘇りうる遺体 |
| :--- | :--- | :--- | :--- |
| 土葬 (`inhumation`) | 棺・土坑葬 | 木棺（高地は石棺、砂漠・遊牧は麻布） | 高い（約80%） |
| 火葬 (`cremation`) | 薪の荼毘 | 薪（多め） | なし |
| 鳥葬 (`skyBurial`) | チベットの鳥葬、ゾロアスターのダフマ | 麻の経帷子 | 低い（散骨） |
| 水葬 (`waterBurial`) | 水葬・水葬船 | 石の錘 | ごく低い |
| ミイラ化 (`mummification`) | 乾燥地のミイラ | 麻布（多め） | 非常に高い |
| 風葬 (`exposure`) | 樹上葬・台葬 | 木の葬台 | 中程度（骨） |

割り当ては `CultureType` の事前分布に種族補正を掛けて1回振る（`src/utils/cultureFuneralRite.ts`）。高地は鳥葬、砂漠はミイラ化、工業文化は火葬、海洋文化は水葬が厚い。Wildlands（文化0）には儀礼がない。

文化エディタの Funeral 列で後から変更できる。変更後の死者から新しい儀礼が適用される。既に埋まっている遺体はそのまま残る。

## 死亡時の処理

`simulateDemographics` と戦闘死 (`applyDemographicCasualties`) がセル単位で `processFuneralDeaths` を呼ぶ。都市の死亡数は `populationRate × urbanization` で人数に換算する。蘇生兵の戦闘損失は葬儀・人口損失・負傷者の帰還処理から除外する。

1. セルの文化儀礼を読む。
2. `remainFraction` を遺体ストック `simulationContext.funeral.remainsByCell` に加算する。
3. 薪・石・麻布の需要を `pendingMaterialsByCell` に積む。
4. 薪需要分だけそのセルの `forestStock` をわずかに減らす。
5. Economy が有効なら `fmg:funeral-demand-batch` を1回投げ、市場在庫の Wood / Stone / Linen（なければ Cloth）を引き落とす。

資材が足りなくても儀礼は行われる（遺体の行方は儀礼どおり）。歴史的な初期遺体の種まき（生成時 80 年分）は資材を消費しない。

Fast-Forward の人口近似は死亡をセル単位で記録しないため、その間は遺体が増えない。

## リッチの蘇生

毎ティック `undead-raising.tick`（military フェーズ）が次の「不浄の圏」にある遺体をすべて起こす。

- リッチ国家が領有するセル
- その隣接セル
- リッチ国家の連隊がいるセルとその隣接セル

蘇生対象セルと所属するリッチ国家はティック開始時の領土・連隊位置から確定する。そのティックで蘇った連隊が広げる範囲は次のティックから有効になる。

蘇った兵は最寄りのリッチ国家の `isRisen` 連隊（`skeletons` / `zombies`）に入り、生きた所有者国家との外交を Enemy にする。人的資源台帳（`landRegiments`）からは除外するので、生者の徴兵を食い潰さない。

ミイラはゾンビ寄り、風葬・鳥葬はスケルトン寄り。火葬セルでは何も起きない。

`Military.generate()` は連隊を組み直す前に蘇生済み兵力をスナップショットし、再生成後に戻す。
