# 経済拡張無効時の食料容量近似

## 境界

本体は経済拡張のモジュールを import しない。経済拡張の作物選択・収量計算を呼ぶのは、オフラインの校正ツール `src/extensions/economy/generators/foodClimateCalibration.test.ts` だけとする。

本体は出力済みの `src/data/foodClimateCalibration.json` を補間する。作物追加や経済モデル変更後は再校正する。出力には参照した6ファイルの SHA-256 を保存する。既存の土壌・作物適性を本体が再実行して結果を合わせる方式は採用しない。

## 実測したモデル

- `getCropMix`: 気温・降水・土壌・灌漑補給に適合する候補を抽出。文化の嗜好とセルID・商品ID由来の決定的な小変動（0.93～1.07倍）で主作物と豆類を選ぶ。通常の輪作面積は2:1。一方しか育たない場合はその作物だけになる。
- `calculateAgriculturalLandProfile`: 実際の `yieldPerArea`（kg/播種ha）を測定。作物適性・作物収量倍率に加え、気温係数・降水係数・灌漑面積割合を含む。技術・肥料・塩害・土壌劣化・一時的な災害は基準状態とする。
- 気候ガイドで候補が選べても、現行モデルの基本降水係数は降水値8（800 mm）未満で0。これを校正時に変更してはいない。
- スペルトを含め、現在の商品カタログの全畑作物を使用する。食用クリは樹園地生産に属し、現行経済拡張の主食容量に算入されないため、この主食収量の表にも算入しない。

## 組み合わせと統計

27気温点（−5～40℃）、24降水点（0～25,500 mm）、7補給水深点（0～1,600 mm）、6土壌、11文化、各文化4セルを測定した。

灌漑割合0と1の端点で実際の関数を測定し、その間の面積割合は補間する。割合0・補給水深正の端点は、作物選択を固定した時の非灌漑部分の収量を取り出すための測定であり、水を供給せず灌漑作物を選ぶ本体の実運用条件ではない。

計 **2,395,008セル条件**。`food-climate.csv` に土壌・気候・水深・面積割合別の平均収量、10/90パーセンタイル、作物の選択回数を保存した。本体用表は54,432個の平均値と取水目標値からなる。文化・セルの差は平均化し、本体で個別の作物計画を復元しない。

測定に含めなかった気候点・補給水深・灌漑割合0.1/0.5と、別の文化・セルID組み合わせで **17,556条件**を検証した。

| 誤差（平均収量に対する絶対誤差） | kg/播種ha |
| --- | ---: |
| 平均 | 3.32 |
| 95パーセンタイル | 17.83 |
| 最大 | 49.29 |

これらは基準状態の気候収量の検証結果であり、肥料・投資・災害・現実の歴史的収量に対する精度保証ではない。作物が切り替わる境界で誤差が大きくなる。

沖積土・灌漑なしの実測例:

| 気温 | 年降水 | 平均収量 kg/播種ha |
| --- | ---: | ---: |
| 4℃ | 500 mm | 0 |
| 4℃ | 800 mm | 74.96 |
| 14℃ | 800 mm | 162.82 |
| 14℃ | 2,000 mm | 130.12 |

4℃・500 mmでは主作物に大麦、豆類にエンドウが選ばれたが、基本降水係数で収量0になる。Degoryeskの1275セルの条件はこの例に当たる。指定されたBria保存データを直接読み取り、近似処理後の容量が **4,935.462人**になることを検証した。保存された非農業食料容量を維持した結果である。

## 本体への適用

`estimatedFoodProduction.ts` は本体側の地形・土地面積と、既存の本体の河川水量配分器を使用する。河川上と隣接セルだけが取水でき、複数セルが同じ河川の水を重複使用しない。流量不明・0なら補給は0。

拡張機能なしでは灌漑投資の実態がないため、村落の低投資シナリオとして指令面積10%、配送効率40%を仮定する。流量1あたり年水量30、河川に残す割合55%は校正対象の経済モデルの基準と対応する。この流量換算は地図用係数であり、実測のm³/sではない。補給量はha×降水プロキシの単位で保持する。灌漑目標の不足水深を満たせる面積だけに届ける。

農業容量は耕作面積×補間した収量×播種割合0.67×可食割合0.65÷年間200 kg/人で近似し、人口ポイントへ換算する。土地予算があれば既存の農地面積を使用し、予算がなければ森林被覆・地形から未開墾面積を除く。農地計画の入力には開墾可能な土地上限と同じ校正収量を渡す。

新規地図の初期容量、拡張無効時の農地計画、地図読み込み後・経済拡張無効化時の容量更新に適用する。経済拡張が有効な時は拡張自身の計算結果を使う。無効化によって保存済みの農地・人口・市場在庫を変更しない。非農業・地下食料容量は維持する。

## 再現コマンド

```sh
FOOD_CLIMATE_CALIBRATE=1 npx vitest run src/extensions/economy/generators/foodClimateCalibration.test.ts
```

通常の同テストはテーブルを書き換えず、未使用条件で誤差を検証する。校正は固定のカタログ・セルID・文化順序で再現可能。結果の検証値は `food-climate-validation.json` に保存する。
