# 中世ヨーロッパの橋形式とCEの選択基準に関する調査

調査日: 2026-10-31

## 結論

中世ヨーロッパを再現する場合、橋面と平水面の高低差だけで支持橋から吊り橋へ切り替える根拠は確認できなかった。通常の候補は木造桁橋・木造支柱橋、石造アーチ橋、石造橋脚と木製橋床の組み合わせである。高い位置での渡河は、両岸に支持するアーチや適切な場所への経路変更も含めて判断する。

BVに追加したロープ吊り橋は、ファンタジー文化や個別の技術設定で許可する素材として保持する。中世ヨーロッパ向けの標準的な自動配置形式とは扱わない。この調査ではCEのコードと既存BVモデルは変更していない。

## 距離・高さの定義

| 記号 | 意味 | 選択時の用途 |
| --- | --- | --- |
| H | 橋面から平水面までの高さ | 景観、通航、支柱の高さの一部 |
| W | 渡河地点の岸から岸までの距離 | 橋全体の必要延長。洪水敷への延長とは別 |
| S | 隣接する支持点間で、支えずに渡す距離 | 桁・アーチの能力。史料の純径間と支点中心間距離も区別する |
| D | 平水面から河床までの深さ | H+Dで河床から橋面までの高さを概算。杭の根入れはさらに別 |
| F | 洪水時の水位 | アーチ下面・橋桁下面との余裕を調べる基準 |

全長100mの橋を10m前後の径間に分割することと、100mを無橋脚で渡すことは別の条件である。石橋ではアーチの起拱部を高い岸や岩盤に置けるため、河床から橋面までの全高と「細長い独立橋脚の高さ」も一致しない。

公開資料の高さには、河床からの構造高、アーチ頂部、欄干頂部、塔の高さが混在する。以下の公表高を、そのままCEのHとして採用してはならない。平水位自体も一定ではなく、中世当時と現在の河道・水位の一致は保証できない。

高さと支間が独立であることの比較例として、ウェールズのPontarfynach最下段の石橋は、開口約6m、流れから約30m上と記録される。ただし文化財記録自身が中世由来・16世紀頃の可能性・後世の改修を記し、建設年代を確定していない。確実な中世橋の統計には算入しない。[Coflein / CADW由来の記録](https://coflein.gov.uk/en/sites/23859)

これらは事例集であり、当時の橋全体の平均値・頻度分布ではない。長持ちする石橋と大規模な名橋が資料に残りやすい点にも注意する。

## 木橋・石橋・吊り橋の選択を左右する条件

Historic Englandの調査では、中世にも木橋が多く、イングランド南部で11世紀末までに石造アーチ橋が建設され、12〜13世紀には橋の記録が増える。木造を「特別な橋」、石造だけを「普通の橋」とみなすべきでもない。[Historic Englandの歴史・考古学的調査、第2.3節](https://historicengland.org.uk/research/results/reports/8318/TheRoadRailandParklandBridgesofBishopAucklandCoDurham_anassessmentofthehistoricalandarchaeologicalevidence)

木橋については、城の堀橋や基礎の発掘資料を整理したRigoldの研究が、陸上に見える支柱だけでは判断できない横架材・底盤・筋交いなどの構成を示す。一方、大規模中世木橋の証拠は断片的であると著者自身が明記する。この調査から木橋の普遍的な最大支間・最大高さを確定することはできない。[Rigold, 1975, Structural Aspects of Medieval Timber Bridges](https://www.tandfonline.com/doi/abs/10.1080/00766097.1975.11735372)

アーチ橋にも、両岸で水平推力を受けられること、基礎を施工できること、施工中の木製支保工を設けられること、洪水を通せることが必要になる。Moultonの15世紀橋では、大きな単アーチにすると取付道路が急勾配になるため、複数の小アーチを使ったことが説明されている。単に大支間が可能かだけで形式を決めない。[English Heritage](https://www.english-heritage.org.uk/visit/places/moulton-packhorse-bridge/history/)

深い水、速い流れ、洗掘や洪水、船の通航は、河中橋脚の設置・維持に不利な条件である。強固な両岸を使って大アーチにするか、別の渡河地点・渡し船を選ぶ。セレでは橋が成立する以前に渡し船が使われていたことが記される。[セレの遺産案内](https://ceret66.fr/visiter-ceret/pont-du-diable/)

### 吊り橋の歴史的な位置づけ

ESDEPの橋梁史教材は、初期のロープ橋の系統を中国・インド・南米に位置づけ、水平橋床を鎖で吊るVerantiusの案と、18世紀末以後の実用化を説明する。中世ヨーロッパの恒久的な道路橋を、高低差に応じて吊り橋にする裏づけにはならない。[ESDEP Lecture 1B.4.4、Suspension Bridges節](https://fgg-web.fgg.uni-lj.si/~/pmoze/ESDEP/master/wg01b/l0440.htm)

スイスのTwärrenbrückeは注意すべき例である。古い図に鎖吊りで描かれることがあるが、連邦の歴史交通路資料は、実際には岩に固定した木の梁で支えた岩壁沿いの歩廊だったとする。これを中世の河川横断吊り橋の証拠にしない。[スイス連邦IVS・Uri資料、項目29](https://www.ivs.admin.ch/images/dienstleistungen/downloads/kantonshefte/PDF/ur_kantonsheft.pdf)

中世ヨーロッパの全地域・全時期に吊り構造が一切存在しなかったと証明したものではない。今回の結論は、通常の恒久橋として自動配置する根拠が得られないという範囲である。跳ね橋は開閉機構であり、川全体を吊り構造で渡す吊り橋とは区別する。

### 「中世最大72m」の扱い

Trezzoの橋は、市の解説でも72mの単アーチとして紹介されている。しかしTullia Ioriの2024年の建設史研究は、記録間で径間数や構造の説明が食い違い、19世紀の復元図と寸法が後の技術史に引き継がれた経緯を検討する。少なくとも「中世の一般的な能力は72m」と設定する根拠にはならない。自動生成の通常上限を決める校正用データからは除外する。[Trezzo市資料](https://www.comune.trezzosulladda.mi.it/sites/default/files/2023-09/castellointerno.pdf)、[Iori, 2024, The strange history of the bridge over the Adda in Trezzo](https://www.tulliaiori.com/downloads/2024_8ICCH_Iori.pdf)

## CE向けの仮基準

以下は史料に書かれた当時の法則や安全限界ではなく、上記の事例を参考にした生成用の保守的な初期案である。実物橋梁の設計基準ではない。

| 条件 | 優先候補 | 仮の数値と扱い |
| --- | --- | --- |
| 短い開口、木材・労働力が確保できる | 木造桁橋、筋交い付き支柱橋 | 通常の反復径間3〜6mを初期値とする。歴史上の最大値ではない |
| 岸・河床に基礎を作れ、交通上の価値・予算がある | 石造多アーチ橋、石橋脚＋木橋床 | 通常アーチの開口5〜20mを候補域とする。Wが100〜300mでも多径間に分割できる |
| 河中橋脚を置きにくく、両岸が強固 | 単アーチ／少数の大アーチ | 開口20〜35mを高度な工事、35〜50mを例外的な大工事として扱う |
| 無橋脚で50m超を要求する | 地点変更・中州の活用・渡し船を先に検討 | 中世の通常自動生成では除外。個別の史跡や特別な技術設定は別に扱う |
| Hが約10〜15mを超え、長い支柱を川底から立てる必要がある | 支持構成の再検討、岩盤上のアーチ候補を比較 | 木造支柱形式に不利な評価を付ける仮の警戒域。木橋の史実上の限界値ではなく、吊り橋への切替閾値でもない |
| Hが20〜30m級でも、強固な両岸の間が短い | 両岸支持の石造アーチを検討 | Hだけで石橋を禁止しない。アーチのライズ・厚み、洪水位、取付勾配を別途検証する |
| 中世ヨーロッパの通常設定 | 吊り橋を候補から外す | H・W・Sのいずれにも吊り橋への自動切替閾値を設けない |
| ファンタジー文化／独自の吊り構造技術がある | BVのロープ吊り橋も候補に加える | 歩行・荷駄・荷車の用途、アンカーを置く岸の余地、材料強度、主塔・主索・横揺れ対策を別の技術ポリシーで扱う。史実調査だけから48m／96mの許容値は決めない |

判断順序は、時代・文化・技術で形式を絞り、渡河地点と基礎の可否を調べ、必要なSを決め、交通用途・費用と照合し、最後にH・D・F・取付勾配に合う立体形状を組み立てる順が適切である。川幅と高低差の二変数だけで史実的な選択を再現することはできない。

## 次に進める作業

1. CEの橋候補に、橋脚設置の可否・無橋脚で渡す区間・岸の支持位置を持たせる方法を整理する。
2. 河面との差を単独の切替条件にせず、現在の反復小アーチ／木造支柱橋に加えて、岸に支持する大アーチを候補化する。
3. 通常の中世ヨーロッパと、吊り橋を許可する文化・技術設定のポリシーを分ける。
4. 仮基準は少数の固定地形ケースで検証し、史実の寸法とゲーム上の調整値を区別して記録する。
