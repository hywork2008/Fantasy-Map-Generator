# City Editor の軽量表示

Generate パネルの「描画品質」で切り替える。初期値は「自動」で、Large 相当（表示範囲 3,600 m 以上）の都市を軽量表示する。設定は表示専用で、都市ファイル・履歴・共有リンクには含めない。

| 設定 | 表示 |
| --- | --- |
| 詳細 | 個別の建物、農地の畝、公園の植栽を描く |
| 軽量 | 一般建物を街区ごとの複合パスにまとめる。路地は同じ線幅ごとにまとめる。農地の畝・草・庭の装飾を省略し、公園の樹冠を円1個で表す |
| 最軽量 | 軽量に加え、一般建物を街区ごとに約1/2、公園の樹木を約1/3に間引く |

軽量表示では、まとめて描く建物の表示座標を 0.1 m 単位に丸める。城・門・主要道路・ランドマーク建物は保持する。透明な街区境界の SVG 要素を省き、グリッド線表示または編集表示にすると復帰する。各街区の面は選択用に保持する。

建物の集合をクリックすると、その街区は間引きなしの個別建物表示になり、敷地の詳細を選択できる。建物数の表示は常に元の全件数。保存データと SVG エクスポートは詳細品質のまま。

パンは `viewBox` の更新だけで移動し、ズームも都市の SVG を再構築しない。街道の行き先ラベル・ホバー・距離計測は小さな専用レイヤーだけ更新する。選択頂点の診断ラベルを有効にしている場合のズームは、従来どおり再描画する。

## 計測

2026-09-30、macOS / headless Chromium、Large / Grid evolution、seed `render-quality`。同じ生成済み都市で品質だけを変更した。各品質のウォームアップ後3回の中央値。SVG 構築から DOM への挿入、レイアウト確認、2回の animation frame 待機までの時間であり、都市生成全体の時間や操作時の FPS ではない。

| 建物パターン | 品質 | SVG 要素数 | 再描画時間 |
| --- | --- | ---: | ---: |
| 中世（UI既定） | 詳細 | 35,718 | 1,241 ms |
| 中世 | 軽量 | 898（97.5%減） | 1,168 ms（5.9%短縮） |
| 中世 | 最軽量 | 897 | 1,122 ms（9.6%短縮） |
| 従来 | 詳細 | 37,286 | 713 ms |
| 従来 | 軽量 | 813（97.8%減） | 621 ms（12.9%短縮） |
| 従来 | 最軽量 | 812 | 573 ms（19.6%短縮） |

別途 Node + jsdom で従来パターンを測定したところ、建物形状は詳細・軽量ともに23,307棟、最軽量は11,662棟。SVG文字列は約14.9 MBから軽量約2.78 MB、最軽量約2.11 MBになった。jsdom の時間はブラウザ描画時間とは異なるため比較しない。

SVG の要素数は大きく減るが、敷地・建物形状の計算は同じ処理を行うため、初回の都市作製が同じ割合で高速化するわけではない。主な操作面の改善は、パン・ズームで形状計算と SVG 全再生成を行わなくなったこと。ブラウザでもパン・ズーム後に同じ SVG / 街区ノードが保持され、再生成の診断イベントが0回であることを確認した。詳細・軽量・最軽量のスクリーンショットを比較し、都市外形・道路・ランドマークが保持されることを確認した。

### 再計測

```sh
node --import tsx scripts/benchmarkCityEditorRendering.ts --size=large --grid=evolution --pattern=legacy
node --import tsx scripts/benchmarkCityEditorRendering.ts --size=large --grid=evolution --pattern=medieval --out=/tmp/ce-render-quality-medieval
```

このスクリプトは Node + jsdom で計測し、指定フォルダーに `report.json` と3品質の SVG を保存する。`--seed` も指定可能。ブラウザと jsdom は別の実行環境なので、要素数・時間はそれぞれの実行内で比較する。

## 検証

- City Editor の render / ui テスト100件が通過。追加の路地形状保持テストを含む軽量表示関連5件も通過。
- 建物形状の保持、表示だけの間引き、選択した街区の詳細復帰、グリッド線・編集用境界の復帰、保存対象データの不変性、詳細SVG出力、パン・ズーム時のノード再利用を検証。
- `tsc --noEmit` は変更外の既存エラーで失敗（`streets.ts`、`passages.ts`、`openSpaceBoundary.ts`、未使用変数等）。今回変更したファイルの型エラーは報告されていない。
