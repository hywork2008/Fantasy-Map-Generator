# City Editor の城郭実装

[城と城壁の設計](castles-and-fortifications.md)の F1〜F4 を実装。新規生成は `castle-city-v1` を使い、旧生成レシピは `legacyCastles` で互換経路を選ぶ。

## 生成と描画

- 城域を街路生成より前に予約する。小さい街区は隣接区画を結合し、大きい街区は実際のメッシュを切って局所的な城域を作る。
- 自動配置は都市端を優先し、中央にも配置する。条件が合わない場合は別候補・中央配置・独立した囲郭を検討する。明示した位置・関係・規模を変更するフォールバックはしない。
- 規模の自動選択は Micro/Tiny、または都市半径120m以下で「小」、それ以外で「標準」。面積下限は小2,500㎡、標準5,000㎡、大10,000㎡。上限は30,000㎡。
- 建物の寸法を城域に合わせた後、各棟を実際の城壁から約4m離れた位置まで移す。入口は中庭側へ向け、中庭は縦横比と位置を探索して広く確保する。城内通路は城門から伸びる幹線と直角の分岐で各入口へ接続し、建物内の横断を避ける。
- 主塔と中庭を持つ形式、中庭を囲む居館の形式を用意する。広間・付属棟・建物入口・城内通路を専用データとして生成する。
- `DefenseCircuit` が都市域と城域を区別する。一体型の共有城壁は一つの物理グループを両境界が参照する。市街側の仕切り壁も実際の辺に置く。
- 市門の候補から城域を除外する。城門は市門の予算・外部道路数・四方向の街路交差検査に混入させない。城門には市街側の道路と城内通路を接続する。
- 城壁を門幅に応じて切り、開口を描く。隅塔と途中の塔を描き、共有部分で重複しないようにする。
- 一般住宅・路地の生成結果を城域から除外する。街路を隠す完成表示では都市の防御境界を使い、独立城の壁を都市の外壁として扱わない。

## 編集と互換性

生成パネルに城の位置・城壁との関係・形式・規模を追加した。城を選ぶと「城内を再配置」で形式・城壁を維持したまま現在の配置方式を適用できる。形式を切り替え、城郭全体または建物を固定し、城を削除できる。共有する都市壁は削除後も保持する。

区画の選択画面から「選択区画を新しい城郭にする」を実行できる。旧城地区の連続区画はまとめて変換し、道路の接続と城内配置が成立した場合だけ確定する。作成できない場合は元の地図を保持する。

読み込み時は v1 の城を自動変換しない。JSON保存は v2。城郭データは Undo/Redo、区画・辺の分割、頂点移動、拡大縮小でも保持・検証する。固定した城郭は再生成でも予約を維持する。城を水域へ変更する操作、城門や必要な城壁を個別に壊す操作は拒否する。都市壁の明示的な削除は都市境界の開口として記録する。

## 検証

`castles.test.ts` と `castleGeneration.test.ts` で、共有壁、門・通路、住宅除外、位置と形式、Micro〜Largeの領域予約、Hex/Voronoi/evolution、城と都市壁の独立性、保存往復、旧生成経路、固定、分割、拡大縮小、Undo/Redoを検査する。City Editor全体の回帰テストも実行し、3種類の配置と形式切替・固定・JSON保存はブラウザーで確認する。

水堀、複数城、年代・地域別の構成、旧市壁、複数の庭や高度な城内動線は F5 以降の対象。現在は一都市につき一城を生成する。
