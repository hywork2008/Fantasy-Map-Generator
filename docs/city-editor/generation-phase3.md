# Grid evolution 第3段階：地区単位の密度・農地・編集

## セルと描画領域の分離

MFCGのWarpでは、頂点の移動に対して遠方の建物が変わる場合と、近傍の建物が変わらない場合がある、というユーザーの観察を設計へ反映した。ただし、この挙動だけでは内部の地区結合を断定できない。共有乱数列や処理順の変化でも遠方の再配置は起こり得る。CEではその不安定さを再現せず、描画単位と再計算の依存関係を明示する。

同じ用途・市街地区分の隣接セルを、初期生成では最大6セルずつ描画用の地区にまとめる。壁・川・主要街道・固定境界・ロック面・ランドマーク領域を越えて結合しない。穴を含む領域や一点で接する領域も結合しない。

地区内部の補助辺を取り除いた一時メッシュで路地と建物を生成する。編集用の `Mesh` と主要街道の `FeatureGroup` は変更しない。建物は補助セル境界をまたぐことができ、選択時の所属セルは建物の中心で決める。したがって、建物が一つの編集セル内に収まることは新方式の条件ではなく、所属する地区内に収まることを検証する。

凹地区は描画処理内で凸領域へ分解する。各領域の外周通路、地区間の入口、再帰分割時の路地を接続する。地区内では共通の直交軸を使い、分解領域ごとの放射状の路地を作らない。建物はこの軸に沿った矩形として敷地内に収める。

## 地区設定と農地

建物またはセルを選択するとInspectorに地区設定が表示される。

- **Lot occupancy (%)**：建築可能な敷地のうち建物を残す割合。
- **Building coverage (%)**：各敷地に対する建物面積の上限。路地・空地・地形の制約があるため、地区全体の実測建蔽率とは異なる。
- **Target lot area (m²)**：再帰分割の目標敷地面積。
- **Lane width (m)**：地区内の基準路地幅。細い枝路はその60%。主要街道の幅には影響しない。
- **Building direction (°)**：地区で共有する建物・分割の軸。

城外市街地は引き続き街道沿いに建物を限定する。`farm`用途を保持し、農地区画と平行な畝を描画する。農地には住宅用の路地や建物を生成しない。畝は編集用メッシュに追加せず、一つの区画につき最大100本とする。evolutionの用途ブラシ／Inspectorから農地を指定できる。

## キャッシュと編集

地区の外周、入口、用途、密度設定、接する道路・壁の幅、近接する河川線分をキャッシュキーにする。最大256件のLRUキャッシュを使い、無制限には保持しない。農地も同じキャッシュで管理する。

- 地区内部だけの頂点移動では、建物・路地の形状を再計算しない。所属セルの選択情報だけは現在のメッシュに合わせる。
- 地区外周や接道条件の変更では、その依存関係を持つ地区を再計算する。接道の接続性が変われば、その先の地区も対象になる。
- 新しい壁、用途変更、海への変更、ロックによって地区を分離する。無関係な地区を再び全域から組み直さない。
- 補助セルの分割・結合では保存済みの地区対応も更新する。
- ロック面の用途・水面変更、ロック面／辺／Featureに接する頂点移動を拒否する。自動生成の再実行時も、ロックされた生成済みFeature・要素を消去しない。

キャッシュは生成済みの描画形状に対するもので、保存データの代わりではない。空のキャッシュで再計算しても同じ形状になる。

## 保存と再生成

`CityDocument.fabric`に描画アルゴリズム版（2）、シード、地区とセルの対応、地区設定を保存する。完成生成では、生成アルゴリズム識別子 `evolution-city-v3`、要求シード、設定、生成前の入力図面も保存する。入力図面には過去の `fabric` を入れず、再生成履歴の入れ子を防ぐ。

JSON読込時に版と地区設定・生成入力を検証する。読み込んだ完成図では、保存された生成前の入力と設定を次の一括生成に使用する。編集済み図面から生成する場合は、その図面を新しい入力として扱う。地区設定だけの変更は骨格の自動生成を実行しない。

履歴の差分に `fabric`、`gridKind`、`referenceImage` を含め、Undo / Redoで復元する。`fabric`のない従来図面は第2段階までの描画を維持し、新しい完成生成または地区設定の編集で新方式を使用する。Hexagonal / Voronoiの生成経路は維持する。

## 表示負荷について

低倍率の建物省略は検討したが、今回の既定表示には導入していない。選択対象と表示の切り替わりを別途設計する必要があるため。地区キャッシュは建物生成の再実行を減らすが、SVGのDOM構築やブラウザのペイントは省略しない。Largeの総表示時間とキャッシュ再利用時間は区別して計測する。
