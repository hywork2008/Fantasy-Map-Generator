# 中世ヨーロッパ教会・墓地複合体（Church & Cemetery Precinct）設計書

## 1. 背景と課題認識

### 1.1 現状の課題
City Editor（CE）の現在の市街地生成では、街区の多くが `merchant`, `craftsmen`, `patriciate` などの町家・テラスハウス（連続住宅）で埋め尽くされており、全体が均一な住宅地に見えやすい。
また、教会（`kind: "temple"`）は単なる無味乾燥な長方形フットプリント（`templeRect`）とその周囲の進入禁止余白（`civicYard`）としてしか表現されておらず、中世ヨーロッパ都市において景観・信仰・社会生活の絶対的中心であった**「教会聖域（Churchyard / Precinct）」**および**「墓地（Cemetery）」**としての空間的広がりと特異なテクスチャが完全に欠落している。

### 1.2 目的
中世ヨーロッパ（一神教／キリスト教）の教会建築・教会墓地・関連施設の歴史的・空間的特徴を調査し、以下の2つのアプローチによって都市に鮮烈なコントラストと歴史的説得力を付与する：
1. **教会区聖域（Church Precinct Fabric）**: 既存の `temple` が配置されるセルにおいて、教会建築（ラテン十字・アプス）、教会墓地（石壁・十字架・イチイ・墓標）、司祭館、納骨堂を一体生成する。
2. **新Ward `cemetery`（独立共同墓地）**: 都市内または城壁外のセルを墓苑として指定可能にし、回廊型納骨堂（Charnel Arcade）や小礼拝堂（Chapel）を備えた厳かな緑地空間を生成する。

## 2. 史実調査：中世ヨーロッパの教会と墓地の空間秩序

中世ヨーロッパ都市における教会と墓地は、単なる宗教施設ではなく、厳格な宇宙観（オリエンテーション）、衛生・死生観、治外法権（アジール／聖域権）が具現化された空間であった。

### 2.1 空間配置の絶対原則

```
                  【 北 (North) 】：日陰・悪魔の領域・納骨堂・司祭館
              ┌──────────────────────────────────────────────┐
              │  [司祭館]              [納骨堂 (Charnel)]    │
              │  (Rectory)                                   │
              │  ┌───────────────┐                           │
【 西 (West) 】│  │ 門 (Lychgate) │                           │【 東 (East) 】
正面ファサード│  └───────┬───────┘                           │祭壇 (再臨の光)
信徒入口      │          │                                   │アプス (Apse)
              │   ┌──────┴───────────────────────────┐       │
              │   │ 西塔   身廊 (Nave)   翼廊   内陣 │=======│ [東側墓地]
              │   │ (Tower)               (Transept) │ (Apse)│ (聖職者・特権階級)
              │   └──────┬───────────────────────────┘       │
              │          │ 南ポルティコ(主入口)              │
              │          ▼                                   │
              │      [中央十字架] (Calvary)                  │
              │      †   †   †   †   †   †   †   †       │
              │        【 南側教会墓地 (South Churchyard) 】 │
              │        日当たり良好・復活を待つ信徒の墓標列  │
              │        常緑のイチイの木 (Yew Tree) ♠         │
              └──────────────────────────────────────────────┘
                  【 南 (South) 】：光・神の慈悲・主たる信徒墓地
```

1. **東西主軸（Ad Orientem / 東面礼拝）**:
   * **東（East）**: 祭壇（後陣／アプス）は厳格に東を向く。東はエルサレムの方向であり、「キリストの再臨（昇る朝日）」を象徴する。
   * **西（West）**: 教会の正面入口（ファサード／西塔）。俗界からの入口であり、「日没＝終末」を意味する。
   * **南北軸の二面性**:
     * **南側（South）**: 太陽の光が降り注ぐ「神の慈悲と聖者の領域」。主たる信徒用墓地、回廊（Cloister）、参詣用の主ポルティコ（南扉口）が配置される。
     * **北側（North）**: 太陽が差さない「寒冷・暗黒・悪魔の領域」。一般の信徒は埋葬を嫌がり、納骨堂（骨を一時保管する場所）、未洗礼の幼児や処刑された罪人の埋葬地、あるいは司祭の居住区（俗人の侵入を防ぐ）に充てられた。

2. **聖域の囲い込み（Churchyard Enclosure）**:
   * 墓地は無秩序に広がる原野ではなく、**高さ1.2〜1.8mの石壁や生垣で厳重に四方を囲われていた**。
   * **理由**:
     * **衛生・尊厳**: 放し飼いにされていた家畜（特に豚）が死体を掘り返すのを防ぐ。
     * **聖域権（Sanctuary / Asyl）**: 壁の内部は教会の治外法権であり、犯罪者や追われる者が逃げ込めば世俗領主の警察権が及ばない神聖領域であった。

3. **遺体受入門（リッチゲート / Lychgate）**:
   * 街路から墓地への入口に設けられる小さな屋根付きの門。
   * 葬儀の際、司祭が迎えに来るまで遺体の棺（Lych）を日陰・雨風から守るために屋根とベンチが設けられていた。

4. **納骨堂（Charnel House / Ossuary / Charnier）**:
   * 中世都市の城壁内の土地は極めて限られていた。数百年もの間、同じ教会墓地に何千人もの市民を埋葬し続けたため、**遺体は数年〜10数年で掘り起こされ、白骨化した骨（特に頭蓋骨と大腿骨）は納骨堂に集約保管された**。
   * 墓地境界壁の北側・西側に沿って、あるいは地下室（Crypt）に長細い納骨堂が建てられた。

## 3. 構成施設とスケール感（実測・寸法設計）

City Editorのメートル単位（`extentMeters: 600〜4800m`）に整合する各施設のフットプリント寸法を定義する。

### 3.1 構成要素一覧

| 要素 | 役割 | 典型的な寸法 (幅×長さ) | 敷地内での配置位置 |
| :--- | :--- | :--- | :--- |
| **教会堂本体<br>(Church / Temple)** | 礼拝の中心。ラテン十字形（身廊・翼廊・アプス） | 幅 12〜25m<br>長さ 25〜60m | 敷地の北側中央。東西軸に平行。 |
| **教会墓地<br>(Churchyard)** | 一般信徒の埋葬芝地。墓標列・土盛 | 敷地床面積の 50〜70%<br>(数百〜2,500 m²) | **教会の南側および東側** |
| **司祭館・牧師館<br>(Rectory / Presbytery)** | 司祭・従者の居住棟。私有菜園付き | 幅 8〜12m<br>長さ 12〜16m | 敷地の**北西隅**、または街路に面した北側 |
| **納骨堂<br>(Charnel House)** | 掘り起こされた骨を保管する細長い建物 | 幅 5〜7m<br>長さ 12〜25m | 敷地の**北東隅または北側境界壁沿い** |
| **外周石壁<br>(Precinct Wall)** | 聖域と俗界を分かつ境界壁 | 厚み 0.6〜1.0m<br>高さ 1.5m | 敷地ポリゴン外周（街路・隣棟側） |
| **リッチゲート<br>(Lychgate)** | 屋根付きの墓地入口門 | 幅 3〜4m<br>奥行き 3〜4m | 主街路に面した石壁の開口部 |
| **中央十字架<br>(Calvary / Pulpit Cross)** | 説教壇を兼ねる石造十字架塔 | 基壇 2〜3m四方<br>高さ 3〜5m | 墓地の中央、または門から南扉口への小道沿い |
| **イチイ／糸杉<br>(Yew / Cypress Trees)** | 不滅と死と再生の象徴。毒性で家畜除け | 樹冠直径 4〜7m | 墓地南側の境界沿い、門の脇 |

## 4. City Editorへの機能統合設計

### 4.1 二つのアプローチ

#### A. 教会区聖域（Church Precinct）ファブリック
* **トリガー**: `element.kind === "temple"` が存在するFace、または `ward === "market"` 付近の宗教セル。
* **特徴**:
  * 既存の単なる矩形 `templeRect` を、**ラテン十字の教会堂＋東側アプス半円**に進化。
  * セル内部の空地を `medievalFabric` の住宅で埋めず、**南側に教会墓地、北側に司祭館と納骨堂**をプロシージャル配置。
  * 周囲を石壁（Wall）で囲い、最寄りの道路に向けてリッチゲートと石畳アプローチを敷設。

#### B. 新Ward `cemetery`（独立型共同墓地）
* **トリガー**: `FaceProperties.ward === "cemetery"`
* **用途**:
  * 都市周縁、城壁際、または城外（outskirts）に配置される広大な共同墓地（例: パリのイノサン墓地、野戦病院墓地）。
  * 住宅は一切配置されない。
* **特徴**:
  * 外周を**四角い回廊型納骨アーケード（Charnel Galleries）**または石壁が囲む。
  * 内部は整然とした格子状の墓標列（Grave rows）、中央の大型カルヴァリオ（十字架塔）、糸杉の並木道。
  * 中央または北端に**小礼拝堂（Mortuary Chapel: 12×8m）**を配置。

## 5. 幾何生成アルゴリズム（Procedural Layout）

教会区（Church Precinct）のセルポリゴン $P$ が与えられたときの自動配置手順：

```
                    [ 幾何生成パイプライン ]

       入力: セルポリゴン P, extentMeters, 近接道路 Frontage
                          │
                          ▼
             1. 主軸決定 (Orientation)
             ・原則真東 (Vector [1, 0]) を目標角とする
             ・ただし敷地が狭い場合は、敷地長軸と東西角の内積で重み付け
                          │
                          ▼
             2. 敷地ゾーニング (North/South Split)
             ・主軸に平行な線で敷地を「北帯 (35%)」と「南帯 (65%)」に分割
                          │
                          ▼
        ┌─────────────────┴─────────────────┐
        ▼                                   ▼
 [ 北帯: 建築ゾーン ]                [ 南帯: 墓地ゾーン ]
 ・教会本体 (ラテン十字 + アプス)     ・外周石壁 (Setback 1.5m)
 ・司祭館 (北西)                      ・主ゲート (Lychgate)
 ・納骨堂 (北東)                      ・門〜教会扉への歩道
                                      ・中央十字架 (Calvary)
                                      ・墓標グリッド (East-West向)
                                      ・イチイ・糸杉の樹冠配置
```

### 5.1 教会堂本体の幾何生成（Latin Cross Footprint）
単なる矩形ではなく、本格的な中世教会形状を生成：
1. **身廊（Nave）**: 長さ $L$、幅 $W$（既存の `TEMPLE_FOOTPRINT_M` を基準）。
2. **翼廊（Transept）**: 身廊の東側 2/3 の位置で交差。幅 $W \times 0.7$、翼長 $W \times 1.6$。
3. **後陣（Apse）**: 東端に突き出す半円または多角形（半径 $W \times 0.4$）。
4. **西塔（West Tower）**: 西端に正方形の鐘楼塔（幅 $W \times 0.6$）。

### 5.2 墓地の装飾・テクスチャ生成
1. **外周壁**: セルの境界線から 1.2m インセットしたポリラインを石壁（幅0.8m）として描画。
2. **小道（Path）**: 街路に最も近い境界点（Lychgate）から、教会南ポルティコ、および中央十字架を結ぶ細い歩道（幅1.5〜2.0m）。
3. **墓標（Graves）**:
   * すべて東西軸に直交（遺体は東を向いて仰臥するため、墓石は西端に立ち、盛り土は東西に長い短冊形: 0.8m × 2.0m）。
   * 墓地ゾーンの芝生内に、2.5m ピッチで規則正しく並ぶ。
4. **植生（Trees）**:
   * イチイ（Yew）や糸杉（Cypress）を、教会壁や墓石列と干渉しない南側壁沿いに2〜4本配置。

## 6. データモデル・型定義案

```typescript
// src/city-editor/core/types.ts の拡張案

export type WardKind =
  | "market"
  | "castle"
  | "merchant"
  | "craftsmen"
  | "patriciate"
  | "harbor"
  | "park"
  | "farm"
  | "cemetery"  // ← 新設: 独立墓地
  | "empty";

export interface ChurchPrecinct {
  faceId: Id;
  churchBuilding: {
    footprint: Point[];   // ラテン十字 + アプス
    tower?: Point[];       // 西側鐘楼
    entrance: Point;       // 南側主ポルティコ
  };
  graveyard: {
    wall: Point[][];       // 外周石壁
    gate: Point;           // リッチゲート位置
    paths: Point[][];      // 歩道ポリライン
    calvary: Point;        // 中央十字架
    graves: Point[][];     // 個別の墓標短冊ポリゴン
    trees: Point[];        // イチイ・糸杉
  };
  ancillaryBuildings: {
    rectory?: Point[];     // 司祭館
    charnelHouse?: Point[];// 納骨堂
  };
}
```

## 7. 実装ステップ計画

1. **Phase 1: 教会堂（Latin Cross）形状と教会墓地の幾何生成モジュール作成 (`churchFabric.ts`)**
   - 既存の `temple` 矩形生成を拡張し、ラテン十字・アプス・西塔のポリゴン生成を実装。
   - 教会の南側に教会墓地（石壁、中央十字架、歩道、墓標列、樹木）を生成するロジックを実装。

2. **Phase 2: 新Ward `cemetery`（独立墓地）のサポート**
   - `WardKind` に `"cemetery"` を追加。
   - `medievalFabric` および `blockInfill` で、`cemetery` セルが住宅で埋まらないよう除外。
   - 独立墓地（回廊納骨堂＋礼拝堂＋墓標群）の生成をサポート。

3. **Phase 3: レンダリングとスタイリング (`svg.ts` / CSS)**
   - 墓標（小さな四角・短冊）、石壁、イチイの深い緑、十字架のSVG描画コンポーネントを追加。
   - 教会屋根と一般住宅屋根の質感の差別化。
