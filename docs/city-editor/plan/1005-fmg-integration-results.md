# CE・FMG連携改善 実装・計測記録

実施日: 2026-10-05

対象は[設計書](1005-fmg-integration-design.md)のP0〜P4の初期実装。P5の自動詳細化は導入しない。

## 実装

- Burg Editorは専用の簡略SVG経路を使用する。詳細住宅・敷地分割・公園fabric・水車fabric・港の詳細描画を呼ばず、既存の構造と検証済み固定地物を共有する。
- 住宅記号は安定した街区IDとseedから直接配置する。街区あたり最大3個、全体最大300個。複雑な街区と水面・道路・施設・城郭・ランドマーク・堀・固定橋取付部の予約に重なる候補は省略する。正式な住宅数には含めない。
- 入力全体・生成器版・プレビュー版・建築設定・再試行番号を含む入力キーで要求を管理する。進捗、棄却理由、取消、古い結果の破棄、Blob URL解放、画像読み込みエラーを扱う。
- FMG descriptor v3に地域スナップショットを追加する。周辺都市の実座標・名称・推定規模、route/branch ID付き道路、coverage、source revisionを保存する。v2入力は従来経路を維持する。
- CE文書v4に中心部境界と接続診断を保存する。保存再読込・共有・履歴・ランドマーク編集で維持する。壊れた地域入力はエラー表示する。
- 郊外道路は既存frameRoadsの検証経路からSVG pathとして描画する。中心部・郊外の表示を独立させ、水系と検証済み橋は共通表示する。未検証の郊外横断を道路で覆わない。
- 地域モードの中心部メッシュと構造計画の範囲を表示範囲から分離する。河川港に必要な範囲は保持する。単独CEと旧ドキュメントの手編集セルを削除しない。

## ブラウザ計測

実行例（ローカルViteサーバーが必要）:

```sh
node scripts/benchmarkCityPreview.mjs --sizes=small,medium,large --terrains=inland,river,coast --runs=11
```

`--descriptor=...`でFMGから保存した入力を指定できる。`--out=...`でJSONの保存先、`--screenshot=...`で簡略画像のスクリーンショット保存先を指定できる。

Chromium、macOS arm64、Node v22.23.1。固定seedは`preview-benchmark-v1`、evolution grid。各ケースの初回1回とウォーム10回を分離し、同じWorker生成結果を簡略・詳細で交互に描画した。作業ツリーの実装を使った測定で、コミット・実行環境はJSONにも記録する。

以下はWorker完了後のSVG生成・シリアライズ・画像decodeまでのウォーム中央値 / p95（ms）。DOMへの描画完了時刻ではない。

| 規模 | 地形 | 簡略 中央値 / p95 | 詳細 中央値 / p95 |
| --- | --- | ---: | ---: |
| large | inland | 8.6 / 8.9 | 620.3 / 686.9 |
| large | river | 11.3 / 15.2 | 1168.2 / 1287.6 |
| large | coast | 11.0 / 21.2 | 1730.4 / 1936.2 |

全99回が生成成功。住宅記号数は122〜191個で予算内。大都市のWorker完了後処理は中央値で約98.6〜99.4%短縮した。これは合成入力の測定であり、FMG実入力での初回表示30%短縮や失敗時間の非悪化を確定する結果ではない。

追加で保存済みFMG河川港fixtureのKiszaszを地域モードに適応して11回実行した。既存の河川・道路・検証済み固定橋はそのまま使い、周辺都市の座標がないため追加しなかった。全11回が成功し、中心部は54セル。簡略の中央値 / p95は8.0 / 19.9 ms、詳細は43.9 / 60.5 ms。約900 mの固定横断と河岸を保持した画像も確認した。

計測スクリプトは入力・グリッド・Worker・結果転送・SVG段階・画像decode・最初の失敗・形状数・SVGバイト数をJSONに記録する。Burg Editorも段階別時間と画像load時刻を開発者コンソールに記録する。

## 検証と残る計測

- 詳細生成関数を例外に置き換えた簡略レンダラー試験、記号上限と決定性、固定水面・固定橋の描画一致。
- 都市切替・入力更新・再試行・取消・古い完了・URL解放の非同期試験。
- 旧入力・新地域入力・保存往復・undo/redo・SVGの単一Y反転・中心部メッシュと生成住宅数の表示範囲独立性。
- 描画、河川横断、Worker、共有入力、FMG descriptor、登録街道の回帰試験。型チェックとarchitecture lint。

初期のcoreBoundaryは既存市街地メッシュの外接矩形を使う。郊外は参照・選択のみ。実FMGの遠い河岸・河川港の網羅的なケース、失敗入力のブラウザ性能計測と完全な初回ロード比較は追加計測が必要。P5は設計どおり後続の任意工程。
