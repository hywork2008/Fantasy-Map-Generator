The Encyclopedia collects explanations of this map's features and rules, the events of the world you generated, and real-world history in one searchable place.

## How to use it

- Type in the search box to find an entry. English and Japanese terms both work, whatever the interface language is.
- Click a highlighted term inside an article to open that entry. **◀ Back** returns to the previous one.
- Each article lists the entries it links to and the entries that link back to it.

## What it covers

| Section | Contents |
| :--- | :--- |
| Features | How the map's tools and panels work, e.g. [[feature:cost-of-living]] |
| World rules | Setting notes for this fork's simulation, e.g. [[rule:multi-race-geopolitics]] |
| History | Real-world wars and inventions from ancient Rome to medieval Europe (in preparation) |
| This world | Wars, technologies, states, and people of the current map (in preparation) |

The history and world sections will add timelines that replay troop movements and battles on the map.
