Encyclopedia(百科事典)は、この地図の機能やルールの説明、生成した世界の出来事、そして実際の歴史を、1か所で検索して読めるようにまとめたものです。

## 使い方

- 検索欄に語句を入力すると項目が見つかります。画面の言語に関係なく、英語でも日本語でも検索できます。
- 本文中の強調された語句をクリックすると、その項目に移動します。**◀ 戻る** で前の項目に戻ります。
- 各項目の末尾に、その項目からのリンク先と、その項目を参照している項目が並びます。

## 収録内容

| 区分 | 内容 |
| :--- | :--- |
| 機能 | 地図のツールやパネルの使い方。例: [[feature:cost-of-living]] |
| 世界のルール | このフォークのシミュレーションの設定解説。例: [[rule:multi-race-geopolitics]] |
| 史実 | 古代ローマから中世ヨーロッパまでの実際の戦争と技術(準備中) |
| この世界 | 現在の地図の戦争・技術・国家・人物(準備中) |

史実とこの世界の区分には、部隊の移動や戦いを地図上で再生する年表が加わる予定です。
